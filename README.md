# 企业资产管理系统（Asset Management System）

## 项目简介

这是一个用于产品演示的企业资产管理前端项目，不是生产系统。当前支持资产申请、审批、配给、领用、借用、资产更换、统一申请汇总、后台配置、报废和机房资产等流程连续演示，并保持导航、页面结构和演示数据一致。

## 技术架构

- React 19 + Create React App
- React Router 7
- Ant Design 6
- Tailwind CSS
- Lucide React
- Recharts
- Playwright

主要分层：

```text
页面组件
  ↓
业务 Service
  ↓
demoStorage
  ↓
localStorage 演示数据
```

- 页面不直接操作 localStorage。
- 查询区域统一使用 `QueryBar` 和 `QueryItem`。
- 状态优先使用 `StatusTag` 或模块统一 Tag 规则。
- 选择资产和基础数据优先复用现有选择弹窗结构。

## 核心流程

### 资产申请与领用

```text
资产申请 → 业务审批 → 资产配给
                         ├─ 库存领用 → ES前台领用 → 员工领用确认
                         └─ 统一采购 → 统一申请汇总-资产
```

### 资产借用

```text
资产借用 → 借用配给 → 借用审批 → 借用发放
                                  ↓
                           员工借用确认
                                  ↓
                              执行出库
```

### 资产更换

```text
我的资产 → 资产更换申请 → MIS鉴定
                           ↓
                    旧资产退回确认
                           ↓
                        执行入库
                           ↓
                    选择同小类新资产
                           ↓
                    新资产领取确认
                           ↓
                        执行出库
```

资产更换规则：

- 正式员工和实习生可对本人名下符合条件的资产发起更换，外包员工不展示入口。
- 批量提交时，一个旧资产生成一张独立申请单。
- 资产必须为“在用-使用中”、配置允许更换且未被其他业务单据锁定。
- 苹果笔记本、苹果一体机、组装机、工作站不支持本流程。
- 资产更换必经 MIS 鉴定。
- 旧资产入库完成后才开放新资产发放。
- 新资产必须与旧资产小类一致，并满足仓库、公司、板块和可出库规则。
- 旧资产退回和新资产领取分别扫码或刷卡确认，分别生成入库单和出库单。
- 旧资产已退库后放弃新资产领用，保留退库结果并结束流程。

## 主要页面能力

### 资产申请、审批与配给

- 资产申请支持资产/耗材、五级物料选择、超标判断和预览。
- 业务审批支持同意、驳回、返回和加签。
- 资产配给支持库存领用、统一采购、资产匹配和员工名下资产查询。

### 资产领用

- ES 前台领用支持仓库校验、地点联动、资产匹配和单据备注。
- 员工领用确认支持刷卡和扫码演示。

### 资产借用

- 借用期限最长三个月，支持快捷日期范围。
- 支持 ES 配给、领导审批、库管员发放和员工确认。
- 不提供续借入口。

### 资产更换

- “我的资产”支持查询、单条更换和批量更换，并展示不可更换原因。
- 申请页支持更换原因、退回资产信息和须知确认。
- “我的资产更换申请”展示状态、当前节点、入库单、出库单和完整流程记录。
- MIS 页面强制校验鉴定结果和同意/驳回组合。
- 库管员办理页分为旧资产退回和新资产发放两个阶段。
- 待发放资产弹窗按同小类、仓库、可出库状态和锁定状态过滤。
- 员工资产确认支持旧资产退回和新资产领取两次确认。
