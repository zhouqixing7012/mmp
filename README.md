# 企业资产管理系统（Asset Management System）

## 项目简介

这是一个用于产品演示的企业资产管理前端项目，不是生产系统。项目重点是让资产申请、业务审批、资产配给、统一申请汇总、ES 前台领用、员工领用确认、资产借用、后台配置、报废管理和机房资产等流程可以连续演示，并保持页面风格、数据口径和导航结构一致。

## 当前技术栈

- React 19
- Create React App / react-scripts 5
- React Router 7
- Ant Design 6
- Tailwind CSS
- Lucide React
- Recharts
- Playwright

`package.json` 是当前依赖版本的准绳。

## 当前核心流程

### 资产申请与领用

```text
资产申请
  ↓
业务审批
  ↓
资产配给
  ├─ 库存领用 → ES前台领用 → 员工领用确认
  └─ 统一采购 → 统一申请汇总-资产 → 汇总审批
```

### 资产借用

```text
资产借用 → 借用配给 → 借用审批 → 借用发放
                                  ↓
                           员工借用确认
                                  ↓
                              执行出库
```

## 主要页面能力

### 资产申请

- 进入页面自动展示申请须知，只能通过“已阅读”关闭。
- 支持资产与耗材 Tab、多选物资和五级物料选择。
- 物料层级为：大类 → 小类 → 品牌 → 型号 → 配置。
- 申请用途包括员工用机、部门公用、其他用途、专业用途。
- 详细说明必填，最多 400 字。
- 支持是否超标判断和预览页超标提示。
- 预览是页面状态，不使用弹窗。

### 业务审批

- 页面直接进入审批详情，不再经过前置查询列表。
- 展示申请人信息、申请物资明细和审批信息。
- 操作包括同意、驳回、返回和加签。
- 是否超标统一展示“未超标”或“已超标”。

### 资产配给

- 页面直接进入待配给详情。
- 支持库存领用和统一采购。
- 库存领用必须匹配资产。
- 匹配资产弹窗支持标签号、序列号、板块和资产说明查询。
- 支持查看申请人名下资产。
- 页面顺序为：申请人信息、申请物资明细、ES配给处理、审批信息、审批操作。
- 同意、驳回、返回和加签统一放在页面最下方。

### 统一申请汇总-资产

- 汇总单列表的申请部门为蓝色链接，点击效果与“查看”一致。
- 汇总明细支持编辑 ES 建议，最多 400 字。
- 汇总页支持编辑 ES 汇总说明和项目用途说明。
- 超标申请和部门现资产参考使用量无数据时保留表头并显示“无展示数据”。
- 导出按钮位于超标申请和非超标申请的公共上方，合并导出两部分申请明细。
- 点击提交后进入只读的统一申请汇总审批页。

### ES前台领用

- 当前仓库和单据备注位于申请人信息区域。
- 申请资产信息采用统一表格式展示。
- 只读字段显示文本，可编辑字段直接在对应单元格中编辑。
- 资产标签号必填，点击放大镜打开物资列表弹窗修改。
- 城市、建筑和楼层按照地点维护数据联动。
- 清空城市时同步清空建筑和楼层；修改建筑时清空楼层。
- 申请资产信息不展示申请原因。
- 领用确认前校验资产所在仓库与当前仓库是否一致。

### 员工领用确认

- 领用人信息仅展示使用人和部门。
- 展示领用物资明细、保管职责、刷卡输入和二维码。
- 固定提示为：`提示：我已阅读并确认保管职责说明，特此刷卡确认！`
- 员工卡号为空时不能确认领用。

### 资产借用

- 仅正式员工可发起；非正式员工展示拦截提示。
- 只展示启用且“是否允许借用=是”的资产物料，不支持单独借用耗材。
- 借用开始日期可选当前日期至未来 30 天，借用期限最长 3 个月。
- 支持近 7 天、近 15 天、近 1 个月、近 2 个月、近 3 个月快捷选择。
- 同一物资数量大于 1 时，提交后拆成多行，但仍属于同一借用单。
- ES 可匹配实物资产或暂不匹配，库管员发放时可重新匹配。
- 直属领导审批按申请人汇报链的 5 级及以上领导处理。
- 支持狐小e扫码、刷卡、输入工号三种员工确认方式。
- 员工确认完成后，库管员可执行出库或选择放弃领用。
- 不提供续借入口；到期和逾期提醒不改变单据状态或资产标记。

## 开发约定

- 每次任务前先读 `AI_RULES.md`、`CLAUDE.md`、`CONTEXT.md`。
- 新增或修改页面前先搜索相似页面和通用组件。
- 页面优先使用 Ant Design。
- 状态展示统一使用 `StatusTag` 或现有统一状态规则。
- 选择弹窗优先复用 `SelectModal` 或项目中已有同类选择弹窗。
- 查询区域使用 `QueryBar` 和 `QueryItem`。
- 页面不直接操作 localStorage，统一通过 service 调用 `demoStorage`。
- 不新增依赖，不修改 `package.json`，不删除已有路由和功能。
