# 企业资产管理系统（Asset Management System）

## 项目简介

这是一个用于产品演示的企业资产管理前端项目，不是生产系统。当前支持资产申请、审批、配给、领用、借用、资产更换、资产退库、合约号码退库、统一申请汇总、后台配置、后台资产管理、报废和机房资产等流程连续演示，并保持导航、页面结构和演示数据一致。

## 技术架构

- React 19 + Create React App
- React Router 7
- Ant Design 6
- Tailwind CSS
- Lucide React
- Recharts
- Playwright

主要分层：

```text
页面组件
  ↓
业务 Service
  ↓
demoStorage
  ↓
localStorage 演示数据
```

- 页面不直接操作 localStorage。
- 查询区域统一使用 `QueryBar` 和 `QueryItem`。
- 状态优先使用 `StatusTag` 或模块统一 Tag 规则。
- 选择资产和基础数据优先复用现有选择弹窗结构。

## 核心流程

### 资产申请与领用

```text
资产申请 → 业务审批 → 资产配给
                         ├─ 库存领用 → ES前台领用 → 员工领用确认
                         └─ 统一采购 → 统一申请汇总-资产
```

### 资产借用

```text
资产借用 → 借用配给 → 借用审批 → 借用发放
                                  ↓
                           员工借用确认
                                  ↓
                              执行出库
```

### 资产更换

```text
我的资产 → 资产更换申请 → MIS鉴定
                           ↓
                    旧资产退回确认
                           ↓
                        执行入库
                           ↓
                    选择同小类新资产
                           ↓
                    新资产领取确认
                           ↓
                        执行出库
```

### 资产退库

```text
我的资产 → 资产退库
              ↓
       部门公用？领导审批
              ↓
       需要MIS？MIS鉴定
              ↓
         资产退库办理
              ↓
         员工退库确认
              ↓
           执行入库
```

资产退库规则：

- 支持员工单选或批量发起退库，提交后按一项主资产一张单据拆分。
- 主资产存在升级耗材时自动带出并随主资产一并退库。
- 部门公用资产先进入直属 5 级及以上领导审批。
- 物料配置要求退库 MIS 鉴定时进入 MIS 节点，否则由 ES 补充鉴定。
- 员工确认支持狐小 e 扫码、刷卡和手工输入工号。
- 正常退库生成演示入库单；驳回和放弃退库不生成入库单。

### 合约号码退库

```text
合约号码退库 → 合约号码退库办理
                         ↓
                  员工号码退库确认
                         ↓
                      执行入库
```

合约号码退库规则：

- 支持本人名下在用合约号码多选提交，按一号一单拆分。
- 系统按申请人公司和办公区匹配默认号码仓库。
- 员工确认支持扫码、刷卡和手工输入工号。
- 正常退还生成演示号码入库单，号码状态按“在库（旧）”口径处理。

## 主要页面能力

### 后台资产维护

- 查询条件按现系统截图还原，支持标签号、公司、部门、责任人、序列号、资产说明、资产类别、状态、板块、成本中心、用途、仓库、资产类型和主资产标签号筛选。
- 列表固定展示用户确认的资产字段，操作仅保留编辑和导出。
- 编辑演示数据通过 service 写入 `demoStorage`；导出按当前查询结果生成 CSV。

### 资产申请、审批与配给

- 资产申请支持资产/耗材、五级物料选择、超标判断和预览。
- 业务审批支持同意、驳回、返回和加签。
- 资产配给支持库存领用、统一采购、资产匹配和员工名下资产查询。

### 资产领用

- ES 前台领用支持仓库校验、地点联动、资产匹配和单据备注。
- 员工领用确认支持刷卡和扫码演示。

### 资产借用

- 借用期限最长三个月，支持快捷日期范围。
- 支持 ES 配给、领导审批、库管员发放和员工确认。
- 不提供续借入口。

### 资产更换

- “我的资产”支持查询、单条更换和批量更换，并展示不可更换原因。
- 申请页支持更换原因、退回资产信息和须知确认。
- “我的资产更换申请”展示状态、当前节点、入库单、出库单和完整流程记录。
- MIS 页面强制校验鉴定结果和同意/驳回组合。
- 库管员办理页分为旧资产退回和新资产发放两个阶段。
- 员工资产确认支持旧资产退回和新资产领取两次确认。

### 资产退库

- “我的资产”同时提供退库和批量退库入口。
- 申请页支持资产补充选择、关联耗材强制跟随、退库原因和我的申请列表。
- 审批页整合领导审批和 MIS 鉴定待办。
- 办理页支持仓库、资产标记、日期、使用说明、员工确认、入库、驳回和放弃退库。
- 员工确认页支持扫码、刷卡和工号确认。

### 合约号码退库

- 申请页展示本人名下合约号码，支持多选、附件和我的申请列表。
- 办理页支持号码仓库、员工确认、执行入库、驳回和放弃退还。
- 员工号码确认页支持扫码、刷卡和工号确认。
