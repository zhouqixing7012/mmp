# 资产管理 - 跨公司转移 PRD

## 1. 背景

跨公司转移用于处理资产在不同财务公司之间发生权属调整的业务场景。

跨公司转移属于调账业务。申请审批完成后，资产进入待报废池，后续由 ES 账务人员发起账面报废，完成正式账务调整。

本业务仅处理资产，不处理耗材和合约号码。

本 PRD 覆盖：

- 机房资产；
- 非机房软件资产；
- 非机房办公设备资产。

## 2. 权限

### 2.1 发起权限

跨公司转移根据资产类型走不同发起路径。

| 资产范围 | 发起人 |
|---|---|
| 机房资产 | 当前资产责任人 |
| 非机房软件资产 | 当前资产责任人 |
| 非机房办公设备资产 | ES 专员 |

### 2.2 资产分类判定

非机房资产按资产大类代码区分：

| 业务分类 | 资产大类 |
|---|---|
| 办公设备 | 11.PC / 12.NOTEBOOK / 13.OFFICE EQUIPMENT / 16.FURNITURE / 18.VEHICLE / 19.BUILDINGS / 20.Investment Properties / 21.LEASEHOLD IMPROVEMENT / 22.Park lot land use rights |
| 软件 | 17.SOFTWARE |

机房资产按资产大类判定：14.SERVER、15.NET EQUIPMENT。除机房资产和软件外，本轮涉及的其余资产大类统一按“办公设备”流程处理。

当前跨公司转移仅覆盖以上已明确资产范围。

### 2.3 数据权限

- 资产责任人发起时，只允许选择本人作为当前责任人的可转移资产。
- ES 专员发起办公设备跨公司转移时，只允许选择其资产数据权限范围内的可转移资产。
- 查询、查看、保存、提交和审批时均重新校验当前用户权限。
- 已正式报废资产不可发起跨公司转移。
- 耗材、合约号码不进入跨公司转移资产选择范围。

### 2.4 公司范围

跨公司转移支持所有有效财务公司之间的合法转移。

原公司与新公司必须不同。

当转入方或转出方涉及以下公司时，触发特殊财务同步规则：

- 新媒体上海分公司；
- 新媒体广州分公司。

特殊处理规则见 3.6。

## 3. 通用规则

### 3.1 单据状态

跨公司转移单据状态：

- 草稿；
- 审批中；
- 已驳回；
- 已完成。

规则：

- 新建单据默认为草稿；
- 草稿可编辑、保存和删除；
- 提交成功后进入审批中；
- 审批驳回后状态变为已驳回，退回发起人，允许修改后重新提交；
- 最后一个审批节点通过并成功进入待报废池后，单据状态变为已完成；
- 已完成单据只读。

### 3.2 单据与审批路径

同一张跨公司转移单只允许包含同一资产范围的数据。

资产范围分为：

1. 机房资产；
2. 软件；
3. 办公设备。

机房资产与软件虽然审批链相同，也不得混在同一张申请单中。不同资产范围必须拆单。

### 3.3 资产选择

资产必须来自正式资产台账。

可选资产必须同时满足：

- 当前用户有发起权限；
- 资产未正式报废；
- 同一资产不存在未结束的跨公司转移或资产报废申请；
- 资产属于当前单据对应的资产范围；
- 原公司与拟转入公司不同。

资产选择后，以下原资产信息按同一资产卡片自动带出且只读：

- 资产标签号；
- 资产序列号；
- 资产大类；
- 资产小类；
- 资产说明；
- 原公司；
- 原板块；
- 当前责任人；
- 当前成本中心；
- 当前仓库；
- City；
- Building；
- Floor；
- 资产状态。

### 3.4 录入方式

跨公司转移明细支持：

- 手工选择资产；
- Excel 导入。

Excel 导入与手工选择使用同一套业务校验。

导入任一资产不符合规则时，该行返回明确错误原因；整批提交前必须保证所有明细均通过校验。

### 3.5 附件

支持上传附件。

规则：

- 文件格式不限；
- 单文件大小不得超过 20MB；
- 超过 20MB 时阻止上传并提示；
- 已上传附件支持查看文件名和删除。

### 3.6 上海 / 广州新媒体特殊财务同步

所有有效财务公司均可进行跨公司转移。

如果转入方或转出方为“新媒体上海分公司”或“新媒体广州分公司”，系统自动识别为特殊分公司调账，不要求用户手工维护“调拨”标签。

跨公司转移的转入方或转出方涉及新媒体上海分公司、新媒体广州分公司时，执行特殊财务同步：

1. 系统给原资产号增加后缀后，将调账单据推送财务系统；
2. 财务系统完成同步变更后，目标分公司按原资产号手工新增资产；
3. 该场景不按普通调账规则直接把原资产卡修改为目标公司的资产卡；
4. 非上海、广州新媒体相关转移按普通调账规则处理。

### 3.7 是否处置

跨公司转移属于调账业务。

调账资产完成后续账面报废后不进入实物处置流程。

“是否处置”由系统按调账业务固定判定为否，不提供用户编辑。

## 5. 审批流程

## 5.1 机房资产 + 非机房软件

流程：

> 发起人提交 → 责任人 5 级及以上直属领导审批 → 责任人 7 级及以上直属领导审批 → 进入待报废池 → 流程结束

规则：

- 发起人为资产责任人；
- 5 级及以上直属领导按发起人组织关系自动匹配；
- 7 级及以上直属领导按发起人组织关系自动匹配；
- 如果 5 级及以上直属领导与 7 级及以上直属领导为同一人，第二个重复审批节点自动跳过，只审批一次；
- 任一审批节点驳回，单据退回发起人；
- 发起人修改后可重新提交。

## 5.2 非机房办公设备

流程：

> ES 专员提交 → ES 主管确认 → 进入待报废池 → 流程结束

规则：

- 发起人为 ES 专员；
- 审批节点为 ES 主管确认；
- ES 主管驳回后，单据退回发起人；
- 发起人修改后可重新提交。

## 5.3 审批页面

审批页面中：

- 基本信息只读；
- 每条资产展示原值与调账后目标值的差异，包括新责任人、新公司、新板块、新成本中心、City、Building、Floor 和调账后仓库；仅列出发生变化的字段；
- 附件支持查看；
- 审批历史支持查看。

审批操作：

- 通过；
- 驳回。

审批意见允许填写。

## 6. 校验

### 6.1 保存

保存草稿时：

- 允许资产明细暂未完整；
- 已填写字段必须满足基础数据合法性；
- 首次保存后生成申请单号。

### 6.2 提交

提交时必须校验：

1. 至少存在 1 条资产明细；
2. 单据内所有资产属于同一审批路径；
3. 当前发起人符合对应资产范围的发起权限；
4. 资产未正式报废；
5. 资产未被互斥业务锁定；
6. 新公司不等于原公司；
7. 新公司、新板块、新成本中心、新责任人、City、Building、Floor均已填写；
8. 新责任人属于新公司；
9. Building 属于所选 City；
10. 调账后仓库如填写，必须为有效仓库；
11. 附件单文件不得超过 20MB；
12. Excel 导入数据全部通过同一套资产和字段校验。

任一资产校验失败时，不允许部分提交。

### 6.3 重复提交

提交处理中：

- 禁止重复提交；
- 同一申请不得重复创建审批实例。

## 7. 流程完成后的业务结果

最后一个审批节点通过后，系统按以下顺序处理：

1. 将单据内资产写入待报废池；在库资产状态更新为“在库-待报废”，员工名下资产状态保持不变；
2. 待报废池来源业务标记为“跨公司转移/调账”；
3. 保存本次调账目标信息，包括新公司、新板块、新成本中心、新责任人、City、Building、Floor、调账后仓库、用途、项目和备注；
4. 跨公司转移单据状态更新为已完成；
5. 向发起人及所有审批参与人发送服务号通知；
6. 后续进入账面报废流程。

跨公司转移审批完成时不直接修改正式资产台账中的公司、板块、成本中心、责任人、位置和仓库。

正式台账变更由后续账面报废执行环节完成。

涉及新媒体上海分公司或新媒体广州分公司的资产，在后续财务同步时按 3.6 节执行特殊资产号处理。

## 9. 通知

跨公司转移流程结束后发送服务号通知。

通知对象：

- 发起人；
- 所有实际参与审批的人员。

被自动跳过的重复审批节点不作为实际审批参与人重复发送通知。

通知内容：

- 申请单号；
- 跨公司转移流程已完成；
- 资产数量；
- 后续状态：已进入待报废池，等待账面报废。

点击通知进入跨公司转移单据详情。
