## 业务映射规则管理模块 PRD

**文档版本**：v1.0
**更新日期**：2026年5月28日

---

### 一、模块概述

#### 1.1 模块定位

"业务映射规则管理"模块用于维护各种业务数据之间的映射关系，是系统各模块间数据关联的配置中心。

#### 1.2 包含页面

本模块包含5个子页面，通过顶部Tab标签页切换：

| Tab页面 | 功能说明 |
|---------|----------|
| 办公区与仓库映射 | 维护办公区和仓库的对应关系 |
| PS新员工领用物料映射 | 维护新员工领用物料的配置规则 |
| NO地点与资产地点映射 | 维护NO地点和资产地点的对应关系 |
| 虚拟库管员映射 | 维护虚拟库管员的分配规则 |
| 板块与账簿映射 | 维护业务板块和账簿的对应关系 |

### 七、通用交互说明

#### 7.1 分组表格交互

本模块部分页面支持分组显示（如NO地点、虚拟库管员、板块与账簿）：

- **分组行**：显示分组名称（如公司名称），左侧有展开/收起图标
- **展开状态**：显示该分组下的所有记录
- **收起状态**：隐藏该分组下的记录

#### 7.2 批量操作流程

与"业务基础数据维护"模块一致，参见PRD-业务基础数据维护.md 第九章。

#### 7.3 新增/编辑流程

与"业务基础数据维护"模块一致，参见PRD-业务基础数据维护.md 第九章。


### 八、页面6：公司板块领取资产权限

#### 8.1 页面功能

管理各公司、板块、物料大类下的资产领取权限。通过配置公司、板块、物料大类与员工所属公司、板块的映射关系，控制哪些员工可以领取哪些物料资产。

#### 8.2 主页面

##### 8.2.1 查询条件及表格

**字段说明**：

| 字段名称 | 是否查询条件 | 查询条件控件类型 | 提示文案 | 说明 |
|----------|:----------:|:--------------:|----------|------|
| 公司 | Y | Input + Search | 搜索公司... | 点击搜索图标选择公司，支持模糊检索 |
| 板块 | Y | Input + Search | 搜索板块... | 点击搜索图标选择板块，支持模糊检索 |
| 物料大类 | Y | Input + Search | 搜索物料大类... | 点击搜索图标选择物料大类，支持模糊检索 |

**按钮**：
- **查询**：蓝色主按钮，点击后根据条件筛选数据

##### 8.2.2 操作栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增权限弹窗 |
| 批量修改 | 灰色按钮 | 上传文件、下载模板 |

##### 8.2.3 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 序号 | 自动编号 |
| 公司 | 所属公司 |
| 板块 | 所属板块 |
