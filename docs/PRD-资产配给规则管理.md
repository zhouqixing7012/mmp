# 资产配给规则管理模块 PRD

**文档版本**：v1.0
**更新日期**：2026年5月28日

---

## 一、模块概述

### 1.1 模块定位

"资产配给规则管理"模块用于管理企业为员工配给资产的规则和方案，包括电脑设备、影像器材等不同类型的配给标准。

### 1.2 包含页面

本模块包含3个子页面，通过顶部Tab标签页切换：

| Tab页面 | 功能说明 |
|---------|----------|
| 电脑配给方案 | 管理电脑设备的配给方案和标准 |
| 影像器材配给方案 | 管理影像器材的配给方案和标准 |
| 配给规则 | 管理具体的配给规则和限制条件 |

---

## 二、页面1：电脑配给方案

### 2.1 页面功能

管理企业为员工配给电脑设备的方案，定义不同岗位、级别的电脑配置标准。

### 2.2 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 方案名称 | 文本输入框 | 支持模糊搜索，如输入"标准" |
| 方案描述 | 文本输入框 | 支持模糊搜索 |
| 资产级别 | 下拉选择框 | 选项：全部、高端、中低端 |

### 2.3 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 序号 | 自动编号 |
| 方案名称 | 如：标准台式设计机、高端笔记本方案 |
| 方案描述 | 方案的详细说明 |
| 物料小类 | 适用的物料小类，如：PC、NOTEBOOK |
| 资产级别 | 高端/中低端 |
| 数量 | 可配给数量 |
| 操作 | 编辑/删除按钮 |

### 2.4 工具栏

[新增] [删除] [批量修改]

### 2.5 新增/编辑弹窗

**表单字段**（每行2个）：

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 方案名称*（文本输入） | 方案描述（文本输入） |
| 第2行 | 物料小类*（搜索选择） | 资产级别*（下拉选择） |
| 第3行 | 数量*（数字输入） | （空） |

**校验规则**：
- 方案名称、物料小类、资产级别、数量：必填
- 方案名称唯一性校验
- 数量必须为正整数

---

## 三、页面2：影像器材配给方案

### 3.1 页面功能

管理企业为员工配给影像器材（如摄像机、镜头、三脚架等）的方案。

### 3.2 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  [Tab: 电脑配给方案] [影像器材配给方案] [配给规则]          │
├─────────────────────────────────────────────────────────────┤
│  搜索条件区域                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 影像器材配给方案名称: [▼选择]                         │  │
│  │ 影像器材配给方案描述: [▼选择]                         │  │
│  │ 资产级别: [▼选择]                                     │  │
│  │                                    [查询] [重置]      │  │
│  └───────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  工具栏: [新增] [删除]                                      │
├─────────────────────────────────────────────────────────────┤
│  数据表格                                                    │
│  ☐ │序号│影像器材配给..│配给描述│物料小类│资产级别│数量│操作│
│  ☐ │ 1  │高配影像器材  │方案3  │摄影摄像│ 高端   │ 3  │编辑│
│  ...                                                        │
├─────────────────────────────────────────────────────────────┤
│  共X条记录          [上一页] [1] [2] ... [下一页]  10条/页  │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 影像器材配给方案名称 | 下拉选择框 | 选项：全部、高配影像器材、标配影像器材 |
| 影像器材配给方案描述 | 下拉选择框 | 选项：全部、方案1、方案2、方案3 |
| 资产级别 | 下拉选择框 | 选项：全部、高端、中低端 |

### 3.4 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 序号 | 自动编号 |
| 影像器材配给方案名称 | 方案名称，如：高配影像器材 |
| 影像器材配给方案描述 | 方案描述，如：方案3 |
| 物料小类 | 适用的物料小类，如：摄影摄像-镜头 |
| 资产级别 | 高端/中低端 |
| 数量 | 可配给数量，如：3 |
| 操作 | 编辑/删除按钮 |

### 3.5 工具栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增弹窗 |
| 删除 | 红色按钮 | 删除选中的记录（需先勾选） |

### 3.6 新增/编辑弹窗

#### 弹窗标题
- 新增时：标题为"新增影像器材配给方案"
- 编辑时：标题为"编辑影像器材配给方案"

#### 表单字段布局

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 方案名称*（下拉选择） | 方案描述*（下拉选择） |
| 第2行 | 物料小类*（搜索选择） | 资产级别*（下拉选择） |
| 第3行 | 数量*（数字输入） | （空） |

#### 字段详细说明

**方案名称（必填）**：
- 控件类型：下拉选择框
- 选项：高配影像器材、标配影像器材
- 说明：选择预设的方案名称

**方案描述（必填）**：
- 控件类型：下拉选择框
- 选项：方案1、方案2、方案3
- 说明：方案的具体描述

**物料小类（必填）**：
- 控件类型：搜索选择框
- 交互：点击搜索图标，弹出物料小类选择弹窗
- 说明：该方案适用的物料小类，如：摄影摄像-镜头、摄影摄像-三脚架

**资产级别（必填）**：
- 控件类型：下拉选择框
- 选项：高端、中低端
- 说明：该方案适用的资产级别

**数量（必填）**：
- 控件类型：数字输入框
- 格式：正整数
- 说明：该方案允许配给的数量

#### 弹窗按钮

| 按钮 | 样式 | 功能 |
|------|------|------|
| 保存 | 蓝色主按钮 | 保存数据，关闭弹窗 |
| 返回 | 灰色按钮 | 取消操作，关闭弹窗 |

### 3.7 校验规则

| 字段 | 校验规则 | 错误提示 |
|------|----------|----------|
| 方案名称 | 必填 | "请选择方案名称" |
| 方案描述 | 必填 | "请选择方案描述" |
| 物料小类 | 必填 | "请选择物料小类" |
| 资产级别 | 必填 | "请选择资产级别" |
| 数量 | 必填 | "请输入数量" |
| 数量 | 必须为正整数 | "数量必须为正整数" |
| 组合唯一性 | 同一方案名称+物料小类不能重复 | "该方案下已存在此物料小类" |

## 四、页面3：配给规则

### 4.1 页面功能

管理具体的资产配给规则，定义员工可以申请哪些资产、申请条件、审批流程等。

### 4.2 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 规则名称 | 文本输入框 | 支持模糊搜索，如输入"标准" |
| 适用岗位 | 下拉选择框 | 选项：全部、技术岗、管理岗、销售岗等 |
| 是否启用 | 下拉选择框 | 选项：全部、是、否 |

### 4.3 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 序号 | 自动编号 |
| 规则名称 | 如：技术岗标准配给、管理岗高端配给 |
| 适用岗位 | 技术岗/管理岗/销售岗等 |
| 适用级别 | 员工级别要求 |
| 资产类型 | 电脑/影像器材/其他 |
| 最大数量 | 可申请的最大数量 |
| 是否启用 | 启用（绿色）/停用（红色） |
| 操作 | 编辑/删除按钮 |

### 4.4 工具栏

[新增] [删除] [启用] [停用] [批量修改]

### 4.5 新增/编辑弹窗

**表单字段**（每行2个）：

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 规则名称*（文本输入） | 适用岗位*（下拉选择） |
| 第2行 | 适用级别*（下拉选择） | 资产类型*（下拉选择） |
| 第3行 | 最大数量*（数字输入） | 是否启用*（下拉选择） |

**校验规则**：
- 所有字段必填
- 规则名称唯一性校验
- 最大数量必须为正整数
