## 10.1 模块概述

### 10.1.1 模块定位

"用户管理"是企业管理系统的系统配置模块，用于管理企业员工信息及角色分配。该模块采用**左右分栏布局**，左侧为组织架构树，右侧为用户列表。支持查看用户详情、为用户分配角色。

权限：所有涉及用户编辑、修改的权限，目前仅开放给系统管理员

### 10.1.2 包含页面

本模块包含1个主页面：

| 页面 | 功能说明 |
|------|----------|
| 用户管理 | 左侧组织架构树 + 右侧用户列表，支持查看用户详情、分配角色 |

## 10.2 页面功能

### 10.2.1 页面布局

页面采用左右分栏布局：
- **左侧（256px）**：组织架构树，显示企业各级组织节点，支持关键字搜索过滤
- **右侧（填充区）**：选定组织下的用户列表，含查询条件、操作栏、数据表格

### 10.2.2 左侧：组织架构树

显示企业的组织架构，支持展开/折叠。点击组织名称选中该组织，右侧显示该组织下的用户。

**组件**：递归树形组件（`SidebarTreeNode`）

**交互**：
- 点击组织名称：选中并右侧刷新
- 点击展开/折叠图标：展开或折叠子节点
- 搜索框：输入关键字过滤组织节点

### 10.2.3 右侧：用户列表

#### 10.2.3.1 查询条件

| 字段名称 | 是否查询条件 | 查询条件控件类型 | 提示文案 | 说明 |
|----------|:----------:|:--------------:|----------|------|
| 员工姓名 | Y | Input | 请输入员工姓名 | 支持模糊检索 |

**按钮**：
- **查询**：蓝色主按钮，点击后根据条件筛选用户

#### 10.2.3.2 操作栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 启用 | 绿色文字按钮 | 启用选中的用户（需先勾选） |
| 停用 | 红色文字按钮 | 停用选中的用户（需先勾选） |

#### 10.2.3.3 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 工号 | 可点击蓝色链接，点击后查看用户详情 |
| 姓名 | 员工姓名 |
| 邮箱 | 员工邮箱 |
| 职级 | 员工职级（如 4B、3A） |
| 部门 | 所属部门 |
| 使用状态 | 启用（绿色标签）/ 停用（红色标签） |
| 角色 | "分配"蓝色链接按钮，点击打开角色分配弹窗 |

### 10.2.4 用户详情页

**触发方式**：点击表格中工号蓝色链接

**页面标题**：用户信息

**展示字段（两列布局）**：

| 左侧列 | 右侧列 |
|--------|--------|
| 姓名 | 联系电话 |
| 所在部门 | 状态有效 |
| 登录名 | 性别 |
| 移动电话 | Email地址 |
| 拥有的角色 | 上级领导 |
| 员工职级 | 职类 |
| 公司 | 职目 |
| 成本中心 | - |
| HR公司 | - |
| 部门全称 | - |
| 办公区 | - |
| 职位 | - |

**按钮**：
- **返回**：灰色按钮，点击返回用户列表

### 10.2.5 角色分配弹窗

#### 10.2.5.1 触发方式

点击用户表格中的"分配"按钮，打开角色分配弹窗。

#### 10.2.5.2 弹窗标题

- 弹窗标题：`角色分配 - {用户姓名}`

#### 10.2.5.3 交互模式

采用**原位替换（Step-in-place）**设计，只有一个 Modal，通过视图切换避免弹窗嵌套：

**视图一：已分配角色列表**

| 控件/列名 | 说明 |
|-----------|------|
| 新增按钮 | 蓝色主按钮，点击进入"选择角色"视图 |
| 删除按钮 | 红色按钮，删除选中的角色（需先勾选） |
| 角色名称 | 已分配的角色名称 |
| 职责 | 角色职责描述 |
| 确定按钮 | 关闭弹窗，保存角色分配结果 |
| 返回按钮 | 关闭弹窗，不保存 |

**视图二：选择角色（点击"新增"后切换）**

| 控件/列名 | 说明 |
|-----------|------|
| 角色名称搜索 | Input 搜索框，按角色名称模糊检索 |
| 角色名称 | 可选角色名称（已分配角色自动过滤） |
| 职责 | 角色职责描述 |
| 确定按钮 | 确认选择，将选中角色合并至当前用户 |
| 返回按钮 | 取消选择，返回列表视图 |

**校验规则**：
- 选择角色时已分配的角色自动不出现在候选列表中
- 同一用户不能分配重复角色
