# 库存管理－入库当前实现 PRD

## 1. 页面范围

本页面位于「库存管理 → 入库」。用户从入库单列表点击“创建”后进入入库单编辑页，并根据入库类型切换对应的物资添加方式和字段。

当前确认的入库类型共 4 类：

- 新增入库
- 采购接收
- 退库入库
- 借用归还

页面视觉不复刻历史系统样式，统一使用当前项目的 Ant Design、QueryBar、DetailGrid、StatusTag 等规范。

## 2. 入库单公共信息

所有入库类型共用以下单据信息：

| 字段 | 说明 |
|---|---|
| 入库单号 | 新建时保存后自动生成 |
| 单据类型 | 固定为“入库单” |
| 单据状态 | 草稿 / 已完成 |
| 入库类型 | 新增入库 / 采购接收 / 退库入库 / 借用归还 |
| 制单人 | 当前制单人 |
| 制单时间 | 当前制单日期 |
| 是否刷卡领用 | 展示字段 |
| 当前仓库 | 当前入库仓库 |
| 备注 | 单据备注 |

新增入库、采购接收额外展示合计原值、合计税金、合计金额；采购接收额外展示“是否计费”。

## 3. 新增入库

### 3.1 入库物资列表

物资说明、物资总类、入库数量、资产标签号、SN序列号、原值、税金、总价、PO单号、PR单号。

### 3.2 添加物资字段

| 分组 | 字段 |
|---|---|
| 基础物资 | 物资说明、物资总类、物资大类、物资小类、品牌、规格型号、配置、计量单位 |
| 库存 | 库区、库位、申请批次、入库数量 |
| 金额 | 合同编号、原值、税金、合计 |
| 资产识别 | 资产标签号、SN号、资产级别、资产状态 |
| 位置 | City、Building、Floor |
| 使用与责任 | 用途、所在部门、责任人、新增类型、原资产标签号 |
| 组织财务 | 公司、成本中心、业务线、项目、板块、费用账户 |
| 日期与来源 | 购置日期、启用日期、PR单号、申请单号、PO单号、申请人 |
| 部件与关联 | 部件数量、部件说明、主资产标签号、供应商 |
| 其他 | 使用说明、备注 |

新增入库的资产状态按截图口径展示“在库-新增”。

## 4. 采购接收

### 4.1 入库物资列表

在新增入库公共列表字段基础上增加“是否计费”。

### 4.2 选择待入库物资弹窗

查询字段：公司、板块、部门、资产类别、供应商、PO单号、接收单号、资产标签号；支持扫描资产标签号加入选择。

列表字段：公司、资产标签号、SN号、PO单号、接收单号、物资总类、资产大类、资产小类、物料说明、配置、部件数量、部件说明、PR单/行。

用户勾选待入库物资后确认加入当前入库单。

## 5. 借用归还

### 5.1 入库物资列表

资产标签号、SN序列号、物资总类、物资说明、数量、借用原因、借用日期、资产标记、借用人、资产状态。

### 5.2 添加物资字段

选择区：资产标签号、SN号、物资说明。

物资信息：资产标签号、SN号、物资说明、启用日期、物资总类、物资大类、物资小类、主资产标签号、品牌、规格型号、配置、计量单位、借用人、借用数量、资产状态、印刷号、公司、板块、业务线、成本中心、City、Building、Floor、Room、费用账户、用途、部件数量、部件说明、借用开始日期、借用申请单号、借用原因、续借次数、备注。

借用归还入库字段：责任人、库区、货位、资产标记、归还数量、资产状态、归还日期、鉴定单号、鉴定结果、鉴定人、鉴定日期、使用说明。

归还后的资产状态按截图口径展示“在库-待处理”。

## 6. 退库入库

### 6.1 入库物资列表

资产标签号、SN序列号、物资总类、物资说明、数量、退库类型、资产标记、退库人、资产状态。

### 6.2 添加物资字段

选择区：资产标签号、SN号、物资说明。

物资信息：资产标签号、SN号、物资说明、启用日期、物资总类、物资大类、物资小类、主资产标签号、品牌、规格型号、配置、计量单位、退库人、资产数量、资产状态、印刷号、公司、板块、业务线、成本中心、City、Building、Floor、Room、费用账户、用途、部件数量、部件说明、备注。

一般退库入库字段：责任人、库区、货位、资产标记、鉴定单号、资产状态、退库日期、退库原因、退库数量、鉴定结果、鉴定人、鉴定日期、使用说明。

退库后的资产状态按截图口径展示“在库-待处理”。

## 7. 页面操作

- 入库单列表支持查询、创建、删除、批量打印。
- 编辑页支持添加/选择物资、删除所选物资、Excel 导入入口、保存草稿、返回。
- 切换入库类型时，如果已经存在物资行，必须先确认；确认切换后清空现有物资行，避免不同类型字段混用。
- 页面级“保存草稿 / 返回”放页面底部居中；物资表格相关操作保留在物资分区内。

## 8. 当前实现边界

本轮以用户提供的历史系统截图作为字段依据，重点复刻字段集合和不同入库类型的分支结构；未从截图明确得到的后端校验、真实接口、权限、模板导入逻辑不补造。演示数据仅用于当前前端原型展示。
