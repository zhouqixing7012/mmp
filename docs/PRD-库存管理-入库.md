# 库存管理－入库当前实现 PRD

## 1. 页面范围

本页面位于「库存管理 → 入库」。用户从入库单列表点击“创建”后进入入库单编辑页，并根据入库类型切换对应的物资添加方式和字段。

当前确认的入库类型共 4 类：新增入库、采购接收、退库入库、借用归还。

页面视觉不复刻历史系统样式，统一使用当前项目的 Ant Design、QueryBar、DetailGrid、StatusTag 等规范。

## 2. 入库单列表

查询条件：入库单号、入库类型、单据状态、PO单号、PR单号、资产标签号、制单人、制单日期。

“制单日期”使用一个日期范围控件，不拆成“制单日期从 / 制单日期至”两个查询项。

操作列按单据状态区分：

| 单据状态 | 操作 |
|---|---|
| 草稿 | 编辑 |
| 已完成 | 打印 |

列表继续支持创建、删除、批量打印。

## 3. 入库单公共信息

所有入库类型共用以下单据信息：

| 字段 | 说明 |
|---|---|
| 入库单号 | 新建时保存后自动生成 |
| 单据类型 | 固定为“入库单” |
| 单据状态 | 草稿 / 已完成 |
| 入库类型 | 新增入库 / 采购接收 / 退库入库 / 借用归还 |
| 制单人 | 当前制单人 |
| 制单时间 | 当前制单日期 |
| 是否刷卡领用 | 展示字段 |
| 当前仓库 | 当前入库仓库 |
| 备注 | 单据备注，多行字段独占一整行 |

新增入库、采购接收额外展示合计原值、合计税金、合计金额；采购接收额外展示“是否计费”。

草稿入库单编辑页底部提供页面级“执行入库 / 保存草稿 / 返回”，其中“执行入库”为主操作。执行入库后单据进入“已完成”。

## 4. 新增入库

### 4.1 入库物资列表

物资说明、物资总类、入库数量、资产标签号、SN序列号、原值、税金、总价、PO单号、PR单号。

### 4.2 添加物资字段与编辑规则

| 字段 | 规则 |
|---|---|
| 物资说明 | 必填，红色星号；通过选择物资确定 |
| 物资总类 / 物资大类 / 物资小类 | 由物资说明带出，只读 |
| 品牌 / 规格型号 / 配置 / 计量单位 | 由物资说明带出，只读 |
| 申请批次 | 可编辑 |
| 入库数量 | 必填，可编辑 |
| 原值 | 必填，可编辑 |
| 税金 | 可编辑 |
| 合计 | 只读，固定等于原值 + 税金 |
| 资产标签号 / SN号 | 可编辑 |
| 资产状态 | 只读，固定为“在库-新增” |
| City | 根据当前仓库带出，只读 |
| Building | 根据当前仓库带出，允许修改 |
| Floor | 可编辑 |
| 责任人 | 必填；选择责任人后带出所在部门和成本中心 |
| 所在部门 | 位于责任人之后，可编辑 |
| 新增类型 | 必填，可编辑 |
| 原资产标签号 | 可编辑 |
| 公司 | 根据当前仓库带出，只读 |
| 成本中心 | 根据责任人带出，但允许修改 |
| 业务线 / 项目 / 板块 | 可编辑 |
| 费用账户 | 自动生成，只读 |
| 购置日期 / 启用日期 | 可编辑 |
| PR单号 / 申请单号 / PO单号 / 申请人 | 可编辑 |
| 部件数量 / 部件说明 / 主资产标签号 / 供应商 | 可编辑 |
| 使用说明 / 备注 | 可编辑；备注为多行整行字段 |

删除字段：库区、库位、资产级别、合同编号、用途。

当物资小类为服务器、网络设备、服务器备件、网络设备备件时，额外展示两个可编辑字段：**服务、NO位置**。

添加物资弹窗底部提供“取消 / 添加并继续 / 添加并关闭”。“添加并继续”新增当前物资后保持弹窗打开；“添加并关闭”新增当前物资后关闭弹窗。

## 5. 采购接收

### 5.1 入库物资列表

在新增入库公共列表字段基础上增加“是否计费”。

### 5.2 选择待入库物资弹窗

查询条件：公司、板块、部门、资产类别、供应商、PO单号、接收单号、资产标签号、扫描光标。

“扫描光标”与其他查询条件处于同一查询区域，本质上是资产标签号快速查询输入框：支持扫码枪输入，也支持手工输入，输入完成后回车直接执行查询，不单独设置扫描分区或扫描卡片。

列表字段：公司、资产标签号、SN号、PO单号、接收单号、物资总类、资产大类、资产小类、物料说明、配置、部件数量、部件说明、PR单/行。

弹窗布局：查询区置顶；下方左侧为待入库物资列表，右侧固定“已选择”区域。右侧只展示当前全部已选资产的资产标签号，并支持逐条删除；右侧删除后，左侧对应勾选状态同步取消。

用户确认后将当前已选资产加入入库单。

## 6. 退库入库

### 6.1 入库物资列表

资产标签号、SN序列号、物资总类、物资说明、数量、退库类型、资产标记、退库人、资产状态。

### 6.2 添加物资字段

选择区：资产标签号、SN号、物资说明。

物资信息：资产标签号、SN号、物资说明、启用日期、物资总类、物资大类、物资小类、主资产标签号、品牌、规格型号、配置、计量单位、退库人、资产数量、资产状态、公司、板块、业务线、成本中心、City、Building、Floor、Room、费用账户、用途、部件数量、部件说明、备注。

其中物资信息里的资产状态固定展示 **在用-使用中**。

一般退库入库字段：责任人、资产标记、退库数量、资产状态、退库日期、鉴定单号、退库原因、鉴定人、鉴定日期、使用说明。

退库数量为只读，直接带出待退库资产数量；执行退库入库后的资产状态展示“在库-待处理”。

退库入库添加物资弹窗不展示：**印刷号、库区、货位、鉴定结果**。

弹窗底部提供“取消 / 添加并继续 / 添加并关闭”。

## 7. 借用归还

### 7.1 入库物资列表

资产标签号、SN序列号、物资总类、物资说明、数量、借用原因、借用日期、资产标记、借用人、资产状态。

### 7.2 添加物资字段

选择区：资产标签号、SN号、物资说明。

物资信息：资产标签号、SN号、物资说明、启用日期、物资总类、物资大类、物资小类、主资产标签号、品牌、规格型号、配置、计量单位、借用人、借用数量、资产状态、公司、板块、业务线、成本中心、City、Building、Floor、Room、费用账户、用途、部件数量、部件说明、借用开始日期、借用申请单号、借用原因、备注。

借用归还入库字段：责任人、资产标记、归还数量、资产状态、归还日期、鉴定单号、鉴定人、鉴定日期、使用说明。

归还数量为只读，直接带出待归还资产数量；归还后的资产状态展示“在库-待处理”。

借用归还添加物资弹窗不展示：**印刷号、续借次数、库区、货位、鉴定结果**。

弹窗底部提供“取消 / 添加并继续 / 添加并关闭”。

## 8. 页面操作规则

- 入库单列表：创建、删除、批量打印。
- 草稿入库单：编辑页底部提供执行入库、保存草稿、返回。
- 入库物资分区：添加/选择物资、删除所选物资；**Excel导入只对非采购接收类型展示**。
- 采购接收入库只能通过“待入库物资”选择已有接收资产，不展示 Excel 导入入口。
- 新增入库、退库入库、借用归还的添加物资弹窗均提供“添加并继续 / 添加并关闭”；采购接收使用“选择待入库物资”确认交互，不套用该按钮组合。
- 切换入库类型时，如果已经存在物资行，必须先确认；确认切换后清空现有物资行，避免不同类型字段混用。
- 页面级操作统一放页面底部居中；表格相关操作保留在物资分区内。

## 9. 当前实现边界

本轮以用户已确认的历史系统字段和交互为依据，重点校准页面字段、状态操作和选择交互；未明确得到的后端接口、权限、模板导入逻辑不补造。演示数据仅用于当前前端原型展示。
