## 一、物料大类页面补充

### 1.1 业务特殊说明

1. **启用规则优化**：不再对物料大类的启用状态进行限制，仅以物料小类的"是否启用"作为核心管控依据
2. **数据来源**：资产大类基础数据来源于EBS，同步EBS资产关键字中用到
3. **手动新增**：可手动新增，如果大类是资产，则EBS也必须同步新增
4. **耗材大类**：需要在资产系统单独维护
5. **同步采购系统**：资产大类基础信息也会同步采购系统一份

## 二、物料小类页面补充

### 2.1 业务特殊说明

1. **数据来源**：物料大类字段数据来自物料大类表
2. **EBS同步**：物料小类在资产系统中创建完成后，EBS获取物料小类
3. **编号规则**：在每个物料大类下，小类序号从1开始按"1、2、3、4……"依次编排
4. **唯一性规则**：不同大类下的小类需保持唯一，即一个小类名称/编码仅对应一个大类，不能在多个大类下重复出现
5. **上下级关系**：大类和小类是上下级关系，正在使用的小类会和EBS的小类相互对应
6. **采购系统同步**：资产大类基础信息也会同步采购系统一份

### 2.2 物料小类编号规则

- 每个物料大类下的小类编号从1开始递增（1、2、3、4...）
- 小类编号显示为3位（如：001、002、003）
- 小类唯一性规则：不同大类下的小类编号可以相同

### 2.3 物料小类字段清单

| 字段名称 | 字段属性 | 备注 |
|---------|---------|------|
| 物料大类 | 下拉选择框 | 数据联动物料大类表 |
| 物料小类 | 单行文本 | 申请人输入 |
| 物料小类编号 | 数字 | 自动生成，每个物料大类下小类编码自动生成001、002...... |
| 是否启用 | 单选框 | 是否启用当前物料小类 |
| 是否允许借用 | 单选框 | 当前物料是否允许借用 |

## 三、物料品牌页面补充

### 3.1 业务特殊说明

1. **编码自动生成**：品牌编号将由系统自动生成，无需手动录入
2. **数据来源**：属于资产系统自建数据，采购系统会用到
3. **采购系统同步**：资产大类基础信息也会同步采购系统一份

### 3.2 品牌编码规则

- 品牌编码自动生成为001、002、003......
- 品牌编码不能重复
- 品牌名称不能重复

## 四、物料型号页面补充

### 4.1 业务特殊说明

1. **品牌关联**：型号在创建时需要与品牌进行关联
2. **唯一性规则**：同一品牌下的型号需保持唯一，即一个型号仅对应所属品牌，不能在同一品牌下重复存在
3. **上下级关系**：品牌和型号是上下级关系，属于资产系统自有
4. **采购系统同步**：资产大类基础信息也会同步采购系统一份

### 4.2 型号编码规则

- 型号的编码自动生成
- 每个品牌下，型号编码自动生成为001、002、003......
- 同一个品牌下规格型号名称不能重复

## 五、物料配置页面补充

### 5.1 业务特殊说明

1. **型号关联**：在配置新建流程中，当创建人选择具体的型号数据后，系统将自动关联并带出对应的品牌数据，无需手动录入
2. **上下级关系**：型号和配置是上下级关系，属于资产系统自有
3. **采购系统同步**：资产大类基础信息也会同步采购系统一份

### 5.2 配置编码规则

- 配置的编码自动生成
- 每个品牌规格型号组合下，配置编码自动生成为001、002、003......
- 配置描述唯一值不允许重复

## 六、物料维度组合（物料综合集合）页面补充

### 6.1 业务特殊说明

1. **物料类型构成规则**：物料类型将以多层级维度组合生成，具体由物料总类为基础框架，结合物料大类、物料小类、品牌、型号、配置进行层级细分
2. **物料总类与大类对应关系**：当选定特定物料总类后，系统仅展示该总类所对应的大类数据
3. **是否需要借用字段联动**：当申请人选择资产小类后，系统将自动填充"是否需要借用"字段的数据，且该字段填充后不允许修改
4. **物料编码生成规则**：总类编码+大类编码+小类编码+品牌编码+型号编码+配置编码（如配置为空，该段默认为000）
5. **物料名称生成规则**：品牌名称.型号名称
6. **列表排序规则**：以各物料的"最后修改时间"为依据，按时间从高到低排列
7. **字段锁定规则**：物料信息一经提交后，系统将自动锁定物料分类、品牌、型号、配置这四个字段，后续无法对其进行修改操作
8. **临时申请页签**：支持自定义配置，在生效结束日期（含当日）前，可实现将物料临时分配至指定部门的所有员工，或定向分配给特定员工
9. **物料提交后自动新增配置**：物料提交后，用该物料的品牌+型号查找是否存在编码为"000"的配置，若不存在自动新增编码为"000"的配置，配置名称为空，配置品牌、型号用该物料品牌、型号

## 七、员工超标规则详细说明

### 7.1 判断逻辑

"员工是否超标"的判断逻辑：
- 非技术岗位员工（员工对应唯一职务序列，在【职务序列】基础资料中配置"是否技术序列"）申请特定物料（在【物料】基础资料中配置"非技术申请超标"）属于超标
- "员工超标规则"配置物料小类和排除小类
- 如员工申请物料小类为A，找到排除小类为B、C、D，则统计员工名下所有资产和本次申请中物料小类为A、B、C、D的资产总数，总数大于1即为超标

### 7.2 字段清单

## 八、部门超标规则详细说明

### 8.1 判断逻辑

"部门是否超标"判断逻辑：

1. **判断条件**：
   - 如果当前审批人所在一级部门与申请人所在一级部门相同且当前审批人所管辖的部门包含申请人所在末级部门
   - 如果当前审批人所在一级部门与申请人所在一级部门相同且当前审批人所管辖的部门不包含申请人所在末级部门
   - 如果当前审批人所在一级部门与申请人所在一级部门不同且当前审批人所管辖的部门不包含申请人所在末级部门

2. **判断流程**：
   - 首先判断申请人所在末级部门是否超标
   - 如果超标，返回"部门超标"
   - 如果不超标，判断当前审批人所管辖的部门整体是否超标
   - 如果超标，返回"部门超标"
   - 如果不超标，返回"部门不超标"

3. **后台判断逻辑**：
   - 判断部门人均持有量 > 人均资产最小数量，视为"部门超标"
   - 人均持有量 = 部门所有员工名下这些物料小类对应资产总数 / 部门总人数

## 九、基础资料功能按钮统一说明

### 9.1 列表页面主要按钮及功能

- **新增**：新增基础资料
- **复制**：复制当前基础资料信息后弹出新增页面
- **删除**：删除基础资料，只能删除可用状态基础资料
- **禁用**：禁用可用状态的基础资料，禁用后使用状态更新为禁用
- **启用**：启用禁用状态的基础资料，启用后使用状态更新为可用

### 9.2 编辑页面主要按钮及功能

- **保存**：保存当前基础资料编辑页面
- **保存并新增**：保存当前基础资料编辑页面并弹出新增页面

## 十、物料基础资料状态流转

### 10.1 列表页面按钮功能

- **新增**：新增物料
- **复制**：复制当前物料信息后弹出新增页面
- **删除**：删除物料，只能删除暂存状态物料
- **提交**：提交"暂存"并且"可用"状态的物料，提交后数据状态更新为已审核，更新启用日期
- **反审核**：反审核"已审核"并且"可用"状态的物料，反审核后数据状态更新为暂存
- **禁用**：禁用"已审核"并且"可用"状态的物料，禁用后使用状态更新为禁用，更新停用日期
- **启用**：启用"已审核"并且"禁用"状态的物料，启用后使用状态更新为可用，更新启用日期

### 10.2 编辑页面按钮功能

- **保存**：保存当前物料编辑页面并自动生成物料编码和名称
- **提交**：提交"暂存"并且"可用"状态的物料，提交后数据状态更新为已审核，更新启用日期
- **反审核**：反审核"已审核"并且"可用"状态的物料，反审核后数据状态更新为暂存
- **禁用**：禁用"已审核"并且"可用"状态的物料，禁用后使用状态更新为禁用，更新停用日期
- **启用**：启用"已审核"并且"禁用"状态的物料，启用后使用状态更新为可用，更新启用日期

### 10.3 物料状态枚举值

| 状态 | 说明 |
|------|------|
| 暂存 | 初始状态，可以修改 |
| 已提交 | 提交后等待审核 |
| 已审核 | 审核通过，可以使用 |
