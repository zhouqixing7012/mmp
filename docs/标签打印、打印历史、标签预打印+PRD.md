# 标签打印、打印历史、标签预打印 PRD

## 1. 背景

资产/耗材标签主列表补打、标签预打印和接收单标签打印使用不同的标签来源、批次规则和打印记录。三条链路如果混在一起，会把已有标签补打误认为再次生成标签，导致标签批次、标签明细和打印次数口径不一致。

标签打印相关能力统一归属于：

> **资产管理 → 标签打印**

该菜单需要明确区分以下业务：

1. **标签打印**：查询已经存在的资产/耗材主标签，支持补打、批量打印和导出；部件标签不进入该主列表。
2. **标签预打印**：在资产实际形成前，按照标签编码规则提前批量生成标签号，并形成标签批次及标签清单。
3. **打印历史**：记录并追溯标签预打印、接收单标签打印的实际打印行为。资产/耗材标签主列表补打只累计打印次数，不生成详细打印历史。

标签号生成、标签批次、标签明细、打印次数和打印历史按三条业务链路分别处理，主列表补打不生成标签批次。

## 2. 权限

### 2.1 数据权限

1. 标签打印查询、打印、导出遵循当前用户的**公司 + 板块**数据权限。
2. 用户只能查询、打印和导出本人有权访问的数据。
3. 预打印生成标签必须同时具备菜单权限和标签生成权限；账套候选范围只展示当前用户可操作的账套。
4. 接收入库打印只能处理当前用户有权访问的接收数据和标签。
5. 权限控制同时适用于标签打印主列表、预打印批次、标签清单、打印历史和导出结果。

### 2.2 角色与操作范围

| 人员/角色 | 菜单权限 | 打印权限 | 数据范围 |
| --- | --- | --- | --- |
| 王英、刘建 | 开通“资产管理 → 标签打印”菜单 | 可执行标签打印主列表补打、预打印标签打印、接收单标签打印 | 当前用户公司 + 板块权限范围 |
| 机房管理员（人员名单待定） | 开通“资产管理 → 标签打印”菜单 | 仅可打印机房大类和备件标签 | 当前用户公司 + 板块权限范围内的机房大类和备件 |

3. 王英、刘建可进入标签预打印页面并生成、打印标签。
4. 机房管理员不得通过标签打印菜单打印普通资产、普通耗材或其他非机房大类标签；如需标签预打印生成权限，必须另行授权。
5. 菜单和打印权限不扩大公司 + 板块数据范围。
6. 每次查询、生成、打印和导出都必须校验人员权限、数据权限及资产类别范围。

## 3. 通用规则

### 3.1 三条打印链路

标签打印相关业务分为三条链路，三条链路的标签号、打印次数、批次和打印历史处理方式分别如下：

| 链路 | 标签来源 | 批次与明细 | 打印结果 |
| --- | --- | --- | --- |
| 资产/耗材标签主列表补打 | 已经存在的资产/耗材主标签 | 直接使用已有标签，不新建标签批次和标签明细 | 打印完成后只增加主列表累计打印次数，不生成详细打印历史 |
| 标签预打印 | 预先生成的新标签号 | 首次生成时创建标签批次和全部标签明细；之后重复打印复用原批次和明细 | 按每个标签实际成功份数累计打印次数，并记录打印历史 |
| 接收单/员工接收标签打印 | 接收明细中已经存在的标签号 | 同一 PO 首次点击打印时创建标签批次，并把接收明细中的标签号写入标签明细；再次打印时使用原批次和明细 | 按标签明细累计打印次数，并记录打印历史 |

其中：

1. **标签生成批次不等于打印任务**。同一标签可以被多次打印，但不能因为资产/耗材标签主列表补打再次生成标签号或创建标签批次。
2. 资产/耗材标签主列表补打不创建标签批次和标签明细，不生成详细打印历史，只累计主列表打印次数。
3. 预打印和接收单打印的批次只在首次生成或首次建立关联时创建，后续打印复用原批次。
4. 预打印和接收单打印使用标签批次、标签明细和详细打印历史；资产/耗材标签主列表补打使用独立的累计打印次数，不得强行并入批次链路。

### 3.2 菜单与入口

进入“资产管理 → 标签打印”后：

1. 默认展示已有资产/耗材标签查询、补打、批量打印和导出能力。
2. 点击“预打印”进入“标签预打印”。
3. 标签预打印页可进入某批次的“标签清单”或“打印历史”。
4. 标签清单可查看某个标签的打印历史。
5. 不再提供独立“标签预打印”“标签打印历史”菜单。

### 3.3 查询与操作权限

1. 用户不得查看、打印或导出权限范围外的标签数据。
2. 标签批次、标签明细和打印历史的查询都必须按当前用户权限过滤。
3. 同一标签跨入口显示时，必须再次按当前用户权限判断是否允许查看和打印。

### 3.4 标签数据来源

1. 标签打印主列表动态获取当前系统中的资产卡片和耗材卡片主标签。
2. 部件标签不进入标签打印主列表，只在所属标签批次的标签清单中查询和打印。
3. 默认展示用户权限范围内全部可打印主标签。
4. 台账信息发生变化后，标签打印列表根据标签号展示最新卡片信息，不长期保存独立快照作为展示来源。
5. 接收明细中的标签号在首次打印时按 PO 编号建立批次和标签明细关联。
6. 预打印生成标签和接收生成标签共用统一标签号空间。

### 3.5 标签类型与打印模板

1. 标签生成时必须保存标签类型，至少区分**主资产标签**和**部件标签**。
2. 打印时直接读取已保存的标签类型选择模板，不通过标签号是否包含 `-`、标签号长度或其他字符串特征推断标签类型。
3. 显示器主资产标签的 `-V` 是主资产标签后缀，不改变其主资产标签类型。
4. 对尚未补充标签类型的存量标签明细，显示器主标签兼容判断使用“标签号包含 `-V`”，不要求 `-V` 位于标签号结尾。
5. `P-`、`N-`、`QT-` 是高耗主标签前缀，不能因标签号包含 `-` 被识别为部件标签。
6. `-H1`、`-H2` 等历史部件标签保留原标签号；其主/部件关系按历史标签明细关系读取，不重新改号，也不进入标签打印主列表。

#### 主资产标签

| 位置 | 打印内容 |
| --- | --- |
| 左侧 | 标签号二维码 |
| 右侧第一行 | 公司英文名称 |
| 右侧第二行 | 公司中文名称 |
| 右侧第三行 | 标签号 |

二维码内容固定为当前标签号，不包含资产详情或其他扩展内容。

#### 部件标签

| 顺序 | 打印内容 |
| --- | --- |
| 第一行 | 公司英文名称 |
| 第二行 | 公司中文名称 |
| 第三行 | 标签号 |

部件标签不打印二维码，不生成独立资产卡片。公司中文名、公司英文名和标签号均从所属主标签或标签批次取得；预打印主资产标签的公司中文名、公司英文名从所选账套对应的公司信息取得。

### 3.6 标签号全局唯一

生成标签前必须在统一标签空间校验标签号是否已被占用，至少覆盖：

1. 标签清单已有标签。
2. 正式资产卡片已有标签。
3. 耗材卡片已有标签。
4. 资产/耗材接收链路已生成或已占用标签。
5. 其他共用同一标签号体系的业务记录。

系统最终保存标签号时必须强制校验唯一性，任何入口都不能保存重复标签号。

任一标签号重复，本批次整体失败，不产生部分成功标签。

### 3.7 标签生成完整性

生成标签时按以下顺序处理：

1. 根据账套、标签规则、资产类型、年份或标签前缀确定本次使用的流水。
2. 同一组流水同时收到多个生成请求时，必须依次处理，不能重复占用同一号段。
3. 读取该组流水已经使用的最大序号。
4. 按跨年规则处理当年规则不存在的情况。
5. 校验本次主标签数量、标签明细数量和剩余号段。
6. 为本次主标签预留连续号段。
7. 生成全部标签号。
8. 校验全部标签号全局唯一。
9. 创建标签批次。
10. 创建标签明细。
11. 更新已使用最大序号和下一个可用序号。
12. 标签批次、标签明细和流水必须同时保存成功。

任一步失败时，本次不生成标签批次和标签明细，也不占用流水号。不得出现流水已经推进但标签未生成、只生成部分标签或没有批次却占用了号段等结果。

系统必须保证：

- 标签批次号唯一；
- 标签号唯一；
- 流水规则键唯一；
- 同一生成请求只能产生一次业务结果。

### 3.8 流水维度

| 规则 | 流水维度 |
| --- | --- |
| 常规标签规则 | 账套 + 资产类型 + 年份分别维护规则；当年规则不存在时按年份倒序查找最近一个存在规则的历史年度 |
| 高耗标签规则 | `QT-`、`P-`、`N-` 三类前缀分别维护流水，不区分公司；每个前缀按年份维护规则，当年规则不存在时按年份倒序查找最近一个存在规则的历史年度 |
| 特殊规则-家具 | 所有家具共用一组不带年份的公共流水，不区分家具类型 |
| 特殊规则-手机 | 所有手机共用一组不带年份的公共流水 |
| 特殊规则-备件 | 所有备件共用一组不带年份的公共流水，CPU / Card / HD / ME / SP 只决定标签前缀，不拆分流水 |

### 3.9 跨年续号

预打印与资产接收标签生成共用同一套流水数据，具体按以下规则处理。

**常规标签规则**

1. 按“账套 + 资产类型 + 年份”读取规则。
2. 当年规则存在时，从当年已经使用的最大序号后继续编号。
3. 当年规则不存在时，按年份倒序查找最近一个存在规则的历史年度，不要求必须是紧邻上一年度。
4. 常规流水使用 5 位数字，范围为 `00001～99999`。
5. 最近历史年度已使用最大序号未达到 `99999` 时，新年度接着该序号编号。
6. 不存在任何历史年度规则时，从 `00001` 开始。
7. 流水达到 `99999` 后的扩展编号、重新起号和删除年份后的跨年重复场景不在本次需求范围内，不新增处理规则。

**高耗标签规则**

1. `QT-`、`P-`、`N-` 三类前缀分别维护流水，三类流水互不影响。
2. 每个前缀按年份读取规则。
3. 当年规则不存在时，按年份倒序查找该前缀最近一个存在规则的历史年度，不要求必须是紧邻上一年度。
4. 高耗流水使用 4 位数字，范围为 `0001～9999`。
5. 最近历史年度已使用最大序号未达到 `9999` 时，新年度接着该序号编号。
6. 不存在任何历史年度规则时，从 `0001` 开始。
7. 流水达到 `9999` 后的扩展处理不在本次需求范围内。

**家具、手机、备件**

1. 家具使用一组不带年份的公共流水。
2. 手机使用一组不带年份的公共流水。
3. 备件使用一组不带年份的公共流水，CPU / Card / HD / ME / SP 只决定标签前缀。
4. 以上三类规则不按年份重置；下一次生成从公共流水已经使用的最大序号后继续编号。

### 3.10 防止重复生成

1. 点击“生成标签”后按钮进入处理中状态。
2. 处理完成前不能再次点击生成。
3. 同一次生成操作无论被重复提交多少次，只能产生一个标签批次和一组标签明细。
4. 页面重试、网络超时重发和用户双击不能重复生成标签或重复占用流水号。

### 3.11 防止打印结果重复累计

标签预打印和接收单标签打印的每次打印操作都必须能够单独识别，防止同一次成功结果被重复处理。

打印动作包括：

- 标签清单打印所选；
- 标签清单打印本批次全部；
- 接收单/员工接收标签打印。

1. 每次打印操作记录打印来源、处理结果和失败原因，供重复提交判断和故障排查使用。
2. 同一次打印操作的成功结果只处理一次，重复返回或网络重试不得重复增加打印次数。
3. 用户再次打印属于新的打印操作，单独累计打印次数并生成新的打印历史。
4. 上述内部信息不作为标签批次列表、标签清单或打印历史的业务字段展示。
5. 资产/耗材标签主列表补打不生成上述详细打印记录。

### 3.12 打印次数

1. 资产/耗材标签主列表单独保存累计打印次数。
2. 主列表一次补打 N 份，打印完成后累计打印次数增加 N；该链路不生成详细打印历史。
3. 预打印和接收单标签打印次数保存在对应标签明细中。
4. 标签清单一次打印 N 份，成功后对应标签明细打印次数增加 N。
5. 预打印和接收单打印历史记录本次打印份数，用于与标签明细累计打印次数核对。
6. 三条链路分别累计打印次数，不要求通过新建批次把主列表补打次数同步到标签明细。

### 3.13 打印结果处理

1. 资产/耗材标签主列表打印完成后，只增加累计打印次数，增加值等于本次打印份数。
2. 预打印和接收单标签打印只有在得到成功结果后，才增加标签明细打印次数并写入成功日志。
3. 未确认成功时不得提前把标签明细标记为已打印。
4. 同一批次内允许出现部分标签成功、部分标签失败；按标签实际结果分别处理。
5. 任务级状态和失败原因可在后台内部记录，但不作为业务打印历史列表字段展示。

| 公司英文名 | 所属公司英文名称 | 展示卡片最新公司英文名称 |
| 板块中文名 | 所属板块中文名称 | 展示卡片最新板块中文名称 |
| 序列号 | 资产/耗材序列号 | 展示卡片最新序列号 |
| 资产类别 | 资产/耗材类别 | 展示卡片最新类别 |
| 资产状态 | 当前业务状态 | 展示完整业务状态名称 |
| 使用人 | 当前使用人员 | 展示 `工号-姓名`，无值显示 `-` |
| 打印次数 | 主列表累计打印份数 | 按业务原值展示，不使用千分位 |

#### 4.1.5 页面操作

| 按钮 | 展示条件 | 可用条件 | 点击结果 |
| --- | --- | --- | --- |
| 打印所选 | 用户具有对应类别打印权限时展示 | 至少勾选一条有权打印的记录 | 打开“打印确认”，按钮显示已选数量 |
| 打印全部 | 用户具有打印权限时展示 | 当前查询结果至少有一条可打印记录 | 打开“打印确认”，范围为当前查询条件下全部有权打印的数据，不受分页限制 |
| 预打印 | 王英、刘建或另行取得标签生成权限的人员展示 | 用户具有标签生成权限 | 进入“标签预打印”页面 |
| 导出 | 用户具有菜单权限时展示 | 当前存在勾选记录或查询结果 | 有勾选时导出勾选记录；无勾选时导出当前查询结果全部有权数据 |

#### 4.1.6 打印确认

点击打印后弹出“打印确认”：

1. 展示本次标签数量。
2. 打印份数输入范围 1～99，默认 1。
3. 展示“共打印 X 张标签”，其中 `X = 标签数量 × 打印份数`。
4. 确认后执行标签打印。
5. 打印所选按勾选集合处理。
6. 打印全部按当前查询结果全部数据处理，不受当前分页限制。
7. 从标签打印主列表发起补打时，直接使用已有标签，不创建新的标签批次或标签明细。
8. 打印完成后，主列表累计打印次数增加本次打印份数。
9. 主列表补打不生成详细打印历史，也不进入预打印/接收单的打印历史页面。

#### 4.1.7 标签内容

点击确认打印时，系统重新读取对应资产/耗材卡片的最新信息和当前用户权限，再生成打印内容，不使用进入页面时的旧快照。

1. 标签打印主列表只打印主资产/耗材标签，使用主标签模板：二维码、公司英文名称、公司中文名称、标签号。
2. 二维码内容固定为当前标签号。

中文显示规则：

1. 有板块中文时优先使用板块中文。
2. 无板块中文时回退公司中文。
3. 公司英文为空时阻止打印并提示维护公司英文信息。

### 4.3 生成标签

点击“生成标签”进入生成标签页面。

#### 4.3.1 基础信息

| 页面字段 | 业务含义 | 交互规则 |
| --- | --- | --- |
| 账套 | 标签所属财务账套及公司信息来源 | 必选；候选按当前用户权限展示；默认选中第一项，允许调整 |
| 标签规则 | 本次生成标签使用的编号规则 | 单选：常规、高耗、家具、手机、备件 |
| 打印标签数量 | 本次生成的主标签数量 | 默认 1；输入 1～500 的正整数 |
| 部件数量 | 每个主标签对应的标签明细总数，包含主标签本身 | 默认 1；输入 1～99 的整数 |
| 标签批次 | 本次生成结果所属批次 | 生成成功后自动带出，只读 |
| 操作员 | 执行生成操作的人员 | 自动带出当前用户，只读 |
| 当前日期 | 页面操作日期 | 自动带出当前日期，只读 |
| 备注说明 | 本批标签的业务说明 | 允许填写，可为空 |

“打印标签数量”表示本次生成的主资产标签数量，不表示已经完成打印的标签数量；是否实际打印由后续标签清单中的打印操作决定。

单次生成的标签明细总数不得超过 5000 条。

标签生成时间取用户点击“生成标签”并成功创建标签批次时的系统时间；页面“当前日期”仅展示当前日期，不替代标签批次实际生成时间。

一次只能选择一种标签规则；切换规则后，只展示该规则需要填写或确认的字段。

#### 4.3.2 常规标签规则

| 页面字段 | 业务含义 | 交互规则 |
| --- | --- | --- |
| 资产类型 | 决定常规标签中的资产类型编码 | 默认选中第一项，允许调整 |
| 年份 | 决定标签中的年份后两位 | 默认当前年份，必填 |
| 当前最大序号 | 该账套、资产类型和年份已经使用的最大流水号 | 自动带出，只读 |

普通常规标签格式：

> 账套编码 + 资产类型编码 + 年份后两位 + 5 位流水号

资产类型为 `11 - PC.显示器` 时，标签格式为：

> 账套编码 + 资产类型编码 `11` + 年份后两位 + 5 位流水号 + `-V`

常规标签按规则组合后如果长度超过 15 位，删除标签规则中位于流水号之前的年份后两位，再生成最终标签号。该处理不是截掉最终标签号最后两位，5 位流水号和显示器主标签的 `-V` 后缀均不得删除。

#### 4.3.3 高耗标签规则

| 页面字段 | 业务含义 | 交互规则 |
| --- | --- | --- |
| 高耗大类 | 高耗标签所属大类 | 默认选中第一项，允许调整 |
| 高耗小类 | 决定使用 `P-`、`N-` 或 `QT-` 前缀 | 默认选中当前大类第一项；切换大类后自动改为新大类第一项 |
| 年份 | 决定标签中的年份后两位 | 默认当前年份，必填 |
| 当前最大序号 | 当前前缀和年份已经使用的最大流水号 | 自动带出，只读 |

高耗标签格式：

- 合约手机：`P-` + 年份后两位 + 4 位流水号。
- 合约电话卡：`N-` + 年份后两位 + 4 位流水号。
- 其他高耗：`QT-` + 年份后两位 + 4 位流水号。

高耗大类与小类映射：

| 高耗大类 | 高耗小类 |
| --- | --- |
| 电脑配件 | 内存、内置硬盘、板卡 |
| 电脑外设 | 移动硬盘、移动光驱 |
| 办公设备 | 会议白板、验钞机、考勤机、碎纸机 |
| 家电（ES权限） | 微波炉、电扇\|空调扇、饮水机、咖啡机、电暖器、机顶盒 |
| 合约机 | 合约手机、合约电话卡 |

`P-`、`N-`、`QT-` 三类前缀分别维护流水，互不占用对方流水。

#### 4.3.4 特殊规则-家具

| 页面字段 | 业务含义 | 交互规则 |
| --- | --- | --- |
| 家具类型 | 决定家具标签末尾类型编码 | 默认选中第一项，允许调整 |
| 当前最大序号 | 所有家具共用流水已经使用的最大序号 | 允许输入更大的正整数，不得小于已经使用的最大序号 |

家具标签格式：

> 6 位流水号 + 家具类型编码

家具类型编码：

- 工位：`A`
- 柜子：`D`
- 桌子：`E`
- 椅子：`Y`
- 其他：`Q`

所有家具共用一组公共流水，家具类型只决定标签末尾编码。

人工输入当前最大序号不能小于系统已经使用的最大值，否则阻止生成。

#### 4.3.5 特殊规则-手机

| 页面字段 | 业务含义 | 交互规则 |
| --- | --- | --- |
| 固定前缀 | 特殊规则手机标签前缀 | 固定为 `NE`，不可修改 |
| 当前最大序号 | 手机公共流水已经使用的最大序号 | 自动带出，只读 |

标签格式：`NE` + 4 位流水。

#### 4.3.6 特殊规则-备件

| 页面字段 | 业务含义 | 交互规则 |
| --- | --- | --- |
| 备件类型 | 决定备件标签前缀 | 默认选中第一项，允许调整 |
| 当前最大序号 | 所有备件共用流水已经使用的最大序号 | 自动带出，只读 |

前缀：CPU / Card / HD / ME / SP，后接 5 位公共流水。

#### 4.3.7 部件标签

“部件数量”表示每个主资产对应的标签明细总数量，包含主标签本身。

- 部件数量 = 1：只生成主标签，不生成关联部件标签。
- 部件数量 = X：每个主标签额外生成 `X - 1` 张关联部件标签。
- 标签明细总数量 = 打印标签数量 × 部件数量。

关联部件标签格式：

> 主标签号 + `-01`、`-02`……

部件标签类型在生成标签明细时写入。打印时直接按标签类型选择模板：主资产标签包含二维码；部件标签不生成资产卡片且不包含二维码。不能通过标签号包含 `-` 或排除 `-V` 的字符串规则判断部件标签。

#### 4.3.8 生成成功

生成成功后：

1. 创建标签批次。
2. 创建全部标签明细。
3. 更新对应流水已经使用的最大序号。
4. 页面回填标签批次。
5. 刷新当前最大序号。
6. 展示“打印标签”入口，可直接进入当前批次标签清单。

### 4.5 打印历史

打印历史用于业务人员追溯标签预打印和接收单标签打印行为。资产/耗材标签主列表补打不写详细打印历史，不在该页面查询。

从标签批次列表某一行点击“打印历史”进入时，系统直接限定当前批次。当前批次属于页面上下文，不再作为查询条件或列表列重复展示。

| 查询条件 | 业务含义 | 交互规则 |
| --- | --- | --- |
| 标签号 | 本次查询的标签号 | 从批次入口进入时支持模糊查询；从单标签入口进入时自动带出并设为只读 |
| 打印人 | 执行打印的人员 | 文本输入，支持模糊查询 |
| 打印时间 | 标签成功打印时间 | 日期范围，包含开始日期和结束日期当天 |

#### 4.5.2 列表字段

| 列表字段 | 业务含义 | 展示规则 |
| --- | --- | --- |
| 标签号 | 本次打印的标签 | 完整展示 |

| 打印 IP | 执行打印的电脑地址 | 完整展示 |
| 打印人 | 执行打印的人员 | 展示姓名 |
| 打印份数 | 本次该标签成功打印的份数 | 按业务原值展示 |

当前标签批次由入口自动限定，不提供查询条件，也不作为列表字段重复展示。

按打印时间倒序展示，最近打印记录优先。

#### 4.5.3 单标签打印历史

从标签清单某一行点击“打印历史”时：

1. 自动限定当前标签所属标签批次。
2. 自动带出当前标签号并设为只读。
3. 展示该标签全部打印记录。
4. 展示字段与批次打印历史一致。
5. 按打印时间倒序。

### 4.6 打印历史记录规则

标签预打印和接收单/员工接收标签打印生成详细打印历史；资产/耗材标签主列表补打只累计打印次数，不生成详细打印历史。

一条业务打印日志对应“一次打印任务中的一个标签”，业务页面可见字段至少包含：

- 标签号；
- 打印时间；
- 打印 IP；
- 打印人；
- 打印份数。

从标签批次进入打印历史时，页面自动限定当前批次，但不显示批次查询条件和列表列。

系统记录每次打印的来源、处理结果和失败原因，但不在业务打印历史列表展示。

### 4.7 导出

标签打印主列表支持导出：

1. 有勾选记录时，只导出当前勾选且有权限的数据。
2. 无勾选记录时，导出当前查询条件下全部有权限的数据，不只当前分页。
3. 导出字段按标签打印列表业务字段输出。
4. 导出文本以 `= + - @` 等字符开头时，按普通文本输出，避免被表格软件识别为公式。

## 5. 校验

### 5.1 标签打印校验

1. 打印所选时必须至少勾选一条。
2. 公司英文为空时不得打印。
3. 打印份数必须为 1～99 的整数。
4. 打印全部使用当前查询全部结果，不只当前分页。
5. 标签必须仍属于当前用户数据权限范围。
6. 部件标签不得进入资产/耗材标签主列表补打范围。
7. 机房管理员只能打印机房大类和备件标签。
8. 点击确认打印时必须重新校验最新标签数据和当前用户权限。

### 5.2 标签生成校验

1. 账套必选且属于当前用户权限范围。
2. 常规规则资产类型、年份必填。
3. 高耗规则高耗大类、高耗小类、年份必填。
4. 家具规则家具类型必填。
5. 备件规则备件类型必填。
6. 打印标签数量为 1～500 正整数。
7. 部件数量为 1～99 整数。
8. 单次标签明细总数不超过 5000。
9. 家具当前最大序号必须为正整数，且不能低于已经使用的最大值。
10. 常规流水不得超过 `99999`，高耗流水不得超过 `9999`；达到最大值后的扩展规则不在本次需求范围内。
11. 生成的全部标签号必须全局唯一。
12. 同一生成请求不得因双击或网络重试重复生成。

### 5.3 打印结果校验

1. 资产/耗材标签主列表补打完成后，`PRINTED_COUNT` 增加本次打印份数，不创建批次、标签明细或打印日志。
2. 预打印和接收单标签打印只有成功标签才增加标签明细打印次数并写入成功日志。
3. 预打印和接收单标签打印次数增加值等于本次成功打印份数。
4. 同一次打印操作的成功结果重复返回时，打印次数只能增加一次。
5. 部分成功时只累计成功标签，失败标签不改变打印次数。
6. 主列表 `PRINTED_COUNT` 与标签明细打印次数属于不同业务链路，不强制合并为同一累计值。

### 5.4 日期查询

1. 创建时间开始日期不得晚于结束日期。
2. 打印时间范围开始日期不得晚于结束日期。
3. 日期范围包含起止日期当天。

## 6. 后续操作 / 业务结果 / 补充说明

### 6.1 标签生成结果

标签预打印生成成功后：

1. 创建一个标签生成批次。
2. 创建该批次全部主标签和部件标签明细。
3. 保存主标签/部件标签类型及主从关系。
4. 更新对应流水当前值。
5. 页面回填标签批次并进入标签清单打印。

标签生成成功只表示标签号已经生成并占用，不表示标签已经关联正式资产/耗材卡片，也不表示标签已经打印。

### 6.2 资产/耗材标签主列表补打结果

1. 主列表补打直接打印已经存在的主标签。
2. 不创建标签批次和标签明细，不生成详细打印历史。
3. 打印完成后，主列表累计打印次数增加本次打印份数。
4. 主列表只能补打资产/耗材主标签，部件标签不进入该列表。

### 6.3 标签预打印结果

1. 预打印标签从所属标签批次进入标签清单。
2. 主标签打印二维码、公司英文名称、公司中文名称和标签号；二维码内容为标签号。
3. 部件标签从上到下打印公司英文名称、公司中文名称和标签号，不打印二维码。
4. 公司中文名称和公司英文名称根据生成标签时选择的账套取得。
5. 打印成功后更新标签明细打印次数、批次是否已打印状态并写入详细打印历史。

### 6.4 接收单/员工接收标签打印结果

1. 接收明细中的标签号在点击打印前已经存在。
2. 同一 PO 首次打印时创建标签批次，并把接收明细中的标签号写入标签明细。
3. 同一 PO 再次打印时使用原批次和原标签明细，不重复创建。
4. 打印成功后更新标签明细打印次数、批次是否已打印状态并写入详细打印历史。
5. 接收标签和预打印标签共用标签号生成规则及流水数据，不得维护两套独立流水。

### 6.5 标签批次与打印记录

1. 标签批次只来源于预打印和接收单标签打印；资产/耗材标签主列表补打不创建标签批次。
2. 同一次打印操作的成功结果只能累计一次。
3. 标签批次“是否已打印”表示该批次是否至少有一个标签成功打印过：任一标签成功为“是”，全部标签从未成功为“否”。
4. “是否已打印”不表示该批次全部标签已经完成打印。

### 6.6 当前尚未定义的业务规则

以下内容没有已确认业务口径，本 PRD不自行补充：

1. 预打印标签被资产/耗材接收占用、正式使用、释放和作废的生命周期。
2. 高耗合约手机 `P-` 标签与特殊规则手机 `NE` 标签各自适用的业务范围。
3. 标签批次号的生成格式。
4. 列表跨页勾选、翻页、查询、重置和排序时的选择保留规则。
5. 单次打印标签总数及“标签数量 × 打印份数”的任务上限。
6. 部分成功时业务页面是否展示成功数量、失败数量和失败标签号清单。
7. 打印 IP 的可信来源。
8. 导出文件格式、文件名、Sheet 名、固定字段顺序及文本/日期/空值格式。
9. 家具当前最大序号人工调大时的调整原因和审计记录。
