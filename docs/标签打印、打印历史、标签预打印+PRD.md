# 标签打印、打印历史、标签预打印 PRD

## 1. 背景

现状中“标签打印”“标签预打印”“标签打印历史”为三个独立菜单，入口分散，普通标签补打、预打印、接收入库打印在标签批次、打印次数和打印历史上的追溯口径也不完全一致。

本次将三个能力统一收口至：

> **资产管理 → 标签打印**

统一后的业务职责如下：

1. **标签打印**：查询已经存在的资产/耗材标签，支持补打、批量打印和导出。
2. **标签预打印**：在资产实际形成前，按照标签编码规则提前批量生成标签号，并形成标签批次及标签清单。
3. **打印历史**：记录并追溯标签打印、预打印、接收入库打印等实际打印行为。

本次同时补充流水并发、标签号唯一、打印任务幂等、打印次数一致性等后台规则，避免重复标签号、重复累计打印次数以及系统记录与实际打印结果不一致。

## 2. 改造总结

1. 原“标签打印 / 标签预打印 / 标签打印历史”三个菜单合并为一个“标签打印”菜单。
2. 默认进入标签打印列表，点击“预打印”进入“标签预打印”页面。
3. 标签预打印页承担标签批次查询和新建预打印入口。
4. 下钻关系为：**标签打印 → 标签预打印 → 标签清单 / 打印历史 → 单标签打印历史**。
5. 标签打印支持打印所选、打印全部、导出、预打印。
6. 标签打印、预打印、接收入库打印均进入统一标签批次、标签清单和详细打印日志体系。
7. 标签打印列表动态获取资产卡片、耗材卡片最新信息；台账字段变化后按标签号展示最新信息。
8. 预打印与资产接收生成标签共用同一套标签生成服务、同一流水规则和同一 CurrentValue。
9. 标签流水正式实现由服务端事务控制，不依赖浏览器临时状态。
10. 标签号在统一标签空间内全局唯一。
11. 所有打印动作均记录详细打印日志；一次打印多份时，打印次数按实际打印份数累计。
12. 标签大小本次不再维护。
13. 规则正式名称保留“常规标签规则 / 高耗标签规则 / 特殊规则-家具 / 特殊规则-手机 / 特殊规则-备件”，生成页面规则选择器简称为“常规 / 高耗 / 家具 / 手机 / 备件”。
14. 标签打印查询不再提供“是否在员工名下”“标签类型”。
15. 本轮不调整现有部件标签识别规则。
16. 业务界面不展示打印任务 ID、内部打印来源、内部打印状态、失败原因等技术排障字段；这些字段可作为后台内部日志字段保留。
17. 标签批次列表不展示“来源”。
18. 标签清单弹窗顶部已明确当前标签批次，列表内不重复展示“标签批次”列。
19. 打印历史查询使用一个“打印时间”范围条件，不拆成“打印时间从 / 打印时间至”两个查询项。
20. 编辑/业务页面不展示“原型模拟 / 正式环境 / 后端回执”等研发说明文案。
21. 打印历史可按标签批次查询，但列表不重复展示“标签批次”列。

## 3. 通用规则

### 3.1 菜单与入口

进入“资产管理 → 标签打印”后：

1. 默认展示已有资产/耗材标签查询、补打、批量打印和导出能力。
2. 点击“预打印”进入“标签预打印”。
3. 标签预打印页可进入某批次的“标签清单”或“打印历史”。
4. 标签清单可继续查看某个标签的打印历史。
5. 不再提供独立“标签预打印”“标签打印历史”菜单。

### 3.2 数据权限

1. 标签打印查询、打印、导出遵循当前用户的**公司 + 板块**数据权限。
2. 用户只能查询、打印和导出本人有权访问的数据。
3. 预打印生成标签需具有标签生成权限。
4. 账套候选范围结合用户可操作权限控制。
5. 不允许通过修改前端参数绕过权限。
6. 正式接口再次校验权限，不能只依赖前端按钮显隐。

### 3.3 标签数据来源

1. 标签打印列表动态获取当前系统中的资产卡片和耗材卡片。
2. 默认展示用户权限范围内全部可打印标签。
3. 台账信息发生变化后，标签打印列表根据标签号展示最新卡片信息，不长期保存独立快照作为展示来源。
4. 资产接收、耗材接收形成标签后进入统一标签清单。
5. 预打印生成标签和接收生成标签共用统一标签号空间。

### 3.4 标签号全局唯一

生成标签前必须在统一标签空间校验标签号是否已被占用，至少覆盖：

1. 标签清单已有标签。
2. 正式资产卡片已有标签。
3. 耗材卡片已有标签。
4. 资产/耗材接收链路已生成或已占用标签。
5. 其他共用同一标签号体系的业务记录。

数据库层必须建立标签号唯一约束。

任一标签号重复，本批次整体失败，不产生部分成功标签。

### 3.5 标签流水事务

正式生成标签时按以下顺序执行：

1. 根据当前规则计算流水规则键。
2. 服务端锁定对应流水规则。
3. 在锁内读取最新 CurrentValue。
4. 按跨年规则处理当年规则不存在的情况。
5. 校验本次主标签数量、标签明细数量和剩余号段。
6. 预占本次主标签流水区间。
7. 生成全部标签号。
8. 校验全部标签号全局唯一。
9. 创建标签批次。
10. 创建标签明细。
11. 更新 CurrentValue，并设置 NextValue = CurrentValue + 1。
12. 批次、明细、流水更新在同一事务内提交。

任一步失败全部回滚，禁止出现流水已推进但标签未生成、只生成部分标签或批次创建失败但流水被占用等情况。

数据库至少需要：

- 标签批次号唯一约束；
- 标签号唯一约束；
- 流水规则键唯一约束；
- 标签生成接口幂等控制。

### 3.6 流水维度

| 规则 | 流水维度 |
| --- | --- |
| 常规标签规则 | 账套 + 资产类型 + 年份对应规则；跨年按历史规则续号 |
| 高耗标签规则 | `QT-`、`P-`、`N-` 三类前缀分别维护公共流水，不区分公司，跨年不清零 |
| 特殊规则-家具 | 所有家具共用一组流水，不区分家具类型，跨年不清零 |
| 特殊规则-手机 | 所有手机共用一组流水，跨年不清零 |
| 特殊规则-备件 | 所有备件共用一组流水，CPU / Card / HD / ME / SP 只决定前缀，不拆分 CurrentValue，跨年不清零 |

### 3.7 跨年续号

预打印与资产接收标签生成共用同一流水体系，跨年不清零。

常规规则按“账套 + 资产类型 + 年份”查询：

1. 当年规则存在：使用当年 CurrentValue。
2. 当年规则不存在：查找最近上一年度有效规则。
3. 历史规则未达到 MaxValue：新年度继续使用历史 CurrentValue 续号。
4. 历史规则已达到 MaxValue：按新规则最小值开始。
5. 没有历史规则：按规则最小值开始。

高耗、家具、手机、备件按各自公共流水继续编号，不因年份切换清零。

### 3.8 标签生成幂等

1. 点击“生成标签”后按钮进入处理中状态。
2. 前端处理中禁止再次提交。
3. 正式接口接受唯一请求幂等键。
4. 同一幂等键重复请求只能返回同一业务结果。
5. 浏览器重试、网络超时重发、用户双击不得重复生成批次和标签。

### 3.9 打印任务与后台内部日志

每次打印动作建立唯一打印任务，用于后台幂等和排障。

打印动作包括：

- 标签打印页打印所选；
- 标签打印页打印全部；
- 标签清单打印所选；
- 标签清单打印全部；
- 接收入库打印。

后台内部可保存：

| 内部字段 | 用途 | 是否在业务页面展示 |
| --- | --- | --- |
| printTaskId | 一次打印动作唯一标识，用于幂等 | 否 |
| source | 区分标签打印、预打印、接收入库打印 | 否 |
| printStatus | 记录提交、成功、失败、部分成功等内部任务状态 | 否 |
| failureReason | 打印失败排障信息 | 否 |

这些字段属于技术实现和审计辅助信息，不属于标签批次列表、标签清单或打印历史的业务展示字段。

同一 printTaskId 的成功结果只允许累计一次。重复回调、网络重试或前端重复提交成功结果不得重复增加打印次数。

### 3.10 打印次数

1. 打印次数代表标签实际成功打印的累计份数。
2. 一次打印 N 份，成功后打印次数增加 N。
3. 标签清单打印次数与标签打印主列表中同一标签的打印次数保持一致。
4. 失败打印不增加打印次数。
5. 打印历史记录本次打印份数，用于与累计打印次数核对。

### 3.11 打印结果处理

1. 正式环境只有在得到可信的打印成功结果后，才增加打印次数并写入成功日志。
2. 未确认成功时不得提前把标签标记为已打印。
3. 同一批次内允许出现部分标签成功、部分标签失败；按标签实际结果分别处理。
4. 任务级状态可在后台内部记录，但不作为业务打印历史列表字段展示。
5. 打印失败原因可后台留存用于排障，但不作为业务打印历史列表字段展示。

## 4. 页面字段及交互

### 4.1 标签打印主列表

不提供“是否在员工名下”“标签类型”。

首次进入按以下顺序升序：

1. City。

支持表头排序。

| 选择 | 用于打印所选和勾选导出 |

| 部门 | 当前部门 |

| 公司英文 | 当前公司英文名称 |
| 板块中文 | 当前板块中文名称 |
| 序列号 | 当前 SN |

| 资产状态 | 状态标签 |
| 使用人 | `工号-姓名` |
| 打印次数 | 当前累计成功打印份数 |

#### 4.1.4 页面操作

页面右上方提供：

1. **打印所选**：未勾选时禁用；按钮可显示当前已选数量。
2. **打印全部**：打印当前查询条件下全部结果，不只当前分页。
3. **预打印**：进入“标签预打印”页面，为普通次级入口。
4. **导出**：有勾选时导出勾选记录；无勾选时导出当前查询结果全部数据。

#### 4.1.5 打印确认

点击打印后弹出“打印确认”：

1. 展示本次标签数量。
2. 打印份数输入范围 1～99，默认 1。
3. 展示“标签数量 × 打印份数 = 总打印张数”。
4. 确认后调用本地 Brother 打印能力。
5. 打印所选按勾选集合处理。
6. 打印全部按当前查询结果全部数据处理，不受当前分页限制。

#### 4.1.6 标签内容

打印标签时根据最新资产/耗材卡片信息生成标签内容。

中文显示规则：

1. 有板块中文时优先使用板块中文。
2. 无板块中文时回退公司中文。
3. 公司英文为空时阻止打印并提示维护公司英文信息。

### 4.2 标签预打印页面

页面标题统一为“标签预打印”。

页面提供：

- 生成标签；
- 标签批次查询；
- 标签清单；
- 打印历史；
- 返回。

底部返回按钮统一只显示“返回”，不带图标。

#### 4.2.1 标签批次查询

查询条件：

| 条件 | 规则 |
| --- | --- |

| 是否已打印 | 是 / 否 |
| 创建人 | 模糊查询 |
| 订单编号 | 模糊查询 |
| 资产标签号 | 查询包含该标签的批次 |
| 创建时间 | 日期范围 |

#### 4.2.2 标签批次列表

展示字段：

| 字段 | 规则 |
| --- | --- |
| 标签批次 | 批次号 |
| 订单编号 | 无值展示 `-` |
| 生成标签数量 | 当前批次标签明细数量 |
| 是否已打印 | 只要该批次发生过至少一次成功打印即为“是” |
| 创建人 | 创建人 |
| 创建时间 | 创建日期 |
| 备注说明 | 批次备注 |
| 操作 | 固定在右侧，提供“标签清单 / 打印历史” |

**业务列表不展示“来源”。** 打印链路如需区分预打印、标签打印、接收入库打印，由后台内部字段维护。

### 4.3 生成标签

点击“生成标签”进入生成标签页面。

#### 4.3.1 基础信息

| 字段 | 规则 |
| --- | --- |
| 账套 | 必选；候选按当前用户权限；默认当前可操作候选第一项 |
| 标签规则 | 按钮式单选：常规 / 高耗 / 家具 / 手机 / 备件 |
| 打印标签数量 | 默认 1；正整数；1～500 |
| 部件数量 | 默认 1；整数；1～99 |
| 标签批次 | 生成成功后回填，只读 |
| 生成操作人 | 当前用户，只读 |
| 生成日期 | 当前日期，只读 |
| 备注说明 | 可填写 |

单次生成的标签明细总数不得超过 5000 条。

规则切换使用按钮式单选，不使用 Tabs；下方只展示当前规则对应字段。

#### 4.3.2 常规标签规则

| 字段 | 规则 |
| --- | --- |
| 资产类型 | 默认候选第一项；可选择 |
| 年份 | 默认当前年份；必填 |
| 当前最大序号 | 系统计算，只读文本 |

标签示意：账套 + 资产类型 + 年份 + 5 位流水。

显示器等既有特殊类型继续按现有 `-V` 规则处理。

#### 4.3.3 高耗标签规则

| 字段 | 规则 |
| --- | --- |
| 高耗大类 | 默认候选第一项 |
| 高耗小类 | 默认当前大类第一项；切换大类时自动切换到该大类第一项 |
| 年份 | 默认当前年份；必填 |
| 当前最大序号 | 系统计算，只读文本 |

前缀：

- 合约手机：`P-`；
- 合约电话卡：`N-`；
- 其他高耗：`QT-`。

流水为 4 位。

#### 4.3.4 特殊规则-家具

| 字段 | 规则 |
| --- | --- |
| 家具类型 | 默认候选第一项；可选择 |
| 当前最大序号 | 可编辑正整数，用于业务允许的向前调整场景 |

家具后缀继续使用 A / D / E / Y / Q 等既有规则。

人工输入当前最大序号不能小于服务端已经使用的最大值，否则阻止生成。

#### 4.3.5 特殊规则-手机

| 字段 | 规则 |
| --- | --- |
| 固定前缀 | `NE`，只读文本，不展示成可编辑输入框 |
| 当前最大序号 | 系统计算，只读文本 |

标签格式：`NE` + 4 位流水。

#### 4.3.6 特殊规则-备件

| 字段 | 规则 |
| --- | --- |
| 备件类型 | 默认候选第一项；可选择 |
| 当前最大序号 | 系统计算，只读文本 |

前缀：CPU / Card / HD / ME / SP，后接 5 位公共流水。

#### 4.3.7 部件标签

主标签生成后，按部件数量生成对应标签明细。

部件标签使用：

> 主标签号 + `-01`、`-02`……

当前部件标签识别规则保持不变：

> 标签号包含 `-`，同时不是 `-V` 特殊形式。

本轮不调整该识别规则。

#### 4.3.8 生成成功

生成成功后：

1. 创建标签批次。
2. 创建全部标签明细。
3. 更新对应流水 CurrentValue。
4. 页面回填标签批次。
5. 刷新当前最大序号。
6. 展示“打印标签”入口，可直接进入当前批次标签清单。

### 4.4 标签清单

从标签批次进入“标签清单”。

弹窗顶部明确展示当前标签批次，因此列表中不再重复展示“标签批次”列。

#### 4.4.1 查询条件

| 条件 | 规则 |
| --- | --- |
| 标签号 | 模糊查询 |
| 是否已打印 | 是 / 否 |

#### 4.4.2 列表字段

| 字段 | 规则 |
| --- | --- |
| 选择 | 用于打印所选 |
| 标签号 | 标签号 |
| 打印次数 | 累计成功打印份数 |
| 是否已打印 | 成功打印次数 > 0 时为“是” |
| 操作 | “打印历史”，查看当前标签历史 |

#### 4.4.3 操作

1. **打印所选**：未勾选时禁用；按当前勾选标签打印。
2. **打印全部**：始终打印当前批次全部标签，不受当前标签号/是否已打印筛选条件影响。
3. 两种操作均弹出“打印确认”，输入打印份数。
4. 成功后对应标签打印次数增加本次份数。
5. 批次“是否已打印”更新为“是”。
6. 对于与标签打印主列表同一资产/耗材标签的记录，同步累计打印次数。

### 4.5 打印历史

打印历史用于业务人员追溯实际打印行为。

#### 4.5.1 查询条件

| 条件 | 规则 |
| --- | --- |
| 标签批次 | 模糊查询 |
| 标签号 | 模糊查询；从单标签入口进入时锁定当前标签 |
| 打印人 | 模糊查询 |
| 打印时间 | 一个日期范围条件，包含开始日期和结束日期 |

#### 4.5.2 列表字段

| 字段 | 规则 |
| --- | --- |
| 标签号 | 本次打印标签 |
| 打印时间 | 实际成功打印时间 |
| 打印 IP | 客户端 IP |
| 打印人 | 当前打印操作人 |
| 打印份数 | 本次该标签成功打印的份数 |

标签批次仍作为日志关联与查询字段保留，但不在打印历史列表中重复展示。

按打印时间倒序展示，最近打印记录优先。

业务页面**不展示**：

- 标签批次；
- 来源；
- 打印状态；
- 打印任务 ID；
- 失败原因。

以上字段如正式研发需要，可作为后台内部日志字段用于幂等、链路识别、批次关联和故障排查。

#### 4.5.3 单标签打印历史

从标签清单某一行点击“打印历史”时：

1. 自动限定当前标签号。
2. 展示该标签全部打印记录。
3. 展示字段与批次打印历史一致。
4. 按打印时间倒序。

### 4.6 打印日志生成

标签打印、预打印、接收入库打印均生成详细日志。

一条业务打印日志对应“一次打印任务中的一个标签”，业务页面可见字段至少包含：

- 标签号；
- 打印时间；
- 打印 IP；
- 打印人；
- 打印份数。

标签批次作为日志关联和查询字段保留，但不作为打印历史列表展示列。

后台实现可额外保存 printTaskId、source、printStatus、failureReason，但不直接展示在业务打印历史列表。

### 4.7 导出

标签打印主列表支持导出：

1. 有勾选记录时，只导出当前勾选且有权限的数据。
2. 无勾选记录时，导出当前查询条件下全部有权限的数据，不只当前分页。
3. 导出字段按标签打印列表业务字段输出。
4. CSV/Excel 输出时对以 `= + - @` 等公式字符开头的文本执行安全处理，防止表格公式注入。

## 5. 校验

### 5.1 标签打印校验

1. 打印所选时必须至少勾选一条。
2. 公司英文为空时不得打印。
3. 打印份数必须为 1～99 的整数。
4. 打印全部使用当前查询全部结果，不只当前分页。
5. 标签必须仍属于当前用户数据权限范围。

### 5.2 标签生成校验

1. 账套必选且属于当前用户权限范围。
2. 常规规则资产类型、年份必填。
3. 高耗规则高耗大类、高耗小类、年份必填。
4. 家具规则家具类型必填。
5. 备件规则备件类型必填。
6. 打印标签数量为 1～500 正整数。
7. 部件数量为 1～99 整数。
8. 单次标签明细总数不超过 5000。
9. 家具当前最大序号必须为正整数，且不能低于服务端已使用最大值。
10. 本次生成不得超过对应规则 MaxValue。
11. 生成的全部标签号必须全局唯一。
12. 同一生成请求不得因双击或网络重试重复生成。

### 5.3 打印结果校验

1. 只有确认成功的标签才增加打印次数。
2. 打印次数增加值 = 本次成功打印份数。
3. 同一 printTaskId 的重复成功回调不能重复累计。
4. 部分成功时只累计成功标签。
5. 失败打印不改变累计打印次数。
6. 标签清单和标签打印主列表中同一标签的累计打印次数必须一致。

### 5.4 日期查询

1. 创建时间开始日期不得晚于结束日期。
2. 打印时间范围开始日期不得晚于结束日期。
3. 日期范围包含起止日期当天。

## 6. 后续操作及补充说明

### 6.1 Brother 本地打印环境

正式标签打印继续使用既有 Brother 本地打印能力和标签模板。

需满足当前业务约定的浏览器、Brother 驱动及本地打印组件要求。

打印前由页面准备业务数据，实际物理打印结果以打印组件可确认的结果为准。

### 6.2 资产接收 / 耗材接收对接

1. 接收流程生成标签时调用与预打印相同的统一标签生成服务。
2. 接收生成标签写入统一标签清单。
3. 接收打印同样生成详细打印日志。
4. 接收打印成功后按实际份数累计打印次数。
5. 接收与预打印不得维护两套独立流水。

### 6.3 批次内部来源

标签批次或日志后台可维护内部来源，用于区分：

- 预打印；
- 标签打印；
- 接收入库打印。

该字段用于内部链路识别，不作为标签批次列表或打印历史列表的业务展示字段。

### 6.4 技术日志与业务页面边界

打印任务 ID、内部打印状态、失败原因等字段主要用于：

- 幂等；
- 重试；
- 部分成功处理；
- 故障排查；
- 技术审计。

这些字段不直接暴露给当前业务页面。若后续确有运维排障页面需求，应单独设计运维视图，不与当前业务打印历史混在同一列表。

### 6.5 批次“是否已打印”口径

标签批次“是否已打印”表示该批次是否已经发生过至少一次成功打印：

- 任意一个标签成功打印过 → 是；
- 全部标签从未成功打印 → 否。

该字段不表示当前批次全部标签都已经完成打印。

### 6.6 UI 固定口径

1. 页面名称使用“标签预打印”。
2. 批次明细入口使用“标签清单”。
3. 字段统一使用“是否已打印”。
4. 打印份数弹窗标题使用“打印确认”。
5. 标签预打印与生成标签页面返回按钮只显示“返回”，不带返回图标。
6. 规则切换使用按钮式单选，不使用页签。
7. 固定值、系统只读值使用只读文本展示，不使用 disabled 输入框模拟。
8. 业务页面不展示研发实现说明、内部任务字段和技术排障字段。
9. 打印历史列表不展示标签批次，批次仅用于查询和后台关联。
