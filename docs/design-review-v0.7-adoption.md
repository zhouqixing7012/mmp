| 原规则 | V2.3处理 |

| 查询标签默认88px，长标签扩大宽度 | 统一84px、省略及全文提示；详情96px标签不变 |

## 本轮实现范围与保留边界

- 实际入口为 `/yewurules → 后台基础配置 → 物料数据维护 → 物料维度组合`，与评审中的“库存数据维护”命名不同，保留项目现有名称。
- 统一Theme及Tailwind语义主色、后台面包屑与卡片画布；Ant Design静态浮层通过holderRender继承主题。历史页面单独硬编码的旧色值未全仓批量替换，移动独立主题和报表版式保持。
- 所有现有QueryBar调用继承新栅格和默认84px标签；报告、申请查询、盘点查询的显式112px已清理。自定义含查询/重置/更多的五处调用已顺序统一；只含单个查询动作的两个调用不新增按钮。
- 物料页已实现查询/重置、更多展开保留草稿、受控本页勾选、查询和分页清选择、密度切换、长文本提示及匹配空状态。选择候选复用既有基础资料；不从三条示例结果反推候选。
- “批量修改”原来承载上传文件、下载模板等文件入口，与本页勾选无关，故保留为常驻入口；启用/停用在所选操作条。既有保存、启停、文件处理未接写服务，本轮改为明确未开放提示，不再用关闭弹窗伪装保存成功；不新增写入规则。
- 公共弹窗同时兼容现用Ant Design 6的container结构与历史content结构。普通弹窗滚动正文，静态确认弹窗只滚动确认内容，标题和操作保留可见。
- 本轮未修改正式业务PRD。尚未接入的写能力不作为UI完成或业务验收通过的证据。
