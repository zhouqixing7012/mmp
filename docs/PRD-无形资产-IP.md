# 无形资产管理—IP PRD

版本：V1.0　日期：2026-10-27

## 一、背景

将小说、剧本等IP纳入无形资产的统一查询，帮助使用者了解IP内容、评审结果，以及相关采购、合同和付款记录。资产系统承担数据汇总与展示职能，业务办理在来源系统完成。

本次包含“无形资产—IP”的查询列表、IP详情及关联采购、合同、付款信息。资产系统不提供剧本采购、新增、修改、删除、审批、撤回、付款或打印申请等办理入口；不迁入原资料中已标注废弃的知识产权申请功能。

本次不将采购金额作为资产净值，不计算IP资产总额、累计付款或授权到期提醒。没有权利期限、权利范围、计价与摊销依据时，不推导相应业务结果。

## 二、权限

| 角色 | 可查看的数据范围 | 可执行操作 | 操作限制 | 无权限结果 |
| --- | --- | --- | --- | --- |
| 获得IP菜单及数据授权的用户 | 授权范围内的IP及其关联记录 | 查询、查看IP详情、查看采购明细 | 所有业务字段只读，不办理业务，不下载或导出敏感明细 | 无菜单权限不展示入口；直接访问及越权查看均不得展示数据，并提示“无权查看该IP” |

IP授权名单与按公司、部门或人员划分的数据范围尚未确定，见第六章；其他无形资产分类的管理员名单不自动成为IP权限名单。关联单据不得绕过对应IP及单据的查看权限。

## 三、通用规则

1. IP、采购、合同、付款是不同业务对象。IP评审状态与单据状态分别展示；IP评审通过不代表采购、合同或付款已完成。
2. IP代码为来源业务标识，按原值展示，不在资产系统生成新编号。来源中的业务关联决定明细归属，不按名称相同自动关联。
3. 只读内容保留来源的事实，空值展示“—”。明细为空展示“暂无采购信息”“暂无合同基本信息”或“暂无付款信息”；不得将加载失败显示为空记录。
4. 金额保留币种，采用千分位及两位小数。来源未给出金额时展示“—”，不得补为0；不同币种不得直接相加。
5. 采购金额仅表示该采购记录的金额，必须与币种及状态一并展示。已驳回采购不能据此认定取得IP权利或形成资产。
6. 名称、作者和内容简介等保留来源文本，不自动改写、生成摘要或评价。题材、市场反应、当前进度等枚举以来源字典为准，不依据少量样例推导完整枚举。

## 四、页面字段及交互

### 4.1 IP查询列表

首次进入查询授权范围内的数据；查询条件组合取交集，点击查询或在关键字中按回车执行。修改条件本身不刷新结果，查询后回到第一页。重置清空条件并重新查询。分页默认每页10条，可切换页大小；来源顺序暂予保留，正式业务排序见第六章。

#### 查询条件

| 字段 | 交互方式 | 数据来源及匹配规则 |
| --- | --- | --- |
| 关键字 | 文本输入，允许清空 | 对IP代码、IP名称进行包含匹配，去除首尾空格；英文字母不区分大小写 |
| 类型 | 下拉单选，允许清空 | 来源IP类型；已知值为小说、剧本，不允许手工新增类型 |

原图“时间”未说明对应IP创建、评审还是采购日期，本次不提供含义不明确的时间筛选。

#### 查询结果

| 字段 | 业务含义 | 展示及交互 |
| --- | --- | --- |
| IP代码 | 来源IP标识 | 原值展示，点击进入该IP详情 |
| 名称 | IP作品名称 | 完整展示，不以采购费用名称替代 |
| 类型 | IP所属内容类型 | 展示来源值 |
| 作者 | IP创作者 | 展示来源值；未提供时为“—” |
| 题材 | IP题材分类 | 展示来源值，帮助判断内容方向 |
| IP来源 | IP来源方 | 展示来源值，与采购记录的供应商分开 |
| 评审状态 | IP评审结果 | 展示来源值，与采购状态分开 |
| 操作 | IP查看入口 | 点击“查看详情”进入该IP详情 |

列表不提供勾选、批量处理、剧本采购、删除或导出按钮。无结果显示“暂无符合条件的IP”。加载过程中展示加载反馈；失败保留查询条件，提示“IP数据加载失败，请重试”，允许重新查询。

### 4.2 IP详情—基本信息

从列表的IP代码或查看详情进入，页面显示IP代码、名称及评审状态。基本信息全部只读，不存在保存或提交流程。

| 字段 | 业务含义及展示规则 |
| --- | --- |
| 名称 | 来源IP名称 |
| 类型 | 来源IP类型 |
| IP来源 | 提供该IP的来源方，不以采购供应商替代 |
| 作者 | 来源记录的创作者 |
| 题材 | 来源记录的题材分类 |
| 地区 | 来源记录的地区 |
| 当前进度 | 内容创作进度，不表示采购进度 |
| 市场反应 | 来源记录的市场反应描述，仅供参考，不作为估值或推荐结论 |
| 故事亮点或标签 | 来源提供的内容标签，完整展示 |
| 一句话故事 | 来源提供的故事概述，完整展示、支持换行 |
| 内容简介 | 来源提供的作品介绍，完整展示、支持换行 |

点击“返回列表”恢复进入详情前的已执行查询结果、输入条件、页码及页大小。记录不存在时显示“该IP不存在或已不可查看”，允许返回列表；不可展示上一条IP的残留信息。

### 4.3 采购信息

展示与当前IP明确关联的全部可查看采购记录，包括已驳回记录，以便追溯采购过程；不因IP评审通过而过滤或改写单据状态。

| 字段 | 展示及交互 |
| --- | --- |
| PR单号 | 来源PR单号；无正式编号时不生成编号。来源明确给出的“审批通过后生成”属于说明文字，不作为正式单号 |
| 费用名称 | 来源采购费用名称；点击查看该采购的只读明细 |
| 费用类型 | 来源费用类型 |
| 金额 | 该采购记录的金额，千分位、两位小数 |
| 币种 | 金额对应币种 |
| 采购类型 | 来源采购类型 |
| 授权形式 | 来源授权形式；不自动延伸为永久、全地域或全媒介授权 |
| 供应商 | 当前采购记录的供应商 |
| 申请人 | 来源申请人 |
| 申请时间 | 来源申请日期，按年-月-日展示 |
| 状态 | 来源采购单据状态 |

采购明细只读展示上述全部字段，关闭后回到原详情位置；不提供审批记录、编辑、打印申请或打印PR单入口。

### 4.4 合同基本信息

| 字段 | 展示及交互 |
| --- | --- |
| 合同单号 | 来源合同编号，不在资产系统生成 |
| 合同名称 | 来源合同名称 |
| 合同类型 | 来源合同类型 |
| 金额 | 来源合同金额，千分位、两位小数 |
| 币种 | 合同金额币种 |
| 采购类型 | 来源采购类型 |
| 授权形式 | 来源合同授权形式 |
| 供应商 | 来源合同供应商 |
| 申请人 | 来源申请人 |
| 申请时间 | 来源申请日期，按年-月-日展示 |
| 状态 | 来源合同状态 |

同一IP可展示多条合同，不将采购记录复制为合同。没有合同明细时展示空结果，不填充示例合同。

### 4.5 付款信息

| 字段 | 展示及交互 |
| --- | --- |
| 付款单号 | 来源付款单号 |
| 合同名称 | 来源付款关联的合同名称，不自动取IP下第一份合同 |
| 付款金额 | 来源付款金额，千分位、两位小数；币种规则见第六章 |
| 供应商名称 | 当前付款记录的供应商 |
| 发票状态 | 来源发票状态，不等同于付款状态 |
| 申请人 | 来源申请人 |
| 申请时间 | 来源申请日期，按年-月-日展示 |
| 状态 | 来源付款单据状态，不因存在付款单而显示为已付款 |

无付款明细时展示空结果。采购、合同、付款三张表独立分页，每页默认10条，显示各自总条数，不提供新增、修改、删除及打印按钮。

## 五、校验

| 校验项 | 触发时机 | 判断条件 | 处理方式及提示 | 修正方式 |
| --- | --- | --- | --- | --- |
| 菜单与数据权限 | 进入列表、详情或采购明细 | 不在授权范围 | 阻止展示，提示“无权查看该IP” | 返回列表或联系权限管理人 |
| IP存在性 | 打开详情 | 记录不存在或不可查看 | 不展示旧数据，提示“该IP不存在或已不可查看” | 返回列表重新查询 |
| 明细关联 | 加载采购、合同、付款 | 无法确认属于当前IP | 不混入当前IP，不按名称猜测关联 | 核对来源业务关联后展示 |
| 金额与币种 | 展示金额 | 金额缺失或币种未提供 | 缺失值为“—”，不补0、不换算、不汇总 | 由来源业务补齐信息 |
| 查询空结果 | 查询完成 | 授权范围内无匹配IP | 展示“暂无符合条件的IP” | 修改或重置查询条件 |
| 数据读取失败 | 查询或进入详情 | 数据未成功获取 | 明确提示失败并提供重试，不提示成功或显示为真实空台账 | 重试，失败时保留原查询条件 |

## 六、后续操作 / 业务结果 / 补充说明

查询和查看只改变当前展示内容，不生成业务单据、待办、通知、审批或变更记录，不修改IP及关联单据。来源记录更新后，重新查询应展示最新可查看数据；刷新后可重新进入列表，不要求保留上次打开的详情。

本次优先呈现内容识别、采购授权及单据追溯信息。市场反应保留在详情中作为来源描述；没有明确金额口径时不提供资产总额看板。原图合同及付款为空，只能证明字段结构，不能证明不存在历史业务或已完成采购。
