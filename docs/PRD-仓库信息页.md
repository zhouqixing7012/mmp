# 仓库基础数据维护模块 PRD

**文档版本**：v1.1
**更新日期**：2026年6月25日

---

## 一、模块概述

### 1.1 模块定位

"仓库基础数据维护"模块用于管理企业的仓库信息、仓库用途和仓库操作权限，是资产出入库管理的基础。

权限：所有涉及仓库编辑、修改的权限，目前仅开放给ES王英、刘建

### 1.2 包含页面

本模块包含3个子页面，通过顶部Tab标签页切换：

| Tab标签 | 功能说明 |
|---------|----------|
| 仓库信息 | 管理仓库的基本信息，包括编码、描述、地址、管理员等 |
| 仓库用途 | 管理仓库的用途分类（标准库、报废库、借用库、待检库） |
| 仓库权限 | 管理仓库的操作权限（入库/出库权限分配） |

---

## 二、页面1：仓库信息

### 2.1 页面功能

管理企业所有仓库的基本信息。每个仓库包含编码、描述、城市、楼栋、地址、用途、公司、管理员等字段。

### 2.2 主页面

#### 2.2.1 查询条件及表格

**查询条件默认状态**：展开显示所有搜索条件

**排序**：以仓库编码为依据，按编码升序排列

**分页**：每页默认10条，支持切换每页条数

**字段说明**：

| 字段名称 | 是否查询条件 | 查询条件控件类型 | 提示文案 | 说明 |
|----------|:----------:|:--------------:|----------|------|
| 仓库编码 | Y | Input | 请输入仓库编码 | 支持模糊检索 |
| 仓库描述 | Y | Input | 请输入仓库描述 | 支持模糊检索 |
| 是否虚拟库 | Y | Select | 请选择 | 枚举值：全部、是、否，表格内用标签样式 |
| 是否启用 | Y | Select | 请选择 | 枚举值：全部、启用、停用，表格内用标签样式 |
| 仓库用途 | N | - | - | 表格展示字段 |
| 公司 | N | - | - | 表格展示字段 |
| City | N | - | - | 表格展示字段 |
| 库管员 | N | - | - | 表格展示字段 |
| 操作 | N | - | - | "编辑"蓝色链接按钮，点击打开编辑弹窗 |

**按钮**：

- **查询**：蓝色主按钮，点击后根据条件筛选数据
- **重置**：灰色按钮，点击后清空所有搜索条件

#### 2.2.2 操作栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增弹窗 |
| 删除 | 红色按钮 | 删除选中的记录（需先勾选） |
| 启用 | 绿色文字按钮 | 启用选中的记录（需先勾选） |
| 停用 | 红色文字按钮 | 停用选中的记录（需先勾选） |

### 2.3 新增/编辑弹窗

#### 2.3.1 弹窗标题

- 新增时：标题为"仓库信息"（系统自动生成编码，无需区分新增/编辑标题，由Modal统一管理）
- 编辑时：标题为"仓库信息"

#### 2.3.2 表单字段布局

**字段说明**

| 分组 | 字段名 | 新增弹窗组件类型 | 编辑弹窗组件类型 | 是否必填 | 枚举值/格式 | 说明 |
|------|--------|:--------------:|:--------------:|:------:|-------------|------|
| 基础信息 | 仓库编码 | 文本输入框 | 文本（只读） | Y | 系统自动生成或手动输入 | - |
|  | 仓库描述 | 文本输入框 | 文本输入框 | Y | - | - |
|  | 城市 | 文本输入框+搜索图标 | 文本输入框+搜索图标 | N | - | 点击搜索图标弹出选择弹窗 |
|  | 楼栋 | 文本输入框+搜索图标 | 文本输入框+搜索图标 | N | - | 点击搜索图标弹出选择弹窗 |
|  | 楼层 | 文本输入框 | 文本输入框 | N | - | - |
|  | 地址 | 文本输入框 | 文本输入框 | N | - | - |
|  | 仓库类型 | 下拉选择 | 下拉选择 | N | 枚举值见字典管理 | - |
|  | 仓库用途 | 下拉选择 | 下拉选择 | N | ES库、MIS库、周转库、报废库 | - |
|  | 公司 | 文本输入框+搜索图标 | 文本输入框+搜索图标 | N | - | 点击搜索图标弹出选择弹窗 |
|  | 库管员 | 文本输入框+搜索图标 | 文本输入框+搜索图标 | N | - | 点击搜索图标弹出选择弹窗 |
| 状态 | 是否虚拟库 | 单选按钮 | 单选按钮 | N | 是、否 | 默认：否 |
|  | 是否启用 | 单选按钮 | 单选按钮 | Y | 启用、停用 | 默认：启用 |
|  | 启用日期 | 日期选择 | 日期选择 | N | YYYY-MM-DD | - |
|  | 停用日期 | 日期选择 | 日期选择 | N | YYYY-MM-DD | - |

**按钮**：

- 保存：蓝色主按钮，保存数据，关闭弹窗
- 返回：灰色按钮，取消操作，关闭弹窗

#### 2.3.3 校验规则

| 校验规则 | 校验项 | 错误提示 |
|----------|--------|----------|
| 必填字段合法性 | 所有必填字段 | "请输入XXXX" |
| 仓库编码唯一性 | 仓库编码 | "当前仓库编码已存在" |
