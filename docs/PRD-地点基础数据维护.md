## 一、模块概述

### 1.1 模块定位

"地点基础数据维护"模块用于管理企业的地点信息，采用**树形结构**展示城市与建筑的层级关系，是资产存放位置管理的基础。

### 1.2 包含页面

本模块只有1个页面：**地点基础数据维护**

### 1.3 核心设计原则

- **层级清晰**：城市 → 建筑，采用树形结构展示
- **筛选保留树**：筛选后保留完整树结构，用户能清楚看到建筑属于哪个城市
- **操作便捷**：点击城市行可展开/收起建筑列表

### 2.3 搜索条件区域

**默认状态**：展开显示所有搜索条件

**搜索字段**：

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 城市名称 | 文本输入框 | 支持模糊搜索，如输入"北京"可匹配"北京市" |
| 建筑名称 | 文本输入框 | 支持模糊搜索，如输入"搜狐"可匹配"搜狐媒体大厦" |
| 状态 | 下拉选择框 | 选项：全部、启用、停用 |

**筛选逻辑**：
- 选择城市时：树形视图只展开该城市及其建筑
- 搜索建筑时：树形视图展开匹配建筑所在的城市节点
- 多条件组合：取交集，同时满足所有条件的记录才会显示
- **重要**：筛选后保留完整树结构，父节点（城市）始终显示

**按钮**：
- **查询**：蓝色主按钮，点击后根据条件筛选数据
- **重置**：灰色按钮，点击后清空所有搜索条件

### 2.4 工具栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增弹窗 |
| 删除 | 红色按钮 | 删除选中的记录（需先勾选） |
| 启用 | 绿色文字按钮 | 批量启用选中的记录 |
| 停用 | 红色文字按钮 | 批量停用选中的记录 |

### 2.5 数据表格

#### 表格结构说明

表格采用**树形结构**展示，分为两层：

| 层级 | 说明 |
|------|------|
| 第一层（城市） | 父节点，显示城市名称，可展开/收起 |
| 第二层（建筑） | 子节点，显示建筑名称，隶属于某个城市 |

#### 表格列说明

| 列名 | 宽度 | 说明 |
|------|------|------|
| 序号 | 8% | 城市序号：1、2、3...；建筑序号：1.1、1.2、2.1... |
| 城市名称 | 35% | 城市行显示城市名称（加粗）；建筑行显示所属城市名称（灰色） |
| 建筑名称 | 35% | 城市行显示"-"；建筑行显示建筑名称 |
| 是否启用 | 22% | 启用（绿色标签）/停用（红色标签） |

#### 表格交互

**展开/收起**：
- 点击城市行可展开/收起该城市的建筑列表
- 展开图标：▶（收起状态）/ ▼（展开状态）
- 默认展开所有城市

**行悬浮**：
- 城市行悬浮：背景变为浅蓝色（#e6f7ff）
- 建筑行悬浮：背景变为更浅的蓝色（#f0f5ff）

**视觉区分**：
- 城市行：背景色 #f5f5f5，城市名称加粗显示
- 建筑行：白色背景，建筑名称常规显示
- 建筑行的城市名称列：灰色文字，表示归属关系

### 2.6 新增/编辑弹窗

#### 弹窗标题
- 新增时：标题为"新增地点"
- 编辑时：标题为"编辑地点"

#### 表单字段布局

**场景一：新增城市**

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 城市名称*（文本输入） | 是否启用*（单选） |

**场景二：新增建筑**

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 所属城市*（下拉选择） | 建筑名称*（文本输入） |
| 第2行 | 是否启用*（单选） | （空） |

#### 字段详细说明

**城市名称（必填）**：
- 控件类型：文本输入框
- 格式：直接输入城市名称，如"北京市"、"上海市"
- 校验：不能与已有城市名称重复

**建筑名称（必填）**：
- 控件类型：文本输入框
- 格式：直接输入建筑名称，如"搜狐媒体大厦"
- 校验：同一城市下不能有重复的建筑名称

**所属城市（必填）**：
- 控件类型：下拉选择框
- 数据来源：已有的城市列表
- 说明：选择建筑所属的城市

**是否启用（必填）**：
- 控件类型：单选按钮
- 选项：是、否
- 默认值：是

#### 弹窗按钮

| 按钮 | 样式 | 功能 |
|------|------|------|
| 保存 | 蓝色主按钮 | 保存数据，关闭弹窗 |
| 返回 | 灰色按钮 | 取消操作，关闭弹窗 |

### 2.7 校验规则

#### 新增城市时

| 字段 | 校验规则 | 错误提示 |
|------|----------|----------|
| 城市名称 | 必填 | "请输入城市名称" |
| 城市名称 | 唯一性校验 | "该城市名称已存在" |
| 是否启用 | 必填 | "请选择是否启用" |

#### 新增建筑时

| 字段 | 校验规则 | 错误提示 |
|------|----------|----------|
| 所属城市 | 必填 | "请选择所属城市" |
| 建筑名称 | 必填 | "请输入建筑名称" |
| 建筑名称 | 同城市下唯一性 | "该城市下已存在同名建筑" |
| 是否启用 | 必填 | "请选择是否启用" |

## 三、筛选逻辑详细说明

### 3.1 筛选流程

```
用户输入筛选条件
       ↓
┌─────────────────────────────────────┐
│ 1. 筛选建筑节点                     │
│    - 建筑名称匹配                   │
│    - 状态匹配                       │
│    - 城市名称匹配（如果有）          │
└─────────────────────────────────────┘
       ↓
┌─────────────────────────────────────┐
│ 2. 保留父节点                       │
│    - 如果城市下有匹配的建筑          │
│      → 保留该城市节点                │
│    - 如果城市名称匹配                │
│      → 保留该城市节点及其所有建筑    │
└─────────────────────────────────────┘
       ↓
┌─────────────────────────────────────┐
│ 3. 返回筛选后的树结构                │
│    - 保留完整的层级关系              │
│    - 自动展开匹配的城市节点          │
└─────────────────────────────────────┘
```

### 3.2 筛选示例

**示例1：搜索"搜狐"**
```
输入：建筑名称 = "搜狐"
结果：
├─ 北京市（保留，因为有匹配建筑）
│  ├─ 搜狐媒体大厦 ✓
│  ├─ 搜狐网络大厦 ✓
│  └─ 搜狐畅游大厦 ✓
├─ 上海市（保留，因为有匹配建筑）
│  └─ 搜狐上海大厦 ✓
└─ 深圳市（保留，因为有匹配建筑）
   └─ 搜狐深圳大厦 ✓
```

**示例2：搜索"媒体"**
```
输入：建筑名称 = "媒体"
结果：
└─ 北京市（保留，因为有匹配建筑）
   └─ 搜狐媒体大厦 ✓
```

**示例3：筛选城市="北京市"**
```
输入：城市名称 = "北京市"
结果：
└─ 北京市（保留）
   ├─ 搜狐媒体大厦 ✓
   ├─ 搜狐网络大厦 ✓
   └─ 搜狐畅游大厦 ✓
```
