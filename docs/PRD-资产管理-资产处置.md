# 资产管理 - 资产处置 PRD

## 1. 背景

资产处置以处置申请单处理已完成账面报废、仍需进行实物处理的资产，完成实物交接、回款凭证归档、必要的数据清洗及审批确认，并最终将资产状态更新为“已报废-已处置”。机房资产由系统自动发起处置单，办公资产由有权限的人员手动创建处置单。

本 PRD 仅覆盖实物处置，不覆盖：

- 跨公司转移；
- 资产报废申请；
- 账面报废。

本业务覆盖：

1. 机房资产：14.SERVER、15.NET EQUIPMENT；
2. 非机房办公设备：11.PC、12.NOTEBOOK、13.OFFICE EQUIPMENT、16.FURNITURE、18.VEHICLE、19.BUILDINGS、20.Investment Properties、21.LEASEHOLD IMPROVEMENT、22.Park lot land use rights。

非机房资产中的软件以及报废类型为“丢失”的资产没有实物处置流程，不生成处置单。调账资产、无需处置资产及其他明确不进入处置池的资产，也不进入本流程。

## 3. 通用规则

### 3.1 数据来源

实物处置资产来源于完成账面报废后进入待处置池的数据。

进入待处置池的资产必须满足：

- 已完成账面报废；
- 资产仍需实物处置；
- 资产状态为“已报废-待处置”；
- 未处于其他未结束实物处置流程。

以下资产不进入待处置池，也不会生成处置单，并且不能在手动创建处置单的资产选择弹窗中被选中：

- 调账资产；
- 报废类型为“丢失”的资产（包括丢失赔偿）；
- 非机房资产中的软件；
- 物料配置为无需处置的资产；
- 已在其他前置业务完成实物处置并确认无需再次处置的资产。

### 3.2 资产状态

处置前：

> 已报废-待处置

实物处置完成后：

> 已报废-已处置

状态更新必须与处置流程完成、凭证归档和操作历史记录保持一致。

### 3.3 单据状态

资产处置申请单支持：

- 草稿；
- 审批中；
- 已驳回；
- 办理中；
- 待 ES 专员处理；
- 已完成。

单据状态按以下动作流转：

| 资产范围 | 动作 | 新状态 |
|---|---|---|
| 办公设备 | 手动创建 | 草稿 |
| 办公设备 | 提交审批 | 审批中 |
| 办公设备 | 任一审批驳回 | 已驳回 |
| 办公设备 | 财务审批通过 | 待 ES 专员处理 |
| 办公设备 | ES 专员确认完成 | 已完成 |
| 机房资产 | 系统自动生成处置单 | 办理中 |
| 机房资产 | 全部协办完成 | 已完成 |

仅办公设备的草稿或已驳回单可由原发起人编辑并重新提交；其他状态只读。

### 3.4 附件

全流程仅使用单头【附件】，不设置附件类型，不增加独立附件区。各审批或办理节点上传的文件追加到同一附件列表，并记录上传节点、上传人和上传时间。

规则：

- 文件格式不限；
- 单文件大小不得超过 20MB；
- 超过 20MB 时阻止上传并提示；
- 草稿状态下发起人可上传和删除；当前审批或办理节点的处理人可上传，并只能在单据离开该节点前删除本人于该节点上传的文件；
- 已完成及其他只读状态仅支持查看和下载。

### 3.5 操作一致性

资产状态更新、处置记录、附件归档和操作历史属于同一次业务完成动作。

任一关键步骤失败时，不允许出现“资产已处置但处置记录未生成”或“流程已结束但状态未更新”的部分成功结果。

## 6. 机房资产实物处置

### 6.1 流程入口

机房资产完成账面报废且确认需要实物处置时，系统自动生成资产处置单并开始协办流程，不需要人员手动创建。系统首先判断资产归属地：

- 北京；
- 非北京。

机房资产实物处置不再重复走 ES 二级、ES 一级、财务审批链，主要由采购专员和 ES 专员按最终流程完成线下交接、凭证归档和数据清洗。

### 6.2 北京机房资产

正式流程：

> 实物处置流程开始  
> → 判断归属地=北京  
> → 采购专员协办  
> → ES 专员协办  
> → 判断是否需要数据清洗  
> → 如需要，采购专员协办数据清洗  
> → 资产状态更新为“已报废-已处置”  
> → 实物处置流程结束  
> → 通知相关人员

#### 6.2.1 采购专员协办

采购专员负责线下供应商打款确认。

完成后上传：

- 到款凭证。

文件上传至单头【附件】，不选择附件类型；本节点至少新增 1 个附件后进入 ES 专员协办。

#### 6.2.2 ES 专员协办

ES 专员负责线下供应商取货/实物交接。

完成后上传：

- 交接签字表。

文件上传至单头【附件】，不选择附件类型；本节点至少新增 1 个附件后进入“是否需要数据清洗”判断。

#### 6.2.3 数据清洗

如果资产需要数据清洗：

- 进入采购专员协办；
- 完成线下数据清洗；
- 将数据清洗报告上传至单头【附件】，不选择附件类型；
- 本节点至少新增 1 个附件后进入状态更新。

如果资产不需要数据清洗：

- 跳过数据清洗协办；
- 直接进入状态更新。

“是否需要数据清洗”直接读取资产报废申请明细中的【数据清洗】结果：值为“是”时进入采购专员数据清洗协办，值为“否”时跳过该协办。

### 6.3 非北京机房资产

正式流程：

> 实物处置流程开始  
> → 判断归属地=非北京  
> → 判断是否需要数据清洗  
> → 如需要，采购专员协办数据清洗  
> → 资产状态更新为“已报废-已处置”  
> → 实物处置流程结束  
> → 通知相关人员

#### 6.3.1 需要数据清洗

采购专员完成数据清洗后，将数据清洗报告上传至单头【附件】，不选择附件类型；本节点至少新增 1 个附件后进入状态更新。

#### 6.3.2 不需要数据清洗

跳过采购专员数据清洗任务，直接进入状态更新。

### 6.4 机房资产流程结束

状态更新成功后：

1. 资产状态更新为“已报废-已处置”；
2. 记录实物处置完成时间；
3. 记录实际处理人；
4. 生成处置操作历史；
5. 实物处置流程结束；
6. 按第 10.1 节发送通知。

自动跳过的节点不生成重复通知。

## 7. 非机房资产 - 办公设备实物处置

### 7.1 范围

办公设备范围：

- 11.PC；
- 12.NOTEBOOK；
- 13.OFFICE EQUIPMENT；
- 16.FURNITURE；
- 18.VEHICLE；
- 19.BUILDINGS；
- 20.Investment Properties；
- 21.LEASEHOLD IMPROVEMENT；
- 22.Park lot land use rights。

仅处理进入待处置池且仍需实物处置的办公设备资产。

### 7.2 正式流程

流程：

> 实物处置流程开始  
> → ES 专员提交处置申请  
> → ES 二级审批  
> → ES 一级审批  
> → 财务审批  
> → ES 专员处理  
> → 资产状态更新为“已报废-已处置”  
> → 实物处置流程结束  
> → 服务号通知 ES 主管

任一审批节点驳回后退回 ES 专员发起节点。

### 7.3 ES 专员发起处置申请

ES 专员在资产处置单列表点击【创建】，选择本公司“已报废-待处置”的办公资产，手动生成处置申请。

发起前完成线下询价。页面需要记录：

- 处置申请人；
- 所属部门；
- 处置申请日期；
- 备注；
- 单头附件；
- 处置资产及每项资产的回收商一至三报价金额。

盖章报价单及处置文件上传至单头【附件】，不选择附件类型。

#### 7.3.1 资产选择

添加资产弹窗查询字段与第 5.1 节一致，选择范围受单头公司约束。

只允许选择：

- 当前用户有权限；
- 当前处于待处置池；
- 资产状态为“已报废-待处置”；
- 未进入其他未结束处置流程；
- 不属于软件、丢失、调账或其他无需处置资产。

草稿内支持手工新增、删除、Excel 导入和导出明细。删除仅在选中明细时可执行。

Excel 模板字段包括资产标签号、回收商一、回收商二、回收商三，资产标签号为匹配键。导入时校验资产是否在当前公司待处置池、当前用户权限、未结束处置流程、重复标签号，以及三列报价金额是否均已填写且格式合法。任一行失败时整批不写入，并返回包含行号和失败原因的错误结果；全部通过后一次性加入或更新明细。

#### 7.3.2 报价金额

回收商一、回收商二、回收商三用于录入三个报价金额，支持单条维护和 Excel 导入并按资产标签号关联。每条资产的三列报价金额均必填，金额必须大于 0、最多 2 位小数。盖章报价单及处置文件上传至单头【附件】，不选择附件类型。页面不另设报价信息区块。

### 7.4 ES 二级审批

审批节点为 ES 二级审批。

审批操作：

- 通过；
- 驳回。

驳回退回 ES 专员。

### 7.5 ES 一级审批

审批节点为 ES 一级审批。

审批操作：

- 通过；
- 驳回。

审批通过后进入财务审批，并同时通过服务号抄送王明君、许丽、张洁、冯丽婷。

### 7.6 财务审批

财务审批人为徐博。

审批操作：

- 通过；
- 驳回。

驳回退回 ES 专员。

审批通过后进入 ES 专员实物处置处理节点。

### 7.7 ES 专员实物处置

财务审批通过后，ES 专员完成线下实物处置。

线下动作：

1. 供应商取货；
2. 供应商打款；
3. 完成实物交接。

ES 专员将实物照片、到款凭证和交接签字表等处置文件上传至单头【附件】，不选择附件类型。本节点至少新增 1 个附件，且 ES 专员确认线下材料均已归档后，方可完成处置。

### 7.8 流程结束

ES 专员确认完成后：

1. 资产状态更新为“已报废-已处置”；
2. 记录实物处置完成时间；
3. 记录回收商一、回收商二、回收商三报价金额；
4. 记录全部处置凭证；
5. 生成资产处置记录；
6. 生成资产操作历史；
7. 实物处置流程结束；
8. 按第 10.2 节发送通知。

## 8. 保存与提交校验

### 8.1 办公设备处置申请保存

草稿保存时：

- 已填写字段必须满足基础数据合法性；
- 首次保存后生成处置申请单号；
- 不触发审批。

### 8.2 办公设备处置申请提交

提交前必须校验：

1. 至少存在 1 条资产；
2. 所有资产仍在待处置池且状态为“已报废-待处置”；
3. 所有资产属于单头公司和当前用户数据权限；
4. 资产未进入其他未结束处置流程；
5. 每条资产的回收商一、回收商二、回收商三报价金额均已填写，金额大于 0 且最多 2 位小数；
6. 当前提交节点已向单头【附件】新增至少 1 个文件，业务人员确认其中包含盖章报价单；系统不按附件类型分类校验；
7. 附件单文件不超过 20MB；
8. Excel 导入资产全部通过同一套处置校验。

任一资产失败时不允许部分提交。

### 8.3 机房协办任务完成

机房协办节点完成前，当前处理人必须向单头【附件】新增至少 1 个文件，并确认本节点要求的线下材料已归档。北京采购专员节点应上传到款凭证，北京 ES 专员节点应上传交接签字表，数据清洗节点应上传数据清洗报告；系统不设置附件类型，也不按文件类型自动识别。

### 8.4 办公设备最终完成

ES 专员完成处置前，当前处理节点必须至少新增 1 个单头附件，并由 ES 专员确认实物照片、到款凭证和交接签字表等线下材料均已归档；系统不分类识别附件。当前资产不得已完成处置，完成处理中禁止重复提交。

## 9. 审批与处理历史

审批与处理历史可从单据详情、审批页和【查看进度】查看，按流程顺序展示。当前待审批或待办理节点展示在末尾，处理时间和意见为空；可查看单据的人员均可查看历史。字段包括：

- 处置申请单号；
- 资产标签号；
- 资产范围；
- 来源报废申请单号；
- 来源账面报废单号；
- 处理节点；
- 处理人；
- 处理时间；
- 审批结果；
- 审批意见；
- 回收商一报价金额；
- 回收商二报价金额；
- 回收商三报价金额；
- 单头附件变更记录；
- 数据清洗标识；
- 数据清洗报告；
- 资产状态变更前值；
- 资产状态变更后值；
- 流程完成时间。

## 10. 通知

### 10.1 机房资产

流程结束后：

- 服务号通知所有实际参与人；
- 通知内审经理；
- 通知集团财务。

### 10.2 办公设备

流程结束后：

- 服务号通知 ES 主管。

ES 一级审批通过后的流程抄送按第 7.5 节执行。
