## 1.需求概述
### 1.1目标
1. 支持正式员工对本人名下、允许转移且未被其他流程锁定的资产发起单笔或批量转移。
2. 统一接收人范围校验，确保接收人与转出人同成本中心，并满足公司板块领用资产权限。
3. 实现接收人保管职责确认、转出人及接收人领导审批、接收人超标审批和实物确认线上闭环。
4. 流程完成后自动生成转移单，更新资产台账、关联耗材台账、事务记录及相关报表。
### 1.2角色与权限
| 角色 | 权限及职责 |
| --- | --- |
| 转出人/申请人 | 仅正式员工；发起一般转移或离职转移；选择接收人和资<br>产；填写转移原因、使用用途。 |
| 接收人 | 仅正式员工；确认资产保管职责；流程审批完成后确认收<br>到实物。 |
| 转出人5级及以上领导 | 审批转出行为；申请人本人为5级及以上时，由其直接上<br>级审批。 |
| 接收人5级及以上领导 | 审批接收行为；接收人本人为5级及以上时，由其直接上<br>级审批。 |
| 接收人7级及以上领导 | 接收人个人超标时审批。 |
| 部门超标审批人 | 仅在接收人个人超标后且部门超标时，按资产申请超标权<br>限逐级审批。 |
| 系统 | 执行资格校验、相同审批人跳过、VP/CEO-1规则、超标<br>判断、资产锁定/解锁、转移单生成、台账和事务更新。 |

| --- | --- | --- |

## 2.全局业务规则
| 规则项 | 规则说明 |
| --- | --- |
| 人员权限 | 仅正式员工可发起和接收资产转移，实习生、外包员工不可发<br>起，也不可作为接收人。 |
| 转移类型 | 保留“一般转移、离职转移”两种类型，使用同一套审批流程。 |
| 是否可转移配置 | 直接使用物料基础资料中的“是否可转移”配置项；配置为<br>“否”时不得发起转移。 |
| 批量转移 | 支持一次选择多项资产，多个资产生成一张转移申请单，整单<br>审批、整单驳回。 |
| 资产范围 | 仅允许转出人本人名下、符合公司板块领用资产权限、物料允<br>许转移、未被锁定且资产状态为在用-使用中的资产。 |
| 盘点校验 | 资产处于启动中的盘点计划，且盘点状态为“未盘”、是否需<br>盘点为“是”时，禁止转移。 |
| 接收人范围 | 接收人与转出人必须同成本中心；同时接收人的公司、板块须<br>满足所有转移资产对应的公司板块领用资产权限。 |
| 地点规则 | City、Building、Floor 默认带出转出人的办公地点，全部只读<br>不可修改；流程完成后按该地点更新资产台账。 |
| 审批去重 | 相邻两个审批节点的审批人为同一人时，仅审批一次，后续相 |

|  | 同节点自动跳过。 |
| --- | --- |
| 领导查找 | 转出人或接收人本人为5级及以上时，对应领导节点取其直接<br>上级。流程流转至VP/CEO前，必须先经过一名VP/CEO-1<br>审批。 |

| 部门超标 | 仅在个人超标且部门超标时触发，按资产申请超标审批权限逐<br>级审批，直至审批人满足权限。 |

## 3.改造流程
流程说明：申请提交后依次经过接收人保管职责确认、转出人领导审批、接收人领导审批；接收人个人超标时增加7级及以上领导审批，个人超标且部门超标时继续逐级审批；
最终由接收人确认收到实物，系统更新台账与事务。任一节点驳回均结束流程。
### 3.1流程节点说明
| 序号 | 节点 | 处理人 | 通过后流向 | 驳回结果 |
| --- | --- | --- | --- | --- |

| 2 | 接收人确认保管职责 | 接收人 | 转出人5级及以上领导 | 单据状态修改为已驳回， |

| --- | --- | --- | --- | --- |
| 4 | 接收人5级及以上领导 | 接收人领导 | 个人超标判断 |  |
