# 资产借用

> 来源：`员工自助功能PRD.pdf`。原文边界：第 102 页起，至第 122 页下一模块标题前。仅做 Markdown 结构化排版，不主动改写业务口径。

## 1.建设目标
1. 统一资产借用申请入口、借用范围和借用期限。
2. 实现 ES 配给、直属领导审批、库管员发放和员工确认的线上闭环。
3. 规范借用资产出库、关联耗材同步出库及台账更新。
4. 建立到期前和逾期后的自动提醒机制。
## 2.角色与权限
| 角色 | 权限范围 | 主要操作 |
| --- | --- | --- |
| 申请人 | 仅正式员工；实习生、外包及其他员工类型不可<br>发起 | 提交借用申请、确认保管职责、现场扫码/刷卡/输入<br>工号确认 |
| ES 配给人员 | 具备资产借用配给权限的 ES 人员 | 选择仓库、匹配实物资产、查看员工名下资产、同意<br>或整单驳回 |

<!-- PDF 第 103 页 -->

| 直属领导 | 申请人汇报链上的直属 5 级及以上领导 | 同意或整单驳回 |
| --- | --- | --- |
| 库管员 | 对当前仓库具备出库权限的人员 | 查看待办、重新匹配资产、发起员工确认、执行出库、<br>驳回 |

## 3.单据状态与处理结果
| 单据状态 | 触发条件 | 说明 |
| --- | --- | --- |
| 处理中 | 申请提交成功，且流程尚未结束 | 覆盖 ES 配给、领导审批、库管员待<br>办和员工确认阶段 |
| 已完成 | 资产正常出库 | 放弃领用时同步记录处理结果为“放<br>弃领用”，不生成出库单<br>执行出库，生成事务 |
| 已驳回 | ES 配给或领导审批驳回或员工放弃领用驳<br>回 | 流程结束；已匹配资产解除锁定 |

## 4.全局业务规则
| 规则项 | 规则说明 |
| --- | --- |
| 借用权限 | 仅正式员工可发起资产借用申请。 |
| 物资范围 | 仅展示物料基础资料中“是否允许借用=是”的资产小类；不支持单独借用耗材。主资产已有<br>升级耗材时，耗材随主资产一并出库。 |
| 借用期限 | 借用开始日期可选择当前日期至未来 30 天；借用结束日期默认开始日期后 1 个月，最长<br>不得超过开始日期后 3 个月。 |
| 多物资与数量 | 一张申请单可包含多种物资；同一明细数量大于 1 时，提交后按数量拆成多行，但不拆单，<br>整单进入同一审批流程。 |
| 审批路径 | 员工提交 →ES 配给 → 直属 5 级及以上领导审批 → 库管员发放。若审批链需流转至<br>VP/CEO，不得由发起人直接流转至 VP/CEO，必须先经过一名 VP/CEO-1。 |
| 确认方式 | 下线 Pad 手写签名，仅保留狐小 e 扫码确认、刷卡确认和输入工号确认。 |
| 续借 | 下线续借入口和续借流程。 |

<!-- PDF 第 104 页 -->

| 到期处理 | 到期或逾期不修改借用单状态，不增加资产逾期标记，仅按提醒规则发送通知。 |

## 5.整体流程
| 节点 | 处理人 | 关键处理 | 流转结果 |
| --- | --- | --- | --- |
| 员工提交借用申请 | 申请人 | 选择借用物资、填写借用期限和需求说<br>明、确认保管职责 | 提交后状态变为“处理中”，进入 ES 配<br>给 |
| ES 配给 | ES 配给人员 | 选择仓库并匹配实物资产；可暂不匹<br>配；可查看申请人名下资产 | 同意进入直属领导审批；驳回后单据“已<br>驳回” |
| 直属领导审批 | 直属 5 级及以上领导 | 审批整单，不可修改申请明细 | 通过后通知申请人及库管员；驳回后单据<br>“已驳回” |
| 库管员发放 | 库管员 | 核对资产，可重新匹配实物资产；发起<br>员工现场确认 | 正常领用后执行出库；放弃领用后单据<br>“已处理” |
| 员工确认 | 申请人 | 扫码、刷卡或输入工号，阅读并确认资<br>产保管职责 | 确认成功后允许库管员执行出库 |
| 执行出库 | 库管员/系统 | 生成出库单、更新台账、事务及相关报<br>表 | 单据“已处理”，资产进入“在用-借用<br>中” |
| 到期提醒 | 系统 | 按借用结束日期执行提醒任务 | 仅发送通知，不修改单据或资产标记 |
