## 16.新员工/实习生资产领用
### 16.1背景与目标
新员工及实习生入职前，资产系统根据 PS 系统提供的待入职人员及资产配置信息，自动生成新员工资产领用单，由对应仓库库管员提前完成资产准备。
员工入职后，由库管员现场发放资产，员工通过刷卡确认领用。领用完成后系统自动完成资产出库、资产台账更新，并将领用结果回传 PS 系统。
本次同时下线新员工领用场景中的 Pad 签字能力，后续统一使用刷卡方式完成领用确认。

### 16.2适用范围
| 项目 | 规则 |
| --- | --- |
| 适用人员 | 新员工、实习生共用本流程 |
| 领用确认方式 | 仅刷卡确认 |
| 刷卡校验 | 刷出的员工工号必须等于领用单申请人工号 |
| 手工录入工号 | 保留；刷卡设备向确认框写入工号并触发校验 |
| Pad 签字 | 下线 Pad 签字页、清除/确认签字按钮、签名图片保存、签名复核和打印签名图 |

### 16.3参与角色
| 角色 | 职责 |
| --- | --- |
| PS / HR 系统 | 提供待入职人员信息；回传合同状态；接收领用结果<br>并推进入职流程 |
| 资产系统 | 拉取人员信息、生成领用单、校验合同、执行资产出<br>库、更新资产台账并回传结果 |
| 库管员 | 处理领用待办、选择并锁定资产、完成发放操作 |
| 新员工 / 实习生 | 现场刷卡确认领用 |

### 16.4接口与数据交互
| 编号 | 名称 | 调用方向 | 调用时机 | 结果 |
| --- | --- | --- | --- | --- |
| I01 | 待入职人员信息 | 资产系统 -> PS | 资产系统定时任务执行 | 返回待入职人员和资产配置，资产系统写入待<br>处理数据 |
| I02 | 合同状态通知 | PS -> 资产系统 | 员工签约或取消入职时 | 更新合同状态；已签约允许发放，取消入职关<br>闭领用处理 |

#### 16.4.1待入职人员信息

| 场景 | 处理 |

#### 16.4.2合同状态通知
PS 调用资产系统合同状态接口，最少提供员工工号和状态。如果周三12点前员工未入职，HR 系统将未签订合同信息推送到资产系统，资产系统自动将新员工领用单单据状态改为“已驳回”，并将驳回结果回传至 HR 系统。

<!-- PDF 第 51 页 -->

| 状态 | 资产系统处理 |
| --- | --- |
| 已签约 | 标记为可领用；库管员可继续刷卡确认 |
| 未签约 | 禁止确认领用，提示“新员工合同未签订” |
| 取消入职 | 取消待办；如已锁定资产则解除锁定；领用单置为已驳回 |

#### 16.4.3资产领用结果回传
资产系统在结果确定后实时调用 PS。回传结果必须可区分不同业务结果，不能继续以同一个状态值同时表示正常领用、弃领和拒绝。
| 结果码 | 触发场景 | PS 处理建议 |
| --- | --- | --- |
| SUCCESS | 刷卡校验通过、出库成功 | 自动通过“发放资产”节点 |
| ABANDONED | 员工主动弃领 | 结束或驳回“发放资产”节点 |
| REJECTED | 未签合同、合同取消或库管员驳回 | 驳回“发放资产”节点 |
| NO_ASSET_REQUIRE<br>D | 员工无资产配置 | 自动完成“发放资产”节点，并记录无需领用 |

回传内容至少包括：员工工号、实际发放人、发放时间、结果码、审批/弃领原因、资产领用单号、出库单号。PS 应返回明确成功或失败结果；资产系统需记录请求和响应，失败后可人工补发。
### 16.5.领用单与资产处理规则
#### 16.5.1领用单生成
1. 根据“公司+ City+资产配置”查询新员工领用物料映射。
2. 映射到几种物料，即生成几条领用明细；每条明细写入物料、资产总类、资产大类、申请数量和领用数量。
3. 默认仓库由办公地点与仓库映射带出；可选范围：当前公司下的且库管员有出库权限的仓库：仓库基础资料中“库管员”=当前审批人员且“出库权限”=“是”的当前单据“公司”（仓库数据维护）
4. 资产配置为空时，不生成领用单，直接按“无需领用”回传 PS。

<!-- PDF 第 52 页 -->

5. 资产配置存在但未找到物料映射时，不得静默停留在待处理状态；领用单应标记为“待配置处理”，并通知配置管理员处理。
| 场景 | 当前处理 |
| --- | --- |
| 有资产配置，且找到物料映射 | 自动创建新员工领用单、明细行和库管员待办；<br>随后启动 430 工作流 |
| 有资产配置，但未找到物料映射 | 当前任务不创建领用单，通知异常管理员 |
| 无资产配置且合同标记为 Y | 不创建领用单，直接调用 I03，随后更新生成<br>标记，PS 根据该结果自动完成“发放资产”节<br>点。 |
| 无资产配置且合同标记不是 Y | 当前任务直接跳过，不创建领用单、不回传 |

#### 16.5.2资产选择与锁定
1. 库管员可在允许的资产范围内选择资产，也可增加或删除资产明细。
2. 选择资产后，在保存时锁定资产；弃领、合同取消或驳回时解除锁定。
3. 发放前校验资产当前仓库必须与领用单仓库一致；不一致时提示“资产不在当前库，请进行移库操作”。
4. City、Building、Floor 可在领用页面修改，并在出库和资产台账更新时使用。
#### 16.5.3刷卡确认
1. 员工到现场后，由刷卡设备写入员工工号。
2. 系统校验刷卡工号与领用单申请人工号一致。
3. 一致时，弹出“是否确认领用”；确认后校验合同标记是否为 Y；否则提示“新员工合同未签订！”。是则立即执行出库。
4. 不一致时，提示“员工工号不匹配”，不得出库、不得完成领用单。
5. 全部 Pad 签字逻辑下线；刷卡成功后不展示签字页，不保存签名图片，不进行签名复核。
#### 16.5.4出库与台账更新
刷卡确认成功后，系统自动：

<!-- PDF 第 53 页 -->

1. 生成并审核领用出库单，回写出库单号。
1. 更新领用单为已完成。
2. 更新资产状态为“在用-使用中”。
3. 更新领用人、责任人、部门、成本中心、地点、用途和使用说明。
4. 生成资产变更/事务记录。
5. 回传 PS 领用成功结果。
### 16.6.单据状态
| 状态 | 含义 | 进入条件 |
| --- | --- | --- |
| 处理中 | 已生成领用单，等待库管员处理或员工刷卡 | 成功生成领用单 |
| 已完成 | 资产已成功出库并完成台账更新 | 刷卡校验通过且出库成功 |
| 已驳回 | 本次领用结束，未发放资产 | 弃领、合同取消、未签约拒绝或库管员驳回 |

### 16.7业务流程
资产系统定时拉取待入职人员（I01）->按资产配置映射物料和数量->生成新员工/实习生领用单并创建库管员待办->库管员选择资产并锁定-> PS 回传合同状态（I02）->已签约：员工现场刷卡->工号一致：执行出库、更新资产台账、领用单完成、实时回传 PS（I03SUCCESS）->工号不一致：提示“员工工号不匹配”，不出库->未签约/取消入职：解除锁定、领用单驳回、回传 PS（I03 REJECTED）->员工弃领：领用数量置零、解除锁定、领用单驳回、回传 PS（I03 ABANDONED）

->无资产配置：不生成领用单，回传 PS（I03 NO_ASSET_REQUIRED）

#### 16.8.3页面操作
-添加资产页面支持【新增】资产行。
库管员可根据员工实际领用情况新增资产，不强制完全按照 PS 预设资产配置的大类进行选择。
例如：PS 配置为某一类电脑，但实际现场根据库存情况需要更换其他资产大类时，允许库管员选择实际发放资产。
-删除资产页面支持删除已添加资产行。若该资产已经被当前领用单锁定，删除明细时同步解除资产锁定-保存当领用资产明细已经选择资产标签号后，库管员保存单据，系统锁定对应资产。锁定后的资产不得被其他领用、出库等业务重复选择。

<!-- PDF 第 58 页 -->

以下场景解除资产锁定：
| 场景 | 处理 |
| --- | --- |
| 当前资产明细被删除 | 解除该资产锁定 |
| 员工弃领 | 解除当前单据全部资产锁定 |
| 员工取消入职 | 解除当前单据全部资产锁定 |
| 单据被驳回 | 解除当前单据全部资产锁定 |

-弃领新员工资产领用单提供【弃领】按钮。点击后弹出弃领原因选择且为必选。
枚举值：
1. 非正常领用（不领用）
2. 非正常领用（更换设备）
3. 非正常领用（无库存）提交弃领后，系统自动：
1. 将所有领用资产明细的“领用数量”更新为0。
2. 解除当前单据已锁定资产。
3. 单据状态更新为已驳回。
4. 当前库管员待办结束。
5. 将弃领结果及弃领原因实时回传 PS 系统。
