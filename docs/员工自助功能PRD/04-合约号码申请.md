## 1.需求背景与目标
### 1.1需求背景
现有合约号码申请同时承载员工级别福利和因公业务需求，申请条件、审批方式与话费报销政策存在交叉。后续合约号码仅开放因公使用，不再因员工晋升或新员工级别自动发放，因此需要重新调整申请权限、审批链路和领用确认方式。
### 1.2已确认业务结论
1. 4级升5级或5级及以上新员工入职，不再自动发放合约号码。
2. 合约号码申请仅开放因公业务场景。

<!-- PDF 第 63 页 -->

3. 因公合约号码申请不校验申请人是否具备话费申请权限。
4. 历史已持有合约号码的个人使用员工不允许发起话费报销申请；本次流程新发放的合约号码可进行话费报销申请。
### 1.3建设目标
5. 通过 ES 预授权，仅向符合条件的正式员工开放申请表单。
6. 将申请类型统一为业务申请。
7. 减少重复线上审批，以已取得的高层审批邮件附件作为业务审批凭证。
8. 在 ES 主管审批后自动通知员工并生成库管员待办。
9. 取消员工线下纸质签字，以狐小 e 扫码确认形成电子领用记录。
10. 领用完成后自动出库并同步更新合约号码台账和操作历史。

## 5.全局业务规则
### 5.1业务场景
14. 申请类型固定为“业务申请”
15. 申请前需完成线下需求沟通，系统不记录线下沟通过程。
### 5.2实名认证附件
16. 申请人上传身份证正反面扫描文件，正反面需放在同一文件中。
17. 要求支持 PDF、Word、JPG、PNG，单文件最大10MB。
18. ES 配给人员和主管可下载附件。
### 5.3合约号码可选范围
19. ES 仅可选择号码状态为“在库（新）”或“在库（旧）”的合约号码。
20. 已被其他处理中单据选中的号码应锁定，不得重复配给。

<!-- PDF 第 66 页 -->

21. 申请被驳回、撤回或放弃领用后，应释放对应号码锁定。
### 5.4高层审批凭证
22. ES 配给提交前必须上传7级及以上领导的审批邮件附件；可包含 VP、CEO-1等更高层级审批。
23. 附件用于证明业务需求已获得授权，ES 主管在审批页面可查看或下载。
### 5.5单据状态
| 状态 | 进入条件 | 结束性 |
| --- | --- | --- |
| 处理中 | 申请提交成功后，直至出库完成、驳回。 | 否 |
| 已完成 | 员工扫码确认且库管员成功执行出库。<br>放弃领用也视为单据完成 | 是 |
| 已驳回 | ES 配给或 ES 主管执行驳回。 | 是 |

### 5.6话费报销关联规则
| 场景 | 规则 |
| --- | --- |
| 业务合约号码申请 | 不校验申请人当前是否具备话费申请权限。 |
| 历史个人使用（含5级及以上领导使<br>用）合约号码 | 不允许发起话费报销申请。 |
| 本流程新发合约号码 | 允许发起话费报销申请。 |

| 触发时间 | ES 主管审批通过后。 |
| 通知内容 | 申请单号、领取地点、联系人、联系电话、领取要求、详情链接。 |

### 13.3保管职责文案
保管职责:领用人确认已收到上述合约号码，认同公司合约号码作为工作用途使用且仅享有使用权。领用人应承担妥善保管合约号码的责任，使用期间严禁转售、借出等，否则将承担包括但不限于上述行为造成的相应赔偿责任。应公司需要时，领用人应当配合及时归还合约号码。如领用人延迟甚至拒绝交还合约号码，公司保留采取进一步手段的权利，包括但不限于留置领用人工资、奖金或者其他个人资产。
