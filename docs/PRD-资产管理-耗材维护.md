# 耗材维护

## 1. 背景

当前“资产管理 → 耗材维护”仍使用通用台账页面，只能完成基础查询、列表、简单编辑和导出，无法完整承载低值耐用品的卡片查看、字段维护、批量覆盖、主资产关联和操作历史。

本次将耗材维护收敛为独立业务页面，固定面向低值耐用品耗材卡片，并以本 PRD 作为页面和交互口径。

## 2. 改造总结

1. “资产管理 → 耗材维护”固定查询低值耐用品，不提供直接新增和删除。
2. 耗材标签号改为蓝色链接，点击进入耗材卡片。
3. 耗材卡片只保留“详细信息 / 资产操作历史”两个页签。
4. 耗材卡片详细信息只展示本 PRD 明确的 29 个字段，不增加其他字段。
5. 单条编辑只允许修改白名单字段；板块、耗材说明、数量等只读字段禁止修改。
6. 公司变更后，仓库候选按当前公司实时刷新；原仓库不属于新公司时立即清空。
7. 批量修改采用覆盖策略：模板中的可编辑字段按单元格值覆盖，空白会覆盖为空；必填字段空白直接校验失败。
8. 批量模板保留板块、耗材说明、数量作为只读核对列，只校验、不写回。
9. 批量修改采用全文件原子保存，任一行校验失败则整份文件不保存。
10. 列表支持组合查询、更多查询、排序、分页、模板下载、批量修改和导出。
11. 耗材修改成功后更新最后修改时间并生成操作历史；未发生变化不生成无效历史。
12. 低值耐用品不纳入 EBS 资产自动同步范围。

## 3. 通用规则

### 3.1 数据范围

1. 页面固定查询低值耐用品耗材卡片。
2. 已报废或已失效卡片继续保留在列表中供查询和查看。
3. 页面不提供直接新增耗材卡片入口。
4. 页面不提供直接删除耗材卡片入口。
5. 耗材卡片由采购接收、入库或其他正式业务流程生成。

### 3.2 数据权限

耗材台账按“财务公司 + 板块”隔离。

| 台账范围 | 查看人员 | 编辑人员 |
| --- | --- | --- |
| 集团台账 | ES 资产组及 ES 领导 | ES 资产组穆晓丹、吕静 |
| 上海媒体分公司台账 | ES 卢铭华 | ES 卢铭华 |
| 广州媒体分公司台账 | ES 李琴宝 | ES 李琴宝 |

权限规则：

1. 用户只能查看、编辑和导出授权范围内的数据。
2. 没有编辑权限的用户不展示单条编辑和批量修改入口。
3. 有编辑权限的用户也只能修改本 PRD 明确的可编辑字段。
4. 导出必须同时叠加当前用户数据权限和当前查询条件。

### 3.3 空值展示

1. 列表、卡片和操作历史中的普通空值统一展示为 `-`。
2. 编辑控件中的空值保持为空，不使用 `-` 作为提交值。
3. 批量修改中的可编辑空白单元格按照覆盖策略处理，不再表示“保留原值”。

### 3.4 默认排序

1. 首次进入按“最后修改时间倒序 → 耗材标签号升序”。
2. 新增入库或耗材信息实际发生变化后更新最后修改时间。
3. 用户可对支持排序的业务列执行升序或降序。
4. 手动排序只改变当前展示顺序，不改变数据权限和查询范围。
5. 页面刷新后不保留手动排序条件。

1. 不同查询条件之间使用 AND。
2. 同一多选条件内使用 OR。
3. 未填写条件不参与过滤。
4. 清空查询条件后恢复当前账号权限范围内的默认列表。
5. 查询、分页、排序不得突破数据权限。
6. 文本查询支持回车提交。
7. 查询条件支持双击清空当前条件。

### 4.5 单条编辑

用户勾选耗材后点击“编辑”。

| 场景 | 处理 |
| --- | --- |
| 未选择 | `请选中要编辑的数据！` |
| 选择超过一条 | `只能选中一条要编辑的数据！` |
| 恰好一条 | 打开当前耗材卡片编辑态 |

#### 4.5.1 可编辑字段

| 字段 | 控件 | 规则 |
| --- | --- | --- |
| 公司 | 公司选择器 | 必填；修改后立即刷新仓库候选 |

| 使用说明 | 多行文本 | 可为空 |

#### 4.5.2 不允许手工变更字段

除上述可编辑字段外，耗材卡片其他字段全部只读。

其中明确禁止修改：

1. 板块。
2. 耗材说明。
3. 数量。
4. 耗材大类。
5. 耗材小类。
6. 耗材标签号。
7. 原值。
8. 购置日期。
9. 新增类型。
10. 单位。
11. PR 单号、申请单号、入库单号、PO 单号。
12. 部门不允许独立编辑，只随责任人选择结果更新。
13. 成本中心只读。

#### 4.5.3 公司与仓库联动

1. 仓库候选始终根据编辑页面“当前公司”实时生成。
2. 修改公司后立即重新计算仓库候选。
3. 原仓库仍属于新公司时可继续保留。
4. 原仓库不属于新公司时立即清空，用户必须重新选择。
5. 打开既有耗材时，如果当前已保存仓库因基础资料调整已经不属于正常候选，但公司未变化，仍允许继续展示并原样保留；只有用户主动修改仓库或公司后才按当前候选重新校验。
6. 保存时再次校验仓库与当前公司的关系，不能只依赖前端候选范围。

### 4.6 批量修改

#### 4.6.1 模板字段

批量修改模板固定包含：

| 字段 | 作用 | 是否写回 |
| --- | --- | --- |
| 耗材标签号 | 定位既有耗材 | 否 |
| 公司 | 可编辑字段 | 是 |
| 板块 | 只读核对字段 | 否 |
| City | 可编辑字段 | 是 |
| Building | 可编辑字段 | 是 |
| Floor | 可编辑字段 | 是 |
| 耗材说明 | 只读核对字段 | 否 |
| 主资产标签号 | 可编辑字段 | 是 |
| 数量 | 只读核对字段 | 否 |
| 耗材责任人工号 | 可编辑字段 | 是 |
| 耗材状态 | 可编辑字段 | 是 |
| 仓库 | 可编辑字段 | 是 |
| 启用日期 | 可编辑字段 | 是 |

板块、耗材说明、数量虽然保留在模板中用于人工核对和上传校验，但不得通过批量上传写回修改，也不得通过接口补传绕过限制。

#### 4.6.2 覆盖策略

1. 耗材标签号只用于定位既有耗材，不能修改。
2. 板块、耗材说明、数量只用于核对，不参与覆盖。
3. 其余可编辑模板字段全部采用覆盖策略。
4. 可编辑单元格有值：使用模板值覆盖原值。
5. 可编辑单元格空白：将原字段覆盖为空。
6. 公司、责任人、City、Building 为必填字段，因此对应单元格空白时直接校验失败，不允许把必填字段覆盖为空。
7. 不再存在“空白表示保留旧值”的规则。
8. 不再定义额外的“清空标识”，可编辑字段的空白本身就是清空指令。

#### 4.6.3 批量校验

1. 文件必须符合固定模板、表头和列顺序。
2. 耗材标签号必填且必须存在。
3. 同一文件中的耗材标签号不得重复。
4. 板块、耗材说明、数量必须与系统当前卡片值一致；任一不一致时该行校验失败，不执行写回。
5. 公司必须存在。
6. 责任人工号必须存在并属于 MMP 管理范围。
7. City、Building、Floor 必须满足位置基础数据关系。
8. Building 必须属于 City；Floor 有值时必须属于 Building。
9. 耗材状态必须存在；报废状态禁止通过批量修改写入。
10. 主资产标签号有值时必须存在、未报废且不得等于当前耗材标签号。
11. 仓库有值时必须属于模板中当前公司的有效耗材仓库。
12. 启用日期有值时按合法日期校验。
13. 板块、耗材说明、数量以及其他非白名单字段禁止通过任何批量接口变更。

#### 4.6.4 保存策略

1. 全部行先完成校验，再进入保存。
2. 任一行校验失败，整份文件不保存。
3. 不允许部分成功。
4. 保存成功后，实际发生变化的耗材分别更新最后修改时间并生成耗材维护修改事务。
5. 页面提示 `上传成功！` 并刷新列表。

### 4.7 资产操作历史

1. 按耗材标签号查询当前耗材事务。
2. 按操作时间从早到晚展示。
3. 相邻两条事务中发生变化的业务字段使用黄色背景标识。
4. 人工保存未发生字段变化时不生成历史。
5. 旧系统迁移历史与当前系统历史统一在该页签展示。

展示字段固定为：

| 字段 |
| --- |
| 操作类型 |
| 操作时间 |
| 操作人 |
| 单据编号 |
| 申请单号 |
| 耗材标签号 |
| 序列号 |
| 类别 |
| 耗材说明 |
| 责任人 |
| 公司 |
| 地点 |
| 耗材状态 |
| 使用说明 |
| 备注 |
| 主资产标签号 |

### 4.8 导出

1. 勾选耗材时提示 `确定要导出选中的数据吗?`，只导出勾选且有权限的数据。
2. 未勾选时提示 `确定要导出列表中的数据吗?`，导出当前查询条件下全部结果，不只导出当前分页。
3. 两种导出都叠加当前用户数据权限。
4. 文件名：`导出耗材卡片信息-日期.xlsx`。
5. 工作表名称：`低值耐用品明细`。

## 5. 校验

### 5.1 单条保存

| 校验项 | 规则 |
| --- | --- |
| 公司 | 必填且必须有效 |
| 责任人 | 必填且必须有效，并属于 MMP 管理范围 |
| City | 必填且必须有效 |
| Building | 必填且必须属于 City |
| Floor | 有值时必须属于 Building |
| 序列号 | 最多 120 字；真实序列号唯一 |
| 耗材状态 | 必须有效；报废走专门报废功能 |
| 主资产 | 有值时必须有效、未报废、不得关联自身 |
| 仓库 | 新选择的仓库必须属于当前公司；历史已保存但已退出候选的仓库可在公司未变化时原样保留 |
| 字段白名单 | 页面和保存接口都必须校验，禁止修改非白名单字段 |

保存接口不能直接信任页面显示值：责任人姓名、部门、公司编码、主资产说明等派生字段必须根据主数据重新获取，防止通过接口伪造。

### 5.2 保存结果

1. 保存成功提示 `保存成功！`。
2. 保存成功后继续停留在当前耗材编辑页，并使用保存后的最新数据刷新当前页面。
3. 保存失败展示真实失败原因，保留当前输入，不产生半条历史。
4. 没有字段变化时提示 `耗材信息未发生变化`，继续停留编辑态，不更新最后修改时间，不生成事务。

## 6. 后续操作及补充说明

### 6.1 主资产联动

耗材通过主资产标签号与主资产建立关联。主资产执行借用、归还、报废等正式操作后，关联低值耐用品可按后续业务规则同步责任人、仓库、状态和位置等信息；该联动属于跨业务流程，不在耗材维护页面通过额外按钮触发。

### 6.2 EBS

1. 低值耐用品不纳入 EBS 资产自动同步。
2. 耗材维护页面不提供手工 EBS 同步入口。
3. 低值耐用品的入库、编辑和主资产联动不得生成低值耐用品 EBS 自动同步任务。

### 6.3 历史数据

旧系统历史迁移后统一进入“资产操作历史”，页面不再单独提供旧系统历史页签。

### 6.4 保存后的事务

人工修改耗材并实际发生字段变化后，生成耗材维护修改事务并进入现有资产事务处理链路；页面通过“资产操作历史”继续追溯本次变化。
