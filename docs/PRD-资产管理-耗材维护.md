# 资产管理 - 耗材维护 PRD

## 1. 背景

耗材维护用于统一查询、查看和维护已经形成正式耗材卡片的低值耐用品数据。

耗材卡片由采购接收、入库及其他正式业务流程生成。耗材维护仅维护已有正式耗材卡片，不提供耗材卡片新增、删除和正式报废入口。

耗材维护支持：

- 查询耗材；
- 查看耗材卡片；
- 单条编辑；
- Excel 批量修改；
- 查看耗材操作历史；
- 导出耗材卡片信息。

低值耐用品与普通资产的财务同步范围独立，耗材维护不创建普通资产 EBS 自动同步任务。

## 2. 权限

耗材数据按“财务公司 + 板块”进行权限隔离。查看权限与编辑权限独立控制。

| 权限范围 | 数据范围 | 查看人员 | 编辑人员 |
|---|---|---|---|
| 集团台账 | 集团授权范围 | ES 资产组及 ES 领导 | ES 资产组穆晓丹、吕静 |
| 上海媒体分公司台账 | 公司 115，板块 11 | ES 卢铭华 | ES 卢铭华 |
| 广州媒体分公司台账 | 公司 116，板块 11 | ES 李琴宝 | ES 李琴宝 |

权限规则：

- 用户只能查询、查看、导出其授权范围内的耗材。
- 只有编辑人员可以执行单条编辑和 Excel 批量修改。
- 编辑人员只能修改其授权公司、板块范围内的耗材。
- 查看权限不代表编辑权限。
- 单条保存、批量保存、导出时重新校验当前数据权限和操作权限。
- 无编辑权限时不展示行级【编辑】和【批量修改】入口。

## 3. 通用规则

### 3.1 维护范围

耗材维护固定管理低值耐用品耗材卡片。

规则：

- 已报废、已失效耗材继续保留在列表中供查询和查看。
- 页面不新增耗材卡片。
- 页面不删除耗材卡片。
- 页面不直接执行正式报废。
- 页面和接口均只能修改本 PRD 明确开放的字段。
- 页面字段名称统一使用“耗材”业务术语。

### 3.2 默认排序、数量、金额与空值

首次进入页面时，默认：

最后修改时间倒序 → 耗材标签号升序

规则：

- 新增入库或耗材信息实际发生变化后更新最后修改时间。
- 用户可对支持排序的业务列执行升序或降序。
- 用户手工排序仅改变展示顺序，不改变数据权限和查询范围。
- 重新进入页面或清空排序后恢复默认排序。
- 数量按业务原值展示，不强制千分位。
- 原值、净值等金额使用千分位 + 2 位小数。
- 列表、卡片和操作历史中的普通空值显示“-”。
- 编辑控件空值保持为空，不使用“-”作为提交值。
- Excel 导出空值写为空单元格。

### 3.3 单条开放编辑字段

单条编辑开放以下 12 个业务字段：

| 字段 | 必填 | 规则 |
|---|---:|---|
| 公司 | Y | 财务公司；修改后刷新仓库候选 |
| 序列号 | N | 真实 SN 唯一；“缺省”可重复 |
| 耗材状态 | Y | 正常状态可维护；正式报废状态锁定 |
| 耗材责任人 | Y | 选择后重新取得员工姓名和部门 |
| City | Y | 修改后清空 Building，不清空 Floor |
| Building | Y | 必须属于当前 City |
| Floor | N | 非空时必须为启用 Floor；不要求属于 Building |
| 启用日期 | N | 有值保存页面值；为空按 3.9 节处理 |
| 主资产标签号 | N | 按 3.6 节关联规则 |
| 仓库 | N | 按 3.5 节候选规则 |
| 使用说明 | N | 文本 |
| 备注 | N | 文本 |

除以上字段外，耗材卡片其他字段均为只读。

以下字段明确禁止手工修改：

- 板块；
- 耗材说明；
- 数量；
- 耗材大类；
- 耗材小类；
- 耗材标签号；
- 原值；
- 购买日期；
- 新增类型；
- 单位；
- PR单号；
- 申请单号；
- 入库单号；
- PO单号；
- 成本中心。

部门不提供独立编辑入口，只随责任人更新。

主资产说明不提供独立编辑入口，只随主资产标签号关联结果更新。

### 3.4 组织与财务归属

公司、板块、责任人、部门和成本中心的关系如下：

- 公司允许用户修改。
- 板块保持当前耗材卡片值，不随责任人变化。
- 责任人允许用户修改。
- 修改责任人后，根据员工主数据重新取得责任人姓名和部门。
- 责任人与公司独立维护，修改责任人不自动修改公司。
- 责任人不自动修改板块。
- 成本中心在页面只读。
- 当前耗材已有有效成本中心时保留当前值。
- 当前成本中心为空时，根据责任人员工信息取得成本中心。
- SOHU 开头虚拟用户按虚拟用户成本中心规则处理。
- 非 SOHU 普通员工没有部门时不允许保存。
- 责任人必须属于 MMP 管理范围。

保存时根据最终公司、板块、责任人、成本中心、资产大类、City、服务等信息重新计算财务归属字段和费用账户。

### 3.5 公司与仓库

有效耗材维护仓库必须同时满足：

1. 仓库状态 = 启用；
2. 仓库公司 = 当前耗材公司；
3. 仓库用途属于：
   - IU0001（耗材库）；
   - IU0003（资产高耗库）。

联动规则：

- 修改公司后立即重新计算仓库候选。
- 原仓库仍满足新公司候选条件时可保留。
- 原仓库不满足新公司候选条件时立即清空。
- 用户主动选择或修改仓库时，必须从当前有效候选中选择。
- 打开历史耗材时，如果已保存仓库因基础资料变化退出正常候选，但公司未发生变化，该历史仓库允许继续展示和原样保留。
- 用户主动修改公司或仓库后，历史保留例外失效，必须按当前有效候选重新校验。
- 保存时重新校验仓库启用状态、所属公司和仓库用途。

### 3.6 主资产关联

主资产标签号允许为空。

选择主资产前必须已经选择耗材责任人。

主资产必须同时满足：

- 主资产存在；
- 主资产未正式报废；
- 主资产标签号不得等于当前耗材标签号；
- 主资产责任人与当前耗材责任人一致。

选择主资产后：

- 保存主资产标签号；
- 同步主资产说明。

清空主资产标签号后：

- 主资产标签号清空；
- 主资产说明同步清空。

修改责任人后，如果原主资产不再属于新的责任人：

- 清空主资产标签号；
- 清空主资产说明；
- 用户需要重新选择符合条件的主资产。

### 3.7 耗材状态

耗材状态必须为有效状态。

正式报废状态只能由耗材报废业务产生。

耗材维护规则：

- 非正式报废状态之间允许按业务字典修改。
- 当前耗材已经处于正式报废状态时，耗材状态字段锁定。
- 已正式报废耗材的其他开放维护字段仍可按权限修改。
- 单条编辑中正式报废状态直接展示只读文本，不展示 disabled 下拉框。
- Excel 批量修改不得把耗材状态改为正式报废状态。

### 3.8 SN 规则

序列号保存前去除首尾空格。

规则：

- 空值允许；
- “缺省”为合法占位值；
- “缺省”不参与唯一性冲突；
- 除“缺省”外的真实序列号全局唯一；
- 唯一性比较忽略英文字母大小写；
- 保存与展示保留用户原始大小写；
- 单条编辑最大长度 120 字。

### 3.9 启用日期

单条编辑：

- 用户填写启用日期时保存页面值。
- 用户将启用日期留空时，根据购买日期重新计算启用日期：
  - 购买日期为当月 1～25 日：启用日期 = 购买日期；
  - 购买日期为当月 26 日及以后：启用日期 = 下月 1 日。
- 启用日期重新计算结果作为本次保存结果，不保留旧值。

Excel 批量修改：

- 启用日期有值时按模板值覆盖。
- 启用日期空白时清空原值。
- Excel 批量修改不触发单条编辑的启用日期自动计算。

### 3.10 单条与批量字段范围

单条编辑和 Excel 批量修改使用不同字段白名单。

单条编辑范围见 3.3。

Excel 批量修改：

- 通过耗材标签号定位已有耗材；
- 包含 3 个只读核对字段：板块、耗材说明、数量；
- 允许批量修改公司、City、Building、Floor、主资产标签号、耗材责任人、耗材状态、仓库、启用日期；
- 不通过 Excel 修改序列号、使用说明、备注；
- 不通过 Excel 修改用途；
- 不通过 Excel 修改板块、耗材说明、数量。

任何接口不得通过额外字段绕过以上范围。

### 3.11 修改事务与操作历史

每一次发生实际变化的耗材维护都必须生成一笔维护事务。

耗材卡片更新与维护事务属于同一次本地业务提交：

- 两者均成功才视为修改成功；
- 任一失败均不产生部分结果。

维护事务至少保存：

- 操作类型；
- 操作时间；
- 操作人；
- 修改后的耗材业务快照；
- 实际变化字段集合。

未发生实际变化：

- 不更新最后修改时间；
- 不生成维护事务。

### 3.12 并发与重复提交

单条编辑：

- 打开编辑时记录当前耗材版本；
- 保存前重新校验版本；
- 资产已被其他用户或业务修改时拒绝旧版本覆盖。

Excel 批量修改：

- 校验通过后、正式保存前重新读取所有耗材最新版本；
- 任一耗材发生并发变化，整批不保存。

重复提交：

- 同一次保存重复点击、超时重试、网络重放，只产生一次有效修改；
- 不重复生成维护事务；
- 不重复更新时间；
- 同一个 Excel 文件后续由用户再次主动上传，视为新的业务批次。

### 3.13 EBS 隔离

低值耐用品不进入普通资产 EBS 自动同步范围。

以下低值耐用品业务均不创建普通资产 EBS 自动同步任务：

- 入库；
- 耗材维护；
- 借用；
- 归还；
- 报废；
- 主资产联动。

耗材维护页面不提供手工 EBS 同步入口。

## 4. 页面字段及交互

### 4.1 查询条件

查询区分为基础查询条件和更多查询条件。

查询操作：

- 【查询】
- 【重置】
- 【更多条件 / 收起】

查询规则：

- 不同查询条件之间使用 AND。
- 同一多选条件中的多个值使用 OR。
- 未填写条件不参与过滤。
- 文本条件支持回车查询。
- 查询、分页、排序均受当前用户数据权限限制。
- 查询或重置后返回第 1 页，并清空当前页勾选。
- 支持清空的选择控件使用明确清除入口，不使用双击清空。

编辑态：

- 标题继续使用“耗材卡片信息：耗材标签号”；
- 不需要先勾选列表记录；
- 仅 3.3 节定义的 12 个字段切换为编辑控件；
- 其他字段保持只读；
- 正式报废状态使用只读文本展示；
- 公司、责任人、主资产等选择弹窗显示在当前编辑弹窗之上。

底部操作：

- 【保存】
- 【取消】

保存成功后：

- 停留当前编辑态；
- 使用最新保存结果刷新当前页面。

取消：

- 放弃未保存修改；
- 关闭编辑弹窗；
- 返回耗材列表。

### 4.5 Excel 批量修改

#### 4.5.1 入口与文件格式

列表顶部提供【批量修改】和【模板下载】。

【模板下载】直接下载当前正式模板。

点击【批量修改】打开“耗材批量修改”弹窗。

弹窗内同时提供：

- 【下载模板】
- Excel 上传
- 【取消】
- 【校验】/【保存】

列表顶部【模板下载】与弹窗内【下载模板】下载同一模板版本。

正式支持文件格式：

- .xls
- .xlsx

正式模板文件名：

耗材批量修改模板.xlsx

#### 4.5.2 模板字段

模板固定 13 列：

| 序号 | 字段 | 字段性质 | 是否必填 | 空白处理 |
|---:|---|---|---:|---|
| 1 | 耗材标签号 | 定位字段 | Y | 校验失败 |

#### 4.5.3 覆盖策略

规则：

1. 耗材标签号仅用于定位已有耗材。
2. 板块、耗材说明、数量仅用于核对，不写回。
3. 公司、City、Building、Floor、主资产标签号、耗材责任人、耗材状态、仓库、启用日期按模板值覆盖。
4. 必填字段为空时校验失败。
5. 非必填可编辑字段为空时清空原值。
6. 不使用额外“清空标识”。
7. 不存在“空白表示保留原值”的规则。

#### 4.5.4 上传与校验交互

上传文件后先执行模板和全部数据行校验，不直接保存。

校验结果表格固定展示：

| 字段 | 说明 |
|---|---|
| 行号 | Excel 数据行号 |
| 耗材标签号 | 当前行耗材标签号 |
| 字段 | 校验失败字段；整行错误可为空 |
| 校验结果 / 失败原因 | 具体失败原因 |

规则：

- 上传新文件后清空上一文件的校验结果。
- 校验失败时【保存】不可用。
- 多条错误一次展示全部已识别错误。
- 任一行失败时明确提示本次文件未保存。
- 全部行通过后显示“校验通过”。
- 校验通过后按钮切换为【保存】。
- 用户点击【保存】前不修改任何耗材数据。
- 正式保存成功后提示“修改成功！”。

## 5. 校验

### 5.1 单条保存

保存前校验：

- 当前用户具有该耗材编辑权限；
- 公司必填且有效；
- 责任人必填且有效；
- 责任人属于 MMP 管理范围；
- 非 SOHU 普通员工必须存在部门；
- City 必填且有效；
- Building 必填且属于当前 City；
- Floor 非空时必须为启用 Floor；
- 序列号满足 3.8 节规则；
- 耗材状态必填且有效；
- 正式报废状态不得通过耗材维护设置；
- 当前正式报废耗材状态不得改变；
- 主资产按 3.6 节规则校验；
- 仓库按 3.5 节规则校验；
- 启用日期按 3.9 节处理；
- 非开放字段不得被接口修改。

责任人姓名、部门、主资产说明等派生字段根据主数据重新取得，不直接信任页面提交文本。

### 5.2 单条保存提示

| 场景 | 页面反馈 |

| 责任人为空 | 责任人不能为空 |
| City 为空 | City不能为空 |
| Building 为空 | Building不能为空 |
| Building 与 City 不匹配 | 当前 Building 与 City 关系无效 |

### 5.3 Excel 模板校验

支持 .xls 和 .xlsx。

模板必须满足：

- 使用正式耗材批量修改模板；
- 表头与 4.5.2 完全一致；
- 列数一致；
- 列顺序一致；
- 不出现模板外业务列。

模板结构不一致时提示：

导入的EXCEL和系统要求的模板不一致，请核查

### 5.4 Excel 行级校验

每一行执行：

1. 耗材标签号必填、存在、文件内不重复。
2. 当前用户具有该耗材编辑权限。
3. 板块必填且必须与系统当前耗材板块一致。
4. 耗材说明必填且必须与系统当前耗材说明一致。
5. 数量必填且必须与系统当前耗材数量一致。
6. 公司必填且有效。
7. 责任人工号必填、存在且属于 MMP 管理范围。
8. 非 SOHU 普通责任人必须存在部门。
9. City 必填且有效。
10. Building 必填且属于当前 City。
11. Floor 非空时必须为启用 Floor。
12. 耗材状态必填且有效。
13. 不允许通过批量修改写入正式报废状态。
14. 当前耗材已经正式报废时，耗材状态只能填写当前原状态。
15. 主资产标签号非空时必须存在、未报废、不得等于当前耗材标签号，且责任人与模板责任人一致。
16. 仓库非空时必须满足 3.5 节有效仓库规则。
17. 启用日期非空时按 yyyy/MM/dd 读取并校验合法日期。
18. 板块、耗材说明、数量及其他非白名单字段不得通过接口写回。

### 5.5 Excel 整批校验

任一行失败：

- 整批不保存；
- 不生成部分耗材修改；
- 不生成部分维护事务。

全部行通过后，在用户点击【保存】前重新校验：

- 当前用户权限；
- 各耗材最新版本；
- 公司、责任人、主资产、仓库等依赖基础数据有效性。

任一耗材发生并发变化：

- 整批不保存；
- 提示用户重新上传或重新校验。

### 5.6 Excel 保存成功判定

只有以下结果全部成功，才能返回“修改成功！”：

1. 所有发生变化的耗材卡片更新成功；
2. 所有对应维护事务生成成功；
3. 整批本地业务提交成功。

实际保存或维护事务任一失败：

- 整批视为失败；
- 页面不得返回成功提示；
- 不允许出现页面显示成功但实际部分数据未提交。

### 5.7 查询与导出校验

购买日期、启用日期：

- 结束日期不得早于开始日期。

原值范围：

- 最小金额不得大于最大金额。

导出时：

- 当前查询结果和当前页勾选均为空时不生成文件；
- 提示“当前没有可导出的数据”；
- 导出前重新校验当前用户数据权限。

## 6. 后续操作 / 业务结果 / 补充说明

### 6.1 单条修改结果

单条保存成功后：

1. 更新 12 个开放字段中的实际变化项；
2. 根据最终责任人更新部门；
3. 根据最终主资产标签号更新主资产说明；
4. 根据最终公司、板块、责任人、成本中心、City 等数据完成财务归属计算；
5. 更新最后修改人、最后修改时间；
6. 生成一笔耗材维护事务；
7. 使用保存后的最新数据刷新当前编辑页。

没有实际变化时不更新最后修改时间，不生成维护事务。

### 6.2 批量修改结果

全部校验通过并点击【保存】后：

- 所有发生变化的耗材作为同一批本地业务提交；
- 每一条实际变化耗材分别生成维护事务；
- 未发生变化的行不更新时间、不生成维护事务；
- 保存成功后刷新耗材列表；
- 清空当前页勾选；
- 提示“修改成功！”。

批量处理结果至少记录：

- 上传人；
- 上传时间；
- 文件名；
- 上传总行数；
- 实际修改行数；
- 无变化行数；
- 处理结果。

### 6.3 耗材操作历史

单条或批量维护成功后，在“耗材操作历史”中形成可追溯记录。

历史记录按 4.6 节从新到旧展示，并对规定字段的变化使用浅黄色背景标识。

### 6.4 主资产联动

耗材与主资产建立关联后，主资产在正式业务流程中发生以下变化时，关联耗材根据对应业务结果同步更新：

- 责任人；
- 仓库；
- 耗材状态；
- City；
- Building；
- Floor；
- 部门；
- 成本中心。

主资产借用、归还、报废等业务是否触发上述字段变化，以对应业务流程最终结果为准；耗材维护页面不提供单独的主资产联动按钮。

### 6.5 EBS 结果

耗材维护成功：

- 不创建普通资产 EBS 自动同步任务；
- 不提供手工 EBS 同步操作；
- 本地耗材卡片和维护事务作为最终耗材维护结果保留。

### 6.6 导出结果

导出操作：

- 生成 4.7 节定义的 Excel 文件；
- 不修改耗材卡片；
- 不生成耗材操作历史；
- 不改变最后修改时间；
- 不触发 EBS 自动同步。

### 6.7 历史数据

旧系统迁移后的耗材维护历史与当前系统耗材维护历史统一进入“耗材操作历史”。

不单独设置旧系统历史页签。
