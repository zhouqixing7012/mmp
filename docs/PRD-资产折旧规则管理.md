## 一、模块概述

### 1.1 模块定位

"资产折旧规则管理"模块用于管理资产折旧的计算规则，配置不同物料大类和小类的折旧年限、计算方式等参数，是固定资产核算的基础。

### 1.2 包含页面

本模块只有1个页面：**资产折旧规则管理**

---

## 二、页面：资产折旧规则管理

### 2.1 页面功能

管理资产折旧的计算规则，定义不同物料大类、小类的折旧年限和计算方式。

### 2.3 页面特殊说明

本页面在搜索条件区域上方有一个**"计算"按钮**，位置在页面右上角，用于触发折旧计算。

### 2.4 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 物料大类 | 搜索选择框 | 点击搜索图标选择大类，如：OFFICE EQUIPMENT |
| 物料小类 | 搜索选择框 | 点击搜索图标选择小类，如：摄影摄像-单反机身 |
| 使用年限 | 下拉选择框 | 选项：全部、4年以上、4年以内 |

### 2.5 表格列

| 列名 | 说明 |
|------|------|
| 物料大类 | 大类名称，如：OFFICE EQUIPMENT |
| 物料小类 | 小类名称，如：摄影摄像-单反机身 |
| 原值要求 | 价格门槛，如：5000.0（元） |
| 计算关系 | >=、<=、= |
| 使用年限 | 折旧年限，如：4年以上 |
| 账面金额类型 | 净值/原值 |
| 操作 | 编辑按钮 |

### 2.6 工具栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增弹窗 |
| 编辑 | 灰色按钮 | 编辑选中的记录 |
| 删除 | 红色按钮 | 删除选中的记录 |
| 计算 | 灰色按钮 | 触发折旧计算（位于搜索区域上方） |

**计算按钮说明**：
- 位置：搜索条件区域的右上角
- 功能：根据配置的折旧规则，重新计算所有资产的折旧
- 流程：
  1. 点击"计算"按钮
  2. 系统显示"正在计算折旧，请稍候..."
  3. 后台执行折旧计算逻辑
  4. 计算完成后显示"折旧计算完成，共处理X条资产"

### 2.7 新增/编辑弹窗

#### 弹窗标题
- 新增时：标题为"新增折旧规则"
- 编辑时：标题为"编辑折旧规则"

#### 表单字段布局

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 物料大类*（搜索选择） | 物料小类（搜索选择） |
| 第2行 | 原值要求（数字输入） | 计算关系（下拉选择） |
| 第3行 | 使用年限（下拉选择） | 账面金额类型（下拉选择） |

#### 字段详细说明

**物料大类（必填）**：
- 控件类型：搜索选择框
- 交互：点击搜索图标，弹出物料大类选择弹窗
- 说明：折旧规则适用的物料大类

**物料小类（选填）**：
- 控件类型：搜索选择框
- 交互：点击搜索图标，弹出物料小类选择弹窗
- 说明：折旧规则适用的物料小类（如果不填，则适用于该大类下的所有小类）

**原值要求（选填）**：
- 控件类型：数字输入框
- 格式：支持小数，如：5000.0
- 说明：资产原值的门槛，只有原值满足条件的资产才适用此规则

**计算关系（选填）**：
- 控件类型：下拉选择框
- 选项：
  - >=（大于等于）
  - <=（小于等于）
  - =（等于）
- 说明：与原值要求配合使用

**使用年限（选填）**：
- 控件类型：下拉选择框
- 选项：
  - 4年以上
  - 4年以内
  - 不限
- 说明：资产的折旧年限分类

**账面金额类型（选填）**：
- 控件类型：下拉选择框
- 选项：
  - 净值
  - 原值
- 说明：折旧计算时使用的金额类型

#### 弹窗按钮

| 按钮 | 样式 | 功能 |
|------|------|------|
| 保存 | 蓝色主按钮 | 保存数据，关闭弹窗 |
| 返回 | 灰色按钮 | 取消操作，关闭弹窗 |

### 2.8 校验规则

| 字段 | 校验规则 | 错误提示 |
|------|----------|----------|
| 物料大类 | 必填 | "请选择物料大类" |
| 原值要求 | 如果填写，必须为正数 | "原值要求必须为正数" |
| 组合唯一性 | 物料大类+物料小类+原值要求不能重复 | "该组合已存在" |

## 三、通用交互说明

### 3.1 计算功能流程

1. **点击计算按钮**
   - 用户点击搜索区域上方的"计算"按钮

2. **显示计算进度**
   - 弹出提示："正在计算折旧，请稍候..."
   - 禁用"计算"按钮，防止重复点击

3. **执行计算**
   - 系统调用后端接口，根据配置的折旧规则计算所有资产的折旧
   - 计算逻辑：遍历所有资产，匹配适用的折旧规则，计算折旧金额

4. **显示计算结果**
   - 计算完成后，显示结果统计："折旧计算完成！"
   - 详细信息："共处理X条资产，计算折旧金额Y元"

5. **刷新数据**
   - 如果有资产信息页面，自动刷新显示最新的折旧数据
