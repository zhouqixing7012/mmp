## 员工资产信息查询

### 1. 页面概览

#### 1.1 功能定位

“员工资产信息查询”位于资产管理后台，用于资产管理人员以**员工维度**集中查询该员工当前关联的资产、耗材、合约号码及历史单据信息。

主要使用场景包括：

1. 查询员工当前名下资产。
2. 查询员工当前名下耗材。
3. 查询员工当前使用的合约号码。
4. 查询员工历史及当前处理中相关资产业务单据。
5. 员工离职、调动、资产核查等场景下，集中核对员工相关资产信息。

#### 1.2 页面整体结构

##### 1.2.1 页面入口

菜单：

**资产管理 → 员工资产信息查询**

进入后默认展示“资产”页签。

##### 1.2.2 页面组成

页面由两部分组成：

1. 顶部员工及业务条件查询区。
2. 下方四个信息页签。

##### 1.2.3 页签切换

切换页签时：

- 当前查询员工保持不变。
- 与当前页签仍适用的查询条件保持不变。
- 自动查询该员工对应页签的数据。
- 当前选中的页签高亮。
- 不需要重新选择员工。

### 2. 查询条件

#### 2.1 员工信息

“员工信息”为本功能核心查询条件。

点击人员选择按钮打开人员选择器。

人员选择器支持按照：

- 员工编号。
- 员工姓名。
- 部门。

查询员工。

选择后页面展示：

**员工编号 - 员工姓名**

员工选择为单选。

#### 2.2 标签号

标签号用于辅助查询。

按照标签号查询对应员工关联记录。

#### 2.3 合约号码

选择“合约号码”页签时，展示合约号码查询条件。

#### 2.4 单据编号

适用于“单据信息”页签。

按照申请单号或当前单据信息查询链路支持的单据编号查询。

#### 2.5 单据状态

适用于“单据信息”页签。

状态沿用现有业务状态，包含：

| **状态名称** |
| ------------------ |
| 已完成             |
| 处理中             |
| 已驳回             |

#### 2.6 查询条件适用范围

| **查询条件** | **资产** | **耗材** | **合约号码** | **单据信息** |
| ------------------ | -------------- | -------------- | ------------------ | ------------------ |
| 员工信息           | √              | √              | √                  | √                  |
| 资产标签号         | √              | √              |                    |                    |
| 合约号码           |                |                | √                  |                    |
| 单据编号           |                |                |                    | √                  |
| 单据状态           |                |                |                    | √                  |

切换页签后，只展示或启用当前页签适用的辅助查询条件。

### 3. 查询结果页签
#### 3.1 资产

##### 3.1.1 功能说明

“资产”用于查询当前员工名下由其承担资产责任的资产。

判断员工与资产的核心关系为：

**资产责任人 = 查询员工**

##### 3.1.2 数据范围

资产状态为：3、6

物资大类为：资产

##### 3.1.3 列表字段

资产页签展示：

| **字段** | **说明**                             |
| -------------- | ------------------------------------------ |
| 行号           | 当前结果序号                               |
| 资产标签号     | 资产唯一标签号，可点击打开对应资产卡片详情 |
| 资产说明       | 资产名称/说明                              |
| 资产状态       | 按资产状态字典展示                         |
| 资产责任人     | 当前资产责任人员工编号/信息                |
| 单据申请人     | 当前资产关联业务单据申请人                 |
| 所在单据编号   | 当前资产关联的业务单据                     |
| 单据类型       | 单据类型名称                               |
| 单据业务类型   | 当前单据业务类型                           |
| 单据状态       | 当前业务单据状态                           |
| 单据审批环节   | 当前所处业务环节                           |
| 单据审批人     | 当前处理人                                 |
| 公司           | 资产/责任人对应公司                        |
| 板块           | 对应板块                                   |

##### 3.1.4 资产详情

##### 3.1.5 单据查看

资产存在关联单据时：支持查看该资产当前关联的业务单据或流程信息。

#### 3.2 耗材

##### 3.2.1 功能说明

数据查询对象：

**员工当前责任的耗材**

##### 3.2.2 员工关联规则

查询员工耗材时，以：

**耗材当前责任人 = 查询员工**

作为核心条件。

##### 3.2.3 数据范围

仅展示当前系统中属于耗材类型、且当前责任人为所查询员工的耗材记录。

员工没有耗材时展示空结果。

| 公司           | 当前耗材对应公司                               |
| 板块           | 当前板块                                       |
| 资产大类       | 耗材所属大类                                   |
| 资产小类       | 耗材所属小类                                   |
| 资产说明       | 耗材名称/说明                                  |
| 品牌           | 品牌                                           |
| 主资产标签号   | 如耗材关联主资产则展示                         |
| 数量           | 当前记录数量                                   |
| 原值           | 原值                                           |

| 责任人编号     | 当前责任人员工编号                             |

#### 3.3 合约号码

##### 3.3.1 功能说明

查询员工当前持有哪些合约号码

##### 3.3.2 查询规则

以**合约号码当前责任人 = 查询员工**查询员工当前有效合约号码。

#### 3.4 单据信息

##### 3.4.1 功能说明

用于查询指定员工相关的资产业务单据。

##### 3.4.2 单据查询范围

| **类型**     | **说明**                                |
| ------------------ | --------------------------------------------- |
| 普通员工申请单     | 员工领用、退库、转移、借用、续领、换领等业务  |
| CAA/CAC 库存类单据 | 员工相关库存申请形成的业务单据                |
| CAA/CAC 采购类单据 | 员工相关采购申请形成的业务单据                |
| 独立入库单         | 没有前置申请单，但员工为对应退库/借用关联人员 |
| 独立出库单         | 没有前置申请单，但员工为对应责任人            |
| 资产转移单         | 没有前置申请单，但员工为责任人或申请人        |

##### 3.4.3 单据

根据不同业务单据关系查询，包括：

- `payPersonId`
- 责任人员工字段。
- 申请人员工字段。
- 入库/出库明细对应人员字段。

所有分支最终必须归属于当前所查询员工。

##### 3.4.4 当前已识别业务类型

现有详情页面已适配的主要业务包括：

| **业务** |
| -------------- |
| 更换           |
| 退库           |
| 员工转移       |
| 借用           |
| 统一申请相关   |
| 合约号码相关   |
| 新员工相关     |
| 出库           |
| 入库           |
| 资产转移       |

单据信息展示：

| **字段** | **说明**                                               |
| -------------- | ------------------------------------------------------------ |
| 行号           | 当前结果序号                                                 |
| 申请单号       | 员工发起或系统形成的申请业务单据存在申请单时展示，可点击跳转详情页 |
| 单据类型       | 按 APPLY_TYPE_ORDER 转换                                     |
| 业务类型       | 按 APPLY_BUSINESS_TYPE 转换                                  |
| 单据状态       | 当前单据状态                                                 |
| 申请人         | 单据申请人                                                   |
| 申请时间       | 单据创建/申请时间                                            |
| 核心单据       | 由申请业务进一步形成的实际出库、入库、资产转移等执行单据。存在核心单据时展示，可点击进入对应核心单据详情页 |
| 公司           | 员工/单据对应公司                                            |
| 板块           | 对应板块                                                     |
| 部门           | 对应部门                                                     |
| 操作           | 查看业务流程或相关信息                                       |

##### 3.4.6 排序

默认按照**单据创建时间倒序**展示。

### 4. 查询与页签联动

#### 4.1 查询员工后

选择员工并点击查询：当前选中页签加载该员工对应数据。

#### 4.2 切换页签

切换至其他页签后：使用当前已经选择的员工继续查询。无需再次点击人员选择。

#### 4.3 查询条件保留

切换页签时：

- 员工信息必须保留。
- 当前页签不适用的查询条件不参与查询。
- 返回原页签后，原查询条件可继续保留。

#### 4.4 重新选择员工

重新选择员工后：四个页签后续查询均切换为新员工。

### 5. 权限

只有拥有：**资产管理 → 员工资产信息查询**权限的后台用户可以访问。用户可查询的数据范围继续沿用资产管理后台现有数据权限。

### 6. 空数据与异常处理

#### 6.1 员工无资产

资产页签展示空结果：

**暂无资产信息。**

#### 6.2 员工无耗材

耗材页签展示：

**暂无耗材信息。**

#### 6.3 员工无合约号码

合约号码页签展示：

**暂无合约号码信息。**

#### 6.4 员工无单据

单据信息页签展示：

**暂无单据信息。**

#### 6.5 员工不存在

查询的员工已经离职或工号不存在时，提示：

**未查询到对应员工信息。**

#### 6.6 关联详情

切换新系统后，调整历史单据详情页保留旧系统地址
