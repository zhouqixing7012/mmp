# 资产盘点移动端现状 PRD

## 1. 文档范围

本文整理资产盘点移动端的现状需求。PC 端现状以 [资产盘点 PRD](../PRD-资产盘点.md) 为准；移动端原始资料保留在 [资产盘点移动端.docx](../source/资产盘点移动端.docx)。本文只整理移动端范围，不从新版 PRD 推导现状要求。

移动端用于现场执行盘点；PC 端负责盘点项目管理和盘点结果管理。

## 2. 进入方式与开放条件

移动端有以下入口：

1. 狐小 e 的资产管理入口。
2. 盘点待办入口。

盘点项目启动后开放对应的移动端盘点任务。移动端根据当前已启动项目中的任务进入工作台。

## 3. 盘点工作台

工作台展示未盘和已盘资产，并提供资产搜索和详情查看入口。资产列表以卡片形式展示，按盘点结果状态区分：

- 未盘
- 已盘
- 代盘
- 报失

资产完成盘点后，更新至对应的盘点结果状态，并在工作台相应区域展示。

## 4. 盘点执行方式

移动端提供扫码盘点和快速扫描两种执行方式。当前项目配置的盘点方式决定相应任务可使用的执行入口。

扫码盘点用于逐项读取资产标签并查看资产信息；快速扫描用于连续读取多个资产标签后提交盘点结果。

## 5. 资产详情

用户可从工作台打开资产详情，查看盘点所需的资产信息并进入盘点操作。字段明细以原始移动端资料为准；本文不补写原资料未明确的字段、状态变更细节或异常提示。

## 6. 照片

移动端支持上传盘点照片。照片类型、适用资产范围、必传要求和后续审核规则以原始移动端资料为准。
