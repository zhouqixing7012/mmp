## Excel原件定位

原Excel有两个工作表。分析表dimension为A1:N56，N列仅有格式；明细dimension为A1:BD12，实际表格只至S列，不能按dimension误加空业务列。

| 区块 | 原件范围 | 业务列及已确认调整 |
|---|---|---|
| 汇总 | B9:I13 | C为原资产管控方隐藏列；可见业务为B资产情况、D数量、E数量占比、F原值、G原值占比、H净值、I净值占比。已确认取消管控方，不恢复其值。 |
| 四年对比 | B17:L22 | C隐藏。可见10列，B年度；D/E/F总数量、总原值、总净值；G/H、I/J、K/L分别盘亏数量/占比、原值/占比、净值/占比。 |
| 分类盘亏 | B25:I39 | C隐藏。B分类、D年度、E数量、F原值、G净值、H:I备注合并，真正业务为6列。 |
| 分类增量 | B42:E55 | C隐藏。真正业务仅B大类、D细类、E汇总三列。不能按区域宽度把它扩成4个业务字段。 |
| 盘亏及待查明细 | A3:S12 | 原19列；S备注已确认取消，目标为A:R的18列。O责任人编号在原件隐藏，但目标有效字段仍保留，不能因原隐藏而删除。 |

PRD将以上区域作为基准定位，原C不恢复为业务字段；如保留原物理列定位则置空并隐藏。已确认删列优先。后续年度行、电话行或明细增加时，后面的区块整体顺延并保留空白行间隔，不截数据、不覆盖前表。
