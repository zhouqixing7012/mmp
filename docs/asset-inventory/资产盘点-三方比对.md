# 资产盘点三方比对

| 模块 | 原PRD | 当前原型 | 处理建议 |
|---|---|---|---|
| 盘点入口 | PC创建管理，移动端执行 | 当前已有PC资产盘点模块 | 待确认移动端实现范围 |
| 盘点项目列表 | 支持状态查询、进度查看、图片审核、关联项目聚合 | 当前原型已有项目页面 | 对照字段补齐 |
| 创建盘点项目 | 项目类型、期间、规则、范围筛选 | 待详细比对 | 待确认 |
| 快照 | 生成后形成固定盘点范围 | 待确认 | 保留快照冻结规则 |
| 移动端工作台 | 未盘、已盘、搜索、任务入口 | 当前无移动端页面 | 新增移动端原型 |
| 扫码盘点 | 普通扫码、快速扫描、提交校验 | 当前无移动端页面 | 新增扫描流程 |
| 图片上传 | 根据规则配置是否上传照片 | 待确认 | 纳入移动端详情页 |

## 待确认事项

1. 移动端是否完全按照现有狐小e流程还原。
2. PC端现有原型字段是否以新PRD为准调整。
3. 扫码、快速扫描是否都需要本次实现。
