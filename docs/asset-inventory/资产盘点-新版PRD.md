# 资产盘点 PRD

## 1. 背景

资产盘点用于在指定盘点期间，对企业资产进行范围确认、清单冻结、任务分配、现场盘点、结果审核和报告输出。

一次完整盘点包括：

`创建盘点项目 → 确定盘点范围 → 生成快照 → 生成盘点计划 → 启动盘点任务 → 现场盘点 → 图片审核/复盘审批 → 关闭项目 → 导出报告`

PC 端负责盘点项目和结果管理，移动端负责盘点执行。

## 2. 业务范围

### 2.1 项目类型

| 项目类型 | 业务含义 | 项目编号前缀 |
|---|---|---|
| 初盘 | 形成指定盘点期间的首次盘点结果 | CP |
| 抽盘 | 对初盘执行范围进行全量或比例抽查 | DCP |
| 复盘 | 对初盘执行范围进行复核并提交审批 | RCP |

抽盘项目必须关联一个已关闭且未被其他抽盘项目关联的初盘项目。复盘项目必须且只能关联一个已关闭且未被其他复盘项目关联的初盘项目。关联初盘项目的年度、季度或月份自动带入当前项目。复盘项目由财务人员发起，复盘项目的盘点执行人仅限财务人员。机房资产和非机房资产不得纳入同一个初盘项目；机房初盘与非机房初盘分别建立，后续抽盘或复盘只关联其中一个初盘项目，并按该初盘的资产范围确定审批流程。

### 2.2 盘点范围

| 盘点范围 | 资产范围规则 |
|---|---|
| 库房 | 资产责任人名称包含“库房管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 公共 | 资产责任人名称包含“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 机房 | 资产大类属于服务器、网络设备；电话指定小类除外 |

手动创建的盘点项目不能选择机房资产。年度机房初盘由系统独立创建，不得与非机房资产合并。
| 员工 | 资产责任人名称不包含“库房管理员”“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |

### 2.3 盘点方式

盘点项目按盘点范围分别配置盘点方式：

1. 狐小e扫码。
2. 狐小e快速扫描资产标签号。
3. 扫码枪扫码。
4. 人工上传盘点结果。

每个盘点范围至少选择一种盘点方式。未选择时，保存和提交均提示具体盘点范围未配置盘点方式。

## 3. 角色与权限

权限按财务公司和板块控制。

| 角色 | 可执行操作 |
|---|---|
| 盘点负责人 | 创建、编辑、查看盘点项目；维护范围；生成快照和计划；导入、审核、调整盘点结果；查看进度和报告 |
| 计划负责人 | 维护盘点计划信息，协调计划启动和执行 |
| 盘点监督人 | 查看对应计划进度，接收催盘和异常通知 |
| 盘点执行人 | 执行分配给自己的移动端、扫码枪或人工导入盘点任务 |
| 财务人员 | 接收初盘项目关闭通知；发起复盘项目；执行复盘计划 |
| 图片审核人 | 审核需要上传照片的盘点结果 |
| 复盘审批人 | 审核复盘项目结果 |

已启动的盘点计划只向对应的执行人、监督人和项目负责人开放。没有有效盘点任务的用户不能进入移动端盘点。

## 4. 业务对象

| 对象 | 说明 |
|---|---|
| 盘点项目 | 盘点业务的主对象，定义期间、类型、范围和规则 |
| 盘点范围明细 | 根据项目规则筛选出的资产范围，快照前可以调整 |
| 快照 | 固定项目盘点范围和生成时资产信息的结果 |
| 盘点计划 | 将执行盘点资产分配给具体人员和时间的任务对象 |
| 计划资产清单 | 计划下的资产及其盘点状态、盘点人、盘点日期和盘点备注 |
| 图片审核 | 对需要上传照片的盘点资产进行审核的对象 |
| 项目进度 | 按范围和组织汇总盘点结果的查询视图 |
| 盘点报告 | 按财务公司、板块和资产分类输出盘点结果 |

资产标签号是盘点项目、快照、计划、移动端结果和图片审核记录之间的关联标识。

## 5. 状态规则

### 5.1 盘点项目状态

| 状态 | 业务含义 | 可执行操作 |
|---|---|---|
| 草稿 | 项目尚未生成固定快照 | 编辑、保存、删除 |
| 快照生成 | 项目范围已经冻结 | 查看清单、调整清单、生成计划 |
| 生成盘点计划 | 项目已进入计划配置阶段 | 编辑、补充、启动计划 |
| 盘点中 | 至少一个计划已经启动 | 执行盘点、查看进度、图片审核 |
| 盘点关闭 | 盘点结果已经结束 | 查看历史、导出报告 |

### 5.2 盘点计划状态

| 状态 | 业务含义 |
|---|---|
| 草稿 | 计划日期和人员可以维护，尚未开放任务 |
| 启动 | 任务已开放，计划和资产清单的分配信息不可修改 |
| 审核中 | 复盘计划已提交审批 |
| 已审核 | 复盘计划审批通过 |
| 已驳回 | 复盘计划审批不通过，允许重新处理 |
| 关闭 | 项目关闭时同步关闭关联计划 |

### 5.3 资产盘点状态

| 状态 | 业务含义 |
|---|---|
| 未盘 | 尚未产生有效盘点结果 |
| 已盘 | 当前资产责任人完成盘点 |
| 代盘 | 非当前资产责任人完成盘点 |
| 报失 | 用户提交报失并完成二次确认 |
| 盘亏 | 后台或财务结果确认资产盘亏 |

“未执行盘点”表示该资产未纳入本次现场执行范围，不属于盘点结果状态。

## 6. PC 端盘点项目

### 6.1 项目列表

#### 查询条件

| 字段 | 查询规则 |
|---|---|
| 项目编号 | 包含匹配 |
| 项目名称 | 包含匹配 |
| 项目状态 | 按状态筛选 |
| 项目负责人 | 按人员筛选 |
| 盘点开始时间 | 按日期范围筛选 |
| 盘点结束时间 | 按日期范围筛选 |
| 项目类型 | 初盘 / 抽盘 / 复盘 |
| 创建时间 | 按日期范围筛选 |

#### 列表字段

项目编号、项目名称、项目类型、项目状态、项目负责人、盘点开始时间、盘点结束时间、执行盘点数量、资产总量、创建时间。

存在关联关系的初盘、抽盘和复盘项目按同一业务链路分组展示。

项目状态为草稿时提供删除入口。符合关闭条件的项目可在项目列表或项目详情内关闭；机房初盘项目由系统自动关闭，不提供手动关闭操作。项目已生成计划后提供“进入计划”；项目已启动后提供“查看进度”；存在图片审核记录时提供“图片审核”。

### 6.2 创建和编辑项目

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 项目编号 | 只读文本 | 是 | 系统自动生成 |
| 项目名称 | 输入框 | 是 | 默认“期间-盘点类型”，允许修改 |
| 项目类型 | 单选 | 是 | 初盘 / 抽盘 / 复盘 |
| 盘点开始时间 | 日期选择 | 是 | 盘点开始日期 |
| 盘点结束时间 | 日期选择 | 是 | 必须晚于开始时间 |
| 盘点类型 | 单选 | 是 | 年度 / 季度 / 月度 |
| 盘点期间 | 联动选择 | 是 | 年度选年份，季度选年份和季度，月度选年份和月份 |
| 初盘项目 | 项目选择 | 抽盘/复盘必填 | 只能选择符合关联条件的初盘项目 |
| 抽样方式 | 单选 | 抽盘/复盘必填 | 全盘 / 百分比 |
| 比例 | 数字输入 | 条件必填 | 抽样方式为百分比时显示，范围0～100 |
| 盘点说明 | 多行输入 | 否 | 最多150字 |
| 快照生成日期 | 只读文本 | 否 | 每次生成快照时自动更新 |

复盘项目仅允许财务人员创建。手动创建的初盘、抽盘和复盘项目均不得选择机房资产；机房初盘只能由系统按年度规则创建。

项目编号格式：

- 初盘：`CP-年月日-四位流水号`。
- 抽盘：`DCP-年月日-四位流水号`。
- 复盘：`RCP-年月日-四位流水号`。

### 6.3 盘点规则

#### 规则字段

盘点公司、City、Building、资产类别、盘点范围和盘点方式。

盘点公司可按子公司或资产公司选择，具体选择维度以公司与账套映射关系为准。

#### 图片上传规则

项目提供“是否上传图片”开关。开启后，按盘点范围配置图片规则。

图片规则字段：资产责任人职级、部门、资产类别、资产状态、盘点组织、City、Building、Floor、上传百分比。

1. 默认生成员工、库房、公共、机房四条规则。
2. 每条规则可以新增或删除。
3. 上传百分比为100%时，符合条件的资产全部要求上传。
4. 上传百分比小于100%时，在符合条件的资产中按比例随机抽取。

### 6.4 盘点范围明细

保存项目后生成盘点范围明细。

初盘项目按照盘点组织、资产状态、City、Building、资产类别和盘点范围筛选资产。手动创建的初盘只纳入非机房资产。系统每年7月1日自动创建并启动一个年度机房初盘项目，范围仅包含符合机房规则的资产，不设置盘点监督人；该项目在数量进度达到100%时自动关闭。机房初盘与非机房初盘分别建项。

抽盘、复盘以关联初盘项目生成快照时的执行盘点资产清单作为基础范围。

范围筛选条件：盘点组织、部门、资产类别、资产状态、仓库、板块、City、Building、Floor、责任人职级、启用开始日期、启用结束日期。

点击“生成查询”后，根据当前条件生成一条范围汇总记录。用户可以多次查询并将结果加入盘点范围明细，也可以查看全部或删除全部。

盘点范围明细展示公司、部门、资产类别、资产标签号、序列号、资产说明、数量、原值、使用状态、资产责任人、责任人部门、责任人职级、City、Building、Floor、盘点组织、成本中心和启用日期。

### 6.5 生成快照

点击“生成快照”后：

1. 将盘点范围明细中的资产汇总为项目快照。
2. 根据物料的“是否需盘点”属性拆分执行盘点和未执行盘点资产。
3. 将项目规则过滤结果与执行/未执行清单按资产标签号比对，差异放入未包含资产清单。
4. 根据图片上传规则标记“是否需上传图片”。
5. 更新项目快照生成日期和项目状态。

快照生成后，资产范围和快照时的资产基础信息保持不变。盘点状态、盘点人、盘点日期、盘点备注和照片属于后续盘点结果，可以继续更新。

快照页面包含四个页签：

1. 快照清单统计。
2. 执行盘点资产清单。
3. 未执行盘点资产清单。
4. 未包含资产清单。

四个页签均支持条件查询和导出。

### 6.6 快照清单操作

| 清单 | 启动前 | 启动后 |
|---|---|---|
| 执行盘点资产清单 | 批量、按查询条件或导入转移至未执行；导出；同步NO扫描数据 | 导入盘点结果；导出 |
| 未执行盘点资产清单 | 批量、按查询条件或导入转移至执行；导出 | 批量确认；导入盘点结果；导出 |
| 未包含资产清单 | 批量、按查询条件或导入转移至执行或未执行；导出 | 按项目状态限制操作 |

转移和导入必须校验资产是否属于当前清单。NO 扫描按序列号匹配；匹配不到的记录不得导入；标签号、序列号、型号、品牌、City、Building、Floor不一致时展示差异。

## 7. PC 端盘点计划

### 7.1 生成计划

点击“生成盘点计划”后，用户选择默认生成或自定义生成。

默认生成按照同一子公司、一级部门、City和盘点范围拆分计划。每个盘点范围单独形成计划明细。

自定义生成支持按公司、部门、资产类别、资产责任人、启用日期和盘点范围筛选执行盘点资产，并按员工、库房、公共、机房配置计划负责人、监督人和执行人。盘点监督人非必填；机房初盘不设置盘点监督人。

### 7.2 计划字段

| 字段 | 规则 |
|---|---|
| 计划编号 | 按项目类型和日期自动生成 |
| 计划名称 | 默认按 City 生成，允许修改 |
| 盘点组织 | 根据资产组织与盘点组织映射关系带出 |
| City | 根据计划资产清单带出 |
| 盘点范围 | 员工 / 库房 / 公共 / 机房 |
| 资产总量 | 当前计划资产数量合计 |
| 未盘数量 | 未盘、报失、盘亏资产数量合计 |
| 已盘数量 | 已盘、代盘资产数量合计 |
| 盘点开始日期 | 草稿状态可编辑 |
| 盘点结束日期 | 草稿状态可编辑 |
| 计划负责人 | 草稿状态可编辑 |
| 盘点监督人 | 非必填；草稿状态可编辑；机房初盘不设置 |
| 盘点执行人 | 草稿状态可编辑 |

### 7.3 人员带出规则

| 盘点范围 | 盘点监督人 | 盘点执行人 |
|---|---|---|
| 员工 | 与资产责任人一级部门相同的部门助理 | 资产责任人 |
| 库房 | 资产所在位置的库管员 | 资产所在位置的库管员 |
| 公共 | 资产所在位置的库管员 | 资产所在位置的库管员 |
| 机房初盘 | 不设置 | 资产责任人或手工配置 |

生成计划后允许手工修改监督人和执行人。修改计划人员后，同步更新当前计划下的资产清单人员。

复盘项目的盘点执行人仅可从财务人员中选择；保存和启动计划时均校验执行人身份。

### 7.4 启动计划

启动前校验：

1. 所有执行盘点资产都已经进入盘点计划。
2. 计划开始日期、结束日期、计划负责人和盘点执行人已经填写；盘点监督人非必填，机房初盘不设置盘点监督人。
3. 结束日期晚于开始日期。

校验通过后，关联计划状态更新为启动，项目状态更新为盘点中。计划和资产清单的分配信息锁定，并向狐小e、Myfamily和资产系统发送盘点任务通知。

## 8. 移动端盘点

### 8.1 进入条件

移动端提供两条入口：

1. 狐小e → 资产管理 → 盘点。
2. 盘点待办通知。

用户是盘点执行人、盘点监督人或项目负责人，且存在已启动未完成计划时，才允许进入盘点工作台。没有任务时，盘点入口置灰或不可进入。

项目启动时向已配置的执行人和监督人发送通知；机房初盘未设置监督人时，只向执行人发送通知。同一项目下有多个计划时，每个项目按最早启动计划的时间发送一条通知；只要仍有已启动且未完成的计划，通知保持待办。所有已启动计划完成后，通知转为已办。所有计划完成后，如新增计划且执行人和监督人均与上一轮相同，则按新计划启动时间重新发送通知。

关闭初盘、抽盘或复盘项目时，关闭该项目下所有执行人的移动端待办，并停止扫码、快速扫描和提交。关闭允许存在未盘资产或待提交结果；已提交结果保留，待提交结果不计入盘点结果，也不转给财务补录。项目关闭后，项目及关联计划、资产清单、盘点结果和审核记录均只读，不允许修改或补交。

### 8.2 盘点工作台

| 区域 | 展示和交互 |
|---|---|
| 项目信息 | 项目名称、盘点期间、当前用户待盘数量 |
| 未盘页签 | 未盘、报失资产；展示数量和资产卡片 |
| 已盘页签 | 已盘、代盘、未执行盘点资产；展示数量和盘点结果 |
| 搜索 | 按资产说明、资产标签号、序列号模糊查询，查询后同步更新数量 |
| 任务入口 | 监督人查看按员工、公共、库房、机房分组的任务清单 |
| 返回 | 从工作台返回 PC 端盘点项目列表；资产详情、扫码和快速扫描页面内的返回按移动端页面层级返回上一页 |
| 退出 | 返回资产管理首页 |

资产完成对应计划后，从未盘列表移出。移动端只展示当前用户有权限访问的计划资产。

### 8.3 任务清单

任务按员工、公共、库房、机房分组展示。

1. 员工任务标题显示盘点项目名称。
2. 公共和库房任务可以合并展示，但必须保留资产范围信息。
3. 机房任务显示快速扫描入口，是否显示取决于计划配置。
4. 监督人可以查看任务下的资产数量和完成情况。

## 9. 移动端资产详情

### 9.1 详情字段

| 字段 | 规则 |
|---|---|
| 资产标签号 | 只读 |
| 序列号 | 只读 |
| 数量 | 只读 |
| 使用状态 | 只读 |

| 责任人 | 只读 |
| City | 只读；公共资产是否可编辑待确定 |
| Building | 只读；公共资产是否可编辑待确定 |
| Floor | 只读；公共资产是否可编辑待确定 |
| 盘点人 | 盘点完成后展示 |
| 盘点日期 | 盘点完成后展示 |
| 盘点备注 | 有值时展示 |

### 9.2 操作

未盘资产提供“盘点”和“报失”。已盘、代盘资产不提供报失入口。

报失原因必填，提交前进行二次确认。确认后更新资产状态、盘点人、盘点日期和盘点备注，并通知资产责任人和对应监督人。

## 10. 普通扫码盘点

1. 用户打开摄像头扫描资产标签号二维码。
2. 系统校验当前用户是否有对应任务。
3. 系统校验资产是否属于当前计划范围。
4. 系统校验资产是否已经被其他人盘点。
5. 校验通过后展示资产信息，并根据图片规则进入拍照或提交结果。
6. 当前责任人盘点成功，状态更新为已盘；非当前责任人盘点成功，状态更新为代盘。
7. 盘点人、盘点日期和盘点备注同步写入计划资产清单和项目资产清单。

扫码异常包括：已被扫描、已被他人盘点、资产不在范围、无效二维码、非资产二维码和网络失败。异常时允许返回扫码或退出，不更新盘点结果。

## 11. 快速扫描盘点

快速扫描只记录资产标签号，提交时统一校验：

1. 标签号是否属于当前计划。
2. 标签号是否重复扫描。
3. 资产是否已经盘点。
4. 标签号是否有效。

提交结果展示扫描总数、成功数和失败数。成功记录更新盘点状态、盘点人和盘点日期，失败记录展示失败原因。

快速扫描只在当前计划配置了快速扫描方式时开放。

## 12. 照片上传与审核

### 12.1 移动端拍照

只有图片规则标记“是否需上传图片”的资产进入拍照环节。移动端只允许拍照，不允许从相册选择。

| 资产范围 | 必传照片 |
|---|---|
| 非机房 | 资产整体照片、二维码标签照片 |
| 机房 | 二维码标签照片、实物序列号照片 |

照片提交成功后，盘点结果和照片一起保存。

### 12.2 PC 端图片审核

计划启动时，为需要上传照片的执行盘点资产生成图片审核记录。

图片审核列表展示图片、资产标签号、实际盘点人、盘点日期、盘点状态和盘点备注，按待审核、审核不通过、审核通过排序。

审核操作：

1. 审核通过：更新审核状态并锁定记录。
2. 审核不通过：更新审核状态，资产恢复为未盘，重新向执行人发送任务。
3. 图片支持放大、缩小和旋转。

## 13. 项目进度

项目进度按盘点范围、盘点组织、盘点执行人一级部门和 City 汇总。

| 指标 | 计算规则 |
|---|---|
| 应盘数量 | 执行盘点资产数量合计 |
| 已盘数量 | 已盘、代盘资产数量合计 |
| 报失数量 | 报失资产数量合计 |
| 未盘数量 | 应盘数量 - 已盘数量 - 报失数量 |
| 数量进度 | 已盘数量 / 应盘数量 |
| 剩余时间 | 当前日期与盘点结束日期的差值 |

支持查看盘点全量资产、查看未盘资产、发送催盘通知和导出进度数据。

## 14. 复盘审批

复盘计划启动后显示“提交审批”。提交审批前校验计划状态为启动。系统计算已盘数量与复盘资产总量的比例；未达到设定比例时提示用户，但允许继续提交。

审批按复盘计划包含的资产范围路由：

| 复盘资产范围 | 审批顺序 |
|---|---|
| 非机房资产 | ES 主管 → 财务主管 |
| 机房资产 | NO 领导 → 财务主管 |
财务主管审批适用于机房和非机房复盘计划。机房资产和非机房资产不得出现在同一个初盘项目中；复盘项目必须关联唯一初盘项目，因此审批流按该初盘的资产范围选择一条路径。前一审批节点通过后流转至下一节点；任一节点驳回，复盘审批单更新为已驳回，关联复盘计划回到启动状态，并通知盘点负责人重新处理。

全部审批通过后：

1. 复盘审批单更新为已审核。
2. 关联复盘计划更新为已审核。
3. 通知盘点负责人。

## 15. 项目关闭

项目列表和项目详情均提供“关闭项目”操作。除机房初盘外，初盘、抽盘和复盘项目由用户手动关闭；机房初盘由系统在盘点进度达到100%时自动关闭。

手动关闭初盘或抽盘项目时，系统校验：

1. 关联计划不存在未启动计划。
2. 图片审核记录不存在待审核或审核不通过记录。

关闭初盘或抽盘不要求后续复盘计划先完成审批。手动关闭复盘项目时，系统还需校验关联复盘计划已完成审批。已启动计划可以存在未盘资产或待提交结果；这些情况不阻止关闭。

关闭后，项目状态更新为盘点关闭，关联计划同步关闭，移动端执行人待办结束，所有资产停止盘点。已提交结果保留；待提交结果不计入盘点结果，也不转给财务补录。项目、计划、资产清单、盘点结果和审核记录均转为只读，不能修改、补录或重新提交。关闭校验通过后弹出确认信息，展示未盘数量和待提交数量。

初盘关闭后，无论是手动关闭还是机房初盘自动关闭，系统均通过服务号通知财务人员，并提示是否创建抽盘项目；确认后自动带入该初盘项目。财务人员可根据已关闭初盘发起复盘。抽盘关闭后，可以提示财务人员发起复盘；确认后自动带入其关联初盘项目。

关闭项目后，资产卡片的盘点历史展示该项目已关闭计划中的盘点记录。

## 16. 盘点报告

### 16.1 财务盘点报告

财务报告包含三个页签：

1. 盘点报告汇总。
2. 盘亏资产明细。
3. 待盘资产明细。

导出前选择一个财务公司和一个或多个板块。报告按照资产分类映射汇总原值、数量、已盘、报失和未盘差异。原值保留两位小数。

### 16.2 其他报告

ES 业务盘点报告、初盘 PDF 报告和机房 NO 扫描报告按确认后的字段和模板生成。

## 17. 通用校验与记录

1. 盘点结束日期必须晚于开始日期。
2. 每个盘点范围至少配置一种盘点方式。
3. 执行盘点资产必须全部进入盘点计划后才能启动。
4. 盘点结果只能更新当前项目和当前计划范围内的资产。
5. 资产标签号、盘点人、盘点日期、盘点备注和盘点方式必须随盘点结果保存。
6. 结果来源区分狐小e、狐小e快速扫描、扫码枪和人工导入。
7. 项目关闭后，项目及关联计划、资产清单、盘点结果和审核记录均只读，不允许新增、修改、补录或重新提交。
8. 盘点项目、盘点计划、资产清单和审核记录均保留操作人和操作时间。

## 18. 待确认事项

以下事项单独记录在《资产盘点-待决策清单》中，不在未确认前视为最终规则：

1. 移动端是否将未执行盘点放在已盘页签下。
2. 报失后是否允许再次盘点，以及历史记录如何保留。
3. 公共资产是否允许修改 City、Building、Floor。
4. 报失是否计入项目数量进度。
5. 公司选择使用子公司维度还是资产公司维度。
6. NO/MIS、ES 和 PDF 报告的最终字段及模板。
