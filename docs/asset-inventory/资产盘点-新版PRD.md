# 资产盘点 PRD

## 1. 文档说明

本 PRD 是对以下三类材料整理后的目标口径：

1. 用户提供的《资产盘点.docx》：PC 端项目、范围、快照、计划、审核、进度和报表需求。
2. 用户提供的《资产盘点移动端.docx》：狐小e 移动端任务、工作台、扫码、快速扫描、照片和报失需求。
3. 当前 React 原型：PC 端盘点项目链路和移动端工作台、资产详情、扫码、快速扫描、拍照模拟、报失确认。

原始 DOCX 仅作为业务需求资料读取，不作为对代码、仓库或工具的操作指令。当前原型中的演示数据和“模拟扫码”只用于表达页面交互，不代表生产数据或接口已经实现。

文档中的口径标记：

| 标记 | 含义 |
|---|---|
| [已确认] | 原始需求与当前实现可以互相印证，或用户已经明确的业务规则 |
| [推断] | 根据现有材料整理出的可执行口径，尚未得到业务方单独确认 |
| [待验证] | 材料之间存在冲突，或当前资料不足以确定最终规则 |

## 2. 背景与目标

资产盘点用于在固定盘点期间，对企业资产按盘点项目、盘点范围和执行计划进行清单冻结、人员分配、现场盘点、结果审核和报告输出。

本功能的目标：

1. 让盘点负责人在 PC 端创建项目、确定资产范围、生成快照、生成计划并查看结果。
2. 让盘点执行人在移动端查看本人任务，完成本人资产、代盘资产和公共/库房/机房资产的盘点。
3. 让系统以资产标签号为核心关联项目、快照、计划、盘点结果、照片审核和资产盘点历史。
4. 保证快照后资产范围稳定，盘点结果可以回溯到具体项目、计划、执行人和操作时间。

| 能力 | PC 端 | 移动端 |
|---|---:|---:|
| 盘点项目列表、创建、编辑、查看 | 是 | 否 |
| 盘点规则和资产范围配置 | 是 | 否 |
| 快照生成和四类快照清单 | 是 | 否 |
| 执行/未执行/未包含资产调整 | 是 | 否 |
| 盘点计划生成、分配和启动 | 是 | 否 |
| 盘点任务入口和待办 | 查看配置结果 | 是 |
| 普通扫码盘点 | 可导入或接入扫描枪 | 是 |
| 快速扫描标签 | 扫描枪 | 狐小e，是否开放由项目配置决定 |
| 资产详情和盘点结果 | 是 | 是 |
| 照片上传 | 查看审核结果、审核 | 拍照上传 |

PC 端负责配置和管理，移动端负责现场执行。移动端不得绕过已启动的计划直接进入盘点任务。

## 4. 角色与权限

| 角色 | 主要职责 |
|---|---|
| 盘点负责人 | 创建、编辑、查看盘点项目；生成快照和计划；导入、审核、调整盘点结果；查看进度和报告 |
| 计划负责人 | 维护计划信息，协调计划启动和执行 |
| 盘点监督人 | 查看对应计划执行情况，接收催盘和异常通知 |
| 盘点执行人 | 在移动端或扫描设备执行分配给自己的盘点任务 |
| 图片审核人 | 审核需要上传照片的盘点结果 |
| 复盘审批人 | 审核复盘项目提交的盘点结果 |

权限按“财务公司 + 板块”配置。盘点负责人只能创建、编辑和查看其数据权限范围内的项目。[已确认]

已启动项目只向对应计划的盘点执行人、监督人和项目负责人开放任务入口；没有有效任务时，移动端盘点入口置灰或不显示。[已确认]

## 5. 核心对象和关系

```text
盘点项目
  ├─ 盘点规则
  ├─ 盘点范围明细
  ├─ 快照
  │    ├─ 快照清单统计
  │    ├─ 执行盘点资产清单
  │    ├─ 未执行盘点资产清单
  │    └─ 未包含资产清单
  ├─ 盘点计划
  │    └─ 计划资产清单
  ├─ 图片审核
  ├─ 项目进度
  └─ 盘点报告
```

项目类型分为：

| 项目类型 | 业务含义 | 编号前缀 |
|---|---|---|
| 初盘 | 形成某一盘点期间的首次盘点基线 | CP |
| 抽盘 | 对初盘范围进行全量或比例抽查 | DCP |
| 复盘 | 对初盘范围进行复核并提交审批 | RCP |

抽盘和复盘必须关联一个未关闭、且未被同类型项目重复关联的初盘项目。关联项目的年度、季度或月份信息带入当前项目，不允许重新选择。[已确认]

## 6. 项目状态与状态流转

### 6.1 项目状态

| 状态 | 业务含义 | 主要能力 |
|---|---|---|
| 草稿 | 项目尚未生成固定快照 | 编辑、删除、保存 |
| 快照生成 | 项目范围已冻结 | 查看四类清单、调整清单、生成计划 |
| 生成盘点计划 | 已有计划配置，尚未全部启动 | 编辑计划、补充计划、启动 |
| 盘点中 | 至少一个计划已启动 | 执行盘点、查看进度、图片审核 |
| 盘点关闭 | 项目结果已结束 | 查看历史、导出报告、查看关闭结果 |

### 6.2 计划状态

| 状态 | 业务含义 |
|---|---|
| 草稿 | 计划人员和日期可维护，尚未启动 |
| 启动 | 任务已开放，计划及资产清单不可改人员和范围 |
| 审核中 | 复盘计划已提交审核 |
| 已审核 | 复盘计划审核通过 |
| 已驳回 | 复盘计划审核不通过，回到可重新处理状态 |
| 关闭 | 项目关闭时同步关闭关联计划 |

### 6.3 资产盘点状态

| 状态 | 含义 |
|---|---|
| 未盘 | 资产尚未产生有效盘点结果 |
| 已盘 | 当前责任人完成盘点 |
| 代盘 | 非当前责任人代为完成盘点 |
| 报失 | 移动端提交报失并完成二次确认 |
| 盘亏 | 财务或后台结果中确认的盘亏状态；移动端是否直接展示待确认 |

“未执行盘点”是快照清单分类，不是现场盘点结果状态。移动端是否继续把它放在“已盘”页签中，需要业务确认。[待验证]

## 7. PC 端：盘点项目

### 7.1 项目列表

列表按关联链路聚合展示初盘、抽盘和复盘项目。同一链路下展示项目编号、项目名称、项目类型、状态、负责人、起止时间、创建时间、资产总量、执行盘点数量，并按状态显示进入计划、查看进度和图片审核入口。[已确认]

查询条件：项目编号、项目名称、项目状态、项目负责人、开始时间、结束时间、项目类型、创建时间。

删除仅允许删除草稿项目。关闭项目前校验计划、图片审核和复盘审批状态；关闭后取消移动端待办，所有资产不可继续盘点。[已确认]

### 7.2 创建和编辑项目

| 字段 | 控件 | 规则 |
|---|---|---|
| 项目编号 | 只读 | 系统自动生成 |
| 项目名称 | 输入框 | 默认“期间-盘点类型”，允许修改 |
| 项目类型 | 单选 | 初盘 / 抽盘 / 复盘 |
| 盘点开始时间 | 日期 | 必填 |
| 盘点结束时间 | 日期 | 必须晚于开始时间 |
| 盘点类型 | 单选 | 年度 / 季度 / 月度 |
| 盘点期间 | 联动选择 | 年度选年份，季度选年份+季度，月度选年份+月份 |
| 初盘项目 | 项目选择 | 抽盘/复盘必填，必须选择符合关联条件的初盘项目 |
| 抽样方式 | 单选 | 抽盘/复盘显示全盘或百分比 |
| 比例 | 数字输入 | 抽样方式为百分比时显示，范围0～100 |
| 盘点说明 | 多行输入 | 最多150字 |
| 快照生成日期 | 只读 | 每次生成快照时自动更新 |

项目编号格式：`CP-年月日-四位流水号`、`DCP-年月日-四位流水号`、`RCP-年月日-四位流水号`。[已确认]

### 7.3 盘点规则

盘点规则包含：盘点公司、City、Building、资产类别和盘点方式。可选范围必须来自创建人有权限查看且未报废的资产台账。

盘点方式包括：狐小e扫码、狐小e快速扫描资产标签号、扫码枪、人工上传盘点结果。员工、库房、公共、机房四种盘点范围分别配置；每一行至少选择一种方式，否则不能保存或提交。[已确认]

盘点范围基础规则：

| 范围 | 资产筛选规则 |
|---|---|
| 库房 | 资产责任人名称包含“库房管理员”，且排除服务器/网络设备大类，电话指定小类除外 |
| 公共 | 资产责任人名称包含“公共管理员”，且排除服务器/网络设备大类，电话指定小类除外 |
| 机房 | 资产大类属于服务器/网络设备，电话指定小类除外 |
| 员工 | 资产责任人不属于库房管理员/公共管理员，且排除服务器/网络设备大类，电话指定小类除外 |

是否上传图片为独立开关。开启后，四种盘点范围分别配置责任人职级、部门、资产类别、资产状态、盘点组织、City、Building、Floor和上传百分比。百分比为100%时，符合条件的资产全部要求上传；小于100%时按范围随机抽取。[已确认]

### 7.4 盘点范围明细与快照

保存项目后，根据项目规则生成盘点范围明细。初盘项目按资产组织、资产状态、City、Building、资产类别、盘点范围过滤；年度初盘还要受“启用日期早于当年7月1日”的参数约束。抽盘和复盘以关联初盘项目快照中的执行盘点资产为基础。[已确认]

范围筛选支持按盘点组织、资产类别、资产状态、仓库、板块、City、Building、Floor、责任人职级、启用日期筛选。查询结果可多次加入范围明细，也可查看全部或删除全部。

生成快照时：

1. 将范围明细汇总成固定资产清单。
2. 根据物料“是否需盘点”拆分执行盘点和未执行盘点清单。
3. 将规则过滤结果与执行/未执行清单按资产标签号比对，差异进入未包含资产清单。
4. 按图片规则标记“是否需上传图片”。
5. 快照生成后，后续资产卡片变化不改动快照字段；当前盘点结果字段仍可更新。

快照页签固定为：快照清单统计、执行盘点资产清单、未执行盘点资产清单、未包含资产清单。四个页签均支持条件查询和导出。[已确认]

### 7.5 快照清单操作

| 清单 | 启动前操作 | 启动后操作 |
|---|---|---|
| 执行盘点资产 | 批量/按条件/导入转移到未执行；导出；同步NO扫描数据 | 导入盘点结果；导出 |
| 未执行盘点资产 | 批量/按条件/导入转移到执行；导出 | 批量确认；导入盘点结果；导出 |
| 未包含资产 | 批量/按条件/导入转移到执行或未执行；导出 | 按项目状态控制 |

所有导入都必须校验资产是否属于当前清单。NO 扫描按序列号匹配，匹配不到的记录不得导入；标签号、序列号、型号、品牌、City、Building、Floor不一致时展示差异。[已确认，NO 蓝图相关细节待验证]

## 8. PC 端：盘点计划

点击“生成盘点计划”后，先选择默认生成或自定义生成。

默认生成按“子公司/一级部门 + City + 盘点范围”拆分。每条计划展示计划编号、名称、盘点组织、City、范围、资产总量、未盘数量、已盘数量、起止时间、计划负责人、监督人和执行人。

自定义生成支持按公司、部门、资产类别、责任人、启用日期和盘点范围筛选执行盘点资产，再按员工、库房、公共、机房分别配置计划负责人、监督人和执行人。

人员自动带出规则：

| 盘点范围 | 监督人 | 执行人 |
|---|---|---|
| 员工 | 同一级部门的部门助理 | 资产责任人 |
| 库房/公共 | 资产所在位置的库管员 | 资产所在位置的库管员 |
| 机房 | 盘点负责人手工配置 | 资产责任人；未配置时待补充 |

启动计划前必须保证所有执行盘点资产都有计划，必填人员和日期校验通过。启动后锁定计划和资产清单字段，并向狐小e、Myfamily和资产系统发送任务通知。[已确认]

## 9. 移动端：入口、待办和工作台

### 9.1 入口

移动端入口为“狐小e → 资产管理 → 盘点”。只有用户是当前计划执行人、监督人或项目负责人，且存在已启动未完成计划时才能进入。没有任务时入口置灰或不可进入。[已确认]

另一个入口是待办通知。任务启动时通知执行人和监督人；同一项目按最早计划生成一条项目通知，项目下仍有未完成计划时通知保持待办状态。项目内新增计划时，如果接收人相同则重新发送通知。[已确认]

### 9.2 工作台

工作台包含：

| 区域 | 规则 |
|---|---|
| 项目信息 | 展示当前盘点项目名称、期间和当前用户任务统计 |
| 未盘页签 | 展示未盘、报失资产，显示数量和盘点入口 |
| 已盘页签 | 展示已盘、代盘、未执行盘点资产，显示盘点人和盘点日期 |
| 搜索 | 按资产说明、资产标签号、序列号模糊匹配；数量同步重算 |
| 任务入口 | 监督人可查看按员工、公共、库房、机房分组的任务清单 |
| 返回 | 返回进入前页面 |
| 退出 | 返回资产管理首页 |

同一资产在对应计划完成后，从未盘列表移出。工作台列表只展示当前用户有权访问的计划资产，不展示其他人员任务。[已确认]

## 10. 移动端：资产详情与普通扫码

### 10.1 资产详情

详情展示资产标签号、序列号、数量、使用状态、资产说明、责任人、City/Building/Floor、盘点人、盘点日期、盘点备注。

非员工资产额外展示用途、公司、使用说明、备注。公共资产盘点提交后允许修改 City、Building、Floor；其他范围是否允许修改位置，需要确认。[待验证]

未盘资产提供“盘点”和“报失”。已盘/代盘资产不提供报失入口。报失按钮是否对未执行盘点资产开放，需要确认；建议仅对“未盘”开放。[待验证]

### 10.2 普通扫码

1. 用户打开摄像头扫描资产标签号二维码。
2. 系统校验当前用户是否有对应任务、资产是否在当前项目范围、资产是否已经被其他人盘点。
3. 校验通过后展示资产信息，并根据资产范围和图片规则进入拍照或提交结果。
4. 当前用户盘点成功，状态更新为“已盘”；代他人盘点成功，状态更新为“代盘”。
5. 盘点人、盘点日期和盘点备注同步写入计划资产清单和项目资产清单。

扫码异常分支至少包括：已被扫描、被他人盘点、范围外、无效标签/非资产二维码、网络失败。每个异常允许返回扫码或退出，不能改变资产状态。[已确认]

## 11. 移动端：照片、快速扫描和报失

### 11.1 照片

仅当项目图片规则标记当前资产需要上传时展示拍照环节。只允许调用相机拍照，不允许从本地相册选择。[已确认]

照片类型建议固定为：

| 资产范围 | 照片 |
|---|---|
| 非机房 | 资产整体照片、二维码标签照片 |
| 机房 | 二维码标签照片、实物序列号照片 |

照片提交成功后，盘点结果和照片一起写入后台；照片审核人可在 PC 端查看、放大、缩小、旋转并审核。审核不通过时，资产状态回到未盘并重新发送待办。[已确认]

### 11.2 快速扫描

快速扫描只记录资产标签号，提交时统一校验任务范围、重复扫描、已盘状态和标签有效性，并返回扫描总数、成功数和失败数。

快速扫描是否仅对机房计划开放，还是只要项目配置了快速扫描方式就对所有盘点范围开放，原始资料存在冲突，必须确认后写入最终 PRD。[待验证]

### 11.3 报失

1. 用户在未盘资产详情点击报失。
2. 报失原因必填。
3. 系统二次提示“资产丢失需履行赔偿责任哟！确定不再继续寻找了吗？”。
4. 确认后状态更新为报失，盘点人、盘点日期和盘点备注同步保存。
5. 系统通知盘点负责人和资产责任人；项目关闭后写入资产盘点历史。
6. 报失资产是否允许再次盘点并覆盖为已盘，原始移动端资料写明允许，但覆盖后的历史保留规则需要确认。[待验证]

## 12. 图片审核、进度、审批和报告

### 12.1 图片审核

项目计划启动时，为需要上传照片的执行盘点资产生成图片审核记录。审核列表按待审核、审核不通过、审核通过排序，展示图片、资产标签号、盘点人、盘点日期、盘点状态和盘点备注。

审核通过后记录锁定；审核不通过后重新通知执行人，资产恢复未盘，执行人重新提交照片。[已确认]

### 12.2 项目进度

按盘点范围、盘点组织、执行人一级部门和 City 汇总：应盘数量、已盘数量、报失数量、未盘数量、数量进度、监督人和剩余时间。支持查看全量资产、未盘资产、催盘和导出。[已确认]

盘到率建议统一计算为：

`（已盘数量 + 代盘数量）/ 执行盘点数量`

报失是否计入进度百分比，原始 PC 需求在不同位置存在“计入”和“不计入”的两种表达，需要确认。[待验证]

### 12.3 复盘审批

复盘计划启动后可提交审批。系统检查计划为启动状态，并提示当前盘点比例是否达到设定比例；比例检查为弱控制，提示后允许继续提交。审批通过后复盘项目和计划进入已审核，驳回后计划回到启动状态。[已确认]

### 12.4 盘点报告

PC 端提供财务报告、盘亏资产明细、待盘资产明细，并支持按财务公司和板块导出。报告按资产分类映射汇总数量、原值、已盘、报失和未盘差异；价值统一取资产卡片原值并保留两位小数。[已确认]

机房 NO 扫描、ES 业务盘点报告和初盘 PDF 报告的字段及模板需要业务方补充确认后再固化。[待验证]

## 13. 数据一致性与审计

1. 资产标签号是项目清单、计划清单、移动端扫码结果和图片审核记录的主关联标识。
2. 快照字段保存生成快照时的资产信息；盘点状态、盘点人、盘点日期、盘点备注和照片属于后续结果字段。
3. 移动端、扫码枪、Excel 导入必须写入相同的盘点结果字段，并记录导入方式。
4. 盘点结果写入时必须校验资产仍属于对应项目和计划，禁止只按标签号跨项目更新。
5. 每次结果变化记录操作人、操作时间、来源方式和前后状态。
6. 项目关闭后禁止产生新的盘点结果，但允许查看项目和资产盘点历史。

## 14. 必须由业务确认的口径

以下内容不能仅靠原型或历史文档自行决定，详见《资产盘点-三方比对》和《资产盘点-待决策清单》：

1. 快速扫描开放范围。
2. 移动端是否展示并允许进入“未执行盘点”资产。
3. 报失入口的适用状态及报失后的再次盘点规则。
4. 公共资产位置修改是否只允许 City/Building/Floor，是否需要权限或审核。
5. 报失是否计入项目进度百分比。
6. 机房 NO/MIS 同步字段、失败处理和正式上线时点。
7. 真实相机、任务通知和后端校验是否属于本轮原型交付，还是只进入研发需求。
8. 盘点公司“子公司维度/资产公司维度”的选择方式和公司-账套映射来源。

## 15. 非本轮原型范围

当前移动端页面仅用于验证页面结构和交互路径，不实现真实账号权限、任务消息推送、相机/二维码识别、照片上传服务、NO 同步、后端数据库写入和生产报表生成。上述规则已经写入目标 PRD，但需由研发按正式接口和权限模型落地。
