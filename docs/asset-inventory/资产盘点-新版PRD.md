# 资产盘点 PRD

## 1 背景

资产盘点用于在指定盘点期间，对企业资产进行范围确认、清单冻结、任务分配、现场盘点、结果审核和报告输出。

一次完整盘点包括：

`创建盘点项目 → 确定盘点范围 → 生成快照 → 生成盘点计划 → 启动盘点任务 → 现场盘点 → 图片审核/复盘审批 → 关闭项目 → 导出报告`

PC 端负责盘点项目和结果管理，移动端负责盘点执行。

### 1.1 业务范围

#### 1.1.1 项目类型

| 项目类型 | 业务含义 | 项目编号前缀 |
|---|---|---|
| 初盘 | 形成指定盘点期间的首次盘点结果 | CP |
| 抽盘 | 对初盘执行范围进行全量或比例抽查 | DCP |
| 复盘 | 对初盘执行范围进行复核并提交审批 | RCP |

#### 1.1.2 盘点范围

| 盘点范围 | 资产范围规则 |
|---|---|
| 库房 | 资产责任人名称包含“库房管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 公共 | 资产责任人名称包含“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 机房 | 资产大类属于服务器、网络设备；电话指定小类除外 |
| 员工 | 资产责任人名称不包含“库房管理员”“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |

手动创建的初盘、抽盘项目仅纳入非机房资产。年度机房初盘由系统独立创建。财务创建复盘项目时，可以关联已关闭的机房初盘项目，并从该初盘执行盘点快照带入机房资产；机房与非机房资产分别建项。

#### 1.1.3 盘点方式

盘点项目按盘点范围分别配置盘点方式：

1. 狐小e扫码。
2. 狐小e快速扫描资产标签号。
3. 扫码枪扫码。
4. 人工上传盘点结果。

每个盘点范围至少选择一种盘点方式。未选择时，保存和提交均提示具体盘点范围未配置盘点方式。

## 2 权限

权限按财务公司和板块控制。

| 角色 | 可执行操作 |
|---|---|
| 盘点负责人 | 创建、编辑、查看盘点项目；维护范围；生成快照和计划；导入、审核、调整盘点结果；查看进度和报告 |
| 计划负责人 | 维护盘点计划信息，协调计划启动和执行 |
| 盘点监督人 | 查看对应计划进度，接收催盘和异常通知 |
| 盘点执行人 | 执行分配给自己的移动端、扫码枪或人工导入盘点任务 |
| 财务人员 | 接收初盘项目关闭通知；发起复盘项目；执行复盘计划 |
| 复盘项目创建人 | 发起、修改并重新提交本复盘项目的位置变更申请 |
| 图片审核人 | 审核需要上传照片的盘点结果 |
| 复盘审批人 | 审核复盘项目结果；财务经理徐博负责财务审批节点 |

手动创建项目时，ES-孙志强仅可创建初盘和抽盘；财务-冯丽婷仅可创建复盘。项目类型选项按当前操作人权限展示，保存时仍须校验创建权限。年度机房初盘由系统创建。

已启动的盘点计划只向对应的执行人、监督人和项目负责人开放。没有有效盘点任务的用户不能进入移动端盘点。

## 3 通用规则

### 3.1 业务对象

| 对象 | 说明 |
|---|---|
| 盘点项目 | 盘点业务的主对象，定义期间、类型、范围和规则 |
| 盘点范围明细 | 根据项目规则筛选出的资产范围，快照前可以调整 |
| 快照 | 固定项目盘点范围和生成时资产信息的结果 |
| 盘点计划 | 将执行盘点资产分配给具体人员和时间的任务对象 |
| 计划资产清单 | 计划下的资产及其盘点状态、盘点人、盘点日期和盘点备注 |
| 图片审核 | 对需要上传照片的盘点资产进行审核的对象 |
| 待确认位置变更 | 复盘扫描中填写的新地点与资产台账地点不同，等待 PC 端核对和发起审批的记录 |
| 项目进度 | 按范围和组织汇总盘点结果的查询视图 |
| 盘点报告 | 按财务公司、板块和资产分类输出盘点结果 |

资产标签号是盘点项目、快照、计划、移动端结果和图片审核记录之间的关联标识。

### 3.2 项目关联

| 事项 | 规则 |
|---|---|
| 抽盘关联 | 关联一个已关闭且未被其他抽盘项目关联的初盘项目。 |
| 复盘关联 | 必须且只能关联一个已关闭且未被其他复盘项目关联的初盘项目。 |
| 期间 | 关联初盘项目的年度、季度或月份自动带入当前项目。 |
| 资产范围 | 机房和非机房分别建立初盘项目；后续抽盘或复盘只关联其中一个初盘，按关联初盘的资产范围确定审批流程。 |
| 复盘人员 | 由财务人员发起，盘点执行人仅限财务人员。 |

### 3.3 状态规则

#### 3.3.1 盘点项目状态

| 状态 | 业务含义 | 可执行操作 |
|---|---|---|
| 草稿 | 项目尚未生成固定快照 | 编辑、保存、删除 |
| 快照生成 | 项目范围已经冻结 | 查看清单、调整清单、生成计划 |
| 生成盘点计划 | 项目已进入计划配置阶段 | 编辑、补充、启动计划 |
| 盘点中 | 至少一个计划已经启动 | 执行盘点、查看进度、图片审核 |
| 盘点关闭 | 盘点结果已经结束 | 查看历史、导出报告 |

#### 3.3.2 盘点计划状态

| 状态 | 业务含义 |
|---|---|
| 草稿 | 计划日期和人员可以维护，尚未开放任务 |
| 盘点中 | 任务已开放，计划和资产清单的分配信息不可修改 |
| 审核中 | 复盘计划已提交审批 |
| 已审核 | 复盘计划审批通过 |
| 关闭 | 项目关闭时同步关闭关联计划 |

#### 3.3.3 资产盘点状态

| 状态 | 业务含义 |
|---|---|
| 未盘 | 尚未产生有效盘点结果 |
| 审核中 | 员工按图片规则上传必需照片并提交盘点，尚待图片审核；不计入已盘数量 |
| 已盘 | 当前资产责任人完成盘点；需审核照片的资产仅审核通过后进入 |
| 代盘 | 非当前资产责任人完成盘点 |
| 报失 | 用户提交报失并完成二次确认；仍可继续盘点该资产，不可重复报失 |

“未执行盘点”表示该资产未纳入本次现场执行范围，不属于盘点结果状态。

同一项目、同一资产只允许报失一次。报失后继续盘点会改变当前盘点状态，但已报失记录须保留；若上传照片后审核不通过、当前状态恢复为未盘，仍不得再次报失。

## 4 页面字段及交互

### 4.1 PC 端盘点项目

#### 4.1.1 项目列表

##### 4.1.1.1 查询条件

| 字段 | 查询规则 |
|---|---|
| 项目编号 | 包含匹配 |
| 项目名称 | 包含匹配 |
| 项目状态 | 按状态筛选 |
| 项目负责人 | 按人员筛选 |
| 盘点开始时间 | 一个日期区间条件，按项目的盘点开始时间筛选 |
| 项目类型 | 初盘 / 抽盘 / 复盘 |
| 创建时间 | 一个日期区间条件，按项目创建时间筛选 |

##### 4.1.1.2 列表字段

列表字段：项目名称、项目编号、项目类型、项目状态、盘点开始时间、盘点结束时间、执行盘点数量、资产总量、项目负责人、创建时间。

| 操作 | 条件与结果 |
|---|---|
| 展开或折叠 | 在初盘项目名称处展开或折叠关联抽盘、复盘；展开后显示子项目名称。 |
| 项目名称 | 点击进入对应项目详情。 |
| 删除 | 草稿项目提供删除入口。 |
| 关闭项目 | 除机房初盘外，列表和详情均提供入口，满足“项目关闭”规则后执行；机房初盘自动关闭。 |
| 进入计划 | 项目已生成盘点计划时提供入口。 |
| 查看进度 | 项目已启动时提供入口。 |
| 图片审核 | 存在图片审核记录时提供入口。 |

#### 4.1.2 创建和编辑项目

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 项目编号 | 只读文本 | 是 | 系统自动生成 |
| 项目名称 | 输入框 | 是 | 默认“期间-盘点类型”，允许修改 |
| 项目类型 | 单选 | 是 | 初盘 / 抽盘 / 复盘 |
| 盘点开始时间 | 日期选择 | 是 | 盘点开始日期 |
| 盘点结束时间 | 日期选择 | 是 | 所有项目的结束日期不得早于开始日期；复盘项目可跨天，各复盘计划的开始和结束日期必须为同一天，不同计划可安排在不同日期 |
| 盘点类型 | 单选 | 是 | 年度 / 季度 / 月度 |
| 盘点期间 | 联动选择 | 是 | 人工创建的年度项目展示当年四个季度，格式为“2026年Q2”；系统创建的机房年度初盘仅展示当年年份，如“2026年”；季度展示季度选项；月度展示去年12月至来年1月，格式为“2025年12月”“2026年1月”至“2027年1月”，年份随当前年度变化 |
| 初盘项目 | 项目选择 | 抽盘/复盘必填 | 只能选择符合关联条件的初盘项目 |
| 抽样方式 | 单选 | 抽盘/复盘必填 | 全盘 / 百分比 |
| 比例 | 数字输入 | 条件必填 | 抽样方式为百分比时显示，范围0～100；复盘先取必盘资产，再从剩余范围随机抽样 |
| 净值大于多少元必盘 | 数字输入 | 非必填 | 仅复盘且抽样方式为百分比时显示；当前盘点范围内净值严格大于该金额的资产必盘，等于金额不命中 |
| 净值前多少百分比必盘 | 数字输入 | 非必填 | 仅复盘且抽样方式为百分比时显示；按当前盘点范围资产净值降序取数量前X%，向上取整；净值相同按标签号排序；取值1～100 |
| 盘点说明 | 多行输入 | 否 | 最多150字 |
| 快照生成日期 | 只读文本 | 否 | 每次生成快照时自动更新 |

复盘项目仅允许财务人员创建，资产范围来自所关联初盘项目的执行盘点快照。关联机房初盘时仅带入机房资产，关联非机房初盘时仅带入非机房资产；范围筛选只在该快照内进行，不得添加其他初盘项目或范围外资产。机房初盘由系统按年度规则创建。

盘点范围明细不展示启用开始日期、启用结束日期。项目详情中，初盘不展示“初盘项目”“抽样方式”“比例”；抽盘和复盘按适用规则展示。

项目编号格式：

- 初盘：`CP-年月日-四位流水号`。
- 抽盘：`DCP-年月日-四位流水号`。
- 复盘：`RCP-年月日-四位流水号`。

#### 4.1.3 盘点规则

##### 4.1.3.1 规则字段

盘点公司、City、Building、资产类别、盘点范围和盘点方式。

盘点公司按子公司维度选择；选择范围以用户可管理的子公司为准。账套是独立字段，按已确认的公司与账套对应关系带出，不把子公司名称直接作为账套值。

#### 4.1.4 图片上传规则

项目提供“是否上传图片”开关。开启后，按盘点范围配置图片规则。

图片规则字段：资产责任人职级、部门、资产类别、资产状态、盘点组织、City、Building、Floor、上传百分比。

| 配置项或操作 | 规则 |
|---|---|
| 规则行 | 默认生成员工、库房、公共、机房四行，可增行、删行。 |
| 筛选条件 | 八项条件默认空、不筛选；支持多选、清空；同一项内取并集，不同项取交集。 |
| 上传百分比 | 必填，0～100；100%时全部匹配资产要求上传。 |
| 随机抽取 | 每条规则分别抽取；匹配资产条数乘百分比后四舍五入，不按卡片数量合计。 |
| 合并 | 任一规则选中即需上传，按标签号合并去重。 |
| 保存 | 保存项目时保存图片规则。 |
| 固定结果 | 生成快照时标记“是否需上传图片”，计划、移动及审核读同一标记；查看、刷新、重进不重新抽取。 |
| 关闭开关 | 关闭后生成的新快照资产均无需上传照片。 |

#### 4.1.5 盘点范围明细

保存项目后生成盘点范围明细。

| 项目场景 | 范围来源与更新规则 |
|---|---|
| 手动初盘 | 按盘点组织、资产状态、City、Building、资产类别和盘点范围筛选，仅纳入非机房资产。 |
| 年度初盘 | 纳入创建当年7月1日00:00:00之前启用的资产，截止时点可配置。 |
| 季度、月度初盘 | 按所选范围条件及启用日期区间筛选，不自动增加启用日期截止条件。 |
| 机房年度初盘 | 系统每年7月1日自动创建并启动；仅纳入符合机房规则的资产，不设置监督人；数量进度达到100%自动关闭。 |
| 快照生成前 | 范围资产字段随资产卡片变动更新。 |

抽盘、复盘以关联初盘项目生成快照时的执行盘点资产清单作为基础范围。

##### 4.1.5.1 范围筛选条件

| 字段 | 组件或取值 | 筛选规则 |
|---|---|---|
| 子公司 | 多选下拉框 | 匹配所选子公司资产。 |
| 部门 | 独立多选条件 | 同时选择子公司和部门时，资产须同时满足两项条件。 |
| 资产类别 | 大类、小类两级树形多选 | 选大类包含其下全部小类；选小类匹配对应大类下的小类。 |
| 资产状态、仓库、板块 | 多选条件 | 按所选值匹配。 |
| City | 支持搜索建议的多选下拉框 | 按所选City匹配。 |
| Building、Floor | 多选条件 | 按所选地点匹配。 |
| 资产责任人 | 公共人员选择弹窗，支持多选 | 按所选责任人匹配。 |
| 责任人职级 | 多选下拉框，来源为PS | 实习生、公共分别作为独立选项。 |
| 启用日期 | 起止日期区间 | 筛选资产卡片启用日期；范围明细保留“启用日期”字段。 |
| 净值前X% | 仅复盘，1～100，非必填 | 在满足其他条件的关联初盘执行快照内，按净值降序、按资产数量取前X%；不足一条向上取整，净值相同按标签号排序。只缩小范围，与必盘条件分开处理。 |

筛选条件复用公共选择组件，可选数据受当前页面权限和业务范围限制。枚举条件默认不筛选，支持多选和清空；同一条件取并集，不同条件取交集。日期区间、比例及净值百分比按各自取值规则处理。

##### 4.1.5.2 复盘抽样

| 步骤 | 规则 |
|---|---|
| 确定范围 | 取关联初盘的执行盘点快照，先按本页面条件缩小范围。 |
| 取必盘资产 | 抽样方式为百分比时，在当前范围内取净值大于指定金额或净值排名命中的资产；两条件取并集并按标签号去重。 |
| 抽取剩余资产 | 必盘资产之外的范围按基本信息中的比例随机抽取，数量四舍五入；必盘资产不占用剩余资产的抽样数量。 |
| 未设置必盘条件 | 两项必盘条件均留空时，对全部当前范围按比例随机抽取。 |

##### 4.1.5.3 复盘范围统计

| 字段 | 初始值 | 更新与编辑规则 |
|---|---|---|
| 本次复盘数量 | 关联初盘快照的执行资产数量 | 只读；每次生成查询后回写当前纳入资产数量。 |
| 复盘比例 | 100% | 只读；本次复盘数量 ÷ 关联初盘快照执行资产数量。 |

“当前纳入资产”指筛选结果还是抽样结果、数量按条数还是卡片数量合计，见补充说明。

##### 4.1.5.4 范围操作

| 操作 | 结果 |
|---|---|
| 生成查询 | 按当前条件生成一条范围汇总记录。 |
| 多次查询 | 可将多次查询结果加入盘点范围明细；同一项目按资产标签号取并集并去重，同一资产只保留一条范围明细。 |
| 查看全部 | 提供查看全部入口。 |
| 删除全部 | 清空范围汇总记录和范围资产明细，保留项目基本信息；重新选择范围并加入资产后才可生成快照。 |

##### 4.1.5.5 范围资产明细

查询条件为资产标签号、资产责任人、责任人职级，可组合使用；重置后不筛选。

| 字段组 | 字段 |
|---|---|
| 组织及类别 | 公司、部门、资产类别 |

### 4.4 移动端盘点

#### 4.4.1 进入条件

移动端提供两条入口：

1. 狐小e → 资产管理 → 盘点。

### 4.6 普通扫码盘点

1. 用户从列表【开始盘点】、计划清单【盘点】或资产详情【盘点】打开普通单资产扫码页；展示一张资产标签二维码样例及“参考如下样例，找到标签扫描”，并提供开灯。
2. 系统校验当前用户是否有对应任务。
3. 系统校验资产是否属于当前计划范围。
4. 已盘、代盘及图片审核中的资产不可重复提交；报失资产允许继续盘点。
5. 校验通过后进入该资产的扫码详情页，按图片规则展示上传区域；照片与盘点结果统一通过底部【提交】提交，扫码本身不改变资产盘点状态。
6. 当前责任人盘点成功，状态更新为已盘；非当前责任人盘点成功，状态更新为代盘。
7. 盘点人、盘点日期和盘点备注同步写入计划资产清单和项目资产清单；单资产提交成功后返回扫码页，不返回资产列表。

扫码、提交异常不更新盘点结果。

| 异常 | 处理 |
|---|---|
| 已被扫描、已被他人盘点 | 按当前资产状态提示；已报失资产仍允许重新盘点。 |
| 资产不在范围、无效或非资产二维码 | 给出业务原因，允许继续扫码或退出。 |
| 网络提交失败 | 回资产详情并保留已录入内容，允许重试；不保存本次结果。 |

页面仅展示失败原因及下一步操作，扫码场景的具体返回路径如下。

| 扫码或提交场景 | 提示后的操作与去向 |
|---|---|
| 已盘资产再次扫码 | “休息一下”退出扫描；“再接再厉”留在扫描页 |
| 扫到他人应盘资产 | 进入该资产的扫码详情页，查看责任人信息后可报失或提交；返回继续扫描 |
| 自有资产提交成功、本人仍有待盘资产 | 返回原扫码页面继续扫描 |
| 代盘成功、本人仍有待盘资产 | 返回原扫码页面继续扫描 |
| 代盘成功、本人已无待盘资产 | 返回原扫码页面继续扫描 |
| 网络提交失败 | “好的”回资产详情，不保存本次结果 |
| 无效或非资产二维码、本人仍有待盘资产 | 退出或留在扫描页 |
| 无效或非资产二维码、本人已无待盘资产 | “好的，收工”回盘点首页 |
| 本次不需盘资产、本人仍有待盘资产 | 退出或留在扫描页 |
| 本次不需盘资产、本人已无待盘资产 | “好的，收工”回盘点首页 |
| 自有资产提交成功、本人已无待盘资产 | 返回原扫码页面继续扫描 |

#### 4.7.1 入口与权限

| 角色或入口 | 规则 |

入口、扫描、提交均校验角色、项目和任务范围；不同项目、计划的待提交标签分别保存，不能混交。

|---|---|
| 连续扫描 | 提供手电筒；每次只记录标签，显示本次扫描数量和最近五个标签。 |
| 项目外资产 | 立即提示“不在当前盘点项目内”；不加入待提交列表，不增加扫描数量或最近标签记录。 |

1. 标签号是否属于当前计划。
2. 标签号是否重复扫描。

### 4.8 照片上传与审核

#### 4.8.1 移动端拍照

照片必传规则仅适用于移动端普通扫码及快速扫描；扫码枪和人工导入结果无需补传照片或进行人工照片审核。只有扫码成功后的资产详情且图片规则标记“是否需上传图片”时展示拍照区域；直接打开资产查看详情不展示上传区域。移动端只允许拍照，不允许从相册选择。

| 资产范围 | 必传照片 |
|---|---|
| 非机房 | 资产整体照片、二维码标签照片 |
| 机房 | 二维码标签照片、实物序列号照片 |

员工、公共、库房资产上传必需照片并提交成功后，盘点结果和照片一起保存，资产状态变为审核中；在审核结论出现前不计入已盘，不能重复提交。机房资产上传所需照片后不进入人工图片审核，直接按盘点人身份更新已盘或代盘。无需上传照片的资产按普通扫码结果更新。

#### 4.8.2 PC 端图片审核

计划启动时，为员工、公共、库房范围中需要上传照片的执行盘点资产生成图片审核记录；机房照片保留查看，不生成待人工审核任务。扫码枪或人工导入成功的资产不产生待人工审核事项，也不因照片规则阻止提交审批或关闭项目。

| 区域或操作 | 规则 |
|---|---|
| 列表 | 图片、资产标签号、实际盘点人、盘点日期、盘点状态、盘点备注；按待审核、审核不通过、审核通过排序。 |
| 概览 | 分别统计待审核、审核通过、审核不通过数量。 |
| 查询 | 资产标签号、资产说明、审核状态、责任人、公司、部门、资产类别、盘点起止时间、盘点状态、City、Building、计划编号、计划名称；重新打开保留条件。 |
| 选择结论 | 每行仅能选通过或不通过一项。 |
| 提交 | 仅处理已勾选且已给出结论的行。 |
| 重新审核 | 员工重传被驳回照片后，可重新审核。 |

审核操作：

1. 审核通过：审核状态为审核通过，资产从审核中变为已盘，审核记录锁定。
2. 审核不通过：审核状态为审核不通过，资产从审核中恢复未盘，员工盘点待办重新出现并可再次拍照提交；同时向员工发送驳回通知。若该资产曾报失，保留已报失记录，不恢复【报失】操作。
3. 图片查看使用上传原图，不压缩、不降低画质；支持原图 1:1、放大、缩小和旋转。

| 关闭方式 | 条件 |
|---|---|
| 手动关闭 | 除机房初盘外，初盘、抽盘、复盘可从列表或详情关闭。 |
| 初盘、抽盘校验 | 所有关联计划均已启动；没有待审核或审核不通过的照片。不要求后续复盘先审批。 |
| 复盘校验 | 满足上述条件，且本项目全部复盘计划审批通过。存在审批中的位置变更申请时阻止关闭，须先完成位置变更审批。 |
| 允许保留的未完成内容 | 已启动计划可以有未盘资产或待提交结果，不阻止关闭。 |
| 机房初盘自动关闭 | 数量进度达到100%立即关闭；照片免人工审核，不以照片审核为前置。 |
| 关闭确认 | 校验通过后弹出确认，展示未盘数量和待提交数量。 |

关闭后项目更新为盘点关闭、关联计划关闭、移动待办结束，停止所有盘点。结果保留、历史、通知及下一步操作见第6章。

### 4.12 盘点报告

#### 4.12.1 财务盘点报告

财务报告包含三个页签：

1. 盘点报告汇总。
2. 盘亏资产明细。
3. 待盘资产明细。

| 价值字段 | 来源及时点 |
|---|---|
| 原值 | 资产卡片价值信息中的EBS原值。 |
| 待盘净值：非机房 | 盘点当年6月的资产卡片净值。 |
| 待盘净值：机房 | 导出报告当月的资产卡片净值。 |
| 盘亏净值：非机房 | 移动端报失当月净值。 |
| 盘亏净值：机房 | 导出报告当月净值。 |

所有价值字段保留两位小数。

| 事项 | 规则 |
|---|---|
| 下载条件 | 项目启动盘点计划后提供下载。 |
| 选择范围 | 一个子公司、一个或多个板块。 |
| 纳入资产 | 本项目快照中匹配公司、板块的执行及未执行资产；未包含清单不纳入。 |
| 分类汇总 | 资产大小类经分类映射转换为报告大小类，按小类小计、大类合计；汇总原值、数量、已盘、报失和未盘差异。 |
| 数据缺失 | 指出缺少的分类映射或历史价值；不得用其他月份净值或当前净值替代。 |

| 汇总指标 | 计算规则 |
|---|---|
| 台账价值、数量 | 小类内执行与未执行两类快照资产的EBS原值、资产数量合计；大类合计其下小类 |
| 盘点价值、数量 | 两类清单中已盘、代盘资产的EBS原值、资产数量合计；大类合计其下小类 |
| 价值差额 | 台账价值减盘点价值，分别计算小类小计和大类合计 |
| 数量差额 | 台账数量减盘点数量，分别计算小类小计和大类合计 |
| 盘亏价值、数量 | 两类清单中报失资产的EBS原值、资产数量按大类合计，说明固定为“丢失” |
| 待查价值、数量 | 两类清单中未盘资产的EBS原值、资产数量按大类合计，说明固定为“待查” |

盘亏资产明细仅收录报失资产，待盘资产明细仅收录未盘资产；其余字段分别取对应快照资产及后续盘点记录。

#### 4.12.2 其他报告

ES业务盘点报告、初盘PDF报告、机房NO扫描报告纳入报告范围；最终字段及模板见补充说明。

## 5 校验

| 校验对象 | 触发时机 | 条件与处理 |
|---|---|---|
| 创建权限 | 保存项目 | 项目类型须在当前操作人允许范围内；无权限不能创建。 |
| 项目日期 | 创建、编辑项目 | 结束日期不得早于开始日期；复盘项目可跨天。 |
| 计划日期 | 修改、启动复盘计划 | 每条复盘计划开始结束必须同日，不同计划可安排不同日期。 |
| 盘点方式 | 保存、提交项目 | 每个盘点范围至少一种方式，缺失时提示具体范围并阻止操作。 |
| 计划分配 | 启动计划 | 所有执行资产先分配计划；计划负责人、日期齐全，每项资产执行人有值；监督人非必填。 |
| 复盘执行人 | 保存、启动计划 | 只能选择财务人员。 |
| 任务及资产范围 | 扫码、提交、导入结果 | 仅更新当前项目、当前计划范围内资产；范围外资产不能处理。 |
| 资产状态 | 扫码提交 | 已盘、代盘、审核中禁止重复提交；报失可继续盘点。 |
| 必传照片 | 普通扫码、快扫提交 | 按快照标记校验必需照片，缺失不能记成功。 |
| 重复报失 | 报失确认 | 同项目同资产只允许一次；重盘或审核驳回后仍保留报失历史，禁止再次报失。 |
| 位置变更 | 提交位置申请 | 校验整批资产范围、实际地点变更、完整有效地点及照片审核前置条件；失败不产生部分结果。 |
| 关闭后写入 | 修改、补录或提交 | 关闭项目及关联对象只读，禁止新增、修改、补录和重新提交。 |

## 6 后续操作 / 业务结果 / 补充说明

### 6.1 计划与移动待办通知

| 触发条件 | 对象与处理 |
|---|---|
| 计划启动 | 非机房计划向狐小e、Myfamily及资产系统发送盘点任务通知，通知已配置执行人和监督人；机房计划仅通知NO/MIS在盘点执行期间推送扫描结果。 |
| 发送盘点通知 | 提供入口，非机房向计划执行人、监督人发送消息和待办；机房仅通知NO/MIS推送扫描结果。 |
| 日常提醒 | 存在未完成任务时，非机房每天提醒相关执行人；机房仅通知NO/MIS推送扫描结果。 |
| 催盘 | 非机房向所选分录未盘资产对应的执行人、已配置监督人发送消息和邮件，邮件附所选未盘资产清单；机房仅通知NO/MIS推送扫描结果。 |
| 复盘准备通知 | 非机房以每条计划自身开始日安排，在“启动当天”和“开始日前三天”中离开始日更近的一天，经服务号通知员工资产责任人提前准备资产；与财务执行人分开，同一计划同一员工仅发一次。 |
| 同项目多计划 | 按最早启动计划时间发送一条项目通知；仍有已启动未完成计划时保持待办，所有已启动计划完成后转已办。 |
| 全部完成后新增计划 | 按新计划启动时间向新计划配置的执行人、监督人重新发通知，人员与上一轮是否相同均适用；机房通知对象为NO/MIS。 |

### 6.2 结果记录

| 对象或动作 | 保存结果 |
|---|---|
| 盘点结果 | 保存资产标签号、盘点人、盘点日期、盘点备注、盘点方式；来源区分狐小e、狐小e快速扫描、扫码枪、人工导入。 |
| 操作记录 | 盘点项目、计划、清单、审核记录均保留操作人和操作时间。 |
| 照片审核 | 结论同步到计划清单、项目清单、项目进度及导出；状态处理按照片审核页面规则执行。 |
| 项目关闭 | 项目、计划、资产清单、盘点结果、审核记录转为只读，不能修改、补录、重新提交；已提交结果及历史审核记录保留，待提交不计结果、不转财务补录。 |
| 资产卡片历史 | 仅在项目关闭后，按资产标签号写入一次本项目的最终状态；字段见“盘点历史”。 |

机房盘点由NO/MIS在盘点执行期间推送扫描结果。扫描信息与资产信息不一致时，不将资产变为已盘，向NO/MIS返回不一致信息；完成信息修正后重新扫描，信息一致时变为已盘。

### 6.3 关闭通知与后续项目

| 场景 | 后续处理 |
|---|---|

### 6.4 盘点历史

盘点项目关闭后，每个资产标签号在资产卡片盘点历史中写入一条该项目的最终盘点记录；执行期间不写入，重复关闭不重复写入。报失后重新盘点时，写入关闭时的最终状态，盘点说明保留报失原因。

| 字段 | 取值规则 |
|---|---|
| 盘点类型 | 对应项目的盘点类型。 |
| 盘点标识 | 盘点类型与期间。 |
| 盘点项目名称 | 对应项目名称。 |
| 盘点状态 | 项目关闭时资产的最终盘点结果状态。 |
| 盘点时间 | 盘点记录时间。 |
| 盘点说明 | 取盘点备注。 |
| 实际盘点执行人 | 该次实际执行人。 |
| 导入方式 | 该次盘点结果来源。 |
