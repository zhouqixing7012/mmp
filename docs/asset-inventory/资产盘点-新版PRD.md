# 资产盘点 PRD

## 1 背景

资产盘点用于在指定盘点期间，对企业资产进行范围确认、清单冻结、任务分配、现场盘点、结果审核和报告输出。

一次完整盘点包括：

`创建盘点项目 → 确定盘点范围 → 生成快照 → 生成盘点计划 → 启动盘点计划 → 现场盘点 → 图片审核/复盘审批 → 关闭项目 → 导出报告`

PC 端负责盘点项目和结果管理，移动端负责盘点执行。

### 1.1 业务范围

#### 1.1.1 项目类型

| 项目类型 | 业务含义 | 项目编号前缀 |
|---|---|---|
| 初盘 | 形成指定盘点期间的首次盘点结果 | CP |
| 抽盘 | 对初盘执行范围进行全量或比例抽查 | DCP |
| 复盘 | 财务人员对初盘执行范围进行全量或比例复核，并将复核结果提交审批 | RCP |

#### 1.1.2 盘点范围

| 盘点范围 | 资产范围规则 |
|---|---|
| 库房 | 资产责任人名称包含“库房管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 公共 | 资产责任人名称包含“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 机房 | 资产大类属于服务器、网络设备；电话指定小类除外 |
| 员工 | 资产责任人名称不包含“库房管理员”“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |

手动创建的初盘、抽盘项目仅纳入非机房资产。年度机房初盘由系统独立创建。财务创建复盘项目时，可以关联已关闭的机房初盘项目，并从该初盘执行盘点快照带入机房资产；机房与非机房资产分别建项。

#### 1.1.3 盘点方式

所有盘点资产默认支持以下四种盘点方式：

1. 狐小e扫码。
2. 狐小e快速扫描资产标签号。
3. 扫码枪扫码。
4. 人工上传盘点结果。

项目及盘点范围不再配置盘点方式。各方式按第2章的操作权限控制，操作人只能使用本人有权限的方式处理授权范围内的资产；计划和项目状态、资产范围及各方式的结果校验仍须满足。

## 2 权限

权限按财务公司和板块控制。

| 角色 | 对应人员 | 可执行操作 |
|---|---|---|
| 盘点负责人（项目创建人） | 人工项目为该项目创建人，已明确人员有ES孙志强、财务冯丽婷；系统自动项目为系统管理员 | 创建、编辑、查看权限内项目；维护范围；生成快照和计划；上传本项目盘点结果；审核、调整结果及查看进度和报告须具备对应操作权限 |
| 盘点监督人 | 对应计划配置的监督人 | 查看对应计划进度，接收催盘和异常通知 |
| 盘点执行人 | 对应计划配置的执行人；复盘计划仅可配置财务人员 | 执行本人获分配的盘点计划；盘点方式使用权限见下表 |
| 财务人员 | 冯丽婷；其他人员按正式财务人员名单确定 | 接收初盘项目关闭通知；发起复盘项目；对初盘执行范围进行全量或比例复核 |
| 复盘项目创建人 | 该复盘项目创建人；已明确人员为冯丽婷 | 发起、修改并重新提交本复盘项目的位置变更申请 |
| 图片审核人 | 具体人员名单见6.5待确认事项 | 审核需要人工审核的盘点结果照片 |
| ES资产组 | 孙志强；其他人员按正式ES资产组名单确定 | 在授权项目和资产范围内使用扫码枪；快速扫描权限见下表 |
| 位置变更审批人 | ES主管何文 | 审批复盘位置变更申请 |
| 复盘审批人 | 非机房首审为ES主管，具体人员待明确；机房首审为NO领导，具体人员待明确；财务审批节点为财务经理徐博 | 按4.10规定的审批路径审核复盘结果 |

盘点方式操作权限：

| 盘点方式 | 可操作人员 | 数据范围与限制 |
|---|---|---|
| 狐小e扫码 | 有效已启动计划对应的执行人、监督人、项目负责人 | 当前人员有权处理的项目和计划资产；移动端准入及扫码结果规则见4.4～4.6 |
| 狐小e快速扫描资产标签号 | 获快速扫描权限的指定人员；人员范围及资产限制见4.7.1 | 不因资产支持快速扫描而向所有人员开放 |
| 扫码枪扫码 | ES资产组人员 | 仅处理本人授权项目、计划范围内资产 |
| 人工上传盘点结果 | 本盘点项目创建人，或本机房项目的盘点执行人 | 项目创建人限本项目；机房执行人限本项目本人获分配的资产；其他执行人不因被分配计划而获得上传盘点结果权限 |

手动创建项目时，ES-孙志强仅可创建初盘和抽盘；财务-冯丽婷仅可创建复盘。项目类型选项按当前操作人权限展示，保存时仍须校验创建权限。年度机房初盘由系统创建。

已启动的盘点计划只向对应的执行人、监督人和项目负责人开放。没有有效盘点任务的用户不能进入移动端盘点。

## 3 通用规则

### 3.1 业务对象

| 对象 | 说明 |
|---|---|
| 盘点项目 | 盘点业务的主对象，定义期间、类型、范围和规则；项目创建人同时为项目负责人，系统自动创建项目的负责人为系统管理员 |
| 盘点范围明细 | 根据盘点范围筛选条件取得的资产范围，快照前可以调整 |
| 快照 | 固定项目盘点范围和生成时资产信息的结果 |
| 盘点计划 | 将执行盘点资产分配给具体人员和时间的任务对象 |
| 计划资产清单 | 计划下的资产及其盘点状态、盘点人、盘点日期和盘点备注 |
| 图片审核 | 对需人工审核的非机房盘点照片及其结果进行审核的对象 |
| 待确认位置变更 | 复盘扫描中填写的新地点与资产台账地点不同，等待 PC 端核对和发起审批的记录 |
| 项目进度 | 按范围和组织汇总盘点结果的查询视图 |
| 盘点报告 | 按财务公司、板块和资产分类输出盘点结果 |

资产标签号是盘点项目、快照、计划、移动端结果和图片审核记录之间的关联标识。

### 3.2 项目关联

| 事项 | 规则 |
|---|---|
| 抽盘关联 | 必须且只能关联一个已关闭且未被其他抽盘项目关联的初盘项目。 |
| 复盘关联 | 必须且只能关联一个已关闭且未被其他复盘项目关联的初盘项目。 |
| 期间 | 关联初盘项目的年度、季度或月份自动带入当前项目。 |

### 3.3 状态规则

#### 3.3.1 盘点项目状态

| 状态 | 业务含义 | 可执行操作 |
|---|---|---|
| 草稿 | 项目尚未生成固定快照 | 编辑、保存、删除 |
| 快照生成 | 项目范围已经冻结 | 查看清单、调整清单、生成计划 |
| 生成盘点计划 | 项目已进入计划配置阶段 | 编辑、补充、启动计划 |
| 盘点中 | 至少一个计划已经启动 | 执行盘点、查看进度、图片审核；除机房初盘外，满足4.11关闭条件时可关闭项目 |
| 盘点关闭 | 盘点结果已经结束 | 查看历史、导出报告 |

#### 3.3.2 盘点计划状态

| 状态 | 业务含义 |
|---|---|
| 草稿 | 计划日期和人员可以维护，尚未开放任务 |
| 盘点中 | 任务已开放，计划和资产清单的分配信息不可修改 |
| 审核中 | 复盘计划已提交审批 |
| 已审核 | 复盘计划审批通过 |
| 关闭 | 项目关闭时同步关闭关联计划 |

#### 3.3.3 资产盘点状态

| 状态 | 业务含义 |
|---|---|
| 未盘 | 尚未产生有效盘点结果 |
| 审核中 | 需人工审核的非机房资产已提交必需照片及盘点结果，尚待图片审核；不计入已盘数量 |
| 已盘 | 当前资产责任人完成盘点；需审核照片的资产仅审核通过后进入 |
| 代盘 | 非当前资产责任人完成盘点 |
| 报失 | 用户提交报失并完成二次确认；可继续盘点该资产；报失操作限制见下文。 |

“未执行盘点”表示该资产未纳入本次现场执行范围，不属于盘点结果状态。

同一项目内，资产处于报失状态时禁止重复报失。报失后可继续盘点，当前盘点状态随盘点结果更新，已发生的报失记录须保留。照片审核不通过、资产恢复未盘后，允许再次报失，不因曾经报失而禁止该操作。

#### 4.1.3 盘点范围明细

初盘按盘点范围和盘点类型区分；抽盘、复盘从所关联的初盘取得基础范围。

##### 4.1.3.2 复盘抽样

本节仅适用于复盘项目。全盘时对筛选范围全量复核，不执行比例随机抽取；百分比方式按下表抽样，并展示两项可选净值必盘条件。

| 步骤 | 规则 |
|---|---|
| 确定范围 | 取关联初盘的执行盘点快照，先按本页面条件缩小范围。 |
| 取必盘资产 | 抽样方式为百分比时，在当前范围内取净值大于指定金额或净值排名命中的资产；两条件取并集并按标签号去重。 |
| 抽取剩余资产 | 按资产卡片抽样，每个标签号为一个抽样单位；必盘资产之外的卡片条数乘基本信息中的比例，四舍五入后随机抽取对应条数的整张卡片；必盘资产不占用剩余资产的抽样数量。 |
| 未设置必盘条件 | 两项必盘条件均留空时，对全部当前范围按比例随机抽取。 |

#### 4.1.5 生成快照

点击“生成快照”后：

1. 将盘点范围明细中的资产汇总为项目快照。范围筛选分录为空时沿用项目保存时生成的范围资产；用户手工从范围资产明细移除的资产不因重新生成或二次保存而回到范围内。
2. 根据物料的“是否需盘点”属性拆分执行盘点和未执行盘点资产。
3. 将本项目盘点范围筛选结果与执行/未执行清单按资产标签号比对，差异放入未包含资产清单。
4. 非机房资产根据人工图片规则标记“是否需上传图片”；机房资产按NO/MIS无法自动扫描标识确定需照片要求，具体见4.8.1。
5. 更新项目快照生成日期和项目状态。

快照生成后，资产范围和快照时的资产基础信息保持不变。盘点状态、盘点人、盘点日期、盘点备注和照片属于后续盘点结果，可以继续更新。

快照页面包含四个页签：

1. 快照清单统计。
2. 执行盘点资产清单。
3. 未执行盘点资产清单。
4. 未包含资产清单。

上传盘点结果用于更新盘点结论，与本节导入标签号调整清单归属是两项功能；上传盘点结果还须校验第2章规定的人员权限。

| NO扫描同步步骤 | 规则 |

### 4.8 照片上传与审核

审核操作：

1. 审核通过：审核状态为审核通过；实际盘点人与当前资产责任人一致时，资产从审核中变为已盘，否则变为代盘；审核记录锁定。
2. 审核不通过：审核状态为审核不通过，资产从审核中恢复未盘，员工盘点待办重新出现，可再次拍照提交或报失；即使该资产曾经报失，也恢复报失入口，同时向员工发送驳回通知。

| 机房审批 | NO领导 → 财务经理徐博。 |
| 节点通过 | 进入下一节点；审批路径按唯一关联初盘的资产范围确定。 |
| 节点驳回 | 审批单更新已驳回，计划回盘点中，通知项目负责人处理。 |
| 全部通过 | 审批单、计划均更新已审核，通知项目负责人。 |

复盘结果以审批通过作为确认依据，不额外增加证明实际现场核实的独立凭证要求；现有照片规则及提交审批的前置校验仍按本PRD执行。

复盘审批提交及审批结束不发送邮件通知。

| 资产状态、使用状态 | 共用资产使用状态字典：在用-使用中、在库-修理、在库-新增、在用-借用中、在库-待处理、再利用-使用中、已报废-已处置、已报废-待处置、再利用-待报废；按所选状态匹配。 |
| 公司、子公司、部门 | 取对应组织基础资料；项目范围中的“公司及部门”按既定末级组织树规则处理，不能把财务公司与行政子公司混作同一候选。 |
| City、Building、Floor | 取地点基础资料，按对应地点标识匹配；各页面的地点联动和候选限制须按其已明确规则处理。 |
| 责任人职级 | PS职级，实习生、公共为独立候选；支持多选和清空。 |
| 板块、仓库 | 分别取板块、仓库基础资料，以对应编码匹配，回显编码及名称。 |
| 盘点状态、审核状态、盘点方式、盘点范围、项目状态、项目类型 | 按各查询字段列明的固定选项选择，不从已返回列表临时生成枚举。 |

基础资料候选受数据权限约束，查询结果受所在页面的项目、计划及业务范围约束，两者分别定义；候选不能由当前分页或已返回结果反推。项目、计划是否追加候选限制见6.5。

## 5 校验

| 校验对象 | 触发时机 | 条件与处理 |
|---|---|---|
| 创建权限 | 保存项目 | 项目类型须在当前操作人允许范围内；无权限不能创建。 |
| 项目日期 | 创建、编辑项目 | 结束日期不得早于开始日期；复盘项目可跨天。 |
| 计划日期 | 修改、启动复盘计划 | 每条复盘计划开始结束必须同日，不同计划可安排不同日期。 |
| 盘点方式权限 | 进入操作及提交结果 | 校验第2章对应方式的人员权限和资产范围；无权限不得操作，不因项目默认支持四种方式而放行。 |
| 计划分配 | 启动计划 | 所有执行资产先分配计划；日期齐全，每项资产执行人有值；监督人非必填。 |
| 复盘执行人 | 保存、启动计划 | 只能选择财务人员。 |
| 任务及资产范围 | 扫码、提交、导入结果 | 仅更新当前项目、当前计划范围内资产；范围外资产不能处理。 |
| 资产状态 | 扫码提交 | 已盘、代盘、审核中禁止重复提交；报失可继续盘点。 |
| 必传照片 | 普通扫码、快扫提交 | 按4.8.1的非机房快照标记或机房NO/MIS标记校验必需照片，缺失不能记成功。 |
| 重复报失 | 报失确认 | 当前为报失状态时阻止重复报失；照片审核不通过恢复未盘后允许再次报失，不以曾报失记录阻止操作；报失记录保留。 |
| 位置变更 | 提交位置申请 | 校验整批资产范围、实际地点变更、完整有效地点及照片审核前置条件；失败不产生部分结果。 |
| 盘点报告 | 生成、查看或导出报告 | 项目须已关闭，未关闭时阻止操作并提示先关闭项目。 |
| 关闭后写入 | 修改、补录或提交 | 关闭项目及关联对象只读，禁止新增、修改、补录和重新提交。 |

## 6 后续操作 / 业务结果 / 补充说明

### 6.1 计划与移动待办通知

| 触发条件 | 对象与处理 |
|---|---|
| 计划启动 | 非机房计划向狐小e、Myfamily及资产系统发送盘点任务通知，通知已配置执行人和监督人；机房计划仅通知NO/MIS在盘点执行期间推送扫描结果。 |
| 发送盘点通知 | 提供入口，非机房向计划执行人、监督人发送消息和待办；机房仅通知NO/MIS推送扫描结果。 |
| 未完成任务提醒 | 存在未完成任务时，非机房经服务号通知相关执行人；机房经服务号通知NO/MIS推送扫描结果。提醒频次及发送时刻待确定。 |
| 催盘 | 非机房向所选分录未盘资产对应的执行人、已配置监督人发送消息和邮件，邮件附所选未盘资产清单；机房仅通知NO/MIS推送扫描结果。 |
| 复盘准备通知 | 非机房以每条计划自身开始日安排，在“启动当天”和“开始日前三天”中较晚的一天；晚于开始日启动时，启动当天发送通知，经服务号通知员工资产责任人提前准备资产；与财务执行人分开，同一计划同一员工仅发一次。 |
| 同项目多计划 | 按最早启动计划时间发送一条项目通知；仍有已启动未完成计划时保持待办，所有已启动计划完成后转已办。 |
| 全部完成后新增计划 | 按新计划启动时间向新计划配置的执行人、监督人重新发通知，人员与上一轮是否相同均适用；机房通知对象为NO/MIS。 |

### 6.2 结果记录

| 对象或动作 | 保存结果 |
|---|---|
| 盘点结果 | 保存资产标签号、盘点人、盘点日期、盘点备注、盘点方式；来源区分狐小e、狐小e快速扫描、扫码枪、人工导入。 |

| 照片审核 | 结论同步到计划清单、项目清单、项目进度及导出；状态处理按照片审核页面规则执行。 |
| 项目关闭 | 项目、计划、资产清单、盘点结果、审核记录转为只读，不能修改、补录、重新提交；已提交结果及历史审核记录保留，待提交不计结果、不转财务补录。同步清除本项目下未完成盘点员工的狐小e盘点待办，结束对应移动待办；不清除其他盘点项目的待办。 |
| 资产卡片历史 | 仅在项目关闭后，按资产标签号写入一次本项目的最终状态；字段见“盘点历史”。 |

机房盘点由NO/MIS在盘点执行期间推送扫描结果。扫描信息与资产信息不一致时，不将资产变为已盘，向NO/MIS返回不一致信息；完成信息修正后重新扫描，信息一致时变为已盘。
