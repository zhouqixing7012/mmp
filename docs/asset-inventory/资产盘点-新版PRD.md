# 资产盘点 PRD

## 1 背景

资产盘点用于在指定盘点期间，对企业资产进行范围确认、清单冻结、任务分配、现场盘点、结果审核和报告输出。

盘点的共同流程为：

`创建盘点项目 → 确定盘点范围 → 生成快照 → 生成盘点计划 → 启动盘点计划 → 现场盘点 → 关闭项目 → 导出报告`

需要人工照片审核的非机房资产，提交盘点结果后进入图片审核；复盘项目另按4.10执行计划监督人会签和徐博项目审批。各类型关闭条件按4.11执行。

PC 端负责盘点项目和结果管理，移动端负责盘点执行。

### 1.1 业务范围

#### 1.1.1 项目类型

| 项目类型 | 业务含义 | 项目编号前缀 |
|---|---|---|
| 初盘 | 形成指定盘点期间的首次盘点结果 | CP |
| 抽盘 | 对初盘执行范围进行全量或比例抽查 | DCP |
| 复盘 | 财务人员对初盘执行范围进行全量或比例复核，并将复核结果提交审批 | RCP |

#### 1.1.2 盘点范围

| 盘点范围 | 资产范围规则 |
|---|---|
| 库房 | 资产责任人名称包含“库房管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 公共 | 资产责任人名称包含“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 机房 | 资产大类属于服务器、网络设备；电话指定小类除外 |
| 员工 | 资产责任人名称不包含“库房管理员”“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |

手动创建的初盘、抽盘项目仅纳入非机房资产。年度机房初盘由系统独立创建。财务创建复盘项目时，可以关联已关闭的机房初盘项目，并从该初盘执行盘点快照带入机房资产；机房与非机房资产分别建项。

#### 1.1.3 盘点方式

所有盘点资产默认支持以下四种盘点方式：

1. 狐小e扫码。
2. 狐小e快速扫描资产标签号。
3. 扫码枪扫码。
4. 人工上传盘点结果。

项目及盘点范围不再配置盘点方式。各方式按第2章的操作权限控制，操作人只能使用本人有权限的方式处理授权范围内的资产；计划和项目状态、资产范围及各方式的结果校验仍须满足。

## 3 通用规则

### 3.1 业务对象

| 对象 | 说明 |
|---|---|
| 盘点项目 | 盘点业务的主对象，定义期间、类型、范围和规则；项目创建人同时为项目负责人，系统自动创建项目的负责人为系统管理员 |
| 盘点范围明细 | 根据盘点范围筛选条件取得的资产范围，快照前可以调整 |
| 快照 | 固定项目盘点范围和生成时资产信息的结果 |
| 盘点计划 | 将执行盘点资产分配给具体人员和时间的任务对象 |
| 计划资产清单 | 计划下的资产及其盘点状态、盘点人、盘点日期和盘点备注 |
| 图片审核 | 对需人工审核的非机房盘点照片及其结果进行审核的对象 |
| 待变更池 | 复盘移动端提交的新地点与资产台账地点不同所形成的建议记录；PC端提供查看和导出，项目关闭时仍有记录则通知孙志强 |
| 项目进度 | 按范围和组织汇总盘点结果的查询视图 |
| 盘点报告 | 按财务公司、板块和资产分类输出盘点结果 |

资产标签号是盘点项目、快照、计划、移动端结果和图片审核记录之间的关联标识。

### 3.2 项目关联

| 事项 | 规则 |
|---|---|
| 抽盘关联 | 每个抽盘项目必须且只能关联一个已关闭的初盘项目；同一个初盘可被多个抽盘项目关联。 |
| 复盘关联 | 每个复盘项目必须且只能关联一个已关闭的初盘项目；同一个初盘可被多个复盘项目关联。 |
| 期间 | 关联初盘项目的年度、季度或月份自动带入当前项目。 |

### 3.3 状态规则

#### 3.3.1 盘点项目状态

| 状态 | 业务含义 | 可执行操作 |
|---|---|---|
| 草稿 | 项目尚未生成固定快照 | 编辑、保存、删除；抽盘关闭按4.11校验 |
| 快照生成 | 项目范围已经冻结 | 查看清单、调整清单、生成计划；抽盘关闭按4.11校验 |
| 生成盘点计划 | 项目已进入计划配置阶段 | 编辑、补充、启动计划；抽盘关闭按4.11校验 |
| 盘点中 | 至少一个计划已经启动，或复盘项目审批被驳回 | 执行盘点、查看进度、图片审核、逐计划提交审批；全部计划审批通过后可提交复盘项目审批；满足4.11时可关闭项目 |
| 盘点关闭 | 盘点结果已经结束 | 查看历史、导出报告 |

#### 3.3.2 盘点计划状态

| 状态 | 业务含义 |
|---|---|
| 草稿 | 新生成计划的初始状态；日期和人员可以维护，尚未开放任务 |
| 盘点中 | 任务已开放，计划和资产清单的分配信息不可修改 |
| 审核中 | 复盘计划已提交各资产监督人会签，尚未全部通过 |
| 已审核 | 该计划全部监督人审批通过；执行人狐小e待办清除；之后项目审批被驳回时按4.10.3恢复修改并重新审批 |
| 关闭 | 项目关闭时同步关闭关联计划 |

新增计划一律从草稿开始，不因所属项目已有其他计划正在审批或已经通过而自动进入审核中或已审核；该计划须独立启动和执行，复盘计划还须独立完成监督人会签。

#### 3.3.3 资产盘点状态

| 状态 | 业务含义 |
|---|---|
| 未盘 | 尚未产生有效盘点结果 |
| 审核中 | 需人工审核的非机房资产已提交必需照片及盘点结果，尚待图片审核；不计入已盘数量 |
| 已盘 | 当前资产责任人完成盘点；需审核照片的资产仅审核通过后进入。扫描结果导入统一记为已盘，不区分导入人与责任人是否一致，见4.2.8。 |
| 代盘 | 非当前资产责任人完成盘点；扫描结果导入按已盘处理，不据导入人是否为责任人判为代盘。 |
| 报失 | 用户提交报失并完成二次确认；可继续盘点该资产；报失操作限制见下文。 |

“未执行盘点”表示该资产未纳入本次现场执行范围，不属于盘点结果状态。

同一项目内，资产当前处于报失状态时禁止重复报失；报失后可继续盘点，当前状态随新盘点结果更新。照片审核不通过、资产恢复未盘后允许再次报失，不以曾经报失限制后续操作。盘点备注可被后续有效填写覆盖，资产卡片盘点历史按6.4保存项目关闭时的最终结果。

盘点结果的新增、修改和提交，仅在项目盘点中且未关闭、项目审批未处于审核中或已审核时允许；资产已归属计划时，该计划须已启动且不处于审核中或已审核状态；审批驳回后恢复盘点修改。计划结束日期不限制盘点或提交。已关闭项目保留本人原任务的只读详情，停止新增、修改和提交。

### 3.4 导出范围

本模块列表及资产明细导出：查询有结果时导出本次查询的全部结果，不限分页；查询无结果时，导出当前入口原有数据权限内的完整数据范围。回退不跨越当前项目、计划、清单类型或报告入口，不绕过项目关闭、报告生成及操作权限校验。

照片审核导出不嵌入照片、不提供照片链接；已定义字段按对应导出章节输出，尚未定义的图片审核导出字段见6.5。

### 3.5 数量口径

除4.1.3.3的复盘范围统计按卡片条数外，项目、快照、计划、进度、关闭确认、复盘审批及移动端的资产数量，均合计对应资产卡片的“数量”字段；一张卡片数量为10时计10。已盘、未盘、报失、审核中及必盘等统计先按对应状态或标记筛选，再合计数量，完成比例的分子与分母使用同一口径。列表分页条数、计划条数、文件导入行数、扫描次数及成功失败记录数仍按各自记录数统计；抽样按资产卡片条数计算，每张卡片为一个抽样单位，不把卡片上的“数量”字段合计后用于抽取；抽中后的资产数量统计仍合计“数量”字段。净值排名的单位按对应范围规则处理。

##### 4.1.3.2 复盘抽样

本节仅适用于复盘项目。全盘时对筛选范围全量复核，不执行比例随机抽取；百分比方式按下表抽样，并展示两项可选净值必盘条件。

| 步骤 | 规则 |
|---|---|
| 确定范围 | 取关联初盘的执行盘点快照，先按本页面条件缩小范围。 |
| 取必盘资产 | 抽样方式为百分比时，在当前范围内取已标记必盘的资产，以及净值大于指定金额或净值排名命中的资产；取并集并按标签号去重。 |
| 抽取剩余资产 | 按资产卡片抽样，每个标签号为一个抽样单位；必盘资产之外的卡片条数乘基本信息中的比例，四舍五入后随机抽取对应条数的整张卡片；必盘资产不占用剩余资产的抽样数量。 |
| 未设置必盘条件 | 两项净值条件均留空且没有必盘标记时，对全部当前范围按比例随机抽取。 |

##### 4.1.3.3 复盘范围统计

“本次复盘数量”和“复盘比例”展示在创建、编辑项目页的“盘点资产范围明细”区域顶部，作为只读统计字段，仅复盘项目展示。其中“复盘比例”表示范围数量的占比，基本信息中的“比例”用于抽样。

| 字段 | 格式 | 计算及更新规则 |
|---|---|---|
| 本次复盘数量 | 整数 | 默认取当前复盘项目的资产明细条数；指定范围批次时，取该批次符合已生效查询条件的明细条数。按卡片条数统计，不汇总卡片上的“数量”字段。 |
| 复盘比例 | 百分比 | 本次复盘数量 ÷ 关联初盘项目全部资产明细条数 × 100%；分母不按需盘、已盘或本批筛选范围缩小。初盘明细为零时显示0%；其他比例保留两位小数，0%、100%不显示小数。 |

查看或切换范围批次，以及批次内查询后同步更新上述统计；查看全部恢复项目范围统计。复盘比例表示实际范围占比，与创建时填写的抽样比例分别展示、分别使用。

例如初盘共1,000张卡片，复盘纳入200张，显示200、20.00%；查看其中50张的范围批次，显示50、5.00%。

#### 4.1.5 生成快照

点击“生成快照”后：

1. 将盘点范围明细中的资产汇总为项目快照。范围筛选分录为空时沿用项目保存时生成的范围资产；用户手工从范围资产明细移除的资产不因重新生成或二次保存而回到范围内。
2. 根据物料的“是否需盘点”属性拆分执行盘点和未执行盘点资产。
3. 将本项目盘点范围筛选结果与执行/未执行清单按资产标签号比对，差异放入未包含资产清单。

快照生成后，资产范围和快照时的资产基础信息保持不变。盘点状态、盘点人、盘点日期、盘点备注和照片属于后续盘点结果，可以继续更新。

1. 快照清单统计。
2. 执行盘点资产清单。
3. 未执行盘点资产清单。

##### 4.1.6.1 清单转移

转移用于调整同一盘点项目快照中的资产清单归属。转移至未执行表示该资产不进入执行盘点清单，转移至执行表示纳入执行盘点清单；此操作不变更资产卡片的责任人、地点或使用状态，也不代表资产已盘或报失。

| 来源清单 | 可转移的目标清单 | 完成结果 |

| 执行盘点资产清单 | 未执行盘点资产清单 | 从执行清单移除，加入未执行清单。 |
| 未执行盘点资产清单 | 执行盘点资产清单 | 从未执行清单移除，加入执行清单。 |
| 未包含资产清单 | 执行盘点或未执行盘点资产清单 | 选择目标后，从未包含清单移除，加入目标清单，纳入项目快照。 |

| 操作入口 | 处理范围 | 交互及结果 |
|---|---|---|
| 批量转移 | 当前来源清单中勾选的资产 | 支持单选或多选；未勾选时提示先选择资产，不执行转移。 |
| 批量导入转移 | 导入文件中的资产标签号所匹配的当前来源清单资产 | 提供模板下载，模板仅含“资产标签号”列；导入用于指定已有资产，不新建资产。读取首个工作表，支持xlsx、xls、csv。执行/未执行清单的目标固定为对方清单；未包含清单须选择目标。 |

转移按上表启动前条件及第2章权限控制；启动后禁止通过上述两种方式调整范围，项目关闭后禁止转移。分批启动后按启动后限制处理；三类清单的查询条件统一按4.1.5.1展示。

导入先校验整份文件：表头必须为“资产标签号”，空行忽略；非空明细须填写标签号，不得重复，不得包含额外非空列，所有标签号必须属于当前来源清单。表头错误、无有效明细、重复或不属于来源清单时提示对应原因及错误行，整批不转移；用户修正后重新导入。

#### 4.2.3 人员带出与修改

##### 4.2.3.1 自动带出

以下默认规则按资产逐项带出；同一计划内不同资产可对应不同人员，不能把其中一项资产的人员当作全计划人员。

| 生成场景及范围 | 盘点监督人 | 盘点执行人 |
|---|---|---|
| 默认生成的员工初盘、抽盘 | 资产责任人所属一级部门对应的部门助理 | 该资产责任人 |
| 默认生成的库房初盘、抽盘 | 按资产库房编号匹配库房资料中的管理员 | 按资产库房编号匹配库房资料中的管理员 |
| 公共范围，默认及自定义生成均适用 | 自定义指定监督人时优先取指定人员，否则取项目创建人；复盘仍须为财务人员 | 默认为空；自定义明确指定执行人时带入指定人员 |
| 机房初盘，适用于其全部计划 | 不设置 | 该资产责任人，系统自动带出，不提供手工配置或修改 |
| 复盘 | 从财务人员中配置，各资产监督人参与本计划会签；与项目审批人徐博分别记录 | 从财务人员中配置 |

自定义员工初盘首次生成时，设置计划信息中明确指定的监督人、执行人分别优先于对应默认值；未指定的字段按上表逐资产带出。自定义初盘的库房范围，填写监督人或执行人时带入对应计划及其资产；未填写的对应字段保留空值。公共范围按上表带出，监督人不取库管员，执行人不从责任人、库管员或旧计划人员自动带出。自定义复盘执行人填写时带入本计划及资产，未填写时保留空值，监督人、执行人仍限财务人员。机房初盘始终由责任人执行。生成后修改草稿计划人员按4.2.3.2处理，启动前校验每项资产执行人非空。抽盘员工及库房范围的默认人员按上表带出，公共范围按其独立规则带出。库房管理员按资产库房编号关联库房资料，不按库房名称或地点文字推断。

##### 4.2.3.2 修改与同步

| 修改入口 | 条件 | 影响范围 |
|---|---|---|
| 计划人员配置 | 计划为草稿且项目未关闭 | 修改当前计划某项监督人或执行人配置后，把该值写入当前计划全部资产的对应“盘点监督人”或“盘点执行人”；不改资产责任人，不影响其他计划，也不改变已经记录的实际盘点人。 |
| 计划资产清单逐资产修改 | 计划为草稿且项目未关闭 | 只修改所选资产的盘点监督人或盘点执行人，其他资产人员保持；复盘监督人、执行人均限财务人员。 |
| 计划或资产人员导入 | 与手工配置相同的状态和人员限制 | 按模板对应的计划或资产更新，不能通过导入绕过锁定。 |

机房初盘的执行人始终由资产责任人带出，上述手工配置、逐资产修改及人员导入均不能覆盖该执行人；不设置盘点监督人。计划启动后，计划层级和关联资产清单的监督人、执行人、日期及分配关系都锁定；盘点中、审核中、已审核、关闭状态均不能修改这些分配信息。盘点结果、盘点备注及未盘说明按各自流程更新，不属于人员重新分配。

#### 4.2.7 启动计划

支持单选、多选和分批启动。所有执行资产都已进入计划是“分配完整性”，只启动本次所选计划是“启动批次”，两者分别校验。例如100项执行资产已分配给A、B两个计划，可先启动A，B保留草稿以后启动；若仍有资产未分配到任何计划，则先补生成计划。

启动前依次校验：

1. 项目未关闭，本次已选择计划且所选计划均为草稿。
2. 本项目所有执行盘点资产均已归入计划；有未分配资产时，提示其数量，允许转入默认补生成或自定义创建，补完后重新选择并启动。
3. 本次所选计划开始、结束日期完整，结束日不得早于开始日；初盘、抽盘、复盘计划均可跨天。
4. 本次所选计划的每项资产均有盘点执行人；复盘监督人（已配置时）和执行人均具有财务资格，机房初盘执行人由资产责任人带出；监督人非必填。

| 操作 | 展示、可用条件及结果 |
|---|---|
| 启动盘点计划 | 始终显示；未选择、含非草稿计划、项目关闭或无可启动计划时置灰。校验通过后仅本次所选计划进入盘点中，其他草稿计划保持；项目进入盘点中。 |
| 删除盘点计划 | 始终显示；未选择、含非草稿计划或项目关闭时置灰，仅项目创建人可处理所选草稿计划。删除后原计划资产解除该计划分配，可重新筛选创建计划；其他已启动计划不受影响。 |

启动后锁定本次所选计划及关联资产的人员、日期和分配关系，已经启动或关闭的计划不能再次启动。未启动草稿计划仍可按自身状态维护。需要调整其资产范围时，由项目创建人删除该未启动计划，再从本项目可分配资产中重新筛选创建，不直接修改原计划的资产归属。项目部分计划已启动时仍可采用这一路径，已启动计划及其资产分配保持锁定；删除计划不扩大项目的执行盘点范围，未重新归入计划的执行资产仍须按启动前分配完整性校验补齐。分批启动后快照清单查询条件按4.1.5.1展示。

初盘、抽盘、复盘计划均允许在计划开始日之后启动；不会仅因当前日期晚于开始日而阻止。复盘员工准备通知另按6.1安排，不能据该通知规则限制其他项目类型启动。

#### 4.2.8 导入及模板

计划列表与计划资产清单使用同一套资产导入规则。计划列表按资产标签号定位所属计划，计划资产清单则限定当前计划；根据用途校验目标计划及项目状态，不设置单独更新计划汇总信息的导入。

| 导入用途 / 模板 | 入口及适用状态 | 匹配与更新内容 |
|---|---|---|
| 草稿资产人员导入 | 计划列表或计划资产清单，目标计划为草稿 | 按资产标签号定位所属计划及资产，维护对应人员配置；不支持导入更新计划开始日期、结束日期。日期仅按4.2.2的草稿编辑规则维护；人员导入遵守机房初盘执行人自动带出和启动后锁定。具体模板列尚未明确，见6.5。 |
| 未盘说明导入 | 计划资产清单，盘点中 | 独立模板按资产匹配未盘说明，不改人员、盘点状态、实际盘点人或盘点日期；具体模板列见6.5。 |
| 扫描结果导入 | 计划列表、计划资产清单及执行/未执行盘点清单，项目盘点中，资产所属计划条件见下文 | 使用下述A/B两列格式，按资产标签号更新盘点结果；各入口仍受第2章人工上传盘点结果权限及资产范围限制。 |
| 清单转移模板 | 快照清单，满足启动前范围变更条件 | 仅“资产标签号”一列，整批校验见4.1.6.1；只调整清单归属，不更新盘点结果。 |
| 复盘范围清单模板 | 项目范围明细，复盘草稿且未生成快照 | 与该位置导出一致，为“资产标签号、是否必盘”两列，按4.1.3.5整批替换范围并校验当前生效条件。 |

扫描结果导入格式及处理：

| 文件内容 | 规则 |
|---|---|
| A列 | 资产标签号；填写需要更新的当前入口授权资产。 |
| B列 | 备注，写入盘点备注；非空时覆盖旧盘点备注，空白时保留旧值。 |
| 工作表 | 读取文件各Sheet，每个Sheet第1行为表头并跳过，第2行起为数据；空行忽略。 |
| 盘点结果 | 导入成功后固定记已盘，实际盘点人为当前导入人，盘点日期为本次成功导入时的系统时间；不更新原盘点方式。 |

保存前校验整个文件：资产标签号非空，在所有Sheet之间唯一，属于本入口权限范围，项目须盘点中。计划入口和执行盘点清单中的资产须归属有效的盘点中计划；未执行盘点清单中未分配计划的资产可在项目盘点中导入，已分配计划的资产仍校验该计划为盘点中。非空数据行缺标签、跨Sheet重复标签、范围外资产或状态不允许等均记为错误，不静默跳过，也不先保存其他有效行。

各类导入的空单元格均保留原值，文件内重复资产报错；全部校验通过后整批保存，任一错误则整批不更新，保留原状态、人员、日期、备注和盘点方式。反馈全部错误明细，能定位源工作表、行号、标签号及原因，供修正后重新导入。草稿人员、未盘说明使用各自模板，不因扫描结果导入规则而改变用途；这些模板未确认的列不自行增加。

项目关闭后全部导入停止写入。人员、日期及资产所属计划在保存时再次校验，不能通过文件导入绕过启动后的分配锁定。

### 4.8 照片上传与审核

#### 4.8.1 移动端拍照

照片必传规则仅适用于移动端普通扫码及快速扫描；扫码枪和人工导入结果无需补传照片或进行人工照片审核。普通扫码成功后的详情或快扫查看/补拍页，非机房按快照“是否需上传图片”标记展示照片区域，机房按NO/MIS“是否无法自动扫描”标记展示；直接查看详情不展示拍照上传区域。移动端只允许拍照，不允许从相册选择；项目关闭后不再拍摄或替换照片。

机房照片要求由NO/MIS提供的“是否无法自动扫描”标识确定；无法自动扫描的资产需上传照片，不能仅因机房照片免审核而免除照片要求。机房初盘使用该标识确定需照片资产，不按人工图片规则随机抽取。

员工、公共、库房资产上传必需照片并提交成功后，盘点结果和照片一起保存，资产状态变为审核中；在审核结论出现前不计入已盘，不能重复提交。机房资产上传所需照片后不进入人工图片审核，直接按盘点人身份更新已盘或代盘。无需上传照片的资产按普通扫码结果更新。

普通扫码与快速扫描补拍均只能实时调用相机拍摄，不允许选择相册或本地已有图片。未授予相机权限、取消拍摄或拍摄失败均不计为照片已提交；须完成拍摄后才能通过对应必传照片校验。此限制不适用于4.8.2独立的PC机房项目照片上传。

#### 4.10.2 逐计划提交与会签

PC端盘点计划页操作栏提供【提交计划审批】，须选中一条计划，操作只提交该计划；未选或选择多条时提示选择一条计划。已提交的计划审批记录可查看。其他计划可继续执行或独立审批。

| 校验项 | 规则与处理 |
|---|---|
| 项目及计划状态 | 项目未关闭，本计划为盘点中；审核中或已审核的计划不重复提交。驳回后的计划回到盘点中，可处理后重新提交。 |
| 照片 | 本计划已提交照片存在待审核或审核不通过时阻止提交，指出资产；未盘资产尚未提交照片不作为该项拦截。机房免人工审核、扫码枪及人工导入不要求照片审核的例外仍适用。 |
| 资产与完成情况 | 本计划资产集合须非空且资产数量合计大于零；不以完成率或未盘必盘数量限制提交，未盘、报失及未完成必盘资产仍保留真实结果。 |
| 审批人 | 以本计划资产的全部有效监督人为会签人，同一人员只参与一次；无有效监督人时阻止提交，提示核对本计划监督人配置。 |

| 操作或环节 | 业务结果 |
|---|---|
| 提交计划审批 | 保存本计划审批记录，计划进入审核中；其他计划状态保持。 |
| 监督人同意 | 保存该监督人的结论；本次全部会签人均同意后，本计划与其审批记录更新已审核。 |
| 监督人驳回 | 本计划审批记已驳回，计划回盘点中，通知项目负责人处理；其他已通过计划的结论保留。 |
| 计划审批全部通过 | 立即清除本计划盘点执行人的狐小e待办，只处理本计划，不等待项目审批或关闭，也不清除其他计划、项目的待办。 |

#### 4.10.3 复盘项目提交与审批

计划页提供【提交项目审批】及【查看项目审批】。提交项目前，项目须未关闭且本项目全部计划均审批通过；存在草稿、盘点中、审核中或被驳回的计划时，指出对应计划并阻止项目提交。零计划项目禁止提交审批；项目关闭按4.11校验。

| 操作或环节 | 业务结果 |
|---|---|
| 提交项目审批 | 保存整个复盘项目的审批记录，审批记录进入审核中，交徐博审批；项目状态保持盘点中。 |
| 徐博同意 | 项目审批记录更新为已审核，项目状态保持盘点中，保留各计划已通过结论；通知项目负责人。 |
| 徐博驳回 | 项目审批记录记已驳回，项目状态保持盘点中，项目及所属计划恢复盘点修改；旧审批记录留存，修改后的计划重新提交监督人审批，不以原已通过结论确认新结果。全部计划重新审批通过后可再次提交徐博。 |

同意、驳回、重新提交均保留所属计划或项目的历次记录和审批意见。计划和项目审批均由指定审批人本人处理，不设置代理；驳回时必须填写非空审批意见，未填写则阻止驳回并提示补充。同意意见选填，驳回意见必填；审批意见最多400字。提交由本项目创建人操作。复盘结果以审批通过作为确认依据，不设置专门的初复盘差异确认流程，也不额外增加现场核实凭证要求；照片规则及提交前校验仍按本PRD执行。计划及项目审批提交、审批结束均不发送邮件。

### 4.11 项目关闭

复盘项目审批状态与项目状态分别记录；项目审批通过后项目仍为盘点中，关闭时按计划审批结论及未结束审核校验。

在项目列表选中一条项目后点击【关闭项目】。依次校验列表条件及对应项目类型的关闭条件，通过后进入关闭确认。

| 校验对象 | 规则与处理 |
|---|---|
| 选择数量 | 列表必须且只能选中一条项目，否则提示选择一个需要关闭的项目。 |
| 项目状态 | 列表拦截已关闭项目。初盘、复盘须处于已启动盘点状态，否则提示“还未开启盘点或已关闭”。 |
| 未结束审核 | 审核未结束数量大于零时拦截，包括存在待审核的照片、审核中的复盘计划或复盘项目审批时阻止关闭，指出对应记录；审核通过和驳回均属于已结束。待变更池建议不属于审核，不阻止关闭。 |
| 计划及盘点完成情况 | 复盘须全部执行盘点资产均已创建计划，且所有计划均审批通过；存在未创建计划的资产或未通过审批的计划时阻止关闭。未盘资产和待提交结果不单独阻止关闭。 |
| 关闭确认 | 校验通过后弹出确认，展示未盘数量；确认时再次校验项目状态、未结束审核及对应类型的计划条件。 |
| 机房初盘自动关闭 | 数量进度达到100%时自动关闭；同时支持按上述条件手动关闭。 |

| 未盘数量 | 整数 | 当前项目盘点结果 | 应盘数量减已盘数量，包含报失和审核中资产 |

明细表表头固定从A3:R3开始，共18列，字段顺序按本节明细表；记录从第4行开始，按盘亏记录、小计、待查记录、小计、总计顺序扩展。小计、总计合并前五列A:E，数量及金额保持原列对齐，不恢复已取消的备注列。盘亏、待查汇总名称分别建立工作簿内跳转，跳转到明细实际分组起始行，随明细条数调整。资产类型分布表保留类别、数量、原值（万元）、原值占比四项已定义字段；年度指标保持五列，分类增量为含空白备注的四列，各表按其已定义字段输出。

NO/MIS提供机房扫描盘点结果的同步来源，按机房盘点数据同步规则处理；不将其另列为待新增的报告。

## 5 校验

| 校验对象 | 触发时机 | 条件与处理 |
|---|---|---|
| 创建权限 | 保存项目 | 项目类型须在当前操作人允许范围内；无权限不能创建。 |
| 项目日期 | 创建、编辑项目 | 结束日期不得早于开始日期；复盘项目可跨天。 |

| 计划分配 | 启动计划 | 所有执行资产先分配计划；日期齐全，每项资产执行人有值；监督人非必填。 |

| 结果锁定 | 新增、修改或提交盘点结果、备注、未盘说明及照片 | 项目审批记录处于审核中或已审核，或所属计划处于审核中或已审核时禁止；审批驳回后恢复修改并重新审批；结束日期不作为执行拦截条件。 |
