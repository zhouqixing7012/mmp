# 资产盘点 PRD

## 1 背景

资产盘点用于在指定盘点期间，对企业资产进行范围确认、清单冻结、任务分配、现场盘点、结果审核和报告输出。

一次完整盘点包括：

`创建盘点项目 → 确定盘点范围 → 生成快照 → 生成盘点计划 → 启动盘点计划 → 现场盘点 → 图片审核 → 复盘计划审批 → 复盘项目审批 → 关闭项目 → 导出报告`

PC 端负责盘点项目和结果管理，移动端负责盘点执行。

### 1.1 业务范围

#### 1.1.1 项目类型

| 项目类型 | 业务含义 | 项目编号前缀 |
|---|---|---|
| 初盘 | 形成指定盘点期间的首次盘点结果 | CP |
| 抽盘 | 对初盘执行范围进行全量或比例抽查 | DCP |
| 复盘 | 财务人员对初盘执行范围进行全量或比例复核，并将复核结果提交审批 | RCP |

#### 1.1.2 盘点范围

| 盘点范围 | 资产范围规则 |
|---|---|
| 库房 | 资产责任人名称包含“库房管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 公共 | 资产责任人名称包含“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 机房 | 资产大类属于服务器、网络设备；电话指定小类除外 |
| 员工 | 资产责任人名称不包含“库房管理员”“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |

手动创建的初盘、抽盘项目仅纳入非机房资产。年度机房初盘由系统独立创建。财务创建复盘项目时，可以关联已关闭的机房初盘项目，并从该初盘执行盘点快照带入机房资产；机房与非机房资产分别建项。

#### 1.1.3 盘点方式

所有盘点资产默认支持以下四种盘点方式：

1. 狐小e扫码。
2. 狐小e快速扫描资产标签号。
3. 扫码枪扫码。
4. 人工上传盘点结果。

项目及盘点范围不再配置盘点方式。各方式按第2章的操作权限控制，操作人只能使用本人有权限的方式处理授权范围内的资产；计划和项目状态、资产范围及各方式的结果校验仍须满足。

## 2 权限

权限按财务公司和板块控制。

| 角色 | 对应人员 | 可执行操作 |
|---|---|---|
| 盘点负责人（项目创建人） | 人工项目为该项目创建人，已明确人员有ES孙志强、财务冯丽婷；系统自动项目为系统管理员 | 创建、编辑、查看权限内项目；维护范围；生成快照和计划；上传本项目盘点结果；审核、调整结果及查看进度和报告须具备对应操作权限 |
| 盘点监督人 | 对应计划资产配置的监督人；复盘仅限财务人员 | 查看对应计划进度，接收催盘和异常通知；复盘计划由该计划各资产监督人会签，全部通过后计划审批完成 |
| 盘点执行人 | 对应计划配置的执行人；复盘计划仅可配置财务人员 | 执行本人获分配的盘点计划；盘点方式使用权限见下表 |
| 财务人员 | 冯丽婷；其他人员按正式财务人员名单确定 | 接收初盘项目关闭通知；发起复盘项目；对初盘执行范围进行全量或比例复核 |
| 复盘项目创建人 | 该复盘项目创建人；已明确人员为冯丽婷 | 管理本复盘项目、查看及导出待变更池；审批提交人的具体范围见6.5 |
| 图片审核人 | 具体人员名单见6.5待确认事项 | 审核需要人工审核的盘点结果照片 |
| ES资产组 | 孙志强；其他人员按正式ES资产组名单确定 | 在授权项目和资产范围内使用扫码枪；快速扫描权限见下表 |
| 复盘计划审批人 | 当前计划资产的全部监督人 | 各监督人会签本人负责计划，全部同意后该计划审批通过；仅有权审批本人参与会签的计划 |
| 复盘项目审批人 | 财务经理徐博 | 全部计划审批通过后，审批整个复盘项目；项目审批独立于计划审批 |
| 盘点报表菜单使用人 | ES孙志强、何文、吕静、穆晓丹 | 进入盘点报表菜单、查看及导出权限范围内的报告；其他人员不展示该菜单，也不能直接进入报告页或执行导出 |

盘点方式操作权限：

| 盘点方式 | 可操作人员 | 数据范围与限制 |
|---|---|---|
| 狐小e扫码 | 有效已启动计划对应的执行人、监督人、项目负责人 | 当前人员有权处理的项目和计划资产；移动端准入及扫码结果规则见4.4～4.6 |
| 狐小e快速扫描资产标签号 | 获快速扫描权限的指定人员；人员范围及资产限制见4.7.1 | 不因资产支持快速扫描而向所有人员开放 |
| 扫码枪扫码 | ES资产组人员 | 仅处理本人授权项目、计划范围内资产 |
| 人工上传盘点结果 | 本盘点项目创建人，或本机房项目的盘点执行人 | 项目创建人限本项目；机房执行人限本项目本人获分配的资产；其他执行人不因被分配计划而获得上传盘点结果权限 |

手动创建项目时，ES-孙志强仅可创建初盘和抽盘；财务-冯丽婷仅可创建复盘。项目类型选项按当前操作人权限展示，保存时仍须校验创建权限。年度机房初盘由系统创建。

已启动的盘点计划只向对应的执行人、监督人和项目负责人开放。没有有效盘点任务的用户不能进入移动端盘点。

## 3 通用规则

### 3.1 业务对象

| 对象 | 说明 |
|---|---|
| 盘点项目 | 盘点业务的主对象，定义期间、类型、范围和规则；项目创建人同时为项目负责人，系统自动创建项目的负责人为系统管理员 |
| 盘点范围明细 | 根据盘点范围筛选条件取得的资产范围，快照前可以调整 |
| 快照 | 固定项目盘点范围和生成时资产信息的结果 |
| 盘点计划 | 将执行盘点资产分配给具体人员和时间的任务对象 |
| 计划资产清单 | 计划下的资产及其盘点状态、盘点人、盘点日期和盘点备注 |
| 图片审核 | 对需人工审核的非机房盘点照片及其结果进行审核的对象 |
| 待变更池 | 复盘移动端提交的新地点与资产台账地点不同所形成的建议记录；PC端提供查看和导出，项目关闭时仍有记录则通知孙志强 |
| 项目进度 | 按范围和组织汇总盘点结果的查询视图 |
| 盘点报告 | 按财务公司、板块和资产分类输出盘点结果 |

资产标签号是盘点项目、快照、计划、移动端结果和图片审核记录之间的关联标识。

### 3.2 项目关联

| 事项 | 规则 |
|---|---|
| 抽盘关联 | 必须且只能关联一个已关闭且未被其他抽盘项目关联的初盘项目。 |
| 复盘关联 | 必须且只能关联一个已关闭且未被其他复盘项目关联的初盘项目。 |
| 期间 | 关联初盘项目的年度、季度或月份自动带入当前项目。 |

### 3.3 状态规则

#### 3.3.1 盘点项目状态

| 状态 | 业务含义 | 可执行操作 |
|---|---|---|
| 草稿 | 项目尚未生成固定快照 | 编辑、保存、删除、按4.11关闭项目 |
| 快照生成 | 项目范围已经冻结 | 查看清单、调整清单、生成计划、按4.11关闭项目 |
| 生成盘点计划 | 项目已进入计划配置阶段 | 编辑、补充、启动计划、按4.11关闭项目 |
| 盘点中 | 至少一个计划已经启动，或复盘项目审批被驳回 | 执行盘点、查看进度、图片审核、逐计划提交审批；全部计划审批通过后可提交复盘项目审批；满足4.11时可关闭项目 |
| 审核中 | 复盘项目已提交徐博审批 | 查看项目及计划结果、处理当前项目审批；满足4.11时可关闭项目 |
| 已审核 | 徐博已通过复盘项目审批 | 查看审批结论及结果；满足4.11时可关闭项目 |
| 盘点关闭 | 盘点结果已经结束 | 查看历史、导出报告 |

#### 3.3.2 盘点计划状态

| 状态 | 业务含义 |
|---|---|
| 草稿 | 计划日期和人员可以维护，尚未开放任务 |
| 盘点中 | 任务已开放，计划和资产清单的分配信息不可修改 |
| 审核中 | 复盘计划已提交各资产监督人会签，尚未全部通过 |
| 已审核 | 该计划全部监督人审批通过；执行人狐小e待办清除，不因之后的项目驳回而撤销该结论 |
| 关闭 | 项目关闭时同步关闭关联计划 |

#### 3.3.3 资产盘点状态

| 状态 | 业务含义 |
|---|---|
| 未盘 | 尚未产生有效盘点结果 |
| 审核中 | 需人工审核的非机房资产已提交必需照片及盘点结果，尚待图片审核；不计入已盘数量 |
| 已盘 | 当前资产责任人完成盘点；需审核照片的资产仅审核通过后进入 |
| 代盘 | 非当前资产责任人完成盘点 |
| 报失 | 用户提交报失并完成二次确认；可继续盘点该资产；报失操作限制见下文。 |

“未执行盘点”表示该资产未纳入本次现场执行范围，不属于盘点结果状态。

同一项目内，资产处于报失状态时禁止重复报失。报失后可继续盘点，当前盘点状态随盘点结果更新，已发生的报失记录须保留。照片审核不通过、资产恢复未盘后，允许再次报失，不因曾经报失而禁止该操作。

##### 4.1.3.2 复盘抽样

本节仅适用于复盘项目。全盘时对筛选范围全量复核，不执行比例随机抽取；百分比方式按下表抽样，并展示两项可选净值必盘条件。

| 步骤 | 规则 |
|---|---|
| 确定范围 | 取关联初盘的执行盘点快照，先按本页面条件缩小范围。 |
| 取必盘资产 | 抽样方式为百分比时，在当前范围内取已标记必盘的资产，以及净值大于指定金额或净值排名命中的资产；取并集并按标签号去重。 |
| 抽取剩余资产 | 按资产卡片抽样，每个标签号为一个抽样单位；必盘资产之外的卡片条数乘基本信息中的比例，四舍五入后随机抽取对应条数的整张卡片；必盘资产不占用剩余资产的抽样数量。 |
| 未设置必盘条件 | 两项净值条件均留空且没有必盘标记时，对全部当前范围按比例随机抽取。 |

#### 4.1.5 生成快照

点击“生成快照”后：

1. 将盘点范围明细中的资产汇总为项目快照。范围筛选分录为空时沿用项目保存时生成的范围资产；用户手工从范围资产明细移除的资产不因重新生成或二次保存而回到范围内。
2. 根据物料的“是否需盘点”属性拆分执行盘点和未执行盘点资产。
3. 将本项目盘点范围筛选结果与执行/未执行清单按资产标签号比对，差异放入未包含资产清单。
4. 非机房资产根据人工图片规则标记“是否需上传图片”；机房资产按NO/MIS无法自动扫描标识确定需照片要求，具体见4.8.1。
5. 更新项目快照生成日期和项目状态。

快照生成后，资产范围和快照时的资产基础信息保持不变。盘点状态、盘点人、盘点日期、盘点备注和照片属于后续盘点结果，可以继续更新。

快照页面包含四个页签：

1. 快照清单统计。
2. 执行盘点资产清单。
3. 未执行盘点资产清单。
4. 未包含资产清单。

##### 4.1.6.1 清单转移

转移用于调整同一盘点项目快照中的资产清单归属。转移至未执行表示该资产不进入执行盘点清单，转移至执行表示纳入执行盘点清单；此操作不变更资产卡片的责任人、地点或使用状态，也不代表资产已盘或报失。

| 来源清单 | 可转移的目标清单 | 完成结果 |
|---|---|---|
| 执行盘点资产清单 | 未执行盘点资产清单 | 从执行清单移除，加入未执行清单。 |
| 未执行盘点资产清单 | 执行盘点资产清单 | 从未执行清单移除，加入执行清单。 |
| 未包含资产清单 | 执行盘点或未执行盘点资产清单 | 选择目标后，从未包含清单移除，加入目标清单，纳入项目快照。 |

| 操作入口 | 处理范围 | 交互及结果 |
|---|---|---|
| 批量转移 | 当前来源清单中勾选的资产 | 支持单选或多选；未勾选时提示先选择资产，不执行转移。 |
| 批量导入转移 | 导入文件中的资产标签号所匹配的当前来源清单资产 | 提供模板下载，模板仅含“资产标签号”列；导入用于指定已有资产，不新建资产。读取首个工作表，支持xlsx、xls、csv。执行/未执行清单的目标固定为对方清单；未包含清单须选择目标。 |

转移按上表启动前条件及第2章权限控制；启动后禁止通过上述两种方式调整范围，项目关闭后禁止转移。分批启动时的界面判定见6.5。

导入先校验整份文件：表头必须为“资产标签号”，空行忽略；非空明细须填写标签号，不得重复，不得包含额外非空列，所有标签号必须属于当前来源清单。表头错误、无有效明细、重复或不属于来源清单时提示对应原因及错误行，整批不转移；用户修正后重新导入。

成功后资产只保留在目标清单中一条记录，刷新来源、目标清单及快照统计，提示实际转移数量；执行与未执行之间转移不改变盘点资产总量，从未包含转入时增加相应清单及总量。保留资产快照信息，不因此改变盘点结果；后续生成计划按调整后的清单分配资产。失败时保留原清单归属，不产生部分转移结果。

上传盘点结果用于更新盘点结论，与本节导入标签号调整清单归属是两项功能；上传盘点结果还须校验第2章规定的人员权限。

| NO扫描同步步骤 | 规则 |
|---|---|
| 匹配 | 按序列号匹配资产。 |
| 匹配失败 | 阻止本批导入，提供全部未匹配记录下载。 |

| 盘点执行人 | 人员选择弹窗或只读人员 | 生成时可暂空，启动前每项资产必须有执行人；机房初盘只读 | 机房初盘由每项资产责任人自动带出；复盘仅可选择财务人员；其他按4.2.3处理。 |

确认生成时，以最终资产明细决定计划的资产范围，并使资产归入其所属盘点范围对应的计划；计划范围不能只根据某条查询条件的名称确定。各计划保存自身资产清单和对应人员配置，同一资产在本项目只能归入一条计划。自定义生成中同一范围跨子公司的拆分边界见6.5，不直接套用默认生成分组。

#### 4.2.3 人员带出与修改

##### 4.2.3.1 自动带出

以下默认规则按资产逐项带出；同一计划内不同资产可对应不同人员，不能把其中一项资产的人员当作全计划人员。

| 生成场景及范围 | 盘点监督人 | 盘点执行人 |
|---|---|---|
| 默认生成的员工初盘 | 资产责任人所属一级部门对应的部门助理 | 该资产责任人 |
| 默认生成的库房初盘 | 资产所在位置对应的库管员 | 资产所在位置对应的库管员 |
| 默认生成的公共初盘 | 资产所在位置对应的库管员 | 资产所在位置对应的库管员 |
| 机房初盘，适用于其全部计划 | 不设置 | 该资产责任人，系统自动带出，不提供手工配置或修改 |
| 复盘 | 从财务人员中配置；财务监督人是复盘项目审批财务节点，固定徐博 | 从财务人员中配置 |

自定义员工初盘首次生成时，监督人及执行人的逐资产默认值按上表处理；自定义范围填写的人员是否覆盖该默认值，见6.5。生成后修改草稿计划人员按4.2.3.2处理。库房、公共未填写人员时取默认库管员还是保留空值，以及抽盘默认人员规则，见6.5。启动前仍校验每项资产执行人非空。库管员的地点关联依据和一位置多人员、无人时的处理见6.5。

##### 4.2.3.2 修改与同步

| 修改入口 | 条件 | 影响范围 |
|---|---|---|
| 计划人员配置 | 计划为草稿且项目未关闭 | 修改当前计划某项监督人或执行人配置后，把该值写入当前计划全部资产的对应“盘点监督人”或“盘点执行人”；不改资产责任人，不影响其他计划，也不改变已经记录的实际盘点人。 |

| 计划或资产人员导入 | 与手工配置相同的状态和人员限制 | 按模板对应的计划或资产更新，不能通过导入绕过锁定。 |

##### 4.2.4.3 盘点备注与其他说明

“盘点备注”汇集本次盘点业务填写的说明，不能从资产备注、人员名称或照片要求推导。

| 来源操作 | 写入规则 |
|---|---|
| 员工提交盘点备注 | 将本次填写的盘点备注保存为盘点备注；对应填写入口及与原说明的更新方式见6.5。 |
| 提交报失 | 将填写并确认的报失原因写入盘点备注。 |
| 报失后重新盘点 | 保留已写入的报失原因；同时保留报失过程记录，历史入口及字段见6.5。 |
| 人工导入盘点结果 | 若确认后的模板包含盘点备注，按其列定义写入；准确列名、空值覆盖及与报失原因合并方式见6.5。 |

资产备注取资产卡片，使用说明取资产使用信息；未盘说明由PC维护未盘原因。四者按各自业务用途保存和展示，不得互相覆盖，也不能把“未盘说明”当作已完成盘点的结论。普通扫码、报失、导入完成后，项目清单、计划清单、进度及导出读取同一资产的有效结果。

#### 4.2.7 启动计划

支持单选、多选和分批启动。所有执行资产都已进入计划是“分配完整性”，只启动本次所选计划是“启动批次”，两者分别校验。例如100项执行资产已分配给A、B两个计划，可先启动A，B保留草稿以后启动；若仍有资产未分配到任何计划，则先补生成计划。

启动前依次校验：

1. 项目未关闭，本次已选择计划且所选计划均为草稿。
2. 本项目所有执行盘点资产均已归入计划；有未分配资产时，提示其数量，允许转入默认补生成或自定义创建，补完后重新选择并启动。
3. 本次所选计划开始、结束日期完整，结束日不得早于开始日；初盘、抽盘、复盘计划均可跨天。
4. 本次所选计划的每项资产均有盘点执行人；复盘监督人（已配置时）和执行人均具有财务资格，机房初盘执行人由资产责任人带出；监督人非必填。

| 操作 | 展示、可用条件及结果 |
|---|---|
| 启动盘点计划 | 始终显示；未选择、含非草稿计划、项目关闭或无可启动计划时置灰。校验通过后仅本次所选计划进入盘点中，其他草稿计划保持；项目进入盘点中。 |
| 删除盘点计划 | 始终显示；未选择、含非草稿计划或项目关闭时置灰，只处理所选草稿计划。 |

启动后锁定本次所选计划及关联资产的人员、日期和分配关系，已经启动或关闭的计划不能再次启动。未启动草稿计划仍可按自身状态维护；分批启动后快照清单界面的判定仍见6.5。

初盘、抽盘、复盘计划均允许在计划开始日之后启动；不会仅因当前日期晚于开始日而阻止。复盘员工准备通知另按6.1安排，不能据该通知规则限制其他项目类型启动。

### 4.8 照片上传与审核

#### 4.8.1 移动端拍照

照片必传规则仅适用于移动端普通扫码及快速扫描；扫码枪和人工导入结果无需补传照片或进行人工照片审核。普通扫码成功后的详情或快扫查看/补拍页，非机房按快照“是否需上传图片”标记展示照片区域，机房按NO/MIS“是否无法自动扫描”标记展示；直接查看详情不展示拍照上传区域。移动端只允许拍照，不允许从相册选择；项目关闭后不再拍摄或替换照片。

机房照片要求由NO/MIS提供的“是否无法自动扫描”标识确定；无法自动扫描的资产需上传照片，不能仅因机房照片免审核而免除照片要求。机房初盘使用该标识确定需照片资产，不按人工图片规则随机抽取。

员工、公共、库房资产上传必需照片并提交成功后，盘点结果和照片一起保存，资产状态变为审核中；在审核结论出现前不计入已盘，不能重复提交。机房资产上传所需照片后不进入人工图片审核，直接按盘点人身份更新已盘或代盘。无需上传照片的资产按普通扫码结果更新。

普通扫码与快速扫描补拍均只能实时调用相机拍摄，不允许选择相册或本地已有图片。未授予相机权限、取消拍摄或拍摄失败均不计为照片已提交；须完成拍摄后才能通过对应必传照片校验。此限制不适用于4.8.2独立的PC机房项目照片上传。

| 重新审核 | 员工重传被驳回照片后，在未关闭项目进入新一轮待审核；不能直接把旧不通过结论改成通过。 |

审核操作：

1. 审核通过：审核状态为审核通过；实际盘点人与当前资产责任人一致时，资产从审核中变为已盘，否则变为代盘；审核记录锁定。
2. 审核不通过：审核状态为审核不通过，资产从审核中恢复未盘，员工盘点待办重新出现，可再次拍照提交或报失；即使该资产曾经报失，也恢复报失入口，同时向员工发送驳回通知。

#### 4.10.2 逐计划提交与会签

PC端“复盘项目→进入计划”列表中，每条计划的操作栏提供【提交计划审批】及已提交后的【查看计划审批】入口，不单列计划审批列。一次提交一条计划，其他计划可继续执行或独立审批。

| 校验项 | 规则与处理 |
|---|---|
| 项目及计划状态 | 项目未关闭，本计划为盘点中；审核中或已审核的计划不重复提交。驳回后的计划回到盘点中，可处理后重新提交。 |

| 比例 | 仅百分比抽样时，按本计划已盘数量÷本计划复盘资产总量计算，与项目基本信息中的比例比较；不足时提示本计划未达到审核比例，允许继续提交。零资产计划处理见6.5。 |

| 监督人同意 | 保存该监督人的结论；本次全部会签人均同意后，本计划与其审批记录更新已审核。 |
| 监督人驳回 | 本计划审批记已驳回，计划回盘点中，通知项目负责人处理；其他已通过计划的结论保留。 |
| 计划审批全部通过 | 立即清除本计划盘点执行人的狐小e待办，只处理本计划，不等待项目审批或关闭，也不清除其他计划、项目的待办。 |

#### 4.10.3 复盘项目提交与审批

计划页提供【提交项目审批】及【查看项目审批】。提交项目前，项目须未关闭且本项目全部计划均审批通过；存在草稿、盘点中、审核中或被驳回的计划时，指出对应计划并阻止项目提交。零计划项目是否可提交见6.5。

| 操作或环节 | 业务结果 |
|---|---|
| 提交项目审批 | 保存整个复盘项目的审批记录，项目进入审核中，交徐博审批。 |
| 徐博同意 | 项目审批记录及复盘项目更新已审核，保留各计划已通过结论；通知项目负责人。 |
| 徐博驳回 | 项目审批记录记已驳回，项目回盘点中；各计划已通过结论及已清除的执行人待办保持，不要求各计划重新审批。项目处理后可再次提交徐博。 |

同意、驳回、重新提交均保留所属计划或项目的历次记录和审批意见。提交人角色、代理及意见要求见6.5。复盘结果以审批通过作为确认依据，不额外增加现场核实凭证要求；照片规则及提交前校验仍按本PRD执行。计划及项目审批提交、审批结束均不发送邮件。

### 4.11 项目关闭

列表选中一条项目后可点击【关闭项目】；详情页针对当前项目执行。项目未关闭且没有未结束的审核时，校验通过后进入关闭确认。

| 校验对象 | 规则与处理 |
|---|---|
| 选择数量 | 列表必须且只能选中一条项目，否则提示选择一个需要关闭的项目。 |
| 项目状态 | 任一未关闭状态均允许关闭，已关闭时阻止重复操作。 |
| 未结束审核 | 存在待审核的照片、审核中的复盘计划或复盘项目审批时阻止关闭，指出对应记录；审核通过和驳回均属于已结束。待变更池建议不属于审核，不阻止关闭。 |
| 计划及盘点完成情况 | 零计划、草稿计划、未启动计划、未盘资产和待提交结果均不阻止关闭；复盘不要求所有计划先审批通过。 |
| 关闭确认 | 校验通过后弹出确认，展示未盘数量和待提交数量；确认时再次校验项目状态和未结束审核。 |
| 机房初盘自动关闭 | 数量进度达到100%时自动关闭；同时支持按上述条件手动关闭。 |

关闭确认弹窗展示字段：

| 字段 | 展示方式 | 格式 | 数据来源 | 字段交互及说明 |
|---|---|---|---|---|
| 未盘数量 | 整数展示 | 整数 | 当前项目盘点结果 | 应盘数量减已盘数量，包含报失和审核中资产 |
| 待提交数量 | 整数展示 | 整数 | 当前项目待提交结果 | 统计的具体对象及计算规则未定义 |

关闭后项目更新为盘点关闭、关联计划关闭，停止所有盘点；对应待办的清除及结果保留、历史、通知见第6章。
