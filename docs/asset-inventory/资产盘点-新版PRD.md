# 资产盘点 PRD

## 1 背景

资产盘点用于在指定盘点期间，对企业资产进行范围确认、清单冻结、任务分配、现场盘点、结果审核和报告输出。

一次完整盘点包括：

`创建盘点项目 → 确定盘点范围 → 生成快照 → 生成盘点计划 → 启动盘点任务 → 现场盘点 → 图片审核/复盘审批 → 关闭项目 → 导出报告`

PC 端负责盘点项目和结果管理，移动端负责盘点执行。

### 1.1 业务范围

#### 1.1.1 项目类型

| 项目类型 | 业务含义 | 项目编号前缀 |
|---|---|---|
| 初盘 | 形成指定盘点期间的首次盘点结果 | CP |
| 抽盘 | 对初盘执行范围进行全量或比例抽查 | DCP |
| 复盘 | 对初盘执行范围进行复核并提交审批 | RCP |

#### 1.1.2 盘点范围

| 盘点范围 | 资产范围规则 |
|---|---|
| 库房 | 资产责任人名称包含“库房管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 公共 | 资产责任人名称包含“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 机房 | 资产大类属于服务器、网络设备；电话指定小类除外 |
| 员工 | 资产责任人名称不包含“库房管理员”“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |

手动创建的初盘、抽盘项目仅纳入非机房资产。年度机房初盘由系统独立创建。财务创建复盘项目时，可以关联已关闭的机房初盘项目，并从该初盘执行盘点快照带入机房资产；机房与非机房资产分别建项。

#### 1.1.3 盘点方式

盘点项目按盘点范围分别配置盘点方式：

1. 狐小e扫码。
2. 狐小e快速扫描资产标签号。
3. 扫码枪扫码。
4. 人工上传盘点结果。

每个盘点范围至少选择一种盘点方式。未选择时，保存和提交均提示具体盘点范围未配置盘点方式。

## 2 权限

权限按财务公司和板块控制。

| 角色 | 可执行操作 |
|---|---|
| 盘点负责人 | 创建、编辑、查看盘点项目；维护范围；生成快照和计划；导入、审核、调整盘点结果；查看进度和报告 |
| 盘点监督人 | 查看对应计划进度，接收催盘和异常通知 |
| 盘点执行人 | 执行分配给自己的移动端、扫码枪或人工导入盘点任务 |
| 财务人员 | 接收初盘项目关闭通知；发起复盘项目；执行复盘计划 |
| 复盘项目创建人 | 发起、修改并重新提交本复盘项目的位置变更申请 |
| 图片审核人 | 审核需要上传照片的盘点结果 |
| 复盘审批人 | 审核复盘项目结果；财务经理徐博负责财务审批节点 |

手动创建项目时，ES-孙志强仅可创建初盘和抽盘；财务-冯丽婷仅可创建复盘。项目类型选项按当前操作人权限展示，保存时仍须校验创建权限。年度机房初盘由系统创建。

已启动的盘点计划只向对应的执行人、监督人和项目负责人开放。没有有效盘点任务的用户不能进入移动端盘点。

## 3 通用规则

### 3.1 业务对象

| 对象 | 说明 |
|---|---|
| 盘点项目 | 盘点业务的主对象，定义期间、类型、范围和规则 |
| 盘点范围明细 | 根据项目规则筛选出的资产范围，快照前可以调整 |
| 快照 | 固定项目盘点范围和生成时资产信息的结果 |
| 盘点计划 | 将执行盘点资产分配给具体人员和时间的任务对象 |
| 计划资产清单 | 计划下的资产及其盘点状态、盘点人、盘点日期和盘点备注 |
| 图片审核 | 对需要上传照片的盘点资产进行审核的对象 |
| 待确认位置变更 | 复盘扫描中填写的新地点与资产台账地点不同，等待 PC 端核对和发起审批的记录 |
| 项目进度 | 按范围和组织汇总盘点结果的查询视图 |
| 盘点报告 | 按财务公司、板块和资产分类输出盘点结果 |

资产标签号是盘点项目、快照、计划、移动端结果和图片审核记录之间的关联标识。

### 3.2 项目关联

| 事项 | 规则 |
|---|---|
| 抽盘关联 | 关联一个已关闭且未被其他抽盘项目关联的初盘项目。 |
| 复盘关联 | 必须且只能关联一个已关闭且未被其他复盘项目关联的初盘项目。 |
| 期间 | 关联初盘项目的年度、季度或月份自动带入当前项目。 |
| 资产范围 | 机房和非机房分别建立初盘项目；后续抽盘或复盘只关联其中一个初盘，按关联初盘的资产范围确定审批流程。 |
| 复盘人员 | 由财务人员发起，盘点执行人仅限财务人员。 |

### 3.3 状态规则

#### 3.3.1 盘点项目状态

| 状态 | 业务含义 | 可执行操作 |
|---|---|---|
| 草稿 | 项目尚未生成固定快照 | 编辑、保存、删除 |
| 快照生成 | 项目范围已经冻结 | 查看清单、调整清单、生成计划 |
| 生成盘点计划 | 项目已进入计划配置阶段 | 编辑、补充、启动计划 |
| 盘点中 | 至少一个计划已经启动 | 执行盘点、查看进度、图片审核 |
| 盘点关闭 | 盘点结果已经结束 | 查看历史、导出报告 |

#### 3.3.2 盘点计划状态

| 状态 | 业务含义 |
|---|---|
| 草稿 | 计划日期和人员可以维护，尚未开放任务 |
| 盘点中 | 任务已开放，计划和资产清单的分配信息不可修改 |
| 审核中 | 复盘计划已提交审批 |
| 已审核 | 复盘计划审批通过 |
| 关闭 | 项目关闭时同步关闭关联计划 |

#### 3.3.3 资产盘点状态

| 状态 | 业务含义 |
|---|---|
| 未盘 | 尚未产生有效盘点结果 |
| 审核中 | 员工按图片规则上传必需照片并提交盘点，尚待图片审核；不计入已盘数量 |
| 已盘 | 当前资产责任人完成盘点；需审核照片的资产仅审核通过后进入 |
| 代盘 | 非当前资产责任人完成盘点 |
| 报失 | 用户提交报失并完成二次确认；仍可继续盘点该资产，不可重复报失 |

“未执行盘点”表示该资产未纳入本次现场执行范围，不属于盘点结果状态。

同一项目、同一资产只允许报失一次。报失后继续盘点会改变当前盘点状态，但已报失记录须保留；若上传照片后审核不通过、当前状态恢复为未盘，仍不得再次报失。

#### 4.1.4 图片上传规则

#### 4.1.6 生成快照

点击“生成快照”后：

1. 将盘点范围明细中的资产汇总为项目快照。范围筛选分录为空时沿用项目保存时生成的范围资产；用户手工从范围资产明细移除的资产不因重新生成或二次保存而回到范围内。
2. 根据物料的“是否需盘点”属性拆分执行盘点和未执行盘点资产。
3. 将项目规则过滤结果与执行/未执行清单按资产标签号比对，差异放入未包含资产清单。
4. 根据图片上传规则标记“是否需上传图片”。
5. 更新项目快照生成日期和项目状态。

快照生成后，资产范围和快照时的资产基础信息保持不变。盘点状态、盘点人、盘点日期、盘点备注和照片属于后续盘点结果，可以继续更新。

快照页面包含四个页签：

1. 快照清单统计。
2. 执行盘点资产清单。
3. 未执行盘点资产清单。
4. 未包含资产清单。

### 4.8 照片上传与审核

#### 4.8.1 移动端拍照

照片必传规则仅适用于移动端普通扫码及快速扫描；扫码枪和人工导入结果无需补传照片或进行人工照片审核。只有扫码成功后的资产详情且图片规则标记“是否需上传图片”时展示拍照区域；直接打开资产查看详情不展示上传区域。移动端只允许拍照，不允许从相册选择。

## 5 校验

| 校验对象 | 触发时机 | 条件与处理 |
|---|---|---|
| 创建权限 | 保存项目 | 项目类型须在当前操作人允许范围内；无权限不能创建。 |
| 项目日期 | 创建、编辑项目 | 结束日期不得早于开始日期；复盘项目可跨天。 |
| 计划日期 | 修改、启动复盘计划 | 每条复盘计划开始结束必须同日，不同计划可安排不同日期。 |
| 盘点方式 | 保存、提交项目 | 每个盘点范围至少一种方式，缺失时提示具体范围并阻止操作。 |
| 计划分配 | 启动计划 | 所有执行资产先分配计划；日期齐全，每项资产执行人有值；监督人非必填。 |
| 复盘执行人 | 保存、启动计划 | 只能选择财务人员。 |
| 任务及资产范围 | 扫码、提交、导入结果 | 仅更新当前项目、当前计划范围内资产；范围外资产不能处理。 |
| 资产状态 | 扫码提交 | 已盘、代盘、审核中禁止重复提交；报失可继续盘点。 |
| 必传照片 | 普通扫码、快扫提交 | 按快照标记校验必需照片，缺失不能记成功。 |
| 重复报失 | 报失确认 | 同项目同资产只允许一次；重盘或审核驳回后仍保留报失历史，禁止再次报失。 |
| 位置变更 | 提交位置申请 | 校验整批资产范围、实际地点变更、完整有效地点及照片审核前置条件；失败不产生部分结果。 |
| 盘点报告 | 生成、查看或导出报告 | 项目须已关闭，未关闭时阻止操作并提示先关闭项目。 |
| 关闭后写入 | 修改、补录或提交 | 关闭项目及关联对象只读，禁止新增、修改、补录和重新提交。 |

## 6 后续操作 / 业务结果 / 补充说明

### 6.1 计划与移动待办通知

| 触发条件 | 对象与处理 |
|---|---|
| 计划启动 | 非机房计划向狐小e、Myfamily及资产系统发送盘点任务通知，通知已配置执行人和监督人；机房计划仅通知NO/MIS在盘点执行期间推送扫描结果。 |
| 发送盘点通知 | 提供入口，非机房向计划执行人、监督人发送消息和待办；机房仅通知NO/MIS推送扫描结果。 |
| 日常提醒 | 存在未完成任务时，非机房每天提醒相关执行人；机房仅通知NO/MIS推送扫描结果。 |
| 催盘 | 非机房向所选分录未盘资产对应的执行人、已配置监督人发送消息和邮件，邮件附所选未盘资产清单；机房仅通知NO/MIS推送扫描结果。 |
| 复盘准备通知 | 非机房以每条计划自身开始日安排，在“启动当天”和“开始日前三天”中较晚的一天；晚于开始日启动时，启动当天发送通知，经服务号通知员工资产责任人提前准备资产；与财务执行人分开，同一计划同一员工仅发一次。 |
| 同项目多计划 | 按最早启动计划时间发送一条项目通知；仍有已启动未完成计划时保持待办，所有已启动计划完成后转已办。 |
| 全部完成后新增计划 | 按新计划启动时间向新计划配置的执行人、监督人重新发通知，人员与上一轮是否相同均适用；机房通知对象为NO/MIS。 |
