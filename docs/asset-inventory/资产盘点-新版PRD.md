# 资产盘点 PRD

## 1. 背景

资产盘点用于在指定盘点期间，对企业资产进行范围确认、清单冻结、任务分配、现场盘点、结果审核和报告输出。

一次完整盘点包括：

`创建盘点项目 → 确定盘点范围 → 生成快照 → 生成盘点计划 → 启动盘点任务 → 现场盘点 → 图片审核/复盘审批 → 关闭项目 → 导出报告`

PC 端负责盘点项目和结果管理，移动端负责盘点执行。

### 业务范围

#### 项目类型

| 项目类型 | 业务含义 | 项目编号前缀 |
|---|---|---|
| 初盘 | 形成指定盘点期间的首次盘点结果 | CP |
| 抽盘 | 对初盘执行范围进行全量或比例抽查 | DCP |
| 复盘 | 对初盘执行范围进行复核并提交审批 | RCP |

抽盘项目必须关联一个已关闭且未被其他抽盘项目关联的初盘项目。复盘项目必须且只能关联一个已关闭且未被其他复盘项目关联的初盘项目。关联初盘项目的年度、季度或月份自动带入当前项目。复盘项目由财务人员发起，复盘项目的盘点执行人仅限财务人员。机房资产和非机房资产不得纳入同一个初盘项目；机房初盘与非机房初盘分别建立，后续抽盘或复盘只关联其中一个初盘项目，并按该初盘的资产范围确定审批流程。

#### 盘点范围

| 盘点范围 | 资产范围规则 |
|---|---|
| 库房 | 资产责任人名称包含“库房管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 公共 | 资产责任人名称包含“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |
| 机房 | 资产大类属于服务器、网络设备；电话指定小类除外 |
| 员工 | 资产责任人名称不包含“库房管理员”“公共管理员”；排除服务器、网络设备大类，电话指定小类除外 |

手动创建的盘点项目不能选择机房资产。年度机房初盘由系统独立创建，不得与非机房资产合并。

#### 盘点方式

盘点项目按盘点范围分别配置盘点方式：

1. 狐小e扫码。
2. 狐小e快速扫描资产标签号。
3. 扫码枪扫码。
4. 人工上传盘点结果。

每个盘点范围至少选择一种盘点方式。未选择时，保存和提交均提示具体盘点范围未配置盘点方式。

## 2. 权限

权限按财务公司和板块控制。

| 角色 | 可执行操作 |
|---|---|
| 盘点负责人 | 创建、编辑、查看盘点项目；维护范围；生成快照和计划；导入、审核、调整盘点结果；查看进度和报告 |
| 计划负责人 | 维护盘点计划信息，协调计划启动和执行 |
| 盘点监督人 | 查看对应计划进度，接收催盘和异常通知 |
| 盘点执行人 | 执行分配给自己的移动端、扫码枪或人工导入盘点任务 |
| 财务人员 | 接收初盘项目关闭通知；发起复盘项目；执行复盘计划 |
| 图片审核人 | 审核需要上传照片的盘点结果 |
| 复盘审批人 | 审核复盘项目结果；财务经理徐博负责财务审批节点 |

手动创建项目时，ES-孙志强仅可创建初盘和抽盘；财务-冯丽婷仅可创建复盘。项目类型选项按当前操作人权限展示，保存时仍须校验创建权限。年度机房初盘继续由系统创建。

已启动的盘点计划只向对应的执行人、监督人和项目负责人开放。没有有效盘点任务的用户不能进入移动端盘点。

## 3. 通用规则

### 业务对象

| 对象 | 说明 |
|---|---|
| 盘点项目 | 盘点业务的主对象，定义期间、类型、范围和规则 |
| 盘点范围明细 | 根据项目规则筛选出的资产范围，快照前可以调整 |
| 快照 | 固定项目盘点范围和生成时资产信息的结果 |
| 盘点计划 | 将执行盘点资产分配给具体人员和时间的任务对象 |
| 计划资产清单 | 计划下的资产及其盘点状态、盘点人、盘点日期和盘点备注 |
| 图片审核 | 对需要上传照片的盘点资产进行审核的对象 |
| 待确认位置变更 | 复盘扫描中填写的新地点与资产台账地点不同，等待 PC 端核对和发起审批的记录 |
| 项目进度 | 按范围和组织汇总盘点结果的查询视图 |
| 盘点报告 | 按财务公司、板块和资产分类输出盘点结果 |

资产标签号是盘点项目、快照、计划、移动端结果和图片审核记录之间的关联标识。

### 状态规则

#### 盘点项目状态

| 状态 | 业务含义 | 可执行操作 |
|---|---|---|
| 草稿 | 项目尚未生成固定快照 | 编辑、保存、删除 |
| 快照生成 | 项目范围已经冻结 | 查看清单、调整清单、生成计划 |
| 生成盘点计划 | 项目已进入计划配置阶段 | 编辑、补充、启动计划 |
| 盘点中 | 至少一个计划已经启动 | 执行盘点、查看进度、图片审核 |
| 盘点关闭 | 盘点结果已经结束 | 查看历史、导出报告 |

#### 盘点计划状态

| 状态 | 业务含义 |
|---|---|
| 草稿 | 计划日期和人员可以维护，尚未开放任务 |
| 盘点中 | 任务已开放，计划和资产清单的分配信息不可修改 |
| 审核中 | 复盘计划已提交审批 |
| 已审核 | 复盘计划审批通过 |
| 关闭 | 项目关闭时同步关闭关联计划 |

#### 资产盘点状态

| 状态 | 业务含义 |
|---|---|
| 未盘 | 尚未产生有效盘点结果 |
| 审核中 | 员工按图片规则上传必需照片并提交盘点，尚待图片审核；不计入已盘数量 |
| 已盘 | 当前资产责任人完成盘点；需审核照片的资产仅审核通过后进入 |
| 代盘 | 非当前资产责任人完成盘点 |
| 报失 | 用户提交报失并完成二次确认；仍可继续盘点该资产，不可重复报失 |
| 盘亏 | 后台或财务结果确认资产盘亏 |

“未执行盘点”表示该资产未纳入本次现场执行范围，不属于盘点结果状态。

同一项目、同一资产只允许报失一次。报失后继续盘点会改变当前盘点状态，但已报失记录须保留；若上传照片后审核不通过、当前状态恢复为未盘，仍不得再次报失。

## 4. 页面字段及交互

### PC 端盘点项目

#### 项目列表

有折叠按钮和没有折叠按钮的同层级项目名称保持文字对齐；关联子项目保留层级缩进。

##### 查询条件

| 字段 | 查询规则 |
|---|---|
| 项目编号 | 包含匹配 |
| 项目名称 | 包含匹配 |
| 项目状态 | 按状态筛选 |
| 项目负责人 | 按人员筛选 |
| 盘点开始时间 | 一个日期区间条件，按项目的盘点开始时间筛选 |
| 项目类型 | 初盘 / 抽盘 / 复盘 |
| 创建时间 | 一个日期区间条件，按项目创建时间筛选 |

##### 列表字段

项目名称、项目编号、项目类型、项目状态、盘点开始时间、盘点结束时间、执行盘点数量、资产总量、项目负责人、创建时间。项目名称置于第一列；初盘与其关联的抽盘、复盘在项目名称单元格处展开或折叠，展开后显示子项目名称，项目名称仍可进入该项目详情。不展示“关联项目”列。

项目状态为草稿时提供删除入口。符合关闭条件的项目可在项目列表或项目详情内关闭；机房初盘项目由系统自动关闭，不提供手动关闭操作。项目已生成计划后提供“进入计划”；项目已启动后提供“查看进度”；存在图片审核记录时提供“图片审核”。

#### 创建和编辑项目

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 项目编号 | 只读文本 | 是 | 系统自动生成 |
| 项目名称 | 输入框 | 是 | 默认“期间-盘点类型”，允许修改 |
| 项目类型 | 单选 | 是 | 初盘 / 抽盘 / 复盘 |
| 盘点开始时间 | 日期选择 | 是 | 盘点开始日期 |
| 盘点结束时间 | 日期选择 | 是 | 初盘、抽盘不得早于开始日期；复盘执行期间为1天，结束日期必须与开始日期相同，修改开始日期时同步更新结束日期 |
| 盘点类型 | 单选 | 是 | 年度 / 季度 / 月度 |
| 盘点期间 | 联动选择 | 是 | 人工创建的年度项目展示当年四个季度，格式为“2026年Q2”；系统创建的机房年度初盘仅展示当年年份，如“2026年”；季度展示季度选项；月度展示去年12月至来年1月，格式为“2025年12月”“2026年1月”至“2027年1月”，年份随当前年度变化 |
| 初盘项目 | 项目选择 | 抽盘/复盘必填 | 只能选择符合关联条件的初盘项目 |
| 抽样方式 | 单选 | 抽盘/复盘必填 | 全盘 / 百分比 |
| 比例 | 数字输入 | 条件必填 | 抽样方式为百分比时显示，范围0～100；复盘先取必盘资产，再从剩余范围随机抽样 |
| 净值大于多少元必盘 | 数字输入 | 非必填 | 仅复盘且抽样方式为百分比时显示；当前盘点范围内净值严格大于该金额的资产必盘，等于金额不命中 |
| 净值前多少百分比必盘 | 数字输入 | 非必填 | 仅复盘且抽样方式为百分比时显示；按当前盘点范围资产净值降序取数量前X%，向上取整；净值相同按标签号排序；取值1～100 |
| 盘点说明 | 多行输入 | 否 | 最多150字 |
| 快照生成日期 | 只读文本 | 否 | 每次生成快照时自动更新 |

复盘项目仅允许财务人员创建。手动创建的初盘、抽盘和复盘项目均不得选择机房资产；机房初盘只能由系统按年度规则创建。

盘点范围明细不展示启用开始日期、启用结束日期。项目详情中，初盘不展示“初盘项目”“抽样方式”“比例”；抽盘和复盘按适用规则展示。

项目编号格式：

- 初盘：`CP-年月日-四位流水号`。
- 抽盘：`DCP-年月日-四位流水号`。
- 复盘：`RCP-年月日-四位流水号`。

#### 盘点规则

#### 规则字段

盘点公司、City、Building、资产类别、盘点范围和盘点方式。

盘点公司按子公司维度选择；选择范围以用户可管理的子公司为准。账套是独立字段，按已确认的公司与账套对应关系带出，不把子公司名称直接作为账套值。

#### 图片上传规则

项目提供“是否上传图片”开关。开启后，按盘点范围配置图片规则。

图片规则字段：资产责任人职级、部门、资产类别、资产状态、盘点组织、City、Building、Floor、上传百分比。

1. 默认生成员工、库房、公共、机房四条规则。
2. 每条规则可以新增或删除。
3. 上传百分比为100%时，符合条件的资产全部要求上传。
4. 上传百分比小于100%时，在符合条件的资产中按比例随机抽取。
5. 开启图片上传后，上述八项筛选条件默认均为空值，空值表示不筛选；各项支持多选，同一项内任一值匹配，不同项之间同时满足。清空已选值恢复不筛选。

#### 盘点范围明细

保存项目后生成盘点范围明细。

初盘项目按照盘点组织、资产状态、City、Building、资产类别和盘点范围筛选资产。手动创建的初盘只纳入非机房资产。年度初盘以当年7月1日00:00:00之前启用的资产为范围，截止时点可配置；季度和月度初盘按各自期间规则筛选。生成快照前，范围资产字段随资产卡片变动更新。系统每年7月1日自动创建并启动一个年度机房初盘项目，范围仅包含符合机房规则的资产，不设置盘点监督人；该项目在数量进度达到100%时自动关闭。机房初盘与非机房初盘分别建项。

抽盘、复盘以关联初盘项目生成快照时的执行盘点资产清单作为基础范围。

范围筛选条件：子公司、部门、资产类别、资产状态、仓库、板块、City、Building、Floor、资产责任人、责任人职级、启用日期区间。子公司通过下拉框选择，部门作为独立条件筛选。除日期区间和比例、净值前百分比等数值参数外，各枚举筛选条件均支持多选；同一条件取并集，不同条件取交集，空值表示不筛选。选择子公司匹配该子公司资产；同时选择部门时，还须匹配所选部门。复盘另可填写“净值前 X%”（1～100，留空不限制）：在符合其他条件的关联初盘快照执行资产中，按资产净值从大到小排序，取资产数量的前 X%，不足一条时向上取整；净值相同时按资产标签号排序。该条件只缩小盘点范围，与基本信息中的“净值前多少百分比必盘”分别处理。复盘百分比抽样先在当前范围中选出满足金额或净值排名条件的必盘资产，两条件取并集并按标签号去重；随后对剩余资产按基本信息比例随机抽取，数量四舍五入。两项必盘条件均留空时，全部范围按比例随机抽取；必盘资产不占用剩余资产的抽样数量。启用日期起止用于筛选资产卡片的启用日期，不作为盘点范围明细的展示列；查询控件使用普通日期字段宽度，不占满整行。

复盘的本次复盘数量、复盘比例初始分别为关联初盘快照执行资产数量和100%，只读；每次生成查询后以当前纳入的资产数量回写本次复盘数量，并按本次复盘数量除以关联初盘快照执行资产数量计算复盘比例。

点击“生成查询”后，根据当前条件生成一条范围汇总记录。用户可以多次查询并将结果加入盘点范围明细，也可以查看全部或删除全部。

责任人职级来自 PS 系统，实习生和公共分别作为独立选项展示，不合并为一个职级值。资产责任人使用公共人员选择弹窗；责任人职级使用多选下拉框；资产类别使用大类、小类两级树形多选，选择大类匹配其下全部小类，选择小类匹配对应大类下的小类；City 使用带搜索建议的下拉框；子公司使用下拉框。上述查询条件复用公共选择组件，各页面按自身权限和业务范围限定可选数据。

盘点范围资产明细支持按资产标签号、资产责任人、责任人职级查询；三个条件可组合，重置后不筛选。盘点范围资产明细展示公司、部门、资产类别、资产标签号、序列号、资产说明、数量、原值、净值、使用状态、资产责任人、责任人部门、责任人职级、City、Building、Floor、盘点组织、成本中心和启用日期；净值紧接原值。

#### 生成快照

点击“生成快照”后：

1. 将盘点范围明细中的资产汇总为项目快照。范围筛选分录为空时沿用项目保存时生成的范围资产；用户手工从范围资产明细移除的资产不因重新生成或二次保存而回到范围内。
2. 根据物料的“是否需盘点”属性拆分执行盘点和未执行盘点资产。
3. 将项目规则过滤结果与执行/未执行清单按资产标签号比对，差异放入未包含资产清单。
4. 根据图片上传规则标记“是否需上传图片”。
5. 更新项目快照生成日期和项目状态。

快照生成后，资产范围和快照时的资产基础信息保持不变。盘点状态、盘点人、盘点日期、盘点备注和照片属于后续盘点结果，可以继续更新。

快照页面包含四个页签：

1. 快照清单统计。
2. 执行盘点资产清单。
3. 未执行盘点资产清单。
4. 未包含资产清单。

执行盘点资产清单、未执行盘点资产清单、未包含资产清单均支持条件查询和导出。启动前查询条件为资产标签号、资产类别、盘点状态、资产责任人、City、盘点范围。启动后，三个清单均展示资产标签号、资产类别、序列号、成本中心、资产说明、使用状态、资产责任人、责任人职级、责任人部门、盘点执行人、盘点监督人、City、Building、启用日期从、启用日期至、盘点方式、盘点状态、NO状态共18个查询条件。文字条件模糊匹配；人员和枚举条件按所选值匹配，资产类别按大类、小类层级匹配，启用日期按包含起止日期的区间匹配；不同条件取交集，多选同一条件取并集，空值表示不筛选，重置清空查询条件。资产清单的资产类别合并展示为“大类.小类”，不再拆为资产大类和资产小类两列。三个清单的导出按钮统一为【导出】，导出当前页签在当前查询条件下的全部结果，不限于当前分页。快照清单统计展示汇总数据。盘点项目详情底部【返回】返回盘点项目列表，包括创建并生成快照后进入的详情。

三个资产清单的导出字段及顺序一致：计划编号、盘点方式、盘点状态、盘点人、盘点日期、资产标签号、印刷号、序列号、资产类别（大类.小类）、资产说明、数量、原值、EBS原值、净值、使用状态、NO位置、NO状态、备注、使用说明、资产责任人编号、资产责任人、责任人部门、责任人职级、City、Building、Floor、账套、成本中心、启用日期、NO扫描资产标签号、NO扫描序列号、NO扫描型号、NO扫描品牌、NO扫描位置。字段取当前资产及其盘点记录的实际值；无来源的字段不得按名称推断或填入其他字段。

#### 快照清单操作

快照生成后或已生成计划但所有计划尚未启动时，可删除快照；同时撤销该项目下全部草稿计划及资产分配关系，项目回到草稿，恢复生成快照前可编辑的范围及规则。任一计划已启动或已有提交、审核、审批结果时禁止删除，不清除已提交历史。

#### 启动计划

计划明细导出包含“计划信息”和“关联资产清单”两个页签；未勾选计划时导出当前查询下的全部计划及关联资产，勾选后仅导出所选计划及其资产，不限当前分页。关联资产清单增加盘点备注，报失原因保存到盘点备注；资产备注独立保留，报失后继续盘点不删除已保存的报失原因。计划资产清单也支持导出当前查询下的全部资产，并包含盘点备注。计划资产清单查询的启用日期为一个包含起止日的区间，不提供NO状态查询；列表不展示计划负责人，资产类别合并为大类.小类。计划资产清单按草稿、盘点中、审核中、已审核和关闭状态提供对应操作；草稿可导入盘点人员，盘点中可导入未盘说明、扫码枪结果。导入逐行校验计划和资产归属、人员及日期，返回成功与失败条数及失败原因。资产责任人、部门和职级固定取快照时值；现资产责任人和现部门取资产卡片当前值。盘点结果标记狐小e、快速扫描、扫码枪或手工导入来源。

扫码枪每次扫描记录标签，实时统计扫描总次数、成功次数和失败次数；上传时验证计划资产范围及标签有效性，按上传人与资产责任人是否一致分别记为已盘或代盘，记录盘点人和盘点时间，失败标签逐条显示原因。允许清空本次未上传标签。

未关闭复盘项目的PC盘点计划页面提供【发起位置变更】入口，默认汇总本项目扫描时提交的新地点与资产台账地点不同的全部记录；没有扫描变更记录时仍可进入，通过添加资产或批量导入发起。编辑页申请信息展示申请人、申请部门、申请时间、变更类型及变更理由。申请人为点击【发起位置变更】入口的当前用户，只读，申请部门随申请人带出；变更类型固定为位置变更，变更理由必填，最多500个字符。资产明细展示资产标签号、序列号、资产说明、数量、城市、建筑物、楼层/机房、备注，不展示主备关系。资产基础信息只读，地点默认带出移动端拟变更值并支持弹窗选择，备注可编辑且最多150个字符；城市改变清空建筑物和楼层，建筑物改变清空楼层。编辑页不展示原值及diff，未实际变更地点的资产不进入待发起清单。底部为【提交】【返回】；提交后直接进入审批页，审批页展示实际变化字段的原值删除线和新值标记，不变字段只显示当前值。审批记录在资产明细之后，展示提交申请和ES主管审批节点；计划页【位置变更记录】可再次进入已提交申请。备注作为申请明细保存并在审批页只读展示，不改变资产台账备注。编辑页支持【添加资产】【批量导入】【批量编辑位置信息】。添加资产从本复盘项目资产中多选，已加入明细的资产不能重复添加；带出台账基础信息及原地点，用户填写拟变更地点。批量导入按资产标签号匹配本项目资产，读取城市、建筑物、楼层/机房和备注；支持下载模板，单文件不超过20MB。标签号不存在、跨项目、重复、地点不完整或地点无效时逐行指出原因，本批次不保存部分结果。批量编辑作用于所选明细，统一填写完整的新城市、建筑物和楼层/机房；确认后统一回填，不修改基础资产信息。所有新增与编辑明细提交时再次校验地点和资产范围；审批中不允许增删或批量编辑。员工、公共、库房中需要照片审核的资产，必须照片审核通过后才能发起位置变更审批；审核中、审核不通过或未提交照片时可保存拟变更地点，提交申请时指出未通过的资产并阻止整批发起。机房资产不要求照片审核。发起时将编辑页全部实际变更明细整批提交何文 ES 主管审批，记录与对应盘点资产关联；审批中不修改资产台账地点。何文可同意或驳回，驳回时审批意见必填。审批通过后才将批准地点更新至资产台账，同时生成资产操作历史和位置变更事务。审批驳回不更新资产台账，原盘点结果不因此撤销。公共资产在非复盘项目中修改地点，盘点提交成功后按提交的地点更新台账，不走本入口及何文审批。


启动前校验：

1. 所有执行盘点资产都已经进入盘点计划。
2. 计划开始日期、结束日期和计划负责人已经填写；逐项校验计划内每项资产的盘点执行人不为空。盘点监督人非必填，系统生成的机房初盘不设置监督人。执行人缺失时指出计划和资产标签号，阻止启动。
3. 结束日期不得早于开始日期；复盘计划的开始和结束日期必须是同一天。

支持选择一条或多条草稿计划分批启动；已进入盘点中或关闭的计划不能重复启动。有执行资产未分配计划时，提示未分配数量并提供按默认方式生成或进入手工创建计划的选择；所选计划满足全部校验后才启动。启动盘点计划和删除盘点计划始终显示；未选择计划、所选计划包含非草稿或项目已关闭时均置灰不可点击。所有计划均已启动或关闭时，启动按钮置灰。校验通过后，所选计划状态更新为盘点中，项目状态更新为盘点中。计划和资产清单的分配信息锁定，并向狐小e、Myfamily和资产系统发送盘点任务通知。另提供发送盘点通知入口，向计划执行人、监督人发送消息和待办；有未完成任务时每天提醒相关执行人。催盘支持消息和邮件，邮件附所选未盘资产的清单。

复盘计划启动不得晚于该计划的盘点开始日。计划启动成功后，按每条计划自身开始日，在启动当天与开始日前三天中离开始日更近的一天，通过服务号通知该计划员工提前将资产准备好。通知对象为员工资产责任人，区别于财务盘点执行人；同一计划同一员工仅发送一次准备通知，各计划分别安排日期。

### 移动端盘点

#### 进入条件

移动端提供两条入口：

1. 狐小e → 资产管理 → 盘点。
2. 盘点待办通知。

用户是盘点执行人、盘点监督人或项目负责人，且存在已启动未完成计划时，才允许进入盘点工作台。没有任务时，盘点入口置灰或不可进入。

计划启动时向该计划已配置的执行人和监督人发送通知；机房初盘未设置监督人时，只向执行人发送通知。同一项目下有多个计划时，每个项目按最早启动计划的时间发送一条通知；只要仍有已启动且未完成的计划，通知保持待办。所有已启动计划完成后，通知转为已办。所有计划完成后，如新增计划且执行人和监督人均与上一轮相同，则按新计划启动时间重新发送通知。

关闭初盘、抽盘或复盘项目时，关闭该项目下所有执行人的移动端待办，并停止扫码、快速扫描和提交。关闭允许存在未盘资产或待提交结果；已提交结果保留，待提交结果不计入盘点结果，也不转给财务补录。项目关闭后，项目及关联计划、资产清单、盘点结果和审核记录均只读，不允许修改或补交。

计划详情底部仅提供【盘点】，进入该计划范围的普通单资产扫码，不提供【提交】。个人列表底部【开始盘点】同样进入普通单资产扫码。项目关闭后停止扫描和提交。

| 使用说明 | 非员工资产展示 |
| 备注 | 非员工资产展示 |

#### 操作

直接点击资产卡片进入查看详情，任何资产均不展示上传图片区域。未盘且从未报失的资产提供【盘点】【报失】；曾报失的资产即使当前状态因图片审核不通过恢复为未盘，也只提供【盘点】，不再提供【报失】；已盘、代盘及未执行盘点资产不提供这两个操作。资产详情的【盘点】只扫描当前这项资产，不得把盘点结果提交到列表中的另一项资产。

扫码成功后进入本次扫描资产的详情页，页面底部固定提供操作按钮：未盘且从未报失的资产为等宽等高的【报失】【提交】，曾报失的资产只保留【提交】，不能重复报失。资产信息和上传区域独立滚动；命中图片规则时才在该页展示拍照上传区域。直接查看未盘且从未报失的资产详情，【报失】【盘点】固定于页面底部、等宽等高。提交前校验资产范围、状态和必传照片；提交成功后返回原扫码页面继续扫描。

报失原因必填，提交前进行二次确认。确认后更新资产状态、盘点人、盘点日期和盘点备注，并通知资产责任人和对应监督人。

扫描提交页仅对公共资产及复盘项目中的全部资产提供可选地点修改，字段为 City、Building、Floor。进入页面时显示资产台账当前地点；不修改时按原地点提交盘点。公共资产在非复盘项目中修改地点，盘点提交成功后更新台账地点，不生成何文审批。复盘资产修改地点后，随本次盘点结果保存为拟变更地点，供 PC 端盘点计划页面汇总和编辑；盘点提交本身不修改台账地点，地点的正式变更以何文审批通过为准。直接查看资产详情不提供地点编辑。

### 普通扫码盘点

1. 用户从列表【开始盘点】、计划清单【盘点】或资产详情【盘点】打开普通单资产扫码页；扫描框下展示一张资产标签二维码样例及“参考如下样例，找到标签扫描”，并提供开灯。
2. 系统校验当前用户是否有对应任务。
3. 系统校验资产是否属于当前计划范围。
4. 已盘、代盘及图片审核中的资产不可重复提交；报失资产允许继续盘点。
5. 校验通过后进入该资产的扫码详情页，按图片规则展示上传区域；照片与盘点结果统一通过底部【提交】提交，扫码本身不改变资产盘点状态。
6. 当前责任人盘点成功，状态更新为已盘；非当前责任人盘点成功，状态更新为代盘。
7. 盘点人、盘点日期和盘点备注同步写入计划资产清单和项目资产清单；单资产提交成功后返回扫码页，不返回资产列表。

扫码异常包括：已被扫描、已被他人盘点、资产不在范围、无效二维码、非资产二维码和网络失败。报失资产不属于重复盘点拦截范围；再次扫描后可完成盘点，但仍不能再次发起报失。异常时允许返回扫码或退出，不更新盘点结果。网络提交失败时返回资产详情并保留已录入内容，允许重试，不保存盘点结果。扫码页面不展示系统内部校验过程、校验字段或规则解释；只在失败时给出用户能理解的业务原因和可执行操作。

| 扫码或提交场景 | 提示后的操作与去向 |
|---|---|
| 已盘资产再次扫码 | “休息一下”退出扫描；“再接再厉”留在扫描页 |
| 扫到他人应盘资产 | 进入该资产的扫码详情页，查看责任人信息后可报失或提交；返回继续扫描 |
| 自有资产提交成功、本人仍有待盘资产 | 返回原扫码页面继续扫描 |
| 代盘成功、本人仍有待盘资产 | 返回原扫码页面继续扫描 |
| 代盘成功、本人已无待盘资产 | 返回原扫码页面继续扫描 |
| 网络提交失败 | “好的”回资产详情，不保存本次结果 |
| 无效或非资产二维码、本人仍有待盘资产 | 退出或留在扫描页 |
| 无效或非资产二维码、本人已无待盘资产 | “好的，收工”回盘点首页 |
| 本次不需盘资产、本人仍有待盘资产 | 退出或留在扫描页 |
| 本次不需盘资产、本人已无待盘资产 | “好的，收工”回盘点首页 |
| 自有资产提交成功、本人已无待盘资产 | 返回原扫码页面继续扫描 |

### 快速扫描盘点

快速扫描作为独立入口，放在盘点页面右上角，与监督计划入口并列；符合权限的计划详情页也显示该独立入口。ES 资产组成员（包括孙志强）在员工、公共、库房和机房资产盘点中均可使用；机房资产责任人仅可用于本人负责的机房资产，其他身份不展示，也不能执行快速扫描。普通列表的盘点按钮始终进入普通单资产扫码。扫描页提供手电筒和连续扫码，每次仅记录标签号；实时展示本次扫描数量及最近五个标签号。每次扫码先核对当前盘点项目范围：项目外资产立即提示“不在当前盘点项目内”，不加入待提交标签列表、不增加扫描数量或最近标签记录。点击【结束扫描】进入待上传标签列表，逐项显示标签号；列表底部【盘点】返回继续扫描，【提交】对列表全部标签一次性校验并提交。待提交标签列表中的每条资产提供【查看/补拍】，进入本次扫描资产的详情：需要照片时补拍，公共资产及全部复盘资产可选择修改 City、Building、Floor；完成后返回待提交列表，此时不单独提交盘点结果。公共非复盘资产的地点在批量盘点提交成功后更新台账，不发起何文审批；复盘资产修改的地点保存为拟变更地点，进入 PC 盘点计划页面【发起位置变更】清单。批量提交前要求必需照片齐全；缺照片的资产不能记为成功。点击提交前不改变资产盘点结果；提交时统一校验：

1. 标签号是否属于当前计划。
2. 标签号是否重复扫描。
3. 资产是否已经盘点；报失不属于已盘，允许提交盘点结果。
4. 标签号是否有效。

提交结果展示扫描总数、成功数和失败数。成功记录更新盘点状态、盘点人和盘点日期，失败记录逐项展示标签号及失败原因；重复、已盘、无效或不属于当前任务的资产都不能记为成功。

入口、扫描和提交均校验角色、当前项目及当前任务范围：ES 资产组可处理当前授权任务内各类资产，机房资产责任人仅可处理本人负责的机房资产。不同项目及计划的待提交标签分别保存，不能混交。弹窗宽度不超过移动端页面宽度，内容过长时在弹窗内滚动，不遮挡操作按钮。

### 照片上传与审核

#### 移动端拍照

只有扫码成功后的资产详情且图片规则标记“是否需上传图片”时展示拍照区域；直接打开资产查看详情不展示上传区域。移动端只允许拍照，不允许从相册选择。

| 资产范围 | 必传照片 |
|---|---|
| 非机房 | 资产整体照片、二维码标签照片 |
| 机房 | 二维码标签照片、实物序列号照片 |

员工、公共、库房资产上传必需照片并提交成功后，盘点结果和照片一起保存，资产状态变为审核中；在审核结论出现前不计入已盘，不能重复提交。机房资产上传所需照片后不进入人工图片审核，直接按盘点人身份更新已盘或代盘。无需上传照片的资产按普通扫码结果更新。

#### PC 端图片审核

计划启动时，为员工、公共、库房范围中需要上传照片的执行盘点资产生成图片审核记录；机房照片保留查看，不生成待人工审核任务。

图片审核列表展示图片、资产标签号、实际盘点人、盘点日期、盘点状态和盘点备注，按待审核、审核不通过、审核通过排序。页面概览分别展示待审核、审核通过、审核不通过数量，按各审核状态统计。查询支持资产标签号、资产说明、审核状态、责任人、公司、部门、资产类别、盘点起止时间、盘点状态、City、Building、计划编号和计划名称；查询条件再次打开时保留。每行只能选择通过或不通过中的一项，提交仅处理已勾选且已给出结论的行；驳回行允许员工重传后重新审核。

审核操作：

1. 审核通过：审核状态为审核通过，资产从审核中变为已盘，审核记录锁定。
2. 审核不通过：审核状态为审核不通过，资产从审核中恢复未盘，员工盘点待办重新出现并可再次拍照提交；同时向员工发送驳回通知。若该资产曾报失，保留已报失记录，不恢复【报失】操作。
3. 图片查看使用上传原图，不压缩、不降低画质；支持原图 1:1、放大、缩小和旋转。

### 项目进度

项目进度按盘点范围、盘点组织、盘点执行人一级部门和 City 汇总。

| 指标 | 计算规则 |
|---|---|
| 应盘数量 | 执行盘点资产数量合计 |
| 已盘数量 | 已盘、代盘资产数量合计 |
| 报失数量 | 报失资产数量合计 |
| 未盘数量 | 应盘数量 - 已盘数量 - 报失数量 |
| 数量进度 | 已盘数量 / 应盘数量；已盘数量包含已盘和代盘，报失不计入分子 |
| 剩余时间 | 盘点结束日期减当前日期，单位为天；已逾期显示负数 |

员工、库房和公共范围均支持进入详情进度查看，采用一致的字段和交互；库房、公共的一级部门展示对应虚拟组织名称。汇总和详情均不展示备注字段。汇总数量、进度详情和资产明细均取当前项目同一份计划资产清单，不能从其他项目或未分配计划的资产中补数。审核中资产不计已盘，计入未盘；审核结论同步至计划清单、项目清单、进度和导出。

进度详情展示盘点范围、盘点组织、执行人一级部门、City、应盘数量、已盘数量、报失数量、未盘数量、数量进度和剩余天数。初盘、抽盘展示计划监督人；复盘展示财务监督人和内审监督人。未配置监督人显示为空，不阻止查看。详情各字段支持查询；不同条件同时满足，空值不筛选，重置恢复当前范围全部结果。数量、百分比和天数按输入数值查询，枚举或人员按所选值查询。详情支持分页并显示总条数。

汇总和详情提供【查看盘点全量资产】【查看未盘资产】入口。全量只包含当前项目及所选范围或进度分录的计划资产；未盘清单取其中当前尚未完成盘点的资产，不包含已盘、代盘和报失。资产清单展示盘点方式、盘点状态、盘点人、盘点日期、资产标签号、序列号、资产类别、资产说明、数量、原值、EBS原值、使用状态、NO位置、NO扫描差异、资产备注、资产责任人、责任人部门、责任人职级、责任人办公电话、责任人邮箱、现资产责任人、现部门、盘点监督人、盘点执行人、City、Building、Floor、盘点组织、成本中心、启用日期、未盘说明和是否上传图片；计划负责人按最新清单要求不展示。联系方式取责任人资料，缺失不填入他人的联系方式。

项目进度、范围进度详情、未盘资产明细均支持Excel导出，导出当前查询条件下的全部结果，不限当前分页。进度导出包含所展示的分组维度、角色和数量指标；未盘明细导出包含资产及联系方式字段。催盘作用于所选分录中未盘资产对应的执行人和已配置监督人，发送消息和邮件，邮件附所选未盘资产清单。

### 复盘审批

复盘盘点计划明细的财务监督人固定为徐博，只读，位于盘点结束日期之后；生成、查看和审批页面均保持该值，不能手工选择替换。

提交后进入“复盘结果审核”页面。复盘信息按计划展示计划编号、计划名称、期间、计划负责人、盘点执行人、财务监督人、内审监督人、资产总量、已盘数量、未盘数量、盘点比例；点击计划查看对应资产。查询条件为资产标签号、资产类别、资产说明、使用状态、资产责任人、责任人部门、City、Building、盘点状态，查询结果列表使用相同九列；查询只作用于当前计划，重置恢复该计划全部资产。审批信息在资产查询结果之后展示审批环节、审批人、代理人、审批状态、审批时间、审批意见，未审批时间和意见为空。

复盘计划启动后显示“提交审批”。提交审批前校验计划状态为盘点中。系统计算已盘数量与复盘资产总量的比例；未达到设定比例时提示用户，但允许继续提交。

审批按复盘计划包含的资产范围路由：

| 复盘资产范围 | 审批顺序 |
|---|---|
| 非机房资产 | ES 主管 → 财务经理徐博 |
| 机房资产 | NO 领导 → 财务经理徐博 |
财务经理徐博审批适用于机房和非机房复盘计划。机房资产和非机房资产不得出现在同一个初盘项目中；复盘项目必须关联唯一初盘项目，因此审批流按该初盘的资产范围选择一条路径。前一审批节点通过后流转至下一节点；任一节点驳回，复盘审批单更新为已驳回，关联复盘计划回到启动状态，并通知盘点负责人重新处理。

全部审批通过后：

1. 复盘审批单更新为已审核。
2. 关联复盘计划更新为已审核。
3. 通知盘点负责人。

### 项目关闭

项目列表和项目详情均提供“关闭项目”操作。除机房初盘外，初盘、抽盘和复盘项目由用户手动关闭；机房初盘由系统在盘点进度达到100%时自动关闭。

手动关闭初盘或抽盘项目时，系统校验：

1. 关联计划不存在未启动计划。
2. 图片审核记录不存在待审核或审核不通过记录。

关闭初盘或抽盘不要求后续复盘计划先完成审批。手动关闭复盘项目时，系统还需校验该复盘项目下所有复盘计划均已完成审批；任一计划尚未审核通过时不能关闭。已启动计划可以存在未盘资产或待提交结果；这些情况不阻止关闭。

关闭后，项目状态更新为盘点关闭，关联计划同步关闭，移动端执行人待办结束，所有资产停止盘点。已提交结果保留；待提交结果不计入盘点结果，也不转给财务补录。项目、计划、资产清单、盘点结果和审核记录均转为只读，不能修改、补录或重新提交。关闭校验通过后弹出确认信息，展示未盘数量和待提交数量。

系统创建的机房初盘数量进度达到100%时立即自动关闭，机房照片不进入人工审核，不以图片人工审核作为关闭前置条件。历史审核记录保留，关闭后只读。

初盘关闭后，无论是手动关闭还是机房初盘自动关闭，系统均通过服务号通知财务人员，并提示是否创建抽盘项目；确认后自动带入该初盘项目。财务人员可根据已关闭初盘发起复盘。抽盘关闭后，可以提示财务人员发起复盘；确认后自动带入其关联初盘项目。

关闭项目后，资产卡片的盘点历史展示该项目已关闭计划中的盘点记录。历史按资产标签号关联，展示盘点类型、盘点标识（盘点类型与期间）、盘点项目名称、盘点状态、盘点时间、盘点说明、实际盘点执行人和导入方式；盘点说明取盘点备注。

### 盘点报告

#### 财务盘点报告

财务报告包含三个页签：

1. 盘点报告汇总。
2. 盘亏资产明细。
3. 待盘资产明细。

导出前选择一个子公司和一个或多个板块。报告按照资产分类映射汇总原值、数量、已盘、报失和未盘差异。原值保留两位小数。待盘资产明细中，非机房资产净值取盘点当年6月的资产卡片净值；机房资产净值取导出报告当月的资产卡片净值。盘亏资产明细中，非机房净值取移动端报失当月，机房净值取导出报告当月。报表原值取资产卡片价值信息中的 EBS 原值，保留两位小数；汇总数量和差异按子公司、板块及资产分类计算。

项目启动盘点计划后提供盘点报告下载。下载时只选一个子公司，板块允许多选；仅汇总该公司及所选板块在本项目快照的执行、未执行两类资产，未包含清单不纳入报告。资产大小类通过资产分类映射表转换为报告大小类，再按小类小计、大类合计；缺少映射或历史价值时指出缺失内容，不能用其他月份净值或当前值替代。

| 汇总指标 | 计算规则 |
|---|---|
| 台账价值、数量 | 小类内执行与未执行两类快照资产的EBS原值、资产数量合计；大类合计其下小类 |
| 盘点价值、数量 | 两类清单中已盘、代盘资产的EBS原值、资产数量合计；大类合计其下小类 |
| 价值差额 | 台账价值减盘点价值，分别计算小类小计和大类合计 |
| 数量差额 | 台账数量减盘点数量，分别计算小类小计和大类合计 |
| 盘亏价值、数量 | 两类清单中报失资产的EBS原值、资产数量按大类合计，说明固定为“丢失” |
| 待查价值、数量 | 两类清单中未盘资产的EBS原值、资产数量按大类合计，说明固定为“待查” |

盘亏资产明细仅收录报失资产，待盘资产明细仅收录未盘资产；其余字段分别取对应快照资产及后续盘点记录。所有价值字段保留两位小数。

#### 其他报告

ES 业务盘点报告、初盘 PDF 报告和机房 NO 扫描报告按确认后的字段和模板生成。

## 5. 校验

1. 初盘、抽盘的盘点结束日期不得早于开始日期；复盘项目基本信息的开始和结束时间允许跨天；生成盘点计划后，每个复盘计划明细的开始和结束日期必须是同一天，不同计划可安排在不同日期，修改计划日期和启动计划时逐计划校验。
2. 每个盘点范围至少配置一种盘点方式。
3. 执行盘点资产必须全部进入盘点计划后才能启动。
4. 盘点结果只能更新当前项目和当前计划范围内的资产。图片待审核期间状态为审核中；审核通过为已盘，驳回为未盘并恢复员工待办。
5. 报失资产可以继续盘点，不允许再次报失；图片审核驳回使盘点状态恢复未盘时，已报失记录仍保留并继续禁止二次报失。重新盘点仍按当前项目、计划、照片和人员规则校验。复盘资产填写的新地点与台账地点不同时仅形成待确认位置变更，何文审批通过前不得修改资产台账；公共非复盘资产修改地点随成功盘点更新台账，不发起该审批。
6. 资产标签号、盘点人、盘点日期、盘点备注和盘点方式必须随盘点结果保存。
7. 结果来源区分狐小e、狐小e快速扫描、扫码枪和人工导入。
8. 项目关闭后，项目及关联计划、资产清单、盘点结果和审核记录均只读，不允许新增、修改、补录或重新提交。
9. 盘点项目、盘点计划、资产清单和审核记录均保留操作人和操作时间。
