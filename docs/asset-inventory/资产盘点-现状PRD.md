# 资产盘点现状PRD

来源：用户提供《资产盘点.docx》《资产盘点移动端.docx》整理。

## 当前范围

包含PC端资产盘点项目管理和移动端执行盘点。

## PC端核心范围

- 盘点项目创建、编辑、查看。
- 盘点范围筛选。
- 盘点规则配置。
- 快照生成。
- 执行盘点资产清单、未执行盘点资产清单、未包含资产清单。
- 图片审核。

## 移动端核心范围

- 狐小e资产管理入口进入盘点。
- 待办入口进入盘点工作台。
- 未盘、已盘资产展示。
- 扫码盘点。
- 快速扫描盘点。
- 资产详情查看。
- 图片上传。

## 关键规则

1. 已启动盘点项目后开放盘点功能。
2. PC端负责盘点项目管理，移动端负责执行盘点。
3. 盘点状态包含已盘、代盘、未盘、报失。
4. 盘点方式根据盘点项目配置自动匹配。
