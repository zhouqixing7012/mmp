## 一、模块概述

### 1.1 模块定位

"会计映射规则管理"模块用于维护HR系统和财务系统之间的数据映射关系，确保组织架构、成本中心、业务线等数据在两个系统间保持一致。

### 1.2 包含页面

本模块包含5个子页面，通过顶部Tab标签页切换：

| Tab页面 | 功能说明 |
|---------|----------|
| HR公司与财务公司映射 | 维护HR系统公司和财务系统公司的对应关系 |
| 部门与成本中心映射 | 维护HR部门和财务成本中心的对应关系 |
| 成本中心与板块映射 | 维护成本中心和业务板块的对应关系 |
| 城市与业务线映射 | 维护城市和业务线的对应关系 |
| 部门与业务线映射 | 维护部门和业务线的对应关系 |

### 1.3 通用特点

这5个页面有以下共同特点：
- **只支持同步操作**：不支持手动新增/删除，数据从外部系统同步
- **只读展示**：表格数据仅供查看，不能直接编辑
- **同步按钮**：工具栏只有"同步"按钮，点击后从外部系统拉取最新数据

## 二、页面1：HR公司与财务公司映射

### 2.1 页面功能

维护HR系统中的公司和财务系统中的公司的对应关系，用于数据同步和报表生成。

### 2.2 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  [Tab: HR公司与财务公司映射] [部门与成本中心...] ...       │
├─────────────────────────────────────────────────────────────┤
│  搜索条件区域                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ HR公司: [________]      财务公司: [________]          │  │
│  │ 是否启用: [▼选择]                        [查询] [重置]│  │
│  └───────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  工具栏: [同步]                                             │
├─────────────────────────────────────────────────────────────┤
│  数据表格                                                    │
│  │序号│HR公司│HR公司描述│财务公司│财务公司描述│是否启用│启用日期│停用日期│
│  │ 1  │ FRA  │北京搜狐..│  101   │  新时代   │ 启用  │2010-01-01│     │
│  ...                                                        │
├─────────────────────────────────────────────────────────────┤
│  共X条记录          [上一页] [1] [2] ... [下一页]  10条/页  │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| HR公司 | 文本输入框 | 支持模糊搜索，如输入"FRA" |
| 财务公司 | 文本输入框 | 支持模糊搜索，如输入"101" |
| 是否启用 | 下拉选择框 | 选项：全部、是、否 |

### 2.4 表格列

| 列名 | 说明 |
|------|------|
| 序号 | 自动编号 |
| HR公司 | HR系统中的公司代码，如：FRA |
| HR公司描述 | HR系统中的公司名称，如：北京搜狐新时代信息技术有限公司 |
| 财务公司 | 财务系统中的公司代码，如：101 |
| 财务公司描述 | 财务系统中的公司名称，如：新时代 |
| 是否启用 | 启用（绿色）/停用（红色） |
| 启用日期 | 格式：YYYY-MM-DD |
| 停用日期 | 格式：YYYY-MM-DD |

### 2.5 工具栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 同步 | 绿色按钮 | 从HR系统同步最新的公司映射数据 |

**同步流程**：
1. 点击"同步"按钮
2. 系统显示"正在同步..."提示
3. 从HR系统拉取最新的公司数据
4. 与本地数据比对，新增/更新/停用映射关系
5. 显示同步结果："同步完成，新增X条，更新Y条，停用Z条"

### 2.6 校验规则

本模块不支持手动新增/编辑，因此无校验规则。数据完整性由外部系统保证。

## 七、通用交互说明

### 7.1 同步功能流程

所有5个页面的同步功能流程一致：

1. **点击同步按钮**
   - 用户点击工具栏的"同步"按钮

2. **显示同步进度**
   - 弹出提示："正在从XX系统同步数据，请稍候..."
   - 禁用"同步"按钮，防止重复点击

3. **执行同步**
   - 系统调用后端接口，从外部系统拉取最新数据
   - 与本地数据库比对，识别新增、更新、停用的记录

4. **显示同步结果**
   - 同步完成后，显示结果统计："同步完成！"
   - 详细信息："新增X条记录，更新Y条记录，停用Z条记录"
   - 如果有失败记录，显示"同步失败N条，请查看日志"

5. **刷新列表**
   - 自动刷新表格数据，显示最新的映射关系

### 7.2 查询流程

与"业务基础数据维护"模块一致，参见PRD-业务基础数据维护.md 第九章。

### 7.3 注意事项

1. **数据来源**：所有数据都来自外部系统（HR系统、财务系统），不支持手动录入
2. **编辑限制**：表格中的数据不能直接编辑，只能通过同步更新
3. **删除限制**：不支持删除操作，只能通过同步停用
4. **权限控制**：同步操作需要特殊权限，普通用户只能查看
