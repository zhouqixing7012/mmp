# 标签打印 PRD 整改设计

## 目标

在不删减标签编码、流水、页面字段、打印历史、导出和校验细节的前提下，重组《标签打印、打印历史、标签预打印 PRD》，消除三条打印链路、部件标签识别、标签模板和权限范围之间的冲突。

## 最终口径

1. 资产标签补打、标签预打印、接收单标签打印分别描述。
2. 资产标签主列表补打直接打印已有标签，不创建新的 TPB 批次、不创建标签明细、不写 `MMP_ASSETS_TAG_PRINT_LOG`；成功后只更新 `MMP_ASSETS_TAG_PRINT.PRINTED_COUNT`。
3. 标签预打印生成标签号、标签批次和标签明细；接收单打印首次按 `PO_NUMBER` 创建并生成批次及明细，后续复用同一批次。
4. 新生成的标签明细保存主标签/部件标签类型，打印时按类型选择模板；现有代码兼容判断是“标签号包含 `-` 且不包含 `-V`”，不是“不是以 `-V` 结尾”。
5. 主资产标签打印二维码，二维码内容为标签号；部件标签不打印二维码。
6. 主资产标签内容为二维码、公司英文名、公司中文名、标签号；部件标签内容为公司英文名、公司中文名、标签号。
7. 常规标签超过 15 位时，删除标签规则中的年份后两位，不截断流水号或标签最终末尾字符。
8. 王英、刘建拥有标签打印菜单和打印权限；机房管理员名单尚未确定，其权限只覆盖标签打印菜单以及机房大类、备件打印。
9. 部件标签不进入资产标签打印主列表，只在所属批次的标签清单中处理。
10. 常规流水最大值为 `99999`；删除年份后跨年满号重复等极限场景本轮不定义扩展规则。
11. 原版 PRD 只读保留；新版 PRD 承载最终业务规则；比对和测试文档同步消除与最终口径冲突的旧例外。

## 不在本次范围内

- 不修改标签打印 React 原型代码。
- 不修改原版 PRD。
- 不新增打印机型号、标签纸尺寸或模板坐标等当前未确认的环境参数。
