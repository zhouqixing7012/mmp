# 移库 PRD 整改设计

## 目标

保留 GitHub 当前移库 PRD 中已经确认的业务细节，修正规则冲突和流程缺口，以业务语言重构为可以直接开发、测试和业务确认的正式 PRD。

## 结构

1. 背景。
2. 权限。
3. 通用规则。
4. PC 页面字段及交互。
5. 移动端页面字段及交互。
6. 校验。
7. 业务结果与补充说明。

## 已确认变化

- 明细状态删除“已取消”。
- PC、移动端验证后均不可取消，只允许接收或驳回。
- 添加物资实时保存，删除【保存草稿】。
- PC、移动端发起列表按移出仓库权限展示；接收列表按移入仓库权限展示，均不限创建人。
- 仓库名称统一为“移出仓库、移入仓库”。
- 接收列表删除通知状态、催办状态，但通知和每日催办继续执行。
- 删除接收 Excel。
- 狐小E作为扫码来源，按与扫码枪相同的验证规则处理。
- 已完成允许打印；草稿、出库待接收、已驳回不显示打印。
- 列表和明细统一导出 Excel `.xlsx`。
- 删除外部同步队列等未明确业务目标的内容。
- 业务正文不写页面组件名、代码变量、事务类型代码和无效否定句。

## 必须保留

- 资产和低值耐用品逐件移库，普通耗材不进入范围。
- 单一移出仓库、单一移入仓库、同一财务公司和固定在途库。
- 草稿、出库待接收、已完成、已驳回单据状态。
- 草稿、待接收、已接收、已驳回明细状态。
- 实时锁、删除释放、提交复核、历史信息固定、分批接收、部分驳回、反向移库。
- Excel 导入整批校验、错误结果、模板规则。
- PC 与移动端的创建、添加、验证、接收、驳回和查询能力。
- 调出、调入、反向接收业务记录及权限、通知、催办、打印和导出规则。
