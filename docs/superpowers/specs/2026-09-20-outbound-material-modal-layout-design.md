# 出库物资信息弹窗布局调整设计

## 目标

统一出库物资新增/编辑弹窗与只读详情弹窗的字段布局，避免同一物资在维护态和查看态出现不同顺序。

## 调整范围

仅调整普通资产的“物资信息”区域，不改变耗材信息、领用信息、借用信息、字段取值和业务校验。

1. “备注”由占三列调整为占两列。
2. “主资产标签号”与“总价”交换位置。
3. 新增/编辑弹窗和只读详情弹窗同步调整。
4. 对应更新《PRD-库存管理-出库》，确保 PRD 字段顺序与当前原型一致。

## 调整后的金额与关联字段顺序

1. 总价
2. 原值
3. 税金
4. 主资产标签号
5. 部件数量
6. 部件说明
7. 资产标记
8. NO位置、服务（仅机房资产）
9. 备注（占两列）

## 实现方式

直接调整 `OutboundPage.js` 两处 `DetailGrid` 的 JSX 字段顺序和 `span`，不使用 CSS 猜测字段位置，不新增组件或状态。

## 验证

1. 回归测试同时检查新增/编辑弹窗和只读详情弹窗。
2. 先确认测试在旧结构下失败，再修改源码使测试通过。
3. 运行库存管理定向测试和正式构建。
4. 推送 `feature/asset-inventory` 后核对 GitHub Actions 与功能分支预览。
