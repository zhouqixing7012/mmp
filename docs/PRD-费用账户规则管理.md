## 一、模块概述

### 1.1 模块定位

"费用账户规则管理"模块用于维护费用核算的相关规则和映射关系，包括费用账户配置、成本中心与科目映射、物料与子目映射等，是财务核算的基础配置。

### 1.2 包含页面

本模块包含5个子页面，通过顶部Tab标签页切换：

| Tab页面 | 功能说明 |
|---------|----------|
| 费用账户规则 | 管理费用账户的输入输出映射规则 |
| 成本中心与科目映射 | 维护成本中心和会计科目的对应关系 |
| 物料大类与子目映射 | 维护物料大类和会计子目的对应关系 |
| NO一级服务与科目映射 | 维护NO服务和会计科目的对应关系 |
| 员工与项目映射 | 维护员工和项目的对应关系 |

## 二、页面1：费用账户规则（详细）

### 2.1 页面功能

管理费用账户的配置规则，定义输入属性（物料大类、公司、成本中心）到输出属性（公司、板块、科目、子目等）的映射关系。

```
┌─────────────────────────────────────────────────────────────┐
│  [Tab: 费用账户规则] [成本中心...] [物料大类...] ...        │
├─────────────────────────────────────────────────────────────┤
│  搜索条件区域                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 物料大类(输入): [________]  公司: [________]          │  │
│  │ 成本中心(输入): [________]                            │  │
│  │ 是否启用: [▼选择]                                     │  │
│  │                                    [查询] [重置]      │  │
│  └───────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  工具栏: [新增] [编辑] [删除] [启用] [停用]                 │
├─────────────────────────────────────────────────────────────┤
│  数据表格                                                    │
│  ☐ │序号│物料大类(输入)│公司(输入)│成本中心(输入)│...│操作│  │
│  ☐ │ 1  │16.FURNITURE │114_新媒体│  112064     │...│编辑│  │
│  ...                                                        │
```

### 2.6 新增/编辑弹窗

#### 弹窗标题
- 新增时：标题为"新增费用账户规则"
- 编辑时：标题为"编辑费用账户规则"

#### 弹窗布局

弹窗分为两个分组，用不同颜色背景区分：

**第一组：输入属性信息**（浅蓝色背景标题）

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 物料大类(输入)*（文本输入） | 公司(输入)*（搜索选择） |
| 第2行 | 成本中心(输入)（文本输入） | 是否启用*（下拉选择） |

**第二组：输出属性信息**（浅绿色背景标题）

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第3行 | 公司(输出)*（搜索选择） | 板块(输出)（搜索选择） |
| 第4行 | 成本中心(输出)（文本输入） | 科目(输出)（文本输入） |
| 第5行 | 子目(输出)（文本输入） | 业务线(输出)（文本输入） |
| 第6行 | 项目(输出)（文本输入） | 往来(输出)（搜索选择） |
| 第7行 | 备用(输出)（搜索选择） | （空） |

#### 字段详细说明

**输入属性信息**：

| 字段名 | 是否必填 | 控件类型 | 说明 |
|--------|---------|----------|------|
| 物料大类(输入) | ✅ 必填 | 文本输入框 | 物料大类代码，如：16.FURNITURE |
| 公司(输入) | ✅ 必填 | 搜索选择框 | 点击搜索图标选择公司 |
| 成本中心(输入) | 选填 | 文本输入框 | 成本中心代码 |
| 是否启用 | ✅ 必填 | 下拉选择框 | 选项：启用、停用，默认：启用 |

**输出属性信息**：

| 字段名 | 是否必填 | 控件类型 | 说明 |
|--------|---------|----------|------|
| 公司(输出) | ✅ 必填 | 搜索选择框 | 点击搜索图标选择公司 |
| 板块(输出) | 选填 | 搜索选择框 | 点击搜索图标选择板块 |
| 成本中心(输出) | 选填 | 文本输入框 | 成本中心代码 |
| 科目(输出) | 选填 | 文本输入框 | 会计科目代码 |
| 子目(输出) | 选填 | 文本输入框 | 会计子目代码 |
| 业务线(输出) | 选填 | 文本输入框 | 业务线代码 |
| 项目(输出) | 选填 | 文本输入框 | 项目代码 |
| 往来(输出) | 选填 | 搜索选择框 | 点击搜索图标选择往来单位 |
| 备用(输出) | 选填 | 搜索选择框 | 点击搜索图标选择 |

#### 弹窗按钮

| 按钮 | 样式 | 功能 |
|------|------|------|
| 保存 | 蓝色主按钮 | 保存数据，关闭弹窗 |
| 返回 | 灰色按钮 | 取消操作，关闭弹窗 |

### 2.7 校验规则

| 字段 | 校验规则 | 错误提示 |
|------|----------|----------|
| 物料大类(输入) | 必填 | "请输入物料大类" |
| 公司(输入) | 必填 | "请选择公司" |
| 公司(输出) | 必填 | "请选择输出公司" |
| 是否启用 | 必填 | "请选择是否启用" |
| 组合唯一性 | 物料大类(输入)+公司(输入)不能重复 | "该组合已存在" |
