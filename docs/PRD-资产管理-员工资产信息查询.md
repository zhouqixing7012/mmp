# 员工资产信息查询 PRD

## 1. 背景

“员工资产信息查询”位于：

> 资产管理 → 员工资产信息查询

该功能面向资产管理后台用户，以员工为核心查询维度，集中查看指定员工当前关联的资产、耗材、合约号码以及与该员工相关的资产业务单据。

主要使用场景：

1. 核对员工当前名下资产。
2. 核对员工当前责任耗材。
3. 核对员工当前持有的合约号码。
4. 查询员工历史及当前处理中的资产业务单据。
5. 支持员工离职、调动、资产核查等场景下的一站式资产关系核对。

页面默认进入“资产”页签。

## 2. 改造总结

1. 页面统一以“员工信息”为核心查询条件，员工单选后同时作为资产、耗材、合约号码、单据信息四个页签的查询对象。
2. 页面设置四个页签：资产、耗材、合约号码、单据信息。
3. 切换页签时保留当前查询员工，不要求重复选择员工。
4. 不同页签只展示当前业务适用的辅助查询条件。
5. 资产页签只查询“资产责任人 = 当前查询员工”的资产。
6. 耗材页签只查询“耗材当前责任人 = 当前查询员工”的耗材。
7. 合约号码页签只查询“合约号码当前责任人 = 当前查询员工”的当前有效合约号码。
8. 单据信息页签按申请人、责任人、`payPersonId`、入库/出库明细关联人员等员工关系检索单据，但最终返回的每一条结果都必须能够归属于当前查询员工。
9. 资产标签号、耗材标签号、申请单号、核心单据等具备详情入口的字段按对应业务对象进入详情。
10. 页面仅提供查询与查看能力，不在本页面修改资产、耗材、合约号码或业务单据。
11. 空结果按当前页签分别展示明确的空状态文案。
12. 历史单据详情需要保留旧系统详情访问能力；具体适用范围、地址拼接及权限规则当前文档未明确，需在正式实现前补充。

## 3. 通用规则

### 3.1 员工查询规则

“员工信息”为四个页签共用的核心查询条件。

员工选择规则：

1. 使用人员选择器选择员工。
2. 员工选择为单选。
3. 人员选择器支持按员工编号、员工姓名、部门查询。
4. 选择完成后页面展示：
   > 员工编号 - 员工姓名
5. 页面首次进入时员工信息为空，不预置默认员工。
6. 重新选择员工后，四个页签后续查询对象统一切换为新员工。
7. 已查询员工发生变化时，清空其他页签此前保留的辅助查询条件；当前页签正在填写的辅助条件保留，并在点击“查询”后与新员工一起生效。

员工信息未选择时，不执行员工资产信息查询。

### 3.2 页签联动规则

页面页签顺序：

1. 资产
2. 耗材
3. 合约号码
4. 单据信息

页签位于页面标题下方、查询条件区域上方，作为整页数据视图切换入口，而不是仅作为列表内部页签。

切换页签时：

1. 已完成一次员工查询后，切换页签继续使用当前已查询员工。
2. 切换页签后自动展示该员工在目标页签下的数据，不要求再次点击“查询”。
3. 当前页签不适用的辅助查询条件不参与查询。
4. 同一员工下，返回原页签后，该页签此前已经查询生效的辅助条件继续保留。
5. 如果用户重新选择了其他员工但尚未点击“查询”，清空当前结果并等待用户确认查询；点击“查询”后，再以新员工作为四个页签的公共查询对象。
6. 员工切换并重新查询后，其他页签针对上一员工保留的辅助条件清空，避免隐藏条件影响新员工查询结果。

### 3.3 查询条件适用范围

| 查询条件 | 资产 | 耗材 | 合约号码 | 单据信息 |
| --- | --- | --- | --- | --- |
| 员工信息 | √ | √ | √ | √ |
| 资产标签号 | √ |  |  |  |
| 耗材标签号 |  | √ |  |  |
| 合约号码 |  |  | √ |  |
| 单据编号 |  |  |  | √ |
| 单据状态 |  |  |  | √ |

页面只展示当前页签适用的辅助查询条件。

### 3.4 查询结果原则

1. 查询结果必须属于当前查询员工。
2. 不得因为员工曾经作为申请人参与某业务，就把不属于其当前责任范围的资产、耗材或合约号码带入对应“当前持有”页签。
3. “资产 / 耗材 / 合约号码”用于查询当前责任或当前持有关系。
4. “单据信息”用于查询当前及历史业务关系，可包含已完成、处理中、已驳回记录。
5. 当前页签无数据时展示对应空结果，不切换到其他页签数据。

### 3.5 页面能力边界

本页面为查询页面，不提供：

- 新增资产、耗材、合约号码。
- 编辑资产、耗材、合约号码。
- 审批业务单据。
- 修改业务单据状态。

详情入口只负责跳转或打开对应业务对象的只读/业务详情。

## 4. 页面字段及交互

### 4.1 页面结构

页面由两部分组成：

1. 顶部查询条件区。
2. 下方页签及查询结果列表区。

默认进入“资产”页签。

### 4.2 员工信息查询

| 字段 | 控件 | 规则 |
| --- | --- | --- |
| 员工信息 | 人员选择器 | 必选；单选；支持员工编号、员工姓名、部门查询；回显“员工编号 - 员工姓名” |

### 4.3 资产页签

#### 4.3.1 查询条件

| 字段 | 控件/规则 |
| --- | --- |
| 员工信息 | 共用人员选择器 |
| 资产标签号 | 文本输入，按标签号过滤 |

#### 4.3.2 数据范围

资产页签查询满足以下条件的数据：

1. 资产责任人 = 当前查询员工。
2. 资产状态代码属于：`3`、`6`。
3. 状态代码 `3` = `在用-借用中`。
4. 状态代码 `6` = `在用-使用中`。
5. 物资大类 = 资产。

#### 4.3.3 列表字段

| 字段 | 规则 |
| --- | --- |
| 行号 | 当前查询结果序号 |
| 资产标签号 | 资产唯一标签号；蓝色链接；点击打开资产卡片详情 |
| 资产说明 | 资产名称/说明 |
| 资产状态 | 按资产状态字典展示 |
| 资产责任人 | 当前资产责任人员工编号/信息 |
| 单据申请人 | 当前资产关联业务单据申请人 |
| 所在单据编号 | 当前资产关联业务单据编号 |
| 单据类型 | 单据类型名称 |
| 单据业务类型 | 当前业务类型 |
| 单据状态 | 当前业务单据状态 |
| 单据审批环节 | 当前业务所处审批/办理环节 |
| 单据审批人 | 当前处理人 |
| 公司 | 资产/责任人对应公司 |
| 板块 | 对应板块 |

#### 4.3.4 详情入口

1. 资产标签号使用蓝色链接，点击打开对应资产卡片详情。
2. 资产存在关联单据时，“所在单据编号”使用蓝色链接，点击打开对应业务单据详情或流程信息。
3. 无关联单据时展示 `-`，不提供空链接。

#### 4.3.5 默认排序

资产页签默认按以下顺序排序：

1. 按所在单据编号字段 `sp_po_putin_num` 降序。
2. `sp_po_putin_num` 为空的记录统一排在非空记录之后。
3. `sp_po_putin_num` 相同时，按标签号字段 `tag_number` 升序。
4. 排序字段是否在列表展示，不影响排序规则。

## 5. 校验

### 5.1 员工信息校验

1. 员工信息未选择时，不执行查询。
2. 离职员工允许通过人员选择器查询、选择，并可正常查询其关联资产、耗材、合约号码和单据信息。
3. 查询工号不存在，且系统无法取得对应员工信息时，提示：
   > 未查询到对应员工信息。

### 5.2 页签查询条件校验

1. 当前页签不适用的查询条件不得参与接口查询。
2. 资产、耗材页签的资产标签号只作用于当前页签。
3. 合约号码条件只作用于合约号码页签。
4. 单据编号、单据状态只作用于单据信息页签。
5. 单据状态候选固定为：已完成、处理中、已驳回。

### 5.3 数据归属校验

1. 资产必须满足资产责任人 = 当前查询员工。
2. 耗材必须满足耗材当前责任人 = 当前查询员工。
3. 合约号码必须满足合约号码当前责任人 = 当前查询员工。
4. 单据可以通过多类员工关系字段命中，但必须校验该单据确实与当前查询员工有关。
5. 不允许使用“申请人命中”替代资产、耗材、合约号码的当前责任关系判断。

### 5.4 详情入口校验

1. 资产标签号只能打开对应资产卡片。
2. 耗材标签号只能打开对应耗材详情。
3. 申请单号存在对应申请单时才提供详情入口。
4. 核心单据存在对应执行单据时才提供详情入口。
5. 无对应详情对象时展示普通文本，不提供空链接。

## 6. 后续操作或补充说明

### 6.1 权限

入口权限：

> 资产管理 → 员工资产信息查询

只有拥有该菜单权限的后台用户可以访问。

本功能暂不增加公司、板块、部门等额外数据权限限制。

拥有该菜单权限的用户可以查询全部员工，包括离职员工，并查看其关联的资产、耗材、合约号码及单据信息。

### 6.2 历史单据详情

历史单据查看规则：

> 历史单据跳转至旧系统对应单据详情页。

本 PRD 不维护具体旧系统 URL。

### 6.3 当前未定义规则

当前已确认本功能的核心查询、排序、权限及详情跳转规则；暂无本轮待确认业务规则。
