# 员工资产信息查询 PRD

## 1. 背景

“员工资产信息查询”位于：

> 资产管理 → 员工资产信息查询

该功能面向资产管理后台用户，以员工为核心查询维度，集中查看指定员工当前关联的资产、耗材、合约号码，以及与该员工相关的资产业务单据。

主要使用场景：

1. 核对员工当前名下资产。
2. 核对员工当前责任耗材。
3. 核对员工当前持有的合约号码。
4. 查询员工历史及当前处理中的资产业务单据。
5. 支持员工离职、调动、资产核查等场景下的一站式资产关系核对。

页面默认进入“资产”页签。

## 2. 权限

入口权限：

> 资产管理 → 员工资产信息查询

只有拥有该菜单权限的后台用户可以访问本页面。

权限规则：

1. 拥有菜单权限的用户查询员工及其业务数据时，不受公司、板块和部门范围限制。
2. 拥有菜单权限的用户可以查询全部员工，包括离职员工。
3. 拥有菜单权限的用户可以查看被查询员工关联的资产、耗材、合约号码和单据信息。

## 3. 通用规则

### 3.1 页面范围

页面设置四个页签：

1. 资产
2. 耗材
3. 合约号码
4. 单据信息

页面规则：

1. “资产 / 耗材 / 合约号码”用于查询员工当前责任或当前持有关系。
2. “单据信息”用于查询员工当前及历史业务关系，可包含已完成、处理中、已驳回记录。
3. 当前页签无数据时只展示当前页签的空结果，不自动切换到其他页签。
4. 资产标签号、耗材标签号、合约号码、所在单据编号、申请单号和核心单据的详情入口按第 4 章各页签规则执行。
5. 历史单据点击详情时跳转至旧系统对应单据详情页。
6. 当前单据存在但系统未配置详情页面时，点击后提示：
   > 暂无明细展示页面！请联系维护人员添加。

### 3.2 员工查询规则

“员工信息”为四个页签共用的核心查询条件。

员工选择规则：

1. 使用人员选择器选择员工。
2. 员工选择为单选。
3. 人员选择器支持按员工编号、员工姓名、部门查询。
4. 人员选择器结果展示员工编号、员工姓名和部门；在职员工与离职员工均允许选择。
5. 选择完成后页面回显：
   > 员工编号 - 员工姓名
6. 页面首次进入时员工信息为空，不预置默认员工。
7. 未选择员工时，不执行查询，结果区展示“请选择员工信息后查询。”
8. 查询工号不存在，且系统无法取得对应员工信息时，提示：
   > 未查询到对应员工信息。

员工切换规则：

1. 重新选择员工后，四个页签后续查询对象统一切换为新员工。
2. 如果用户重新选择了其他员工但尚未点击“查询”，清空当前结果并等待用户确认查询。
3. 点击“查询”后，再以新员工作为四个页签的公共查询对象。
4. 员工切换并重新查询后，清空其他页签针对上一员工保留的辅助查询条件，避免隐藏条件影响新员工查询结果。

### 3.3 页签联动规则

页签位于页面标题下方、查询条件区域上方，作为整页数据视图切换入口。

切换页签时：

1. 已完成一次员工查询后，切换页签继续使用当前已查询员工。
2. 切换页签后自动展示该员工在目标页签下的数据，不要求再次点击“查询”。
3. 当前页签不适用的辅助查询条件不参与查询。
4. 同一员工下，返回原页签后，该页签此前已经查询生效的辅助条件继续保留。
5. 如果当前还未完成员工查询，切换页签后仍展示“请选择员工信息后查询。”

### 3.4 查询条件适用范围

| 查询条件 | 资产 | 耗材 | 合约号码 | 单据信息 |
| --- | --- | --- | --- | --- |
| 员工信息 | √ | √ | √ | √ |
| 资产标签号 | √ |  |  |  |
| 耗材标签号 |  | √ |  |  |
| 合约号码 |  |  | √ |  |
| 单据编号 |  |  |  | √ |
| 单据状态 |  |  |  | √ |

页面只展示当前页签适用的辅助查询条件。

查询操作规则：

1. 【查询】按当前页签可见条件执行查询。
2. 文本条件支持回车查询。
3. 不同查询条件之间使用 AND。
4. 未填写条件不参与过滤。
5. 查询后返回第 1 页。
6. 【重置】清空员工信息、四个页签的辅助条件和查询结果，并返回当前页签第 1 页。
7. 当前页签不适用的查询条件不得传入查询。

### 3.5 列表通用规则

1. 四个页签均使用列表展示结果。
2. 设置行号的页签按当前查询结果展示顺序生成行号；分页列表按页码连续编号。
3. 普通空值统一展示“-”。
4. 员工、责任人等人员字段按各业务页签定义的格式展示。
5. 蓝色链接表示可进入详情；普通文本不提供点击行为。
6. 本页面不提供列表导出。

## 4. 页面字段及交互

### 4.1 页面结构

页面由三部分组成：

1. 页面标题下方的业务页签区。
2. 当前页签对应的查询条件区。
3. 当前页签查询结果列表区。

默认进入“资产”页签。

### 4.2 员工信息查询

| 字段 | 控件 | 规则 |
| --- | --- | --- |
| 员工信息 | 人员选择器 | 必选；单选；支持员工编号、员工姓名、部门查询；回显“员工编号 - 员工姓名” |

### 4.3 资产页签

#### 4.3.1 查询条件

| 字段 | 控件/规则 |
| --- | --- |
| 员工信息 | 共用人员选择器 |
| 资产标签号 | 文本输入；支持按标签号包含匹配；支持回车查询 |

#### 4.3.2 数据范围

资产页签查询满足以下条件的数据：

1. 资产责任人 = 当前查询员工。
2. 资产状态属于“在用-借用中”或“在用-使用中”。
3. 物资类型为资产。

#### 4.3.3 列表字段

| 字段 | 规则 |
| --- | --- |
| 行号 | 按当前查询结果展示顺序生成 |
| 资产标签号 | 资产唯一标签号；蓝色链接；点击打开资产卡片详情 |
| 资产说明 | 资产卡片中的资产说明 |
| 资产状态 | 展示完整业务状态名称 |
| 资产责任人 | 当前资产责任人，格式按资产卡片展示口径 |
| 单据申请人 | 当前关联业务单据申请人；无关联单据时显示“-” |
| 所在单据编号 | 当前关联业务单据编号；有详情入口时为蓝色链接；无关联单据时显示“-” |
| 单据类型 | 当前关联业务单据类型；无关联单据时显示“-” |
| 单据业务类型 | 当前关联业务类型；无关联单据时显示“-” |
| 单据状态 | 当前关联业务单据状态；无关联单据时显示“-” |
| 单据审批环节 | 当前单据所处审批或办理环节；无审批信息时显示“-” |
| 单据审批人 | 当前审批人或办理人；无审批人时显示“-” |
| 公司 | 资产卡片中的当前公司；无值显示“-” |
| 板块 | 资产当前板块；无值显示“-” |

#### 4.3.4 关联单据展示规则

1. 单据信息取资产卡片当前关联的业务单据。
2. 不根据员工曾经申请过的其他单据反向补充关联单据信息。
3. 没有关联业务单据时，单据申请人、所在单据编号、单据类型、单据业务类型、单据状态、单据审批环节和单据审批人统一显示“-”。
4. “所在单据编号”只在存在明确详情入口时展示为蓝色链接。

#### 4.3.5 默认排序

资产页签默认按所在单据编号倒序；没有所在单据编号的记录排在有单据编号记录之后。所在单据编号相同时，按资产标签号升序。

### 4.4 耗材页签

#### 4.4.1 查询条件

| 字段 | 控件/规则 |
| --- | --- |
| 员工信息 | 共用人员选择器 |
| 耗材标签号 | 文本输入；按耗材标签号过滤；支持回车查询 |

#### 4.4.2 数据范围

耗材页签只展示：

1. 当前系统中属于耗材类型的记录。
2. 耗材当前责任人 = 当前查询员工。

员工当前无责任耗材时返回空结果。

#### 4.4.3 列表字段

| 字段 | 规则 |
| --- | --- |
| 耗材标签号 | 当前耗材标签号；蓝色链接；点击打开耗材详情 |
| 耗材说明 | 当前耗材卡片中的耗材说明 |
| 耗材状态 | 展示完整业务状态名称 |
| 耗材责任人 | 当前耗材责任人，格式为“工号.姓名” |
| 关联主资产标签号 | 当前耗材关联的主资产标签号；未关联主资产时显示“-”；普通文本，不提供点击入口 |
| 主资产资产说明 | 根据关联主资产取得资产说明；未关联主资产时显示“-” |

耗材页签字段命名统一复用“耗材维护”已确认口径，不再使用“资产大类 / 资产小类 / 资产说明 / 责任人 / 状态”等旧称。

#### 4.4.4 默认排序

耗材页签默认按所在单据编号倒序；没有所在单据编号的记录排在有单据编号记录之后。所在单据编号相同时，按耗材标签号升序。

### 4.5 合约号码页签

#### 4.5.1 查询条件

| 字段 | 控件/规则 |
| --- | --- |
| 员工信息 | 共用人员选择器 |
| 合约号码 | 文本输入；按合约号码过滤；支持回车查询 |

#### 4.5.2 数据范围

合约号码页签查询满足以下条件的数据：

1. 合约号码当前责任人 = 当前查询员工。
2. 合约号码状态 = 在用-使用中。

员工当前无有效合约号码时返回空结果。

#### 4.5.3 列表字段

| 字段 | 规则 |
| --- | --- |
| 行号 | 按当前查询结果展示顺序生成 |
| 合约号码 | 当前员工持有的合约号码；蓝色链接；点击打开合约号码详情 |
| 合约号码说明 | 合约号码台账中的套餐名称或号码说明；无值显示“-” |
| 合约号码状态 | 展示完整业务状态名称 |
| 责任人 | 当前责任人，格式为“工号-姓名” |
| 责任人公司 | 从责任人人员主数据中取得当前财务公司；无值显示“-” |
| 所在单据编号 | 当前关联业务单据编号；有详情入口时为蓝色链接；无关联单据时显示“-” |

| 单据类型 | 当前关联单据类型；无关联单据时显示“-” |

| 单据审批环节 | 当前单据所处审批或办理环节；无审批信息时显示“-” |
| 单据审批人 | 当前审批人或办理人；无审批人时显示“-” |

责任人公司取责任人在人员主数据中的当前财务公司，不取合约号码台账中的使用公司，也不取领用时的历史公司快照。

#### 4.5.4 关联单据展示规则

1. 单据信息取合约号码台账当前关联的业务单据。
2. 不根据员工曾经申请过的其他单据反向补充关联单据信息。
3. 没有关联业务单据时，所在单据编号、单据申请人、单据类型、单据业务类型、单据审批环节和单据审批人统一显示“-”。
4. “所在单据编号”只在存在明确详情入口时展示为蓝色链接。

#### 4.5.5 默认排序

合约号码页签默认按所在单据编号倒序；没有所在单据编号的记录排在有单据编号记录之后。所在单据编号相同时，按号码记录对应的标签号升序。号码记录对应的标签号只参与排序，不在列表中展示。

### 4.6 单据信息页签

#### 4.6.1 查询条件

| 字段 | 控件/规则 |
| --- | --- |
| 员工信息 | 共用人员选择器 |
| 单据编号 | 文本输入；按申请单号或当前查询链路支持的业务单据编号过滤；支持回车查询 |
| 单据状态 | 下拉：已完成 / 处理中 / 已驳回 |

#### 4.6.2 单据查询范围

| 类型 | 查询范围 |
| --- | --- |
| 普通员工业务单据 | 员工领用、员工退库、员工转移、员工借用、员工续借、资产更换、担保相关、合约号码相关、新员工领用等员工业务 |
| 员工库存类申请 | 员工库存类申请及该申请形成的后续库存业务单据 |
| 员工采购类申请 | 员工采购类申请及该申请形成的后续采购、接收或执行单据 |
| 独立入库单 | 无上游员工申请流程的退库、借用归还等入库业务 |
| 独立出库单 | 无上游员工申请流程的出库业务 |
| 独立资产转移单 | 无上游员工申请流程的资产转移业务 |

#### 4.6.3 员工关联规则

不同业务分支必须按各自真实员工关系查询，不允许统一简化成“按申请人查询”。

| 业务分支 | 员工关联规则 |
| --- | --- |
| 普通员工业务单据 | 优先使用单据头申请人员；申请人员为空时，使用单据头领用人员兜底 |
| 员工库存类申请 | 按员工申请单上的申请人员或领用人员关联，并继续关联展示由该申请形成的后续库存业务单据 |
| 员工采购类申请 | 按员工申请关系中的申请人员或领用人员关联，并继续关联展示由该申请形成的采购、接收或后续执行单据 |
| 独立入库单 | 按入库明细中的退回人员关联；员工不要求是单据头申请人 |
| 独立出库单 | 按出库明细中的责任人关联；员工不要求是单据头申请人 |
| 独立资产转移单 | 按转移明细中的责任人或申请人关联，任一关系命中即可 |

边界规则：

1. 普通员工业务单据不反向使用出库明细责任人替代单据头人员关系。
2. 独立入库单不得使用单据头申请人替代入库明细退回人员。
3. 独立出库单不得使用单据头申请人替代出库明细责任人。
4. 独立资产转移单不能只认责任人，明细申请人同样属于有效员工关系。
5. 所有分支最终返回的记录都必须能够通过对应业务关系明确归属于当前查询员工。

#### 4.6.4 已识别业务类型

当前需求明确覆盖：

- 更换
- 退库
- 员工转移
- 借用
- 续借
- 担保
- 统一申请
- 合约号码
- 新员工领用
- 出库
- 入库
- 资产转移

#### 4.6.5 单据状态

单据信息页签的状态筛选固定为：

1. 已完成
2. 处理中
3. 已驳回

状态规则：

1. 列表中的单据状态统一展示为已完成、处理中或已驳回。
2. 查询条件按列表展示的三种状态过滤。
3. 取消、撤回、作废等其他状态不进入本页状态候选。

#### 4.6.6 列表字段

| 字段 | 规则 |
| --- | --- |
| 行号 | 按当前查询结果展示顺序生成 |
| 申请单号 | 每条员工单据信息必须有值；普通申请类展示申请单号；独立入库、独立出库、独立资产转移等无上游员工申请流程的记录，展示当前业务主单号；有详情入口时为蓝色链接 |
| 单据类型 | 展示业务单据类型名称 |
| 业务类型 | 展示业务类型名称 |
| 单据状态 | 展示业务单据当前完整状态名称 |
| 申请人 | 单据申请人 |
| 申请时间 | 单据创建或申请时间 |
| 核心单据 | 申请业务进一步形成的出库、入库、资产转移等执行单据；存在时可点击进入对应核心单据详情；不存在时显示“-” |
| 公司 | 单据保存的财务公司；无值显示“-” |
| 板块 | 单据保存的板块；无值显示“-” |
| 部门 | 单据保存的部门；无值显示“-” |
| 操作 | 存在流程记录时展示【查看流程】；点击打开当前业务流程记录；无流程记录时显示“-” |

#### 4.6.7 默认排序

员工单据信息按申请时间降序展示。

#### 4.6.8 单据详情路由

1. 申请单号为员工单据信息的必有主业务编号，根据单据类型打开对应业务详情。
2. 当前需要支持退库、转移、借用、续借、更换、统一申请、合约号码、新员工领用、入库、出库、资产转移和仓库移库详情。
3. 历史单据不进入新系统详情，统一跳转至旧系统对应单据详情页。
4. 当前单据存在，但系统未配置对应详情页面时，保留可点击入口并提示“暂无明细展示页面！请联系维护人员添加。”
5. 不允许因为未配置详情页面而阻断单据本身的查询和列表展示。

## 5. 校验

### 5.1 员工信息校验

1. 员工信息未选择时，不执行查询。
2. 离职员工允许通过人员选择器查询、选择，并可正常查询其关联资产、耗材、合约号码和单据信息。
3. 查询工号不存在，且系统无法取得对应员工信息时，提示“未查询到对应员工信息。”

### 5.2 页签查询条件校验

1. 当前页签不适用的查询条件不得参与查询。
2. 资产页签的资产标签号只作用于资产页签。
3. 耗材页签的耗材标签号只作用于耗材页签。
4. 合约号码条件只作用于合约号码页签。
5. 单据编号、单据状态只作用于单据信息页签。
6. 单据状态候选固定为：已完成、处理中、已驳回。

### 5.3 数据归属校验

1. 资产必须满足资产责任人 = 当前查询员工。
2. 耗材必须满足耗材当前责任人 = 当前查询员工。
3. 合约号码必须满足合约号码当前责任人 = 当前查询员工。
4. 普通员工业务、员工库存类申请和员工采购类申请按单据头申请人或领用人员关系校验，其中普通员工业务申请人为空时才使用领用人员兜底。
5. 独立入库按入库明细退回人员校验。
6. 独立出库按出库明细责任人校验。
7. 独立资产转移按转移明细责任人或申请人校验。
8. 不允许跨业务分支混用员工关系字段。
9. 不允许使用“申请人命中”替代资产、耗材、合约号码的当前责任关系判断。

### 5.4 详情入口校验

1. 资产标签号只能打开对应资产卡片。
2. 耗材标签号只能打开对应耗材详情。
3. 合约号码只能打开对应合约号码详情。
4. 员工单据信息中的申请单号不得为空；独立入库、独立出库、独立资产转移无上游申请流程时，以当前业务主单号填充申请单号。
5. 核心单据只在当前申请进一步形成下游执行单据时展示并提供详情入口。
6. 历史单据详情跳转至旧系统对应单据详情页。
7. 当前单据对象存在但未配置详情页面时，保留可点击入口并提示“暂无明细展示页面！请联系维护人员添加。”
8. 无对应详情对象时展示普通文本，不提供空链接。
9. 耗材页签中的“关联主资产标签号”为普通文本，不提供点击入口。

## 6. 后续操作 / 业务结果 / 补充说明

### 6.1 查询结果

点击【查询】后：

1. 以当前员工为公共查询对象。
2. 只查询当前页签适用的数据范围。
3. 清空当前页签旧结果。
4. 返回当前页签第 1 页。
5. 查询失败时保留查询条件，并提示失败原因。

### 6.2 详情查看结果

点击详情入口后，打开对应业务对象的详情或流程信息。

### 6.3 历史单据详情

历史单据查看规则：

> 历史单据跳转至旧系统对应单据详情页。
