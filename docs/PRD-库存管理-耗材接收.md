# 库存管理 - 耗材接收 PRD

## 1. 背景

耗材接收用于处理采购到货后的低值耐用品及普通耗材接收业务。

采购类型分为：

| 类型 | 系统采购类型值 | 接收方式 |
|---|---|---|
| 低值耐用品 | 低值耐用品 | PO → 创建接收单 → 逐件维护耗材标签号、SN → 接收确认 → 生成采购接收入库草稿单 → 后续执行正式入库 |
| 普通耗材 | 耗材 | PO → 创建接收单 → 接收确认 → 接收完成并同步完成入库 → 生成已完成采购接收入库单 |

资产、服务器、网络设备及其备件不在本模块处理，由“资产接收”模块处理。

耗材接收解决“实际收到了什么，以及本次接收数量是多少”。

低值耐用品接收完成后仍需进入“库存管理 → 入库”执行正式入库；普通耗材在接收确认时同步完成入库和库存增加，不再执行第二次入库操作。

耗材接收链路不维护申请批次，也不维护任何部件信息。

## 2. 权限

权限采用“公司 + 板块数据范围”与“耗材仓操作权限”两层控制。

### 2.1 数据权限

- 公司、板块决定用户可查看和查询的 PO、采购行及接收单范围。
- 用户无对应公司或板块数据权限时，不返回对应 PO、采购行及接收单。
- PO 列表、接收单列表、详情页均按相同数据权限过滤。

### 2.2 操作权限

业务匹配的耗材仓权限决定用户能否执行以下操作：

- 创建接收单；
- 编辑接收信息；
- 删除草稿接收单；
- 删除接收行；
- 维护低值耐用品逐件明细；
- 删除逐件明细；
- 生成耗材标签号；
- 维护 SN；
- 打印标签；
- 执行接收确认；
- 打印正式接收单。

无耗材仓操作权限时只允许查看已有数据，不允许提交业务操作。

页面展示、打开详情及提交操作时均重新校验权限，不能仅依赖前端按钮显隐判断权限。

## 3. 通用规则

### 3.1 接收模式

#### 3.1.1 低值耐用品

低值耐用品采用“先形成草稿接收单，再逐件维护”的方式接收。

业务过程：

1. 用户进入耗材 PO 接收页面。
2. 系统根据采购数量、已接收数量和草稿占用计算剩余可接收数量。
3. 系统根据采购订单使用部门自动计算成本中心和默认板块。
4. 库管在创建接收单前可以根据实际情况调整板块。
5. 用户勾选一个或多个可接收 PO 行，点击【创建接收单】。
6. 系统生成草稿接收单，并立即形成草稿数量占用。
7. 用户进入接收单详情，点击【维护接收明细】。
8. 系统按“每接收 1 件生成 1 条逐件明细”拆分。
9. 用户生成耗材标签号并维护 SN。
10. 全部逐件明细满足条件后点击【接收确认】。
11. 接收单变为已完成，草稿数量转为已接收数量。
12. 系统生成采购接收入库草稿单。
13. 用户进入“库存管理 → 入库”执行正式入库。
14. 正式入库成功后增加目标耗材仓库存、生成耗材台账卡片并更新 PO 入库状态。

#### 3.1.2 普通耗材

普通耗材采用“草稿接收单 + 接收确认时自动入库”的方式处理，不维护逐件接收明细。

业务过程：

1. 用户进入耗材 PO 接收页面。
2. 系统计算剩余可接收数量。
3. 系统根据采购订单使用部门自动计算成本中心和默认板块。
4. 库管在创建接收单前可以根据实际情况调整板块。
5. 用户勾选一个或多个可接收 PO 行，点击【创建接收单】。
6. 系统生成草稿接收单，并立即形成草稿数量占用。
7. 用户进入接收单详情直接点击【接收确认】。
8. 系统根据当前公司唯一匹配耗材仓。
9. 校验全部通过后，在同一个原子业务动作中：
   - 完成接收；
   - 生成已完成采购接收入库单；
   - 增加目标耗材仓库存数量；
   - 草稿数量转为已接收数量；
   - 更新 PO 行及 PO 状态。
10. 用户不需要再进入入库模块执行第二次操作。

普通耗材“接收确认 + 自动入库 + 库存增加”必须全部成功或全部失败，不允许出现部分成功。

### 3.2 状态规则

耗材接收同时存在 PO 状态、PO 行状态、接收单状态，三类状态独立判断。

#### 3.2.1 PO 状态

| 状态 | 判断规则 |
|---|---|
| 待接收 | 任一采购行仍存在未完成接收数量 |
| 已接收 | 所有采购行均完成接收，但仍存在尚未正式入库的低值耐用品 |
| 已入库 | 对应采购数量均完成正式入库 |

规则：

- 部分接收后，只要任一 PO 行仍有剩余未接收数量，整张 PO 保持“待接收”。
- 低值耐用品全部完成接收但尚未全部正式入库时，PO 为“已接收”。
- 普通耗材接收确认同步完成入库，全量完成后可以直接进入“已入库”。
- 同一张 PO 同时存在不同接收进度时，以整张 PO 是否仍有未接收数量、是否仍有未正式入库数量为最终判断依据。

#### 3.2.2 PO 行状态

| 状态 | 判断规则 |
|---|---|
| 待接收 | 当前行仍存在剩余未接收数量 |
| 已接收 | 当前行采购数量全部完成接收，但尚未全部正式入库 |
| 已入库 | 当前行对应采购数量全部正式入库 |

PO 行【编辑】显隐与字段是否可编辑是两个独立判断：

- 【编辑】是否展示：PO 未已入库且剩余可接收数量大于 0 时展示。
- 字段是否可编辑：只判断当前 PO 行是否被草稿接收单引用。
- 已完成接收记录不作为物料、配置字段锁定条件。
- 剩余可接收数量为 0 时不展示【编辑】，即使该行仍存在草稿接收引用也不额外展示。

#### 3.2.3 接收单状态

接收单状态仅包含：

| 状态 | 说明 | 数据是否可维护 |
|---|---|---|
| 草稿 | 接收单已创建，接收业务尚未完成 | Y |
| 已完成 | 已执行接收确认 | N |

接收单固定按“草稿 → 已完成”流转。

不新增“已取消”“已作废”等第三种接收单状态。

### 3.3 可接收数量与草稿占用

低值耐用品和普通耗材均支持分批接收。

剩余可接收数量计算规则：

可接收数量 = 采购数量 - 已接收数量 - 草稿数量

其中：

- 已接收数量：已经完成接收确认的数量。
- 草稿数量：被有效草稿接收单占用、但尚未完成确认的数量。
- 创建草稿接收单后，本次接收数量立即计入草稿数量。
- 接收确认成功后，本次数量从草稿数量转入已接收数量。

以下操作需要释放对应草稿数量：

| 操作 | 数量处理 |
|---|---|
| 删除草稿接收单 | 释放整张草稿接收单占用数量 |
| 删除接收行 | 释放该接收行对应草稿数量 |
| 删除低值耐用品逐件明细 | 来源接收行数量同步减少，并释放相同草稿数量 |

PO 行【编辑】是否展示始终按重新计算后的剩余可接收数量判断。

如果某 PO 行已被草稿接收单引用，且仍有剩余可接收数量，因此可以进入【编辑】，本次接收数量允许在该草稿当前占用数量范围内重新调整。

被草稿引用时数量上限按：

当前未占用可接收数量 + 当前草稿接收行已占用数量

计算。

保存后按新旧数量差额同步调整：

- 当前草稿接收行本次接收数量；
- PO 行草稿数量；
- 当前 PO 行剩余可接收数量。

### 3.4 PO 级板块固化

耗材接收不维护申请批次，PO、接收单、低值耐用品维护页及后续耗材接收入库数据均不使用申请批次作为本链路业务字段。

PO 级需要固化的字段为板块。

规则：

- 创建接收单前板块必填。
- 当前 PO 尚无任何接收单时，板块允许调整。
- 首次形成有效接收单后，板块立即固化为只读。
- 草稿接收单和已完成接收单均属于有效接收单。
- 后续分批接收统一沿用首次接收时最终确认的板块。
- 接收单及后续采购接收入库数据均使用该最终板块。
- 删除全部草稿后，如果当前 PO 已不存在任何接收单，板块重新允许调整。
- 只要 PO 已存在已完成接收单，板块继续保持固化。

PO 级板块固化与 PO 行物料、配置字段锁定相互独立。

已完成接收单继续固化 PO 级板块，但不继续锁定仍有后续可接收数量的 PO 行物料、配置。

### 3.5 PO 行编辑与草稿引用锁定

PO 行仅在以下条件同时满足时展示【编辑】：

- PO 未处于“已入库”；
- 剩余可接收数量 > 0。

草稿接收单引用本身不会让“剩余可接收数量 = 0”的 PO 行额外显示【编辑】。

#### 3.5.1 未被草稿接收单引用

允许维护：

- 物料；
- 配置；
- 本次接收数量。

#### 3.5.2 已被草稿接收单引用

以下字段只读：

- 物料；
- 配置。

本次接收数量仍允许调整，并按草稿占用规则重新计算。

保存时只允许持久化本次接收数量变化，不能使用编辑弹窗中的旧值覆盖已经固化的物料和配置。

#### 3.5.3 草稿引用解除

删除接收行、删除逐件明细或删除草稿接收单后，重新判断当前 PO 行是否仍被其他草稿接收单引用：

- 无草稿引用：物料、配置恢复可编辑；
- 仍有草稿引用：物料、配置继续只读。

【编辑】是否展示仍单独根据剩余可接收数量重新判断。

已完成接收记录不作为 PO 行物料、配置字段锁定条件。

保存 PO 行接收侧修改仅更新耗材接收侧数据，不反写采购系统原始 PO。

### 3.6 使用部门、成本中心与板块

采购订单中带有使用部门。

耗材接收进入 MMP 后按以下顺序自动确定默认板块：

使用部门 → 成本中心 → 板块

规则：

1. 系统读取采购订单使用部门。
2. 根据部门归属关系取得对应成本中心。
3. 根据成本中心与板块映射取得默认板块。
4. PO 接收页面直接展示系统计算得到的默认板块。
5. 成本中心作为部门与板块之间的业务映射结果，用于规则计算和后续接收数据，不作为当前 PO 基础信息中的独立可编辑字段。
6. 库管在创建接收单前可以根据实际情况重新选择板块。
7. 库管手工调整后，以接收页面最终选择的板块为准。
8. 人工调整后的板块优先级高于系统自动计算结果；重新进入同一 PO 时不得再次被自动结果覆盖。
9. 首次创建接收单后，板块按最终选择值固化，后续分批接收统一沿用。
10. 自动判断后板块仍为空时，必须由库管在创建接收单前选择有效板块。

### 3.7 申请批次

耗材接收链路不维护申请批次。

以下位置均不展示、不编辑申请批次：

- 耗材 PO 接收页面；
- 普通耗材接收单详情；
- 低值耐用品接收单详情；
- 低值耐用品维护 / 查看接收明细；
- 耗材接收生成的后续采购接收入库数据。

### 3.8 部件边界

耗材接收链路不维护任何部件数据，包括：

- 是否部件；
- 部件数量；
- 部件说明；
- 子部件标签号；
- 部件 SN；
- 部件组合信息。

该规则同时适用于：

- 普通耗材；
- 低值耐用品；
- PO 物资明细；
- 编辑接收信息；
- 接收单接收行；
- 低值耐用品逐件明细；
- 标签 / SN 处理；
- 后续采购接收入库数据。

### 3.9 标签号与 SN

标签号、SN 仅适用于低值耐用品逐件明细。

#### 3.9.1 标签号

- 每个低值耐用品逐件明细维护一个耗材标签号。
- 标签号为空时允许生成。
- 已有标签号不得被批量生成操作覆盖。
- 全部标签号生成后允许使用扫描功能。
- 全部标签号生成后允许打印标签。
- 草稿和已完成接收单均允许打印已有标签。

#### 3.9.2 SN

| 类型 | 规则 |
|---|---|
| 真实 SN | 用户录入或扫码；需要唯一性校验 |
| 缺省 | 合法；视为已维护；不参与真实 SN 唯一性校验 |

规则：

- 同一接收单内部真实 SN 不得重复。
- 与系统现有资产 / 耗材真实 SN 不得重复。
- 多条低值耐用品允许同时使用“缺省”。
- 批量维护“缺省”仅处理空白 SN，不覆盖已有真实 SN。
- SN 保存成功后实时写入当前逐件明细。

### 3.10 耗材仓匹配

低值耐用品和普通耗材均按当前公司匹配耗材仓。

每个公司必须唯一匹配一个有效耗材仓。

| 匹配结果 | 处理 |
|---|---|
| 唯一匹配 | 正常继续接收确认 |
| 未匹配 | 阻断：未找到当前公司对应的耗材仓库 |
| 匹配多个 | 阻断：当前公司匹配到多个耗材仓库，请检查耗材仓配置 |

低值耐用品：

- 将唯一匹配的耗材仓写入采购接收入库草稿单；
- 正式库存增加发生在后续执行入库时。

普通耗材：

- 接收确认时直接使用唯一匹配的耗材仓完成库存增加；
- 同时生成已完成采购接收入库单。

### 3.11 制单人与接收人

系统记录制单和接收审计信息，但记录字段与页面是否展示分开处理。

| 字段 | 取值时点 |
|---|---|
| 制单人 | 创建草稿接收单时当前操作人 |
| 制单时间 | 草稿创建成功时间 |
| 接收人 | 接收确认成功时当前操作人 |
| 接收时间 | 接收确认成功时间 |

草稿状态下接收人、接收时间为空。

接收单列表保留制单人、制单时间用于查询和追溯。

普通耗材、低值耐用品接收单详情以及低值耐用品维护 / 查看接收明细均不展示制单人、制单时间。

### 4.2 PO 接收页面

顶部统一提示：

默认为全量接收，可点击编辑按钮修改接收数量！

#### 4.2.1 PO 基础信息

| 供应商 | N | 来源 PO |
| 供应商联系电话 | N | 来源 PO |
| PO 单说明 | N | 来源 PO |
| 采购单位 | N | 来源 PO |
| 合同主体 | N | 来源 PO |
| 不含税合计 | N | 低值耐用品展示 |

| 合计金额 | N | 低值耐用品展示 |

#### 4.7.2 扫描交互

扫描采用“先耗材标签号、后 SN”两步方式。

前置条件：

- 接收单必须为草稿；
- 当前接收单必须已生成全部耗材标签号。

扫描区域与扫描核对信息放在同一个 Card。

核对区固定展示：

- 耗材标签号；
- SN号；
- 耗材说明；
- 配置。

规则：

1. 未定位逐件明细时，核对字段保持空白。
2. 第一次扫描耗材标签号。
3. 系统在当前接收单内查找对应逐件明细。
4. 未找到时提示：未找到对应标签号。
5. 标签号命中后：
   - 在核对区带出耗材标签号、SN号、耗材说明、配置；
   - 下方逐件明细仍保持全量展示；
   - 命中行保持勾选；
   - 扫描状态切换为等待 SN。
6. 第二次扫描 SN。
7. 写入前执行真实 SN 唯一性校验。
8. SN 保存成功后实时写入当前逐件明细。
9. 保存完成后：
   - 清空扫描输入；
   - 清空当前定位状态；
   - 扫描状态恢复为等待下一条耗材标签号；
   - 下方全量列表保持不变；
   - 刚处理行保持勾选并定位到对应分页。
10. 点击【重置】后：
   - 清空扫描输入；
   - 清空定位状态；
   - 清空勾选状态；
   - 核对区恢复空白；
   - 返回第 1 页；
   - 下方明细仍保持全量展示。
11. 已完成接收单进入【查看接收明细】时不展示扫描 Card，仅保留只读逐件明细。

## 5. 校验

### 5.1 创建接收单

| 场景 | 校验 / 提示 |
|---|---|
| 未选择采购行 | 请选择要接收的物料！ |
| 板块为空 | 请选择板块！ |
| 所选行无可接收数量 | 所选物资当前没有可接收数量 |
| PO 已入库 | 不允许新增接收业务 |

创建失败时：

- 不生成接收单；
- 不增加草稿数量；
- 不固化板块；
- 不产生后续入库数据。

### 5.2 编辑 PO 行

接收数量校验：

- 必须为大于 0 的整数。
- 未被草稿接收单引用时，不得超过当前剩余可接收数量。
- 被草稿接收单引用时，上限 = 当前未占用可接收数量 + 当前草稿接收行已占用数量。

字段权限校验：

- 当前行无草稿接收引用时，允许修改物料、配置。
- 当前行存在草稿接收引用时，物料、配置只读，保存时不得覆盖。
- 已完成接收记录不作为物料、配置字段锁定条件。

### 5.3 板块

- 系统优先根据使用部门自动计算成本中心和默认板块。
- 创建接收单前板块必填。
- 当前 PO 已存在任意草稿或已完成接收单时，禁止修改板块。
- 删除全部草稿且当前 PO 不存在任何接收单后，板块恢复可调整。
- 人工调整板块后，重新进入 PO 不得被自动计算结果覆盖。

### 5.4 低值耐用品维护

进入维护接收明细前：

- 当前接收单必须存在有效接收行。
- 每条接收行本次接收数量必须大于 0。

逐件明细数量必须与接收数量一致。

标签号：

- 仅为空时生成；
- 已有标签号不得覆盖；
- 扫描前要求全部标签号已生成。

SN：

- 真实 SN 不得与当前接收单其他真实 SN 重复；
- 真实 SN 不得与系统现有资产 / 耗材真实 SN 重复；
- “缺省”允许重复；
- “缺省”不参与真实 SN 唯一性校验；
- 批量维护“缺省”不得覆盖已有真实 SN。

### 5.5 低值耐用品接收确认

接收确认前必须满足：

- 至少存在一条有效接收行；
- 逐件明细数量与接收数量一致；
- 每条逐件明细均有耗材标签号；
- 每条逐件明细均有 SN；
- 所有非“缺省”的真实 SN 唯一；
- 当前公司能够唯一匹配耗材仓。

任一校验失败时：

- 接收单继续保持草稿；
- 已维护的有效标签号、SN、备注保留；
- 不生成采购接收入库草稿单；
- 不修改正式库存。

### 5.6 普通耗材接收确认

接收确认前必须满足：

- 至少存在一条有效接收行；
- 每条接收行本次接收数量有效；
- 当前公司能够唯一匹配耗材仓。

接收、入库单生成和库存增加属于一个原子业务动作。

任一环节失败时：

- 接收单继续保持草稿；
- 不生成半完成入库结果；
- 不增加库存；
- 草稿占用保持原状态，允许用户修正后重新确认。

### 5.7 耗材仓

| 场景 | 处理 |
|---|---|
| 当前公司无有效耗材仓 | 阻断：未找到当前公司对应的耗材仓库 |
| 当前公司匹配多个有效耗材仓 | 阻断：当前公司匹配到多个耗材仓库，请检查耗材仓配置 |
| 唯一匹配 | 正常继续 |

### 5.8 删除草稿业务

删除草稿接收单、接收行或低值耐用品逐件明细时，必须同步校验并更新：

- 草稿数量；
- 剩余可接收数量；
- 当前 PO 行草稿引用状态；
- PO 行物料、配置字段锁定状态；
- PO 行【编辑】按钮显隐；
- PO 级板块固化状态。

### 5.9 打印

标签打印：

- 仅低值耐用品使用。
- 待打印逐件明细必须已有耗材标签号。
- 存在空白标签号时【打印标签号】不可用。
- 草稿和已完成接收单均允许打印标签。

正式接收单打印：

- 仅已完成接收单允许打印。
- 草稿不打印正式接收单。
- 打印失败允许重试，不重复产生接收或库存业务数据。

## 6. 后续操作 / 业务结果 / 补充说明

### 6.1 删除接收行

仅草稿接收单允许删除接收行。

删除前必须选择需要删除的接收行。

删除后：

1. 删除所选接收行。
2. 低值耐用品同时删除来源于该接收行的逐件明细。
3. 释放该接收行对应 PO 草稿数量。
4. 重新计算 PO 行剩余可接收数量。
5. 重新判断当前 PO 行是否仍被其他草稿接收单引用：
   - 无草稿引用：物料、配置恢复可编辑；
   - 仍有草稿引用：物料、配置继续只读。
6. 根据新的剩余可接收数量重新判断【编辑】按钮显隐。

提示：

确认删除接收行？

确认内容需要说明：删除接收行会释放对应 PO 草稿占用数量。

### 6.2 删除草稿接收单

仅草稿接收单允许删除。

删除前必须选择需要删除的接收单。

删除后：

1. 删除接收单头。
2. 删除接收行。
3. 删除低值耐用品已生成的逐件明细。
4. 释放整张草稿接收单对应 PO 草稿数量。
5. 重新计算 PO 行剩余可接收数量。
6. 重新计算 PO 行草稿引用状态。
7. 重新计算 PO 级板块固化状态。

PO 级处理：

- 如果删除后当前 PO 已不存在任何接收单，板块恢复可调整。
- 如果仍存在其他草稿或已完成接收单，板块继续只读。

PO 行处理：

- 无其他草稿引用：物料、配置恢复可编辑。
- 仍有其他草稿引用：物料、配置继续只读。
- 【编辑】按钮按新的剩余可接收数量重新判断。

提示：

请先选择需要删除的接收单！

确认删除接收单？

确认内容需要说明：删除草稿接收单会释放对应 PO 草稿占用数量。

删除草稿接收单不新增“已取消”“已作废”等状态。

### 6.3 删除低值耐用品逐件明细

仅草稿低值耐用品接收单允许删除逐件明细。

删除后：

1. 删除所选逐件明细。
2. 每删除 1 条逐件明细，来源接收行本次接收数量同步减少 1。
3. 对应 PO 行草稿数量同步减少 1。
4. PO 行剩余可接收数量同步增加 1。
5. 重新计算当前接收行金额、税额相关结果。
6. 如果来源接收行数量减少至 0，则从当前草稿接收单中移除该接收行。
7. 重新判断当前 PO 行草稿引用状态。
8. 根据新的剩余可接收数量重新计算【编辑】按钮显隐。
9. 如果被删除明细正处于扫描定位状态，清空当前扫描定位。
10. 删除完成后回到逐件明细第 1 页并清空勾选。

### 6.4 低值耐用品接收确认结果

接收确认成功后：

- 接收单状态更新为已完成；
- 写入接收人、接收时间；
- 草稿数量转为已接收数量；
- 接收快照固化；
- PO 行、PO 状态按累计接收数量重新计算；
- PO 级板块继续保持固化；
- 当前已完成接收单不再作为 PO 行物料、配置字段锁定条件；
- 如果同一 PO 行后续仍有剩余可接收数量且不存在其他草稿引用，则物料、配置可以在下一批接收前重新维护；
- 系统按当前公司唯一匹配耗材仓；
- 生成采购接收入库草稿单；
- 目标耗材仓写入采购接收入库草稿单；
- 不在接收确认阶段增加正式库存。

用户后续进入“库存管理 → 入库”执行正式入库。

正式入库成功后：

- 增加目标耗材仓库存；
- 生成对应耗材台账卡片；
- 生成正式库存事务；
- 根据累计入库结果更新 PO 行和 PO 状态。

### 6.5 普通耗材接收确认结果

普通耗材接收确认成功后，在同一个原子业务动作中完成：

- 接收单状态更新为已完成；
- 写入接收人、接收时间；
- 草稿数量转为已接收数量；
- 接收快照固化；
- 根据当前公司唯一匹配目标耗材仓；
- 生成已完成采购接收入库单；
- 增加目标耗材仓库存数量；
- 生成库存事务结果；
- 重新计算 PO 行和 PO 状态；
- PO 级板块继续保持固化。

普通耗材不生成逐件耗材标签号，不维护 SN，不生成待后续执行的采购接收入库草稿单。

普通耗材接收确认成功后不再进入入库模块执行第二次操作。

### 6.6 接收与入库边界

低值耐用品：

接收确认只完成实物接收并生成采购接收入库草稿单。

正式库存增加、耗材台账卡片创建和正式库存事务均在后续“库存管理 → 入库”执行成功后产生。

普通耗材：

接收确认与入库属于同一个业务动作。

接收确认成功即同步产生已完成采购接收入库单及库存增加结果。

### 6.7 已完成接收单

已完成后以下数据不可修改：

- 接收单头；
- 接收行；
- 低值耐用品逐件明细；
- 低值耐用品耗材标签号；
- 低值耐用品 SN；
- 低值耐用品备注。

允许：

- 只读查看；
- 低值耐用品查看逐件明细；
- 低值耐用品补打已有标签；
- 接收单打印；
- 作为后续采购接收入库数据来源。

已完成接收单继续参与 PO 级板块固化。

已完成接收单不参与 PO 行物料、配置字段锁定判断。

### 6.8 标签打印

仅低值耐用品使用标签打印。

规则：

- 草稿和已完成接收单均允许打印已有标签。
- 对应逐件明细必须已有耗材标签号。
- 标签号未全部生成时，【打印标签号】保持展示但置灰。
- 已完成接收单允许补打标签。
- 标签打印不修改接收数量、PO 状态、接收单状态或入库结果。

### 6.9 物资接收单打印

仅已完成接收单允许打印正式“物资接收单”。

规则：

- 打印读取接收完成快照。
- 草稿不打印正式接收单。
- 打印失败允许重试。
- 打印失败不重复执行接收确认。
- 打印失败不重复生成采购接收入库单。
- 打印失败不重复增加库存。
- 打印动作不修改接收数量、PO 状态或库存结果。
