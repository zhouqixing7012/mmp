# 库存管理 - 耗材接收 PRD

## 1. 背景

耗材接收用于处理采购到货后的低值耐用品及普通耗材接收业务。

用户根据采购 PO 查看待接收物资，维护本次实际接收数量并创建接收单。根据采购类型不同，接收完成后的处理方式不同：

| 采购类型 | 接收流程 |
|---|---|
| 低值耐用品 | PO → 创建接收单 → 逐件维护耗材标签号、SN → 接收确认 → 接收完成 → 自动生成采购接收入库草稿单 → 后续执行正式入库 |
| 耗材 | PO → 创建接收单 → 接收确认 → 接收完成并自动完成入库 → 自动生成已完成采购接收入库单 |

资产、服务器、网络设备及其备件不在本模块处理，由“资产接收”模块独立处理。

本版进一步明确接收侧数据冻结边界：**首次形成有效接收单即视为接收侧业务数据冻结点，草稿接收单同样参与冻结判断。**

## 2. 改造总结

| 改造项 | 改造后规则 |
|---|---|
| 采购类型 | 固定为“低值耐用品 / 耗材” |
| 接收单状态 | 固定为“草稿 / 已完成” |
| 分批接收 | 支持；草稿接收单中的接收数量立即计入草稿占用 |
| 可接收数量 | `采购数量 - 已接收数量 - 草稿数量` |
| 数据冻结点 | **只要 PO 已存在任意有效接收单，包括草稿，板块立即固化为只读** |
| PO 行编辑 | **仅当当前 PO 行仍有剩余可接收数量时展示【编辑】；草稿接收单引用时物料、配置只读，本次接收数量仍可改；已完成接收记录本身不锁定物料、配置** |
| 冻结释放 | 删除草稿接收单、删除草稿接收行或低值耐用品逐件明细后重新计算；某行不再被草稿接收单引用时物料、配置恢复可编辑 |
| 物料、配置修改 | 仅在该 PO 行未被草稿接收单引用时允许；草稿引用期间只读 |
| 板块 | 系统先按使用部门归属自动带出成本中心和默认板块；库管在创建接收单前可调整板块；首次形成接收单后以页面最终板块固化并用于后续处理 |
| 低值耐用品 | 按接收数量逐件拆分并维护耗材标签号、SN；完成接收后生成采购接收入库草稿单 |
| 普通耗材 | 不维护逐件接收明细；接收确认后自动完成入库并生成已完成采购接收入库单 |
| 耗材仓 | 按公司唯一匹配耗材仓；无法唯一匹配时阻断接收确认 |
| SN“缺省” | 合法 SN，视为已维护，不参与真实 SN 唯一性校验 |
| 制单人与接收人 | 创建草稿记录制单人、制单时间；接收确认成功后记录接收人、接收时间 |
| PO 状态 | 待接收 / 已接收 / 已入库 |
| 删除草稿接收单 | 删除后释放整单 PO 草稿数量并重新计算冻结状态 |
| 删除接收行 / 逐件明细 | 释放对应草稿数量并重新计算当前 PO 行冻结状态 |
| 低值耐用品正式入库 | 正式入库成功后增加目标耗材仓库存，生成耗材台账卡片并更新 PO 入库状态 |
| 普通耗材自动入库 | 接收确认成功后立即增加目标耗材仓库存数量 |

## 3. 业务流程

### 3.1 低值耐用品

1. 用户进入耗材接收 PO 页面，系统根据剩余可接收数量计算本次接收数量。
2. PO 行有剩余可接收数量时展示【编辑】。未被草稿接收单引用时可编辑物料、配置和本次接收数量；被草稿接收单引用时物料、配置只读，仅本次接收数量可改。
3. 采购订单带入使用部门后，系统按部门归属自动取得成本中心和默认板块；接收页面直接展示默认板块，库管在创建接收单前可按实际情况重新选择。
4. 用户勾选一个或多个可接收 PO 行，点击【创建接收单】。
5. 系统生成草稿接收单并立即占用对应 PO 草稿数量。
6. 草稿创建成功后：
   - 当前 PO 的板块立即固化为只读；
   - 本次接收单引用的 PO 行物料、配置等基础信息立即固化；
   - 仍有剩余可接收数量时，该行继续保留【编辑】，仅本次接收数量可调整并继续遵循原数量校验。
7. 用户进入接收单详情，点击【维护接收明细】。
8. 系统按“每接收 1 件生成 1 条明细”逐件拆分。
9. 用户生成耗材标签号并维护 SN。
10. 所有逐件明细满足条件后点击【接收确认】。
11. 系统将接收单更新为已完成并生成采购接收入库草稿单。
12. 用户后续进入“库存管理 → 入库”执行正式入库；正式入库后增加目标耗材仓库存并生成耗材台账卡片。

### 3.2 普通耗材

1. 用户进入耗材接收 PO 页面，系统根据剩余可接收数量计算本次接收数量。
2. PO 行未被接收单引用时，可编辑物料、配置和本次接收数量；已被任意接收单引用后仍可进入编辑，但只允许调整本次接收数量。
3. 系统根据采购订单使用部门自动取得成本中心和默认板块；库管接收前可调整板块，耗材 PO 页面不展示申请批次。
4. 用户勾选一个或多个可接收 PO 行，点击【创建接收单】。
5. 系统生成草稿接收单并立即占用对应 PO 草稿数量，同时冻结 PO 板块以及被引用 PO 行的物料、配置等基础信息。
6. 普通耗材不维护逐件接收明细，用户在接收单详情直接点击【接收确认】。
7. 系统根据当前公司匹配唯一耗材仓。
8. 校验通过后一次性完成接收和入库：接收单更新为已完成，生成已完成采购接收入库单并增加目标耗材仓库存数量。
9. 系统根据累计接收、入库数量重新计算 PO 行和整张 PO 状态。

普通耗材“接收确认 + 自动入库”属于一个完整业务动作，只允许全部成功或全部失败。

## 4. 通用规则

### 4.1 状态规则

#### 4.1.1 PO 状态

| 状态 | 说明 |
|---|---|
| 待接收 | 任一 PO 行仍存在未完成接收数量 |
| 已接收 | 所有采购行均完成接收，但仍存在尚未正式入库的低值耐用品 |
| 已入库 | 对应采购数量均完成入库 |

- 部分接收后只要仍有剩余未接收数量，整张 PO 保持“待接收”。
- 低值耐用品全部接收但未全部正式入库时为“已接收”。
- 普通耗材接收确认同步入库，全量完成后可直接进入“已入库”。

#### 4.1.2 PO 行状态

| 状态 | 判断规则 |
|---|---|
| 待接收 | 当前行仍有剩余未接收数量 |
| 已接收 | 当前行采购数量全部完成接收但尚未全部正式入库 |
| 已入库 | 当前行对应采购数量全部入库 |

**PO 行【编辑】只由剩余可接收数量决定。** 当前剩余可接收数量为 0 时不展示【编辑】，即使该行存在草稿接收引用也不额外展示；剩余可接收数量大于 0 时展示【编辑】。草稿接收引用期间物料、配置只读，本次接收数量仍可调整。

#### 4.1.3 接收单状态

| 状态 | 说明 | 接收单内数据是否可维护 |
|---|---|---|
| 草稿 | 接收单已创建，接收业务尚未完成 | Y |
| 已完成 | 已执行接收确认 | N |

接收单固定按 `草稿 → 已完成` 流转。

### 4.2 可接收数量

低值耐用品和普通耗材均支持分批接收：

`可接收数量 = 采购数量 - 已接收数量 - 草稿数量`

- 已接收数量：已经完成接收确认的数量。
- 草稿数量：被有效草稿接收单占用但尚未完成确认的数量。
- 创建草稿接收单后，本次接收数量立即计入草稿数量。
- 接收确认成功后，本次数量从草稿数量转入已接收数量。

以下操作释放草稿数量：

| 操作 | 数量处理 |
|---|---|
| 删除草稿接收单 | 释放整单占用 |
| 删除接收行 | 释放该接收行占用 |
| 删除低值耐用品逐件明细 | 来源接收行本次接收数量同步减少并释放相同草稿数量 |

数量释放与是否解锁编辑分别计算：只有当前 PO 行已经不再被任何接收单引用时，该行才恢复编辑。

### 4.3 接收快照与冻结规则

接收单保存本次实际接收时的数据快照。

首次形成有效接收单即为接收侧数据冻结点，**草稿接收单即视为有效接收单**。

#### PO 级冻结

只要当前 PO 存在至少一张草稿或已完成接收单：

- 板块只读；
- 不允许通过重新进入页面、切换列表或其他入口绕过冻结。

仅当删除草稿后当前 PO 已不存在任何接收单时，板块重新可编辑。

#### PO 行级冻结

某 PO 行只要被至少一张草稿或已完成接收单引用：

- 仍保留【编辑】入口，前提是该行仍有可接收数量且 PO 未已入库；
- 本次接收数量继续可编辑；
- 物料、配置等其他接收侧信息全部只读；
- 接收数量继续校验为大于 0 的整数，且不得超过当前可接收数量。

删除草稿接收行、草稿接收单或逐件明细导致来源接收行完全移除后，如果该 PO 行已经不再被其他接收单引用，则物料、配置重新可编辑；如果仍有其他引用，则继续只读。

### 4.4 物料、配置及接收信息修改规则

PO 行仅在仍有剩余可接收数量且 PO 未已入库时允许打开【编辑接收信息】。

未被草稿接收单引用时，可维护：

- 物料；
- 配置；
- 本次接收数量。

已被草稿接收单引用时：

- 物料只读；
- 配置只读；
- 本次接收数量仍可编辑；
- 保存时只提交本次接收数量变化，其他字段即使存在旧草稿值也不得覆盖当前固化值。

接收数量始终执行原校验：

- 必须为大于 0 的整数；
- 不得超过当前可接收数量。

保存修改只更新耗材接收侧数据，不反写采购系统原始 PO。

### 4.5 使用部门、成本中心与板块

采购订单中带有使用部门。耗材接收进入 MMP 后按以下规则处理：

1. 系统读取采购订单使用部门。
2. 根据部门归属规则取得对应成本中心。
3. 再根据成本中心与板块映射取得默认板块。
4. 接收页面直接展示系统计算得到的默认板块。
5. 库管在创建接收单前可根据实际情况重新选择板块。
6. 库管手工调整后，以接收页面最终选择的板块为准；重新进入 PO 时不得再次被自动计算结果覆盖。
7. 首次创建接收单后，板块固化为只读，后续分批接收统一沿用该最终板块。
8. PO 为“已入库”时板块只读。

原型优先复用业务规则中的“部门 → 成本中心”“成本中心 → 板块”映射。当前 Mock 映射未覆盖的部门保留采购单已有板块作为默认兜底，不额外编造映射数据。
### 4.6 耗材仓匹配

低值耐用品和普通耗材均按公司匹配耗材仓，每个公司必须唯一匹配一个有效耗材仓。

| 匹配结果 | 处理 |
|---|---|
| 唯一匹配 | 正常继续接收确认 |
| 未匹配 | 阻断：`未找到当前公司对应的耗材仓库` |
| 匹配多个 | 阻断：`当前公司匹配到多个耗材仓库，请检查耗材仓配置` |

低值耐用品将目标耗材仓写入采购接收入库草稿单；普通耗材使用该仓直接完成库存增加。

### 4.7 SN 规则

耗材接收链路不维护“是否部件、部件数量、部件说明、子部件标签号、部件 SN”等部件数据。

SN 仅适用于低值耐用品。

| 类型 | 规则 |
|---|---|
| 真实 SN | 用户录入或扫码；需要唯一性校验 |
| 缺省 | 合法；视为已维护；不参与真实 SN 唯一性校验 |

多个低值耐用品可以同时使用“缺省”。真实 SN 与现有资产 / 耗材真实 SN 重复时不得保存或完成接收。

### 4.8 SN 规则

SN 仅适用于低值耐用品。

| 类型 | 规则 |
|---|---|
| 真实 SN | 用户录入或扫码；需要唯一性校验 |
| 缺省 | 合法；视为已维护；不参与真实 SN 唯一性校验 |

多个低值耐用品可以同时使用“缺省”。真实 SN 与现有资产 / 耗材真实 SN 重复时不得保存或完成接收。

### 4.8 制单人与接收人

| 字段 | 取值时点 |
|---|---|
| 制单人 | 创建草稿时当前操作人 |
| 制单时间 | 草稿创建成功时间 |
| 接收人 | 接收确认成功时当前操作人 |
| 接收时间 | 接收确认成功时间 |

草稿状态接收人、接收时间为空。

### 4.9 权限

权限采用“公司/板块数据范围 + 仓库操作权限”两层控制：

1. 公司、板块决定用户可查看和查询的 PO、采购行及接收单范围；
2. 业务匹配的耗材仓权限决定用户能否创建接收单、编辑接收信息、删除草稿、维护逐件明细、执行接收确认和打印；
3. 页面展示数据、打开详情和提交操作时均重新校验权限；
4. 用户无数据范围时不返回对应记录，无仓库操作权限时只允许查看已有数据。

### 5.3 编辑接收信息

PO 未已入库且当前行剩余可接收数量大于 0 时允许进入。

| 字段 | 未被接收单引用 | 已被接收单引用 | 规则 |
|---|---|---|---|
| 物料 | 可改 | 只读 | 弹窗选择可用物料 |
| 配置 | 可改 | 只读 | 文本输入 |
| 接收数量 | 可改 | 可改 | 正整数且不超过当前可接收数量 |

保存时再次判断当前行是否被草稿接收单引用。若被引用，本次修改直接更新该草稿接收行的本次接收数量，并按差额同步调整 PO 草稿占用数量；物料、配置保持固化值。

接收数量不合法时不保存并提示。

### 5.4 创建接收单

前置校验：

| 场景 | 提示 |
|---|---|
| 未选择任何采购行 | 请选择要接收的物料！ |
| 板块为空 | 请选择板块！ |
| 所选行无可接收数量 | 所选物资当前没有可接收数量 |

创建成功后：

- 生成 REC 接收单号；
- 状态为草稿；
- 保存当前接收行快照；
- 本次接收数量立即计入草稿数量；
- 当前 PO 板块立即冻结；
- 本次接收单引用的 PO 行立即冻结编辑；
- 制单人、制单时间写入；
- 接收人、接收时间为空；
- 进入接收单详情。

### 5.5 接收单列表

查询条件：接收单号、PO 单号、单据状态、制单人、制单时间、供应商。

列表字段：选择、行号、接收单号、单据状态、PO 单号、供应商、制单人、制单时间。

- 草稿可勾选删除；已完成不可删除。
- 默认按制单时间倒序。
- 行号按当前排序及分页连续顺排。
- 默认每页 10 条，支持切换每页条数。
- 从某张 PO 进入时自动带入 PO 单号；重置清空全部查询条件。

#### 删除草稿接收单

删除后：

1. 删除接收单及其接收行、低值耐用品已生成逐件明细；
2. 释放整单 PO 草稿占用；
3. 重新计算 PO 可接收数量；
4. 如果该 PO 已无任何接收单，板块恢复可编辑；
5. 对被删除接收单引用的每条 PO 行重新判断：无其他接收单引用则恢复编辑，否则继续冻结。

### 5.6 接收单详情

“接收单信息”在普通耗材和低值耐用品接收单详情中统一展示并保持以下顺序：

1. 采购接收单号
2. PO 单号
3. PO 说明
4. 供应商
5. 联系人
6. 供应商联系电话
7. 采购单位
8. 采购员
9. 采购员联系电话
10. 合同主体
11. 板块
12. 接收人
13. 接收单状态
14. 接收时间

草稿状态接收人、接收时间为空。

低值耐用品接收单详情不展示制单人、制单时间。

接收行字段包括：行号、耗材说明、配置、本次接收数量、采购数量、价格税额、约定到货日期、PR 单/行号、SA 单/行号、申请单号、部门、业务线。

草稿状态允许删除接收行；已完成只读。

### 5.7 删除接收行

草稿状态允许删除。

删除后：

- 释放该接收行对应 PO 草稿数量；
- 删除低值耐用品来源逐件明细；
- 重新计算 PO 可接收数量；
- 如果该 PO 行已不再被任何其他接收单引用，恢复该行编辑能力；否则继续冻结。

### 5.8 低值耐用品维护 / 查看接收明细

低值耐用品按“每接收 1 件生成 1 条逐件明细”。普通耗材不进入此页面。维护 / 查看接收明细页不展示制单人、制单时间。

逐件明细字段：选择、行号、耗材标签号、SN、物资总类、耗材大类、耗材说明、配置、耗材数量、不含税单价、税金、PR 单/行号、SA 单/行号、申请人、业务线、备注、操作。

操作包括：删除行、生成标签号、维护 SN 号、打印标签号、编辑 / 查看。

#### 扫描规则

1. 全部标签号生成后才允许扫描。
2. 扫描光标与扫描结果对照信息放在同一个区域；未定位明细时，对照字段保持空白。
3. 第一次扫描耗材标签号，系统在当前接收单内定位对应逐件明细，并在对照区带出耗材标签号、SN号、耗材说明、配置；下方接收明细始终保持全量，不因扫描定位筛选为单行，同时保持命中行勾选。
4. 标签号命中后，扫描光标进入 SN 录入阶段；第二次扫描 SN，校验唯一性后写入并实时保存。
5. SN 写入成功后清空扫描输入和定位状态，下方全量列表保持不变，并保留刚处理行勾选。
6. 【重置】清空扫描输入、定位状态和勾选，对照区恢复空白；下方接收明细始终保持全量。
7. 扫描 Card 仅在草稿接收单的【维护接收明细】页面展示；已完成接收单进入【查看接收明细】时不展示扫描 Card，仅保留只读接收明细。

#### 标签 / SN

【删除行】【生成标签号】【维护SN号】【打印标签号】四个操作始终展示，不再通过状态控制显隐；不可执行时按钮置灰。

- 【删除行】：仅草稿且已勾选明细时可用；
- 【生成标签号】：仅草稿、存在逐件明细且仍有空白标签号时可用；
- 【维护SN号】：仅草稿、存在逐件明细且仍有空白 SN 时可用；
- 【打印标签号】：存在逐件明细且标签号全部生成后可用，草稿和已完成均允许打印；
- 【生成标签号】仅处理标签为空的明细；
- 【维护SN号】仅对空白 SN 写入“缺省”。

#### 删除逐件明细

删除一条逐件明细时：

1. 删除当前明细；
2. 来源接收行本次接收数量同步减少 1；
3. 对应 PO 行草稿数量同步减少 1；
4. PO 可接收数量增加 1；
5. 如来源接收行数量减至 0，从草稿接收单中移除该接收行；
6. 来源 PO 行若已无其他接收单引用，则恢复编辑。

### 5.9 接收确认

#### 5.9.1 低值耐用品

接收确认前要求：

- 至少存在有效接收行；
- 逐件明细数量与接收数量一致；
- 每条逐件明细均有耗材标签号和 SN；
- 所有非“缺省”真实 SN 唯一；
- 当前公司能唯一匹配耗材仓。

成功后：

- 接收单变为已完成；
- 写入接收人、接收时间；
- 草稿数量转已接收数量；
- 接收快照固化；
- 生成采购接收入库草稿单；
- PO / PO 行冻结继续保持，因为已完成接收单仍属于有效引用。

#### 5.9.2 普通耗材

接收确认前要求：

- 至少存在有效接收行；
- 接收数量有效；
- 当前公司能唯一匹配耗材仓。

成功后作为一个原子业务动作：

- 接收单变为已完成；
- 写入接收人、接收时间；
- 生成已完成采购接收入库单；
- 目标耗材仓库存立即增加；
- 草稿数量转已接收数量；
- 根据累计数量重新计算 PO 行和 PO 状态；
- PO / PO 行冻结继续保持。

任一环节失败，不允许出现“接收已完成但入库 / 库存未成功”的半完成状态。

## 6. 校验与异常处理

| 场景 | 校验 / 处理 |
|---|---|
| 创建接收单 | 至少选择一条可接收 PO 行 |
| 创建接收单 | 板块必填 |
| 编辑 PO 行 | 已被接收单引用时仍可进入编辑；仅本次接收数量可修改，物料、配置只读 |
| 编辑板块 | 当前 PO 已存在任意接收单时禁止修改 |
| 接收数量 | 正整数；未引用草稿时不得超过当前可接收数量；引用草稿时上限 = 当前未占用可接收数量 + 该草稿当前占用数量 |
| 删除草稿业务 | 释放草稿数量后按接收单引用关系重新判断冻结状态 |
| 低值耐用品接收确认 | 标签号、SN 全部维护完成且真实 SN 唯一 |
| 真实 SN | 不得与其他资产 / 耗材真实 SN 重复 |
| 耗材仓 | 必须唯一匹配 |
| 普通耗材确认 | 接收、入库、库存增加必须原子成功 |

## 7. 后续操作及补充说明

### 7.1 低值耐用品

接收确认完成仅表示实物接收完成并已形成采购接收入库草稿单；用户仍需进入“库存管理 → 入库”执行正式入库。正式入库后增加耗材仓库存、创建对应耗材卡片并更新 PO 入库状态。

### 7.2 普通耗材

接收确认成功即同步完成入库，不再要求用户进入入库模块执行第二次操作。系统生成已完成采购接收入库单作为库存事务凭证。

### 7.3 已完成接收单

接收单头、接收行、低值耐用品逐件明细均只读；允许查看和打印。已完成接收单继续参与 PO 级、PO 行级冻结，不因“接收完成”解除冻结。

### 7.4 冻结释放边界

冻结只可能通过删除尚未完成的草稿业务数据释放：

- PO 级：当前 PO 已无任何接收单 → 板块恢复可编辑；
- PO 行级：当前 PO 行已无任何接收单引用 → 该行恢复编辑；
- 仅释放部分数量但仍保留接收单引用时，不解除冻结；
- 已完成接收记录不可删除，因此对应冻结持续有效。

### 7.5 接收单打印

仅已完成接收单允许打印正式“物资接收单”。打印读取接收完成快照，不修改接收数量、PO 状态或库存结果；打印失败允许重试，不重复产生业务数据。
