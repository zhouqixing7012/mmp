# 员工自助新版——第四阶段 PRD

## 1. 目标

新增“我的申请”，从员工视角统一查询资产申请，并查看申请、业务审批、ES 配给、汇总采购、资产领用、员工确认、库管复核和出库的完整进度。

## 2. 入口

- 顶部导航：个人工作台 → 员工自助新版-我的申请
- 后台框架：个人工作台 → 员工自助新版-我的申请
- 路由：`/employee-self-service/my-applications`

## 3. 查询条件

| 字段 | 规则 |
|---|---|
| 申请单号/资产 | 支持申请单号和资产说明模糊查询 |
| 申请日期 | 支持起止日期筛选 |
| 单据状态 | 处理中、已完成、已驳回 |

查询和重置必须真实作用于列表数据。

## 4. 列表字段

- 申请单号
- 申请日期
- 物资数量
- 当前节点
- 任务状态
- 单据状态
- 查看详情

## 5. 详情结构

### 5.1 基本信息

展示当前节点、任务状态、申请数量、申请日期，以及关联配给单、汇总单、领用单和出库单数量。

### 5.2 全流程进度

按以下阶段展示：

1. 申请提交
2. 业务审批
3. ES 配给
4. 汇总采购
5. 资产领用
6. 员工领用确认
7. 库管复核与出库

阶段状态统一为：待处理、处理中、已完成、已驳回、不涉及。

### 5.3 申请资产

展示资产说明、配置、数量、申请原因、申请用途、详细说明和个人超标标识。

### 5.4 审批记录

复用业务审批记录，展示审批环节、审批人、审批状态、审批时间和审批意见。

### 5.5 关联单据

关联展示：

- 资产申请单
- 资产配给单
- 资产汇总申请单
- 资产领用单
- 出库单

### 5.6 通知记录

通知类型包括：

- 申请提交成功
- 申请驳回
- 库存配给完成
- 进入统一采购
- 汇总采购提交
- 资产领取通知
- 员工领用确认
- 签名退回
- 出库完成

通知渠道展示狐小e、MyFamily、易点、资产系统或采购系统。

## 6. 数据规则

页面不复制流程数据，通过聚合 service 实时读取申请、配给、汇总、领用和出库数据。刷新浏览器后结果保持一致。

采购系统与 PR 系统的真实 PO 单号和状态需要外部系统回传；演示版本以汇总单是否已提交表示采购阶段进度。

## 7. 演示数据重置

“重置演示数据”只清理员工自助新版相关存储：

- 申请单
- 配给单
- 汇总单
- 领用单
- 员工签名
- 出库单

旧版页面和旧版演示数据不受影响。重置前必须二次确认。

## 8. 验收标准

1. 支持按单号、资产说明、日期和状态查询。
2. 查询和重置真实生效。
3. 详情可查看完整流程时间线。
4. 审批、配给、汇总、领用和出库状态与对应页面一致。
5. 关联单据数量与明细一致。
6. 通知记录随业务动作增加。
7. 全部领用分支完成后申请状态显示已完成。
8. 重置后恢复初始申请单，旧版数据不受影响。
9. 刷新浏览器后状态保持。
