1. 权限：

    1. 设置报表查看权限，并且根据登录申请人查看资产卡片的权限过滤查看报表数据权限。

    2. 集团、上海媒体分公司、广州媒体分公司各自台账的数据。

2. 入口：资产系统。

3. 取数来源：资产卡片\.资产标签号

4. 排序规则：先按照资产大类编码升序，然后按照资产小类编码升序。

    1. 设置报表查看权限，并且根据登录申请人查看资产卡片的权限过滤查看报表数据权限。

2. 入口：资产系统。

3. 取数来源：入库单\.资产标签号。

4. 过滤条件：单据状态为“已完成”（入库单执行入库后），并且入库类型=新增入库/采购接收/自购入库，资产总类为资产。

6. 特殊说明：报表取值为入库完成时节点，之后数据不更新。

7. 支持Excel导出。
