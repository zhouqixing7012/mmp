# 资产管理 - 账面报废 PRD

## 1. 背景

账面报废用于承接已经进入待报废池的资产，以及无前置流程、直接添加的丢失资产，完成财务、NO、MIS、ES 等审批，并在最终确认后更新资产台账、生成资产事务、生成报废单并推送 EBS。

本 PRD 仅覆盖账面报废，不覆盖：

- 跨公司转移申请；
- 资产报废申请；
- 待处置池；
- 资产实物处置。

跨公司转移和资产报废分别由独立 PRD 定义。

## 2. 权限

### 2.1 发起权限

账面报废由 ES 账务人员发起。

ES 账务人员只能处理其负责“财务公司 + 板块”范围内的资产。

账面报废数据权限：

| 人员 | 数据范围 |
|---|---|
| 吕静 | 集团、媒体板块 |
| 穆晓丹 | 焦点、视频板块 |
| 卢铭华 | 新媒体-上海分公司 |
| 李琴宝 | 新媒体-广州分公司 |

页面按下表数据范围控制可查看和可处理资产。

### 2.2 数据来源

账面报废资产有两类业务来源：

1. 【待报废资产】：资产报废申请或跨公司转移审批通过后进入待报废池的资产；
2. 【添加资产】：无前置流程、直接进入账面报废的丢失资产。

Excel 导入是批量录入方式，不作为独立业务来源；导入的每条资产仍须符合【待报废资产】或【添加资产】的来源规则。

跨公司转移必须先完成跨公司转移流程；软件必须先完成资产报废申请，二者不得绕过前置流程。丢失资产通过【添加资产】直接加入账面报废，报废类型固定为“丢失”。

无论来源为何，保存、提交和执行账面报废前均按同一套资产有效性、权限和重复业务校验.

### 2.3 数据范围

账面报废只允许处理当前 ES 账务人员有权限的数据。

同一张账面报废单按“财务公司 + 板块”组织。

跨多个“财务公司 + 板块”的资产不得保存在同一张单据中，应拆分为多张账面报废单。

## 3. 通用规则

### 3.1 单据状态

账面报废单据状态：

- 草稿；
- 审批中；
- 已驳回；
- 待提单人确认；
- 已完成。

规则：

- 新建默认草稿；
- 草稿允许编辑、保存和删除；
- 提交成功后进入审批中；
- 任一审批节点驳回后退回发起人，单据进入已驳回；
- 发起人修改后可重新提交；
- 财务一级审批通过后进入提单人确认；
- 提单人确认完成并成功执行账面报废后，状态更新为已完成；
- 已完成单据只读。

### 3.2 审批去重

同一张账面报废单中，如果 NO5、NO7、MIS5、MIS7 任意多个审批节点实际匹配到同一审批人，该审批人只审批一次，后续重复节点自动跳过。

系统保留节点跳过记录，但不重复生成待办。

### 3.3 驳回

流程图中各审批节点驳回均退回发起人。

发起人修改后重新提交时，重新按当前资产构成和当前审批人映射生成审批链。

### 3.4 附件

账面报废支持上传附件。

规则：

- 文件格式不限；
- 单文件大小不得超过 20MB；
- 超过 20MB 时阻止上传并提示；
- 已上传附件支持查看、下载和删除。

### 3.5 金额与日期

- 数量按业务原值展示，不强制千分位；
- 原值、净值、累计折旧、报废金额等金额统一使用千分位 + 2 位小数；
- 日期统一 yyyy-MM-dd；
- 日期时间统一 yyyy-MM-dd HH:mm:ss；
- 空值与真实数值 0 必须区分。

### 3.6 报废方式

账面报废包含两个不同维度：

- 单据报废方式：调账 / 非调账；
- 资产报废方式：全部报废 / 部分报废 / 调账。

资产报废方式按来源确定：

- 来自跨公司转移的资产固定为“调账”，单据报废方式为“调账”；
- 来自资产报废申请的资产，报废数量小于资产卡片数量时为“部分报废”，等于资产卡片数量时为“全部报废”，单据报废方式为“非调账”；
- 通过【添加资产】直接加入的丢失资产固定为“全部报废”，单据报废方式为“非调账”。

调账资产不得与非调账资产保存在同一张账面报废单中；同一张非调账账面报废单允许同时包含“全部报废”和“部分报废”资产。

### 3.7 报废类型

报废类型由账面报废确定：

- 从待报废池选择的非丢失资产，净值等于 0 时默认“已到报废期”，净值大于 0 时默认“未到报废期”；默认值允许编辑；
- 通过【添加资产】直接加入的资产固定为“丢失”。

## 5. 新建 / 编辑页

新建、编辑和详情页均不展示业务流程卡片或单据状态字段。草稿未提交时审批记录为空；提交后，审批页及列表【查看进度】弹窗均展示发起人提交记录、历史审批记录和当前待审批节点。当前节点状态为“待审批”，审批时间和审批意见留空。审批路径按第 6 章规则执行。非调账单展示资产明细，调账单展示公司间转移明细；两类单据使用相同的基本信息和工具栏规则。

编辑页单头不展示“是否公司间转移”“数据来源”“板块”；资产明细不展示“来源业务类型”“来源业务单号”。财务公司与板块仍用于数据隔离和审批匹配。审批页展示基本信息、报废原因、按报废类型与资产大类汇总的资产明细（调账时展示公司间转移明细）、从发起人提交记录到当前待审批节点的完整审批记录、审批意见及同意/驳回操作。当前节点状态为“待审批”，审批时间和审批意见留空；列表【查看进度】弹窗展示相同的审批记录。

### 5.1 明细录入方式

ES 账务人员创建账面报废草稿后，可通过以下方式录入资产明细：

1. 【待报废资产】：选择资产报废或跨公司转移审批通过后进入待报废池的资产；
2. 【添加资产】：直接添加无前置流程的丢失资产；
3. Excel 导入。

从待报废池创建时，系统按当前登录人负责的“财务公司 + 板块”检索可账面报废资产。

如果命中多个“财务公司 + 板块”，分别生成独立草稿单。

当前无可账面报废资产时提示：

> 当前暂无待账面报废资产。

### 5.5 工具栏

草稿支持：

- 【待报废资产】：选择资产报废（非调账）或跨公司转移（调账）审批通过后进入待报废池的资产；
- 【添加资产】：直接从资产范围不限的资产中添加已丢失资产，无前置业务流程，单据报废方式固定为非调账、资产报废方式固定为全部报废、报废类型固定为丢失；
- 删除（选中资产后删除，按钮文案为“删除”）；
- 下载模板；
- Excel 导入；
- 导出明细。

【待报废资产】的数据范围：

- 当前单据“财务公司 + 板块”；
- 当前 ES 账务人员可见范围；
- 仅包含资产报废（非调账）或跨公司转移（调账）审批通过、已进入待报废池的资产；
- 当前资产未处于其他账面报废审批或已完成账面报废；
- 来源业务类型与当前单据报废方式一致；来自资产报废申请的资产带入全部报废或部分报废，来自跨公司转移的资产带入调账。

【添加资产】仅用于无前置流程的丢失资产，选择范围不受机房资产、软件、办公设备类别限制；已进入跨公司转移、资产报废或其他账面报废单据的资产不可重复添加。

### 5.6 Excel 导入

Excel 导入必须逐行校验：

1. 资产存在；
2. 当前用户有权限；
3. 资产满足账面报废前置条件；
4. 资产未进入其他未结束账面报废；
5. 资产未完成账面报废；
6. 来源业务类型与当前单据一致；
7. 同一资产不重复；
8. 必填字段完整；
9. 金额和数量合法。

存在失败行时返回逐行错误信息。

整批提交前所有明细必须通过校验。

## 6. 最终审批流程

正式流程：

> 账面报废流程开始  
> → ES 提单发起账面报废  
> → 财务初审  
> → 判断是否包含机房资产  
> → 条件进入 NO 审批  
> → 判断是否包含需 MIS 审批的电脑类资产  
> → 条件进入 MIS 审批  
> → ES 二级审批  
> → ES 一级审批  
> → 财务三级审批  
> → 财务二级审批  
> → 财务一级审批  
> → 提单人确认  
> → 更新台账 / 生成事务 / 生成报废单  
> → 账面报废流程结束

任一审批节点驳回均退回发起人。

## 6.1 财务初审

ES 账务提交后进入财务初审。

财务初审人员按“财务公司 + 板块”映射。

审批操作：

- 通过；
- 驳回。

通过后进入条件审批判断。

## 6.2 机房资产条件审批

财务初审通过后判断单据是否包含资产大类为 14.SERVER 或 15.NET EQUIPMENT，且报废方式不是“调账”的资产。

### 不包含“机房资产且非调账”的资产

跳过 NO 审批，继续判断 MIS 条件。

### 包含“机房资产且非调账”的资产

依次进入：

> NO 部门 5 级及以上领导  
> → NO 部门 7 级及以上领导

规则：

- 审批节点依次为 NO 部门 5 级及以上领导、NO 部门 7 级及以上领导；
- 两个节点实际审批人为同一人时，第二个重复节点自动跳过；
- 节点支持通过、驳回；
- 驳回退回发起人。

NO 审批全部通过后继续判断 MIS 条件。

## 6.3 MIS 条件审批

系统判断单据是否包含需要 MIS 审批的电脑类资产。

MIS 条件为：单据包含笔记本、台式机或显示器，且对应资产报废类型不是“丢失”，报废方式不是“调账”。

### 不满足 MIS 条件

直接进入 ES 二级审批。

### 满足 MIS 条件

依次进入：

> MIS 部门 5 级及以上领导  
> → MIS 部门 7 级及以上领导

规则：

- 审批节点依次为 MIS 部门 5 级及以上领导、MIS 部门 7 级及以上领导；
- 两个节点实际审批人为同一人时，第二个重复节点自动跳过；
- 节点支持通过、驳回；
- 驳回退回发起人。

MIS 审批完成后进入 ES 二级审批。

## 6.4 ES 审批

审批顺序：

> ES 二级审批  
> → ES 一级审批

审批顺序固定为 ES 二级审批后进入 ES 一级审批。

节点支持：

- 通过；
- 驳回。

驳回退回发起人。

## 6.5 财务复审

ES 一级审批通过后，依次进入：

> 财务三级审批  
> → 财务二级审批  
> → 财务一级审批

审批人均按“财务公司 + 板块”财务审批映射确定。

节点支持：

- 通过；
- 驳回。

驳回退回发起人。

财务一级审批通过后进入提单人确认。

## 6.6 提单人确认

提单人为原 ES 账务发起人。

提单人确认时：

1. 查看完整账面报废单；
2. 查看全部审批历史；
3. 核对资产明细、报废方式、报废类型、报废原因；
4. 确认无误后执行账面报废。

操作：

- 确认并执行；
- 驳回。

驳回退回发起人编辑状态。

确认执行时必须防止重复执行。

## 7. 执行账面报废

提单人确认通过后，系统完成：

1. 更新资产台账；
2. 生成资产事务；
3. 生成报废单；
4. 生成对应报表/套打数据；
5. 记录操作历史；
6. 账面报废流程结束；
7. 流程结束后触发 EBS 推送和参与人通知。

资产台账、资产事务和报废单必须基于同一次账面报废执行结果生成。

## 7.1 调账

普通调账账面报废执行时，按资产标签号将跨公司转移目标信息正式写入资产台账：

| 调账结果 | 资产台账字段 |
|---|---|
| 新公司 | 公司 |
| 新板块 | 板块 |
| 新成本中心 | 成本中心 |
| 新责任人 | 责任人 |
| 新 City | City |
| 新 Building | Building |
| 新 Floor | Floor |
| 调账后仓库 | 仓库 |
| 用途 | 资产用途 |
| 项目 | 项目 |

当转入方或转出方涉及新媒体上海分公司或新媒体广州分公司时，不执行上述“直接修改原资产卡公司”的普通调账逻辑，改为：

1. 给原资产号增加后缀后推送财务系统；
2. 财务系统完成同步变更后，由目标分公司按原资产号手工新增资产。

所有调账资产：

- 不进入待处置池；
- “是否处置”固定为否；
- 生成调账相关事务和报废单记录。

## 7.2 部分报废

部分报废执行时：

1. 原资产按报废数量、报废金额进行拆分；
2. 报废部分完成账面报废；
3. 剩余部分生成新资产卡片；
4. 新资产标签号按“原资产标签号-序号”生成，例如 aaa-1、aaa-2；
5. 入库日期保持原值；
6. 数量、金额按报废比例拆分；
7. 新资产继承原员工信息；
8. 系统匹配虚拟库管员完成剩余资产入库；
9. 原资产属于员工名下时，系统生成领用单，将剩余资产重新挂回原员工。

金额计算：

> 报废金额 = 原资产总金额 ÷ 原资产总数量 × 报废数量

保留 2 位小数。

## 7.3 全部报废

全部报废更新字段：

- 资产状态；
- 报废日期；
- 报废原因；
- 报废类型。

账面报废完成后按以下规则判断处置结果：

- 调账资产不进入待处置池，资产按调账结果更新；
- 报废类型为“丢失”的资产不进入待处置池，不生成处置单；
- 非机房软件资产不进入待处置池，不生成处置单；
- 物料【是否处置】=否时，不进入待处置池，资产状态更新为“已报废-已处置”；
- 机房资产满足处置条件时由系统自动生成处置单；办公设备满足处置条件时进入待处置池，由 ES 专员手动创建处置单；
- 其余物料【是否处置】=是且尚未完成实物处置的资产，进入待处置池，资产状态更新为“已报废-待处置”。

主资产存在升级耗材时，升级耗材随主资产同步报废。

## 8. 审批页面

审批页面包括：

### 8.1 基本信息

全部只读。审批页展示申请单号、申请人、申请日期、公司、办公区、联系电话、邮箱、部门、单据报废方式、备注和附件，不展示单据状态；同时提供“导出”操作，机房与非机房报废均可导出明细。

### 8.2 报废资产明细

按报废类型生成第一层 Tabs：

- 已到报废期；
- 未到报废期；
- 丢失。

Tab 展示当前类型总数量，并展示该类型报废原因、总数量、原值合计和净值合计；报废原因只读。

第二层按资产类别分组。每组展示以下汇总：

- 数量；
- 原值合计；
- 折旧合计；
- 净值合计。

### 8.3 审批历史

审批历史字段：

- 序号；
- 节点；
- 审批人；
- 审批时间；
- 审批状态；
- 审批意见。

### 8.4 当前审批操作

当前审批人可填写审批意见。

待办审批页面提供“返回”“驳回”“同意”操作。

仅提单人确认节点展示“确认并执行”。

## 9. 保存、提交与执行校验

### 9.1 保存

保存草稿时：

- 已填写字段必须满足基础有效性；
- 首次保存生成单据编号；
- 不触发审批。

### 9.2 提交

提交前必须校验：

1. 至少存在 1 条资产明细；
2. 所有资产属于当前“财务公司 + 板块”；
3. 当前 ES 账务人员拥有操作权限；
4. 资产满足账面报废前置条件；
5. 资产未处于其他账面报废审批；
6. 资产未完成账面报废；
7. 同一单据的单据报废方式一致；调账与非调账不得混合，非调账单可同时包含全部报废和部分报废资产；
8. 报废类型合法；
9. 数量和金额合法；
10. 同一资产不重复；
11. 调账资产目标信息完整；
12. 附件单文件 ≤20MB；
13. Excel 导入明细全部通过校验。

任一资产失败时不允许部分提交。

### 9.3 执行

提单人确认执行前再次校验：

- 单据当前节点必须为提单人确认；
- 所有前置审批均已通过；
- 资产当前版本与提交审批时不存在禁止执行的冲突；
- 资产未被其他流程抢占；
- 账面报废未重复执行。

执行处理中：

- 执行过程中禁止重复点击；
- 同一资产不得重复生成报废事务。

## 10. 流程完成后的结果

执行成功后：

1. 单据状态更新为已完成；
2. 更新资产台账；
3. 生成资产事务；
4. 生成报废单；
5. 生成对应报表和套打数据；
6. 记录资产操作历史；
7. 账面报废流程结束；
8. 流程结束后触发 EBS 推送；
9. 向所有实际参与人发送通知。

## 11. 通知

流程结束后向所有实际参与人发送通知。

通知对象：

- 发起人；
- 所有实际审批人。

自动跳过的重复审批节点不重复发送通知。

通知内容：

- 账面报废申请单号；
- 财务公司；
- 板块；
- 资产数量；
- 报废方式；
- 账面报废已完成。

点击通知进入账面报废详情。
