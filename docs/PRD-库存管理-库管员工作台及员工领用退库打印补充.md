# 库存管理 - 库管员工作台及员工领用/退库打印补充 PRD

## 1. 页面与打印范围

本文件补充两类正式规则：

1. 库管员工作台保持单页面结构，扫描枪和刷卡设备通过查询输入框触发查询；
2. 员工领用自动出库打印时追加员工领用信息页；员工退库自动入库打印时追加资产退库审批记录。

借用出库、借用归还不追加上述附页，继续使用各自的员工借用单、借用退库单。

## 2. 库管员工作台

### 2.1 页面结构

页面标题为“库管员工作台”，不设置“资产出入库”页签。

右上角仅提供：

- 【员工页面】；
- 【刷新员工页面】。

查询条件包括：

| 查询条件 | 规则 |
|---|---|
| 资产标签号 | 支持扫描枪录入或人工输入 |
| 员工卡号 | 支持刷卡设备录入或人工输入 |
| 员工姓名 | 文本查询 |
| 资产名称 | 文本查询 |
| 单据编号 | 文本查询 |
| 单据类型 | 下拉查询 |

扫描枪或刷卡设备将结果写入对应输入框，按回车直接查询；页面不提供重复的扫码、刷卡快捷按钮。

### 2.2 使用人

工作台固定开放给：

- `114111-杨芊`；
- `213852-孙志强`。

不在固定名单内的账号进入工作台时返回 403，并提示“当前工作台仅开放给杨芊、孙志强。”

## 3. 打印适用范围

| 来源业务 | 库存单据 | 追加页面 |
|---|---|---|
| 员工领用确认 | 自动生成的领用出库单 | 员工领用信息 |
| 员工退库确认 | 自动生成的退库入库单 | 资产退库审批记录 |
| 手工创建入库/出库 | 手工单据 | 不追加 |
| 借用出库 | 自动或手工借用出库单 | 不追加，使用员工借用单 |
| 借用归还 | 借用归还入库单 | 不追加，使用借用退库单 |

系统通过来源流程标识或来源申请单号识别员工流程自动单据，不能只根据“领用出库”“退库入库”业务类型判断。

## 4. 打印页顺序

### 4.1 员工领用自动出库

`原出库单打印页 → 员工领用信息页`

### 4.2 员工退库自动入库

`原入库单打印页 → 资产退库审批记录`

追加页面必须独立分页，不与原库存单据表格挤在同一页。

## 5. 员工领用信息页

页面标题：**员工领用信息**。

| 字段 | 展示规则 |
|---|---|
| 领用人（工号-姓名） | 展示完成领用确认的员工工号和姓名 |
| 领用人部门（全称） | 展示领用确认发生时的完整部门路径 |
| 领用方式 | 仅展示扫码或刷卡 |
| 领用时间 | 展示领用确认完成时间，精确到秒 |

员工领用确认完成时保存以上数据快照；重新打印时读取历史快照，不根据当前员工档案重新计算。

## 6. 资产退库审批记录

页面标题：**资产退库审批记录**。

| 字段 | 展示规则 |
|---|---|
| 申请单号 | 展示来源资产退库申请单号 |
| 审批节点 | 按资产退库实际流程顺序展示 |
| 审批人 | 展示各节点实际处理人 |
| 审批结果 | 展示已提交、已同意、已确认、已完成、已驳回等实际结果 |
| 审批时间 | 展示节点实际处理时间 |
| 审批备注 | 展示各节点意见；员工退库确认节点固定记录“确认方式：X” |

员工退库确认在审批记录中只保留一个节点：发起确认时该节点为待确认，完成扫码、刷卡或库管员代确认后直接更新为已确认，不再额外生成“申请人退库确认”节点。X 仅允许“扫码”“刷卡”或“库管员代确认”。

员工退库确认完成后由系统自动生成入库结果；系统执行入库不是审批节点，因此打印审批记录时不展示“执行入库”。

重新打印读取资产退库单已保存的审批记录，不重新推断确认方式。

## 7. 校验与异常

1. 非员工流程自动生成的库存单据不追加资产退库审批记录；
2. 退库最终确认方式只允许扫码、刷卡或库管员代确认；
3. 资产退库审批记录必须展示来源申请单号；
4. 员工退库确认只允许展示一个审批节点，审批备注必须记录最终确认方式；
5. 系统自动执行入库不得作为审批节点打印；
6. 重新打印读取资产退库单已保存的审批记录；
7. 历史审批字段缺失时对应字段显示 `-`，不得推断或补造；
8. 打印失败允许重试，不重复生成库存单据或业务事务。

## 8. 业务结果

打印附页只展示已保存的员工领用信息或资产退库审批记录，不改变员工领用、员工退库的审批状态、资产状态、库存数量或库存事务。
