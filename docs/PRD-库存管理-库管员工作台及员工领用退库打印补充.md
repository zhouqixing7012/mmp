# 库存管理 - 库管员工作台及员工领用/退库打印补充 PRD

## 1. 页面与打印范围

本文件补充两类正式规则：

1. 库管员工作台保持单页面结构，扫描枪和刷卡设备通过查询输入框触发查询；
2. 员工领用自动出库、员工退库自动入库打印时，追加对应的员工操作确认信息页。

借用出库、借用归还不追加员工操作确认信息页，继续使用各自的员工借用单、借用退库单。

## 2. 库管员工作台

### 2.1 页面结构

页面标题为“库管员工作台”，不设置“资产出入库”页签。

右上角仅提供：

- 【员工页面】；
- 【刷新员工页面】。

查询条件包括：

| 查询条件 | 规则 |
|---|---|
| 资产标签号 | 支持扫描枪录入或人工输入 |
| 员工卡号 | 支持刷卡设备录入或人工输入 |
| 员工姓名 | 文本查询 |
| 资产名称 | 文本查询 |
| 单据编号 | 文本查询 |
| 单据类型 | 下拉查询 |

扫描枪或刷卡设备将结果写入对应输入框，按回车直接查询；页面不提供重复的扫码、刷卡快捷按钮。

### 2.2 使用人

工作台固定开放给：

- `114111-杨芊`；
- `213852-孙志强`。

不在固定名单内的账号进入工作台时返回 403，并提示“当前工作台仅开放给杨芊、孙志强。”

## 3. 打印适用范围

| 来源业务 | 库存单据 | 追加页面 |
|---|---|---|
| 员工领用确认 | 自动生成的领用出库单 | 员工领用信息 |
| 员工退库确认 | 自动生成的退库入库单 | 员工退库确认信息 |
| 手工创建入库/出库 | 手工单据 | 不追加 |
| 借用出库 | 自动或手工借用出库单 | 不追加，使用员工借用单 |
| 借用归还 | 借用归还入库单 | 不追加，使用借用退库单 |

系统通过来源流程标识或来源申请单号识别员工流程自动单据，不能只根据“领用出库”“退库入库”业务类型判断。

## 4. 打印页顺序

### 4.1 员工领用自动出库

`原出库单打印页 → 员工领用信息页`

### 4.2 员工退库自动入库

`原入库单打印页 → 员工退库确认信息页`

追加页面必须独立分页，不与原库存单据表格挤在同一页。

## 5. 员工领用信息页

页面标题：**员工领用信息**。

| 字段 | 展示规则 |
|---|---|
| 领用人（工号-姓名） | 展示完成领用确认的员工工号和姓名 |
| 领用人部门（全称） | 展示领用确认发生时的完整部门路径 |
| 领用方式 | 仅展示扫码或刷卡 |
| 领用时间 | 展示领用确认完成时间，精确到秒 |

员工领用确认完成时保存以上数据快照；重新打印时读取历史快照，不根据当前员工档案重新计算。

## 6. 员工退库确认信息页

页面标题：**员工退库确认信息**。

| 字段 | 展示规则 |
|---|---|
| 退库人（工号-姓名） | 展示完成本次退库确认的员工工号和姓名 |
| 退库人部门（全称） | 展示退库确认发生时的完整部门路径 |
| 退库确认方式 | 仅展示扫码或刷卡 |
| 退库确认时间 | 展示本次退库确认完成时间，精确到秒 |

员工退库确认完成时保存以上数据快照；不得使用该资产原领用人的历史领用信息替代本次退库确认信息。

## 7. 校验与异常

1. 非员工流程自动生成的库存单据不追加员工操作确认信息页；
2. 操作方式只允许扫码或刷卡；
3. 确认时间精确到秒；
4. 操作人不能为空；
5. 部门保存完整组织路径；
6. 重新打印读取确认动作发生时的数据快照；
7. 历史数据缺失时对应字段显示 `-`，不得推断或补造；
8. 打印失败允许重试，不重复生成库存单据或业务事务。

## 8. 业务结果

打印附页只展示员工操作留痕，不改变员工领用、员工退库的审批状态、资产状态、库存数量或库存事务。
