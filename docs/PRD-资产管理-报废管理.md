# 资产管理 - 报废专项 PRD 索引

## 1. 文档职责

报废专项的正式目标需求拆分为四份独立 PRD。本文件仅作为索引，不重复定义业务规则，避免同一规则在多份文档中产生口径漂移。

| 业务模块 | 正式 PRD |
|---|---|
| 跨公司转移（调账） | `docs/PRD-资产管理-跨公司转移.md` |
| 资产报废 | `docs/PRD-资产管理-资产报废.md` |
| 账面报废 | `docs/PRD-资产管理-账面报废.md` |
| 资产处置 | `docs/PRD-资产管理-资产处置.md` |

四份独立 PRD 为后续原型实现、原型精调和三方比对的唯一新版 PRD 基线。

## 2. 业务链

报废专项主链：

> 跨公司转移 / 资产报废  
> → 待报废池  
> → 账面报废  
> → 按处置条件进入待处置池  
> → 资产处置

其中：

- 调账通过跨公司转移发起，完成账面报废后不进入待处置池；
- 资产报废按机房资产、办公设备、软件分别执行对应审批链；
- 账面报废负责最终更新台账、生成资产事务和报废单；
- 需要实物处置的资产进入待处置池，再执行机房资产或办公设备处置流程。

## 4. 当前确认口径

- 进入待报废池时：在库资产状态更新为“在库-待报废”，员工名下资产状态保持不变。
- 机房报废报价：采购专员可指定报价接收人为采购专员或内审；报废数量达到 500 台及以上时强制由内审接收报价。
- 账面报废手动导入仅用于：丢失赔偿、机房资产盘亏、装修。
- 新媒体上海/广州特殊调账按特殊资产号规则处理，不直接把原资产卡修改为目标公司资产卡。
- 账面报废 NO5 / NO7 / MIS5 / MIS7 任意多个节点匹配到同一审批人时，只审批一次。
- 跨公司转移同一申请单不得混合机房资产、软件、办公设备。
- EBS 推送失败后的技术补偿机制不属于产品需求文档范围。
