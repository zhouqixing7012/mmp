# 库存管理 - 转移 PRD

## 1. 背景

“转移”用于处理资产责任人变更及转移后相关资产信息调整。

转移完成后，根据最终转移信息更新：

- 资产责任人；
- 部门；
- 成本中心；
- City；
- Building；
- Floor；
- Room；
- 用途；
- 业务线；
- 项目；
- 使用说明；
- 特殊 NO 资产的 SN号、NO位置、服务。

后台手工创建的转移单与员工前台申请后形成的核心转移单，统一进入“库存管理 → 转移”进行管理。

## 2. 权限

权限采用“公司 + 板块数据范围”与“仓库操作权限”两层控制。

### 2.1 数据权限

公司、板块决定用户可查看和查询的范围，包括：

- 转移单；
- 转移资产候选；
- 转入人候选；
- 已完成转移结果。

用户无对应公司或板块数据权限时，不返回对应记录。

### 2.2 操作权限

仓库操作权限决定用户能否执行：

- 创建转移单；
- 编辑草稿；
- 添加、编辑、删除转移物资；
- 下载模板；
- Excel 导入；
- 转移确认；
- 删除草稿转移单；
- 打印；
- 导出明细。

打开单据、选择资产、选择转入人、保存草稿、导入 Excel、转移确认、删除草稿时均重新校验当前权限，不能仅依赖页面按钮显隐。

## 3. 通用规则

### 3.1 单据来源

核心转移单存在两类来源：

| 来源 | 申请单号 | 制单人 |
|---|---|---|
| 后台手工创建 | 无上游申请时为空 | 当前登录人 |
| 员工前台发起 | 记录上游申请单号 | 申请人 |

两类来源统一进入转移列表管理，并使用相同的后续转移规则。

员工前台来源单据保留申请单号，用于从核心转移单追溯至员工原始申请。

### 3.2 单据状态与单号

转移单状态固定为：

- 草稿；
- 已完成。

状态流转：

草稿 → 转移确认 → 已完成

已完成单据不可恢复草稿。

转移单号规则：

- 前缀固定为 AT-；
- 新建页首次进入显示“自动生成”；
- 首次点击【保存草稿】时，如尚未生成单号，生成正式 AT 转移单号；
- 首次点击【添加物资】时，如尚未生成单号，系统先自动保存单头并生成正式 AT 转移单号，再打开添加物资弹窗；
- 转移单号生成后不可修改。

### 3.3 公司与单头锁定

页面字段名为【公司】，业务含义为**财务公司**。

规则：

- 公司必填；
- 尚未存在转移物资明细时，公司允许修改；
- 即使已经生成 AT 转移单号，只要尚无转移物资明细，公司仍可修改；
- 第一条转移物资保存成功后，公司变为只读；
- 资产候选必须属于当前转移单公司。

备注规则：

- 尚无转移物资明细时可编辑；
- 存在任一转移物资明细后只读；
- 已保存备注随单据保留。

### 3.4 资产候选资格

转移资产必须同时满足：

1. 资产公司 = 当前转移单公司；
2. 资产状态 = 在用-使用中；
3. 未被其他业务锁定；
4. 当前用户具有对应公司、板块及资产范围权限；
5. 同一转移单内不存在相同资产标签号。

转移资产只允许整项转移，不允许拆分资产数量。

### 3.5 资产锁定与释放

资产加入转移草稿后立即建立转移业务锁。

锁定规则：

- 已被其他业务锁定的资产不得加入；
- 同一资产不得同时出现在多张有效转移草稿中。

释放规则：

| 场景 | 处理 |
|---|---|
| 删除转移明细 | 释放该资产转移锁 |
| 删除草稿转移单 | 释放整单资产转移锁 |
| 转移确认成功 | 完成转移并释放本次转移锁 |

Excel 整批导入成功后，同样对导入成功的资产建立转移锁。

### 3.6 整单人员一致性

同一张后台手工转移单中的所有资产必须满足：

- 转出人一致；
- 转入人一致。

新增、编辑或 Excel 导入后，如导致同单转出人或转入人不一致，不允许完成转移确认。

Excel 导入允许转入人暂时为空，因此“转入人一致性”在导入阶段仅对已填写转入人的行进行比较；转移确认前必须全部补齐并最终保持一致。

### 3.7 转入人联动

选择转入人后自动带出：

- 转入板块；
- 转入部门；
- 转入成本中心；
- City；
- Building；
- Floor；
- Room；
- 业务线；
- 项目。

字段规则：

| 字段 | 规则 |
|---|---|
| 转入板块 | 自动带出，只读 |
| 转入部门 | 自动带出，只读 |
| 转入成本中心 | 自动带出，只读；服务器资产按 3.8 处理 |
| City | 自动带出后允许调整 |
| Building | 自动带出后允许调整 |
| Floor | 自动带出后允许调整 |
| Room | 自动带出后允许调整 |
| 业务线 | 自动带出后允许调整 |
| 项目 | 自动带出后允许调整 |

转入人候选必须满足公司、板块、成本中心、办公区和资产领取权限。

### 3.8 服务器成本中心

服务器资产转移时：

- 责任人允许正常变更；
- 转入板块根据转入人带出；
- 转入部门根据转入人带出；
- 转入成本中心不随转入人变化；
- 转入成本中心继续使用该服务器资产转移前的原成本中心。

服务器资产识别使用正式资产分类。

### 3.9 公司 / 板块不一致确认

保存转移明细时，如果待转移资产当前公司或板块与转入人对应公司、板块信息不一致，不直接阻断，弹出确认：

待转移物资公司或板块同转入人信息不一致，是否确认？

用户取消：

- 不保存本次明细。

用户确认：

- 允许继续保存。

该二次确认不替代正式人员权限校验。

### 3.10 特殊 NO 资产

满足特殊 NO 资产条件时，允许维护以下变更信息：

- SN号；
- NO位置；
- 服务。

规则：

- 原值从资产当前信息读取并只读展示；
- 新值按业务规则维护；
- 普通资产不展示特殊 NO 资产变更区域；
- 正式转移成功后仅更新已维护的新值。

### 3.11 转移数量

转移数量固定为资产当前数量。

规则：

- 系统自动带出；
- 页面不提供转移数量输入；
- 用户不可修改；
- 保存明细及转移确认时重新校验资产当前数量；
- 如存在并发变化，以转移确认时最新资产数据为准。

### 3.12 Excel 批量导入通用规则

转移草稿支持通过 Excel 批量导入转移资产。

通用流程：

选择当前转移单 → 下载模板 → 上传 Excel → 逐行校验 → 整批通过后生成草稿明细 → 锁定资产 → 用户转移确认 → 再次校验资产状态 → 正式更新资产

规则：

1. 资产标签号有值时优先按标签号匹配。
2. 标签号为空时按 SN号匹配。
3. 标签号和 SN号同时填写时只按标签号匹配。
4. 任意一行失败，整批不保存。
5. 错误写入结果文件第一列。
6. 全部通过后生成草稿明细并锁定资产。
7. 上传成功不等于资产已经完成转移。
8. 转移确认时再次读取资产最新状态和最新主数据。
9. 转移确认时资产状态必须仍为“在用-使用中”。
10. Excel 中转入人允许为空进入导入结果，但转移确认前必须补齐并通过人员校验。
11. Excel 中用途为空时沿用资产原用途。
12. Excel 中成本中心不直接覆盖最终转入成本中心：普通资产取转入人对应成本中心，服务器资产保留原成本中心。

5. 第一条转移物资保存成功后，公司和备注按通用规则锁定；

### 4.4 Excel 批量导入

#### 4.4.1 模板

字段顺序：

| 列 | 字段 | 导入规则 |
|---:|---|---|
| 1 | 错误提示 | 系统回写错误，用户不维护 |
| 2 | 资产标签号* | 有值时优先按标签号匹配 |
| 3 | SN号 | 标签号为空时按 SN号匹配 |
| 4 | 转入人（员工编号） | 允许为空导入；转移确认前必须补齐 |
| 5 | 成本中心 | 不直接覆盖最终成本中心 |
| 6 | City* | 必填 |
| 7 | Building* | 必填 |
| 8 | Floor* | 必填 |
| 9 | Room | 选填 |
| 10 | 转移日期（YYYY-MM-DD） | 为空时取上传当天 |
| 11 | 转移原因 | 选填 |
| 12 | 用途 | 为空时沿用资产原用途 |
| 13 | 业务线 | 选填 |
| 14 | 项目 | 选填 |
| 15 | 转移说明 | 选填 |

模板第二张表用于填写辅助字典。

公司不在 Excel 中填写，取当前转移单【公司】。

#### 4.4.2 上传交互

草稿“转移物资”Card 右上角提供：

- 【模板下载】
- 【Excel导入】

上传 Excel 后：

1. 校验模板；
2. 逐行校验；
3. 任意一行失败时不允许整批保存；
4. 错误结果写入第一列；
5. 全部通过后生成转移草稿明细；
6. 对导入成功资产建立转移锁；
7. 上传成功后仍需用户执行【转移确认】。

### 4.5 已完成详情

已完成单据整体只读。

单头固定展示：

- 转移单号；
- 申请单号；
- 单据状态；
- 公司；
- 制单人；
- 制单日期；
- 备注。

保留：

- 转移物资明细；
- 【打印】；
- 【导出明细】。

不提供新增、编辑、删除、保存草稿、转移确认操作。

## 5. 校验

### 5.1 保存草稿

- 公司必填。
- 制单人、制单时间由系统记录。
- 草稿无明细时允许只保存单头。
- 已完成单据不允许再次保存草稿。

### 5.2 添加 / 编辑转移物资

| 校验项 | 规则 |
|---|---|
| 转移资产 | 必选 |
| 资产公司 | 必须等于当前转移单公司 |
| 资产状态 | 必须为在用-使用中 |
| 资产锁 | 不得被其他业务占用 |
| 重复资产 | 同一转移单不得重复 |
| 转入人 | 手工添加 / 编辑时必填 |
| 转入成本中心 | 必须存在；服务器资产取原成本中心 |
| City | 必填 |
| Building | 必填 |
| Floor | 必填 |
| 用途 | 必填 |
| 转移日期 | 必填 |
| 转移数量 | 自动取当前资产数量且必须有效 |

### 5.3 整单人员一致性

同一张手工转移单：

- 转出人必须一致；
- 转入人必须一致。

新增、编辑、Excel 导入及转移确认均执行该规则。

Excel 中转入人为空时，导入阶段允许进入草稿；转移确认前必须全部补齐后再执行一致性校验。

### 5.4 公司 / 板块不一致

如果资产当前公司或板块与转入人相关信息不一致，提示：

待转移物资公司或板块同转入人信息不一致，是否确认？

用户确认后允许继续，但仍必须通过正式人员权限校验。

### 5.5 Excel 导入

逐行校验：

1. 标签号有值时按标签号匹配；为空时按 SN号匹配。
2. 标签号和 SN号同时填写时按标签号匹配。
3. 资产必须属于当前转移单公司。
4. 资产状态必须为“在用-使用中”。
5. 资产不得被其他业务锁定。
6. 同一文件和当前转移单中不得重复资产。
7. 转入人填写时必须为有效员工；为空允许生成草稿明细。
8. City、Building、Floor 必填。
9. City 必须有效。
10. Building 必须属于所选 City。
11. Floor 必须有效。
12. 转移日期填写时格式必须为 YYYY-MM-DD；为空时使用上传当天。
13. 用途填写时必须为有效用途；为空时沿用资产原用途。
14. 业务线、项目填写时必须为有效基础数据；为空允许通过。
15. 成本中心列不直接覆盖最终成本中心。
16. 服务器资产最终成本中心保持原成本中心。

任意一行失败：

- 整份 Excel 不保存；
- 不生成部分明细；
- 不建立部分资产锁；
- 错误原因写入结果文件第一列。

### 5.6 转移确认

点击【转移确认】后重新读取资产最新数据并执行整单校验。

必须满足：

1. 至少存在一条有效转移明细；
2. 不存在重复资产标签号；
3. 所有资产当前状态仍为“在用-使用中”；
4. 所有资产仍由当前转移业务持有有效锁；
5. 所有转入人已经补齐且有效；
6. 同单转出人一致；
7. 同单转入人一致；
8. 公司 / 板块相关人员权限有效；
9. 成本科目信息可以正常生成；
10. 服务器成本中心规则正确；
11. 特殊 NO 资产已维护字段满足对应规则；
12. 转移日期有效。

任一校验失败时，整单转移不生效，单据继续保持草稿。

## 6. 后续操作 / 业务结果 / 补充说明

### 6.1 删除明细 / 删除草稿

删除转移明细：

- 仅草稿允许；
- 删除当前明细；
- 释放对应资产转移锁；
- 其他明细保持不变。

删除草稿转移单：

- 删除单头；
- 删除全部明细；
- 释放整单资产转移锁。

列表混合选择草稿和已完成单据时：

- 删除草稿；
- 保留已完成；
- 反馈实际删除数量和保留数量。

### 6.2 转移确认后的资产变化

转移确认成功后，根据最终明细更新：

- 资产责任人；
- 部门；
- 成本中心；
- City；
- Building；
- Floor；
- Room；
- 用途；
- 使用说明；
- 业务线；
- 项目；
- 相关成本核算信息。

服务器资产：

- 责任人更新；
- 部门、板块按转入人更新；
- 成本中心保持转移前原值。

特殊 NO 资产如维护了新值，同步更新：

- SN号；
- NO位置；
- 服务。

### 6.3 快照与事务

转移确认前保存转移前资产快照，至少包括：

- 责任人；
- 成本中心；
- 公司；
- 板块；
- 部门；
- City；
- Building；
- Floor；
- Room；
- 资产状态；
- 用途。

转移成功后：

- 单据状态更新为已完成；
- 保存最后修改人；
- 保存最后修改时间；
- 生成资产转移事务 / 操作历史；
- 关联转移单号；
- 有申请单号时同时记录申请单号；
- 释放转移资产锁。

### 6.4 已完成查看

已完成详情使用第 4.5 节固定字段集，只读展示最终转移信息和转移前快照。

### 6.5 明细导出

仅已完成转移单提供【导出明细】。

规则：

- 文件格式为 .xlsx；
- 文件名：转移单号-明细.xlsx；
- 导出字段与当前转移物资明细字段一致；
- 导出不修改任何业务数据。

### 6.6 打印

仅已完成转移单提供【打印】。

打印标题：

物资转移单

#### 6.6.1 单头

打印：

- 转移单号；
- 转移日期；
- 公司。

公司打印公司名称。

#### 6.6.2 明细

打印明细固定字段：

| 序号 | 资产类别 | 资产标签号 | 资产说明 | 数量 | 移出部门 | 移出责任人 | 移出资产地点 | 移入部门 | 移入责任人 | 移入资产地点 | 使用说明 含：变动原因 |
|---|---|---|---|---:|---|---|---|---|---|---|---|

字段来源：

- 资产类别 = 资产大类 + 资产小类；
- 移出部门、移出资产地点取转移前快照；
- 移出责任人取转出人；
- 移入部门、移入资产地点取最终转入信息；
- 移入责任人取转入人；
- 使用说明同时承载变动原因。

#### 6.6.3 打印版式

- 顶部左侧展示搜狐黄色 Logo；
- 标题居中“物资转移单”；
- 标题下方横线；
- 明细使用细黑色边框表格；
- 无数据区域补空白行；
- 表格底部展示“合计”数量；
- 底部签字栏：
  - 转移人（签字）/ 时间；
  - 部门领导（签字）/ 时间；
- 页面右侧竖排展示“一联 转出方”；
- 使用 A4 横向打印布局，保证 12 列字段在单页宽度内完整展示；
- 点击【打印】后打开独立打印页面；
- 打印失败允许重试；
- 打印不修改单据、资产台账、事务或锁定状态。
