# 库存管理 - 转移

> 本文仅记录 2026-09-10 ERP 截图确认的字段与页面结构。历史 ERP 仅作为字段来源，页面视觉统一按当前项目规范实现。

## 1. 转移单创建页

### 单据头

- 转移单号：自动生成，只读。
- 单据类型：转移单，只读。
- 单据状态：草稿，只读。
- 公司：选择字段。
- 制单人：只读。
- 制单时间：只读。
- 备注：多行文本，独占完整一行。

### 转移物资列表

- 行号
- 资产标签号
- 物资说明
- 物资总类
- 物资大类.小类
- 转移数量
- 转出人
- 转出成本中心
- 转入人
- 转入成本中心
- 转入城市
- 转入建筑物
- 操作

创建页支持添加物资、Excel 导入、保存草稿、返回。页面级“保存草稿 / 返回”按当前项目规范放页面底部居中。

## 2. 添加转移物资弹窗

### 选择物资

- 当前公司
- 资产标签号
- SN号

### 物资信息

- 资产标签号
- SN号
- 物资说明
- 可用数量
- 物资总类
- 物资大类
- 物资小类
- 资产数量
- 品牌
- 规格/型号
- 配置
- 计量单位
- 资产标记
- 原值
- 净值
- 资产状态
- 公司
- 板块
- 部门
- 成本中心
- 业务线
- 项目
- 费用账户
- 责任人
- City
- Building
- Floor
- Room
- 启用日期
- 印刷号
- 用途
- 备注

### 转移单信息

- 转入人：必填。
- 转入板块
- 转入部门
- 转入成本中心：必填。
- City：必填。
- Building：必填。
- Floor：必填。
- Room
- 用途：必填。
- 资产状态：必填。
- 业务线
- 项目
- 转移原因
- 转移日期
- 使用说明：多行文本，独占完整一行。

必填编辑字段统一使用红色星号；只读物资信息直接展示文本，不用禁用输入框模拟只读。
