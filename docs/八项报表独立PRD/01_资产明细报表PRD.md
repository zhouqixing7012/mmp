# 资产明细报表PRD

## 1. 背景

用于查看资产的归属、使用和财务信息，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。

## 2. 权限

| 角色 / 条件 | 可查看的数据范围 | 可执行操作 | 无权限结果 |
| --- | --- | --- | --- |
| 具备相应台账及资产卡片查看权限的用户 | 使用已有台账及资产卡片查看权限；集团、上海媒体分公司、广州媒体分公司各自查看所属台账数据。查询与导出范围相同，不另设报表角色权限。 | 查询、分页、导出有权查看的记录。 | 无权查看的台账或卡片数据不展示、不导出。 |

## 3. 通用规则

人员、组织、类别及其他选择条件使用对应正式基础资料与授权候选，不同人员角色共用人员资料；不因选择方式改变本页数据范围或历史取值时点。

| 规则 | 业务要求 |
| --- | --- |
| 来源与明细粒度 | 资产卡片，每行对应一个资产标签号。 |
| 数据范围 | 不额外按资产状态、采购日期或报废日期排除记录，按权限及填写的条件筛选。 |
| 默认排序 | 资产大类编码升序，再按资产小类编码升序。 |
| 数据读取 | 每次查询读取最新的业务数据，展示当前有权查看的匹配结果。 |
| 查询匹配 | 不同条件同时满足，同一多选内命中任一值；日期可填写单端并包含所选自然日。文本条件去除首尾空格后包含匹配。 |
| 操作范围 | 报表只读，不提供新增、编辑、删除、审批或打印。 |

## 4. 页面字段及交互

选择候选、搜索、结果列、跨页选择、确定、取消、清空及加载异常遵循[报表公共查询交互规则](00_报表公共查询交互规则.md)，各字段保留本页特有的范围、单多选及联动规则。查询条件均选填，首次为空；单号、编码及标签保留前导零。

### 页面操作

| 操作 | 可用条件 | 结果及异常 |
| --- | --- | --- |
| 查询 | 具备本页查询权限，条件通过校验 | 点击查询或按回车，每次读取最新数据，按当前条件更新结果与条数并回到第一页；加载期间不可重复查询。失败提示“查询失败，请重试”，不得显示为无数据。 |
| 重置 | 查询页面可操作时 | 二次确认后清空输入条件；现有列表、分页和排序不自动改变。取消确认保留条件；重置后点击查询或按回车才按新条件更新结果。 |
| 分页 | 已取得查询结果 | 显示总记录数，翻页和修改每页条数时保留筛选条件；统计的是报表明细行数。 |
| 导出 | 具备本页查询权限，导出条件通过校验 | 导出当前条件下全部有权查看的结果，不限当前页；使用本页业务字段顺序和默认排序，不含显示序号。导出失败提示“导出失败，请重试”。 |

## 5. 校验

| 校验项 | 触发时机 | 判断及处理 | 提示与修正 |
| --- | --- | --- | --- |
| 日期起止 | 选择日期、查询、导出 | 同一日期的开始不得晚于结束，允许只填写一端；不满足时阻止查询或导出。 | “开始日期不能晚于结束日期”；修改起止日期。 |
| 权限 | 进入、查询、导出 | 按已有台账及资产卡片查看权限筛选；查询与导出范围相同，不另设报表角色权限。 | 无权限数据不展示、不导出；没有有权查看的匹配记录时显示“暂无数据”。 |
| 基础资料选择 | 查询、导出 | 按已选编码或工号筛选；多选不转换为单个文本；失效选项不得作为正常候选。 | 所选资料失效时提示“所选资料已失效，请重新选择”。 |
| 只读字段 | 列表展示 | 报表不修改来源业务记录；缺失取值不得自行补0、补“否”或重新猜测来源。 | 缺失值显示为空白。 |

## 6. 后续操作 / 业务结果 / 补充说明

导出生成“资产明细报表-YYYYMMDD.xlsx”。列表和导出使用相同字段含义、权限、筛选条件及排序。空值保持空白，金额保留两位小数，编码按文本保存。查询和导出不改变资产、单据状态，不生成事务、审批或通知。
