# 资产明细报表PRD

## 1. 背景

用于查询资产卡片当前明细，并导出资产、财务价值、责任人、位置及来源信息。本篇以独立资产明细报表入口为主体，末尾说明同名旧入口差异。报表不是历史时点快照，也不是资产事务明细。

## 2. 权限

具备页面访问权限的用户可查询、导出。代码未给出可访问角色名单，不指定ES或财务专属。未列入资产规则用户配置的广州/上海公司用户，仅查本公司；其他公司用户在独立入口没有额外公司排除条件。入口传入板块范围时，在上述范围内进一步限定，用户查询条件不能扩大权限。仓库选择范围另受用户仓库查看权限限制。

## 3. 通用规则

每条结果来自一张未删除的资产卡片，只查资产总类编码1。卡片按资产ID关联价值信息、按扩展信息ID关联资产标记；价值信息不存在时相关字段为空。原值、净值等直接读取现存数据，不汇总历史事务，不按数量重复乘算。

姓名、部门、公司及地点等名称在查询时由当前基础资料转换；责任人变更后显示当前责任人，人员部门调整后HR部门也随当前资料变化。基础资料无匹配项时不能据此推断原历史名称。若资产价值表同一资产ID存在多行，现有连接没有去重，不保证一张卡片只出现一行。

查询条件均可不填，不同条件同时成立，同一多选条件满足任一所选值。采购、启用、报废日期允许单边查询。默认显示常用条件，“更多”默认收起，展开位置、金额、用途等条件。

## 5. 校验

日期选择限制起始日期不得晚于结束日期。原值和净值输入在失焦时去除千分位判断是否数字，非数字被清空，有效值格式化；不是必填。现状未发现对折旧月数的整数范围、费用账户格式或文本长度的专门业务校验。公司、板块数据权限在查询与导出分别应用。

## 6. 后续操作 / 业务结果 / 补充说明

查询和导出不修改资产、责任人、账面价值，不产生审批单或资产事务。导出日期来源与页面相同；导出升级金额为空时写0，其余多数字段为空时写空。

同名旧入口调用资产维护报表查询：字段基本相同，但旧导出缺少EBS资产原值和担保人两列；标签号和序列号使用前缀匹配，而独立入口使用包含匹配；旧入口公司权限存在“排除115/116、板块16例外”的不同逻辑。由于菜单运行配置未提供，本篇不将两套规则混写为唯一规则。独立入口没有实际生效的默认排序，不能写为默认按公司或标签号排序。
