# 报表公共查询交互规则

适用于资产报表目录中01—08的查询和基础资料选择；各页字段的候选限制、单多选、匹配方式、排序及历史时点以对应PRD为准。固定资产新增报表的重置、导出及月度发送按其独立PRD，不套用其他页面操作。

## 查询控件

文本框可输入、清空，去除首尾空格后按字段规定包含匹配；回车执行查询。日期区间允许单端且包含所选自然日，开始不得晚于结束。多选内命中任一值，不同条件同时满足。初始条件为空，不设必填；字段有专属限制时按该字段处理。

候选取人员、公司、组织、物料、仓库及地点的对应基础资料，并遵守当前用户的权限、启用状态和本页业务范围。候选不由已有报表交易反推；有候选不代表一定有匹配记录。人员使用工号，其余资料使用各自编码；显示名称不替代编码。资料名称的选择回显不改变报表历史字段的规定时点。

## 选择入口与候选列表

下拉、树形和弹窗按各页字段表使用，不互相替换。可搜索和清空；不接受不在候选中的自由文本作为选择值。部门树按组织层级展示，类别树按真实父子关系展示；是否包括下级及是否多选按对应字段定义。

| 选择对象 | 候选查询字段及控件 | 结果列及回填 |
| --- | --- | --- |
| 人员 | 工号、姓名、部门文本框；包含匹配，不同条件同时满足 | 工号、姓名、部门；回填工号及姓名，以工号筛选。 |
| 公司 | 编码、名称文本框；包含匹配 | 公司编码、公司名称；回填编码及名称。 |
| 部门 | 编码、名称文本搜索或树内搜索 | 部门编码、完整名称及组织层级；回填所选部门编码和名称。 |
| 办公区 | 编码、名称文本框；包含匹配 | 办公区编码、名称；回填编码及名称。 |
| 仓库 | 编码、名称文本框；包含匹配 | 仓库编码、仓库名称、公司；回填编码及名称。 |
| 成本中心 | 编码、名称文本框；包含匹配 | 成本中心编码、名称；回填编码及名称。 |
| 物料 | 编码、描述文本框；包含匹配 | 物料编码、物料描述；回填编码及描述。 |
| City | 名称文本框；包含匹配 | City名称；回填所选City。 |
| Building | Building名称、City名称文本框；包含匹配 | Building名称、City名称；回填所选Building；按对应页面要求先选City并限制候选。 |
| Floor | 名称搜索 | Floor名称；选中及回显均只展示名称。 |

| 操作或场景 | 交互结果 |
| --- | --- |
| 打开 | 点击选择字段展示候选及原已选项；弹窗内输入不直接改变主查询条件。 |
| 候选查询 | 点击查询或回车应用候选条件并回第一页；分页保留候选条件及已选项。 |
| 候选重置 | 清空候选查询输入，不清除已选资料，不改变主页面结果。 |
| 单选 | 最多选择一项。 |
| 多选 | 跨页保留已选资料、展示选中数量，允许移除；不得只返回当前页选项。 |
| 确定 | 选择有效项后按字段的单多选要求回填，关闭弹窗；未选时提示“请选择一项”或“请至少选择一项”，保留弹窗。 |
| 取消或关闭 | 放弃本次选择，保留主条件原值。 |
| 清空主条件 | 清除编码及回显名称，不立即改变已经展示的结果。 |
| 无候选 | 显示“暂无可选资料”，允许调整查询或取消，不虚构候选。 |
| 加载失败 | 提示“资料加载失败，请重试”，保留候选条件及主条件，可重试或取消；不显示成无候选。 |

## 查询、分页与导出反馈

各页按钮的重置确认、是否自动查询及导出条件范围按本页PRD执行。查询失败提示“查询失败，请重试”，保留输入和上次成功结果，明确旧结果对应上次查询；不将失败当作无数据。查询无匹配才显示“暂无数据”。

分页保留成功查询条件及每页条数。查询和导出按当前权限校验；无权数据既不展示也不导出。编码、标签和单号按文本保留前导零，普通姓名及说明不追加编号格式。空值不补0或猜测来源，真实0与空白区分。

导出使用本页规定字段及排序，不限当前页；只有生成文件并提供下载后才提示成功。生成或下载失败提示“导出失败，请重试”，保留查询条件及列表，可重试。查询及导出在实际处理中防止同一动作重复发起，不以虚假等待替代业务执行。
