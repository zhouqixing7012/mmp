# 资产明细报表PRD

## 1. 背景

用于查询资产卡片当前明细，并导出资产、财务价值、责任人、位置及来源信息。本篇以独立资产明细报表入口为主体，末尾说明同名旧入口差异。报表不是历史时点快照，也不是资产事务明细。

## 2. 权限

具备页面访问权限的用户可查询、导出。代码未给出可访问角色名单，不指定ES或财务专属。未列入资产规则用户配置的广州/上海公司用户，仅查本公司；其他公司用户在独立入口没有额外公司排除条件。入口传入板块范围时，在上述范围内进一步限定，用户查询条件不能扩大权限。仓库选择范围另受用户仓库查看权限限制。

## 3. 通用规则

每条结果来自一张未删除的资产卡片，只查资产总类编码1。卡片按资产ID关联价值信息、按扩展信息ID关联资产标记；价值信息不存在时相关字段为空。原值、净值等直接读取现存数据，不汇总历史事务，不按数量重复乘算。

姓名、部门、公司及地点等名称在查询时由当前基础资料转换；责任人变更后显示当前责任人，人员部门调整后HR部门也随当前资料变化。基础资料无匹配项时不能据此推断原历史名称。若资产价值表同一资产ID存在多行，现有连接没有去重，不保证一张卡片只出现一行。

查询条件均可不填，不同条件同时成立，同一多选条件满足任一所选值。采购、启用、报废日期允许单边查询。默认显示常用条件，“更多”默认收起，展开位置、金额、用途等条件。

## 5. 校验

日期选择限制起始日期不得晚于结束日期。原值和净值输入在失焦时去除千分位判断是否数字，非数字被清空，有效值格式化；不是必填。现状未发现对折旧月数的整数范围、费用账户格式或文本长度的专门业务校验。公司、板块数据权限在查询与导出分别应用。

## 6. 后续操作 / 业务结果 / 补充说明

查询和导出不修改资产、责任人、账面价值，不产生审批单或资产事务。导出日期来源与页面相同；导出升级金额为空时写0，其余多数字段为空时写空。

同名旧入口调用资产维护报表查询：字段基本相同，但旧导出缺少EBS资产原值和担保人两列；标签号和序列号使用前缀匹配，而独立入口使用包含匹配；旧入口公司权限存在“排除115/116、板块16例外”的不同逻辑。由于菜单运行配置未提供，本篇不将两套规则混写为唯一规则。独立入口没有实际生效的默认排序，不能写为默认按公司或标签号排序。


# 耗材明细报表PRD

## 1. 背景

用于查询耗材卡片，并导出耗材详细信息。现状源码没有独立的“耗材明细报表”查询页面：耗材查询列表上的导出功能生成“耗材明细报表”。本篇按这条已确认的页面与导出链路说明，查询列表与导出文件字段分别列出，不把管理列表扩写为新增报表页面。新增、删除、批量修改等耗材维护操作不属于本篇报表范围。

## 2. 权限

具备耗材列表访问权限的用户可查询；访问角色名单、导出按钮角色控制未在已读代码中定义。

| 用户情况 | 列表数据范围 | 导出数据范围 |
| --- | --- | --- |
| 已配置资产规则用户 | 不附加公司隔离条件 | 不附加公司隔离条件。 |
| 非规则用户，所属公司115 | 仅公司115 | 仅公司115。 |
| 非规则用户，所属公司116 | 仅公司116 | 仅公司116。 |
| 非规则用户，其他公司 | 排除公司115、116 | 排除公司115、116，但板块16可例外进入；现状与列表不同。 |
| 普通用户，且未具有查看全部资产角色 | 按人员资料所属板块限制；板块下拉禁用 | 导出方法未重新执行上述板块赋值，是否保留该限制不能仅依赖页面禁用状态确认。 |
| 系统管理员或配置的查看全部资产角色 | 不强制限定人员所属板块 | 仍受导出方法中的公司及入口板块条件限制。 |

入口传入板块范围时，导出进一步限定到该范围。以上为现状代码差异，不能写成“查询与导出权限完全一致”。

## 3. 通用规则

只查耗材总类，排除合约机大类，排除已标记删除的卡片。页面结果按资产ID关联价值表读取净值；没有对应价值时可为空。卡片必须能匹配资产状态字典才出现在列表。报表不记录历史时点，也不按查询期间统计新增、领用或报废数量。

各查询条件均非必填，不同条件同时成立，多选条件匹配任一所选值。日期、金额允许单边查询。默认结果按卡片最后更新时间倒序（空值后置），再按耗材标签号排序；点击表头可改变排序。常用条件默认展示，“更多”中的位置、报废、金额和日期条件默认收起。

## 5. 校验

购买、启用日期选择器限制开始日不晚于结束日。金额输入失焦后去除千分位并写入实际金额字段；没有确认后端对“原值自≤原值至”的独立校验。原值范围0被后端忽略，因此不能用“原值至=0”查询零原值耗材。

仅报废状态选“已报废”时，报废类型允许选择；切换其他状态会禁用报废类型，但代码没有清空已选值。人员查询以选择回填的工号为准，不能将只录入姓名解释为有效人员筛选。

导出文件名“耗材明细报表-YYYYMMDD.xlsx”，工作表名“低值耐用品明细”。导出只读取数据，不修改卡片、不新增事务或审批。导出默认按资产类型、公司、板块、资产编号排序，若已点选表头排序则沿用该排序。

# 资产事务报表 PRD

## 1. 背景

用于查询资产发生的事务明细，核对事务时间、关联单据、资产信息、仓库、责任人及部门变化，并导出结果。本篇按照所提供源码描述当前页面和取值逻辑，不新增业务规则。

报表直接读取资产事务报表数据表 `M0002_FCT_ASSETS_TRANSACTION`。页面不实时关联资产卡片重新计算资产信息，不按单据汇总。结果为该表满足条件的记录；同一资产发生多次事务，可展示多条记录。上游写入粒度、数据刷新频率尚未确认。

## 2. 权限

| 项目 | 规则 |
| --- | --- |
| 页面访问、导出 | 当前页面具有查询、导出入口；具体允许访问的角色及菜单授权未在本报表源码中定义，待确认。 |
| 仓库可选范围 | 源仓库、目标仓库仅可选择启用的一级仓库，且当前登录人工号在该仓库具有查看权限。 |
| 公司、创建人可选范围 | 公司取公司视图全部可选记录；创建人取人员表，不额外限制为当前登录人或本公司人员。 |
| 报表数据范围 | 报表查询服务未按当前登录人追加公司、仓库或资产责任人限制。仓库选择弹窗的权限不等同于整张报表的数据权限；公共访问层是否另有限制，待确认。 |

## 3. 通用规则

1. 查询条件均可留空；不同条件之间同时满足，同一多选条件内满足任一已选值。
2. 当通过带初始化标记的入口进入时，事务处理日期默认从当前日期向前一个月，到当前日期。不是固定最近 30 天。普通查询不自动重新设置日期。
3. 文本条件去除首尾空格后进行包含匹配；不是精确相等。输入中的 SQL 通配字符是否应作为普通字符处理，现有实现未定义。
4. 日期按自然日比较，开始、结束当天均包含；只填一端时只限制该端。无日期条件时不限制事务日期。
5. 默认按记录 ID 升序分页。序号按“前面各页记录数＋本页行号”生成，翻页连续，不是资产编号或事务编号。
6. 查询结果仅用于查看和导出，无新增、修改、审批、删除操作。
7. 报表记录保存的编码会按查询时的字典、公司、板块、人员、仓库名称转换；这些名称可能随基础资料变化，不能把所有展示名称都理解为事务发生时的名称。

# 新员工领用报表 PRD

## 1. 背景

用于查看员工入职信息、PS 配置要求及实际领用资产，核对申请单、资产配置、出库日期、刷卡和领用信息，并导出结果。本篇描述所提供源码的当前行为，不以页面名称推定未实现的规则。

报表直接读取 `M0002_FCT_RECIPIENTS` 中满足条件的明细记录，不按员工或申请单合并。页面不重新计算员工资产是否超标，也不从当前资产卡片重新带出信息。数据表的一行对应哪一条领用明细，以及是否包含未领用员工，取决于上游生成规则，尚待确认。

## 3. 通用规则

1. 所有查询条件均可留空，没有预设入职、启用日期范围。不同条件同时满足，同一多选条件内匹配任一所选值。
2. 文本字段去除首尾空格后做包含匹配。日期按自然日比较，开始日、结束日均包含，单独填写开始或结束日期也可查询。
3. 默认按记录 ID 升序分页，不按入职时间或出库时间倒序。
4. 员工、资产及领用信息全部读取报表表中保存的字段；报表服务没有重新关联当前员工档案、资产卡片或领用单做实时计算。
5. 查询列表只读，无新增、编辑、删除、审批操作。序号按分页位置连续计算，不是工号、资产数量或申请单编号。
6. 当前查询没有额外“新员工”身份、已领用、已刷卡、流程完成状态过滤；这些范围是否已在上游生成表中限定，待确认。

# 资产统一申领报表PRD（现状）

## 1. 背景

用于查询统一申请从申请、子流程审批到领用的处理结果。现有源码分为“统一申请库存领用报表”和“统一申请统一采购报表”两个独立页面，分别记录库存直接领用和需要统一采购后的领用链路。本文分别说明，不合并其查询字段与金额口径。

## 2. 权限

页面具有查询和导出入口；具体允许访问的角色、菜单授权未在所提供页面和报表Action中定义，待确认。页面虽然传递登录账号，但这四个报表的可见查询代码未按登录人、公司或部门追加数据范围；不能宣称仅可见本人或所在公司数据。全局拦截或报表源内部是否限权须另行确认。

## 3. 通用规则

所有查询条件均可不填。不填的条件不限制结果；多个不同条件同时填写时须全部满足，同一弹窗多选条件命中任一选项即可。文本匹配先去除首尾空格，再按包含匹配；源码直接使用LIKE，百分号与下划线未作字面转义。页面只读，不提供新增、编辑、删除、审批。点击查询或按回车提交当前条件；双击查询区后确认可清空条件，但不会自动执行新查询。

列表与导出使用同一查询及同一筛选条件，但统一采购页存在导出列写错问题，见补充说明。分页统计为源返回行数，不是申请单数；不在页面按单据合并，也不另做去重。
两页默认按申请单号倒序、申请日期倒序。同一物料申请数量大于1时，资产入库／领用后会将申请信息拆为多行，申请数量在每行保持原值。不得直接逐行合计申请数量；现有页面提示采用行计数统计，但尚未入库、领用的数据未拆行，因此“行数等于总申请台数”并非全阶段成立。

## 6. 后续操作 / 业务结果 / 补充说明

导出当前条件下全部匹配行，不限于当前页，每批读取20,000行，生成xlsx。没有数据时生成仅表头文件；导出不改变业务数据。空值导出为空白，不替换为0或“否”。金额页面采用千分位两位小数，导出用数字格式化后的文本；页面的50字显示限制不截断导出内容。库存领用和统一采购的申请日期、完成时间导出调用COMMON.DATA_FORMAT，具体格式须配置确认；库存领用出库日期直接导出源字符串，统一采购出库日期调用COMMON.DATA_FORMAT。

# 耗材统一申领报表PRD（现状）

## 1. 背景

用于查询耗材统一申请的采购、领用进度及申请结果对应的耗材明细。源码包含“统一申请耗材采购领用报表”和“统一申请耗材明细报表”两个页面：前者以业务流程字段为主，后者以耗材标签、数量、责任人及申请关系为主。分别列明，避免与普通耗材明细报表混淆。

## 2. 权限

页面具有查询和导出入口；具体允许访问的角色、菜单授权未在所提供页面和报表Action中定义，待确认。页面虽然传递登录账号，但这四个报表的可见查询代码未按登录人、公司或部门追加数据范围；不能宣称仅可见本人或所在公司数据。全局拦截或报表源内部是否限权须另行确认。

## 3. 通用规则

所有查询条件均可不填。不填的条件不限制结果；多个不同条件同时填写时须全部满足，同一弹窗多选条件命中任一选项即可。文本匹配先去除首尾空格，再按包含匹配；源码直接使用LIKE，百分号与下划线未作字面转义。页面只读，不提供新增、编辑、删除、审批。点击查询或按回车提交当前条件；双击查询区后确认可清空条件，但不会自动执行新查询。

列表与导出使用同一查询及同一筛选条件。分页统计为源返回行数，不是申请单数；不在页面按单据合并，也不另做去重。
采购领用页默认按申请单号倒序、申请日期倒序；明细页默认按耗材状态、物料编码、耗材标签号排序。两个页面取自不同报表源，不保证行数相同，不可用其中一页的行数替代另一页的领用数量。采购领用页没有申请数量列，只有领用数量；明细页耗材数量实际取入库数量字段。

## 6. 后续操作 / 业务结果 / 补充说明

导出当前条件下全部匹配行，不限于当前页，每批读取20,000行，生成xlsx。没有数据时生成仅表头文件；导出不改变业务数据。空值导出为空白，不替换为0或“否”。金额页面采用千分位两位小数，导出用数字格式化后的文本；页面的50字显示限制不截断导出内容。日期导出调用系统TIME_FORMAT，其常量具体格式须配置确认。
采购领用页导出31个业务字段，明细页导出27个业务字段，不含序号。文件名分别为“统一申请耗材采购领用报表-日期.xlsx”“统一申请耗材明细报表-日期.xlsx”。明细页列表“采购申请单号”在导出中名为“采购申请号”，均取RELATED_PURCHASE_ID。

采购领用页取M0009_FCT_CONSUM_APPLY_EUA，明细页取M0009_FCT_CONSUM_APPLY_RESULT；没有源定义，未确认申请、采购、出库、耗材卡片之间的关联唯一键与一对多展开规则。金额范围与计算、税金按单件还是整行、是否领用／占用的判断公式、耗材状态字典、仓库STATUSDETAIL在各状态下的含义、责任人与组织信息是当前还是历史、刷新频率及完成时间归属均待确认。不得假设每一行是一张申请单，也不能直接用入库数量计算当前可用库存。

## 1. 背景

用于查看已报废资产的卡片信息、数量、财务价值和报废结果，并导出 Excel。页面取资产卡片记录，不是报废申请单明细，也不是按每次报废事务生成的历史流水。

| 条件组合 | 所有已填写条件同时满足；空条件不追加筛选。 |
| 当前与历史 | 公司、责任人工号、位置、数量、原值等从当前卡片读取；净值从当前价值表读取；报废日期、数量、类型、原因从卡片保存的报废字段读取。责任人姓名及类别名称按当前人员、基础资料转换。不可理解为报废完成时的完整快照。 |
| 日期金额 | 日期 yyyy-MM-dd；数量、折旧月数、报废数量显示整数；原值、净值、报废原值、报废净值显示千分位两位小数。 |
| 默认顺序 | 按资产类型、公司、板块、资产编号排序；不是默认按报废日期倒序。 |

### 4.3 操作

| 操作 | 交互与结果 |
|---|---|
| 查询 | 点击查询或按回车提交条件，返回分页列表。 |
| 清除 | 双击查询区域，确认清空所有查询条件；选择字段也可单独点清除图标。 |
| 列头排序 | 多数列提供排序入口；报废原值和报废净值没有。部分入口仍使用旧表别名，见补充说明。 |
| 导出资产报废报表 | 确认导出列表所有数据后，按表单条件重新查询全部结果；后台不限制本页。文件名为“资产报废报表-yyyyMMdd.xlsx”。 |

## 5. 校验

| 校验项 | 规则 |
|---|---|
| 日期先后 | 日期选择器约束从日不晚于至日；后台包含起止日全天。 |
| 报废范围 | 后台始终要求状态为 13 或 14 且 UNABLE_DATE 非空；未报废资产不能因其他条件匹配而进入结果。 |
| 数量与金额 | 报表只读，未见数量上限或金额分摊校验；不会为缺失报废价值自动计算。 |

## 6. 后续操作 / 业务结果 / 补充说明

查询和导出不产生报废单，不修改卡片，也不触发处置。

| 项目 | 现状与需要明确的口径 |
|---|---|
| 导出字段 | 导出所有列表业务字段，但不含序号、印刷号；仓库标题改为“库房”；末尾新增“备注”，取卡片 REMARK。 |
| 导出显示 | 日期同列表；金额千分位两位小数；数量和报废数量通过取整数输出为文本。列表整数显示与导出取整数在非整数数据下可能不同，不能扩展为允许小数。 |
| 导出地点及板块显示 | City只导出城市名称，不带列表的城市编码；导出财务核算板块是否隐藏，当前错误地判断资产所属板块是否为单个“.”，列表则判断财务核算板块自身，异常值情况下可能不同。 |
| 导出范围差异 | 其他未配置用户导出允许板块 16，而列表排除 115、116 所有资产；这是现有范围差异，需确认业务是否应统一。 |
| 报废价值缺失 | 已核对 DTO、SQL、Service、JSP 和导出代码，报废原值、报废净值没有赋值链路。文档保留页面字段并明确未填充，不虚构计算规则。 |
| 排序异常 | 类别、成本中心、公司、状态、地点等列头仍引用 MS、MT、PED、O、AI3、ML 等旧查询别名，当前 SQL 只关联 MA、MV、M。需要核验排序参数转换；若直接拼接这些列，查询将报错。 |
| 公共资料 | 字典具体可选名称、类别树完整规则、公共板块选择器源码未提供，不能自行补出完整选项列表或多选规则。 |
