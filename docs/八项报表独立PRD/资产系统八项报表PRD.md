# 资产系统八项报表PRD

本合订本与01—08八份独立PRD内容同步，各报表保持独立六章规则。

# 资产明细报表PRD

## 1. 背景

用于查看资产的归属、使用和财务信息，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。

## 2. 权限

| 角色 / 条件 | 可查看的数据范围 | 可执行操作 | 无权限结果 |
| --- | --- | --- | --- |
| 具备相应台账及资产卡片查看权限的用户 | 使用已有台账及资产卡片查看权限；集团、上海媒体分公司、广州媒体分公司各自查看所属台账数据。查询与导出范围相同，不另设报表角色权限。 | 查询、分页、导出有权查看的记录。 | 无权查看的台账或卡片数据不展示、不导出。 |

## 3. 通用规则

同一业务字段共用已有选择组件和基础资料：成本中心按编码选择，人员按工号选择，板块、用途及新增类型使用共享下拉字典。支持搜索、清空及本页规定的单选或多选；不同名称的人员角色不另建人员来源。候选按原权限与业务范围限制，选择组件复用不改变历史快照或结果权限。

| 规则 | 业务要求 |
| --- | --- |
| 来源与明细粒度 | 资产卡片，每行对应一个资产标签号。 |
| 数据范围 | 不额外按资产状态、采购日期或报废日期排除记录，按权限及填写的条件筛选。 |
| 默认排序 | 资产大类编码升序，再按资产小类编码升序。 |
| 数据读取 | 每次查询读取最新的业务数据，展示当前有权查看的匹配结果。 |
| 查询匹配 | 所有条件非必填，默认空。不同条件同时满足，同一多选内命中任一值；日期可填写单端并包含所选自然日。文本条件去除首尾空格后包含匹配。 |
| 操作范围 | 报表只读，不提供新增、编辑、删除、审批或打印。 |

### 页面操作

| 操作 / 组件 | 是否可编辑 / 必填 | 交互与结果 |
| --- | --- | --- |
| 查询条件 | 可编辑，全部非必填 | 首次进入条件为空；未填项不限制结果。不同条件同时满足，多选项命中任一即可；单项可清空。 |
| 选择弹窗 | 只能选择，非必填 | 复用对应基础资料选择组件，可按编码或名称搜索；人员可按工号或姓名搜索。回填名称并保留编码或工号，可移除已选项；这些选择规则仅适用于选择组件，不限制资产标签号、主资产标签号等文本框自由输入。无候选时显示“暂无数据”；加载失败提示失败并允许重试。 |
| 查询 | 不适用 | 点击查询或按回车，每次读取最新数据，按当前条件更新结果与条数并回到第一页；加载期间不可重复查询。失败提示“查询失败，请重试”，不得显示为无数据。 |

# 新员工领用报表PRD

## 1. 背景

用于查看新员工入职、配置要求和实际领用情况，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。

# 资产新增报表PRD

## 1. 背景

用于核对已完成入库的新增资产及完成时信息，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。

## 2. 权限

| 角色 / 条件 | 可查看的数据范围 | 可执行操作 | 无权限结果 |
| --- | --- | --- | --- |
| 具备相应台账及资产卡片查看权限的用户 | 使用已有台账及资产卡片查看权限；集团、上海媒体分公司、广州媒体分公司各自查看所属台账数据。查询与导出范围相同，不另设报表角色权限。 | 查询、分页、导出有权查看的记录。 | 无权查看的台账或卡片数据不展示、不导出。 |

## 3. 通用规则

同一业务字段共用已有选择组件和基础资料：成本中心按编码选择，人员按工号选择，板块、用途及新增类型使用共享下拉字典。支持搜索、清空及本页规定的单选或多选；不同名称的人员角色不另建人员来源。候选按原权限与业务范围限制，选择组件复用不改变历史快照或结果权限。

| 规则 | 业务要求 |
| --- | --- |
| 来源与明细粒度 | 入库单，每行对应入库单中的一个资产标签号。 |
| 数据范围 | 仅包括状态为“已完成”（已执行入库）、入库类型为新增入库、采购接收或自购入库，且资产总类为资产的记录。 |
| 默认排序 | 依次按资产大类编码、资产小类编码、公司编码、板块编码、资产标签号升序。 |
| 历史取值 | 以入库完成时点的字段及名称形成历史记录，后续资产、责任人、组织、板块或账簿变化不更新该记录。 |
| 数据读取 | 每次查询读取最新的报表记录；已完成业务的历史字段仍取规定的完成时点值，不随当前资产、人员或基础资料变化改写。 |
| 查询匹配 | 所有条件非必填，默认空。不同条件同时满足，同一多选内命中任一值；日期可填写单端并包含所选自然日。文本条件去除首尾空格后包含匹配。 |
| 操作范围 | 报表只读，不提供新增、编辑、删除、审批或打印。 |

# 资产统一申领报表PRD

## 1. 背景

用于查看资产统一申请、配给、采购和领用进度，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。本报表保留“统一申请库存领用报表”和“统一申请统一采购报表”两页签，分别呈现库存领用和统一采购链路。

## 2. 权限

| 角色 / 条件 | 可查看的数据范围 | 可执行操作 | 无权限结果 |

## 3. 通用规则

同一业务字段共用已有选择组件和基础资料：成本中心按编码选择，人员按工号选择，板块、用途及新增类型使用共享下拉字典。支持搜索、清空及本页规定的单选或多选；不同名称的人员角色不另建人员来源。候选按原权限与业务范围限制，选择组件复用不改变历史快照或结果权限。

# 耗材统一申领报表PRD

## 1. 背景

用于查看耗材统一申请、配给、采购和领用进度，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。本报表展示统一申请耗材采购领用信息；耗材卡片及领用物料明细归入独立的耗材明细报表。

同一业务字段共用已有选择组件和基础资料：成本中心按编码选择，人员按工号选择，板块、用途及新增类型使用共享下拉字典。支持搜索、清空及本页规定的单选或多选；不同名称的人员角色不另建人员来源。候选按原权限与业务范围限制，选择组件复用不改变历史快照或结果权限。

# 资产报废报表PRD

## 1. 背景

用于核对已完成报废的资产及报废时信息，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。

## 2. 权限

| 角色 / 条件 | 可查看的数据范围 | 可执行操作 | 无权限结果 |
| --- | --- | --- | --- |
| 具备相应台账及资产卡片查看权限的用户 | 使用已有台账及资产卡片查看权限；集团、上海媒体分公司、广州媒体分公司各自查看所属台账数据。查询与导出范围相同，不另设报表角色权限。 | 查询、分页、导出有权查看的记录。 | 无权查看的台账或卡片数据不展示、不导出。 |

## 3. 通用规则

同一业务字段共用已有选择组件和基础资料：成本中心按编码选择，人员按工号选择，板块、用途及新增类型使用共享下拉字典。支持搜索、清空及本页规定的单选或多选；不同名称的人员角色不另建人员来源。候选按原权限与业务范围限制，选择组件复用不改变历史快照或结果权限。

| 规则 | 业务要求 |
| --- | --- |
| 来源与明细粒度 | 资产卡片，每行对应一个资产标签号。 |
| 数据范围 | 仅包括资产总类为资产，资产状态为“已报废-待处置”或“已报废-已处置”的记录；耗材不进入本报表。 |
| 默认排序 | 报废日期倒序，最新记录在最上方。 |
| 历史取值 | 以报废完成时点的字段及名称形成历史记录，后续处置、资产、人员或基础资料变化不更新该记录。 |
| 数据读取 | 每次查询读取最新的报表记录；已完成业务的历史字段仍取规定的完成时点值，不随当前资产、人员或基础资料变化改写。 |
| 查询匹配 | 所有条件非必填，默认空。不同条件同时满足，同一多选内命中任一值；日期可填写单端并包含所选自然日。文本条件去除首尾空格后包含匹配。 |
| 操作范围 | 报表只读，不提供新增、编辑、删除、审批或打印。 |

| 结果列表 | 只读，非必填 | 按逐字段规则展示，空结果显示“暂无数据”；单号为文本，列表不发起审批或编辑。 |
| 导出 | 不适用 | 导出当前条件下全部有权查看的结果，不限当前页；使用本页业务字段顺序和默认排序，不含显示序号。导出失败提示“导出失败，请重试”。 |
