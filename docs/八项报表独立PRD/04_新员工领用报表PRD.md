# 新员工领用报表 PRD

## 1. 背景

用于查看员工入职信息、PS 配置要求及实际领用资产，核对申请单、资产配置、出库日期、刷卡和领用信息，并导出结果。本篇描述所提供源码的当前行为，不以页面名称推定未实现的规则。

报表直接读取 `M0002_FCT_RECIPIENTS` 中满足条件的明细记录，不按员工或申请单合并。页面不重新计算员工资产是否超标，也不从当前资产卡片重新带出信息。数据表的一行对应哪一条领用明细，以及是否包含未领用员工，取决于上游生成规则，尚待确认。

## 2. 权限

| 项目 | 规则 |
| --- | --- |
| 页面访问、导出 | 当前页面提供查询、导出；具体角色及菜单授权待确认。 |
| 仓库可选范围 | 仅展示启用的一级仓库，且当前登录人工号对该仓库有查看权限。 |
| 员工可选范围 | 从人员表选择员工，支持多选；弹窗未按本公司、本部门或新员工身份限制。 |
| 公司、部门可选范围 | 公司从公司视图取值；HR 部门从组织表取值。本页面未加当前登录人的公司或部门范围过滤。 |
| 报表数据范围 | 查询服务未按当前登录人追加员工、公司或仓库限制。入口读取 `ASSET_RULE_USER` 字典，但读取结果未用于筛选或拦截；不能据此认为该字典已控制报表权限。公共访问层权限待确认。 |

## 3. 通用规则

1. 所有查询条件均可留空，没有预设入职、启用日期范围。不同条件同时满足，同一多选条件内匹配任一所选值。
2. 文本字段去除首尾空格后做包含匹配。日期按自然日比较，开始日、结束日均包含，单独填写开始或结束日期也可查询。
3. 默认按记录 ID 升序分页，不按入职时间或出库时间倒序。
4. 员工、资产及领用信息全部读取报表表中保存的字段；报表服务没有重新关联当前员工档案、资产卡片或领用单做实时计算。
5. 查询列表只读，无新增、编辑、删除、审批操作。序号按分页位置连续计算，不是工号、资产数量或申请单编号。
6. 当前查询没有额外“新员工”身份、已领用、已刷卡、流程完成状态过滤；这些范围是否已在上游生成表中限定，待确认。

## 4. 页面字段及交互

### 查询条件

| 字段 | 填写方式、可选值与交互 | 取值逻辑 |
| --- | --- | --- |
| 资产大类 | 弹窗多选，只读展示描述，可清空 | 取物料大类表中属性标记包含“1”的大类，按所选编码筛选 `MATERIALTYPECODE`。 |
| 资产小类 | 弹窗多选，回显“大类描述-小类描述” | 取小类及其所属大类；已选大类时只显示这些大类下的小类，未选大类时不加大类限制。筛选 `MATERIALCLASSCODE`。修改已选大类后保留仍属于新大类的小类，其余移除。 |
| 资产状态 | 弹窗多选，只读回显状态描述 | 从 `ASSET_STATUS` 字典中选择启用项，以所选状态编码筛选 `ASSETSTATUS`；列表展示另一字段 `ASSERTSTATUSNAME` 的名称。 |
| 资产标签号 | 文本输入，非必填 | 对 `TAGNUMBER` 做包含匹配，不是精确相等。 |
| 序列号 | 文本输入，非必填 | 对 `SERIALNUMBER` 做包含匹配。 |
| 配置 | 文本输入，非必填 | 对实际资产配置 `ASSETDESC` 做包含匹配；不筛选 PS 配置 `PSREMARK`，也不筛选列表的资产说明 `ITEMNAME`。 |
| 入职日期从 | 日期选择，非必填 | 当前实际筛选 `PURCHASEDATE` 的日期部分大于等于所选日；页面标题为入职日期，但列表入职日期取 `USERENABLEDATE`。这两个源字段不是同一个，是否为上游别名尚未确认。 |
| 入职日期至 | 日期选择，非必填 | 当前实际筛选 `PURCHASEDATE` 的日期部分小于等于所选日，包含结束日全天；与列表入职日期的字段差异同上。 |
| 成本中心 | 弹窗多选，回显“编码.名称” | 取 ERP 成本中心值集 `SOHU_GL_CC`；按所选编码筛选 `ERPCOSTCENTER`，不是对列表成本中心名称做包含匹配。 |
| 启用日期从 | 日期选择，非必填 | 筛选 `ENABLEDATE` 的日期部分大于等于所选日，指资产启用日期，不是员工入职日期。 |
| 启用日期至 | 日期选择，非必填 | 筛选 `ENABLEDATE` 的日期部分小于等于所选日，包含结束日全天。 |
| 公司 | 弹窗多选，回显“编码.名称” | 取 `mmp_company_v` 的公司资料，以所选公司编码筛选 `ERPCOMPANY`。 |
| 员工编号 | 人员弹窗多选，回显“工号-姓名” | 人员弹窗可按员工编号、姓名、部门查询，页面保存 `USER_ID`，实际筛选 `DRAWPERSONID`。报表列表也直接显示 `DRAWPERSONID`；它是否确实存员工工号、是否与所选人员内部 ID 一致，待确认。 |
| HR部门 | 弹窗多选，回显“部门编码.名称” | 组织表关联上级组织，展示部门编码、名称、上级部门名称；按所选组织编号筛选 `DEPTID`。没有自动包含下级部门的递归规则。 |
| 仓库 | 弹窗多选，回显“仓库编码.名称” | 按所选仓库编码筛选 `STORAGEID`。弹窗展示仓库编码、描述、公司，按仓库排序值及编码排序。可选范围见权限。 |

### 查询列表

列表包含序号及 30 个业务字段。以下业务字段均从同一报表记录取值，列表不二次查字典转换名称；因此保存了名称的字段使用表中名称，不保证等于当前基础资料名称。

| 字段 | 取值及显示规则 |
| --- | --- |
| 序号 | 根据页码、每页条数及本页行号生成，翻页连续；不导出。 |
| 申请单号 | 取 `SPPOPUTINNUM`，页面直接显示；导出时若值为单个“-”，转换为空白。普通文本，不提供单据跳转。 |
| 员工编号 | 直接取 `DRAWPERSONID`；不与工号实时拼接。该字段与人员选择保存的内部 ID 是否同口径，待确认。 |
| 员工姓名 | 直接取 `EMPLOYEENAME`；不按查询时人员资料刷新姓名。 |
| 入职日期 | 取 `USERENABLEDATE`，按 `yyyy-MM-dd` 显示；与查询条件实际筛选的 `PURCHASEDATE` 存在字段差异。 |
| PS配置 | 直接取 `PSREMARK`，表示报表保存的 PS 配置信息；不根据当前级别重新生成配置标准。 |
| 办公地点 | 直接取 `LOCATIONNAME`，与资产的 City、Building、Floor 分别展示，不互相代替。 |
| HR部门 | 拼接 `DEPTID`、英文句点及 `DEPTNAME`；显示“部门编码.部门名称”。未设置任一项为空时整列为空的规则，缺项可能只剩另一项或句点。 |
| 资产标签号 | 直接取 `TAGNUMBER`。 |
| 配置 | 直接取 `ASSETDESC`，为本条记录的实际配置；与 PS 配置独立展示，不比较是否符合。 |
| 品牌 | 直接取 `BRANDNAME`。 |
| 级别 | 直接取 `ASSETLEVELNAME`。当前取值名为资产级别名称，不能直接认定为员工职级。 |
| City | 直接取 `CITYNAME`。 |
| Building | 直接取 `BUIDINGNAME`。 |
| Floor | 直接取 `FLOORNAME`。 |
| 资产出库日期 | 取 `TRANSFERDATE`，按 `yyyy-MM-dd` 显示；报表不根据流程完成日期另算。 |
| 领用说明 | 直接取 `TRANSFERREASON`。 |
| 是否刷卡 | 直接取 `DRAWPERSONCARDID`；页面与导出都没有把卡号或空值转换为“是/否”。需确认上游存的是卡号、标记还是已加工后的文字。 |
| 是否领用 | 直接取 `TEXT01`；页面与导出不按出库日期、数量、单据状态推算，也没有“是/否”转换。具体值域与判断规则待确认。 |
| 序列号 | 直接取 `SERIALNUMBER`。 |
| 资产说明 | 直接取 `ITEMNAME`，与“配置”列的 `ASSETDESC` 是不同字段。 |
| 备注 | 直接取 `REMARK`。页面列设置最大显示长度 40，属于展示设置，不是输入长度校验；导出写入完整值。 |
| 数量 | 取 `PURCHASEQUANTITY`，页面使用无小数格式显示；不按员工领用记录数计数，也不合计同单数量。字段名为采购数量，是否就是本次实际领用数量需确认上游口径。 |
| 单位 | 直接取 `UOM`。 |
| 启用日期 | 取 `ENABLEDATE`，按 `yyyy-MM-dd` 显示。 |
| 原值 | 取 `PURCHASEPRICE`，页面与导出按千分位、两位小数显示；没有乘以数量，也不读取当前财务净值。字段名为采购价格，是否已存为卡片原值而非单价需确认。 |
| 资产状态 | 直接取 `ASSERTSTATUSNAME`，不是在页面把 `ASSETSTATUS` 编码转换为当前名称。 |
| 公司 | 拼接 `ERPCOMPANY`、英文句点、`ERPCOMPANYNAME`；取报表表中的名称。 |
| 板块 | 拼接 `ERPPLATE`、英文句点、`ERPPLATENAME`；取报表表中的名称。 |
| 成本中心 | 直接取 `ERPCOSECENTERNAME`；不额外拼接成本中心编码。 |
| 费用账户 | 直接取 `COSTACCOUNT`；不根据公司、板块、成本中心重建账户。 |

### 页面操作

| 操作 | 交互与结果 |
| --- | --- |
| 查询 | 点击查询或按回车提交当前条件，刷新分页结果和总记录数。 |
| 清空单项 | 同时清除选中编码及展示名称，隐藏清空图标；不自动查询。大类的单项清空仅清除大类值，未统一清除小类。 |
| 清空全部 | 双击查询区域，确认后清除全部查询条件与展示值，隐藏清空图标；不自动查询。 |
| 翻页 | 按当前条件读取对应页，保留条件。 |
| 导出新员工领用报表 | 确认后导出当前表单条件对应的全部匹配明细，不局限当前页；条件修改后尚未查询也会按修改后的条件导出。取消则不导出。 |

## 5. 校验

| 项目 | 当前规则 |
| --- | --- |
| 必填 | 查询服务未要求任何查询条件必填。 |
| 日期顺序 | 日期选择器约束开始不晚于结束、结束不早于开始；服务未见独立的日期顺序检查。 |
| 大小类关联 | 选择小类时按已选大类限制可选范围；更新大类后清除不属于新选大类的小类。清空大类图标不触发同一关联清理，现状保留原小类条件。 |
| 人员、部门、公司 | 选择字段只读，通过弹窗选择，以编码或 ID 精确匹配；展示名称不参与包含匹配。 |
| 空值 | 原始字段为空通常显示空白；编码加名称字段为直接拼接，不自动补齐缺失名称。 |
| 金额 | 原值显示两位小数，导出将原始金额转为数值后格式化；不是页面可编辑金额，不新增金额输入校验。 |
