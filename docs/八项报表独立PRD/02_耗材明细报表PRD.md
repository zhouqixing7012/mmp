# 耗材明细报表PRD

## 1. 背景

用于查看低值耐用品和普通耗材的领用明细，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。

## 2. 权限

| 角色 / 条件 | 可查看的数据范围 | 可执行操作 | 无权限结果 |
| --- | --- | --- | --- |
| 具备相应台账及资产卡片查看权限的用户 | 使用已有台账及资产卡片查看权限；集团、上海媒体分公司、广州媒体分公司各自查看所属台账数据。查询与导出范围相同，不另设报表角色权限。 | 查询、分页、导出有权查看的记录。 | 无权查看的台账或卡片数据不展示、不导出。 |

## 3. 通用规则

人员、公司、部门及其他基础资料按本页字段规定的角色和范围选择；选择与回填执行第4章公共交互约定。基础资料选择不改变本报表的数据权限及历史取值时点。

| 规则 | 业务要求 |
| --- | --- |
| 来源与明细粒度 | 耗材配给单，关联对应耗材申请单、耗材统一汇总申请单及耗材领用单。低值耐用品每行对应耗材卡片的耗材标签号；普通耗材每行对应耗材领用单中的一项物料，不要求生成标签号。 |
| 数据范围 | 仅包括物资总类为低值耐用品、耗材的记录。 |
| 默认排序 | 耗材大类编码升序，再按耗材小类编码升序。 |
| 数据读取 | 每次查询读取最新的业务数据，展示当前有权查看的匹配结果。 |
| 查询匹配 | 所有条件非必填，默认空。不同条件同时满足，同一多选内命中任一值；文本条件去除首尾空格后包含匹配。 |
| 操作范围 | 报表只读，不提供新增、编辑、删除、审批或打印。 |

## 4. 页面字段及交互

本章查询、选择、分页、导出与异常处理执行[报表公共查询交互规则](00_报表公共查询交互规则.md)；下表保留本页字段、单多选、匹配方式及专属业务规则。编码、单号及标签按文本保留原值和前导零。

本页提供查询、结果列表、分页和导出，不设置详情入口。所有查询条件非必填；结果只读。申请人、耗材责任人及各自公司、板块、部门分别按对应业务角色取值，不合并为同一归属。

### 页面操作

| 操作 | 可用条件 | 交互与结果 |
| --- | --- | --- |
| 查询 | 具备本报表查看权限，查询条件通过校验 | 点击查询或在文本框按回车，读取最新数据并回到第一页；加载期间不可重复查询。失败时保留条件，按公共规则提示并允许重试。 |
| 重置 | 查询页可用 | 二次确认后仅清空输入条件，不自动改变现有列表、分页或排序；取消时保留条件。重置后点击查询或按回车再更新结果。 |
| 导出 | 具备对应记录查看权限，导出条件通过校验 | 导出当前条件下全部有权查看的结果，不限当前页，不受勾选记录限制；按本页字段顺序和列表排序，不含页面序号。失败提示“导出失败，请重试”，保留条件，可重新导出。 |

列表只读，无匹配记录显示“暂无数据”；单号为文本，不提供审批或编辑入口。分页显示明细总行数，翻页和修改每页条数时保留筛选条件。选择控件的候选、查询、回填、移除、确认、取消及失败行为见公共交互规则。

## 5. 校验

| 校验项 | 触发时机 | 判断及处理 | 提示与修正 |
| --- | --- | --- | --- |
| 权限 | 进入、查询、导出 | 按已有台账及资产卡片查看权限筛选；查询与导出范围相同，不另设报表角色权限。 | 无权限数据不展示、不导出；没有有权查看的匹配记录时显示“暂无数据”。 |
| 基础资料选择 | 查询、导出 | 按已选编码或工号筛选；多选不转换为单个文本；失效选项不得作为正常候选。 | 所选资料失效时提示“所选资料已失效，请重新选择”。 |
| 只读字段 | 列表展示 | 报表不修改来源业务记录；是否领用、是否占用按关联领用单状态判定；其他缺失取值不得自行补0、补“否”或猜测来源。 | 缺失值显示为空白；来源资料缺失时保持空白，不改用其他业务对象的值。 |

## 6. 后续操作 / 业务结果 / 补充说明

导出生成“耗材明细报表-YYYYMMDD.xlsx”。列表和导出使用相同字段含义、权限、筛选条件及排序。空值保持空白，金额保留两位小数，编码按文本保存。查询和导出不改变资产、单据状态，不生成事务、审批或通知。
