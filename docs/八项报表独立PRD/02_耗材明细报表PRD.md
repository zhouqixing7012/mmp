# 耗材明细报表PRD

## 1. 背景

用于查看低值耐用品和普通耗材的领用明细，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。

## 2. 权限

| 角色 / 条件 | 可查看的数据范围 | 可执行操作 | 无权限结果 |
| --- | --- | --- | --- |
| 具备相应台账及资产卡片查看权限的用户 | 使用已有台账及资产卡片查看权限；集团、上海媒体分公司、广州媒体分公司各自查看所属台账数据。查询与导出范围相同，不另设报表角色权限。 | 查询、分页、导出有权查看的记录。 | 无权查看的台账或卡片数据不展示、不导出。 |

## 3. 通用规则

同一业务字段共用已有选择组件和基础资料：成本中心按编码选择，人员按工号选择，板块、用途及新增类型使用共享下拉字典。支持搜索、清空及本页规定的单选或多选；不同名称的人员角色不另建人员来源。候选按原权限与业务范围限制，选择组件复用不改变历史快照或结果权限。

| 规则 | 业务要求 |
| --- | --- |
| 来源与明细粒度 | 耗材配给单，关联对应耗材申请单、耗材统一汇总申请单及耗材领用单。低值耐用品每行对应耗材卡片的耗材标签号；普通耗材每行对应耗材领用单中的一项物料，不要求生成标签号。 |
| 数据范围 | 仅包括物资总类为低值耐用品、耗材的记录。 |
| 默认排序 | 耗材大类编码升序，再按耗材小类编码升序。 |
| 数据读取 | 每次查询读取最新的业务数据，展示当前有权查看的匹配结果。 |
| 查询匹配 | 所有条件非必填，默认空。不同条件同时满足，同一多选内命中任一值；日期可填写单端并包含所选自然日。文本条件去除首尾空格后包含匹配。 |
| 操作范围 | 报表只读，不提供新增、编辑、删除、审批或打印。 |

## 4. 页面字段及交互

本页提供查询、结果列表、分页和导出，不设置详情入口。所有查询条件非必填；结果只读。申请人、耗材责任人及各自公司、板块、部门分别按对应业务角色取值，不合并为同一归属。

### 页面操作

| 操作 / 组件 | 是否可编辑 / 必填 | 交互与结果 |
| --- | --- | --- |
| 查询条件 | 可编辑，全部非必填 | 首次进入条件为空；未填项不限制结果。不同条件同时满足，多选项命中任一即可；单项可清空。 |
| 选择弹窗 | 只能选择，非必填 | 复用对应基础资料选择组件，可按编码或名称搜索；人员可按工号或姓名搜索。回填名称并保留编码或工号，可移除已选项。无候选时显示“暂无数据”；加载失败提示失败并允许重试。 |
| 查询 | 不适用 | 点击查询或按回车，每次读取最新数据，按当前条件更新结果与条数并回到第一页；加载期间不可重复查询。失败提示“查询失败，请重试”，不得显示为无数据。 |
| 重置 | 不适用 | 二次确认后清空输入条件；现有列表、分页和排序不自动改变。取消确认保留条件；重置后点击查询或按回车才按新条件更新结果。 |
| 分页 | 不适用 | 显示总记录数，翻页和修改每页条数时保留筛选条件；统计的是报表明细行数。 |
| 结果列表 | 只读，非必填 | 按逐字段规则展示，空结果显示“暂无数据”；单号为文本，列表不发起审批或编辑。 |
| 导出 | 不适用 | 导出当前条件下全部有权查看的结果，不限当前页，不受勾选记录限制；使用本页业务字段顺序和列表排序，不含显示序号。导出失败提示“导出失败，请重试”。 |

## 5. 校验

| 校验项 | 触发时机 | 判断及处理 | 提示与修正 |
| --- | --- | --- | --- |
| 权限 | 进入、查询、导出 | 按已有台账及资产卡片查看权限筛选；查询与导出范围相同，不另设报表角色权限。 | 无权限数据不展示、不导出；没有有权查看的匹配记录时显示“暂无数据”。 |
| 基础资料选择 | 查询、导出 | 按已选编码或工号筛选；多选不转换为单个文本；失效选项不得作为正常候选。 | 所选资料失效时提示“所选资料已失效，请重新选择”。 |
| 只读字段 | 列表展示 | 报表不修改来源业务记录；是否领用、是否占用按关联领用单状态判定；其他缺失取值不得自行补0、补“否”或猜测来源。 | 缺失值显示为空白；尚未定义的取值集中列于第6章。 |

## 6. 后续操作 / 业务结果 / 补充说明

导出生成“耗材明细报表-YYYYMMDD.xlsx”。列表和导出使用相同字段含义、权限、筛选条件及排序。空值保持空白，金额保留两位小数，编码按文本保存。查询和导出不改变资产、单据状态，不生成事务、审批或通知。
