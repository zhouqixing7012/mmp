# 资产事务报表 PRD

## 1. 背景

用于查询资产发生的事务明细，核对事务时间、关联单据、资产信息、仓库、责任人及部门变化，并导出结果。本篇按照所提供源码描述当前页面和取值逻辑，不新增业务规则。

报表直接读取资产事务报表数据表 `M0002_FCT_ASSETS_TRANSACTION`。页面不实时关联资产卡片重新计算资产信息，不按单据汇总。结果为该表满足条件的记录；同一资产发生多次事务，可展示多条记录。上游写入粒度、数据刷新频率尚未确认。

## 2. 权限

| 项目 | 规则 |
| --- | --- |
| 页面访问、导出 | 当前页面具有查询、导出入口；具体允许访问的角色及菜单授权未在本报表源码中定义，待确认。 |
| 仓库可选范围 | 源仓库、目标仓库仅可选择启用的一级仓库，且当前登录人工号在该仓库具有查看权限。 |
| 公司、创建人可选范围 | 公司取公司视图全部可选记录；创建人取人员表，不额外限制为当前登录人或本公司人员。 |

## 3. 通用规则

1. 查询条件均可留空；不同条件之间同时满足，同一多选条件内满足任一已选值。
2. 当通过带初始化标记的入口进入时，事务处理日期默认从当前日期向前一个月，到当前日期。不是固定最近 30 天。普通查询不自动重新设置日期。
3. 文本条件去除首尾空格后进行包含匹配；不是精确相等。输入中的 SQL 通配字符是否应作为普通字符处理，现有实现未定义。
4. 日期按自然日比较，开始、结束当天均包含；只填一端时只限制该端。无日期条件时不限制事务日期。
5. 默认按记录 ID 升序分页。序号按“前面各页记录数＋本页行号”生成，翻页连续，不是资产编号或事务编号。
6. 查询结果仅用于查看和导出，无新增、修改、审批、删除操作。
7. 报表记录保存的编码会按查询时的字典、公司、板块、人员、仓库名称转换；这些名称可能随基础资料变化，不能把所有展示名称都理解为事务发生时的名称。

## 4. 页面字段及交互

### 查询条件

| 字段 | 填写方式、可选值与交互 | 取值逻辑 |
| --- | --- | --- |
| 单据编号 | 文本输入，非必填 | 对报表记录中的事务单据编号 `TRANSACTIONORDER_NO` 做包含匹配；不是申请单号。 |
| 单据类型 | 弹窗多选，只读回显名称，可清空 | 取 `TRANSACTION_ORDER_TYPE` 字典的编码、名称；按所选编码筛选 `TRANSACTIONORDERTYPE_CODE`。弹窗未单独加启用标记限制。 |
| 事务类型 | 弹窗多选，只读回显名称，可清空 | 取 `TransactionType` 字典；按所选编码筛选 `TRANSACTIONTYPE_CODE`。单据类型和事务类型独立筛选，不互相带出。 |
| 物资说明 | 文本输入，非必填 | 对 `ASSET_DESC` 做包含匹配；对应列表的“资产说明”。 |
| 板块 | 弹窗多选，回显“编码.名称” | 取 ERP 板块值集 `SOHU_GL_BU`，可选编码限定为 11、12、13、14、15、16、17、51、52、53、54、56；筛选 `ASSETPLATE_CODE`，不是财务核算板块。 |
| 资产标签号 | 文本输入，非必填 | 对事务记录保存的 `ASSETTAG_NO` 做包含匹配。 |
| 公司 | 弹窗多选，回显“编码.名称” | 取 `mmp_company_v` 的公司编码、名称；筛选事务记录中的 `COMPANY_CODE`。公司为空时不限制公司。 |
| 事务处理日期从 | 日期选择，非必填 | 筛选 `TRANSACTION_DATE` 的日期部分大于等于所选日期；日期选择器不允许选晚于结束日期的日期。 |
| 事务处理日期至 | 日期选择，非必填 | 筛选 `TRANSACTION_DATE` 的日期部分小于等于所选日期；包括结束日全天。日期选择器不允许选早于开始日期的日期。 |
| 资产状态 | 弹窗多选，只读回显名称 | 取 `ASSET_STATUS` 字典中启用项；筛选事务表保存的 `ASSETSTATUS_CODE`，不是当前资产卡片状态。 |
| 源仓库 | 弹窗多选，回显“编码.名称” | 按所选仓库编码筛选 `SOURCESTORAGE_CODE`。弹窗展示仓库编码、描述、公司，按仓库排序值及编码排序。可选范围见权限。 |
| 目标仓库 | 弹窗多选，回显“编码.名称” | 按所选仓库编码筛选 `TARGETSTORAGE_CODE`；范围和选择方式与源仓库一致。两个仓库条件独立，不互相限制。 |
| 创建人 | 人员弹窗多选，回显“工号-姓名” | 人员弹窗展示工号、姓名、部门；保存人员内部 ID，筛选 `CREATEUSER_ID`。查的是事务创建人，不是资产责任人。 |

### 查询列表

以下字段全部只读。除序号、显示格式和编码转名称外，不在页面做金额、数量或责任人重算。

| 字段 | 取值及显示规则 |
| --- | --- |
| 序号 | 根据当前页、每页条数和本页行号计算；不导出。 |
| 事务处理日期 | 取 `TRANSACTION_DATE`，页面按 `yyyy-MM-dd HH:mm:ss` 显示，保留秒。 |
| 单据编号 | 取 `TRANSACTIONORDER_NO`，显示事务关联单据编号；普通文本，不提供跳转。 |
| 单据类型 | 取 `TRANSACTIONORDERTYPE_CODE`，按查询时单据类型字典转名称。 |
| 事务类型 | 取 `TRANSACTIONTYPE_CODE`，按查询时事务类型字典转名称。 |
| 申请单号 | 取 `SP_PO_REC_NUM`；与单据编号分别展示，不互相替代。具体对应哪类源申请单由上游写入决定。 |
| 公司 | 取 `COMPANY_CODE`，按当前公司资料拼接“编码.名称”；编码为空或当前公司映射不存在时显示空白。 |
| 财务核算板块 | 直接取事务记录中的 `FINANCEPLATE`；不再按板块字典转换，不从费用账户重新截取。 |
| 资产所属板块 | 取 `ASSETPLATE_CODE`，按当前板块资料拼接“编码.名称”；编码为空或映射不存在时显示空白。 |
| 业务线 | 直接取 `BIZLINE_NAME`；不是根据当前板块重新推算。 |
| 资产标签号 | 直接取 `ASSETTAG_NO`。 |
| 印刷号 | 直接取 `ASSETPRINT_NO`。 |
| SN号 | 直接取 `ASSETSERIAL_NO`。 |
| 资产说明 | 直接取 `ASSET_DESC`。 |
| 资产大类 | 直接取 `ASSET_BIGTYPE`，页面不再转换分类名称。 |
| 资产小类 | 直接取 `ASSET_SMALLTYPE`，与大类分列展示。 |
| 资产用途 | 直接取 `ASSET_USEDTYPE`，不在报表服务中另查用途字典。 |
| 资产状态 | 取 `ASSETSTATUS_CODE`，按查询时资产状态字典转名称。筛选用编码，展示用名称。 |
| 单位 | 直接取 `UNIT`。 |
| 数量 | 取本条事务记录的 `AMOUNT`，页面使用千分位、无小数格式显示；不等同于当前卡片数量，也不是按同单资产合计。 |
| 源仓库 | 取 `SOURCESTORAGE_CODE`，按查询时仓库资料转仓库名称。 |
| 目标仓库 | 取 `TARGETSTORAGE_CODE`，按查询时仓库资料转仓库名称。 |
| 创建人 | 取 `CREATEUSER_ID`，按查询时人员 ID 映射转人员展示值；不是直接读取事务中的姓名。姓名是否附工号由公共人员映射决定，待确认。 |
| 原资产责任人 | 直接取 `OLDASSETUSER_NAME`，不按现有人员信息重新查姓名。 |
| 原资产责任人部门 | 直接取 `OLDASSETUSER_DEPT`。 |
| 现资产责任人 | 直接取事务记录中的 `ASSETUSER_NAME`。“现”指该条记录保存的责任人，报表不重新查当前资产卡片的责任人。 |
| 现资产责任人部门 | 直接取事务记录中的 `ASSETUSER_DEPT`，不是当前人员组织的实时部门。 |
| 成本中心 | 直接取 `COSTCENTER`，不在报表服务中另查当前成本中心。 |
| City | 直接取 `CITY`。 |
| Building | 直接取 `BUILDING`。 |
| Floor | 直接取 `FLOOR`。 |
| 启用日期 | 取事务记录中的 `ENABLEDATE`；页面按 `yyyy-MM-dd` 显示。 |
| 使用说明 | 直接取 `DESCRIPTION`。 |
| 业务原因 | 直接取 `BUSIREASION`；不根据事务类型自动生成说明。 |
| 备注 | 直接取 `REMARK`。 |

### 页面操作

| 操作 | 交互与结果 |
| --- | --- |
| 查询 | 点击查询或按回车，将当前条件提交，重新读取分页结果及总记录数。 |
| 清空单项 | 点击选择字段旁的清空图标，同时清除编码与展示名称；不自动查询。 |
| 清空全部 | 双击查询区域，确认后清除所有查询输入及已选值，隐藏清空图标；不自动查询。 |
| 翻页 | 按当前查询条件读取对应页，保留条件。 |
| 导出资产事务报表 | 确认后按当前表单条件导出全部匹配记录，不只导出当前页；修改条件后即使尚未点击查询，导出也以当前表单值为准。取消确认则不导出。 |

## 5. 校验

| 项目 | 当前规则 |
| --- | --- |
| 必填 | 报表服务没有要求公司、仓库、创建人等条件必须填写。页面部分输入带通用样式标记，不能据此视为业务必填。 |
| 日期顺序 | 页面日期选择器约束开始日期不晚于结束日期；未见报表服务另做日期倒置校验。 |
| 选择值 | 选择字段只读，通过弹窗选择或清空；筛选使用编码或人员 ID，展示名称不参与匹配。 |
| 多选逻辑 | 仓库多选编码由页面组织成可用于多个仓库匹配的值，其余多选按逗号分隔后逐项匹配。 |
| 空值 | 原始字段为空时页面显示空白；转换字段未找到对应名称时不保证保留原编码。公司、板块明确显示空白，不擅自补名称。 |
