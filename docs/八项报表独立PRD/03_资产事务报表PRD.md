# 资产事务报表PRD

## 1. 背景

用于追溯已处理资产事务及变更前后信息，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。

## 2. 权限

| 角色 / 条件 | 可查看的数据范围 | 可执行操作 | 无权限结果 |
| --- | --- | --- | --- |
| 具有本报表查看权限的用户 | 按当前登录人的资产卡片查看权限过滤；集团、上海媒体分公司、广州媒体分公司各自查看所属台账数据。 | 查询、分页、导出有权查看的记录。 | 无报表查看权限不允许进入；无卡片权限的数据不展示、不导出。 |

## 3. 通用规则

| 规则 | 业务要求 |
| --- | --- |
| 来源与明细粒度 | 资产变更单，关联对应资产变更申请单和申请单；每行对应资产变更单中的一个资产标签号。 |
| 数据范围 | 仅包括单据状态为“已处理”、资产总类为资产的记录。 |
| 默认排序 | 事务处理日期（单据审核日期）倒序，最新记录在最上方。 |
| 历史取值 | 以变更完成时点的字段及名称形成历史记录，后续资产、人员或基础资料变化不更新该记录。 |
| 查询匹配 | 所有条件非必填，默认空。不同条件同时满足，同一多选内命中任一值；日期可填写单端并包含所选自然日。文本条件去除首尾空格后包含匹配。 |
| 操作范围 | 报表只读，不提供新增、编辑、删除、审批或打印。 |

### 页面操作

| 操作 / 组件 | 是否可编辑 / 必填 | 交互与结果 |
| --- | --- | --- |
| 查询条件 | 可编辑，全部非必填 | 首次进入条件为空；未填项不限制结果。不同条件同时满足，多选项命中任一即可；单项可清空。 |
| 选择弹窗 | 只能选择，非必填 | 复用对应基础资料选择组件，可按编码或名称搜索；人员可按工号或姓名搜索。回填名称并保留编码或工号，可移除已选项。无候选时显示“暂无数据”；加载失败提示失败并允许重试。 |
| 查询 | 不适用 | 点击查询或按回车，按当前条件更新结果与条数并回到第一页；加载期间不可重复查询。失败提示“查询失败，请重试”，不得显示为无数据。 |
| 清除 | 不适用 | 二次确认后清空输入条件；现有列表、分页和排序不自动改变。取消确认保留条件；清除后点击查询或按回车才按新条件更新结果。 |
| 分页 | 不适用 | 显示总记录数，翻页和修改每页条数时保留筛选条件；统计的是报表明细行数。 |
| 结果列表 | 只读，非必填 | 按逐字段规则展示，空结果显示“暂无数据”；单号为文本，列表不发起审批或编辑。 |
| 导出 | 不适用 | 导出当前条件下全部有权查看的结果，不限当前页；使用本页业务字段顺序和默认排序，不含显示序号。导出失败提示“导出失败，请重试”。 |

## 5. 校验

| 校验项 | 触发时机 | 判断及处理 | 提示与修正 |
| --- | --- | --- | --- |
| 日期起止 | 选择日期、查询、导出 | 同一日期的开始不得晚于结束，允许只填写一端；不满足时阻止查询或导出。 | “开始日期不能晚于结束日期”；修改起止日期。 |
| 权限 | 进入、查询、导出 | 无报表查看权限阻止进入；结果与导出均限定在当前用户有权查看的台账及卡片范围。 | “无权查看该报表”；无权限数据不展示、不导出。 |
| 基础资料选择 | 查询、导出 | 按已选编码或工号筛选；多选不转换为单个文本；失效选项不得作为正常候选。 | 所选资料失效时提示“所选资料已失效，请重新选择”。 |
| 只读字段 | 列表展示 | 报表不修改来源业务记录；缺失取值不得自行补0、补“否”或重新猜测来源。 | 缺失值显示为空白；尚未定义的取值集中列于第6章。 |

## 6. 后续操作 / 业务结果 / 补充说明

导出生成“资产事务报表-YYYYMMDD.xlsx”。列表和导出使用相同字段含义、权限、筛选条件及排序。空值保持空白，金额保留两位小数，编码按文本保存。查询和导出不改变资产、单据状态，不生成事务、审批或通知。
