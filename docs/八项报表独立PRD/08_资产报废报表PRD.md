# 资产报废报表 PRD

## 1. 背景

用于查看已报废资产的卡片信息、数量、财务价值和报废结果，并导出 Excel。页面取资产卡片记录，不是报废申请单明细，也不是按每次报废事务生成的历史流水。

## 2. 权限

| 项目 | 规则 |
|---|---|
| 查询公司范围 | 未配置在 ASSET_RULE_USER 的登录人：所属公司编码为 115 的只看 115；为 116 的只看 116；其他登录人排除 115、116。已配置用户不追加这项限制。 |
| 导出公司范围 | 115、116 登录人仍限定各自公司；其他未配置用户允许“公司不属于 115、116，或资产所属板块为 16”的记录。与列表范围不同，不能保证导出只包含列表可见的数据。 |
| 仓库选择范围 | 已启用、层级为 1、当前登录人在仓库控制表中拥有查看权限的仓库。 |
| 页面访问角色 | 当前页面和调用代码未提供可访问岗位，不能推定仅财务或 ES 可查看。 |

## 3. 通用规则

| 项目 | 规则 |
|---|---|
| 数据范围 | 排除删除标记为 Y 的资产；资产状态编码为 13 或 14，且报废日期 UNABLE_DATE 不为空。状态名称通过 ASSET_STATUS 字典转换，不将编码自行解释成业务名称。 |
| 一行数据 | 按当前资产卡片关联当前资产价值表和资产扩展表；未按报废单号、报废批次或事务分行。若同一资产在关联表中匹配多行，当前连接不保证一张卡片仅返回一行。 |
| 条件组合 | 所有已填写条件同时满足；空条件不追加筛选。 |
| 当前与历史 | 公司、责任人工号、位置、数量、原值等从当前卡片读取；净值从当前价值表读取；报废日期、数量、类型、原因从卡片保存的报废字段读取。责任人姓名及类别名称按当前人员、基础资料转换。不可理解为报废完成时的完整快照。 |
| 日期金额 | 日期 yyyy-MM-dd；数量、折旧月数、报废数量显示整数；原值、净值、报废原值、报废净值显示千分位两位小数。 |
| 默认顺序 | 按资产类型、公司、板块、资产编号排序；不是默认按报废日期倒序。 |

## 4. 页面字段及交互

### 4.1 查询条件

常用条件直接展示；City 至 PO 单号放在“更多”区域，默认收起。选择型字段显示名称、提交编码，可清空。源码未提供查询必填校验，不能依据 required 样式认定业务必填。

| 查询条件 | 输入方式与选项来源 | 实际筛选规则 |
|---|---|---|
| 资产种类 | 单选下拉；资产种类表，编码限定 1、2 | 卡片资产种类等于所选编码；空选不追加条件。 |
| 资产类别 | 类别树弹窗，保存选中的第二级类别编码，支持多个 | 卡片 ASSET_TYPE 属于选中编码集合；完整类别树数据源未提供。 |
| HR 部门 | 多选弹窗；部门表显示部门编码、名称和上级部门 | 先找到所选部门及下属部门，再查当前人员表中属于这些部门的人员，最后匹配卡片责任人工号。不是直接按卡片保存的 HR 部门字段过滤。 |
| 资产标签号 | 文本 | 卡片标签号以输入内容开头，去前后空格。 |
| 序列号 | 文本 | 卡片序列号以输入内容开头；列表本身没有序列号列。 |
| 资产说明 | 文本 | 卡片 ASSET_NAME 包含输入内容。 |
| 采购日期从、至 | 两个日期框，前后相互限制 | 卡片 PURCHASE_DATE 从日起零点及以后、至日下一日零点之前，包含起止日全天。 |
| 成本中心 | 多选弹窗；ERP 值集 SOHU_GL_CC | 卡片成本中心属于所选编码集合。 |
| 启用日期从、至 | 两个日期框，前后相互限制 | 卡片 ENABLE_DATE；包含起止日全天。 |
| 公司 | 多选弹窗；公司视图 mmp_company_v | 卡片公司编码属于所选集合，并叠加数据权限。 |
| 报废日期从、至 | 两个日期框，前后相互限制 | 卡片 UNABLE_DATE；包含起止日全天，不匹配 RETIRED_DATE。 |
| 资产所属板块 | 弹窗选择，复用 assets.js 的 editPlate | 卡片 PLATE 属于所选编码集合；不匹配费用账户第二段财务核算板块。公共脚本未提供，弹窗完整选项来源、是否多选尚未确认。 |
| 员工编号 | 人员弹窗，人员表关联人员扩展及 PS 部门信息 | 卡片责任人工号属于选中工号集合；字段展示人员姓名，不是自由填写姓名匹配。 |
| 仓库 | 多选仓库弹窗；已启用一级仓库及查看权限 | 卡片 STORAGE_NUMBER 属于所选编码集合。 |
| City | 单选弹窗；地点表 city 类型 | 卡片 City 编码匹配所选编码。 |
| Building | 地点弹窗，按当前 City 查询 building | 卡片 Building 编码匹配所选编码。 |
| Floor | 单选下拉；地点表全部 floor 类型，按名称中数字排序 | 卡片 Floor 编码匹配所选编码；下拉没有按 Building 限制。 |
| 配置 | 文本 | 卡片 REQUIREMENTS 包含输入内容；列表没有配置列。 |
| 备注 | 文本 | 卡片 REMARK 包含输入内容。 |
| 品牌 | 文本 | 卡片 BRAND 原始保存值包含输入内容；现有列表未额外转品牌名称，不能认定按品牌基础资料名称查询。 |
| 原值 | 金额文本，修改时格式化 | 去千分位逗号后，精确匹配卡片 ASSET_COST，支持按文本 0 查询。 |
| 净值 | 金额文本，修改时格式化 | 去千分位逗号后，精确匹配当前价值表 ASSET_NBV。 |
| 折旧月数 | 数字文本 | 精确匹配卡片 DEPRECIATION_MONTHS。 |
| 费用账户 | 文本 | 卡片 COST_ACCOUNT 包含输入内容。 |
| 业务线 | 单选弹窗；ERP 值集 SOHU_GL_BL | 卡片 BUSINESS_LINE 属于提交编码集合，单选实际是一个编码。 |
| 资产用途 | 单选下拉；ASSETS_USE 字典 | 卡片 ASSET_USED_TYPE 等于选中编码。 |
| 级别 | 单选下拉；ASSET_LEVEL 字典 | 卡片 ASSET_LEVEL 等于选中编码；页面回显绑定结果对象 VO 而非查询表单，选择后的回显需核验。 |
| 主资产标签号 | 文本 | 卡片 PARENT_ASSET_NUMBER 包含输入内容，或卡片自身 TAG_NUMBER 以输入内容开头；两种情况任一满足即可。 |
| NO 位置 | 文本 | 卡片 NO_LOCATION 包含输入内容。 |
| PR 单编号 | 文本 | 卡片 PR_NUMBER 包含输入内容。 |
| PO 单号 | 文本 | 卡片 PO_NUMBER 包含输入内容。 |

### 4.2 列表字段

| 字段 | 取值逻辑 |
|---|---|
| 序号 | （当前页－1）×每页条数＋本页行号。 |
| 仓库 | 卡片 STORAGE_NUMBER，查询仓库映射取得显示名称；名称为“-”时显示空。 |
| 资产大类 | 卡片 ASSET_CATE_SEG1，转换当前类别名称。 |
| 资产小类 | 卡片 ASSET_CATE_SEG2，转换当前类别名称。 |
| 资产标签号 | 卡片 TAG_NUMBER。 |
| 品牌 | 卡片 BRAND 原值；现有查询服务未进行品牌名称转换。 |
| 资产说明 | 卡片 ASSET_NAME。 |
| 数量 | 卡片 QUANTITY，当前卡片数量；不是报废数量，也不汇总报废单明细。 |
| 单位 | 卡片 UOM 原值。 |
| 采购日期 | 卡片 PURCHASE_DATE。 |
| 启用日期 | 卡片 ENABLE_DATE。 |
| 原值 | 卡片 ASSET_COST，不取价值表 EBS 原值，也不乘数量。 |
| 净值 | 当前资产价值表 ASSET_NBV，以资产 ID 关联；不取卡片净值。 |
| 折旧月数 | 卡片 DEPRECIATION_MONTHS。 |
| 资产用途 | 卡片 ASSET_USED_TYPE，转换 ASSETS_USE 字典名称。 |
| 资产状态 | 卡片 ASSET_STATUS，转换 ASSET_STATUS 字典名称。 |
| 资产标记 | 根据卡片 ASSETS_EXT_ID 关联资产扩展表，取 ASSETS_MARK，转换 ASSETS_MARK 字典名称。 |
| 责任人编号 | 卡片 USED_PERSON_CODE。 |
| 责任人姓名 | 按卡片责任人工号取得当前人员姓名，覆盖卡片保存姓名；不是报废时姓名。 |
| 成本中心 | 卡片 ORGANIZATION，显示“编码.当前名称”；只有“.”时隐藏。 |
| 公司 | 卡片 REGION_ID_COMPANY，显示“编码.当前公司名称”；只有“.”时隐藏。 |
| 财务核算板块 | 从卡片 COST_ACCOUNT 的第一个点与第二个点之间取板块编码，转换板块名称，显示“编码.名称”；只有“.”时隐藏。 |
| 资产所属板块 | 卡片 PLATE，显示“编码.当前板块名称”；与财务核算板块来源不同。 |
| City | 卡片 CITY 转地点名称，另取该城市的城市编码映射，显示“城市编码.城市名称”。 |
| Building | 卡片 BUILDING 转地点名称。 |
| Floor | 卡片 FLOOR 转地点名称。 |
| 主资产标签号 | 卡片 PARENT_ASSET_NUMBER。 |
| 印刷号 | 卡片 PRINTED_NUMBER。 |
| 报废数量 | 卡片 UNITS_RETIRED；为空时直接使用卡片 QUANTITY。不按报废申请单求和，不通过数量差额计算。 |
| 报废原值 | 页面读取 retiredAssetCost，导出读取同一字段；现有 SQL 未返回该字段，服务未填充，DTO 仅有普通 getter，没有计算公式。当前链路未填充，不能写成原值按数量比例计算。 |
| 报废净值 | 页面读取 retiredAssetNbv，导出读取同一字段；现有 SQL 未返回，服务未填充，DTO 无计算。当前链路未填充，不能写成净值按数量比例计算。 |
| 报废类型 | 卡片 RETIRED_TYPE，转换 RETIRED_STATE 字典名称。 |
| 报废原因 | 卡片 RETIRED_REASON 原值。 |
| 报废日期 | 卡片 UNABLE_DATE，非 RETIRED_DATE。 |
| 处置类型 | 卡片 RETIRED_HANDLE_TYPE 原值，现有服务没有字典转换；不取 HANDLE_TYPE。 |

### 4.3 操作

| 操作 | 交互与结果 |
|---|---|
| 查询 | 点击查询或按回车提交条件，返回分页列表。 |
| 清除 | 双击查询区域，确认清空所有查询条件；选择字段也可单独点清除图标。 |
| 列头排序 | 多数列提供排序入口；报废原值和报废净值没有。部分入口仍使用旧表别名，见补充说明。 |
| 导出资产报废报表 | 确认导出列表所有数据后，按表单条件重新查询全部结果；后台不限制本页。文件名为“资产报废报表-yyyyMMdd.xlsx”。 |

## 5. 校验

| 校验项 | 规则 |
|---|---|
| 日期先后 | 日期选择器约束从日不晚于至日；后台包含起止日全天。 |
| 报废范围 | 后台始终要求状态为 13 或 14 且 UNABLE_DATE 非空；未报废资产不能因其他条件匹配而进入结果。 |
| 数量与金额 | 报表只读，未见数量上限或金额分摊校验；不会为缺失报废价值自动计算。 |

## 6. 后续操作 / 业务结果 / 补充说明

查询和导出不产生报废单，不修改卡片，也不触发处置。

| 项目 | 现状与需要明确的口径 |
|---|---|
| 导出字段 | 导出所有列表业务字段，但不含序号、印刷号；仓库标题改为“库房”；末尾新增“备注”，取卡片 REMARK。 |
| 导出显示 | 日期同列表；金额千分位两位小数；数量和报废数量通过取整数输出为文本。列表整数显示与导出取整数在非整数数据下可能不同，不能扩展为允许小数。 |
| 导出地点及板块显示 | City只导出城市名称，不带列表的城市编码；导出财务核算板块是否隐藏，当前错误地判断资产所属板块是否为单个“.”，列表则判断财务核算板块自身，异常值情况下可能不同。 |
| 导出范围差异 | 其他未配置用户导出允许板块 16，而列表排除 115、116 所有资产；这是现有范围差异，需确认业务是否应统一。 |
| 报废价值缺失 | 已核对 DTO、SQL、Service、JSP 和导出代码，报废原值、报废净值没有赋值链路。文档保留页面字段并明确未填充，不虚构计算规则。 |
| 排序异常 | 类别、成本中心、公司、状态、地点等列头仍引用 MS、MT、PED、O、AI3、ML 等旧查询别名，当前 SQL 只关联 MA、MV、M。需要核验排序参数转换；若直接拼接这些列，查询将报错。 |
| 公共资料 | 字典具体可选名称、类别树完整规则、公共板块选择器源码未提供，不能自行补出完整选项列表或多选规则。 |
