# 耗材统一申领报表PRD

## 1. 背景

用于查看耗材统一申请、配给、采购和领用进度，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。本报表保留“统一申请耗材采购领用报表”和“统一申请耗材明细报表”两页签，第二页作为独立的附加申请结果明细保留，不替代独立耗材明细报表。

## 2. 权限

| 角色 / 条件 | 可查看的数据范围 | 可执行操作 | 无权限结果 |
| --- | --- | --- | --- |
| 具备相应台账及资产卡片查看权限的用户 | 使用已有台账及资产卡片查看权限；集团、上海媒体分公司、广州媒体分公司各自查看所属台账数据。查询与导出范围相同，不另设报表角色权限。 | 查询、分页、导出有权查看的记录。 | 无权查看的台账或卡片数据不展示、不导出。 |

## 3. 通用规则

| 规则 | 业务要求 |
| --- | --- |
| 来源与明细粒度 | 耗材配给单，关联耗材申请单、耗材统一汇总申请单、耗材领用单及耗材出库单；采购领用页每行对应耗材配给单中的一项物料。 |
| 数据范围 | 仅包括物资总类为低值耐用品、耗材的记录。 |
| 默认排序 | 采购领用页按申请日期倒序，最新申请在最上方；附加明细页保留按耗材状态、物料编码、耗材标签号排序。 |
| 数据读取 | 每次查询读取最新的业务数据，展示当前有权查看的匹配结果。 |
| 查询匹配 | 所有条件非必填，默认空。不同条件同时满足，同一多选内命中任一值；日期可填写单端并包含所选自然日。文本条件去除首尾空格后包含匹配。 |
| 操作范围 | 报表只读，不提供新增、编辑、删除、审批或打印。 |
