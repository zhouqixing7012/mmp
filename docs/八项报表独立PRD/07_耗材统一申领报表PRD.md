# 耗材统一申领报表PRD（现状）

## 1. 背景

用于查询耗材统一申请的采购、领用进度及申请结果对应的耗材明细。源码包含“统一申请耗材采购领用报表”和“统一申请耗材明细报表”两个页面：前者以业务流程字段为主，后者以耗材标签、数量、责任人及申请关系为主。分别列明，避免与普通耗材明细报表混淆。

## 2. 权限

页面具有查询和导出入口；具体允许访问的角色、菜单授权未在所提供页面和报表Action中定义，待确认。页面虽然传递登录账号，但这四个报表的可见查询代码未按登录人、公司或部门追加数据范围；不能宣称仅可见本人或所在公司数据。全局拦截或报表源内部是否限权须另行确认。

## 3. 通用规则

所有查询条件均可不填。不填的条件不限制结果；多个不同条件同时填写时须全部满足，同一弹窗多选条件命中任一选项即可。文本匹配先去除首尾空格，再按包含匹配；源码直接使用LIKE，百分号与下划线未作字面转义。页面只读，不提供新增、编辑、删除、审批。点击查询或按回车提交当前条件；双击查询区后确认可清空条件，但不会自动执行新查询。

列表与导出使用同一查询及同一筛选条件。分页统计为源返回行数，不是申请单数；不在页面按单据合并，也不另做去重。
采购领用页默认按申请单号倒序、申请日期倒序；明细页默认按耗材状态、物料编码、耗材标签号排序。两个页面取自不同报表源，不保证行数相同，不可用其中一页的行数替代另一页的领用数量。采购领用页没有申请数量列，只有领用数量；明细页耗材数量实际取入库数量字段。

#### 查询与列表操作

查询选择弹窗回显所选名称并保存对应编码，可单独清空；日期从、至分别展示。资产大类与小类联动：选定大类后，小类弹窗限定其下小类；调整大类后只保留属于新大类的小类。没有选择大类时可以直接选小类。列表字段均不可编辑，单号为文本，没有明细跳转或查看进度操作。
明细页公司选择弹窗取mmp_company，以公司编码和名称查询；申请人公司、责任人公司、耗材公司是三个独立条件。板块弹窗取SOHU_GL_BU值集，选项编码固定为11、12、13、14、15、16、17、51、52、53、54、56，以编码或名称查询。责任人部门多选包含全部下级部门。

## 5. 校验

采购领用页日期起止由日期选择器限制先后，允许只填写一端。明细页没有日期条件；两个页面均未设置业务必填查询条件。是否弃领、是否刷卡领用、是否领用、是否占用独立匹配源文本，不互相倒推，也不因字段缺失自动设置为“否”。

明细页查询条件名称为“是否占有”，列表与导出名称为“是否占用”，两者都匹配ISOCUPY；名称差异需统一口径，不能解释成两个业务标记。

## 6. 后续操作 / 业务结果 / 补充说明

导出当前条件下全部匹配行，不限于当前页，每批读取20,000行，生成xlsx。没有数据时生成仅表头文件；导出不改变业务数据。空值导出为空白，不替换为0或“否”。金额页面采用千分位两位小数，导出用数字格式化后的文本；页面的50字显示限制不截断导出内容。日期导出调用系统TIME_FORMAT，其常量具体格式须配置确认。
采购领用页导出31个业务字段，明细页导出27个业务字段，不含序号。文件名分别为“统一申请耗材采购领用报表-日期.xlsx”“统一申请耗材明细报表-日期.xlsx”。明细页列表“采购申请单号”在导出中名为“采购申请号”，均取RELATED_PURCHASE_ID。

采购领用页取M0009_FCT_CONSUM_APPLY_EUA，明细页取M0009_FCT_CONSUM_APPLY_RESULT；没有源定义，未确认申请、采购、出库、耗材卡片之间的关联唯一键与一对多展开规则。金额范围与计算、税金按单件还是整行、是否领用／占用的判断公式、耗材状态字典、仓库STATUSDETAIL在各状态下的含义、责任人与组织信息是当前还是历史、刷新频率及完成时间归属均待确认。不得假设每一行是一张申请单，也不能直接用入库数量计算当前可用库存。
