# 资产新增报表 PRD

## 1. 背景

用于查询新增、采购收货入库形成的资产明细，查看采购、财务归属和责任人信息，并导出 Excel。这里的“新增”来自入库单，不是 EBS 同步新增报表。

## 2. 权限

| 项目 | 规则 |
|---|---|
| 公司数据范围 | 登录人未配置在 ASSET_RULE_USER 时：所属公司编码为 115 的只能查 115；为 116 的只能查 116；其他登录人排除 115、116。已配置用户不追加这项限制。列表按入库明细 ERP 公司判断。 |
| 仓库选择范围 | 只展示已启用、仓库层级为 1、当前登录人在仓库控制表中拥有查看权限的仓库。 |
| 页面访问权限 | 本页源码未定义可访问岗位，不能由公司范围推定岗位权限。 |

## 3. 通用规则

| 项目 | 规则 |
|---|---|
| 数据范围 | 入库单类型为 PUTIN，来源类型为 ADD 或 RECEIVE，流程步骤为 1。资产种类在查询及导出后台固定为资产，不包含耗材。步骤 1 的业务状态名称未提供。 |
| 一行数据 | 对应一条入库分配明细，按入库单关联仓库，按物料编码关联物料组合资料。不是按资产标签号去重，也不按资产卡片汇总。 |
| 查询组合 | 已填写条件同时满足；未填写的条件不追加筛选。 |
| 时间口径 | 入库明细保存采购、财务归属等业务数据；责任人姓名、品牌、类别名称等通过查询时的人员和基础资料转换；资产账簿取当前资产卡片。因此并非完整的入库时点快照。 |
| 格式 | 日期显示 yyyy-MM-dd，数量显示整数，原值、税金、含税金额显示千分位、两位小数。 |
| 默认顺序 | 按资产大类编码、公司编码、板块编码、序列号排序；后台支持按所选列和排序方向查询；页面点击列头提交 orderBy，公共表单如何转换为 orderCol 尚未提供。含税金额、资产所属板块、资产账簿无列头排序入口。 |

## 4. 页面字段及交互

### 4.1 查询条件

常用条件直接展示；City 至 NO 位置放在“更多”区域，默认收起。选择型条件展示名称、提交编码，可通过旁边清除图标清空。源码未提供业务必填校验，不将样式中的 required 直接认定为必填。

| 查询条件 | 输入方式与选项来源 | 实际筛选规则 |
|---|---|---|
| 资产种类 | 下拉；ASSET_KIND_ID 字典，仅编码 1 | 后台固定资产种类，不随前端改变。 |
| 资产类别 | 选择类别弹窗，使用 ASSET_TYPE 类别树；保存选中的第二级类别编码 | 匹配物料组合的小类编码，支持多个小类；弹窗自身完整规则未提供。 |
| 资产状态 | 多选弹窗；ASSET_STATUS 字典中启用的选项 | 实际按入库明细资产状态“等于整段提交字符串”查询；单选能形成一个状态条件，多选未按集合查询，见补充说明。 |
| 资产标签号 | 文本 | 匹配入库明细标签号，以输入内容开头；去掉前后空格。 |
| 序列号 | 文本 | 匹配入库明细序列号，以输入内容开头；去掉前后空格。 |
| 资产说明 | 文本 | 匹配物料组合说明，包含输入内容。 |
| 采购日期从、至 | 两个日期框，前后日期相互限制 | 匹配入库明细采购日期；从日含当日零点，至日含整天。 |
| 成本中心 | 多选弹窗；ERP 值集 SOHU_GL_CC，展示编码与说明 | 入库明细 ERP 成本中心属于选中编码集合。 |
| 启用日期从、至 | 两个日期框，前后日期相互限制 | 匹配入库明细启用日期；从日含当日零点，至日含整天。 |
| 公司 | 多选弹窗；公司视图 mmp_company_v | 入库明细 ERP 公司属于所选编码集合，并叠加登录人数据范围。 |
| 板块 | 弹窗选择，复用 assets.js 的 editPlate；公共脚本未提供，完整来源及是否多选未确认 | 入库明细 ERP 板块属于所选编码集合；筛选资产所属板块，不是费用账户拆出的财务核算板块。 |
| 责任人 | 人员选择弹窗，人员表关联人员扩展、PS 部门资料 | 入库明细责任人工号属于选中工号集合，不直接按姓名查询。 |
| 仓库 | 多选仓库弹窗；启用的一级仓库并受查看权限限制 | 入库单头仓库编码属于选中集合。 |
| 新增类型 | 多选弹窗；ASSETS_ADD_TYPE 启用字典 | 入库明细新增类型属于选中编码集合；不是按入库来源类型筛选。 |
| PR 单号 | 文本 | 入库明细关联 PR 编号包含输入内容。 |
| PO 单号 | 文本 | 入库明细采购编号包含输入内容。 |
| City | 单选弹窗；地点表中 city 类型 | 入库明细 City 编码等于所选编码。 |
| Building | 地点弹窗；按当前 City 查询 building | 入库明细 Building 编码等于所选编码。 |
| Floor | 单选下拉；地点表全部 floor 类型，按名称中数字排序 | 入库明细 Floor 编码等于所选编码；下拉 SQL 没有限定到选中 Building。 |
| 配置 | 文本 | 入库明细配置包含输入内容。 |
| 备注 | 文本 | 入库明细备注包含输入内容。 |
| 品牌 | 文本 | 先按品牌名称包含输入内容取得品牌编码，再匹配物料组合品牌编码。 |
| 原值 | 金额文本；修改时格式化，查询时去千分位逗号 | 精确匹配入库明细 ASSET_COST；列表原值却取 PURCHASE_PRICE，两者不能直接认定一致。 |
| 净值 | 金额文本；修改时格式化 | 精确匹配入库明细 ASSET_NBV，列表没有净值列。 |
| 折旧月数 | 数字文本 | 后台条件引用 MA.DEPRECIATION_MONTHS，但当前查询没有 MA 表别名，此条件存在查询错误。 |
| 费用账户 | 文本 | 入库明细 COST_ACCOUNT 包含输入内容；不是按列表转换后的历史事务费用账户过滤。 |
| 业务线 | 单选弹窗；ERP 值集 SOHU_GL_BL | 入库明细 ERP 业务线编码包含所选编码，现状为包含匹配而非精确匹配。 |
| 级别 | 单选下拉；ASSET_LEVEL 字典 | 入库明细 ASSET_LEVEL 等于所选编码；列表级别取物料组合 PRIORITY_LEVEL，来源不同。 |
| 主资产标签号 | 文本 | 入库明细父资产标签号包含输入内容，不匹配自身标签号。 |
| NO 位置 | 文本 | 入库明细 NO 位置包含输入内容。 |

### 4.2 列表字段

以下“入库明细”指 MMP_SP_PO_LINE_MOST_DIS，“入库单头”指 MMP_SP_PO_PUTIN_HEAD。名称转换使用查询时的基础资料。

| 字段 | 取值逻辑 |
|---|---|
| 序号 | （当前页－1）×每页条数＋本页行号。 |
| 仓库 | 入库单头 STORAGE_ID，转换为仓库显示名称。 |
| 资产种类 | 入库明细 MATERIAL_KIND，转换为物料种类名称。 |
| 资产大类 | 入库明细 MATERIAL_TYPE_CODE，转换为类别名称。 |
| 资产小类 | 入库明细 MATERIAL_CLASS_CODE，转换为类别名称。 |
| 资产标签号 | 入库明细 TAG_NUMBER。 |
| 序列号 | 入库明细 SERIAL_NUMBER。 |
| 品牌 | 物料组合资料 BRAND_CODE，转换为品牌名称。 |
| 级别 | 物料组合资料 PRIORITY_LEVEL，转换 ASSET_LEVEL 字典名称。 |
| 资产说明 | 物料组合资料 MATERIAL_DIM_COM_DESC；不是入库明细使用说明。 |
| 配置 | 入库明细 CONFIG_DETAILS。 |
| 数量 | 入库明细 PUTIN_QUANTITY；不是当前资产卡片剩余数量。 |
| 单位 | 入库明细 UOM 原值。 |
| 采购日期 | 入库明细 PURCHASE_DATE。 |
| 启用日期 | 入库明细 ENABLE_DATE。 |
| 原值 | 入库明细 PURCHASE_PRICE；不再乘数量。 |
| 税金 | 入库明细 PURCHASE_TAX；不再乘数量。 |
| 含税金额 | 原值为空按 0，税金为空按 0，两者相加；不再乘数量。 |
| 责任人编号 | 入库明细 DUTY_USER_ID。 |
| 责任人姓名 | 按责任人工号查当前人员姓名，覆盖结果对象中的姓名。 |
| NO 位置 | 入库明细 NO_LOCATION。 |
| 成本中心 | 入库明细 ERP_COST_CENTER，显示“编码.名称”。 |
| 申请单号 | 入库明细 APPL_NUMBER。 |
| PO 单号 | 入库明细 PURCHASE_ID。 |
| PR 单号 | 入库明细 RELATED_PR_ID。 |
| 入库单号 | 入库单头 SP_PO_PUTIN_NUM。 |
| 批次号 | 入库明细 IN_BATCHES。 |
| 入库来源类型 | 入库单头 PUTIN_TYPE，转换 PUTIN_TYPE 字典名称；结果仅可能来自 ADD、RECEIVE。 |
| 新增类型 | 入库明细 ADD_TYPE，转换 ASSETS_ADD_TYPE 字典名称。 |
| 公司 | 入库明细 ERP_COMPANY，显示“编码.公司名称”。 |
| 财务核算板块 | 以资产标签号和入库单号查询历史资产事务费用账户，拆出按点分隔的第二段板块编码，转换板块名称，显示“编码.名称”；费用账户为空，或“失败”从第2个字符及之后出现时显示空；现有判断没有拦截以“失败”开头的值。 |
| 资产所属板块 | 入库明细 ERP_PLATE，显示“编码.名称”；不取当前卡片板块。 |
| 业务线 | 入库明细 ERP_BUSINESS_LINE，显示“编码.名称”。 |
| 项目 | 入库明细 PROJECT_CODE，显示“编码.项目名称”。 |
| 资产账簿 | 按资产标签号查询当前资产卡片，取 BOOK_TYPE_CODE；可能与入库时点不同。 |
| 主资产标签号 | 入库明细 PARENT_TAG_NUMBER。 |
| 使用说明 | 入库明细 ASSET_DESC。 |
| 备注 | 入库明细 REMARK。 |
| 服务 | 入库明细 SERVICE，转换服务名称。 |

### 4.3 操作

| 操作 | 交互与结果 |
|---|---|
| 查询 | 点击查询或按回车提交当前条件，返回分页列表。 |
| 清除 | 弹出“此操作将清除所有查询条件，确定清除吗？”确认框，确认后清空查询条件。 |
| 导出资产新增报表 | 确认“导出列表中的所有数据到 Excel”后，按当前条件重新查询全部结果，不仅导出本页。文件名为“资产新增报表-yyyyMMdd.xlsx”。 |

## 5. 校验

| 校验项 | 规则 |
|---|---|
| 日期先后 | 日期选择器限制开始日期不晚于结束日期，结束日期不早于开始日期；后台范围查询结束边界为次日零点前。 |
| 资产范围 | 后台固定资产种类，即使前端空选或改变也不包含耗材。 |
| 条件有效性 | 多选状态、折旧月数存在页面和后台不一致，不能将页面可填写直接写成条件正常有效。 |

## 6. 后续操作 / 业务结果 / 补充说明

查询和导出只读取数据，不修改资产、入库单或事务。

| 项目 | 现状与需要明确的口径 |
|---|---|
| 导出字段 | 不导出序号；仓库列标题为“库房”，资产种类标题为“资产总类”；另增加“费用账户”。其余列表字段均导出，末尾顺序为主资产标签号、备注、使用说明、服务。 |
| 导出费用账户 | 直接取入库明细 COST_ACCOUNT。列表处理时覆盖为历史事务费用账户，但该字段未在列表展示；查询也筛选入库明细账户。 |
| 导出财务核算板块 | 事务表按“事务来源包含 PI”形成事务集合，再以标签号＋入库单号关联；从事务费用账户第 5 位起取 2 位板块编码。列表按点拆第二段，计算方式不同。 |
| 导出名称格式 | 公司、资产所属板块、业务线、项目、成本中心在导出 SQL 中取名称；列表多显示“编码.名称”。仓库导出显示“编码.名称”。大类、小类分别查物料大类、小类基础表；列表使用公共类别映射。 |
| 导出行数 | 导出关联使用不同费用账户、账簿的去重集合；同标签号、同入库来源存在多个账户或多个账簿时仍可能匹配多行，未见最终按入库明细去重。不能保证与分页总条数一致。 |
| 未确认 | 事务 DAO 如何在多个匹配事务中选取一条未提供；公共板块选择器源码未提供；类别树公共页面完整规则未提供；未取得入库明细表结构，原值、净值、级别查询字段是否实际存在需要核验。 |
| 已发现问题 | 排序参数从 orderBy 到 orderCol 的公共转换未提供；状态弹窗支持多选但后台按等于查询；折旧月数引用未关联的 MA；服务列排序引用 SPPLM.SUB_SERVICE，但显示取 SERVICE，需核对表字段与业务含义。 |
