# 资产报表PRD偏好整改交付

## 本轮范围

整改01—08八篇独立PRD及固定资产新增报表PRD，汇编与独立篇同步；新增报表公共查询交互规则。仅文档修改，未改原始现状PRD、截图、业务原型或实现通知发送。

## 用户确认回填

固定资产新增报表就是每月26日上午10点（北京时间）通过服务号发送的报表，不新增另一项财务月报。统计当月1—25日启用的新增记录。有记录时发生成完成消息，点击“查看详情”下载文件；全部无新增文案“本月无新增”；生成或发送失败通知ERP-周琦星，不考虑补发流程。参考[用户提供的服务号消息](https://chatgpt.com/library?file_id=libfile_1edf1f1f9314819189ad91a030120689&account_id=personal)，该图仅为需求依据，不是本轮原型验证截图。

财务实际接收人及各人授权公司、Media历史样例具体板块仍为资料缺口；未猜测名单或扩大权限。消息下载仅限获授权公司。已收口的通知形式与失败处理从待定义项移出。

## 偏好整改及保留内容

查询表只保留字段、交互方式、匹配规则；只读结果表保留字段、格式、业务来源。删除逐字段重复的必填/可编辑/默认空及无关模板句。按钮分别说明可用条件及结果，基础资料候选、结果列、跨页选择、确认取消、清空和失败行为归公共规则。数据来源仅写业务单据及关联关系，不写具体接口。

全部原查询、列表及独立导出字段与顺序逐项比对保留；公式、单多选、日期范围、历史取值、默认排序、权限及已确认状态仍有效。报废数量按已完成账面报废明细保存的本次报废数量定义；资产新增税金格式纠正为两位金额。耗材明细仍16查询27结果/导出、无详情、全部匹配导出。财务保留15列表字段、13导出字段、13个映射Sheet，重置重新查询，导出最近成功查询全部结果；其行为不套用其他报表。
