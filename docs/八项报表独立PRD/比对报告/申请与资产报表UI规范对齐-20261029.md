# 申请与资产报表UI规范对齐

基线：main 7fac5e67。依据UI规范V2.4及main已调整的物料维度组合、查询栏、表格密度、空状态和侧栏。范围为资产报表9个入口/10个查询页、申请9个查询入口及其详情/汇总/进度弹窗。没有恢复已经撤掉的耗材附加页、耗材详情入口或退库相关信息卡片。

| 核对区域 | 整改结果 |
| --- | --- |
| 查询区域 | 继续使用公共84px标签及容器自适应QueryBar；报表补齐展开更多/收起、重置、查询顺序、图标和展开状态。收起不清条件。 |
| 结果工具区 | 普通报表/申请的匹配数量移至结果Card右上，与行高、已有导出入口并列；依赖勾选的既有动作只在选择条出现，不增加权限。 |
| 表格 | 提供32/40/44/48px密度、默认40，保留14px正文；共用样式处理多行、边框和链接。主表显式复用自动列宽，表头完整、编码/金额/日期按实际格式测量，宽表只在内部横向滚动。 |
| 长文本与空状态 | 单元格省略后提供全文Tooltip；复用main空状态原图，同时保留各页专属无结果或错误文字。缺失和真实0不互换。 |
| 已生效条件 | 结果区展示已应用条件及真实名称；未查询的新输入不冒充结果条件。清除入口读取对应页规则，报表保留原重置仅清输入的行为，新增清除结果条件入口单独确认。 |
| 详情 | 共用紧凑小Card及分区标识；保留DetailGrid三列和退库明确三列例外。备注/建筑/使用说明/项目用途按既定只读PRD显示文本，不保留无保存结果的伪编辑框或PR同步承诺。 |
| 弹窗 | 超宽移库/退库物资详情收回960px；滚动由内容区和表格分别承载，Footer与全局居中/关闭交互保持。 |
| 财务报表特例 | 保留15列列表、13列导出、四项合计在Card extra，不另增加记录条数。重置重新查询、导出最近成功查询结果的独立语义保留。 |
