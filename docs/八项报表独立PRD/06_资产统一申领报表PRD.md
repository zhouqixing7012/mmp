# 资产统一申领报表PRD

## 1. 背景

用于查看资产统一申请、配给、采购和领用进度，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。本报表保留“统一申请库存领用报表”和“统一申请统一采购报表”两页签，分别呈现库存领用和统一采购链路。

## 2. 权限

| 角色 / 条件 | 可查看的数据范围 | 可执行操作 | 无权限结果 |
| --- | --- | --- | --- |
| 具备相应台账及资产卡片查看权限的用户 | 使用已有台账及资产卡片查看权限；集团、上海媒体分公司、广州媒体分公司各自查看所属台账数据。查询与导出范围相同，不另设报表角色权限。 | 查询、分页、导出有权查看的记录。 | 无权查看的台账或卡片数据不展示、不导出。 |

## 3. 通用规则

人员、公司、部门及其他基础资料按本页字段规定的角色和范围选择；选择与回填执行第4章公共交互约定。基础资料选择不改变本报表的数据权限及历史取值时点。

| 规则 | 业务要求 |
| --- | --- |
| 来源与明细粒度 | 资产配给单，关联资产申请单、资产统一汇总申请单、资产领用单和资产出库单。 |
| 数据范围 | 不额外增加流程完成状态过滤。库存领用页仅显示匹配状态为“库存领用”的记录；统一采购页仅显示匹配状态为“统一采购”的记录。 |
| 默认排序 | 申请日期倒序，最新申请在最上方。 |
| 数据读取 | 每次查询读取最新的业务数据，展示当前有权查看的匹配结果。 |
| 查询匹配 | 所有条件非必填，默认空。不同条件同时满足，同一多选内命中任一值；日期可填写单端并包含所选自然日。文本条件去除首尾空格后包含匹配。 |
| 操作范围 | 报表只读，不提供新增、编辑、删除、审批或打印。 |

## 4. 页面字段及交互

本章查询、选择、分页、导出与异常处理执行[报表公共查询交互规则](00_报表公共查询交互规则.md)；下表保留本页字段、单多选、匹配方式及专属业务规则。编码、单号及标签按文本保留原值和前导零。

库存领用：配给单及对应领用单均无标签号时，每行对应配给单中的一项物料；任一存在标签号时按数量为1拆行。领用单有标签号优先取领用单，否则取配给单。统一采购：无PO时按配给单物料展示；有PO时按数量为1拆行。拆行后申请数量仍为原申请数量，不能逐行累计成总申请数量，也不能用行数代表全流程总申请台数。

库存页保留完整13项查询；库存领用无汇总单，填写汇总提交人或资产统一汇总单号后不返回匹配记录。两页独立保存查询条件与分页，切换页签不把库存条件带入采购页。

统一采购页“预计采购金额”按配给单物料数量×参考单价计算；拆成单件行后不改用领用数量计算。“实际采购金额”取采购系统对应采购含税单价，单位为元/件，不乘数量，不当作全单或整行合计。子流程类型按库存领用=领用、统一采购无汇总单=采购、统一采购有汇总单=采购汇总分别显示。审批节点展示全部当前待审批节点，当前审批人展示全部待审批人的工号.姓名；多条内容按业务来源顺序，列表与导出一致。流程结束（已处理或已驳回）后，审批节点与当前审批人均为空。完成时间和出库日期均取对应资产出库单审核日期。

### 页面操作

| 操作 | 可用条件 | 交互与结果 |
| --- | --- | --- |
| 查询 | 具备本报表查看权限，查询条件通过校验 | 点击查询或在文本框按回车，读取最新数据并回到第一页；加载期间不可重复查询。失败时保留条件，按公共规则提示并允许重试。 |
| 重置 | 查询页可用 | 二次确认后仅清空输入条件，不自动改变现有列表、分页或排序；取消时保留条件。重置后点击查询或按回车再更新结果。 |
| 导出 | 具备对应记录查看权限，导出条件通过校验 | 导出当前条件下全部有权查看的结果，不限当前页；按本页字段顺序和默认排序，不含页面序号。失败提示“导出失败，请重试”，保留条件，可重新导出。 |

列表只读，无匹配记录显示“暂无数据”；单号为文本，不提供审批或编辑入口。分页显示明细总行数，翻页和修改每页条数时保留筛选条件。选择控件的候选、查询、回填、移除、确认、取消及失败行为见公共交互规则。

## 5. 校验

| 校验项 | 触发时机 | 判断及处理 | 提示与修正 |
| --- | --- | --- | --- |
| 日期起止 | 选择日期、查询、导出 | 同一日期的开始不得晚于结束，允许只填写一端；不满足时阻止查询或导出。 | “开始日期不能晚于结束日期”；修改起止日期。 |
| 权限 | 进入、查询、导出 | 按已有台账及资产卡片查看权限筛选；查询与导出范围相同，不另设报表角色权限。 | 无权限数据不展示、不导出；没有有权查看的匹配记录时显示“暂无数据”。 |
| 基础资料选择 | 查询、导出 | 按已选编码或工号筛选；多选不转换为单个文本；失效选项不得作为正常候选。 | 所选资料失效时提示“所选资料已失效，请重新选择”。 |
| 只读字段 | 列表展示 | 报表不修改来源业务记录；缺失取值不得自行补0、补“否”或重新猜测来源。 | 缺失值显示为空白；来源资料缺失时保持空白，不改用其他业务对象的值。 |

## 6. 后续操作 / 业务结果 / 补充说明
