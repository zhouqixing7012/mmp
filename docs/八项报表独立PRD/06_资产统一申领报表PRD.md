# 资产统一申领报表PRD

## 1. 背景

用于查看资产统一申请、配给、采购和领用进度，并导出核对。入口为“资产报表”，该菜单位于“资产盘点”之后。本次仅包括报表查询、分页和Excel导出，不包括来源单据办理或资产维护。本报表保留“统一申请库存领用报表”和“统一申请统一采购报表”两页签，分别呈现库存领用和统一采购链路。

## 2. 权限

| 角色 / 条件 | 可查看的数据范围 | 可执行操作 | 无权限结果 |
| --- | --- | --- | --- |
| 具有本报表查看权限的用户 | 按当前登录人的资产卡片查看权限过滤；集团、上海媒体分公司、广州媒体分公司各自查看所属台账数据。 | 查询、分页、导出有权查看的记录。 | 无报表查看权限不允许进入；无卡片权限的数据不展示、不导出。 |

## 3. 通用规则

| 规则 | 业务要求 |
| --- | --- |
| 来源与明细粒度 | 资产配给单，关联资产申请单、资产统一汇总申请单、资产领用单和资产出库单。 |
| 数据范围 | 不额外增加流程完成状态过滤。库存领用页仅显示匹配状态为“库存领用”的记录；统一采购页仅显示匹配状态为“统一采购”的记录。 |
| 默认排序 | 申请日期倒序，最新申请在最上方。 |
| 历史取值 | 现状未规定不可变历史时点；具体更新时机见当前尚未定义。 |
| 查询匹配 | 所有条件非必填，默认空。不同条件同时满足，同一多选内命中任一值；日期可填写单端并包含所选自然日。文本条件去除首尾空格后包含匹配。 |
| 操作范围 | 报表只读，不提供新增、编辑、删除、审批或打印。 |

## 4. 页面字段及交互

库存领用：配给单及对应领用单均无标签号时，每行对应配给单中的一项物料；任一存在标签号时按数量为1拆行。领用单有标签号优先取领用单，否则取配给单。统一采购：无PO时按配给单物料展示；有PO时按数量为1拆行。拆行后申请数量仍为原申请数量，不能逐行累计成总申请数量，也不能用行数代表全流程总申请台数。

统一采购页“预计采购金额”按配给单物料数量×参考单价计算；拆成单件行后不改用领用数量计算。“实际采购金额”保持现状字段名称，取采购系统对应采购含税单价，单位为元/件，不乘数量，不当作全单或整行合计。子流程类型按库存领用=领用、统一采购无汇总单=采购、统一采购有汇总单=采购汇总分别显示。当前审批人取当前节点的一位审批人，显示工号.姓名；多位时具体取谁尚未定义。完成时间和出库日期均取对应资产出库单审核日期。
