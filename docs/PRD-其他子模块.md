## 一、地点基础数据维护

### 1.1 页面功能

管理企业的地点信息，包括城市、建筑、楼层等地理位置数据。

### 1.2 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 地点名称 | 文本输入框 | 支持模糊搜索 |
| 地点类型 | 下拉选择框 | 选项：全部、city、province |
| 状态 | 下拉选择框 | 选项：全部、启用、停用 |

### 1.3 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 序号 | 自动编号 |
| 地点名称 | 如：辽宁省-铁岭市 |
| 地点类型 | city/province |
| 启用 | 启用/停用 |
| 操作 | 编辑按钮 |

### 1.4 新增/编辑弹窗

| 字段名 | 控件类型 | 是否必填 |
|--------|----------|---------|
| 地点名称 | 文本输入框 | 是 |
| 地点类型 | 下拉选择框 | 是 |
| 状态 | 下拉选择框 | 是 |

## 二、单据编号规则管理

### 2.1 页面功能

管理各类单据的编号生成规则，如员工信息、资产调拨等单据的编号格式。

### 2.2 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 单据类型 | 下拉选择框 | 选项：全部、员工信息、资产调拨等 |
| 前缀 | 文本输入框 | 支持模糊搜索 |
| 分隔符 | 文本输入框 | 支持模糊搜索 |

### 2.3 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 序号 | 自动编号 |
| 单据类型 | 如：员工信息 |
| 前缀 | 如：PAI |
| 分隔符 | 如：- |
| 是否包含公司缩写 | 是/否 |
| 日期类型 | 年月日/年月 |
| 流水号类型 | 5位流水号/4位流水号 |
| 操作 | 编辑按钮 |

### 2.4 规范说明

1. 单据编号规则必须包含有单据类型
2. 单据前缀及其连缀符仅在规则生成时使用

### 2.5 新增/编辑弹窗

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 单据类型*（下拉选择） | 前缀（文本输入） |
| 第2行 | 分隔符（文本输入） | 是否包含公司缩写（下拉选择） |
| 第3行 | 日期类型（下拉选择） | 流水号类型（下拉选择） |

## 七、资产折旧规则管理

### 7.1 页面功能

管理资产折旧的计算规则，配置不同物料大类和小类的折旧年限。

### 7.2 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 物料大类 | 搜索选择框 | 点击搜索图标选择大类 |
| 物料小类 | 搜索选择框 | 点击搜索图标选择小类 |
| 使用年限 | 下拉选择框 | 选项：全部、4年以上、4年以内 |

### 7.3 表格列

| 列名 | 说明 |
|------|------|
| 物料大类 | 大类名称 |
| 物料小类 | 小类名称 |
| 原值要求 | 价格门槛 |
| 计算关系 | >=、<=、= |
| 使用年限 | 折旧年限 |
| 账面金额类型 | 净值/原值 |
| 操作 | 编辑按钮 |

### 7.4 工具栏

[计算] [新增] [编辑] [删除]

### 7.5 新增/编辑弹窗

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 物料大类*（搜索选择） | 物料小类（搜索选择） |
| 第2行 | 原值要求（数字输入） | 计算关系（下拉选择） |
| 第3行 | 使用年限（下拉选择） | 账面金额类型（下拉选择） |
