# 资产管理 - 资产维护 PRD

## 1. 背景

资产维护用于统一查询、查看和维护已经形成正式资产卡片的资产数据。

本模块覆盖全部正式资产卡片，包括普通资产和机房资产。资产卡片由入库等上游资产业务生成，资产维护页面本身不提供新增资产卡片和删除资产卡片能力。

## 2. 范围与权限

### 2.1 业务范围

资产维护展示全部已经生成正式资产卡片的资产，包括普通资产、机房资产以及已报废但仍需留存查询的资产。

页面不直接新增或删除资产卡片，不直接执行资产报废，也不允许修改未开放的资产核心字段。

### 2.2 权限

资产数据按“财务公司 + 板块”进行权限隔离。用户只能查询、查看、维护和导出其授权范围内的数据。

查看权限和编辑权限分开控制。无编辑权限用户不展示编辑及批量修改入口；有编辑权限用户只能修改其数据范围内、且本 PRD 明确开放的字段。权限校验必须在服务端再次执行。

当前 PC 原型不模拟不同用户身份和权限按钮显隐。

## 3. 通用规则

### 3.1 默认加载与排序

进入“资产管理 → 资产维护”后，系统直接查询当前用户权限范围内的资产。

用户未主动排序时，默认排序为：`最后修改时间倒序 → 资产标签号升序`。

### 3.2 数字与日期展示

- 数量等计数型字段使用整数及千分位展示。
- 原值、EBS原值、净值、EBS净值、配置参考价值、升级金额等金额字段使用千分位 + 2 位小数。
- 日期统一展示为 `yyyy-MM-dd`。
- 日期时间统一展示为 `yyyy-MM-dd HH:mm:ss`。
- 标签号、序列号、员工编号、单据号等标识类字段不得使用千分位格式。

### 3.3 资产状态

“已报废-已处置”“已报废-待处置”不得通过资产维护人工设置，正式报废状态必须由资产报废业务产生；“再利用-待报废”暂保留为可编辑状态。

### 3.4 查询关系

- 不同查询条件之间使用 AND 关系。
- 同一多选条件中的多个值使用 OR 关系。
- 支持多值的文本条件中，多个值按 OR 处理。
- 点击【查询】或在文本条件中按 Enter 均执行查询。
- 点击【重置】清空全部基础条件及更多条件。
- 重新查询后返回第一页并清空当前页勾选状态。

### 3.5 选择范围

资产列表复选框仅保留当前页选择状态，不保留跨分页勾选。单条编辑不依赖复选框，通过右侧固定操作列【编辑】进入。

## 4. 资产列表

### 4.1 查询条件布局

PC 端查询条件固定按 **一行 3 个字段** 展示。

- 每个字段标签固定宽度并右对齐；
- 基础查询条件和展开后的更多查询条件共用同一 3 列栅格；
- 不允许把整组查询条件堆叠到单列中；
- 查询、重置、更多条件操作位于查询区右侧。

### 4.2 基础查询条件

| 字段 | 交互方式 | 查询规则 |
|---|---|---|
| 资产标签号 | 文本输入 | 支持模糊及多值查询 |
| 公司 | 多选弹窗 | 仅展示授权公司 |
| 部门 | 多选弹窗 | 包含下级组织 |
| 资产责任人 | 多选弹窗 | 支持员工编码、姓名、部门名称查询 |
| 资产序列号 | 文本输入 | 支持模糊及多值查询 |
| 资产说明 | 文本输入 | 支持模糊及多值查询 |
| 资产类别 | 树形多选 | 按资产大类 / 资产小类层级多选 |
| 资产状态 | 多选下拉 | 仅展示有效状态 |
| 板块 | 多选下拉 | 只能选择授权板块 |
| 成本中心 | 多选弹窗 | 展示编码.名称 |
| 资产用途 | 多选下拉 | 部门公用 / 员工用机 / 其他用途 / 专业用途 / 空 |
| 仓库 | 多选下拉 | 多选 |
| 资产类型 | 多选下拉 | 公司资产 / 自备资产 |

### 4.3 更多查询条件

更多查询条件默认收起，展开后继续按一行 3 个字段排列。

| 字段 | 交互方式 | 查询规则 |
|---|---|---|
| City | 单选下拉 | 单选 |
| Building | 单选下拉 | 必须先选择 City |
| Floor | 多选下拉 | 受 City / Building 关系限制 |
| 新增类型 | 多选下拉 | 多选 |
| PO 单号 | 文本输入 | 支持模糊及多值查询 |
| 购买日期 | 日期范围 | 起止日期校验 |
| 原值 | 金额范围 | 最小金额不得大于最大金额 |
| 品牌 | 多选弹窗 | 支持品牌查询及多选 |
| 启用日期 | 日期范围 | 起止日期校验 |
| PR 单号 | 文本输入 | 支持模糊及多值查询 |

### 4.4 列表字段

列表固定展示：标签号、公司、板块、资产大类、资产小类、资产说明、数量、原值、净值、资产责任人、资产状态、成本中心、仓库、启用日期、资产类型。

标签号为蓝色链接，点击打开资产卡片；右侧固定操作列仅展示【编辑】。

## 5. 资产卡片弹窗

### 5.1 通用交互

资产卡片使用 Modal 弹窗承载，不跳转独立页面。弹窗不做全屏，内容超高时在弹窗内部纵向滚动。

固定包含 6 个页签：详细信息、价值信息、资产维修记录、资产盘点历史、资产操作历史、RFID资产操作历史。

### 5.2 详细信息分组

详细信息使用 3 列 DetailGrid 展示，分组为：基础信息、账务信息、NO 信息、报废信息、耗材信息、部件信息。

每个分组标题左侧展示蓝色区块。基础信息固定展开；其他分组支持独立展开 / 收起。无数据分组不隐藏，展示对应“无信息”空状态。

### 5.4 账务信息

账务信息字段固定按以下顺序展示：

| 顺序 | 字段 | 编辑态 |
|---:|---|---|
| 1 | 资产编号 | 只读 |
| 2 | 成本中心 | 可编辑 |
| 3 | 板块 | 只读 |
| 4 | 业务线 | 只读 |
| 5 | 项目 | 只读 |

| 7 | 费用账户 | 只读 |

资产卡片不展示账簿、税额、资产入库批次。

### 5.5 NO 信息

机房资产只展示 NO位置、服务。普通资产或未关联 NO 数据的资产显示 `无 NO 信息`。

### 5.6 报废信息

存在报废记录时展示报废原因、报废日期、报废类型、是否处置、报废数量、ES 实物报废期；无记录时展示 `无报废信息`。

### 5.7 耗材信息

存在关联耗材时展示耗材标签号、耗材说明、启用日期；无数据时展示 `无耗材信息`。

### 5.8 部件信息

存在部件时展示部件名称 / 说明、部件标签号、部件 SN 号；无数据时展示 `无部件信息`。

## 6. 价值信息页签

普通资产只读展示：

- 原值；
- 净值；
- EBS净值；
- EBS原值；
- 折旧年限；
- 折旧剩余月份。

机房资产在以上字段基础上额外展示 **配置参考价值**。

价值信息页签不展示税额。

## 7. 资产维修记录页签

维修记录来自 MIS 系统同步，只读展示。维修单号先按普通文本展示，不定义下钻。

## 8. 资产盘点历史页签

资产盘点历史只读展示并按盘点时间倒序排列。

表格展示：盘点类型、盘点标识、盘点项目名称、盘点状态、盘点时间、盘点说明、盘点执行人、导入方式。

盘点状态固定只有两种：

- 已盘；
- 代盘。

## 9. 资产操作历史页签

资产操作历史默认按操作日期倒序展示。

单据编号、申请单号均为只读文本。数据关系必须符合真实业务：

- 正式业务事务若存在申请单号，则必须同时存在单据编号；
- 不允许出现只有申请单号、没有单据编号的业务事务；
- 手工资产维护修改允许单据编号和申请单号同时为空。

字段包括：操作类型、操作日期、操作人、单据编号、申请单号、资产标签号、序列号、主资产标签号、类别、资产说明、责任人、成本中心、费用科目、公司、地点、用途、资产状态、使用说明、备注、服务、配置、NO位置、升级金额。

不展示资产担保人。

相邻事务中纳入比较范围的字段发生变化时，对应单元格使用浅黄色背景标识。

## 10. RFID资产操作历史页签

RFID 资产操作历史与资产核心事务历史为独立数据来源，只读展示，不与资产操作历史合并。

## 11. 单条资产编辑

编辑态仍展示完整资产卡片，只允许修改以下 10 个字段：

1. 成本中心；
2. City；
3. Building；
4. Floor；
5. 资产状态；
6. 资产序列号（资产卡片展示名称为“序列号”）；
7. 备注；
8. 资产标记；
9. 使用说明；
10. 资产用途（资产卡片展示名称为“用途”）。

可编辑字段继续在其所属分组的原位置切换为编辑控件。成本中心位于“账务信息”，其余字段按本 PRD 的资产卡片字段位置展示。

手工资产维护保存后形成资产维护修改事务，该事务的单据编号、申请单号均为空。

## 12. Excel 批量修改

列表提供【批量修改】，弹窗内提供【下载模板】和 Excel 上传。

资产标签号必须填写，用于定位已有资产；其余 10 个维护字段按模板单元格内容 **覆盖更新**，空白单元格表示覆盖为空。

任意一行校验失败时整批不保存，并返回行号、资产标签号和失败原因。

## 13. 导出

当前页有勾选时只导出当前勾选资产；未勾选时导出当前查询条件下全部资产，不受当前分页限制。

文件名：`导出资产卡片信息-yyyyMMdd.xlsx`。

导出字段覆盖当前目标资产卡片业务字段，包括 EBS原值、EBS净值以及机房资产配置参考价值，不包含已从资产卡片删除的账簿、税额、资产入库批次、资产更换日期、可用标志、资产要求。

## 14. 数据来源

| 数据 | 来源 / 处理 |
|---|---|
| 资产主数据 | 资产卡片主数据 |
| 原值、净值 | 资产价值数据 |
| EBS原值、EBS净值 | EBS 同步结果 |
| 配置参考价值 | 机房资产配置价值数据 |
| 维修记录 | MIS 同步结果 |
| 盘点标识 | 最近一次盘点年份 |
| 盘点历史 | 盘点项目及盘点明细 |
| 资产操作历史 | 资产核心事务记录 |
| RFID资产操作历史 | RFID 独立历史数据源 |
| NO位置、服务 | NO 关联数据 |
| 耗材信息 | 按耗材主资产标签号关联 |
| 部件信息 | 资产部件信息 |

## 15. 研发前需确认

研发前需结合正式接口和基础资料确认 EBS 原值 / EBS 净值同步规则、机房资产配置参考价值来源、MIS 维修字段映射、财务变更同步接口、文本字段最大长度、正式字典编码以及 Excel 模板最终格式。
