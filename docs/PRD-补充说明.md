## 一、系统架构与接口说明

### 1.1 外部系统集成

本模块与以下外部系统有数据交互：

| 系统名称 | 接口类型 | 同步数据 | 说明 |
|----------|----------|----------|------|
| **EBS（财务系统）** | EBS接口 | 公司、成本中心、科目、账簿 | 财务核算相关数据从EBS同步 |
| **PS（HR系统）** | PS接口 | 员工、部门、办公区 | 人力资源相关数据从PS同步 |
| **采购系统** | 采购接口 | 物料大类、小类、品牌、型号 | 物料基础数据从采购系统同步 |

### 1.2 数据流向

```
┌─────────────────────────────────────────────────────────────┐
│                    外部系统                                  │
├─────────────────────────────────────────────────────────────┤
│  EBS（财务）  ←→  资产管理系统  ←→  PS（HR）                │
│                  ↑                ↑                         │
│                  │                │                         │
│              采购系统          业务系统                      │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 同步规则

- **同步时机**：外部系统数据变更后，通过接口同步到资产管理系统
- **同步方式**：定时同步（每日）或实时同步（关键数据）
- **冲突处理**：以外部系统数据为准，本地修改会被覆盖
- **日志记录**：所有同步操作记录日志，便于追溯

## 四、业务规则详细说明

### 4.1 物料维度组合编码生成规则

**编码格式**：大类编码 + 小类编码 + 品牌编码 + 型号编码 + 配置编码（如果为空，默认为000）

**示例**：
- 大类：PC（11）
- 小类：001
- 品牌：040（苹果）
- 型号：014
- 配置：001

**生成的编码**：11001040014001

### 4.2 物料小类编号规则

- 每个大类下的小类编号从1开始递增（1、2、3、4...）
- 小类编号显示为3位（如：001、002、003）
- 小类唯一性规则：不同大类下的小类编号可以相同

**示例**：
- PC大类下的小类：001、002、003...
- NOTEBOOK大类下的小类：001、002、003...

### 4.3 品牌编码生成规则

- 品牌编码由系统自动生成，无需手动输入
- 品牌编码全局唯一

### 4.4 规格型号与品牌的关系

- 型号在创建时需要与品牌进行关联
- 同一品牌下的型号必须保持唯一
- 一个型号只能对应一个品牌

### 4.5 配置与型号的关系

- 配置在创建时需要选择品牌和型号
- 配置编码由系统自动生成，唯一值
- 一个配置对应一个型号

### 4.6 物料维度组合的联动逻辑

1. **选择型号后自动带出品牌**：选择型号时，系统自动填充对应的品牌
2. **选择配置后自动带出型号和品牌**：选择配置时，系统自动填充对应的型号和品牌
3. **物料小类自动带出"是否需要盘点"字段**：选择物料小类后，系统自动填充该小类的盘点设置

### 4.7 仓库权限业务规则

1. **默认仓库限制**：每个仓库只能有一个默认入库仓库和一个默认出库仓库
2. **入库权限**：入库时，员工只能看到有入库权限的仓库和对应库位
3. **出库权限**：出库时，员工只能看到有出库权限的仓库和对应库位

### 4.8 公司板块提取资产权限规则

- 员工根据"公司+板块"提取资产
- 包括：公司所属资产 + 个人资产映射范围内的资产
- 用于控制员工可以看到哪些资产数据

### 4.9 办公区与仓库映射规则

- 通过"公司+部门+办公区"信息，自动匹配对应的仓库
- 用于资产领用、归还时自动选择仓库
- 映射规则：优先级数字越小，优先级越高

## 五、页面原型参考

### 5.1 物料综合集合页面

**搜索条件区域**：
- 维度组合编码：文本输入框
- 维度组合描述：文本输入框
- 物资总类：下拉选择框（全部、资产、耗材、低值耐用品）
- 大类描述：搜索选择框
- 小类描述：搜索选择框
- 单位：下拉选择框
- 是否启用：下拉选择框（全部、是、否）
- 参考价格（从/至）：数字输入框

**工具栏**：新增、删除、启用、停用、批量修改

**数据表格**：支持分组显示，按物料总类分组

### 5.2 仓库信息页面

**搜索条件区域**：
- 仓库编码：文本输入框
- 仓库描述：文本输入框
- 是否虚拟库：下拉选择框（全部、是、否）
- 是否启用：下拉选择框（全部、是、否）

**工具栏**：新增、删除、启用、停用

**数据表格**：显示仓库详细信息，包括编码、描述、类型、地址、管理员等
