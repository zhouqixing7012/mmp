## 一、模块概述

### 1.1 模块定位

"单据编号规则管理"模块用于管理各类业务单据的编号生成规则，如员工信息单、资产调拨单等，确保单据编号的规范性和唯一性。

### 1.2 包含页面

本模块只有1个页面：**单据编号规则管理**

---

## 二、页面：单据编号规则管理

### 2.1 页面功能

管理系统中所有单据的编号生成规则，配置单据类型的前缀、分隔符、日期格式、流水号位数等参数。

### 2.3 搜索条件区域

**默认状态**：展开显示所有搜索条件

**搜索字段**：

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 单据类型 | 下拉选择框 | 选项：全部、员工信息、资产调拨、资产报废、资产归还等 |
| 前缀 | 文本输入框 | 支持模糊搜索，如输入"PAI" |
| 分隔符 | 文本输入框 | 支持模糊搜索，如输入"-" |

**按钮**：
- **查询**：蓝色主按钮，点击后根据条件筛选数据
- **重置**：灰色按钮，点击后清空所有搜索条件

### 2.4 工具栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增弹窗 |
| 删除 | 红色按钮 | 删除选中的记录（需先勾选） |

**说明**：本模块不支持批量修改，因为单据规则通常不需要批量操作。

### 2.5 数据表格

#### 表格列说明

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 用于批量选择 |
| 序号 | 自动编号 |
| 单据类型 | 如：员工信息、资产调拨、资产报废 |
| 前缀 | 单据编号的前缀，如：PAI、ADJ |
| 分隔符 | 前缀和后续内容的分隔符，如：-、_ |
| 是否包含公司缩写 | 是/否，决定编号中是否包含公司代码 |
| 日期类型 | 年月日（如：20260528）或 年月（如：202605） |
| 流水号类型 | 5位流水号或4位流水号 |
| 操作 | 包含"编辑"按钮 |

#### 单据编号格式示例

**规则配置**：
- 单据类型：员工信息
- 前缀：PAI
- 分隔符：-
- 是否包含公司缩写：否
- 日期类型：年月日
- 流水号类型：5位流水号

**生成的编号**：PAI-20260528-00001

**规则配置**：
- 单据类型：资产调拨
- 前缀：ADJ
- 分隔符：-
- 是否包含公司缩写：是（公司缩写为：SOHU）
- 日期类型：年月
- 流水号类型：4位流水号

**生成的编号**：ADJ-SOHU-202605-0001

#### 表格交互

- **行悬浮**：鼠标悬浮时，该行背景变浅蓝色
- **排序**：点击列标题可排序（升序/降序）
- **分页**：每页默认10条，支持切换每页条数

### 2.6 新增/编辑弹窗

#### 弹窗标题
- 新增时：标题为"新增单据编号规则"
- 编辑时：标题为"编辑单据编号规则"

#### 表单字段布局

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 单据类型*（下拉选择） | 前缀（文本输入） |
| 第2行 | 分隔符（文本输入） | 是否包含公司缩写（下拉选择） |
| 第3行 | 日期类型（下拉选择） | 流水号类型（下拉选择） |

#### 字段详细说明

**单据类型（必填）**：
- 控件类型：下拉选择框
- 选项：
  - 员工信息
  - 资产调拨
  - 资产报废
  - 资产归还
  - 资产借用
  - 其他自定义类型
- 校验：不能与已有单据类型重复

**前缀（选填）**：
- 控件类型：文本输入框
- 格式：大写字母，如PAI、ADJ
- 说明：单据编号的起始部分，便于识别单据类型

**分隔符（选填）**：
- 控件类型：文本输入框
- 格式：单个字符，如：-、_、/
- 说明：用于分隔前缀、日期、流水号等部分

**是否包含公司缩写（选填）**：
- 控件类型：下拉选择框
- 选项：
  - 是
  - 否
- 默认值：否
- 说明：如果选择"是"，编号中会自动加入公司缩写代码

**日期类型（选填）**：
- 控件类型：下拉选择框
- 选项：
  - 年月日（格式：YYYYMMDD，如20260528）
  - 年月（格式：YYYYMM，如202605）
- 默认值：年月日

**流水号类型（选填）**：
- 控件类型：下拉选择框
- 选项：
  - 5位流水号（如：00001）
  - 4位流水号（如：0001）
- 默认值：5位流水号
- 说明：流水号在每次生成新编号时自动递增

#### 弹窗按钮

| 按钮 | 样式 | 功能 |
|------|------|------|
| 保存 | 蓝色主按钮 | 保存数据，关闭弹窗 |
| 返回 | 灰色按钮 | 取消操作，关闭弹窗 |

### 2.7 校验规则

| 字段 | 校验规则 | 错误提示 |
|------|----------|----------|
| 单据类型 | 必填 | "请选择单据类型" |
| 单据类型 | 唯一性校验 | "该单据类型已存在" |
| 前缀 | 只能包含大写字母 | "前缀只能包含大写字母" |
| 分隔符 | 只能包含一个字符 | "分隔符只能是一个字符" |

### 2.8 规范说明

在表格下方显示以下规范说明：

1. **单据编号规则必须包含有单据类型**
   - 每种单据类型只能有一条规则

2. **单据前缀及其连缀符仅在规则生成时使用**
   - 前缀和分隔符只用于生成编号，不影响编号的存储和查询

## 三、通用交互说明

### 3.1 新增流程

1. 点击工具栏"新增"按钮
2. 弹出新增弹窗
3. 选择单据类型（必填）
4. 配置前缀、分隔符、日期类型、流水号类型
5. 点击"保存"按钮
6. 系统校验：
   - 如果校验通过：保存成功，关闭弹窗，刷新列表
   - 如果校验失败：显示错误提示，不关闭弹窗

### 3.2 编辑流程

1. 点击表格"操作"列的"编辑"按钮
2. 弹出编辑弹窗，显示当前规则的配置
3. 修改需要更新的字段（单据类型不可修改）
4. 点击"保存"按钮
5. 系统校验并保存

### 3.3 查询流程

1. 在搜索条件区域输入筛选条件
2. 点击"查询"按钮
3. 表格显示符合筛选条件的数据
4. 点击"重置"按钮，清空所有搜索条件，显示全部数据
