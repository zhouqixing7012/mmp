## 八、账套内容维护

---

### 8.1 模块说明

#### 8.1.1 模块定位

“账套内容维护”模块用于管理财务账套的基本信息，包括账套名称、所属公司、所属板块等，是财务系统的基础配置。

权限：所有涉及账套内容编辑、修改的权限，目前仅开放给ES王英、刘建

#### 8.1.2 包含页面

本模块只有1个页面，通过顶部Tab标签页切换：

| 页面 / Tab 标签 | 功能说明 |
|-----------------|----------|
| 账套内容维护 | 管理财务账套的基本信息 |

---

### 8.2 账套内容维护页面

#### 8.2.1 页面功能

管理企业的财务账套信息，定义每个账套的名称、所属公司、所属板块等基本属性。账套名称全局唯一。

---

#### 8.2.2 查询列表页

##### 8.2.2.1 查询条件及表格

查询条件默认状态：展开显示所有搜索条件

排序：以序号为依据，按编号从小到大排列

分页：每页默认10条，支持切换每页条数

字段说明：

| 字段名称 | 是否查询条件 | 查询条件控件类型 | 提示文案 | 说明 |
|----------|:----------:|:--------------:|----------|------|
| 序号 | N | - | - | 自动编号 |
| 公司 | Y | Input | 请输入公司 | 查询条件：支持模糊检索；表格展示：所属公司代码 |
| 板块 | Y | Input | 请输入板块 | 查询条件：支持模糊检索；表格展示：所属板块代码 |
| 账套名称 | N | - | - | 账套编码，全局唯一 |
| 标签名中文 | N | - | - | 账套的中文标签名称 |
| 标签名英文 | N | - | - | 账套的英文标签名称 |
| 操作 | N | - | - | “编辑”蓝色链接按钮，点击打开编辑弹窗 |

按钮：
- 查询：蓝色主按钮，点击后根据条件筛选数据
- 重置：灰色按钮，点击后清空所有搜索条件

---

##### 8.2.2.2 操作栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增弹窗 |
| 删除 | 红色按钮 | 删除选中的记录（需先勾选） |

---

#### 8.2.3 新增/编辑弹窗

##### 8.2.3.1 弹窗标题

- 新增时：标题为新增账套内容
- 编辑时：标题为编辑账套内容

##### 8.2.3.2 表单字段

| 字段名 | 新增弹窗组件类型 | 编辑弹窗组件类型 | 是否必填 | 枚举值/格式 | 说明 |
|--------|:--------------:|:--------------:|:--------:|------------|------|
| 公司 | SelectModal弹窗选择 | 文本只读 | Y | - | 点击输入框唤起弹窗选择公司，编辑时只读展示 |
| 板块 | SelectModal弹窗选择 | 文本只读 | Y | - | 点击输入框唤起弹窗选择板块，编辑时只读展示 |
| 账套名称 | 文本输入框 | 文本只读 | Y | - | 账套编码全局唯一，新增提交后不可修改 |
| 标签名中文 | 文本输入框 | 文本输入框 | N | - | 账套的中文标签名称 |
| 标签名英文 | 文本输入框 | 文本输入框 | N | - | 账套的英文标签名称 |

按钮：
- 保存：蓝色主按钮，保存数据，关闭弹窗
- 返回：灰色按钮，取消操作，关闭弹窗

---

##### 8.2.3.3 校验规则

点击保存按钮时进行以下校验，校验通过保存数据，不通过则拦截操作。

| 校验规则 | 校验项 | 错误提示 |
|----------|--------|----------|
| 必填字段合法性 | 公司、板块、账套名称 | 请输入XX / 请选择XX |
| 账套名称唯一性 | 账套名称 | 该账套名称已存在 |
