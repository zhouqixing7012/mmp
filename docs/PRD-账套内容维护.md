## 一、模块概述

### 1.1 模块定位

"账套内容维护"模块用于管理财务账套的基本信息，包括账套名称、所属公司、所属板块等，是财务系统的基础配置。

### 1.2 包含页面

本模块只有1个页面：**账套内容维护**

---

## 二、页面：账套内容维护

### 2.1 页面功能

管理企业的财务账套信息，定义每个账套的名称、所属公司、所属板块等基本属性。

### 2.2 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  [Tab: 账套内容维护]                                         │
├─────────────────────────────────────────────────────────────┤
│  搜索条件区域                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 公司: [________________]                              │  │
│  │ 板块: [________________]                              │  │
│  │                                    [查询] [重置]      │  │
│  └───────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  工具栏: [新增] [删除]                                      │
├─────────────────────────────────────────────────────────────┤
│  数据表格                                                    │
│  ☐ │序号│公司│板块│账套名称│账套名称中文│账套名称英文│操作│  │
│  ☐ │ 1  │搜狐干线│SAAS│搜狐干线│搜狐干线│FOCUS XinGanXian│编辑│

```

### 2.3 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 公司 | 文本输入框 | 支持模糊搜索，如输入"搜狐" |
| 板块 | 文本输入框 | 支持模糊搜索，如输入"SAAS" |

### 2.4 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 用于批量选择 |
| 序号 | 自动编号 |
| 公司 | 所属公司代码，如：搜狐干线 |
| 板块 | 所属板块代码，如：SAAS |
| 账套名称 | 账套编码，如：搜狐干线 |
| 账套名称中文 | 账套的中文名称，如：搜狐干线 |
| 账套名称英文 | 账套的英文名称，如：FOCUS XinGanXian |
| 操作 | 编辑按钮 |

### 2.5 工具栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增弹窗 |
| 删除 | 红色按钮 | 删除选中的记录（需先勾选） |

### 2.6 新增/编辑弹窗

#### 弹窗标题
- 新增时：标题为"新增账套"
- 编辑时：标题为"编辑账套"

#### 表单字段布局

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 公司*（文本输入） | 板块*（文本输入） |
| 第2行 | 账套名称*（文本输入） | 账套名称中文（文本输入） |
| 第3行 | 账套名称英文（文本输入） | （空） |

#### 字段详细说明

**公司（必填）**：
- 控件类型：文本输入框
- 格式：公司代码，如：搜狐干线
- 说明：账套所属的公司

**板块（必填）**：
- 控件类型：文本输入框
- 格式：板块代码，如：SAAS
- 说明：账套所属的业务板块

**账套名称（必填）**：
- 控件类型：文本输入框
- 格式：账套编码，如：搜狐干线
- 说明：账套的唯一标识

**账套名称中文（选填）**：
- 控件类型：文本输入框
- 格式：中文名称，如：搜狐干线
- 说明：账套的中文描述

**账套名称英文（选填）**：
- 控件类型：文本输入框
- 格式：英文名称，如：FOCUS XinGanXian
- 说明：账套的英文描述

#### 弹窗按钮

| 按钮 | 样式 | 功能 |
|------|------|------|
| 保存 | 蓝色主按钮 | 保存数据，关闭弹窗 |
| 返回 | 灰色按钮 | 取消操作，关闭弹窗 |

### 2.7 校验规则

| 字段 | 校验规则 | 错误提示 |
|------|----------|----------|
| 公司 | 必填 | "请输入公司" |
| 板块 | 必填 | "请输入板块" |
| 账套名称 | 必填 | "请输入账套名称" |
| 账套名称 | 唯一性校验 | "该账套名称已存在" |
| 组合唯一性 | 公司+板块+账套名称不能重复 | "该组合已存在" |
