## 十二、字典管理

---

### 12.1 模块说明

#### 12.1.1 模块定位

“字典管理”模块用于管理系统中的字典数据和字典项数据。字典是系统中各下拉选择框、枚举值的数据来源，支持按字典编码和字典名称检索。

权限：所有涉及字典编辑、修改的权限，目前仅开放给系统管理员

#### 12.1.2 包含页面

本模块只有1个页面，但包含两级视图：字典列表视图和字典项列表视图（点击管理按钮进入）。

| 页面 / 视图 | 功能说明 |
|-------------|----------|
| 字典列表 | 管理所有字典条目，支持新增字典 |
| 字典项列表 | 管理选定字典下的字典项，支持新增/启用/停用字典项 |

---

### 12.2 字典列表

#### 12.2.1 页面功能

展示系统所有字典的列表，支持按字典编码和字典名称检索。点击管理按钮可进入该字典的字典项列表页面。

---

#### 12.2.2 查询列表页

##### 12.2.2.1 查询条件及表格

查询条件默认状态：展开显示所有搜索条件

排序：以编号为依据，按编号从小到大排列

分页：每页默认10条，支持快捷跳页

字段说明：

| 字段名称 | 是否查询条件 | 查询条件控件类型 | 提示文案 | 说明 |
|----------|:----------:|:--------------:|----------|------|
| 字典编码 | Y | Input | 请输入字典编码 | 查询条件：支持模糊检索；表格展示：字典编码 |
| 字典名称 | Y | Input | 请输入字典名称 | 查询条件：支持模糊检索；表格展示：字典名称 |
| 描述 | N | - | - | 字典的描述信息 |
| 字典明细 | N | - | - | 管理蓝色链接按钮，点击进入该字典的字典项列表 |

按钮：
- 查询：蓝色主按钮，点击后根据条件筛选数据

##### 12.2.2.2 操作栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增字典弹窗 |

---

#### 12.2.3 新增字典弹窗

##### 12.2.3.1 弹窗标题

- 弹窗标题为字典-新增

##### 12.2.3.2 表单字段

| 字段名 | 新增弹窗组件类型 | 是否必填 | 枚举值/格式 | 说明 |
|--------|:--------------:|:--------:|------------|------|
| 字典编码 | 文本输入框 | Y | - | 字典的唯一编码 |
| 字典名称 | 文本输入框 | Y | - | 字典的名称 |
| 描述 | 文本域（TextArea） | N | - | 字典的描述信息 |

按钮：
- 保存：蓝色主按钮，保存数据，关闭弹窗
- 返回：灰色按钮，取消操作，关闭弹窗

##### 12.2.3.3 校验规则

点击保存按钮时进行以下校验，校验通过保存数据，不通过则拦截操作。

| 校验规则 | 校验项 | 错误提示 |
|----------|--------|----------|
| 必填字段合法性 | 字典编码、字典名称 | 请输入字典编码 / 请输入字典名称 |
| 字典编码唯一性 | 字典编码 | 该字典编码已存在 |

---

### 12.3 字典项列表

#### 12.3.1 页面功能

展示指定字典下的字典项列表，支持按字典编码、字典名称、字典项编码、字典项名称检索。支持新增字典项、启用/停用字典项。

点击左上角返回按钮可回到字典列表。

---

#### 12.3.2 查询列表页

##### 12.3.2.1 查询条件及表格

查询条件默认状态：展开显示所有搜索条件

排序：以编号为依据，按编号从小到大排列

分页：每页默认10条，支持快捷跳页

字段说明：

| 字段名称 | 是否查询条件 | 查询条件控件类型 | 提示文案 | 说明 |
|----------|:----------:|:--------------:|----------|------|
| 字典项编码 | Y | Input | 请输入字典项编码 | 查询条件：支持模糊检索；表格展示：字典项编码 |
| 字典项名称 | Y | Input | 请输入字典项名称 | 查询条件：支持模糊检索；表格展示：字典项名称 |
| 字典编码 | Y | Input | 请输入字典编码 | 查询条件：支持模糊检索；表格展示：所属字典编码 |
| 字典名称 | Y | Input | 请输入字典名称 | 查询条件：支持模糊检索；表格展示：所属字典名称 |
| 查询类型 | Y | Select | 全部 | 查询条件：下拉选择查询类型 |
| 描述 | N | - | - | 字典项的描述信息 |
| 状态 | N | - | - | 启用（绿色标签）/ 停用（默认标签） |

按钮：
- 查询：蓝色主按钮，点击后根据条件筛选数据

##### 12.3.2.2 操作栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增字典项弹窗 |
| 启用 | 绿色文字按钮 | 启用选中的字典项（需先勾选） |
| 停用 | 红色文字按钮 | 停用选中的字典项（需先勾选） |
| 返回 | 灰色按钮 | 返回字典列表 |

---

#### 12.3.3 新增字典项弹窗

##### 12.3.3.1 弹窗标题

- 弹窗标题为字典项-新增

##### 12.3.3.2 表单字段

| 字段名 | 新增弹窗组件类型 | 是否必填 | 枚举值/格式 | 说明 |
|--------|:--------------:|:--------:|------------|------|
| 字典编码 | 文本输入框（disabled） | Y | - | 当前字典的编码，自动带出不可修改 |
| 字典名称 | 文本输入框（disabled） | Y | - | 当前字典的名称，自动带出不可修改 |
| 字典项编码 | 文本输入框 | Y | - | 字典项的唯一编码 |
| 字典项名称 | 文本输入框 | Y | - | 字典项的名称 |
| 字典优先级 | InputNumber | N | 非负整数 | 字典项的排序优先级 |
| 状态 | Select下拉选择 | N | 启用、停用 | 默认：启用 |
| 描述 | 文本域（TextArea） | N | - | 字典项的描述信息 |

按钮：
- 保存：蓝色主按钮，保存数据，关闭弹窗
- 返回：灰色按钮，取消操作，关闭弹窗

##### 12.3.3.3 校验规则

点击保存按钮时进行以下校验，校验通过保存数据，不通过则拦截操作。

| 校验规则 | 校验项 | 错误提示 |
|----------|--------|----------|
| 必填字段合法性 | 字典项编码、字典项名称 | 请输入字典项编码 / 请输入字典项名称 |
| 字典项编码唯一性 | 字典项编码（同一字典下） | 该字典项编码已存在 |
