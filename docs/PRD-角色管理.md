## 11.1 模块概述

### 11.1.1 模块定位

"角色管理"是企业管理系统的系统配置模块，用于管理系统的角色定义、用户关联及菜单权限分配。每个角色包含角色名称、职责描述，可与多个用户关联，并为角色分配菜单功能权限。

权限：所有涉及角色编辑、修改的权限，目前仅开放给系统管理员

### 11.1.2 包含页面

本模块包含1个主页面：

| 页面 | 功能说明 |
|------|----------|
| 角色管理 | 角色列表的增删改查，关联用户，菜单权限分配 |

## 11.2 页面功能

### 11.2.1 主页面

#### 11.2.1.1 查询条件及表格

**字段说明**：

| 字段名称 | 是否查询条件 | 查询条件控件类型 | 提示文案 | 说明 |
|----------|:----------:|:--------------:|----------|------|
| 角色名称 | Y | Input | 请输入角色名称 | 支持模糊检索 |
| 是否启用 | Y | Select | 请选择 | 枚举值：全部、启用、停用 |

**按钮**：
- **查询**：蓝色主按钮，点击后根据条件筛选数据

#### 11.2.1.2 操作栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增角色弹窗 |
| 启用 | 绿色文字按钮 | 启用选中的角色（需先勾选） |
| 停用 | 红色文字按钮 | 停用选中的角色（需先勾选） |

#### 11.2.1.3 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 角色名称 | 角色名称，如"系统管理员" |
| 职责 | 角色职责描述 |
| 关联用户 | 已关联的用户列表（逗号分隔），右侧"关联"蓝色链接按钮 |
| 菜单权限 | 已分配的菜单名称列表（逗号分隔），右侧"分配"蓝色链接按钮 |
| 状态 | 启用（绿色标签）/ 停用（红色标签） |

## 11.3 新增/编辑角色弹窗

### 11.3.1 弹窗标题

- 新增时：标题为"新增角色"
- 编辑时：标题为"编辑角色"

### 11.3.2 表单字段布局

| 字段名 | 组件类型 | 编辑是否只读 | 必填 | 说明 |
|--------|:-------:|:----------:|:----:|------|
| 角色名称 | 文本输入框 | N | Y | 手动输入角色名称 |
| 状态 | 下拉选择框 | N | N | 枚举值：启用、停用，默认：启用 |
| 职责 | 多行文本输入框 | N | N | 输入角色职责描述 |

### 11.3.3 校验规则

| 校验规则 | 校验项 | 错误提示 |
|----------|--------|----------|
| 必填字段合法性 | 角色名称 | "请输入角色名称" |

## 11.4 关联用户弹窗

### 11.4.1 触发方式

点击角色表格中的"关联"按钮，打开关联用户弹窗。弹窗标题：`关联用户 - {角色名称}`

### 11.4.2 页面功能

选择一个或多个用户关联到当前角色。弹窗内包含搜索条件、用户表格、分页和底部按钮。

### 11.4.3 查询条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 工号 | 文本输入框 | 支持模糊搜索 |
| 姓名 | 文本输入框 | 支持模糊搜索 |
| 部门 | 文本输入框 | 支持模糊搜索 |

### 11.4.4 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 工号 | 员工工号 |
| 姓名 | 员工姓名 |
| 部门 | 所属部门 |

### 11.4.5 交互说明

- 表格支持全选/取消全选（表头复选框）
- 已关联用户默认选中
- 支持多选，底部显示"已选 X 人"
- 分页：每页5条，支持上一页/下一页

**底部按钮**：
- **确定**：蓝色主按钮，保存关联用户
- **取消**：灰色按钮，放弃修改

## 11.5 菜单权限分配页面

### 11.5.1 触发方式

点击角色表格中的"分配"按钮，页面切换至菜单权限分配视图。

### 11.5.2 页面功能

为选定角色分配菜单功能权限。页面顶部显示一级菜单 Tab 导航，内容区按二级/三级菜单展示功能点复选框。

### 11.5.3 一级菜单导航

一级菜单 Tab 栏（按顺序）：

| Tab 名称 | 说明 |
|----------|------|
| 资产总览 | - |
| 资产分类 | 资产分类管理（资产类别、资产型号） |
| 资产采购 | 资产入库管理（采购申请、入库登记、供应商管理） |
| 资产领用 | 资产领用管理（领用申请、领用登记、归还管理） |
| 资产盘点 | 资产盘点管理（盘点计划、盘点执行、盘点差异） |
| 资产维修 | 资产维修管理（维修申请、维修记录、维修供应商） |
| 资产报废 | 资产报废管理（报废申请、报废处理、报废记录） |
| 资产报表 | 资产报表管理（资产台账、资产统计、资产分析） |
| 系统设置 | 系统设置（用户管理、角色管理、权限配置） |

### 11.5.4 权限表格

| 列名 | 说明 |
|------|------|
| 二级菜单 | 所属二级菜单名称 |
| 三级菜单 | 所属三级菜单名称 |
| 功能点 | 该菜单下可勾选的功能权限复选框列表 |

### 11.5.5 交互说明

- 每个功能点为独立复选框，可单独勾选/取消
- 每行左侧有一个行全选复选框，可勾选该行所有功能点
- 页面顶部有"全选"复选框，可勾选当前一级菜单下的所有功能点
- 已选功能点文字高亮为蓝色（`#1677ff`）

**底部按钮**：
- **确定**：蓝色主按钮，保存权限分配
- **取消**：灰色按钮，放弃修改

## 11.6 通用交互说明

### 11.6.1 批量操作

1. 勾选需要操作的角色记录
2. 点击工具栏的"启用"或"停用"按钮，弹出确认弹窗："确定要启用/停用选中的X条记录吗？"

### 11.6.2 查询流程

1. 在搜索条件区域输入筛选条件
2. 点击"查询"按钮，表格显示符合筛选条件的数据
3. 点击"重置"按钮，清空所有搜索条件，显示全部数据

### 11.6.3 新增/编辑流程

1. 点击工具栏"新增"按钮或表格"编辑"按钮，弹出弹窗
2. 填写/修改表单字段（必填字段标红色星号*）
3. 点击"保存"按钮，保存成功，关闭弹窗，刷新列表
4. 校验失败则显示错误提示，不关闭弹窗
