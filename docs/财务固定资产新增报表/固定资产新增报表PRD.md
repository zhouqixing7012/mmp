# 固定资产新增报表需求

## 一、背景

财务需要按公司、板块及启用日期查询固定资产新增记录，并每月通过服务号接收当期报表。入口为“资产报表 → 固定资产新增报表”，与已有“资产新增报表”分别使用。

## 二、需求详情

### 1. 查询页面

页面为只读查询列表，支持查询、重置、分页和导出。财务人员按获授权的公司范围查询和导出，具体人员及公司授权范围见待确认事项。

| 查询条件 | 交互及取值 |
|---|---|
| 公司 | 下拉框多选，可搜索、清空，候选数据与资产明细报表的公司查询条件共用同一来源；默认空，表示全部获授权公司。 |
| 板块 | 下拉框多选，可搜索、清空，候选数据与资产维护的板块查询条件共用同一来源；默认空，按所选板块编码筛选。 |
| 启用日期 | 一个日期范围选择器，格式YYYY-MM-DD；默认空，可填写单端，包含所选开始和结束自然日。 |

| 操作 | 规则及结果 |
|---|---|
| 查询 | 公司、板块与日期条件同时满足；同一多选条件内满足任一项。点击后刷新列表并回到第一页；开始日期晚于结束日期时提示“启用日期的开始日期不能晚于结束日期”，保留上次查询结果。 |
| 重置 | 清空公司、板块及启用日期条件，重新查询全部获授权记录，回到第一页。 |
| 分页 | 支持翻页和切换每页条数；页面不另外展示记录条数。 |
| 导出 | 导出最近一次已执行查询的全部结果，不受当前页限制；尚未点击查询的条件不影响导出。一个Excel文件按公司分别放在不同Sheet中，字段按附件原13列顺序，不增加公司、板块列，以Sheet名称区分。公司无明细时保留表头及数量、金额均为0的合计行。 |
| 合计 | 在查询结果区右上角展示全部查询结果的数量、原值、税金、含税金额合计，随查询及重置刷新，不受分页影响；不把附件中的Total行当作明细，不重复汇总。 |
| 无结果 | 展示“暂无数据”。 |

列表前两列为公司、板块，之后按附件原13列顺序展示，共15列，字段均只读；手动导出及服务号自动发送的Excel使用附件原13列。

| 字段 | 取值及显示 |
|---|---|
| 公司 | 对应新增记录的公司；正式公司名称与附件Sheet的对应关系见待确认事项。 |
| 板块 | 对应资产所属板块，显示“编码.名称”；按编码筛选。 |
| PO单号 | 对应新增记录的PO单号或自购标识，按原值展示。 |
| 资产大类 | 对应新增记录的资产大类。 |
| 资产说明 | 对应新增记录的资产说明。 |
| 配置 | 对应新增记录的配置，完整显示，允许换行。 |
| 数量 | 对应新增记录的数量，整数展示。 |
| 原值 | 对应新增记录的原值，千分位、两位小数。 |
| 税金 | 对应新增记录的税金，千分位、两位小数。 |
| 含税金额 | 对应新增记录的含税金额，千分位、两位小数。 |
| 启用日期 | 对应新增记录的启用日期，YYYY-MM-DD；查询及月度归属均使用该日期。 |
| 使用说明 | 对应新增记录的使用说明，完整显示，允许换行。 |
| PR单号 | 对应新增记录的PR单号，文本展示。 |
| 资产标签号 | 对应新增记录的资产标签号，文本展示，保留前导零。 |
| 服务 | 对应新增记录的服务字段；含义及取值来源见待确认事项。 |

未提供的字段值留空，已有0值按数字展示；公司、板块用于系统筛选及列表展示，Excel中不重复增加这两列。每个公司Sheet末尾提供Total行，汇总数量、原值、税金、含税金额，其余字段留空。

### 2. 月度服务号通知

| 项目 | 规则 |
|---|---|
| 发送日期及时间 | 每月26日早上10:00，北京时间。 |
| 统计期间 | 当月1日至25日，含起止日；按启用日期归属。 |
| 接收对象 | 财务接收人，具体名单及可接收公司范围待确认。 |
| 报表组织 | 合并为一个Excel文件，按公司分别放在不同Sheet，形式与附件一致。 |
| 报表内容 | 使用附件原13个字段及各公司Total行，公司、板块不额外成列，限定在接收人获授权的公司范围。 |

### 3. 待确认事项

| 事项 | 需要明确的内容 |
|---|---|
| 接收人及权限 | 具体财务人员、各人可查看/接收的公司范围；不同权限范围的接收人是否分开发送文件。 |
| 公司对应关系 | 附件各Sheet名称与系统财务公司的对应关系。 |
| 新增记录口径 | 新增记录的纳入条件及取值时点；是否与已有资产新增报表的已完成入库范围一致。 |
| 板块取值 | 附件没有板块字段，需补充两条样本的板块归属及正式资产板块来源；不按使用说明中的部门文字推断。 |
| 服务字段 | 业务含义、取值来源及格式。 |
| 通知呈现方式 | 在服务号中如何获取Excel文件。 |
| 特殊发送结果 | 全部公司均无新增记录、生成或发送失败时的处理方式。 |
