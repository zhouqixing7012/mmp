# 固定资产新增报表PRD

## 1. 背景

财务按公司、板块及启用日期核对固定资产新增记录，并每月通过服务号接收报表。入口为“资产报表 → 固定资产新增报表”，与“资产新增报表”分别使用。本功能包括只读查询、分页、合计、Excel导出及月度通知，不提供入库办理、资产维护或补发操作。

## 2. 权限

| 角色 | 数据范围 | 操作与限制 |
| --- | --- | --- |
| 许丽、冯丽婷、张洁 | 三人范围相同：其他公司资产，以及新媒体上海、新媒体广州的视频板块资产；排除这两家公司的非视频资产 | 查询、导出及通过服务号下载同一范围的报表；查询条件只能进一步缩小范围，不能扩大权限。 |
| ERP-周琦星 | 本报表生成或发送失败的信息 | 接收失败通知；失败通知不授予额外财务明细查看权限。 |

权限按公司与板块组合判断，查询、合计、导出、月度统计及消息下载使用同一范围。新媒体上海对应115.新媒体-上海，新媒体广州对应116.新媒体-广州，视频板块为16.视频；这两家公司仅包含视频资产，其他公司不因视频板块而被排除。三人查看、导出和下载范围完全相同；不因发送对象不同改变报表范围。

## 3. 通用规则

| 规则 | 业务要求 |
| --- | --- |
| 来源及粒度 | 已完成的新增入库单和采购接收入库单明细，每行对应一个资产标签号。 |
| 历史时点 | 所有字段取入库完成时保存的信息；后续卡片、组织及基础资料变化不改写该记录。 |
| 统计日期 | 查询、手动导出及月度发送使用同一来源，按入库完成记录中的启用日期筛选和归属期间。 |
| 条件组合 | 查询条件均非必填、初始为空；不同条件同时满足，同一多选内命中任一项；日期允许单端，包含起止自然日。 |
| 空值 | 未提供的值留空，真实0值按数字展示；不根据部门名称推断板块。 |
| 编号 | 编码及单号按文本保留前导零，列表与导出保持一致。 |

## 4. 页面字段及交互

### 查询条件

| 查询条件 | 交互及取值 |
|---|---|
| 公司 | 下拉框多选，可搜索、清空，基础资料与资产明细报表共用；候选限本报表授权范围，未选择时查询全部获授权公司。选择新媒体上海或新媒体广州时仍仅包含其视频板块。 |
| 板块 | 下拉框多选，可搜索、清空，候选数据与资产维护的板块查询条件共用同一来源；按所选板块编码筛选。 |
| 启用日期 | 一个日期范围选择器，格式YYYY-MM-DD；可填写单端，包含所选开始和结束自然日。 |

### 查询结果

列表前两列为公司、板块，之后为下表其余13列。所有字段只读；手动导出和服务号文件只使用后13列，不增加公司、板块列。

| 字段 | 取值及显示 |
|---|---|
| 公司 | 对应入库快照中的财务公司；英文Sheet名按2026-10-20提供的公司及板块范围映射使用。 |
| 板块 | 入库快照中的资产所属板块，显示“编码.名称”；按编码筛选。 |
| PO单号 | 对应新增记录的PO单号或自购标识，按原值展示。 |
| 资产大类 | 对应新增记录的资产大类。 |
| 资产说明 | 对应新增记录的资产说明。 |
| 配置 | 对应新增记录的配置，完整显示，允许换行。 |
| 数量 | 对应新增记录的数量，整数展示。 |
| 原值 | 对应新增记录的原值，千分位、两位小数。 |
| 税金 | 对应新增记录的税金，千分位、两位小数。 |
| 含税金额 | 对应新增记录的含税金额，千分位、两位小数。 |
| 启用日期 | 对应新增记录的启用日期，YYYY-MM-DD；查询及月度归属均使用该日期。 |
| 使用说明 | 对应新增记录的使用说明，完整显示，允许换行。 |
| PR单号 | 对应新增记录的PR单号，文本展示。 |
| 资产标签号 | 对应新增记录的资产标签号，文本展示，保留前导零。 |
| 服务 | 入库快照中的NO服务名称，文本展示。 |

### 页面操作与汇总

| 操作或区域 | 触发条件 | 规则与结果 |
| --- | --- | --- |
| 查询 | 有查看权限且查询条件有效 | 点击查询按输入条件刷新结果，回第一页；公司、板块、日期共同限制范围。 |
| 重置 | 有查看权限 | 清空三个查询条件，重新查询全部获授权记录，回第一页。 |
| 分页 | 有查询结果 | 翻页或切换每页条数保留条件；页面不另外展示记录条数。 |
| 导出 | 有导出权限且最近一次查询成功 | 导出最近一次已执行查询的全部结果，不限当前页；未查询的新输入不影响导出。生成一个Excel，按公司及板块映射拆分Sheet。 |
| 合计 | 查询或重置成功 | 查询结果区展示全部匹配记录的数量、原值、税金、含税金额合计，不受分页影响。 |
| 无结果 | 成功查询后无匹配记录 | 展示“暂无数据”，不将读取失败显示为无数据。 |

### 公司、板块与Excel

采用[账套及财务映射原件](../source/账套内容维护20261020(1).xlsx)右侧提供的财务公司、板块及英文名对应关系，详见[映射明细](账套及报表映射确认-20261020.md)。英文名用于报表Sheet名称；账套维护中的标签名英文仅用于标签，不混用。

同一公司可按板块范围对应不同Sheet；一个Sheet可对应多个板块，明细按快照中的公司与具体板块归入对应Sheet，仅计入一次。查询公司覆盖该公司已配置的各Sheet，叠加板块条件时限定在对应范围。未提供具体板块的历史样例不推断，列表留空，按具体板块查询不计入。

映射共13个英文Sheet名，包含新增的ENTMT GZ；无明细时保留表头及零合计。历史记录保留原有业务明细，不根据公司及板块映射生成资产记录。

每个Sheet按规定13列顺序输出，以Sheet名称区分公司及板块，不重复增加公司、板块列。末尾Total行汇总数量、原值、税金、含税金额，其余列留空。数量用整数，金额用千分位、两位小数。无明细的有效Sheet仍保留表头和零合计。Total不是明细，不纳入列表或二次汇总。

## 5. 校验

| 触发时机 | 判断条件 | 处理及提示 |
| --- | --- | --- |
| 查询 | 启用日期开始晚于结束 | 阻止查询，提示“启用日期的开始日期不能晚于结束日期”，保留上次结果，修改后可查询。 |
| 查询、合计、导出、月度统计及文件下载 | 记录不属于获授权的公司与板块组合 | 排除该记录；不得因选择公司或清空板块而包含新媒体上海、新媒体广州的非视频资产。无对应权限时提示“无权查看该公司报表”。 |
| 查询 | 报表读取失败 | 提示“查询失败，请重试”，保留条件及上次成功结果，不能将旧结果标成新结果。 |
| 手动导出或下载 | 文件生成或下载失败 | 提示“导出或下载失败，请重试”，保留查询结果，不提示成功。 |
| 月度生成或发送 | 报表生成或消息发送失败 | 通知ERP-周琦星，标明统计期间及失败环节；不将失败记成发送成功，不安排补发。 |

## 6. 后续操作 / 业务结果 / 补充说明

### 月度服务号消息

| 场景 | 业务结果 |
| --- | --- |
| 定时发送 | 每月26日早上10:00（北京时间），统计当月1日至25日（含起止日）启用的新增记录，发送给许丽、冯丽婷、张洁，三人使用第2章同一授权范围。 |
| 有新增记录 | 服务号发送报表生成完成消息，内容包含文件名及下载说明，提供“查看详情”入口；点击后下载获授权范围的Excel。 |
| 全部无新增记录 | 服务号通知文案为“本月无新增”，不把空结果当成生成或发送失败。 |
| 生成或发送失败 | 通知ERP-周琦星；本功能不提供补发流程。 |

查询、手动导出及消息下载不修改来源单据和资产信息。月度通知只承载本报表，不新增另一种“财务月报”功能。
