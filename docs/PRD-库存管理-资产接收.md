# 库存管理 - 资产接收

## 当前实现口径

### PO 列表

- 操作列固定同时展示“接收 / 查看”。
- 点击 PO 单号或“接收”进入 PO 单详情。
- 点击“查看”进入该 PO 的接收单列表。
- 电子设备 PO 详情通过“创建接收单”进入普通资产接收流程。
- 服务器、服务器备件、网络设备、网络设备备件不再使用“执行入库”文案，统一使用“接收确认”。
- PO 接收状态固定为：**待接收 / 已接收 / 已入库**。
- PO 状态按整张 PO 的累计数量判断，而不是按是否点击过接收按钮判断：
  - 任一 PO 行仍存在未接收数量时，PO 保持“待接收”。
  - 全部 PO 行累计已接收数量达到采购数量后，PO 变为“已接收”。
  - 全部 PO 行后续完成入库后，PO 变为“已入库”。
- 部分接收不能提前把整张 PO 更新为“已接收”。

### PO 单详情

- 如果当前 PO 已经存在接收单，页面底部展示“查看接收单”，点击进入当前 PO 的接收单列表。
- “创建接收单”和机房资产“接收确认”都必须先勾选需要处理的 PO 物资明细行，因此按钮放在“PO物资明细”Card 右上角，与选择对象保持同一操作上下文。
- 电子设备点击“创建接收单”后生成**草稿接收单**并直接进入新接收单详情页。
- 创建草稿接收单后，当前接收数量立即计入对应 PO 行的“草稿数量”，占用 PO 可接收数量。
- 可接收数量固定按以下公式计算：

```text
可接收数量 = 采购数量 - 已接收数量 - 草稿数量
```

- 删除草稿接收行、删除拆分后的接收资产明细、删除草稿接收单或取消接收时，必须同步释放对应草稿占用数量。
- 服务器、服务器备件、网络设备、网络设备备件点击“接收确认”后，直接针对勾选行生成：**已完成接收单 + 草稿采购接收入库单**。
- 机房资产接收确认后只累计本次勾选行的接收数量；只有整张 PO 全部接收完成后，PO 才变为“已接收”。
- “板块”按当前选择结果随接收单保存，并继续传递到后续入库单。
- “申请批次”为**非必填**字段；有值时随接收单保存，并继续传递到后续采购接收入库单及入库物资明细。

#### PO 物资“编辑”弹窗

资产接收 PO 详情的编辑交互与耗材接收保持一致，字段和规则统一为：

- 物料：通过选择物料维护。
- 配置：可编辑。
- 接收数量：大于 0 的整数，且不能超过当前剩余可接收数量。
- 是否部件：是 / 否。
- 部件数量：选择“是”时必须为大于 0 的整数。
- 部件描述：选择“是”时可维护。

编辑结果保存后作为后续创建接收单或机房资产接收确认的实际数据来源。

### 接收单列表

- “制单时间”使用一个日期范围查询条件。
- 列表不保留仅用于查看的操作列，点击接收单号进入详情。
- 接收单状态只保留：**草稿 / 已完成**。
- 电子设备通过“创建接收单”生成的单据状态为“草稿”。
- 机房资产通过 PO 详情“接收确认”生成的接收单直接为“已完成”。
- 只有草稿接收单允许勾选删除；已完成接收单不可删除。
- 删除草稿接收单时，接收单作废并释放该单占用的全部 PO 草稿数量。

### 接收单详情

- 接收物资明细支持勾选，勾选只用于“删除接收行”等行级操作。
- 接收单详情页不提供导入功能。
- 普通电子设备接收单的“维护接收明细”是页面级操作，不依赖接收物资行勾选；进入后针对当前接收单的全部接收物资，按每行“本次接收数量”拆成一台资产一条接收明细进行维护。
- 草稿状态底部提供“维护接收明细 / 取消接收 / 接收确认 / 返回”；已完成状态只允许查看接收明细和返回。
- “取消接收”固定含义为：**作废当前草稿接收单，并释放该草稿占用的全部 PO 可接收数量**。
- 机房资产 PO 直接生成的接收单已经完成，不再进入普通标签号/SN维护链路。
- 接收单区分两组时间与人员：
  - 制单人 / 制单时间：创建草稿接收单时记录。
  - 接收人 / 接收时间：点击“接收确认”成功时记录；草稿阶段为空。

### 接收单明细

接收资产明细字段：资产标签号、SN号、物资总类、资产大类、物资说明、配置、部件数量、部件说明、资产数量、不含税单价、税金、PR单/行号、SA单/行号、申请人、业务线、资产标记、备注、操作。

#### 拆行与数量回写规则

- 不再按接收物资行单独进入维护。
- 进入“维护接收明细”后，系统读取当前接收单全部接收物资。
- 每个接收物资行按照“本次接收数量”拆分明细，例如本次接收数量为 3，则生成 3 条资产接收明细。
- 一条拆分明细代表 1 台资产。
- 删除拆分后的某一条资产明细时，不只是删除展示行，还必须同步将对应接收行的“本次接收数量”减 1，并向 PO 释放 1 个草稿占用数量。
- 删除到某接收行数量为 0 时，该接收行从当前草稿接收单中移除。

#### 状态与按钮

- 不再提供“合并行”。
- 只有接收单状态为“草稿”时展示“删除行 / 生成标签号 / 维护SN号”。
- 接收单状态为“已完成”后不展示上述修改类按钮。
- “删除行”只删除当前勾选的接收明细行，并按上述规则同步回写数量、释放 PO 占用。
- “生成标签号”不依赖勾选，一次给当前全部接收明细生成资产标签号；生成完成后按钮消失。
- 标签号全部生成后展示“打印标签号”，打印作用于当前全部标签号。
- “维护SN号”不依赖勾选，但**只处理 SN 为空的明细**：将空白 SN 设置为“缺省”，已有真实 SN 不得被覆盖。
- 删除行、生成标签号、维护SN号、扫描写入SN执行成功后均实时保存并立即生效。

#### SN 规则

- SN 为空表示未维护，不允许接收确认。
- SN 为“缺省”视为已维护。
- “缺省”不参与 SN 唯一性冲突校验。
- 除“缺省”外的真实 SN 必须唯一；扫描写入、明细编辑保存、接收确认时都需要校验重复。
- 已有真实 SN 不允许被批量“维护SN号”覆盖为“缺省”。

#### 扫描维护

- 接收单明细页不再单独展示“扫描资产信息”分区，也不重复展示资产标签号、SN号、物资说明、配置四个字段。
- 生成标签号之前，扫描光标不可用。
- 生成标签号后，扫描光标连接扫码枪，也支持键盘手输并回车。
- 第一次扫描资产标签号：定位并筛选到对应接收明细行。
- 第二次扫描序列号条形码：校验真实 SN 不重复后，把该值写入刚定位资产的 SN 号，并立即保存。
- 完成一次 SN 赋值后重新等待扫描下一条资产标签号。
- 输入框 placeholder 根据当前阶段提示“请扫描资产标签号”或“已定位 xxx，请扫描SN号”，避免用户混淆两步扫描顺序。

### 接收确认

#### 普通电子设备接收单

- 点击“接收确认”前，系统校验当前接收单拆分出的全部资产接收明细。
- 每条明细必须同时有资产标签号和 SN 号；SN 号为“缺省”视为已维护，空值视为未维护。
- 所有非“缺省”的真实 SN 必须通过唯一性校验。
- 任意明细的资产标签号或 SN 号为空、或真实 SN 重复时，不允许接收确认。
- 校验通过后：
  1. 接收单状态由“草稿”更新为“已完成”。
  2. 记录当前操作人为接收人、当前时间为接收时间。
  3. 当前接收数量从 PO“草稿数量”转入“已接收数量”。
  4. 根据整张 PO 累计接收数量重新判断 PO 是“待接收”还是“已接收”。
  5. 生成一张状态为“草稿”的采购接收入库单。
  6. 将板块、申请批次和已维护的资产标签号/SN等接收结果传递到入库单及入库物资明细。

#### 机房资产 PO 直接接收

- 适用类型：服务器、服务器备件、网络设备、网络设备备件。
- 在 PO 物资明细勾选目标行后点击“接收确认”。
- 系统一次操作直接生成已完成接收单，同时生成状态为“草稿”的采购接收入库单。
- 本次只累计勾选行的接收数量；部分接收后整张 PO 继续保持“待接收”，全部接收完成后才变为“已接收”。
- 板块和非必填申请批次继续传入生成的草稿入库单。
- 生成的草稿入库单进入「库存管理 → 入库」列表，可继续编辑并执行入库。

### 明细信息维护弹窗

字段为：资产标签号、资产说明、SN号、资产标记、备注；资产标签号和资产说明只读，SN号、资产标记、备注可编辑；保留部件信息分区。

- 草稿状态保存后立即生效。
- 保存真实 SN 时必须校验重复。
- 已完成状态只读查看。
