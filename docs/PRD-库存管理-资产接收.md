# 库存管理 - 资产接收

## 当前实现口径

### PO 列表

- 操作列固定同时展示“接收 / 查看”。
- 点击 PO 单号或“接收”进入 PO 单详情。
- 点击“查看”进入该 PO 的接收单列表。
- 电子设备 PO 详情只显示“创建接收单”；服务器、服务器备件、网络设备、网络设备备件只显示“执行入库”。

### PO 单详情

- 如果当前 PO 已经存在接收单，页面底部展示“查看接收单”，点击进入当前 PO 的接收单列表。
- 创建接收单必须先勾选需要接收的 PO 物资行。
- 创建成功后直接进入新创建的接收单详情页，不停留在 PO 详情页。

### 接收单列表

- “制单时间”使用一个日期范围查询条件。
- 列表不保留仅用于查看的操作列，点击接收单号进入详情。

### 接收单详情

- 接收物资行支持勾选。
- 点击“维护接收明细”进入独立的接收单明细页。

### 接收单明细

接收资产明细字段：资产标签号、SN号、物资总类、资产大类、物资说明、配置、部件数量、部件说明、资产数量、不含税单价、税金、PR单/行号、SA单/行号、申请人、业务线、资产标记、备注、操作。

#### 状态与按钮

- 不再提供“合并行”。
- 只有接收单状态为“待接收”时展示“删除行 / 生成标签号 / 维护SN号”。
- 接收完成后不展示上述三个按钮。
- “删除行”只删除当前勾选的接收明细行。
- “生成标签号”不依赖勾选，一次给当前全部接收明细生成资产标签号；生成完成后按钮消失。
- 标签号全部生成后展示“打印标签号”，打印作用于当前全部标签号。
- “维护SN号”不依赖勾选，一次把当前全部接收明细的 SN 设为“缺省”；执行后按钮消失。

#### 扫描维护

- 接收单明细页不再单独展示“扫描资产信息”分区，也不重复展示资产标签号、SN号、物资说明、配置四个字段。
- 生成标签号之前，扫描光标不可用。
- 生成标签号后，扫描光标连接扫码枪，也支持键盘手输并回车。
- 第一次扫描资产标签号：定位并筛选到对应接收明细行。
- 第二次扫描序列号条形码：把该值写入刚定位资产的 SN 号。
- 完成一次 SN 赋值后重新等待扫描下一条资产标签号。
- 输入框 placeholder 根据当前阶段提示“请扫描资产标签号”或“已定位 xxx，请扫描SN号”，避免用户混淆两步扫描顺序。

### 明细信息维护弹窗

字段为：资产标签号、资产说明、SN号、资产标记、备注；资产标签号和资产说明只读，SN号、资产标记、备注可编辑；保留部件信息分区。
