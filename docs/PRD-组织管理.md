## 九、组织管理

---

### 9.1 模块说明

#### 9.1.1 模块定位

组织管理页面用于管理企业的组织结构，采用树形表格展示组织层级，支持展开/折叠查看、新增组织、启用/停用、批量操作、导出数据。

权限：所有涉及组织编辑、修改的权限，目前仅开放给系统管理员

#### 9.1.2 包含页面

本模块只有1个页面：

| 页面 / Tab 标签 | 功能说明 |
|-----------------|----------|
| 组织管理 | 树形表格展示组织层级，支持增删改查 |

---

### 9.2 组织管理页面

#### 9.2.1 页面功能

采用树形表格展示企业的组织层级，支持展开/折叠查看组织架构。支持新增组织、启用/停用组织、批量操作和导出数据。

---

#### 9.2.2 树形表格

排序：以序号为依据，按编号从小到大排列

分页：共 X 条记录（底部统计，不分页）

表格列（左到右）：

| 字段名称 | 是否查询条件 | 查询条件控件类型 | 提示文案 | 说明 |
|----------|:----------:|:--------------:|----------|------|
| 序号 | N | - | - | 自动编号 |
| 组织机构 | N | - | - | 带层级缩进，公司类型蓝色图标，部门类型黄色图标 |
| 架构图 | N | - | - | 图标按钮，点击查看架构图 |
| 组织类别 | N | - | - | 公司 / 部门 |
| 在职（直属/总共） | N | - | - | 直属人数 / 总人数 |
| 部门负责人 | N | - | - | 负责人姓名 |
| 部门编码 | N | - | - | 组织编码（如 D0001） |
| 状态 | N | - | - | 已启用（绿色标签）/ 已停用（灰色标签） |
| 操作 | N | - | - | “编辑”蓝色链接按钮，点击打开编辑弹窗 |

右侧控件：

| 控件名称 | 控件类型 | 功能说明 |
|----------|----------|----------|
| 展开1级 | 下拉选择框 | 控制树形表格展开级别 |
| 组织名称搜索 | 搜索框 | 输入关键字搜索组织 |
| 设置 | 灰色按钮 | 打开设置菜单 |

#### 9.2.3 操作栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增组织弹窗 |
| 导出 | 灰色按钮 | 导出组织数据 |
| 批量操作 | 灰色按钮 | 弹出批量操作菜单 |
| 启用 | 绿色文字按钮 | 启用选中的组织（需先勾选） |
| 停用 | 红色文字按钮 | 停用选中的组织（需先勾选） |
