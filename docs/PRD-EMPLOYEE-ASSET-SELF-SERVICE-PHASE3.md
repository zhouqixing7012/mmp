# 员工资产领用与确认 PRD

## 1. 阶段目标

承接资产配给和统一申请汇总结果，完成个人工作台中的 ES 前台领用、员工领用确认及相关校验。本轮展示入口以“ES前台领用”和“员工领用确认”页面为准。

## 2. 页面入口

个人工作台保留以下领用相关菜单：

- ES前台领用
- 员工领用确认

独立路由继续保留，现有页面文件不删除。

## 3. ES前台领用

### 3.1 页面结构

页面包含：

1. 页面标题和申请单号。
2. 申请人信息。
3. 申请资产信息。
4. 页面底部操作栏。

申请资产信息采用表格式展示：

- 只读字段以普通文本展示。
- 可编辑字段直接在对应单元格中使用 Input 或 Select。
- 不额外拆分“实际领用信息”“申请参考信息”等卡片。

### 3.2 申请人信息

申请人身份字段使用当前统一默认集合：

- 申请人
- 申请日期
- 公司
- 办公区
- 联系电话
- 邮箱
- 部门

本办理节点另外保留：

- 当前仓库（可编辑、必填）

不展示成本中心、板块、单据备注等身份扩展字段。当前仓库属于办理字段，不改变申请人信息默认 7 字段口径。

### 3.3 申请资产信息

申请资产信息展示：

- 资产标签号（可编辑、必填）
- 序列号
- 资产说明
- 配置
- 部件数量
- 公司
- 板块
- 启用日期
- 备注（只读）
- `city`（可编辑、必填）
- `building`（可编辑、必填）
- `floor`（可编辑、必填）
- 资产用途（可编辑、必填）
- 使用说明（可编辑，单行）
- 实际盘点人
- 盘点状态
- 申请物资说明
- 申请配置
- 申请原因

不再展示“所在仓库”；资产所属仓库继续用于后台校验，但不作为申请资产信息字段展示。“详细说明”在本节点统一使用业务名称“申请原因”。

### 3.4 资产标签号选择

资产标签号点击放大镜打开“选择资产”弹窗。

查询条件：

- 标签号
- 序列号
- 板块
- 资产说明

列表字段：

- 选择
- 资产标签号
- 序列号
- 板块
- 资产说明
- 配置
- 所在仓库

弹窗支持单选，点击确定后回填资产标签号并刷新所选资产的只读信息。

### 3.5 地点联动

`city / building / floor` 的数据口径与地点基础数据一致。

联动规则：

1. 选择 `city` 后，`building` 仅展示该城市下的数据。
2. 清空或修改 `city` 时，`building` 和 `floor` 同步清空。
3. 选择 `building` 后，`floor` 仅展示该建筑下的数据。
4. 清空或修改 `building` 时，`floor` 同步清空。

### 3.6 领用确认校验

点击“领用确认”后按顺序执行：

1. 校验资产标签号、当前仓库、`city / building / floor` 和资产用途等必填字段。
2. 判断所选资产的仓库与单据“当前仓库”是否一致。
3. 仓库不一致时阻止后续操作并提示：

> 资产不在当前库，请进行移库操作！

4. 仓库一致时弹出确认框：

> 是否确认领用

5. 点击“取消”关闭确认框并停留当前页面。
6. 点击“确定”进入员工领用确认页面，由员工刷卡或扫码确认。

### 3.7 其他操作

页面保留：

- 弃领
- 加签
- 返回
- 发送领用通知

## 4. 员工领用确认

### 4.1 页面结构

页面展示：

1. 页面标题和申请单号。
2. 领用人信息。
3. 领用物资明细。
4. 确认提示及保管职责。
5. 刷卡/扫码确认。
6. 页面底部返回按钮。

### 4.2 领用人信息

当前页面仅展示：

- 使用人
- 部门

这里是“员工领用确认”页面的现行口径，不与资产更换链路中的“员工资产确认”页面混用。

### 4.3 确认提示及保管职责

页面固定展示红字确认提示：

> 提示：我已阅读并确认保管职责说明，特此刷卡确认！

并展示资产保管职责正文。

### 4.4 刷卡确认

- 员工卡号为空时，点击确认领用提示“请先输入员工卡号”。
- 输入卡号后可点击确认领用。
- 当前为前端演示反馈，尚未接入真实刷卡设备和员工身份接口。

### 4.5 扫码确认

页面展示基于申请单号和资产标签号生成的二维码，用于演示扫码核对并确认领用信息。

## 5. 后台和菜单配套调整

### 5.1 个人工作台菜单

精简后的个人工作台菜单为：

1. 工作台首页
2. 号码管理
3. 号码控制
4. 资产申请
5. 业务审批
6. 资产配给
7. 统一申请汇总-资产
8. ES前台领用
9. 员工领用确认

### 5.2 侧边栏滚动

个人工作台和后台基础配置共用的侧边栏菜单区域支持纵向滚动，确保组织管理及其下方菜单可正常访问。

## 6. 演示数据说明

当前以下内容仍使用前端 mock 数据：

- 可选择资产列表
- 仓库列表
- 地点数据
- 申请人和资产卡片信息
- 领用结果和按钮反馈

业务页面和用户信息里的“联系电话”Mock 使用座机号格式；合约号码、电话号码等号码资产不受该规则影响。

## 7. 验收标准

1. 个人工作台可进入 ES前台领用和员工领用确认。
2. ES前台领用申请人身份字段使用默认 7 字段，并额外保留当前仓库；不展示成本中心和单据备注。
3. 申请资产信息不展示所在仓库，启用日期后展示只读备注。
4. 位置字段统一显示为 `city / building / floor`。
5. “详细说明”在 ES 前台领用使用“申请原因”展示。
6. 资产标签号必填，可通过放大镜弹窗修改。
7. 资产选择弹窗支持标签号、序列号、板块和资产说明查询。
8. 清空 `city` 时 `building / floor` 同步清空；修改 `building` 时 `floor` 同步清空。
9. 必填字段缺失时不能继续领用确认。
10. 资产仓库与当前仓库不一致时提示移库并阻止确认。
11. 仓库一致时弹出“是否确认领用”。
12. 取消后停留在 ES前台领用页面，确定后进入员工领用确认。
13. 员工领用确认页保持“使用人 / 部门”的当前页面口径。
14. 员工领用确认展示红字确认提示和保管职责。
15. 未输入员工卡号时不能确认领用。
16. 后台侧边栏可以滚动到组织管理下方菜单。
