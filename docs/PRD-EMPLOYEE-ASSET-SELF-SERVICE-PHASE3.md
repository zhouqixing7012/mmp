# 员工资产领用与确认 PRD

## 1. 阶段目标

承接资产配给和统一申请汇总结果，完成个人工作台中的 ES 前台领用、员工领用确认及相关校验。本轮展示入口以原“ES前台领用”和“员工领用确认”页面为准，员工自助新版领用页面和独立路由继续保留但不在精简后的个人工作台菜单中展示。

## 2. 页面入口

个人工作台保留以下领用相关菜单：

- ES前台领用
- 员工领用确认

独立路由仍保留，现有页面文件不删除。

## 3. ES前台领用

### 3.1 页面结构

页面包含：

1. 页面标题和申请单号。
2. 申请人信息。
3. 申请资产信息。
4. 页面底部操作栏。

申请资产信息采用表格式展示：

- 只读字段以普通文本展示。
- 可编辑字段直接在对应单元格中使用 Input、Select 或 TextArea。
- 不额外拆分“实际领用信息”“申请参考信息”等卡片。

### 3.2 申请人信息

申请人信息区域展示：

- 申请人
- 联系电话
- 邮箱
- 公司
- 办公区
- 申请日期
- 成本中心
- 部门
- 当前仓库（可编辑、必填）
- 单据备注（可编辑）

### 3.3 申请资产信息

申请资产信息展示：

- 资产标签号（可编辑、必填）
- 序列号
- 所在仓库
- 资产说明
- 配置
- 部件数量
- 公司
- 板块
- 启用日期
- 城市（可编辑、必填）
- 建筑（可编辑、必填）
- 楼层（可编辑、必填）
- 资产用途（可编辑、必填）
- 使用说明（可编辑）
- 实际盘点人
- 盘点状态
- 申请配置
- 申请物资说明
- 详细说明

“申请原因”字段不展示。

### 3.4 资产标签号选择

资产标签号点击放大镜打开“物资列表”弹窗。

弹窗复用资产配给页面的匹配资产交互，支持以下查询条件：

- 标签号
- 序列号
- 板块
- 资产说明

弹窗列表支持单选，点击确定后回填资产标签号，并同步刷新所选资产的只读信息。

### 3.5 地点联动

城市、建筑和楼层的数据口径与“地点基础数据维护”一致。

联动规则：

1. 选择城市后，建筑仅展示该城市下的数据。
2. 清空或修改城市时，建筑和楼层同步清空。
3. 选择建筑后，楼层仅展示该建筑下的数据。
4. 清空或修改建筑时，楼层同步清空。

### 3.6 领用确认校验

点击“领用确认”后按顺序执行：

1. 校验资产标签号、当前仓库、城市、建筑、楼层和资产用途等必填字段。
2. 判断所选资产卡片的仓库与单据“当前仓库”是否一致。
3. 仓库不一致时阻止后续操作并提示：

> 资产不在当前库，请进行移库操作！

4. 仓库一致时弹出确认框：

> 是否确认领用

5. 点击“取消”关闭确认框并返回当前资产领用单页面。
6. 点击“确定”进入员工领用确认页面，由员工刷卡或扫码确认。

### 3.7 其他操作

页面保留：

- 弃领
- 加签
- 返回
- 发送领用通知

当前均为前端演示反馈。

## 4. 员工领用确认

### 4.1 页面结构

页面展示：

1. 页面标题和申请单号。
2. 领用人信息。
3. 领用物资明细。
4. 固定提示。
5. 员工卡号输入和确认领用按钮。
6. 资产保管职责。
7. 二维码。
8. 页面底部返回按钮。

### 4.2 领用人信息

仅展示：

- 使用人
- 部门

不展示公司、联系电话和办公区。

### 4.3 固定提示

页面固定展示：

> 提示：我已阅读并确认保管职责说明，特此刷卡确认！

### 4.4 刷卡确认

- 员工卡号为空时，点击确认领用提示“请先输入员工卡号”。
- 输入卡号后可点击确认领用。
- 当前为前端演示反馈，尚未接入真实刷卡设备和员工身份接口。

### 4.5 扫码确认

页面展示基于申请单号和资产标签号生成的二维码，用于演示扫码查看和确认领用信息。

## 5. 后台和菜单配套调整

### 5.1 个人工作台菜单

精简后的个人工作台菜单为：

1. 工作台首页
2. 号码管理
3. 号码控制
4. 资产申请
5. 业务审批
6. 资产配给
7. 统一申请汇总-资产
8. ES前台领用
9. 员工领用确认

### 5.2 侧边栏滚动

个人工作台和后台基础配置共用的侧边栏菜单区域支持纵向滚动，确保组织管理及其下方菜单可正常访问。

## 6. 演示数据说明

当前以下内容仍使用前端 mock 数据：

- 可选择资产列表
- 仓库列表
- 地点数据
- 申请人和资产卡片信息
- 领用结果和按钮反馈

尚未接入真实后台接口、刷卡设备和消息通知服务。

## 7. 验收标准

1. 个人工作台可进入 ES前台领用和员工领用确认。
2. 当前仓库和单据备注位于申请人信息区域。
3. 申请资产信息采用统一表格式展示，不拆分多张业务卡片。
4. 申请资产信息不展示申请原因。
5. 资产标签号必填，可通过放大镜弹窗修改。
6. 资产选择弹窗支持标签号、序列号、板块和资产说明查询。
7. 清空城市时建筑和楼层同步清空。
8. 修改建筑时楼层同步清空。
9. 必填字段缺失时不能继续领用确认。
10. 资产仓库与当前仓库不一致时提示移库并阻止确认。
11. 仓库一致时弹出“是否确认领用”。
12. 取消后停留在 ES前台领用页面，确定后进入员工领用确认。
13. 员工领用确认页仅展示使用人和部门。
14. 固定提示文案准确。
15. 未输入员工卡号时不能确认领用。
16. 后台侧边栏可以滚动到组织管理下方菜单。
