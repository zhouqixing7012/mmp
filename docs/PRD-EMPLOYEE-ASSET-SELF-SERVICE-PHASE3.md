# 员工自助新版——第三阶段资产领用 PRD

## 1. 阶段目标

承接资产配给和汇总采购结果，完成资产领用单生成、领用通知、员工确认、库管复核、资产出库、台账更新和原申请进度回写。旧版 ES 前台领用及员工领用确认页面继续保留。

## 2. 领用单生成

### 2.1 库存领用

ES 配给选择“库存领用”并配给通过后，系统根据配给单自动生成资产领用单。

### 2.2 采购入库领用

汇总采购提交完成后，演示系统模拟采购及入库完成，并根据汇总明细生成采购入库领用单。采购入库领用的资产标签号和当前仓库默认锁定。

### 2.3 单据字段

- 领用单号
- 申请单号
- 配给单或采购来源单号
- 来源类型：库存领用、采购入库领用
- 当前仓库
- 申请人及组织信息
- 资产标签号、资产说明、配置
- City、Building、Floor
- 资产用途、使用说明
- 盘点人、盘点状态
- 确认方式
- 单据状态

## 3. 库管员领用处理

### 3.1 当前仓库

库存领用允许库管员在有出库权限的仓库范围内调整；采购入库领用默认使用资产所在仓库并锁定。

执行出库前校验资产卡片仓库与当前仓库是否一致。不一致时提示：

> 资产不在当前库，请先执行移库操作！

### 3.2 领用通知

库管员点击“发送领用通知”，单据状态由“待通知”变为“待员工确认”。演示反馈表示已通过狐小e、MyFamily和易点发送。

### 3.3 确认方式

- 狐小e电子签：默认方式。
- 刷卡/工号确认：校验输入工号必须与申请人工号一致。

员工确认后进入“待库管复核”。

## 4. 员工确认

员工确认页面展示：

1. 申请单和领用单信息。
2. 资产标签号、资产说明、配置、用途和领取地点。
3. 资产保管职责。
4. 领用确认方式。

员工必须先点击“已阅读”确认保管职责。

### 4.1 电子签

员工在签名区域手写签名，可清除并重新签名。提交后签名以图片数据保存到演示存储。

### 4.2 刷卡或工号确认

输入或刷卡读取工号后立即校验。与申请人工号不一致时提示：

> 员工工号不匹配！

## 5. 库管复核与出库

库管员查看员工签名或确认结果：

- 签名不合规：填写意见后退回员工重新确认。
- 确认无误：填写复核意见并执行出库。

执行出库后：

1. 领用单状态更新为“已完成”。
2. 生成出库记录。
3. 资产状态更新为“在用-使用中”。
4. 仓库置空。
5. 更新责任人、部门、成本中心、City、Building、Floor、用途和使用说明。
6. 原资产申请单对应分支更新为已完成；相关领用单全部完成时，原申请单状态更新为“已完成”。

## 6. 状态流转

```text
待通知
→ 待员工确认
→ 待库管复核
├─ 签名驳回 → 待员工确认
└─ 复核通过 → 已完成
```

## 7. 页面入口

- `/employee-self-service/asset-claim`
- `/employee-self-service/asset-claim-confirm`

顶部个人工作台导航和 `/yewurules` 个人工作台内部菜单均提供入口。

## 8. 验收标准

1. 旧版领用页面和路由可继续访问。
2. 库存领用配给完成后可生成新版领用单。
3. 已汇总采购明细可生成采购入库领用单。
4. 库管员可维护发放地点、用途、盘点信息和确认方式。
5. 可发送领用通知。
6. 员工未阅读保管职责时不能确认。
7. 电子签未签名时不能提交。
8. 刷卡或工号与申请人不一致时不能提交。
9. 库管员可驳回签名并要求重签。
10. 仓库不一致时不能出库。
11. 出库后生成出库记录并更新资产台账字段。
12. 原申请进度随领用结果更新。
13. 刷新页面后领用和确认结果仍然保留。
