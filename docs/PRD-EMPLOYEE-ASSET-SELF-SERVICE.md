# 员工自助新版——资产申请 PRD

## 1. 目标

重构员工资产申请链路，覆盖员工申请、业务审批、ES 配给、汇总采购、资产领用和员工确认。新版功能与旧页面并行，旧页面、旧路由和旧演示数据保持不变。

本阶段实现：

- 员工自助新版资产申请
- 员工自助新版业务审批
- 申请与审批共用演示数据

后续阶段实现：

- ES 配给
- 汇总采购
- 资产领用
- 员工电子签或刷卡确认
- 全流程进度查询

## 2. 范围

本期只实现资产申请，不实现耗材申请。数据结构预留物料类型，以便后续接入耗材拆单。

## 3. 人员准入

| 员工状态 | 是否允许申请 | 处理方式 |
|---|---:|---|
| 正式员工 | 是 | 按正式员工和技术人员规则展示可申请资产 |
| 实习生 | 是 | 按实习生可申请规则和名下电脑限制处理 |
| 外包员工 | 否 | 页面拦截并提示“当前员工身份暂不支持发起资产申请” |

## 4. 申请页面

### 4.1 入口

- 顶部导航：个人工作台 → 员工自助新版-资产申请
- 后台框架：个人工作台 → 员工自助新版-资产申请

### 4.2 申请须知

进入页面后弹出申请须知。用户可点击“已阅读”或右上角关闭按钮关闭。

### 4.3 申请人信息

只读展示：

- 申请人
- 联系电话
- 邮箱
- 公司
- 部门全路径
- 办公区
- 员工状态
- 人员类型
- 成本中心
- 申请日期

### 4.4 资产选择

使用统一选择弹窗，支持多选和模糊搜索。

分类路径格式：物料类型-物料大类-物料小类-品牌-型号。

查询字段：

- 资产说明
- 配置

### 4.5 申请明细字段

| 字段 | 编辑 | 必填 | 规则 |
|---|---:|---:|---|
| 资产说明 | 否 | 是 | 资产小类.品牌.型号 |
| 配置 | 否 | 是 | 无配置时显示“无” |
| 数量 | 是 | 是 | 正整数，大于等于 1 |
| 申请原因 | 是 | 是 | 设备更新、新项目需要、设备损坏、新增岗位、其他原因 |
| 申请用途 | 是 | 是 | 员工用机、部门公用、其他用途、专业用途 |
| 详细说明 | 是 | 否 | 多行或单行文本均可 |
| 是否个人超标 | 否 | 否 | 系统计算，超标时展示红色标签 |
| 是否部门超标 | 否 | 否 | 申请端不展示，在审批过程中计算 |

### 4.6 提交校验

提交时依次校验：

1. 员工状态是否允许申请。
2. 是否至少选择一项资产。
3. 数量是否为正整数。
4. 申请原因是否填写。
5. 申请用途是否填写。
6. 是否存在个人超标。

存在个人超标时提示：

> 当前有 X 条申请资产超标，申请将依次经过直属领导、5级及以上领导、7级及以上领导审批。是否继续？

### 4.7 单据编号

格式：`CA-年月日-5位流水号`。

### 4.8 提交结果

提交成功后：

- 生成资产申请单。
- 状态为“处理中”。
- 任务状态为“业务审批”。
- 当前节点为“直属领导”。
- 数据写入统一演示存储，刷新页面后保留。

## 5. 审批规则

### 5.1 通用规则

- 到老板或 VP 前，必须先经过其直接汇报人。
- 相同审批人节点自动跳过。
- 驳回时审批意见必填。
- 单据状态：处理中、已完成、已驳回。
- 申请记录和流程节点可查询。

### 5.2 正常申请

```text
申请人提交
→ 直属领导
→ 5级及以上领导
→ 业务审批完成
→ 资产配给
```

### 5.3 超标申请

7级及以上领导才有超标审批权限，因此超标申请必定经过 5 级和 7 级节点。

```text
申请人提交
→ 直属领导
→ 5级及以上领导
→ 7级及以上领导
→ 判断部门人均量是否在审批权限范围内
   ├─ 未超标：业务审批完成
   └─ 超标：继续寻找上级审批
            → 最高到 VP / CFO
```

### 5.4 非技术人员申请苹果电脑

按超标路径处理：

```text
直属领导
→ 5级及以上领导
→ 7级及以上领导
→ 逐级审批至 VP / CFO
```

## 6. 审批页面

### 6.1 列表

查询条件：

- 申请单号或申请人关键字

列表字段：

- 申请单号
- 申请人
- 申请日期
- 申请数量
- 当前节点
- 任务状态
- 操作

### 6.2 详情

分区展示：

1. 申请单提醒
2. 申请人信息
3. 申请资产信息
4. 审批信息
5. 当前审批操作

### 6.3 审批操作

- 同意：完成当前节点并进入下一节点。
- 驳回：审批意见必填，单据状态改为“已驳回”，返回申请人。
- 业务审批全部完成：任务状态改为“待配给”，当前节点改为“资产配给”。

## 7. ES 配给原则（后续阶段）

审批完成后按申请行和数量拆分配给单。同一申请单允许同时存在库存领用和统一采购两种处理方式。

- 库存领用：进入资产领用流程。
- 统一采购：实时进入待汇总池，由 ES 按月集中提交采购。

## 8. 数据流

```text
新版资产申请页
→ employeeSelfServiceService
→ localStorage 统一演示数据
→ 新版业务审批列表及详情
→ 审批更新同一份申请数据
→ 业务审批完成后标记为待配给
```

## 9. 验收标准

1. 旧申请、审批和配给页面仍可正常访问。
2. 新版申请和审批拥有独立菜单及路由。
3. 外包员工无法提交申请。
4. 申请须知进入页面时自动展示。
5. 支持多选资产并填写申请明细。
6. 缺少必填字段时不能提交。
7. 超标申请提交前展示确认提示。
8. 申请提交后可在新版审批列表查看。
9. 同意后正确进入下一审批节点。
10. 超标申请依次经过直属领导、5级和7级节点。
11. 驳回时审批意见必填。
12. 业务审批完成后任务状态变为“待配给”。
13. 刷新浏览器后申请和审批结果仍保留。
