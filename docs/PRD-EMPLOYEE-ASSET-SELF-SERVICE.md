# 员工资产申请、审批、配给与统一汇总 PRD

## 1. 目标

覆盖员工资产申请、业务审批、ES 配给、统一申请汇总、ES 前台领用和员工领用确认的主要演示链路。当前个人工作台采用收口后的菜单名称，旧页面、旧路由和旧演示数据继续保留。

当前主要页面：

- 资产申请
- 业务审批
- 资产配给
- 统一申请汇总-资产
- ES前台领用
- 员工领用确认

涉及来源 PDF 与当前原型差异时，同时参考：

`docs/员工自助功能PRD/12-当前原型补充口径.md`

## 2. 个人工作台入口

个人工作台最终保留：

1. 工作台首页
2. 号码管理
3. 号码控制
4. 资产申请
5. 业务审批
6. 资产配给
7. 统一申请汇总-资产
8. ES前台领用
9. 员工领用确认

原“员工自助新版”前缀不再展示，但对应页面组件和独立路由继续保留。

## 3. 人员准入

| 员工状态 | 是否允许申请 | 处理方式 |
|---|---:|---|
| 正式员工 | 是 | 按正式员工和技术人员规则展示可申请物资 |
| 实习生 | 是 | 按实习生可申请规则和名下电脑限制处理 |
| 外包员工 | 否 | 页面拦截并提示当前员工身份暂不支持发起资产申请 |

## 4. 资产申请

### 4.1 申请须知

进入页面后自动弹出申请须知。

关闭规则：

- 只能点击“已阅读”关闭。
- 不展示右上角关闭按钮。

申请原则文案：

1. 须以实际业务需求及办公为前提填写申请。
2. 资产申请以部门为维度，每月汇总提交；耗材申请以公司为维度，每周一汇总提交。
3. 资产目录缺少信息时联系集团 ES 王英。
4. 耗材目录缺少信息时联系集团 ES 刘建。
5. 外地分公司申请资产或耗材可先联系当地 ES。

### 4.2 申请人信息

申请编辑页不重复展示申请人信息卡片，申请流程聚焦物资选择和申请明细。

### 4.3 物资选择

支持资产和耗材 Tab，多选物资。

选择层级：

```text
大类 → 小类 → 品牌 → 型号 → 配置
```

交互规则：

- 使用五个横向分栏展示层级。
- 鼠标悬停或聚焦当前项时展开下一层。
- 不展示“只能选择第五级”等额外提示。
- 已选物资卡片第一行显示“小类.品牌.型号”。
- 第二行以小号灰色文字显示配置摘要。

耗材支持关联主资产。

### 4.4 申请明细

| 字段 | 编辑 | 必填 | 规则 |
|---|---:|---:|---|
| 物资说明 | 否 | 是 | 由所选物资生成 |
| 配置 | 否 | 是 | 无配置时显示“无” |
| 数量 | 是 | 是 | 正整数且大于等于 1 |
| 申请用途 | 是 | 是 | 员工用机、部门公用、其他用途、专业用途 |
| 详细说明 | 是 | 是 | 最多 400 字 |
| 是否超标 | 否 | 否 | 系统计算，已超标显示红色标签 |
| 关联主资产 | 是 | 条件必填 | 耗材申请使用 |

“申请原因”统一改为“申请用途”。

### 4.5 预览

预览为页面状态，不使用弹窗。

预览页：

- 所有字段只读。
- 底部按钮为“上一步”和“提交”。
- “本次申请明细”不再嵌套多层卡片。
- 超标数量按 `overStandard` 明细实时统计。

存在超标申请时提示：

- 标题：`当前有 X 条申请物资超标`
- 说明：`超标资产申请将自动提交至部门 7 级及以上领导审批，请确认申请内容无误后再提交。`

### 4.6 返回路径

资产申请页点击返回时，统一返回个人工作台首页。

## 5. 业务审批

### 5.1 页面入口

当前页面直接进入审批详情，不经过前置查询列表。

### 5.2 页面内容

页面展示：

1. 申请人信息
2. 申请物资明细
3. 审批信息
4. 审批操作

申请单号仅在页面右上角展示。

申请人信息使用默认 7 字段：申请人 / 申请日期 / 公司 / 办公区 / 联系电话 / 邮箱 / 部门；当前业务审批页公司固定展示 `114.新媒体`。

申请物资字段：

- 资产说明
- 配置
- 数量
- 申请用途
- 申请原因
- 是否超标

原“详细说明”在业务审批页面展示为“申请原因”，底层继续读取 `detail`。

不展示成本中心和人员类型。

是否超标统一显示：

- 未超标
- 已超标

### 5.3 审批操作

按钮包括：

- 同意
- 驳回
- 返回
- 加签

业务审批完成后进入资产配给阶段。

## 6. 资产配给

### 6.1 页面入口

当前页面直接进入待配给详情，不经过前置查询列表。

### 6.2 页面顺序

1. 申请人信息
2. 申请物资明细
3. ES 配给处理
4. 审批信息
5. 审批操作

审批操作栏固定在页面最下方。

### 6.3 申请物资字段

- 物资说明
- 参考单价
- 配置
- 申请用途
- 详细说明
- 是否超标
- 数量
- 主资产说明（耗材独有）

### 6.4 ES 配给处理

ES 建议：

- 可编辑
- 最多 400 字

匹配状态：

- 库存领用
- 统一采购

选择库存领用时必须匹配资产。

### 6.5 匹配资产

第一层弹窗展示申请物资和已匹配资产。

点击放大镜后进入物资列表弹窗，查询字段：

- 标签号
- 序列号
- 板块
- 资产说明

资产列表字段：

- 选择
- 标签号
- 公司
- 板块
- 资产大类
- 资产小类
- 资产说明
- 品牌
- 数量
- 原值
- 资产责任人
- 资产状态
- 成本中心
- 启用日期

支持查看申请人名下资产，当前查询条件为：

- 资产标签号
- 资产状态
- 资产说明
- 是否锁定

不再提供“物资总类”和“资产用途”查询条件。

### 6.6 审批操作

页面最下方展示：

- 同意
- 驳回
- 返回
- 加签

## 7. 统一申请汇总-资产

### 7.1 汇总单列表

列表字段：

- 申请部门
- 申请数量
- 汇总时间
- 操作

申请部门为蓝色链接，点击行为与“查看”一致。

### 7.2 汇总单明细

按申请人展示申请物资明细。

ES 建议可编辑，最多 400 字。

底部按钮居中：

- 下一步
- 保存
- 返回

### 7.3 汇总页面

包含：

- ES 汇总说明
- 项目用途说明
- 部门汇总信息
- 超标申请
- 非超标申请
- 附件信息
- 部门现资产参考使用量

ES 汇总说明可编辑。

超标申请和非超标申请字段按当前页面实现展示。

### 7.4 空数据展示

“超标申请”和“部门现资产参考使用量”无数据时：

- 保留完整表头。
- 表头下只显示“无展示数据”。
- 不显示 Empty 插图。

部门现资产参考使用量字段：

- 序号
- 物资类别
- 现使用量
- 现人均用量
- 申请采购量
- 采购后人均用量
- 公司人均用量

### 7.5 导出

汇总申请页支持导出申请明细，导出范围覆盖超标申请和非超标申请。

### 7.6 汇总审批

点击提交后进入统一申请汇总审批页。

审批页复用汇总页面信息，但主体全部只读：

- 文本字段只读展示
- 表格只读展示
- 附件只展示文件名
- 不提供上传和编辑操作

审批页仍保留审批动作“同意 / 驳回 / 返回”。

审批页在“超标申请”上方同样提供“导出申请明细”按钮，复用当前 CSV 导出逻辑，不改变只读表格和审批动作。

## 8. ES前台领用与员工领用确认

详细规则见：

`docs/PRD-EMPLOYEE-ASSET-SELF-SERVICE-PHASE3.md`

核心规则：

- ES 前台领用申请人身份字段使用默认 7 字段，并额外保留当前仓库；不展示成本中心和单据备注。
- 资产标签号必填并通过放大镜弹窗修改。
- 申请资产信息不展示“所在仓库”，启用日期后展示只读备注。
- 地理位置字段统一使用 `city / building / floor` 并按地点维护数据联动。
- “详细说明”在 ES 前台领用展示为“申请原因”。
- 资产仓库与当前仓库不一致时阻止确认并提示移库。
- 仓库一致时弹出“是否确认领用”。
- 确定后进入员工领用确认页面。

## 9. 数据流

```text
资产申请
→ employeeSelfServiceService
→ 业务审批
→ employeeSelfServiceWorkflowService
→ 资产配给
   ├─ 库存领用 → ES前台领用 → 员工领用确认
   └─ 统一采购 → 统一申请汇总 → 汇总审批
```

## 10. 当前演示限制

- 加签主要为页面演示，未完整持久化审批记录。
- ES前台领用和员工领用确认仍有部分本地状态未接入统一 service。
- 地点、仓库和资产列表为 mock 数据。
- 业务联系人 Mock 使用座机号；号码资产本身不受影响。
- 导出使用前端 CSV 生成。
- 当前分支尚未完成本地构建和全链路自动化回归。

## 11. 验收标准

1. 个人工作台只展示最终 9 个菜单。
2. 资产申请须知只能通过“已阅读”关闭。
3. 支持资产和耗材多选及五级物料选择。
4. 申请用途和详细说明校验正确。
5. 预览页超标数量和提示正确。
6. 业务审批直接进入详情，申请物资字段使用“申请原因”，公司显示 `114.新媒体`，操作按钮完整。
7. 资产配给直接进入详情，审批操作栏位于最下方；员工名下资产查询不提供物资总类和资产用途。
8. 库存领用必须匹配资产。
9. 统一申请汇总列表的申请部门可点击。
10. 汇总页空表格保留表头并显示“无展示数据”。
11. 汇总申请和汇总审批都支持导出申请明细。
12. 提交汇总后进入只读审批页，底部保留同意 / 驳回 / 返回。
13. ES前台领用仓库校验和 `city / building / floor` 联动正确，且不展示成本中心、单据备注和所在仓库。
14. 员工领用确认提示和卡号校验正确。
15. 刷新页面后需要持久化的申请、审批和配给数据仍然存在。
