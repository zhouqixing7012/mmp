## 九、组织与用户管理

---

### 9.1 模块说明

#### 9.1.1 模块定位

组织与用户管理是企业资产管理系统的系统配置模块，用于管理企业的组织结构和用户信息。该模块为系统中所有涉及部门、人员的功能提供基础数据支持。

权限：所有涉及组织与用户编辑、修改的权限，目前仅开放给系统管理员

#### 9.1.2 包含页面

本模块包含2个子页面，通过顶部Tab标签页切换：

| 页面 / Tab 标签 | 功能说明 |
|-----------------|----------|
| 用户管理 | 管理员工信息，采用左右分栏布局，左侧为组织架构树，右侧为用户列表 |
| 组织管理 | 管理组织结构，采用树形表格展示组织层级 |

---

### 9.2 用户管理页面

#### 9.2.1 页面功能

采用左右分栏布局。左侧为组织架构树，点击组织节点后右侧显示该组织下的用户列表。支持新增人员、启用/停用、查看用户详情。

---

#### 9.2.2 左侧：组织架构树

显示企业的组织架构，支持展开/折叠。点击组织名称选中该组织，右侧显示该组织下的用户。

组件：递归树形组件

交互：
- 点击组织名称：选中并右侧刷新
- 点击展开/折叠图标：展开或折叠子节点
- 搜索框：输入关键字过滤组织节点

#### 9.2.3 右侧：用户列表

##### 9.2.3.1 查询条件及表格

查询条件：

| 字段名称 | 是否查询条件 | 查询条件控件类型 | 提示文案 | 说明 |
|----------|:----------:|:--------------:|----------|------|
| 员工姓名 | Y | Input | 请输入员工姓名 | 支持模糊检索 |

按钮：
- 查询：蓝色主按钮，点击后根据条件筛选用户

表格列（左到右）：

| 字段名称 | 是否查询条件 | 查询条件控件类型 | 提示文案 | 说明 |
|----------|:----------:|:--------------:|----------|------|
| 工号 | N | - | - | 可点击蓝色链接，点击后查看用户详情 |
| 姓名 | N | - | - | 员工姓名 |
| 邮箱 | N | - | - | 员工邮箱 |
| 职级 | N | - | - | 员工职级（如 4B、3A） |
| 职务序列 | N | - | - | 是/否，表示是否为技术序列 |
| 员工状态 | N | - | - | 在职（蓝色标签）/ 离职（灰色标签） |
| 使用状态 | N | - | - | 启用（绿色标签）/ 停用（红色标签） |
| 操作 | N | - | - | “编辑”蓝色链接按钮，点击打开编辑弹窗 |

##### 9.2.3.2 操作栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增人员 | 蓝色主按钮 | 打开新增用户弹窗 |
| 启用 | 绿色文字按钮 | 启用选中的用户（需先勾选） |
| 停用 | 红色文字按钮 | 停用选中的用户（需先勾选） |
| 批量删除 | 红色按钮 | 删除选中的用户（需先勾选） |

#### 9.2.4 用户详情页

触发方式：点击表格中工号蓝色链接

页面标题：用户信息

展示字段（两列布局）：

| 左侧列 | 右侧列 |
|--------|--------|
| 姓名 | 联系电话 |
| 所在部门 | 状态有效 |
| 登录名 | 性别 |
| 移动电话 | Email地址 |
| 拥有的角色 | 上级领导 |
| 员工职级 | 职类 |
| 公司 | 职目 |
| 成本中心 | - |
| HR公司 | - |
| 部门全称 | - |
| 办公区 | - |
| 职位 | - |

按钮：
- 返回：灰色按钮，点击返回用户列表

---

### 9.3 组织管理页面

#### 9.3.1 页面功能

采用树形表格展示企业的组织层级，支持展开/折叠查看。支持新增组织、启用/停用、批量操作、导出数据。

#### 9.3.2 树形表格

排序：以序号为依据，按编号从小到大排列

分页：共 X 条记录（底部统计，不分页）

表格列（左到右）：

| 字段名称 | 是否查询条件 | 查询条件控件类型 | 提示文案 | 说明 |
|----------|:----------:|:--------------:|----------|------|
| 序号 | N | - | - | 自动编号 |
| 组织机构 | N | - | - | 带层级缩进和图标，公司类型蓝色图标，部门类型黄色图标 |
| 架构图 | N | - | - | 图标按钮，点击查看架构图 |
| 组织类别 | N | - | - | 公司 / 部门 |
| 在职（直属/总共） | N | - | - | 直属人数 / 总人数 |
| 部门负责人 | N | - | - | 负责人姓名 |
| 部门编码 | N | - | - | 组织编码（如 D0001） |
| 状态 | N | - | - | 已启用（绿色标签）/ 已停用（灰色标签） |
| 操作 | N | - | - | “编辑”蓝色链接按钮，点击打开编辑弹窗 |

右侧控件：

| 控件名称 | 控件类型 | 功能说明 |
|----------|----------|----------|
| 展开1级 | 下拉选择框 | 控制树形表格展开级别 |
| 组织名称搜索 | 搜索框 | 输入关键字搜索组织 |
| 设置 | 灰色按钮 | 打开设置菜单 |

#### 9.3.3 操作栏

| 按钮名称 | 按钮样式 | 功能说明 |
|----------|----------|----------|
| 新增 | 蓝色主按钮 | 打开新增组织弹窗 |
| 导出 | 灰色按钮 | 导出组织数据 |
| 批量操作 | 灰色按钮 | 弹出批量操作菜单 |
| 启用 | 绿色文字按钮 | 启用选中的组织（需先勾选） |
| 停用 | 红色文字按钮 | 停用选中的组织（需先勾选） |
