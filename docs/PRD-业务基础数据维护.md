## 一、模块概述

### 1.1 模块定位

"业务基础数据维护"是企业资产管理系统的**基础数据配置模块**，用于维护物料相关的所有基础数据。其他模块（如资产入库、资产盘点等）都依赖这里的基础数据。

### 1.2 包含页面

本模块包含7个子页面，通过顶部Tab标签页切换：

| Tab标签 | 页面名称 | 功能说明 |
|---------|----------|----------|
| 物料综合集合 | 物料维度组合管理 | 管理物料的完整维度组合信息 |
| 物料大类 | 物料大类管理 | 管理物料的一级分类 |
| 物料小类 | 物料小类管理 | 管理物料的二级分类 |
| 品牌 | 品牌管理 | 管理物料品牌信息 |
| 型号 | 规格型号管理 | 管理物料规格型号 |
| 配置 | 配置管理 | 管理物料配置信息 |
| NO服务 | NO服务管理 | 管理NO服务信息 |

## 二、页面1：物料综合集合（物料维度组合）

### 2.1 页面功能

这是本模块**最核心、最复杂**的页面，用于管理物料的完整维度组合信息。每个物料维度组合由"物料大类+小类+品牌+型号+配置"共同决定。

#### 2.6.3 字段详细说明

**物料总类（必填）**：
- 控件类型：下拉选择框
- 选项：资产、耗材、低值耐用品
- 说明：选择后会影响下方显示哪些额外字段

**物料大类（必填）**：
- 控件类型：搜索选择框
- 交互：点击搜索图标，弹出物料大类选择弹窗
- 选择后自动带出大类编码

**物料小类（必填）**：
- 控件类型：搜索选择框
- 依赖：必须先选择物料大类
- 交互：点击搜索图标，弹出该大类下的小类选择弹窗

**品牌（必填）**：
- 控件类型：搜索选择框
- 交互：点击搜索图标，弹出品牌选择弹窗

**规格型号（必填）**：
- 控件类型：搜索选择框
- 交互：点击搜索图标，弹出型号选择弹窗

**配置（选填）**：
- 控件类型：搜索选择框
- 交互：点击搜索图标，弹出配置选择弹窗

**单位（必填）**：
- 控件类型：下拉选择框
- 选项：台、块、个、套、件等

**是否启用（必填）**：
- 控件类型：下拉选择框
- 选项：启用、停用
- 默认值：启用

**启用日期（选填）**：
- 控件类型：日期选择框
- 格式：YYYY-MM-DD

**停用日期（选填）**：
- 控件类型：日期选择框
- 格式：YYYY-MM-DD
- 校验：如果"是否启用"选择"停用"，则此项必填

**参考价格（选填）**：
- 控件类型：数字输入框
- 格式：支持小数，如1380.00

**是否允许更换（选填）**：
- 控件类型：下拉选择框
- 选项：是、否
- 默认值：否
- 说明：如果选择"是"，员工在资产列表中可以点击"更换"按钮发起更换流程

**是否允许转岗（选填）**：
- 控件类型：下拉选择框
- 选项：是、否
- 默认值：是
- 说明：如果选择"是"，员工转岗时资产会跟随转岗

**是否允许借用（选填）**：
- 控件类型：下拉选择框
- 选项：是、否
- 默认值：否
- 说明：如果选择"是"，员工可以在资产列表中借用该资产

**是否需要ES审批（选填）**：
- 控件类型：下拉选择框
- 选项：是、否
- 默认值：否
- 说明：如果选择"是"，转岗/退库时需要ES审批

**是否允许退库（选填）**：
- 控件类型：下拉选择框
- 选项：是、否
- 默认值：否
- 说明：如果选择"是"，员工可以在资产列表中发起退库

**是否需要盘点（选填）**：
- 控件类型：下拉选择框
- 选项：是、否
- 默认值：是
- 说明：如果选择"是"，该资产在盘点范围内

**非技术申请超标（选填，仅资产类显示）**：
- 控件类型：下拉选择框
- 选项：是、否
- 默认值：否
- 说明：如果选择"是"，非技术岗位可以超标申请该资产

**退库时需要MIS鉴定（选填，仅资产类显示）**：
- 控件类型：下拉选择框
- 选项：是、否
- 默认值：否
- 说明：如果选择"是"，员工提交退库申请后，需要MIS部门进行鉴定

**是否关联主资产（选填，仅耗材/低值耐用品显示）**：
- 控件类型：下拉选择框
- 选项：是、否
- 默认值：否
- 说明：如果选择"是"，需要选择主资产的物料小类，用于关联到主资产

**主资产物料小类（选填，仅耗材/低值耐用品且关联主资产时显示）**：
- 控件类型：搜索选择框
- 交互：点击搜索图标，弹出物料小类选择弹窗
- 说明：关联的主资产的物料小类，用于资产归属管理

**是否MIS鉴定（选填，仅耗材/低值耐用品显示）**：
- 控件类型：下拉选择框
- 选项：是、否
- 默认值：否
- 说明：如果选择"是"，该资产需要MIS部门进行鉴定

**非技术申请超标（选填，仅资产类显示）**：
- 控件类型：下拉选择框
- 选项：是、否
- 默认值：否
- 说明：如果选择"是"，非技术岗位可以超标申请该资产

#### 2.6.4 弹窗按钮

## 九、通用交互说明

### 9.1 批量操作流程

**勾选记录**：
1. 点击表格第一列的复选框，勾选单条记录
2. 点击表头的复选框，全选/取消全选当前页

**批量启用/停用**：
1. 勾选需要操作的记录（可多选）
2. 点击工具栏的"启用"或"停用"按钮
3. 弹出确认弹窗："确定要启用/停用选中的X条记录吗？"
4. 点击"确定"，执行操作

**批量删除**：
1. 勾选需要删除的记录
2. 点击工具栏的"删除"按钮
3. 弹出确认弹窗："确定要删除选中的X条记录吗？此操作不可恢复！"
4. 点击"确定"，执行删除

### 9.2 新增流程

1. 点击工具栏"新增"按钮
2. 弹出新增弹窗
3. 填写表单字段（必填字段标红色星号*）
4. 点击"保存"按钮
5. 系统校验：
   - 如果校验通过：保存成功，关闭弹窗，刷新列表
   - 如果校验失败：显示错误提示，不关闭弹窗

### 9.3 编辑流程

1. 点击表格"操作"列的"编辑"按钮
2. 弹出编辑弹窗，显示当前记录的数据
3. 修改需要更新的字段
4. 点击"保存"按钮
5. 系统校验并保存

### 9.4 查询流程

1. 在搜索条件区域输入筛选条件
2. 点击"查询"按钮
3. 表格显示符合筛选条件的数据
4. 点击"重置"按钮，清空所有搜索条件，显示全部数据
