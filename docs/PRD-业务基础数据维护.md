## 一、模块概述

### 1.1 模块定位

"业务基础数据维护"是企业资产管理系统的**基础数据配置模块**，用于维护物料相关的所有基础数据。其他模块（如资产入库、资产盘点等）都依赖这里的基础数据。

权限：所有涉及物料编辑、修改的权限，目前仅开放给ES王英、刘建

### 1.2 包含页面

本模块包含6个子页面，通过顶部Tab标签页切换：

| Tab标签 | 功能说明 |
|---------|----------|
| 物料维度组合 | 管理物料的完整维度组合信息 |
| 物料大类 | 管理物料的一级分类 |
| 物料小类 | 管理物料的二级分类 |
| 品牌 | 管理物料品牌信息 |
| 型号 | 管理物料规格型号 |
| 配置 | 管理物料配置信息 |

## 二、页面1：物料维度组合

### 2.1 页面功能

这是本模块**最核心、最复杂**的页面，用于管理物料的完整维度组合信息。每个物料维度组合由"物料总类+物料大类+物料小类+品牌+型号+配置"共同决定。

**业务规则**：

1. **物料类型构成规则**：物料类型将以多层级维度组合生成，具体由物料总类为基础框架，结合物料大类、物料小类、品牌、型号、配置进行层级细分

2. **字段锁定规则**：物料信息一经新增提交后，系统将自动锁定物料分类、品牌、型号、配置四个字段，后续无法对其进行修改操作

3. **物料提交后自动新增配置**：物料提交后，用该物料的品牌+型号查找是否存在编码为"000"的配置，若不存在自动新增编码为"000"的配置，配置名称为空，配置品牌、型号用该物料品牌、型号

4. **物料总类与大类对应关系**：当选定特定物料总类后，系统仅展示该总类所对应的大类数据，确保大类选项与总类匹配一致。

5. **同步采购**：物料组合及编码在资产系统创建完成后，自动同步至采购系统。

## 八、通用交互说明

### 8.1 批量操作流程

1. **勾选记录**：点击表格第一列的复选框，勾选单条记录；点击表头的复选框，全选/取消全选当前页
2. **批量启用/停用**：勾选需要操作的记录后，点击工具栏的"启用"或"停用"按钮，弹出确认弹窗："确定要启用/停用选中的X条记录吗？"
3. **批量删除**：勾选需要删除的记录后，点击工具栏的"删除"按钮，弹出确认弹窗："确定要删除选中的X条记录吗？此操作不可恢复！"

### 8.2 查询流程

1. 在搜索条件区域输入筛选条件
2. 点击"查询"按钮，表格显示符合筛选条件的数据
3. 点击"重置"按钮，清空所有搜索条件，显示全部数据

### 8.3 新增/编辑流程

1. 点击工具栏"新增"按钮或表格"编辑"按钮，弹出对应弹窗
2. 填写/修改表单字段（必填字段标红色星号*）
3. 点击"保存"按钮，保存成功，关闭弹窗，刷新列表
4. 校验失败则显示错误提示，不关闭弹窗
