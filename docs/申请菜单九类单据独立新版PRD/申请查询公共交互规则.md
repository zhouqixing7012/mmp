# 申请查询公共交互规则

## 1 背景

本规则适用于申请菜单的移库、退库、转移、借用、更换、未完成单据、资产申请、耗材申请、新员工领用九类查询页面。统一查询、选择、返回和异常处理；每类单据的范围、字段、日期来源、状态及导出内容由对应PRD定义。

## 2 权限

进入页面、查询、打开详情或审批记录、下载附件及导出时，分别校验当前菜单资格和对应单据的数据权限。需管理员资格的页面同时校验该资格。候选资料的可选范围和业务单据的可见范围分别受授权限制，选择某个人员、组织或仓库不增加单据查看权限。

无菜单或所需资格时停止加载，提示“无权访问此功能”；无单据权限时不显示该单据内容，提示“该单据不存在或无权查看”，可返回列表重新查询。缺少数据范围配置时提示“未配置查询数据范围，请联系权限管理员”，不默认返回全部数据。

## 3 通用规则

1. 页面为员工自助或ES业务入口所生成原单据的查询入口，按各页单据类型及关联范围查询。查询、详情、审批记录和导出使用同一单据及其实际关联结果，不产生新的申请、审批或库存结果。
2. 查询条件均按对应页面定义匹配；不同条件同时满足，同一多选字段满足任一所选值即可。选填条件未填或清空时不增加该限制。
3. 日期按对应字段的业务时间筛选，以北京时间自然日处理。日期区间允许只填开始或结束，开始日包含00:00:00，结束日包含23:59:59。日期展示采用各页面明确的格式，不因展示到日期而截断筛选所用的原时间。
4. 业务编号、标签号及人员、组织编码保持原值和前导零。使用人员账号、组织或仓库编码匹配，名称用于阅读，不以手工修改显示名称改变实际选择。

## 4 页面字段及交互

### 4.1 查询、分页与返回

| 场景／操作 | 交互及结果 |
| --- | --- |
| 首次进入 | 校验资格后，按本页默认条件、默认排序查询获权范围内的单据，展示第一页。首次查询未成功前不展示未经取得的结果或数量。 |
| 编辑条件 | 修改输入或选择值只改变待查询条件；点击“查询”或在文本查询框按回车后应用。不因子选择弹窗关闭而自动替换主列表。 |
| 查询 | 使用本次条件查询，成功后替换列表并回到第一页；保留当前每页条数。页面允许更改排序时使用当前选择的排序，否则使用本页默认排序。 |
| 重置 | 清空查询条件，恢复本页规定的特殊默认值及默认排序，重新查询第一页；保留当前每页条数。 |
| 分页 | 展示匹配总数，支持切换页码和每页条数；调整每页条数后从第一页显示。分页及排序作用于全部匹配结果，不只处理当前页。 |
| 排序 | 仅在页面PRD明确允许时提供；按所选字段及升降序显示结果。未开放交互排序的页面始终使用其默认排序。 |
| 无匹配结果 | 显示“暂无符合条件的单据”，保留已填条件，不自动清空条件、扩大日期或放宽授权。 |
| 打开详情／进度 | 按所点行的原申请和实际关联单据打开，并重新校验当前权限；关联号为空时按字段规则保留空值，不用其他单据代替。 |
| 返回／关闭 | 从详情返回保留最近一次成功查询的条件、页码、每页条数及排序；关闭子明细或进度弹窗返回原单据或列表，不触发办理。 |
| 真实等待 | 查询或加载未结束时显示正在加载，避免重复提交同一查询；不把等待显示成无记录。 |

### 4.2 下拉与选择弹窗

各页面字段表明确使用单选下拉、多选下拉或选择弹窗，并写本字段的匹配方式。下拉展示实际业务名称，支持按名称搜索和清空；不接收不在候选中的手工文本。子公司下拉取组织资料中的子公司，板块下拉取板块资料，状态和配置选项取本页指定业务字典。相同选择弹窗按下表定义一次，各页面引用并补充本字段限制。申请人、制单人、当前审批人、汇总提交人、转出人及接收人统一复用人员选择弹窗，不因角色名称不同改为通用编码名称弹窗。部门、公司、办公区及仓库各复用对应选择模板；公司保留各页规定的单选或多选弹窗，子公司与板块按规定使用下拉框。

候选来源为对应人员、组织、板块、仓库等正式基础资料及该字段的授权范围，不以当前列表是否已有交易倒推这些基础资料候选。未完成单据页的“单据类型”按该页明确的处理中业务集合提供，不套用基础资料候选规则。基础资料存在不代表当前条件一定能查询到单据。人员、组织名称及业务归属按各页字段明确的资料时点展示，不根据候选显示名称另造单据归属。

| 选择对象 | 查询字段与匹配 | 结果字段及回填 |
| --- | --- | --- |
| 人员 | 员工编号（账号）、员工姓名、部门，均为文本框，分别包含匹配，组合时同时满足。 | 员工编号、员工姓名、部门；单选后回填账号及姓名，实际筛选使用账号。部门仅展示明确的人员资料，不借用申请单所属部门补齐。 |
| 部门 | 部门编码、名称，均为文本框，分别包含匹配。 | 部门编码、从子公司至末级部门的完整名称；单选后回填部门编码及完整名称，不以末级简称代替全称。 |
| 公司 | 公司编码、名称，均为文本框，分别包含匹配。 | 公司编码、名称；单多选以对应页面字段为准，多选按所选编码集合过滤。 |
| 办公区 | 办公区编码、名称，均为文本框，分别包含匹配。 | 办公区编码、名称、办公区地址（位于名称列之后）；单选后回填编码及名称。地址缺失留空，不以关联仓库地址代替。 |
| 仓库 | 仓库编码、名称，均为文本框，分别包含匹配。 | 仓库编码、名称、所属公司；单选后回填仓库编码及名称。查询查看权限与出入库办理权限不得互相替代。 |

选择弹窗的入口、确认及异常统一如下：

| 操作／场景 | 结果 |
| --- | --- |
| 打开 | 点击选择字段进入弹窗，展示可选资料及原已选项。弹窗内查询、重置只影响候选列表。 |
| 查询／重置 | 点击查询应用候选条件并回第一页；重置清空候选查询条件。候选查询不清除已选项。 |
| 单选／多选 | 单选最多选择一项；多选可跨页保留选中项，显示已选数量并允许移除。切换页码不丢失选择。 |
| 确定 | 按页面字段要求选择后回填对应编码和名称，关闭弹窗；未选择有效项时提示“请选择一项”或“请至少选择一项”，保留弹窗。 |
| 取消／关闭 | 放弃本次候选选择，保留主查询字段原值。 |
| 清空主字段 | 清除已选编码及显示名称，下次主查询不再使用该条件；不立即改变已展示的列表。 |
| 无候选 | 显示“暂无可选资料”，不虚构候选，允许取消或调整条件重新查询。 |
| 候选加载失败 | 提示“资料加载失败，请重试”，保留主字段原值和已填候选条件，可重新查询或取消；不解释为没有候选。 |

### 4.3 导出与附件

有导出功能的页面按最近一次成功应用的查询条件、排序及当前权限生成Excel；“导出当前页”只取该页，“导出”取全部匹配结果。无结果时保留规定表头。只在文件成功生成并提供下载后提示成功；处理中不重复发起相同导出，失败后可按原条件重试。

详情仅展示源单已有的附件或维修记录，不因查询增加附件或新维修单。附件有下载入口时，点击前校验其所属单据权限；文件失效或下载失败时提示“附件无法下载，请重试或联系单据负责人”，保留原详情。不以空白页面表示下载成功。

## 5 校验

| 触发时机 | 条件 | 处理、提示及下一步 |
| --- | --- | --- |
| 查询或导出 | 起始日期晚于结束日期 | 阻止操作，提示“开始日期不能晚于结束日期”，保留条件，修改后可重试。 |
| 查询 | 查询失败 | 提示“查询失败，请重试”，保留输入条件；如有上次成功结果，保留并标明其对应上次条件，不把它冒充本次结果。用户可重试或重置。 |
| 打开详情或进度 | 原单失效、不存在或不再有权查看 | 停止展示该单内容，提示“该单据不存在或无权查看”，允许返回列表重新查询。 |
| 打开详情或子明细 | 原单存在但必需关联资料缺失 | 提示“关联资料缺失，请联系单据负责人”，保留已取得且获权的内容；不以其他资产或其他申请补位。 |
| 打开审批记录 | 尚未产生审批记录 | 显示“暂无审批记录”；有真实记录时逐条保留，不补造未发生节点。 |
| 读取流程 | 流程读取失败 | 显示“审批记录读取失败，请重试”，保留所属单据；不将失败写成没有审批记录或已完成。 |
| 导出 | 文件生成或下载失败 | 提示“导出失败，请重试”，保留查询条件及列表；不得提示导出成功。 |

## 6 后续操作 / 业务结果 / 补充说明

查询结果展示源单最新取得的业务状态；详情或导出发起前重新核验单据范围。查询返回后保留的列表若已被他人办理，下一次查询读取更新结果，不由查询入口反向修改源单。各页面的单据完成条件、历史兼容、字段来源及尚未明确的业务分支仍按其独立PRD定义。
