# 借用单 PRD

编写日期：2026年10月14日。版本：按现状需求收口的目标规则；修订于2026年10月16日。

## 1 背景

范围为“申请→借用单”的借用／续借查询列表，以及点击申请单号进入的借用详情、续借详情和流程查看。

本篇明确查询、只读详情、全流程信息及Excel导出要求。未定义的业务事项集中放在第6章。

## 2 权限

按人员、部门、公司分配可见单据范围。用户同时具备菜单权限和单据数据权限后，才能查询、查看详情及导出；查看与导出使用同一范围。菜单权限不能替代单据数据权限。无权访问的单据不返回数据，详情及导出入口也须校验。实际授权人员和组织范围由权限配置维护。

## 3 通用规则

3.1 列表包含借用EBA、续借ERB；默认按申请时间倒序。

3.2 列表申请人取制单人，显示账号.姓名；部门按制单人当前用户部门查完整名称，不是单据创建时的部门快照。数量为全部借用明细执行数量合计。

3.3 借用出库单号按出库单来源号关联申请号，找到一张单据后显示其编号；多张匹配单据的取第一张稳定顺序未明确。审批人从所有流程记录按流程序号长度及流程序号倒序取第一条；未限定待办、未排除等待节点，结束后不自动清空。

3.4 查询选填条件为空时不增加过滤；多项条件组合为同时满足。编码、账号和日期用于匹配，显示名称用于阅读。日期从／至在本篇合为一个范围条件。页面存在重置或清空查询条件入口时，统一按“重置”描述；不据此新增原页面未提供的业务动作。

## 4 页面字段及交互

### 4.1 查询条件

进入方式：申请→借用单。

| 字段 | 展示及交互 | 来源和取值逻辑 |
| --- | --- | --- |
| 申请单号 | 文本框，选填 | 按借用或续借申请单号包含匹配。 |
| 借用出库单号 | 文本框，选填 | 关联出库单号前缀匹配，通过来源申请号反查借用或续借申请。 |
| 单据状态 | 下拉框，选填 | 只提供单据状态字典中的1、3、5，精确匹配。 |
| 资产标签号 | 文本框，选填 | 明细标签号前缀匹配，返回包含匹配明细的整张申请。 |
| 资产说明 | 文本框，选填 | 明细物资说明前缀匹配，非任意位置包含匹配。 |
| 单据类型 | 下拉框，选填 | 借用、续借；分别精确匹配EBA、ERB。 |
| 申请人 | 人员单选，选填 | 精确匹配申请头制单人账号。 |
| 子公司 | 组织单选，选填，可清空 | 选择申请人所属子公司，按组织标识精确匹配；与财务公司分开。 |
| 部门 | 部门单选，选填，可清空 | 选择申请人部门，按部门标识精确匹配。 |
| 制单时间 | 日期范围，选填 | 匹配申请头创建时间；含起日00:00:00与止日23:59:59。 |

### 4.5 查看进度弹窗字段及交互

进入方式：申请→借用单→列表“查看”列。借用行使用借用流程类型，续借行使用续借流程类型，业务编号均取本行申请编号。

弹窗标题为“审批信息”，只读展示当前单据从发起至当前节点的完整审批记录。不同节点、不同审批人的有效记录逐条保留，同一流程序号的多人不得仅保留首条。仅按审批记录唯一标识排除同一记录的重复返回。流程结束后保留历史记录。

| 字段 | 展示及交互 | 来源和取值逻辑 |
| --- | --- | --- |
| 审批环节 | 只读 | 记录保存的节点名称。 |
| 审批人 | 只读 | 对应审批人工号及姓名；姓名缺失时仅显示已有工号。 |
| 审批状态 | 只读 | 该记录实际处理结果；当前节点显示待审批。 |
| 审批时间 | 只读 | 实际处理日期；待处理记录为空。 |
| 审批意见 | 只读，支持长文本阅读 | 实际意见；没有意见时留空。 |

按流程节点顺序、审批时间及记录标识稳定排列；无审批记录时显示暂无审批记录。关闭弹窗保留原列表筛选、分页和排序。查询详情不提供同意、驳回或业务办理入口。

### 4.6 页面操作

| 操作 | 触发条件及结果 |
| --- | --- |
| 查询／重置 | 向分页列表提交查询条件。 |
| 查看申请 | 点击申请号，按借用或续借类型打开对应详情，逐条展示全部资产及各自配件。 |
| 导出 | 导出全部匹配结果的单据内容；按单头、逐资产、配件、审批记录分别成表。 |
| 查看流程 | 按业务申请编号打开完整审批记录。 |

## 5 校验

5.1 查询条件选填；申请时间按所选起止日期过滤。

5.2 点击申请单号时根据借用或续借类型打开对应只读详情；流程查看使用该申请编号。

## 6 后续操作 / 业务结果 / 补充说明

6.1 Excel导出字段与单据内容一致，按单据信息、逐条资产明细、附属耗材及配件、审批记录、附件及维修记录分别成表；各表以申请单号关联，子表同时保留主资产标签号。单头包括申请人、子公司、部门、办公区、联系电话、邮箱、公司及本篇特有字段；资产明细包含本篇对应详情的全部业务字段，配件按资产逐项输出。不得仅导出列表列代替完整单据。借用和续借均支持导出，续借次数、原因及起止日期随对应资产输出。

6.2 从详情及进度返回保留已提交查询条件、分页、每页条数和排序。查询、查看及导出不办理申请，不改变资产及申请状态。

6.3 当前尚未定义：正式状态字典、实际授权人员及各组织范围；退库库管员正式取值来源需明确到关联仓库责任人配置。基础资料未匹配时只展示已保存内容，不拼接空值文本或编造人员。
