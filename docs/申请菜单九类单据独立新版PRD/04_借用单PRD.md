# 借用单 PRD

编写日期：2026年10月14日。版本：申请菜单可达页面的现状规则；范围修订于2026年10月15日。

## 1 背景

范围为“申请→借用单”的借用／续借查询列表，以及点击申请单号进入的借用详情、续借详情和流程查看。

本篇用于确认现有页面的字段取值、查询条件和交互结果，供产品与研发核对。未确认事项集中放在第6章，不作为正式规则。

## 2 权限

具有菜单权限的用户可查询借用、续借。查询方法未按当前申请人额外限缩。从列表进入借用或续借详情时为查看模式。

菜单授权来自当前社区及角色配置；管理员菜单查询绕过角色菜单授权，业务办理权限仍以对应页面和节点校验为准。源码未包含运行中的菜单授权数据，不能据页面文件列出实际获权人员名单。

## 3 通用规则

3.1 列表包含借用EBA、续借ERB；默认按申请号倒序，而非按申请时间倒序。

3.2 列表申请人取制单人，显示账号.姓名；部门按制单人当前用户部门查完整名称，不是单据创建时的部门快照。数量为全部借用明细执行数量合计。

3.3 借用出库单号按出库单来源号关联申请号，找到一张单据后显示其编号；多张匹配单据的取第一张稳定顺序未明确。审批人从所有流程记录按流程序号长度及流程序号倒序取第一条；未限定待办、未排除等待节点，结束后不自动清空。

3.4 查询选填条件为空时不增加过滤；多项条件组合为同时满足。编码、账号和日期用于匹配，显示名称用于阅读。日期从／至在本篇合为一个范围条件。页面存在重置或清空查询条件入口时，统一按“重置”描述；不据此新增原页面未提供的业务动作。

## 4 页面字段及交互

### 4.1 查询条件

进入方式：申请→借用单。

| 字段 | 展示及交互 | 来源和取值逻辑 |
| --- | --- | --- |
| 申请单号 | 文本框，选填 | 按借用或续借申请单号包含匹配。 |
| 借用出库单号 | 文本框，选填 | 关联出库单号前缀匹配，通过来源申请号反查借用或续借申请。 |
| 单据状态 | 下拉框，选填 | 只提供单据状态字典中的1、3、5，精确匹配。 |
| 资产标签号 | 文本框，选填 | 明细标签号前缀匹配，返回包含匹配明细的整张申请。 |
| 资产说明 | 文本框，选填 | 明细物资说明前缀匹配，非任意位置包含匹配。 |
| 单据类型 | 下拉框，选填 | 借用、续借；分别精确匹配EBA、ERB。 |
| 申请人 | 人员单选，选填 | 精确匹配申请头制单人账号。 |
| 制单时间 | 日期范围，选填 | 匹配申请头创建时间；含起日00:00:00与止日23:59:59。 |

### 4.5 查看进度弹窗字段及交互

进入方式：申请→借用单→列表“查看”列。借用行使用借用流程类型，续借行使用续借流程类型，业务编号均取本行申请编号。

弹窗标题为“审批信息”，宽800、高550。内容按流程图、审批记录和适用的外部系统记录纵向展示，不使用页签；没有查询条件。弹窗只读，通过外层关闭控件退出，原列表及业务状态不变。

| 字段 | 展示及交互 | 来源和取值逻辑 |
| --- | --- | --- |
| 审批环节 | 只读 | 当前审批记录保存的节点名称。 |
| 审批人 | 只读 | 当前记录保存的审批人工号，拼接“-”及人员基础资料中的当前姓名；不是列表中选出的那一位审批人。工号为空则不拼接；有工号但查不到姓名时，当前代码可能显示工号-null。 |
| 审批状态 | 只读 | 直接显示当前记录保存的审批状态描述，不由页面重新按编码翻译，也不统一改成“审批中”。 |
| 审批时间 | 只读，yyyy-MM-dd | 当前记录保存的审批时间，精确到日；为空时留空。 |
| 审批意见 | 只读，文字自动折行 | 当前记录保存的审批意见；没有意见时留空，不自动填充同意等文案。 |

每张单据的基础审批记录先按流程序号长度、流程序号、审批时间依次升序排列，再对非空流程序号去重，每个序号只保留排序后的第一条；空序号记录不展示。相同排序值没有额外的唯一排序条件。

不同流程序号的多节点、多名审批人逐行显示；相同序号即使有多人也只保留一条，不能按“展示全部并行审批人”理解。此弹窗没有额外剔除跳过、等待节点；是否显示待审批记录取决于已取得的数据，不补齐尚未生成的未来节点。

流程结束后仍显示已取得的记录及其原状态，不清空历史审批人，不统一替换为“流程已结束”。本表没有代理人列，也没有单独的当前节点字段、审批意见输入框、同意或驳回按钮；不提供分页、导出和保存入口。

流程图读取本类型对应的流程配置，在审批记录上方显示；图内节点及连线来自配置。代码以审批时间为空标记对应节点，按记录顺序标记经过的连线；遇到关闭状态时把结束节点纳入连线处理，不另增加一条“结束”审批表记录。未取得流程配置时不保证能显示图，不能把图中全部节点当作都已产生的审批记录。

## 5 校验

5.1 查询条件选填；申请时间按所选起止日期过滤。

5.2 点击申请单号时根据借用或续借类型打开对应只读详情；流程查看使用该申请编号。

## 6 后续操作 业务结果 补充说明

6.1 列表数量及部门、审批人查询时重新填充；字典、用户部门和姓名按当前基础资料。

6.2 借用查询页面未发现导出配置；查看进入借用或续借详情，另可打开流程图。

6.3 基础资料异常时，姓名或名称未匹配到的直接字符串拼接可能保留编码并带空值文本；字典组件按组件实际结果展示，未发现统一显示横线的规则。当前字典数据、实际角色授权及运行环境的菜单链接未随页面源码提供。涉及固定字典名称的取值须以运行环境配置核对；不会自行补写完整枚举。以上说明对应所提供源码，未连接运行系统验证部署版本。
