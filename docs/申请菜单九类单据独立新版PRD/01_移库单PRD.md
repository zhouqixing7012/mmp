# 移库单 PRD

编写日期：2026年10月14日。版本：申请菜单可达页面的现状规则；范围修订于2026年10月15日。

## 1 背景

范围为“申请→移库单”的查询列表、点击移库单号进入的只读详情，以及详情内的物资明细查看。

本篇用于确认现有页面的字段取值、查询条件和交互结果，供产品与研发核对。未确认事项集中放在第6章，不作为正式规则。

## 2 权限

具有对应菜单权限的用户进入移库单查询页。查询方法限定移库单类型，未追加当前用户仓库权限条件。从此查询入口进入详情时按只读模式展示。具体菜单角色以实际授权配置为准。

## 3 通用规则

3.1 列表默认按制单时间倒序；点击列头可提交排序字段。数量为本单全部明细的移库数量之和，空合计按0显示。

3.2 查询页接收人：未完成且未驳回时，读取移入仓库当前有入库权限的人员；已完成或已驳回时，取最后更新人，最后更新人为空时取制单人。此字段不是始终取实际签收人。

3.3 移库单头的移出、移入仓库展示取已记录的业务仓库编码对应名称。

3.4 查询选填条件为空时不增加过滤；多项条件组合为同时满足。编码、账号和日期用于匹配，显示名称用于阅读。日期从／至在本篇合为一个范围条件。页面存在重置或清空查询条件入口时，统一按“重置”描述；不据此新增原页面未提供的业务动作。

## 4 页面字段及交互

### 4.1 查询条件

进入方式：申请→移库单。

| 字段 | 展示及交互 | 来源和取值逻辑 |
| --- | --- | --- |
| 移库单号 | 文本框，选填 | 按移库单号包含匹配，例如输入部分编号可查询包含该内容的单据。 |
| 单据状态 | 下拉框，选填，默认全部 | 读取单据状态字典；当前通用查询按选择的状态编码包含匹配。 |
| 制单人 | 人员单选，显示账号及姓名 | 保存人员账号；按单据制单人账号包含匹配，并非按显示姓名匹配。 |
| 制单日期 | 日期范围，选填 | 匹配单据创建时间；起日从00:00:00开始，止日到23:59:59，含两端；可以只选一端。 |
| 资产标签号 | 文本框，选填 | 查询含有该资产明细的移库单；明细标签号包含匹配，满足条件后展示整张单据。 |

| 移入仓库 | 只读展示。 | 取单头保存的移入业务仓库编码，查询仓库名称，显示编码.名称。 |

## 5 校验

5.1 查询条件选填；制单日期范围按起止日期过滤，日期控件约束开始日期不晚于结束日期。

5.2 从查询列表进入详情时保留查询来源标识，展示只读详情；明细弹窗关闭后不写入接收或验证结果。

## 6 后续操作 业务结果 补充说明

6.1 查询和详情每次从业务单据读取；基础名称按查询时的数据翻译。

6.2 查询导出列为移库单号、状态、移出仓库、移入仓库、制单日期、制单人、物资数量、接收人。页面与导出的人员连接符存在差异，导出制单人为账号-姓名；结束后的接收人导出为账号.姓名。

6.3 导出服务按1000条读取但批次数按另一分母计算，存在大数据量批次计算不一致；需用大于1000条结果核对完整性。

6.4 基础资料异常时，姓名或名称未匹配到的直接字符串拼接可能保留编码并带空值文本；字典组件按组件实际结果展示，未发现统一显示横线的规则。当前字典数据、实际角色授权及运行环境的菜单链接未随页面源码提供。涉及固定字典名称的取值须以运行环境配置核对；不会自行补写完整枚举。以上说明对应所提供源码，未连接运行系统验证部署版本。
