# 移库单 PRD

编写日期：2026年10月14日。版本：按现状需求收口的目标规则；修订于2026年10月16日。

## 1 背景

范围为“申请→移库单”的查询列表、只读单据详情、物资明细及导出；数据直接读取库存管理发起的移库单及其资产明细、接收结果，不为查询入口另建一批交易数据。当前移库仅包含资产，范围及业务规则以[库存管理—移库PRD](../PRD-库存管理-移库.md)为准。

本篇明确查询、只读详情、全流程信息及Excel导出要求。未定义的业务事项集中放在第6章。

## 2 权限

按人员、部门、公司分配可见单据范围。用户同时具备菜单权限和单据数据权限后，才能查询、查看详情及导出；查看与导出使用同一范围。菜单权限不能替代单据数据权限。无权访问的单据不返回数据，详情及导出入口也须校验。实际授权人员和组织范围由权限配置维护。

## 3 通用规则

3.0 本入口为原业务单据的只读查询投影。单号、单头状态、明细状态和验证结果均取原移库单；源单新增、修改、调出、接收或驳回后，查询及导出读取对应最新记录，不在查询端重新计算或猜测状态编码。单头状态为草稿、出库待接收、已完成、已驳回，计算规则引用库存移库PRD第3.6～3.8节。

3.1 列表默认按制单时间倒序；点击列头可提交排序字段。数量为本单全部明细的移库数量之和，空合计按0显示。

3.2 查询页接收人：未完成且未驳回时，读取移入仓库当前有入库权限的人员；已完成或已驳回时，取最后更新人，最后更新人为空时取制单人。此字段不是始终取实际签收人。

3.3 移库单头的移出、移入仓库展示取已记录的业务仓库编码对应名称。

3.4 查询选填条件为空时不增加过滤；多项条件组合为同时满足。编码、账号和日期用于匹配，显示名称用于阅读。日期从／至在本篇合为一个范围条件。页面存在重置或清空查询条件入口时，统一按“重置”描述；不据此新增原页面未提供的业务动作。

## 4 页面字段及交互

### 4.1 查询条件

进入方式：申请→移库单。

| 字段 | 展示及交互 | 来源和取值逻辑 |
| --- | --- | --- |
| 移库单号 | 文本框，选填 | 按移库单号包含匹配，例如输入部分编号可查询包含该内容的单据。 |
| 单据状态 | 下拉框，选填，默认全部 | 复用库存移库的草稿、出库待接收、已完成、已驳回四个状态，按所选状态精确匹配。 |
| 制单人 | 人员单选，显示账号及姓名 | 保存人员账号；按单据制单人账号包含匹配，并非按显示姓名匹配。 |
| 制单日期 | 日期范围，选填 | 匹配单据创建时间；起日从00:00:00开始，止日到23:59:59，含两端；可以只选一端。 |
| 资产标签号 | 文本框，选填 | 查询含有该资产明细的移库单；明细标签号包含匹配，满足条件后展示整张单据。 |

进入方式：申请→移库单，查询条件下方的列表。

| 字段 | 展示及交互 | 来源和取值逻辑 |
| --- | --- | --- |

| 移库单号 | 只读展示；提供详情或明细链接。 | 本单据保存的单据编号；以该编号关联流程记录。 |
| 单据状态 | 只读展示。 | 原移库单保存的当前状态名称；与库存管理列表一致。 |
| 移出仓库 | 只读展示。 | 取单头保存的移出业务仓库编码，查询仓库主数据名称，显示编码.名称；不是当前用户所有可出库仓库拼接。 |
| 移入仓库 | 只读展示。 | 取单头保存的移入业务仓库编码，查询仓库名称，显示编码.名称。 |
| 制单日期 | 只读展示；日期格式yyyy-MM-dd。 | 单据创建时间。 |
| 制单人 | 只读展示。 | 单据创建人的账号及当前姓名。 |

| 接收人 | 只读展示。 | 未完成且未驳回时取目标仓库可接收人员；完成或驳回时取最后更新人，缺少最后更新人退回制单人。 |

### 4.6 页面操作

## 5 校验

5.1 查询条件选填；制单日期范围按起止日期过滤，日期控件约束开始日期不晚于结束日期。

5.2 从查询列表进入详情时保留查询来源标识，展示只读详情；明细弹窗关闭后不写入接收或验证结果。

## 6 后续操作 / 业务结果 / 补充说明

6.1 Excel导出包含当前筛选范围内单据的全部内容，支持当前页和全部匹配结果。按单据信息、逐条资产明细、附属耗材及配件、审批记录、附件及维修记录分别成表；无对应记录的表保留表头。

6.2 单据信息包含本篇详情单头所有字段；逐条明细包含业务行号、资产验证、移库状态、资产标签号、物资说明、物资总类、数量、公司、板块、资产标记、启用日期、资产状态，以及4.4～4.5定义的关联移库、接收及资产资料。资产验证按4.3规定判定，导出同步包含出库及入库验证时间。各表以移库单号关联，不能仅导出列表八列代替单据内容。

6.3 从详情返回保留已提交查询条件、分页、每页条数和排序；关闭明细弹窗保留当前单据。查询与导出不改变移库、接收或库存状态。

6.4 当前尚未定义：独立接收单编号及接收时间的具体业务来源、仓库库区／货位启用配置和实际授权名单；取得明确配置后展示，不生成无依据的业务值。
