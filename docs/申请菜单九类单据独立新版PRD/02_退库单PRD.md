# 退库单 PRD

编写日期：2026年10月14日。版本：申请菜单可达页面的现状规则；范围修订于2026年10月15日。

## 1 背景

范围为“申请→退库单”的查询列表、退库申请只读详情和流程查看。

## 2 权限

具有对应菜单权限的用户进入退库单查询。列表提供单据详情、流程查看、导出及删除入口；批量删除只处理草稿单据，具体角色以实际授权配置为准。

## 3 通用规则

3.1 默认按单据创建时间倒序。列表申请时间显示申请业务日期，日期查询仍比较创建时间；导出申请时间取创建时间。

3.2 物资数量为申请全部明细执行数量之和；列表资产标签号只取找到的第一条明细标签号，未拼接全部标签号。

3.3 列表审批人取审批历史排序后的最后一条：剔除跳过及等待节点，按流程序号长度和流程序号升序、同序号去重后取最后一条；没有记录时为空。该规则未限定为待审批人，流程结束后仍可保留最后处理人。

3.4 查询选填条件为空时不增加过滤；多项条件组合为同时满足。编码、账号和日期用于匹配，显示名称用于阅读。日期从／至在本篇合为一个范围条件。页面存在重置或清空查询条件入口时，统一按“重置”描述；不据此新增原页面未提供的业务动作。

## 4 页面字段及交互

### 4.1 查询条件

进入方式：申请→退库单。

| 字段 | 展示及交互 | 来源和取值逻辑 |
| --- | --- | --- |
| 申请单号 | 文本框，选填 | 按退库申请编号包含匹配。 |
| 退库类型 | 下拉框，选填 | 选项为资产退库、离职归还；匹配单据保存的退库类型，精确匹配。 |
| 单据状态 | 下拉框，选填，默认全部 | 读取申请状态字典中的0、1、3、5；按状态编码精确匹配。 |
| 资产标签号 | 文本框，选填 | 明细资产标签号前缀匹配；筛出包含匹配明细的整张申请单。 |
| 申请人 | 人员单选，选填 | 实际匹配单据制单人账号，包含匹配；与详情申请人读取的单据申请人字段存在来源区别。 |
| 仓库 | 仓库选择，选填 | 选择保存仓库编码，按申请头仓库编码包含匹配；手动修改显示名称不等于修改所选编码。 |
| 退库单号 | 文本框，选填 | 按关联入库单编号包含匹配，再通过该入库单的来源申请号筛选退库申请。 |
| 申请时间 | 日期范围，选填 | 查询单据创建时间，含起日00:00:00和止日23:59:59；列表申请时间另取申请业务日期。 |

### 4.4 查看进度弹窗字段及交互

进入方式：申请→退库单→列表“进度查看”列的“查看”。使用当前退库申请编号及退库流程类型。

弹窗标题为“审批信息”，宽800、高550。内容按流程图、审批记录和适用的外部系统记录纵向展示，不使用页签；没有查询条件。弹窗只读，通过外层关闭控件退出，原列表及业务状态不变。

| 字段 | 展示及交互 | 来源和取值逻辑 |
| --- | --- | --- |
| 审批环节 | 只读 | 当前审批记录保存的节点名称。 |
| 审批人 | 只读 | 当前记录保存的审批人工号，拼接“-”及人员基础资料中的当前姓名；不是列表中选出的那一位审批人。工号为空则不拼接；有工号但查不到姓名时，当前代码可能显示工号-null。 |
| 审批状态 | 只读 | 直接显示当前记录保存的审批状态描述，不由页面重新按编码翻译，也不统一改成“审批中”。 |
| 审批时间 | 只读，yyyy-MM-dd | 当前记录保存的审批时间，精确到日；为空时留空。 |
| 审批意见 | 只读，文字自动折行 | 当前记录保存的审批意见；没有意见时留空，不自动填充同意等文案。 |

每张单据的基础审批记录先按流程序号长度、流程序号、审批时间依次升序排列，再对非空流程序号去重，每个序号只保留排序后的第一条；空序号记录不展示。相同排序值没有额外的唯一排序条件。

不同流程序号的多节点、多名审批人逐行显示；相同序号即使有多人也只保留一条，不能按“展示全部并行审批人”理解。此弹窗没有额外剔除跳过、等待节点；是否显示待审批记录取决于已取得的数据，不补齐尚未生成的未来节点。

流程结束后仍显示已取得的记录及其原状态，不清空历史审批人，不统一替换为“流程已结束”。本表没有代理人列，也没有单独的当前节点字段、审批意见输入框、同意或驳回按钮；不提供分页、导出和保存入口。

流程图读取本类型对应的流程配置，在审批记录上方显示；图内节点及连线来自配置。代码以审批时间为空标记对应节点，按记录顺序标记经过的连线；遇到关闭状态时把结束节点纳入连线处理，不另增加一条“结束”审批表记录。未取得流程配置时不保证能显示图，不能把图中全部节点当作都已产生的审批记录。

### 4.5 页面操作

| 操作 | 触发条件及结果 |
| --- | --- |
| 查询／重置 | 按本篇条件过滤退库申请。 |
| 查看 | 按申请标识取单头与第一条明细、附属耗材及审批历史。 |
| 删除 | 勾选单据确认后，只删除草稿及其明细，解除资产锁，返回成功数量。 |
| 导出 | 按导出入口获取当前页或全部匹配结果；字段以本篇导出配置为准。 |

## 5 校验

5.1 批量删除只处理草稿；删除明细后解除相关资产业务锁，反馈提交数和成功删除数。

5.2 详情在缺少资产关联时提示单据行数据异常；当前详情加载未给资产关联变量赋值，即使有明细也可能出现该提示，不能直接判定资产已删除。

## 6 后续操作 业务结果 补充说明

6.1 查询导出列为申请单号、退库单号、状态、业务类型、审批人、申请人、申请时间、标签号、退库原因、数量、是否赔偿；状态及赔偿标记按字典翻译。

6.2 列表与导出申请时间取值不同：列表取申请业务日期，导出取创建时间。

6.3 详情仅取第一条主明细显示资产信息，耗材附属信息按第一条资产标签号查当前挂接资产。

6.4 基础资料异常时，姓名或名称未匹配到的直接字符串拼接可能保留编码并带空值文本；字典组件按组件实际结果展示，未发现统一显示横线的规则。当前字典数据、实际角色授权及运行环境的菜单链接未随页面源码提供。涉及固定字典名称的取值须以运行环境配置核对；不会自行补写完整枚举。以上说明对应所提供源码，未连接运行系统验证部署版本。
