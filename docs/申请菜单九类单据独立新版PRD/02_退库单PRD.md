# 退库单 PRD

编写日期：2026年10月14日。版本：按现状需求收口的目标规则；修订于2026年10月16日。

## 1 背景

范围为“申请→退库单”的查询列表、退库申请只读详情和流程查看。查询入口不提供单据删除；源业务创建或办理入口按其自身权限和规则处理删除。

## 2 权限

按人员、部门、公司分配可见单据范围。用户同时具备菜单权限和单据数据权限后，才能查询、查看详情及导出；查看与导出使用同一范围。菜单权限不能替代单据数据权限。无权访问的单据不返回数据，详情及导出入口也须校验。实际授权人员和组织范围由权限配置维护。

## 3 通用规则

3.1 默认按单据创建时间倒序。列表申请时间显示申请业务日期，日期查询仍比较创建时间；导出申请时间取创建时间。

3.2 物资数量为申请全部明细执行数量之和；列表资产标签号只取找到的第一条明细标签号，未拼接全部标签号。

3.3 列表审批人取审批历史排序后的最后一条：剔除跳过及等待节点，按流程序号长度和流程序号升序、同序号去重后取最后一条；没有记录时为空。该规则未限定为待审批人，流程结束后仍可保留最后处理人。

3.4 查询选填条件为空时不增加过滤；多项条件组合为同时满足。编码、账号和日期用于匹配，显示名称用于阅读。日期从／至在本篇合为一个范围条件。页面存在重置或清空查询条件入口时，统一按“重置”描述；不据此新增原页面未提供的业务动作。

## 4 页面字段及交互

### 4.1 查询条件

进入方式：申请→退库单。

| 字段 | 展示及交互 | 来源和取值逻辑 |
| --- | --- | --- |
| 申请单号 | 文本框，选填 | 按退库申请编号包含匹配。 |
| 退库类型 | 下拉框，选填 | 选项为资产退库、离职归还；匹配单据保存的退库类型，精确匹配。 |
| 单据状态 | 下拉框，选填，默认全部 | 读取申请状态字典中的0、1、3、5；按状态编码精确匹配。 |
| 资产标签号 | 文本框，选填 | 明细资产标签号前缀匹配；筛出包含匹配明细的整张申请单。 |
| 申请人 | 人员单选，选填 | 实际匹配单据制单人账号，包含匹配；与详情申请人读取的单据申请人字段存在来源区别。 |
| 仓库 | 仓库选择，选填 | 选择保存仓库编码，按申请头仓库编码包含匹配；手动修改显示名称不等于修改所选编码。 |
| 退库单号 | 文本框，选填 | 按关联入库单编号包含匹配，再通过该入库单的来源申请号筛选退库申请。 |
| 子公司 | 组织单选，选填，可清空 | 选择申请人所属子公司，按组织标识精确匹配；与财务公司分开。 |
| 部门 | 部门单选，选填，可清空 | 选择申请人部门，按部门标识精确匹配。 |
| 申请时间 | 日期范围，选填 | 查询单据创建时间，含起日00:00:00和止日23:59:59；列表申请时间另取申请业务日期。 |

### 4.4 查看进度弹窗字段及交互

进入方式：申请→退库单→列表“进度查看”列的“查看”。使用当前退库申请编号及退库流程类型。

弹窗标题为“审批信息”，只读展示当前单据从发起至当前节点的完整审批记录。不同节点、不同审批人的有效记录逐条保留，同一流程序号的多人不得仅保留首条。仅按审批记录唯一标识排除同一记录的重复返回。流程结束后保留历史记录。

| 字段 | 展示及交互 | 来源和取值逻辑 |
| --- | --- | --- |
| 审批环节 | 只读 | 记录保存的节点名称。 |
| 审批人 | 只读 | 对应审批人工号及姓名；姓名缺失时仅显示已有工号。 |
| 审批状态 | 只读 | 该记录实际处理结果；当前节点显示待审批。 |
| 审批时间 | 只读 | 实际处理日期；待处理记录为空。 |
| 审批意见 | 只读，支持长文本阅读 | 实际意见；没有意见时留空。 |

按流程节点顺序、审批时间及记录标识稳定排列；无审批记录时显示暂无审批记录。关闭弹窗保留原列表筛选、分页和排序。查询详情不提供同意、驳回或业务办理入口。

### 4.5 页面操作

| 操作 | 触发条件及结果 |
| --- | --- |
| 查询／重置 | 按本篇条件过滤退库申请。 |
| 查看 | 按申请标识取单头与第一条明细、附属耗材及审批历史。 |

## 5 校验

5.1 查询入口不得删除申请、明细或解除资产业务锁；相关操作由源业务办理入口按其权限及规则处理。

5.2 详情须以申请标识核验访问权限；缺少关联资产或单据行时明确提示数据异常，不把缺少关联自动解释为资产已删除。

## 6 后续操作 / 业务结果 / 补充说明

6.1 Excel导出字段与单据内容一致，按单据信息、逐条资产明细、附属耗材及配件、审批记录、附件及维修记录分别成表；各表以申请单号关联，子表同时保留主资产标签号。单头包括申请人、子公司、部门、办公区、联系电话、邮箱、公司及本篇特有字段；资产明细包含本篇对应详情的全部业务字段，配件按资产逐项输出。不得仅导出列表列代替完整单据。退库导出同时包括是否赔偿、库管员、鉴定、附件与维修记录，支持当前页及全部匹配结果。

6.2 从详情及进度返回保留已提交查询条件、分页、每页条数和排序。查询、查看及导出不办理申请，不改变资产及申请状态。

6.3 当前尚未定义：正式状态字典、实际授权人员及各组织范围；退库库管员正式取值来源需明确到关联仓库责任人配置。基础资料未匹配时只展示已保存内容，不拼接空值文本或编造人员。
