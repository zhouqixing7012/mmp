# 转移单 PRD

## 1 背景

在“申请→转移单”查询员工资产转移申请及其关联转移单，核对转出人、接收人、资产明细和审批进度。查询包含处理中、已驳回、已完成的申请；尚未生成转移单的申请仍可查询，关联转移单号留空。

本菜单提供查询、只读详情、审批进度及 Excel 导出。资产转移的创建、草稿修改和执行属于业务办理，不作为本申请查询菜单的操作。

## 2 权限

支持按人员、部门、公司配置数据权限。查询结果、详情、审批记录、关联明细和导出均受相同权限范围约束。拥有菜单权限不代表拥有全部公司的转移申请查看权限。

| 操作 | 数据范围 | 无权限结果 |
| --- | --- | --- |
| 查询 | 已配置人员、部门、公司授权范围内的申请 | 不返回范围外的申请 |
| 查看详情、进度 | 当前有权查看的同一申请 | 拒绝读取，无权记录不能通过单号直接访问 |
| 导出 | 当前查询条件及授权范围内的申请 | 不扩大范围；无匹配记录输出表头 |

具体授权人员、组织和所属台账范围由权限配置维护，不改变查询、详情与导出的同范围要求。

## 3 通用规则

1. 以员工申请为查询主体，关联资产转移单及核心转移单；申请单号与转移单号分别保留，不互相替代。
2. 同一申请的多条资产分别保留，物资数量为申请资产行数量之和。
3. 审批进度展示已发生记录及当前待审批记录；待审批记录的时间、意见允许为空。不同审批人的记录分别保留。
4. 子公司与财务公司分别取值；转出人、接收人及不同资产分别关联各自业务信息。

## 4 页面字段及交互

本章的首次查询、条件组合、重置、分页、返回保留、日期区间、选择控件、空结果及失败处理，遵循[申请查询公共交互规则](申请查询公共交互规则.md)。本页字段表补充查询对象、匹配方式及专有约束。

### 4.1 查询条件

查询条件按下表匹配；人员及组织控件的候选与选择规则见公共交互规则。

| 查询条件 | 类型及取值 | 匹配与交互 |
| --- | --- | --- |
| 申请单号 | 文本框 | 对员工转移申请单号模糊查询 |
| 转移单号 | 文本框 | 对关联转移单号模糊查询；无关联单号不匹配已填写条件 |
| 单据状态 | 可搜索、可清空的单选下拉框 | 按申请当前状态准确匹配，包含处理中、已驳回、已完成 |
| 转出人 | 人员选择弹窗，单选 | 按申请保存的转出人标识准确匹配，显示账号及姓名 |
| 接收人 | 人员选择弹窗，单选 | 按申请保存的接收人标识准确匹配，显示账号及姓名 |
| 转出人子公司 | 子公司单选下拉框 | 按转出人所属子公司准确匹配 |
| 转出人部门 | 部门选择弹窗，单选 | 按转出人所属部门准确匹配，显示编码及名称 |
| 制单时间 | 日期区间 | 匹配申请时间，起止日均包含，可单独填写一端 |

### 4.4 Excel 导出

导出当前条件下全部有权查看的匹配申请，按列表排序生成工作簿。按申请单号关联以下工作表，字段取当前申请及关联明细。

| 工作表 | 字段 |
| --- | --- |
| 申请单头 | 申请单号、转移单号、单据状态、转出人、转出公司、转出部门、转出联系电话、转出邮箱、接收人、接收公司、接收部门、接收联系电话、接收邮箱、申请时间、转移类型、物资数量、转出原因、使用用途 |
| 转移资产 | 申请单号及逐条资产标签号、SN号、资产说明、配置、数量、资产状态、资产用途、使用用途（本次转移）、公司、City、Building、Floor、仓库、启用日期、模块、备注（转移备注说明）、耗材信息、物资说明；无对应业务值留空 |
| 部件明细 | 申请单号、主资产标签号、部件标签号、物料说明、配置、数量 |
| 审批记录 | 申请单号、审批环节、审批人、代理人、审批状态、审批时间、审批意见 |

资产行和部件行分别展开。编号按文本输出并保留前导零；时间保留原记录精度，数量输出数值；关联执行单号为空时保留申请及明细，空工作表保留表头。

## 5 校验

日期、无权限、记录失效及导出失败的提示与修正方式遵循公共交互规则。

| 触发时机 | 判断条件 | 处理及用户下一步 |
| --- | --- | --- |
| 查询及导出 | 开始日期晚于结束日期 | 阻止操作，提示“开始日期不能晚于结束日期”；调整日期后重新查询或导出 |
| 打开详情、进度、部件及导出 | 记录存在且当前仍在授权范围内 | 重新校验；不满足时阻止，按公共规则提示无权限或记录失效，不用其他记录替代 |
| 查询编号或组织条件 | 匹配对应申请编号、关联转移单编号及转出人组织 | 按各字段独立匹配；没有关联转移单号的申请不满足已填写的转移单号条件，但保留在无该条件的结果中 |

## 6 后续操作 / 业务结果 / 补充说明

### 6.1 查询结果

查询和导出只读取单据及审批记录，不改变资产责任人、位置、费用账户或单据状态，也不触发资产转移。实际转移结果由对应业务办理流程生成，关联后可在申请中查看。
