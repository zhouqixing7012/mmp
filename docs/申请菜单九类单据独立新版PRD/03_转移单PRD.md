# 转移单 PRD

## 1 背景

在“申请→转移单”查询员工发起的资产转移申请及其关联转移单，核对转出人、接收人、资产明细和审批进度。查询包含处理中、已驳回、已完成的申请；尚未生成转移单的申请仍可查询，关联转移单号留空。

本菜单提供查询、只读详情、审批进度及 Excel 导出。资产转移的创建、草稿修改和执行属于业务办理，不作为本申请查询菜单的操作。

## 2 权限

支持按人员、部门、公司配置数据权限。查询结果、详情、审批记录、关联明细和导出均受相同权限范围约束。拥有菜单权限不代表拥有全部公司的转移申请查看权限。

| 操作 | 数据范围 | 无权限结果 |
| --- | --- | --- |
| 查询 | 已配置人员、部门、公司授权范围内的申请 | 不返回范围外的申请 |
| 查看详情、进度 | 当前有权查看的同一申请 | 拒绝读取，无权记录不能通过单号直接访问 |
| 导出 | 当前查询条件及授权范围内的申请 | 不扩大范围；无匹配记录输出表头 |

## 3 通用规则

1. 以员工申请为查询主体，关联资产转移单及核心转移单；申请单号与转移单号分别保留，不互相替代。
2. 按申请时间排序。默认由新到旧；列表进入详情后返回，保留已查询条件、排序和分页。
3. 同一申请的多条资产逐条展示，不只取第一条；物资数量为申请资产行数量之和。
4. 审批进度展示已发生记录及当前待审批记录；待审批记录的时间、意见允许为空。不同审批人的记录分别保留。
5. 申请查询不会修改资产责任人、位置、费用账户或单据状态。

## 4 页面字段及交互

### 4.1 查询条件

各条件均非必填，初始为空；不同条件同时满足才返回。编号文本支持包含匹配；人员、组织支持搜索后选择并按所选标识匹配。日期从、至合为一个区间条件。

| 查询条件 | 类型及取值 | 匹配与交互 |
| --- | --- | --- |
| 申请单号 | 文本框 | 对员工转移申请单号模糊查询 |
| 转移单号 | 文本框 | 对关联转移单号模糊查询；无关联单号不匹配已填写条件 |
| 单据状态 | 可清空下拉 | 按申请当前状态准确匹配，包含处理中、已驳回、已完成 |
| 转出人 | 人员选择 | 按申请保存的转出人标识准确匹配，显示账号及姓名 |
| 接收人 | 人员选择 | 按申请保存的接收人标识准确匹配，显示账号及姓名 |
| 转出人子公司 | 组织选择 | 按转出人所属子公司准确匹配 |
| 转出人部门 | 部门选择 | 按转出人所属部门准确匹配，显示编码及名称 |
| 制单时间 | 日期区间 | 匹配申请时间，起止日均包含，可单独填写一端 |

点击“查询”应用条件并回到第一页；点击“重置”清空条件和排序，重新显示授权范围内结果。查询为零条时显示空列表，不自动放宽条件。

| 字段 | 来源及规则 |
| --- | --- |
| 申请单号 | 员工申请编号，点击进入只读详情 |
| 转移单号 | 已关联的转移单编号，未生成时为空 |
| 单据状态 | 申请当前业务状态名称 |
| 转出人 | 转出人账号及姓名 |
| 转出公司 | 转出人所属财务公司名称 |
| 接收人 | 接收人账号及姓名 |
| 接收公司 | 接收人所属财务公司名称 |
| 申请时间 | 员工申请提交时间，列表显示年月日 |
| 转移类型 | 本申请保存的类型，例如一般转移 |
| 物资数量 | 全部申请资产行数量求和 |
| 进度查看 | 点击查看本申请及明确关联的业务审批记录 |

列表提供分页和“导出”。申请单号在处理中、已驳回和已完成状态均可进入详情。

| 转移类型 | 本申请保存的转移类型 |

| 转移单号 | 关联转移单编号，尚未生成时留空 |

#### 4.3.2 接收人信息

| 字段 | 来源及规则 |
| --- | --- |

点击资产行部件数量打开弹窗，仅展示该资产对应部件；无部件显示空表。

| --- | --- |
| 审批环节 | 实际审批记录的节点名称，显示至当前节点 |

### 4.4 Excel 导出

导出当前条件下全部有权查看的匹配申请，按列表排序生成工作簿。按申请单号关联各工作表，字段同单据内容，不能仅导出列表列。

| 工作表 | 字段 |
| --- | --- |
| 申请单头 | 申请单号、转移单号、单据状态、转出人、转出公司、转出部门、转出联系电话、转出邮箱、接收人、接收公司、接收部门、接收联系电话、接收邮箱、申请时间、转移类型、物资数量、转出原因、使用用途 |
| 转移资产 | 申请单号及逐条资产标签号、SN号、资产说明、配置、数量、资产状态、资产用途、公司、City、Building、Floor、仓库、启用日期、模块、备注、耗材信息、物资说明；无对应业务值留空 |
| 部件明细 | 申请单号、主资产标签号、部件标签号、物料说明、配置、数量 |
| 审批记录 | 申请单号、审批环节、审批人、代理人、审批状态、审批时间、审批意见 |

资产行和部件行分别展开，不将多资产数量累计到首条。编号按文本输出；时间保留原记录，数量输出数值。未生成执行单时，申请和资产仍正常导出，转移单号为空。

## 5 校验

1. 起始日期晚于结束日期时，提示开始日期不能晚于结束日期并停止查询和导出。
2. 子公司与财务公司分别取值，不能根据仓库财务公司推断子公司。人员及组织条件按各自字段匹配，转出与接收信息不得使用同一来源；同一申请不同资产不能拼接成一条虚构明细。
3. 详情、进度和导出前校验查看权限；记录不存在或无权限时明确提示，不返回其他申请替代。
4. 不因关联执行单号为空而排除申请，不用执行单状态限制申请查看。

## 6 后续操作 / 业务结果 / 补充说明

### 6.1 查询结果

查询和导出只读取单据及审批记录，不触发资产转移。实际转移结果由对应业务办理流程生成，关联后可在申请中查看。

### 6.2 当前尚未定义

| 事项 | 已明确范围与待补信息 |
| --- | --- |
| 转出人组织条件 | 现状文字重复列出转出人子公司、部门，本版各保留一次；是否另需接收人子公司、部门筛选尚未明确 |
| 类型与状态字典 | 一般转移及处理中、已驳回、已完成有现状示例；完整类型、状态编码与名称映射待补，不猜编码 |
| 多个执行单 | 同一申请关联多个执行单时的列表展开方式及全部关联单据展示结构尚未明确 |
| 正式授权配置 | 具体人员、部门、公司授权名单及组合配置待提供；此项不取消权限限制 |
