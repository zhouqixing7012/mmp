# 转移单 PRD

编写日期：2026年10月14日。版本：申请菜单可达页面的现状规则；范围修订于2026年10月15日。

## 1 背景

资产转移执行单查询、填写、详情和明细填写。员工转移申请与执行单通过来源申请号关联。

本篇用于确认现有页面的字段取值、查询条件和交互结果，供产品与研发核对。未确认事项集中放在第6章，不作为正式规则。

## 2 权限

具有菜单权限的用户可查询。只查询资产转移执行单，且迁移有效标记为空或为Y。查询方法未按当前制单人额外限制。草稿显示编辑，其他状态显示查看；后台批量删除只禁止已完成单据。

菜单授权来自当前社区及角色配置；管理员菜单查询绕过角色菜单授权，业务办理权限仍以对应页面和节点校验为准。源码未包含运行中的菜单授权数据，不能据页面文件列出实际获权人员名单。

## 3 通用规则

3.1 默认按创建时间倒序。物资数量为本单全部明细转移数量合计，空合计按0。

3.2 新建制单人、制单时间取登录用户和当前时间，状态为草稿；公司默认登录用户所属公司。首次保存生成转移单编号。修改公司并保存后，清理不属于新公司编码的明细，已有明细不自动改写为新公司。

3.3 原责任人、原部门、原成本中心、原地点、原板块等在选择资产时由资产卡片带入明细；保存时再读取部分资产信息并锁定资产。转入属性取本次明细填写值。

3.4 查询选填条件为空时不增加过滤；多项条件组合为同时满足。编码、账号和日期用于匹配，显示名称用于阅读。日期从／至在本篇合为一个范围条件。页面存在重置或清空查询条件入口时，统一按“重置”描述；不据此新增原页面未提供的业务动作。

### 4.7 页面操作

| 操作 | 触发条件及结果 |
| --- | --- |
| 查询／重置 | 按头条件和同一明细上的复合条件查询。 |
| 创建转移单 | 带入登录用户、当前日期及公司，进入草稿填写。 |
| 保存／添加或删除明细 | 保存后产生编号；选定资产带入原属性，填写转入属性；删除明细同时解除资产锁。 |
| 执行转移 | 二次确认后检查明细、重复标签号、账簿及费用账户；成功更新资产并完成单据。 |
| 批量删除 | 禁止已完成单据；其余按后台删除规则处理并反馈结果。 |

## 5 校验

5.1 保存前必须选择公司。执行转移必须有明细，并阻止同一资产标签号重复。

5.2 资产选择范围限定单头公司，资产状态3、6、7、8且未被锁定；不得把已锁定资产再加入。
