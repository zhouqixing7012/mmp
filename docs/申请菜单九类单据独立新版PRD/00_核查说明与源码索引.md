# 申请菜单九类单据依据及源码索引

## 当前目标文档入口（2026-10-26）

申请菜单目标以本目录01～09独立PRD和[申请查询公共交互规则](申请查询公共交互规则.md)为准；本文件以下源码、旧取值及旧页面范围仅保留作来源追溯，不恢复已取消的查询办理或删除入口。本轮逐篇整改及字数见[交付记录](比对报告/申请菜单PRD偏好整改交付-20261026.md)。

2026年10月16日整改以用户提供的《后台报表&申请》申请部分为准；已确认的日期区间、按钮名称及预计金额口径继续保留。旧源码仅作为取值追溯，不能撤销原文已明确的查询、导出、权限和通知需求。九篇正文描述目标业务，技术差异留在比对报告。

范围修订于2026年10月16日。申请菜单承载申请查询及可达详情、进度、导出；员工自助、仓库办理仍在各自入口。转移以员工申请为主并关联执行单；更换依据现状正文及附件补齐只读查询。新员工领用没有独立现状申请章节，保留既有新版基线及待定义事项。以下表格保留旧源码定位证据，不表示目标范围由这些旧入口决定。
