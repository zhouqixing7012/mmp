# 未完成单据 PRD

更新日期：2026年10月16日。以《后台报表&申请》申请部分为业务依据。

## 1 背景

管理员查询当前台账内所有处理中的申请单据，查看申请信息及完整审批过程，导出清单。每周一汇总未完成员工申请并通知指定人员，帮助跟进长期未完成事项。

本页为查询入口，办理仍在对应业务流程进行。

## 2 权限

按人员配置未完成单据管理员。管理员还须具有菜单查看权限，查询范围受人员、部门、公司及所属台账的数据权限限制；人员、部门、公司任一已授权范围内的记录可见。查看流程、查询候选、全部导出、当前页导出和周报使用相同数据范围。

人员权限匹配申请人；部门权限匹配申请单所属部门；公司权限匹配申请单所属公司。菜单授权不能替代管理员资格和单据数据权限。未配置权限时阻止查询和导出，不展示其他人员数据。

## 3 通用规则

3.1 纳入当前台账的所有处理中单据。等待汇总、当前审批人为空、暂未产生待办或审批账号资料异常，都不使处理中单据从清单消失；单据完成后退出未完成清单。

3.2 每张单据一行。同一单据同时有多个待办时，审批环节及审批人分别展示全部已产生的待办信息；同一名称可在列表去重，进度中保留每条真实审批记录。只有等待节点时显示等待；没有待办时，审批环节与审批人留空。异常账号不作为有效审批人，单据仍保留。

3.3 按单据生成时间倒序。查询条件组合为同时满足，选填项为空时不附加该条件。日期从／至合为一个范围，允许只填一端，起止日期包含整天。

3.4 返回清单保留最近一次查询条件、排序和页码；重置清空条件并恢复第一页默认结果。

### 4.3 审批信息

列表查看流程打开只读审批信息弹窗；关闭后保留清单状态。关联统一申领单据时，按本行原申请及明细关联领用／采购子单和汇总单；有采购记录时同时展示采购申请、PR及订单审批历史，按来源区分，不把不同单据的同序号记录合并。

| 字段 | 展示及交互 | 来源及说明 |
| --- | --- | --- |
| 审批环节 | 只读 | 真实记录的节点名称，包含等待及已产生的当前节点。 |
| 审批人 | 只读 | 审批人工号及姓名；同节点多人分别展示。 |
| 审批状态 | 只读 | 记录真实状态，不把历史统一改成当前状态。 |
| 审批时间 | 只读，yyyy-MM-dd | 未办理节点可为空。 |
| 审批意见 | 只读，支持换行 | 保存的意见，未填写可为空。 |

按流程序号及办理时间排序，重复关联到同一条审批记录时按记录唯一标识去重；不同人员及同一人多次实际办理均保留。空序号不导致真实记录被删除。采购系统的每个已产生审批节点均保留。编辑、同意、驳回等办理动作由对应工作台承载，本弹窗只读。

### 4.4 操作

| 操作 | 条件及结果 |

### 4.5 每周一汇总通知

每周一生成当前台账内未完成员工申请的Excel清单，接收人为杨芊、王英、孙志强、刘建、何文。仅包含明确属于员工申请且仍在处理中的记录；字段同本页导出，等待或无审批人的申请仍保留。汇总、导出与查看执行相同权限限制。

发送时刻、渠道、正式任务执行身份及其台账范围集中在第6章确认。配置完成前显示待配置事实，不展示虚假的发送成功记录，不把手动下载Excel当作已发送通知。

## 5 校验

| 触发时机 | 校验 | 结果与提示 |
| --- | --- | --- |
| 查询、流程、导出及周报生成 | 登录人员具备菜单、管理员资格及数据范围 | 缺少配置或无资格时阻止，提示缺少权限配置或无管理员权限。 |
| 查询、导出 | 开始日期不晚于结束日期 | 逆序阻止并提示调整日期。 |
| 查询 | 单据仍为处理中且位于获权台账 | 完成或范围外记录不显示；等待、无有效待办不排除。 |
| 周报生成 | 每周一、员工申请、处理中、授权范围内 | 非员工申请或已完成记录不进入周报；非周一不生成周期材料。 |
| 周报发送 | 发送配置及执行任务可用 | 配置缺失时保留待配置，不声称已发送。 |

## 6 后续操作／业务结果／补充说明

查询和导出均不改变审批或单据状态。单据办理完成后，下一次查询及周报不再包含；关闭流程弹窗不触发审批。
