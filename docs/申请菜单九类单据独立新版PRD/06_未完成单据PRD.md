# 未完成单据 PRD

## 1 背景

管理员查询当前台账内所有处理中的申请单据，查看申请信息及完整审批过程，导出清单。每周一汇总未完成员工申请并通知指定人员，帮助跟进长期未完成事项。

本页为查询入口，办理仍在对应业务流程进行。

## 2 权限

按人员配置未完成单据管理员。管理员还须具有菜单查看权限，查询范围受人员、部门、公司及所属台账的数据权限限制；人员、部门、公司任一已授权范围内的记录可见。查看流程、查询候选、全部导出、当前页导出和周报使用相同数据范围。

人员权限匹配申请人；部门权限匹配申请单所属部门；公司权限匹配申请单所属公司。菜单授权不能替代管理员资格和单据数据权限。未配置权限时阻止查询和导出，不展示其他人员数据。

管理员名单及人员、组织、台账范围由权限配置维护；周报只覆盖该管理员获权的当前台账，不另行扩大汇总范围。

## 3 通用规则

3.1 纳入当前台账的所有处理中单据。等待汇总、当前审批人为空、暂未产生待办或审批账号资料异常，都不使处理中单据从清单消失；单据完成后退出未完成清单。

3.2 每张单据一行；原申请、关联子单及各来源的审批记录分别保留。流程展示真实已发生及当前已产生节点，不改变源单据状态。

## 4 页面字段及交互

本章的首次查询、条件组合、重置、分页、返回保留、日期区间、选择控件、空结果及失败处理，遵循[申请查询公共交互规则](申请查询公共交互规则.md)。本页字段表补充查询对象、匹配方式及专有约束。

### 4.1 查询条件

入口：申请→未完成单据。

| 字段 | 交互方式 | 查询规则 |
| --- | --- | --- |
| 单据类型 | 可搜索、可清空的单选下拉框 | 从当前获权处理中单据提供类型选项，显示类型名称、按类型编码精确匹配；本业务类型条件不限制人员、组织基础资料的候选范围。 |
| 单据编号 | 文本框 | 去除首尾空格，按单据编号包含匹配。 |
| 申请人 | 人员选择弹窗，单选 | 按申请人账号精确匹配。 |
| 公司 | 公司选择弹窗，单选 | 按单据公司精确匹配。 |
| 板块 | 可搜索、可清空的单选下拉框 | 使用公共板块候选，按单据板块精确匹配。 |
| 部门 | 部门选择弹窗，单选 | 按单据部门精确匹配。 |
| 申请时间 | 日期范围 | 取单据生成时间，支持单边及双边范围。 |
| 是否离职 | 可搜索、可清空的单选下拉框 | 是／否，匹配申请人的人员有效状态；资料异常的实际处理见补充说明。 |

### 4.2 查询列表

列表字段只读，默认按单据生成时间倒序。每张单据一行；同一单据多个待办的环节和审批人全部展示，同一名称可去重。只有等待节点时显示等待；没有待办时环节和审批人留空，异常账号不作为有效审批人。分页及返回规则见公共交互规则。

| 字段 | 来源、格式及交互 |
| --- | --- |
| 序号 | 按分页连续编号，不作为业务主键。 |
| 单据编号 | 申请单据编号。 |
| 单据类型 | 单据类型对应名称。 |
| 业务类型 | 单据保存的业务类型对应名称。 |
| 单据状态 | 处理中状态名称。 |
| 审批环节 | 当前所有已产生的待办环节，等待仍展示。 |
| 审批人 | 对应待办审批人工号及姓名；没有有效待办人员时留空。 |
| 申请人 | 申请人工号及姓名。 |
| 申请时间 | yyyy-MM-dd；单据生成日期。 |
| 公司 | 申请单所属公司名称。 |
| 板块 | 申请单所属板块名称。 |
| 部门 | 申请单所属部门完整名称。 |
| 是否离职 | 申请人的人员有效状态。 |
| 查看流程 | 点击链接，打开本行完整流程记录，包含当前已产生的节点；成功读取且确无记录时显示“暂无审批记录”；读取失败按公共异常规则提示，不推断已经完成。 |

### 4.3 审批信息

点击列表“查看流程”打开只读审批信息弹窗；关闭后保留清单状态。关联统一申领单据时，按本行原申请及明细关联领用／采购子单和汇总单；有采购记录时同时展示采购申请、PR及订单审批历史，按来源区分，不把不同单据的同序号记录合并。

| 字段 | 来源、格式及交互 |
| --- | --- |
| 审批环节 | 真实记录的节点名称，包含等待及已产生的当前节点。 |
| 审批人 | 审批人工号及姓名；同节点多人分别展示。 |
| 审批状态 | 记录真实状态，不把历史统一改成当前状态。 |
| 审批时间 | yyyy-MM-dd；未办理节点可为空。 |
| 审批意见 | 保留换行；保存的意见，未填写可为空。 |

按流程序号及办理时间排序，重复关联到同一条审批记录时按记录唯一标识去重；不同人员及同一人多次实际办理均保留。空序号不导致真实记录被删除。采购系统的每个已产生审批节点均保留。编辑、同意、驳回等办理动作由对应工作台承载，本弹窗只读。

### 4.4 操作

| 操作 | 条件及结果 |
| --- | --- |
| 查询 | 管理员具有菜单及数据权限时可用；按公共交互规则查询匹配的处理中单据。 |
| 重置 | 按公共交互规则清空条件、恢复默认排序并重新查询。 |
| 导出 | 管理员有导出范围时可用；导出全部匹配结果，字段与列表内容一致，移除序号及操作列；编号按文本保留前导零。 |
| 导出当前页 | 与全部导出使用相同资格及数据范围；仅导出当前页已匹配记录，字段与全部导出一致。 |

### 4.5 每周一汇总通知

每周一上午10:00（北京时间）生成当前台账内未完成员工申请的Excel清单，通过服务号发送给ES-何文。仅包含明确属于员工申请且仍在处理中的记录；字段同本页导出，等待或无审批人的申请仍保留。汇总、导出与查看执行相同权限限制。

周报按已配置管理员的当前台账授权范围定时生成，不要求管理员届时在线；不得因收件人身份扩大汇总范围。服务号通知用于接收周报汇总清单。手动下载Excel不视为已发送通知；发送结果须与实际投递结果一致。

## 5 校验

日期、记录失效、无权限及导出失败的提示和修正方式遵循公共交互规则。

| 触发时机 | 校验 | 结果与提示 |
| --- | --- | --- |
| 查询、流程及导出 | 登录人员具备菜单、管理员资格及数据范围 | 缺少配置或无资格时阻止，提示缺少权限配置或无管理员权限。 |
| 查询、导出 | 开始日期不晚于结束日期 | 逆序时阻止，提示“开始日期不能晚于结束日期”；调整后重新查询或导出。 |
| 查询 | 单据仍为处理中且位于获权台账 | 完成或范围外记录不显示；等待、无有效待办不排除。 |
| 周报生成及发送 | 每周一上午10:00（北京时间）、员工申请、处理中、授权范围内；服务号发送给ES-何文 | 非员工申请或已完成记录不进入周报；非周一不生成周期材料。 |
| 周报发送 | 服务号发送条件具备且实际投递成功 | 发送条件缺失时标明待配置；投递失败时保留失败结果，不能记为已发送；由通知负责人补齐配置或处理失败后重新发送。 |

## 6 后续操作 / 业务结果 / 补充说明

查询和导出均不改变审批或单据状态。单据办理完成后，下一次查询及周报不再包含；关闭流程弹窗不触发审批。
