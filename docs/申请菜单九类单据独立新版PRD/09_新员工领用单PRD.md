# 新员工领用单 PRD

修订日期：2026年10月26日。

## 1 背景

提供已生成的新员工领用申请查询及领用详情。

本菜单用于查看已生成的新员工领用申请及其明细，不办理领用确认，不替代MIS预装统计或新员工领用报表。

## 2 权限

具有菜单权限的用户按人员、部门、公司配置的申请数据范围查询，取任一已授权范围内且属于获权台账的单据。人员权限匹配领用人，部门和公司权限分别匹配申请单所属部门及公司。查询、候选、详情和关联出库信息使用同一数据范围；菜单可见不能代替数据授权。缺少权限配置时阻止查询，不自动扩大范围。

人员及组织授权由权限配置提供。仓库候选受仓库操作权限限制，不以仓库候选代替单据查看权限。

## 3 通用规则

3.1 仅查询新员工领用单。单据状态、大类、配置等分别按对应字典或基础资料翻译，不能共用一套选项。

3.2 申请人取申请头领用人，显示账号-姓名；公司、板块按单据保存的编码查当前名称并显示编码.名称；部门按保存的部门编码查当前完整部门名。

3.3 审批人取剔除跳过和等待节点后的审批历史最后一条，流程完成后仍可保留最后一位处理人。详情中领用单号按来源申请号查询关联出库单。

## 4 页面字段及交互

首次进入、查询与重置、返回上下文、日期范围、选择弹窗、加载与异常处理遵循[申请查询公共交互规则](申请查询公共交互规则.md)。人员、部门及仓库使用选择弹窗；候选取正式基础资料并受授权范围限制，不从查询结果已有值推导。本菜单的申请详情只读，业务修改通过对应办理入口完成。

### 4.1 查询条件

进入方式：申请→新员工领用单。

| 字段 | 交互方式 | 查询规则 |
| --- | --- | --- |
| 申请单号 | 文本输入框 | 新员工领用申请编号包含匹配。 |
| 申请人 | 人员单选弹窗 | 匹配领用人账号，包含匹配；显示账号及姓名。 |
| 单据状态 | 单选下拉 | 选项为处理中、已完成、已驳回，精确匹配单据状态。 |
| 公司 | 公司多选弹窗 | 精确匹配任一所选公司编码；可选择多个公司。 |
| 板块 | 可搜索单选下拉 | 读取板块基础资料，按所选板块编码精确匹配申请头板块。 |
| 部门 | 部门单选弹窗 | 精确匹配单据头部门编码。 |
| 办公区 | 办公区单选弹窗 | 按办公区编码包含匹配。 |
| 大类 | 单选下拉 | 选项按物资大类编码排序；精确匹配单据头物资大类字段，不是逐条资产明细大类。 |
| 仓库 | 仓库单选弹窗 | 按申请头仓库编码包含匹配。 |
| 资产配置 | 单选下拉 | 选项来自资产配置字典，按所选配置值精确匹配申请头资产配置，与单据状态独立。 |
| 申请日期 | 日期范围 | 按申请头创建时间过滤，含起日00:00:00和止日23:59:59。 |

## 5 校验

5.1 查询前及打开详情时校验菜单权限、台账及单据数据范围；缺少权限配置、无权查看或单据失效时阻止对应操作，提示及返回行为遵循公共交互规则。

5.2 查询前校验日期起止顺序；起日晚于止日时阻止查询，提示“开始日期不能晚于结束日期”，保留已填条件供修改重试。

5.3 板块、资产配置和单据状态分别匹配各自业务字段，同时选择时须全部满足。公司条件支持多选，任一所选公司满足即符合公司条件。

5.4 大类条件仅匹配申请单头大类，不以明细大类替代。详情按申请号关联出库单，没有出库单时该字段为空。

## 6 后续操作 / 业务结果 / 补充说明

6.1 查询详情读取同一新员工领用单的申请信息、明细及关联出库单；地点、公司、板块、成本中心、业务线和仓库名称分别按对应基础资料转换。

6.2 申请数量与领用数量分别展示，不强制相等；PR单号取明细保存的关联PR。

6.3 本查询页不提供导出；新员工领用报表和MIS预装统计的导出属于各自页面。

6.4 申请由新员工业务流程生成；查询、查看及返回不新建申请、不办理领用确认、不产生出库或通知结果。
