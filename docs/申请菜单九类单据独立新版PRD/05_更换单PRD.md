# 更换单 PRD

## 1 背景

在“申请→更换单”查询员工资产更换申请，核对退回物资、待发放物资、鉴定结果和审批进度，支持 Excel 导出。申请未生成更换单时仍可查询，关联更换单号留空。

本菜单提供只读查询。物资添加、导入、鉴定填写及更换办理属于相应业务办理页面，本查询不因单据截图中存在输入控件而提供办理权限。

## 2 权限

系统支持通过人员、部门、公司分配更换申请的数据权限。查看、详情、进度、部件明细和导出使用同一授权范围；菜单可见不能扩大记录范围。

| 操作 | 可访问数据 | 无权限结果 |
| --- | --- | --- |
| 查询 | 授权人员、部门、公司范围内申请 | 不返回范围外记录 |
| 详情及进度 | 当前有权查看的申请和明确关联记录 | 明确提示无权限，不能通过直接单号读取 |
| 导出 | 当前条件内有权查看的匹配申请 | 不扩大权限；无数据输出表头 |

## 3 通用规则

1. 查询以资产更换申请单为主体，关联更换单号分别展示，不用执行单替代申请。
2. 按申请时间排序，默认由新到旧。查看单据返回后保留筛选、排序和分页。
3. 退回物资与待发放物资按各自保存的明细逐条展示，两表不互相覆盖。资产数量为退回资产行数量之和。
4. 鉴定结果、说明及当前审批记录只读展示。尚未鉴定、尚未发放时对应值留空或为空表，不生成默认办理结果。
5. 审批记录显示已发生节点及当前待审批节点，不补造未发生的审批通过结果；待审批时间、意见可为空。

## 4 页面字段及交互

### 4.1 查询条件

查询条件全部非必填，默认空白；多个条件同时满足。编号、标签号文本支持模糊查询；人员和组织支持搜索选择，按标识准确匹配；可清空选择。

| 条件 | 类型 | 取值及查询规则 |
| --- | --- | --- |
| 申请单号 | 文本框 | 员工更换申请编号，包含匹配 |
| 更换单号 | 文本框 | 关联更换单编号，包含匹配；未生成编号的申请不满足已填写条件 |
| 单据状态 | 可搜索下拉框 | 按申请当前状态准确匹配 |
| 申请人 | 人员选择 | 按申请人标识准确匹配，显示账号及姓名 |
| 制单时间 | 日期区间 | 对申请时间查询，起止日期均包含，允许只填一端 |
| 资产标签号 | 文本框 | 对退回资产标签号模糊查询，任一明细匹配即返回所属申请 |
| 子公司 | 组织选择 | 按申请人所属子公司准确匹配 |
| 部门 | 部门选择 | 按申请人所属部门准确匹配，显示编码及名称 |

点击“查询”应用条件，回到第一页；点击“重置”清空条件和排序，显示授权范围内结果。无匹配记录显示空列表。

| 更换单号 | 关联更换单编号，未生成时为空 |

| 鉴定及流程字段 | 数据来源及规则 |

### 4.4 Excel 导出

导出当前条件下全部有权查看的匹配申请，保持查询排序；字段与单据内容一致，以申请单号关联各工作表。

| 工作表 | 字段 |
| --- | --- |
| 申请单头 | 申请单号、更换单号、单据状态、申请人、公司、部门、申请时间、联系电话、邮箱、更换类型、更换原因、资产数量、鉴定结果、鉴定说明 |
| 退回物资 | 申请单号、资产标签号、SN号、资产说明、配置、数量、资产状态、资产用途、公司、City、Building、Floor、仓库、启用日期、模块、备注、耗材信息、物资说明 |
| 待发放物资 | 与退回物资表使用相同明细字段，逐条输出实际待发放物资，无业务值留空 |
| 部件明细 | 申请单号、主资产标签号、部件标签号、物料说明、配置、数量 |
| 审批记录 | 申请单号、审批环节、审批人、代理人、审批状态、审批时间、审批意见 |

一条明细对应一行，不能将多条资产压为首条。编号按文本输出，数量输出数值；没有待发放物资、部件或审批记录时保留对应表头，不虚构行。

## 5 校验

1. 日期区间起始日不能晚于结束日，日期无效时停止查询或导出并提示。
2. 申请单号和更换单号分别匹配各自编号，不能将未生成更换单的申请从无条件查询中排除。
3. 详情、审批、部件及导出重新校验授权；无权限或记录不存在时明确提示，不显示其他记录代替。
4. 子公司与财务公司分别取值，不能根据仓库财务公司推断子公司。资产状态、用途及物料说明按各自来源展示，缺失值为空，不补造类型或鉴定结果。

## 6 后续操作 / 业务结果 / 补充说明

### 6.1 查询结果

本菜单读取更换申请、关联物资及审批结果。查询、进度和导出不改变资产库存、责任人、鉴定或审批状态。正常更换须先完成旧资产入库，再进行新资产领取确认和出库。历史异常中已有新资产出库、旧资产未入库的记录按实际结果保留，不补造旧资产入库结果，也不作为新申请允许先领后退的依据。
