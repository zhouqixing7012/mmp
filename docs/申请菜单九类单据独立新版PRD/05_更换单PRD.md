# 更换单 PRD

## 1 背景

在“申请→更换单”查询员工资产更换申请，核对退回物资、待发放物资、鉴定结果和审批进度，支持 Excel 导出。申请未生成更换单时仍可查询，关联更换单号留空。

本菜单提供只读查询；物资添加、导入、鉴定填写和更换办理在对应业务办理页面进行。

## 2 权限

系统支持通过人员、部门、公司分配更换申请的数据权限。查看、详情、进度、部件明细和导出使用同一授权范围；菜单可见不能扩大记录范围。

| 操作 | 可访问数据 | 无权限结果 |
| --- | --- | --- |
| 查询 | 授权人员、部门、公司范围内申请 | 不返回范围外记录 |
| 详情及进度 | 当前有权查看的申请和明确关联记录 | 明确提示无权限，不能通过直接单号读取 |
| 导出 | 当前条件内有权查看的匹配申请 | 不扩大权限；无数据输出表头 |

具体授权人员、组织和所属台账范围由权限配置维护，不改变查询、详情与导出的同范围要求。

## 3 通用规则

1. 查询以资产更换申请单为主体，关联更换单号分别展示。批量申请按旧主资产拆单，每个旧主资产对应一张独立申请；部件及耗材仍作为该资产的关联明细。
2. 退回物资与待发放物资按各自保存的明细展示。资产数量为退回资产行数量之和；每张更换单选择一个新主资产，尚未配给时待发放表为空。
3. 鉴定结果、说明及当前审批记录只读展示。尚未鉴定、尚未发放时对应值留空或为空表，不生成默认办理结果。
4. 审批记录显示已发生节点及当前待审批节点，不补造未发生的审批通过结果；待审批时间、意见可为空。

## 4 页面字段及交互

本章的首次查询、条件组合、重置、分页、返回保留、日期区间、选择控件、空结果及失败处理，遵循[申请查询公共交互规则](申请查询公共交互规则.md)。本页字段表补充查询对象、匹配方式及专有约束。

### 4.1 查询条件

编号及资产标签号按包含匹配，人员和组织按所选标识精确匹配。候选与选择规则见公共交互规则。

| 条件 | 类型 | 取值及查询规则 |
| --- | --- | --- |
| 申请单号 | 文本框 | 员工更换申请编号，包含匹配 |
| 更换单号 | 文本框 | 关联更换单编号，包含匹配；未生成编号的申请不满足已填写条件 |
| 单据状态 | 可搜索、可清空的单选下拉框 | 处理中、已驳回、已完成；按申请当前状态精确匹配 |
| 申请人 | 人员选择弹窗，单选 | 按申请人标识准确匹配，显示账号及姓名 |
| 制单时间 | 日期区间 | 对申请时间查询，起止日期均包含，允许只填一端 |
| 资产标签号 | 文本框 | 对退回资产标签号模糊查询，任一明细匹配即返回所属申请 |
| 子公司 | 子公司单选下拉框 | 按申请人所属子公司准确匹配 |
| 部门 | 部门选择弹窗，单选 | 按申请人所属部门准确匹配，显示编码及名称 |

### 4.2 查询列表

| 字段 | 取值及交互 |
| --- | --- |
| 申请单号 | 原申请编号，点击进入只读详情 |
| 更换单号 | 关联更换单编号，未生成时为空 |
| 单据状态 | 申请当前业务状态名称 |
| 申请人 | 申请保存的人员账号及姓名 |
| 公司 | 申请人所属公司名称 |
| 申请时间 | 员工申请提交时间，列表显示年月日 |

| 更换类型 | 故障更换；历史缺失值留空 |
| 更换原因 | 员工填写的更换原因，保留文本及换行 |
| 申请时间 | 本申请提交时间 |
| 联系电话 | 本申请保存的申请人联系电话 |
| 邮箱 | 本申请保存的申请人邮箱 |
| 部门 | 本申请人员所属部门编码及名称 |
| 公司 | 本申请人员所属财务公司名称 |

| 资产用途 | 当前行保存的资产用途 |
| 部件 | 当前资产关联部件数量，点击查看对应部件明细 |

#### 4.3.1 部件明细

点击退回资产的部件数量打开部件明细弹窗，仅展示该资产关联部件；没有部件时显示空表。关闭弹窗返回原详情。

| 字段 | 来源及规则 |
| --- | --- |
| 部件标签号 | 当前部件标签号，保留前导零 |
| 物料说明 | 当前部件物料的说明 |
| 配置 | 当前部件物料的配置 |
| 数量 | 当前部件对应数量 |

#### 4.3.2 鉴定及流程

| 鉴定及流程字段 | 数据来源及规则 |
| --- | --- |
| 鉴定结果 | 展示已保存的资产维修或资产更换结果；尚未鉴定为空 |
| 鉴定说明 | 展示已保存的说明，保留换行 |
| 审批环节 | 本条审批记录的节点名称，展示至当前节点 |
| 审批人 | 本条记录的办理人或待审批人；同节点不同人员分别成行 |
| 代理人 | 本条记录保存的代理人，无代理人留空 |
| 审批状态 | 本条记录实际状态，当前节点显示待审批 |
| 审批时间 | 本条记录实际办理时间，待审批时允许为空 |
| 审批意见 | 本条记录保存的意见，待审批时允许为空 |

点击“返回”回到原查询结果；从列表进度入口打开同一申请的审批记录弹窗，展示本节审批字段；关闭后回到列表。

### 4.4 Excel 导出

导出当前条件下全部有权查看的匹配申请，保持查询排序；字段与单据内容一致，以申请单号关联各工作表。

| 工作表 | 字段 |
| --- | --- |
| 申请单头 | 申请单号、更换单号、单据状态、申请人、公司、部门、申请时间、联系电话、邮箱、更换类型、更换原因、资产数量、鉴定结果、鉴定说明、入库单号、出库单号、结束原因 |
| 退回物资 | 申请单号、资产标签号、SN号、资产说明、配置、数量、资产状态、资产用途、公司、City、Building、Floor、仓库、启用日期、模块、备注、耗材信息、物资说明 |
| 待发放物资 | 与退回物资表使用相同明细字段，逐条输出实际待发放物资，无业务值留空 |
| 部件明细 | 申请单号、主资产标签号、部件标签号、物料说明、配置、数量 |
| 审批记录 | 申请单号、审批环节、审批人、代理人、审批状态、审批时间、审批意见 |

一条明细对应一行。编号按文本输出并保留前导零，时间保留原记录精度，数量输出数值；没有待发放物资、部件或审批记录时保留对应表头。

## 5 校验

日期、无权限、记录失效及导出失败的提示与修正方式遵循公共交互规则。

| 触发时机 | 判断条件 | 处理及用户下一步 |
| --- | --- | --- |
| 查询及导出 | 开始日期晚于结束日期 | 阻止操作，提示“开始日期不能晚于结束日期”；调整后重新查询或导出 |
| 打开详情、审批、部件及导出 | 记录存在且当前仍在授权范围内 | 重新校验；不满足时阻止，按公共规则提示无权限或记录失效，不显示其他记录替代 |
| 查询编号 | 申请单号、更换单号匹配各自编号 | 未生成更换单的申请不满足已填写的更换单号条件，但保留在无该条件的查询中 |

子公司与财务公司分别取值；资产状态、用途及物料说明分别关联原业务内容，缺失值留空。尚未鉴定或尚未发放不产生默认鉴定结果及发放明细。

## 6 后续操作 / 业务结果 / 补充说明

### 6.1 查询结果

本菜单读取更换申请、关联物资及审批结果。查询、进度和导出不改变资产库存、责任人、鉴定或审批状态。“已完成”表示更换流程结束，包括正常出库、旧资产退库后新资产发放被驳回及办理前弃领；是否领取新资产结合出库单号判断。正常更换须先完成旧资产入库，再进行新资产领取确认和出库。历史异常中已有新资产出库、旧资产未入库的记录按实际结果保留，不补造旧资产入库结果，也不作为新申请允许先领后退的依据。

### 6.2 当前尚未定义

| 待确认问题 | 涉及页面或操作 | 未确认时无法确定的业务结果 | 需要确认的角色或事项 |
| --- | --- | --- | --- |
| 是否存在同一申请关联多个更换单的业务记录？如存在，列表一行如何展示全部单号？ | 列表、详情及导出 | 不能确定多更换单的展示和导出关联方式 | 业务负责人提供实际关系及展示要求 |
