# 申请菜单 UI 整改记录｜2026-10-22

用户确认实施[走查报告](申请菜单-UI走查-20261022.md)中的确定UI问题，范围为申请菜单九类查询及其详情、汇总和弹窗；仅调整展示和布局。

| 问题 | 修改结果 | 受影响入口 |
|---|---|---|
| UI-01 查询按钮越界 | 页面直接传查询、重置回调，使用公共QueryBar的独立按钮区，移除横排Space包装；宽屏纵排、窄屏下一行右对齐 | 九类查询列表 |
| UI-02 合计错位 | 按实际列位置生成合计单元格，数量和金额各占对应列、右对齐；合计标签只跨前置非数值列 | 资产/耗材部门汇总及申请明细 |
| UI-03 横滚丢失标识 | 资产、耗材的子流程单号及申请单号集中在左侧固定，未产生子流程时仍保留申请单号；其他查询固定其主单据编号，进度或操作固定在右侧，收紧普通列宽 | 九类查询列表 |
| UI-04 长文本拥挤 | 业务调用逐字段指定原因、备注、配置、详细说明等整行，保留换行和连续长文本换行；短字段继续三列 | 移库、退库、转移、借用/续借、更换、新员工、资产/耗材详情 |
| UI-05 只读空白 | 只读普通空值统一“-”，真实0保留；输入字段、导出源数据和错误处理不变 | 查询列表、详情、汇总、审批记录 |
| UI-06 弹窗多层滚动 | 申请弹窗内容区统一限高纵滚，移除表格外包装的额外滚动；宽表在表格内横滚，短表自然撑高 | 审批、配件及相关详情弹窗 |
| UI-07 空文案不明确 | 按单据名称显示无匹配结果，按超标/非超标/耗材明细显示空区；更换显示“暂无待发放物资记录” | 查询空结果、汇总、更换详情 |

配件入口同时补充包含资产标识和件数的可访问名称。字段集合、查询匹配、权限、状态、金额计算、导出字段、可编辑输入及其保存边界保持。
