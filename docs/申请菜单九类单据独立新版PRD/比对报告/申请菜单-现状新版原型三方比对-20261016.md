# 申请菜单：现状 PRD、新版 PRD、原型三方比对

核查日期：2026-10-16（北京时间）。比较基准：main 提交 `2dcc3510f2e46209d98eeca22dba90e42862ead8`。

## 1 结论与核查边界

新版 PRD 与原型大体一致，但两者共同遗漏了现状 PRD 的部分明确要求。最主要的问题是：转移查询对象变成执行单、更换单只剩入口、借用没有导出、退库与借用缺组织查询、耗材导出缺采购及领用字段、未完成单据缺每周通知。另有原型未完整实现新版的详情及流程展示。

原因之一是新版按旧源码反向整理，把“源码未发现功能”和“目标不需要功能”混在一起。现状 PRD 明确提出的新增查询、导出、通知等要求，不能仅因旧源码未实现而撤销。

本报告覆盖九个菜单入口的查询、列表、详情、操作、导出、排序、权限和流程。现状 PRD 实际只有八类申请查询，没有独立的新员工领用申请章节；第九类只能核对新版与原型，不能借用“新员工领用报表”补充申请基线。证据包括现状正文、附件截图、新版正文以及当前菜单实际引用的组件、服务、演示数据；属于源码与资料比对，未运行浏览器、未验证线上系统，不能据此证明生产接口、真实权限或外部流程已经实现。

本轮只新增报告及交付记录，未改原型、九份业务 PRD、现状原文或附件。以下建议均未执行。
