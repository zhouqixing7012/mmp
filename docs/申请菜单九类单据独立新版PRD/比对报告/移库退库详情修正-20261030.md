# 移库、退库详情修正

基线main 559c5075。按用户六项反馈修正普通查询详情，源单、办理流程和原始现状PRD只读保留。

| 反馈 | 处理 |
|---|---|
| 资产数量出现1.0 | 原因是LegacyFields固定一位小数；改为整数不补小数，空值及真实0分别保留，有效非整数不截为整数。移库明细、详情数量及共用附属耗材数量一致处理。 |
| 字段名称及总类 | 移库明细、查看弹窗的物资说明改资产说明，去掉物资总类；导出资产说明使用同一可见名称，源记录属性不删除。 |
| 打印和返回位置不同 | 原因是打印在内层组件左侧、返回在外层组件居中；移库详情统一一个居中操作栏，返回及已完成单据打印并排，打印状态资格不变。 |
| 表格对齐 | 详情Table继续使用BusinessTable→AlignedTable公共规则；资产说明和标签左、数量右、验证/处理状态及日期居中。移库业务行号作为业务标识左对齐，区别于展示序号。增加表头及正文实际DOM断言。 |
| 资产是否验证 | 现状PRD《后台报表&申请》第729行开始的移库字段表没有列验证状态；现有原型不是删除，而是依新版01第4.3节仅在出库待接收时显示资产验证，且在移库状态前。保留该状态规则，不擅自扩大到其他状态或推造验证结果。 |
| 查看弹窗 | 移库信息与资产信息分区，三列网格统一128px标签；仓库跨两列并与管理员同排，长说明/配置/备注整行。去掉库区、入库库区、货位、入库货位、印刷号、品牌、规格/型号、Room与物资总类。只精简展示，源历史字段与既有导出不因此删除。 |
| 退库列表编号 | 退库单号统一改为入库单号，相关查询、列表、详情显示及导出标题同步，仍使用原inboundNo及关联入库单，不改来源或匹配方式。 |
| 办公区与地址 | 按用户进一步确认，附件办公区列是名称，直接使用原文，不再把L062等值解释为编码再套用旧mock名称。10条映射不丢行，名称去重形成候选；没有独立办公区编码或地址的事实不补造，地址在task_plan登记等待用户提供。 |
