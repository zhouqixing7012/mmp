# 耗材申请单 PRD

修订日期：2026年10月26日。

## 1 背景

员工耗材申请的查询、子流程详情和流程进度查看。每条列表以原申请明细及其关联子流程为基础。

查询覆盖原申请、配给、汇总及领用全流程，保留申请单据内容和完整审批信息。人员、组织及状态名称由正式基础资料配置提供。

## 2 权限

按人员、部门、公司分配申请数据范围。用户进入菜单后，仅查询授权范围内的原申请及其关联子单、汇总、出库和审批记录；详情、进度及Excel导出执行相同范围，不能通过单号扩大查看权限。授权名单及组织关系由权限配置提供。

## 3 通用规则

3.1 查询以原申请明细为基础，按物料拆行；同一申请包含多项物料时分别显示。每项物料分别关联配给、采购汇总、领用及出库结果；同一明细存在多个子单或多次出库时，按实际关联分别展示，保留同一原申请单号。

3.2 子流程号规则与资产申请一致：一级子单处理中且汇总单已驳回时取一级子单，否则优先取汇总单，缺失时取一级子单。

3.3 列表显示关联流程当前已产生的最新环节；同环节有多名有效审批人时共同展示。等待环节显示待汇总，审批人为空。进度中逐条保留实际节点、各审批人及重复办理记录，以记录唯一标识识别同一记录，不能按流程序号或人员删去不同记录。

3.4 状态取原申请头。预计采购金额为采购单价×原申请明细数量；领用行金额为空。汇总提交人仅当选定的子流程是耗材汇总单时有值。

## 4 页面字段及交互

首次进入、查询与重置、返回上下文、日期范围、选择弹窗、加载与异常处理遵循[申请查询公共交互规则](申请查询公共交互规则.md)。人员、部门及仓库使用选择弹窗；候选取正式基础资料并受授权范围限制，不从查询结果已有值推导。本菜单的申请详情和汇总详情均只读，业务修改通过对应办理入口完成。

### 4.5 查看进度弹窗字段及交互

点击列表“进度查看”打开只读审批信息。按所点原申请明细关联原申请、配给／领用或采购子单、汇总单；没有子流程时仍显示原申请记录。按业务链依次展示各来源，每个来源内按节点顺序及办理时间展示，不跨来源重排。

| 字段 | 格式及交互 | 来源及业务规则 |
| --- | --- | --- |
| 审批环节 |  | 对应系统实际保存的环节名称。 |
| 审批人 |  | 对应记录审批人工号及姓名；同一环节多人逐条显示，保留再次办理记录。 |
| 审批状态 |  | 对应记录保存的办理或审批结果；当前记录可为待审批、待办理或待汇总。 |
| 审批时间 | 日期 | 对应记录保存的时间；尚未办理时为空。 |
| 审批意见 |  | 对应记录保存的意见；为空时留空。 |

记录保留至当前已产生的节点；完成后保留历史，不补造未来审批人或办理结果。重复获取同一唯一标识的记录只展示一次，不按流程序号去重。资产来源分区标题在耗材采购分支显示“资产申请详情（此信息来源于资产系统）”。

采购分支继续展示以下三个分区，每个实际节点完整保留，不因已有PR单而删除采购记录中的PR节点，也不替换或删减询报价办理记录。

| 分区 | 关联及展示规则 |
| --- | --- |
| 采购申请详情（此信息来源于采购系统） | 从当前申请明细关联的汇总结果取得采购申请及询报价流程，展示其全部实际记录。 |

## 5 校验

5.1 查询、打开详情、查看进度、下载附件和导出均校验查看权限及单据数据范围；无权限、记录失效、读取失败时按公共交互规则阻止相应操作并保留查询上下文。

5.2 查询和导出前校验日期起止顺序；起日晚于止日时阻止执行，提示“开始日期不能晚于结束日期”，修改后可重试。

5.3 查询使用所选人员账号、组织编码及各条件自身的匹配方式；选择值不在授权候选内时阻止查询，提示重新选择。状态、审批节点精确匹配。

5.4 详情按物资总类区分物料编码与资产标签号、数量与部件数量；领用资产标签号保留前导零。未产生采购、出库或审批结果时不补造相应字段值。
