## 一、模块概述

### 1.1 模块定位

"仓库基础数据维护"模块用于管理企业的仓库信息、仓库用途和仓库操作权限，是资产出入库管理的基础。

权限：所有涉及仓库编辑、修改的权限，目前仅开放给ES王英、刘建

### 1.2 包含页面

本模块包含3个子页面，通过顶部Tab标签页切换：

| Tab标签 | 功能说明 |
|---------|----------|
| 仓库信息 | 管理仓库的基本信息，包括编码、描述、地址、管理员等 |
| 仓库用途 | 管理仓库的用途分类（标准库、报废库、借用库、待检库） |
| 仓库权限 | 管理仓库的操作权限（入库/出库/查看权限分配） |

## 二、页面1：仓库信息

### 2.1 页面功能

管理企业所有仓库的基本信息。每个仓库包含编码、描述、城市、楼栋、地址、用途、公司、库管员等字段。

**字段说明**：

| 字段名称 | 是否查询条件 | 查询条件控件类型 | 提示文案 | 说明 |

| 仓库编码 | Y | Input | 请输入仓库编码 | 支持模糊检索 |
| 仓库描述 | Y | Input | 请输入仓库描述 | 支持模糊检索 |
| 是否虚拟库 | Y | Select | 请选择 | 枚举值：全部、是、否 |

## 四、页面3：仓库权限

### 4.1 页面功能

管理仓库的操作权限，包括入库权限、出库权限、查看权限的分配，以及默认入库/出库仓库设置。控制哪些操作人对哪些仓库可以进行哪些操作。

### 4.2 主页面

**表格列**：序号、仓库、操作人、入库权限、默认入库仓库、出库权限、默认出库仓库、查看权限、操作

**查询条件**：

| 操作人 | Input + Search | 搜索操作人... |

**操作栏按钮**：新增、删除、批量修改

## 五、通用交互说明

### 5.1 批量操作流程

1. 勾选记录：点击表格第一列复选框，勾选单条记录；点击表头复选框全选/取消全选当前页
2. 批量启用/停用：勾选记录后点击工具栏的"启用"或"停用"按钮，弹出确认弹窗
3. 批量删除：勾选记录后点击工具栏的"删除"按钮，弹出确认弹窗

### 5.2 查询流程

1. 在搜索条件区域输入筛选条件
2. 点击"查询"按钮，表格显示符合条件的数据
3. 点击"重置"按钮，清空搜索条件，显示全部数据
