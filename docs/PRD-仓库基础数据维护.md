# 仓库基础数据维护模块 PRD

**文档版本**：v1.0
**更新日期**：2026年5月28日

---

## 一、模块概述

### 1.1 模块定位

"仓库基础数据维护"模块用于管理企业的仓库信息、仓库用途和仓库操作权限，是资产出入库管理的基础。

### 1.2 包含页面

本模块包含3个子页面，通过顶部Tab标签页切换：

| Tab页面 | 功能说明 |
|---------|----------|
| 仓库信息 | 管理仓库的基本信息 |
| 仓库用途 | 管理仓库的用途分类 |
| 仓库权限 | 管理仓库的操作权限 |

---

## 二、页面1：仓库信息

### 2.1 页面功能

管理企业所有仓库的基本信息，包括仓库编码、描述、地址、管理员等。

### 2.2 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  [Tab: 仓库信息] [仓库用途] [仓库权限]                     │
├─────────────────────────────────────────────────────────────┤
│  搜索条件区域                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 仓库编码: [________]      仓库描述: [________]       │  │
│  │ 是否虚拟库: [▼选择]      是否启用: [▼选择]          │  │
│  │                                    [查询] [重置]      │  │
│  └───────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  工具栏: [新增] [删除] [启用] [停用]                        │
├─────────────────────────────────────────────────────────────┤
│  数据表格                                                    │
│  ☐ │序号│仓库编码│仓库描述│仓库用途│是否虚拟库│公司│...│操作│
├─────────────────────────────────────────────────────────────┤
│  共X条记录          [上一页] [1] [2] ... [下一页]  10条/页  │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 仓库编码 | 文本输入框 | 支持模糊搜索 |
| 仓库描述 | 文本输入框 | 支持模糊搜索 |
| 是否虚拟库 | 下拉选择框 | 选项：全部、是、否 |
| 是否启用 | 下拉选择框 | 选项：全部、是、否 |

### 2.4 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 序号 | 自动编号 |
| 仓库编码 | 如：I0001 |
| 仓库描述 | 如：资产库北京库(新媒体) |
| 仓库用途 | 用途分类 |
| 是否虚拟库 | 是/否 |
| 公司 | 所属公司 |
| City | 所在城市 |
| 库管员 | 仓库管理员 |
| 是否启用 | 启用（绿色）/停用（红色） |
| 操作 | 编辑按钮 |

### 2.5 新增/编辑弹窗

**表单字段**（每行2个）：

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 仓库编码*（文本输入） | 仓库描述*（文本输入） |
| 第2行 | City*（搜索选择） | Building*（搜索选择） |
| 第3行 | Floor（下拉选择） | 仓库地址（文本输入） |
| 第4行 | 仓库类型（下拉选择） | 仓库用途（搜索选择） |
| 第5行 | 公司*（搜索选择） | 管理员*（搜索选择） |
| 第6行 | 是否虚拟库（单选） | 是否启用库区（单选） |
| 第7行 | 是否启用库位（单选） | 是否启用（单选） |
| 第8行 | 启用日期（日期选择） | 停用日期（日期选择） |

**校验规则**：
- 仓库编码、仓库描述、City、Building、公司、管理员：必填
- 仓库编码唯一性校验

**仓库类型枚举值**：

| 值 | 显示文本 | 说明 |
|----|----------|------|
| ES库 | ES库 | ES系统管理的仓库，用于ES相关业务 |
| MIS库 | MIS库 | MIS系统管理的仓库，用于MIS相关业务 |
| 周转库 | 周转库 | 用于临时周转的仓库，资产临时存放 |
| 报废库 | 报废库 | 用于存放报废资产的仓库 |

**仓库权限业务规则**：
1. 每个仓库只能有一个默认入库仓库和一个默认出库仓库
2. 入库时，员工只能看到有入库权限的仓库和对应库位
3. 出库时，员工只能看到有出库权限的仓库和对应库位

## 四、页面3：仓库权限

### 4.1 页面功能

管理仓库的操作权限，配置哪些人员可以进行入库、出库、盘点等操作。

### 4.2 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  搜索条件区域                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 仓库编号: [________🔍]    操作人: [________🔍]       │  │
│  │ 入库权限: [▼选择]                                     │  │
│  │                                    [查询] [重置]      │  │
│  └───────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  工具栏: [新增] [删除] [批量修改]                           │
├─────────────────────────────────────────────────────────────┤
│  数据表格                                                    │
│  ☐ │序号│仓库│操作人│入库权限│默认入库│出库权限│默认出库│...│操作│
├─────────────────────────────────────────────────────────────┤
│  共X条记录          [上一页] [1] [2] ... [下一页]  10条/页  │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 仓库编号 | 搜索选择框 | 点击搜索图标选择仓库 |
| 操作人 | 搜索选择框 | 点击搜索图标选择人员 |
| 入库权限 | 下拉选择框 | 选项：全部、是、否 |

### 4.4 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 序号 | 自动编号 |
| 仓库 | 仓库编码和名称 |
| 操作人 | 员工编号和姓名 |
| 入库权限 | 是/否 |
| 默认入库仓库 | 是/否 |
| 出库权限 | 是/否 |
| 默认出库仓库 | 是/否 |
| 盘点权限 | 是/否 |
| 操作 | 编辑按钮 |

### 4.5 新增/编辑弹窗

**表单字段**（每行2个）：

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 仓库*（搜索选择） | 操作人*（搜索选择） |
| 第2行 | 入库权限*（下拉选择） | 出库权限*（下拉选择） |
| 第3行 | 默认入库仓库（下拉选择） | 默认出库仓库（下拉选择） |
| 第4行 | 盘点权限*（下拉选择） | （空） |

**校验规则**：
- 仓库、操作人、入库权限、出库权限、盘点权限：必填
- 同一仓库+操作人不能重复配置
