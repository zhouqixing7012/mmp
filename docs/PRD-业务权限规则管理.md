**文档版本**：v1.0
**更新日期**：2026年5月28日

## 一、模块概述

### 1.1 模块定位

"业务权限规则管理"模块用于配置不同维度的数据访问和操作权限，控制哪些公司/板块可以提取哪些资产数据。

### 1.2 包含页面

本模块包含3个子页面，通过顶部Tab标签页切换：

| Tab页面 | 功能说明 |
|---------|----------|
| 公司板块提取资产权限 | 配置公司和板块提取资产的权限范围 |
| NO设备提取资产权限 | 配置NO设备提取资产的权限规则 |
| 公司归属权限 | 配置公司的归属关系 |

---

## 二、页面1：公司板块提取资产权限

### 2.1 页面功能

配置各公司和板块可以提取哪些物料大类的资产数据，用于数据权限控制。

### 2.2 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  [Tab: 公司板块提取资产权限] [NO设备...] [公司归属...]     │
├─────────────────────────────────────────────────────────────┤
│  搜索条件区域                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 公司: [________🔍]      板块: [________🔍]           │  │
│  │ 物料大类: [________🔍]                               │  │
│  │                                    [查询] [重置]      │  │
│  └───────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  工具栏: [新增] [删除] [批量修改]                           │
├─────────────────────────────────────────────────────────────┤
│  数据表格                                                    │
│  ☐ │序号│公司│板块│物料大类│员工所属公司│员工所属板块│操作│  │
├─────────────────────────────────────────────────────────────┤
│  共X条记录          [上一页] [1] [2] ... [下一页]  10条/页  │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 公司 | 搜索选择框 | 点击搜索图标选择公司 |
| 板块 | 搜索选择框 | 点击搜索图标选择板块 |
| 物料大类 | 搜索选择框 | 点击搜索图标选择物料大类 |

### 2.4 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 序号 | 自动编号 |
| 公司 | 资产所属公司 |
| 板块 | 资产所属板块 |
| 物料大类 | 可提取的物料大类 |
| 员工所属公司 | 员工所在公司（可为空） |
| 员工所属板块 | 员工所在板块（可为空） |
| 操作 | 编辑按钮 |

### 2.5 新增/编辑弹窗

**表单字段**（每行2个）：

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 公司*（搜索选择） | 板块*（搜索选择） |
| 第2行 | 物料大类*（搜索选择） | 员工所属公司（搜索选择） |
| 第3行 | 员工所属板块（搜索选择） | （空） |

**校验规则**：
- 公司、板块、物料大类：必填
- 同一组合不能重复配置

## 三、页面2：NO设备提取资产权限

### 3.1 页面功能

配置NO设备（网络设备）提取资产的权限规则，按设备类型和责任人配置。

### 3.2 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  搜索条件区域                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ NO类型: [▼选择]         员工编号: [________]         │  │
│  │ 姓名: [________]                                     │  │
│  │                                    [查询] [重置]      │  │
│  └───────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  工具栏: [新增] [删除] [批量修改]                           │
├─────────────────────────────────────────────────────────────┤
│  数据表格                                                    │
│  ☐ │序号│NO设备类型│责任人│操作│                            │
├─────────────────────────────────────────────────────────────┤
│  共X条记录          [上一页] [1] [2] ... [下一页]  10条/页  │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| NO类型 | 下拉选择框 | 选项：全部、服务器、网络设备 |
| 员工编号 | 文本输入框 | 支持模糊搜索 |
| 姓名 | 文本输入框 | 支持模糊搜索 |

### 3.4 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 序号 | 自动编号 |
| NO设备类型 | 服务器/网络设备 |
| 责任人 | 员工编号和姓名 |
| 操作 | 编辑按钮 |

### 3.5 新增/编辑弹窗

**表单字段**（每行2个）：

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | NO设备类型*（下拉选择） | 责任人*（搜索选择） |

**校验规则**：
- NO设备类型、责任人：必填
- 同一设备类型不能有重复的责任人配置

## 四、页面3：公司归属权限

### 4.1 页面功能

配置公司的归属关系（焦点/搜狐），用于数据隔离和权限控制。

### 4.2 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  搜索条件区域                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 公司归属: [▼选择]         公司: [________🔍]         │  │
│  │ 板块: [________🔍]                                    │  │
│  │                                    [查询] [重置]      │  │
│  └───────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  工具栏: [新增] [删除] [批量修改]                           │
├─────────────────────────────────────────────────────────────┤
│  数据表格                                                    │
│  ☐ │序号│公司归属│公司│板块│操作│                            │
├─────────────────────────────────────────────────────────────┤
│  共X条记录          [上一页] [1] [2] ... [下一页]  10条/页  │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 搜索条件字段

| 字段名 | 控件类型 | 说明 |
|--------|----------|------|
| 公司归属 | 下拉选择框 | 选项：全部、焦点、搜狐 |
| 公司 | 搜索选择框 | 点击搜索图标选择公司 |
| 板块 | 搜索选择框 | 点击搜索图标选择板块 |

### 4.4 表格列

| 列名 | 说明 |
|------|------|
| ☐（复选框） | 批量选择 |
| 序号 | 自动编号 |
| 公司归属 | 焦点/搜狐 |
| 公司 | 公司名称 |
| 板块 | 板块名称 |
| 操作 | 编辑按钮 |

### 4.5 新增/编辑弹窗

**表单字段**（每行2个）：

| 行号 | 左侧字段 | 右侧字段 |
|------|----------|----------|
| 第1行 | 公司归属*（下拉选择） | 公司*（搜索选择） |
| 第2行 | 板块*（搜索选择） | （空） |

**校验规则**：
- 所有字段必填
- 同一公司不能重复归属
