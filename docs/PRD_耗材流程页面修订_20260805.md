# 耗材流程页面修订说明（2026-08-05）

本文档记录 `docs/PRD_耗材申请与领用.md` 在页面评审过程中的最终修订结论。正式需求已同步合并至主 PRD，本文件用于追踪本轮页面变更。

## 1. 个人工作台菜单

- 删除独立“耗材申请”页面及个人工作台入口。
- 保留：耗材 MIS 鉴定、耗材审批、耗材配给、耗材领用、员工耗材领用确认、耗材汇总、耗材汇总审批。

## 2. 耗材 MIS 鉴定

- MIS 意见下拉枚举统一为：鉴定通过、鉴定不通过。
- MIS 意见和意见说明均为必填。
- 同意时所有当前可见行必须选择“鉴定通过”。
- 驳回时所有当前可见行必须选择“鉴定不通过”。
- 本轮暂不新增独立“MIS 鉴定处理”Card，MIS 意见和意见说明继续保留在申请耗材信息中。

## 3. 耗材审批

“申请耗材信息”只展示：

1. 耗材说明
2. 配置
3. 数量
4. 申请原因
5. 详细说明

不展示：主资产标签号、主资产说明、MIS 鉴定结果、MIS 鉴定说明、行状态。

## 4. 耗材配给

- 匹配状态只保留“库存领用、统一采购”。
- “驳回”通过独立按钮执行，不属于匹配状态。
- 删除“驳回类型”字段。
- 驳回时只校验 ES 建议必填。
- 库存领用时必须匹配库存耗材；统一采购时进入耗材汇总。

## 5. 耗材汇总明细

- 页面布局与“统一申请汇总-资产”的汇总明细页保持一致。
- 按申请人/申请单分 Card 展示。
- Card 顶部展示申请人、申请单号和申请部门。
- Card 右上角展示“驳回”按钮，点击后驳回当前申请人的整张申请单明细。
- 明细表不展示“是否通过”字段。
- 页面底部按钮为：下一步、保存、返回。

## 6. 耗材汇总详情

页面包含：

1. ES 汇总说明
2. 项目用途说明
3. 部门汇总信息
4. 申请明细
5. 附件信息

部门汇总字段：序号、部门、申请采购数量、预计采购费用（元）。

申请明细字段：序号、部门、申请单号、申请人、物资类别、物料说明、采购数量、预计费用（元）、申请原因、ES 建议。

页面保留“最终采购价格以 PR 单为准”和“项目用途会同步至 PR 系统”的提示。

## 7. 耗材汇总审批

页面仅保留：

1. ES 汇总说明
2. 部门汇总信息
3. 申请明细
4. 审批信息

审批信息包含审批历史、审批意见及同意、驳回、返回按钮；驳回时审批意见必填。

## 8. 耗材领用

- 页面布局及字段顺序与“ES 前台领用”保持一致。
- 申请人信息展示当前仓库、申请人、联系电话、邮箱、公司、办公区、申请日期、部门和单据备注。
- 申请耗材信息展示耗材标签号、序列号、所在仓库、实际耗材说明、配置、数量、公司、板块、启用日期、城市、建筑、楼层、主资产信息、报废期信息、使用说明和申请参考信息。
- 页面不展示“领用确认方式”和“确认状态”。
- 底部使用“审批操作”Card。
- 操作按钮包含：领用确认、弃领、加签、返回、发送领用通知。
- 点击“领用确认”后保存当前办理信息、发起员工确认并直接进入“员工耗材领用确认”页面。
- 员工确认完成后，耗材领用页主按钮切换为“执行出库”。

## 9. 员工耗材领用确认

- 不支持电子签确认。
- 不展示电子签标签页、电子签名区域或签名按钮。
- 只支持：
  1. 刷卡/录入员工工号确认；
  2. 狐小 e 扫码确认。
- 两种方式均需先勾选耗材保管职责。
- 员工工号必须与申请人工号一致。
- 确认成功后展示员工工号、确认时间、确认方式和确认结果。

## 10. 本轮验收重点

- [ ] 耗材配给不存在“驳回类型”。
- [ ] 耗材汇总明细不存在“是否通过”。
- [ ] 汇总驳回入口位于申请人 Card 右上角。
- [ ] 耗材领用存在“领用确认”按钮，并可进入员工确认页。
- [ ] 耗材领用不展示领用确认方式和确认状态。
- [ ] 员工耗材领用确认不存在电子签方式。
- [ ] 员工耗材领用确认只保留刷卡/工号和扫码确认。
