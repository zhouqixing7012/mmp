# 库存管理 - 出库 PRD

## 1. 背景

出库用于承接资产、低值耐用品、普通耗材从仓库正式发出的库存处理。

出库单既可能由用户在“库存管理 → 出库”中手工创建，也可能由员工资产申领、资产借用、耗材领用等上游业务执行出库后自动生成。

当前出库类型固定为：

| 出库类型 | 说明 |
|---|---|
| 领用出库 | 资产或耗材由仓库正式发放给使用人 |
| 借用出库 | 资产临时借给员工使用，后续通过借用归还入库闭环 |

核心出库模块手工创建时，出库类型固定为“领用出库”，不提供手工创建借用出库入口。

员工资产申领、员工资产借用、低值耐用品领用、普通耗材领用等上游业务已经完成各自审批或确认，正式执行后自动生成已完成出库单，进入核心出库模块用于查询、查看、打印和业务追溯，不重复执行出库审批。

## 2. 权限

权限采用“公司 + 板块数据范围”与“仓库操作权限”两层控制，并叠加审批节点处理人权限。

### 2.1 数据权限

公司、板块决定用户可查看和查询的范围，包括：

- 出库单；
- 手工出库候选资产；
- 出库物资详情；
- 审批记录。

用户无对应公司或板块数据权限时，不返回对应记录。

### 2.2 操作权限

仓库权限决定用户能否执行：

- 手工创建出库单；
- 编辑草稿；
- 删除草稿；
- 添加、编辑、删除出库物资；
- 选择当前仓库；
- 模板下载；
- Excel 导入；
- 执行出库 / 发起审批；
- 出库打印；
- 领用打印。

出库列表不提供导出功能，因此不设置列表导出权限。

审批处理权限按当前审批节点和处理人控制：

- 责任人确认；
- 责任人直属 7 级及以上领导审批；
- ES 出库管理员确认。

打开草稿、选择物资、发起审批、审批处理和正式完成出库时均重新校验当前权限，不能仅依赖按钮显隐。

## 3. 通用规则

### 3.1 出库类型与来源

| 来源 | 出库类型 | 生成方式 | 初始状态 | 是否在核心出库再次审批 |
|---|---|---|---|---:|
| 核心出库模块手工创建普通资产 | 领用出库 | 手工创建 | 草稿 | Y |
| 核心出库模块手工创建机房资产 | 领用出库 | 手工创建 | 草稿 | Y |
| 员工资产申领 | 领用出库 | 上游正式执行后自动生成 | 已完成 | N |
| 员工资产借用 | 借用出库 | 上游正式执行后自动生成 | 已完成 | N |
| 员工低值耐用品领用 | 领用出库 | 上游正式执行后自动生成 | 已完成 | N |
| 员工普通耗材领用 | 领用出库 | 上游正式执行后自动生成 | 已完成 | N |

上游自动生成的已完成出库单：

- 不允许重新编辑；
- 不允许再次执行出库；
- 不重复进入核心出库审批；
- 仅用于查询、查看、打印和业务追溯。

### 3.2 出库单状态

出库单状态固定为：

| 状态 | 说明 |
|---|---|
| 草稿 | 尚未发起正式出库，可编辑 |
| 审批中 | 手工领用出库已发起审批，等待当前节点处理 |
| 已完成 | 已完成正式出库，只读 |

手工领用出库：

草稿 → 审批中 → 已完成

审批驳回：

审批中 → 草稿

审批驳回后：

- 保留原出库单；
- 保留已维护出库物资；
- 保留本轮及历史审批记录；
- 不产生正式库存、资产台账或耗材台账变化；
- 制单人修改草稿后可重新点击【执行出库】发起新一轮审批。

已完成单据不得恢复草稿。

上游自动出库直接生成已完成单据。

### 3.3 当前仓库

手工草稿当前仓库必填。

规则：

- 只能选择当前用户有操作权限的仓库；
- 核心出库手工领用仅选择资产仓，不选择耗材仓；
- 草稿无物资时可以直接修改当前仓库；
- 草稿已有物资时修改仓库需要二次确认；
- 确认切换后清空当前已添加出库物资；
- 审批中、已完成当前仓库只读。

切换确认文案：

切换仓库后当前已添加物资将被清空，是否继续？

### 3.4 手工出库候选资产范围

核心出库手工领用仅允许选择当前仓库内的资产类物资。

低值耐用品、普通耗材不得通过核心出库页面手工添加。

候选资产必须同时满足：

1. 资产当前仓库 = 出库单当前仓库；
2. 资产状态属于：
   - 在库-待处理；
   - 在库-新增；
   - 在库-再利用；
3. 未被其他有效领用、借用、移库等业务锁定；
4. 当前用户具备对应仓库和资产范围的出库权限；
5. 与当前出库单已有资产属于同一审批路线和责任审批链。

### 3.5 手工领用审批路线

仅核心出库模块手工创建的领用出库需要走本节审批。

#### 3.5.1 普通资产

流程：

创建草稿 → 执行出库 → 责任人确认 → 责任人直属 7 级及以上领导审批 → ES 出库管理员确认 → 正式完成出库

| 节点 | 处理人 | 操作 | 结果 |
|---|---|---|---|
| 草稿 | 制单人 | 保存草稿 / 执行出库 | 校验通过后进入责任人确认 |
| 责任人确认 | 当前出库物资责任人 | 同意 / 驳回 | 同意进入领导审批；驳回回草稿 |
| 直属领导审批 | 责任人直属 7 级及以上领导 | 同意 / 驳回 | 同意进入 ES 确认；驳回回草稿 |
| ES 出库管理员确认 | 当前仓库 ES 出库管理员 | 同意 / 驳回 | 同意正式出库；驳回回草稿 |

#### 3.5.2 机房资产

机房资产包括：

- 服务器；
- 服务器备件；
- 网络设备；
- 网络设备备件。

流程：

创建草稿 → 执行出库 → 责任人直属 7 级及以上领导审批 → 正式完成出库

机房资产：

- 不经过独立责任人确认；
- 不经过 ES 出库管理员确认；
- 直属 7 级及以上领导审批通过后正式完成出库。

### 3.6 审批链一致性与单据拆分

一张手工领用出库单中的资产必须属于同一审批路线。

禁止以下资产混在同一张手工出库单：

1. 普通资产与机房资产；
2. 普通资产对应责任人、直属 7 级及以上领导或 ES 出库管理员不同；
3. 机房资产对应直属 7 级及以上领导不同。

选择资产时发现审批路线不一致：

所选资产与当前出库单审批路线不一致，请拆分出库单处理。

整单执行出库前再次校验：

所选资产对应的责任审批链不一致，请拆分出库单后重新提交。

### 3.7 手工创建固定规则

核心出库模块点击【创建】后：

- 出库类型固定为“领用出库”；
- 是否刷卡领用固定为“否”；
- 两个字段均只读；
- 不提供手工借用出库类型切换；
- 当前仓库由用户选择；
- 草稿物资只能从当前仓库合法候选资产中选择。

### 3.8 草稿物资编辑

草稿出库物资列表最后固定展示【操作】列。

草稿状态展示【编辑】。

点击【编辑】时复用原“添加领用物资”弹窗：

- 回显当前行已保存数据；
- 物资选择及领用信息字段保持与新增时一致；
- 不另做字段缩水版编辑弹窗。

审批中、已完成不展示行编辑和复选删除入口。

### 3.9 Excel 导入

手工领用出库草稿的出库物资区域提供：

- 【模板下载】
- 【Excel导入】

该能力属于草稿出库物资维护，不属于出库列表导出。

上传后先校验，不直接执行出库。

至少校验：

- 当前仓库；
- 资产标签号是否存在；
- 资产是否属于当前仓库；
- 资产状态是否允许出库；
- 是否已被其他业务锁定；
- 是否与当前单据审批路线一致；
- 必填领用字段；
- 同单资产责任审批链是否一致。

校验通过的数据加入当前草稿。

失败时反馈 Excel 行号、字段及错误原因。

### 3.10 正式出库事务

只有以下任一条件满足后，才产生正式出库结果：

- 手工领用出库最后一个审批节点通过；
- 上游业务正式执行出库。

正式出库作为一个完整业务事务处理。

任一步骤失败：

- 不允许只完成部分库存扣减；
- 不产生半完成资产 / 耗材台账；
- 不提前将出库单更新为已完成；
- 不重复生成出库事务。

手工审批驳回不产生正式出库结果。

### 3.11 采购接收来源通知

正式出库物资如果来源属于采购接收链路，出库成功后向对应采购专员发送服务号通知。

适用范围包括：

- 普通资产；
- 服务器；
- 服务器备件；
- 网络设备；
- 网络设备备件；
- 低值耐用品；
- 普通耗材。

判断依据使用物资自身采购、PO、采购接收关联关系，不按物资类别简单推断。

处理顺序：

1. 完成正式出库及库存 / 台账 / 事务写入；
2. 再发送采购专员服务号通知。

通知失败：

- 不回滚已完成出库；
- 系统记录通知成功 / 失败；
- 出库单详情不展示采购专员通知状态；
- 出库单详情不提供通知重发入口。

后续如建设后台异常处理能力，通知重试只能重新发送通知，不得重复执行出库、重复扣库存或重复生成事务。

共 X 条

#### 4.1.3 列表操作

出库列表仅提供：

- 【创建】
- 【删除】
- 【出库打印】
- 【领用打印】

**出库列表不提供【导出】功能。**

删除：

- 至少选择 1 张；
- 所选单据必须全部为草稿；
- 包含审批中或已完成时提示：仅草稿出库单允许删除；
- 删除前二次确认；
- 删除草稿不产生正式库存或台账变化。

出库打印：

- 至少选择 1 张；
- 所选单据必须全部已完成；
- 草稿、审批中禁止正式出库打印。

领用打印：

- 至少选择 1 张；
- 所选单据必须全部已完成；
- 已完成领用出库、已完成借用出库均允许领用打印。

| City | 下拉 | Y | 领用人默认位置 | 修改后清空 Building、Floor |
| Building | 下拉 | Y | City 过滤 | 修改后清空 Floor |
| Floor | 下拉 | Y | City + Building 过滤 | 仅展示联动结果 |
| Room | 输入框 | N | 空 / 默认位置 | 可编辑 |
| 领用日期 | 日期 | Y | 当前日期 | 可修改 |
| 用途 | 下拉 | Y | 员工用机 | 员工用机 / 部门公用 / 其他用途 / 专业用途 |
| 使用说明 | 多行文本 | N | 空 | 整行展示 |

位置联动：

- 修改 City 后清空 Building、Floor；
- 修改 Building 后清空 Floor；
- Floor 由 City + Building 联动过滤。

## 5. 校验

### 5.1 草稿通用校验

| 校验项 | 规则 |
|---|---|
| 出库物资 | 至少存在 1 条 |
| 当前仓库 | 必填 |
| 出库数量 | 必须大于 0 |
| 资产仓库 | 必须与当前仓库一致 |
| 资产状态 | 必须属于允许出库状态 |
| 业务锁定 | 已被其他业务锁定资产不可选择 |
| 领用必填字段 | 必须完整 |
| 审批路线 | 单据内全部资产审批路线一致 |
| 审批责任链 | 单据内全部资产责任审批链一致 |

资产不属于当前仓库：

资产不在当前库，请先执行移库操作！

必填信息不完整：

请检查所有必填项及内容格式

### 5.2 候选资产

手工领用候选资产必须满足通用规则 3.4。

选择资产及执行出库两个时点均重新校验，不只依赖首次打开选择弹窗时的状态。

### 5.3 审批人

普通资产必须能够确定：

- 责任人；
- 责任人直属 7 级及以上领导；
- ES 出库管理员。

机房资产必须能够确定：

- 责任人；
- 责任人直属 7 级及以上领导。

无法确定完整审批链时不得发起审批。

### 5.4 审批操作

- 当前用户必须是当前审批节点处理人。
- 同意时审批意见可为空。
- 驳回时审批意见必填。
- 已处理节点不得重复提交。
- 最后节点正式完成出库前再次执行必要库存与业务状态校验。

### 5.5 Excel 导入

至少校验：

- 当前仓库已选择；
- 标签号有效；
- 资产属于当前仓库；
- 状态允许出库；
- 未被其他业务锁定；
- 当前单据不存在重复资产；
- 审批路线一致；
- 责任审批链一致；
- 必填领用字段完整。

校验失败不执行正式出库。

### 5.6 删除

删除出库单：

- 必须至少选择 1 张；
- 所选单据全部为草稿。

删除草稿物资：

- 仅草稿允许；
- 删除前二次确认。

审批中、已完成禁止删除单据或出库物资。

### 5.7 打印

- 正式出库打印仅已完成允许。
- 领用打印仅已完成允许。
- 草稿、审批中不得打印正式凭证。
- 明细为空不生成正式打印单。
- 打印失败允许重试，不重复执行出库业务。

## 6. 后续操作 / 业务结果 / 补充说明

### 6.1 删除草稿 / 删除物资

删除草稿出库单：

- 不修改资产台账；
- 不修改耗材库存；
- 不生成出库事务；
- 已选择资产释放当前草稿占用，可重新被其他合法业务选择。

删除草稿出库物资：

- 只从当前草稿移除；
- 不产生正式业务变化；
- 对应资产恢复为可被其他合法业务选择。

### 6.2 普通资产领用结果

最终审批通过后：

- 出库单更新为已完成；
- 记录正式出库时间；
- 资产从当前仓库可用库存中移出；
- 资产责任人更新为领用人；
- 更新部门、公司、成本中心、业务线；
- 更新 City、Building、Floor、Room；
- 更新用途、使用说明；
- 资产状态更新为“在用-使用中”；
- 生成资产出库事务及相关报表数据。

### 6.3 机房资产领用结果

除普通资产正式出库结果外：

- 保留 NO位置；
- 保留服务等机房资产属性；
- 更新实际责任人；
- 更新实际使用位置；
- 更新在用状态；
- 生成机房资产出库事务及相关报表。

### 6.4 借用出库结果

上游资产借用正式执行后：

- 自动生成已完成借用出库单；
- 资产状态更新为“在用-借用中”；
- 保存借用人；
- 保存借用开始日期；
- 保存预计归还日期；
- 从当前仓库可用库存中移出；
- 生成资产借用出库事务；
- 后续通过借用归还入库闭环。

### 6.5 普通耗材 / 低值耐用品出库结果

普通耗材：

- 扣减目标耗材仓库存数量；
- 更新耗材库存台账；
- 生成耗材出库事务；
- 自动生成已完成领用出库单。

低值耐用品：

- 扣减耗材仓库存；
- 更新低值耐用品耗材台账；
- 保存耗材标签号、SN、领用人等结果；
- 生成耗材出库事务；
- 自动生成已完成领用出库单。

### 6.6 审批驳回

审批驳回后：

- 单据恢复草稿；
- 已维护出库物资保留；
- 审批历史保留；
- 不修改正式库存；
- 不修改正式资产 / 耗材台账；
- 不生成正式出库事务；
- 制单人修改后可再次执行出库并发起新一轮审批。

### 6.7 采购接收来源通知

正式出库完成后，如果物资属于采购接收来源：

- 向对应采购专员发送服务号通知；
- 通知失败不回滚出库；
- 系统记录通知结果；
- 出库详情不展示通知状态；
- 出库详情不提供通知重发。

借用出库不追加员工操作确认信息页。

### 6.11 打印通用规则

- 仅已完成出库单允许正式打印。
- 草稿、审批中不得打印正式凭证。
- 单条打印、批量打印使用同一字段口径。
- 打印只读取已保存数据。
- 打印、预览、重打不改变库存、台账、审批状态和出库时间。
- 空值打印为空白，不打印 null、undefined。
- 金额保留两位小数。
- 整数数量不展示无意义小数。
- 明细跨页时重复表头并显示页码。
- 明细为空不生成正式打印单。
- 打印失败允许重试，不重复执行出库或生成新业务单号。

### 6.12 关键流程汇总

普通资产手工领用：

创建草稿 → 选择同一审批链普通资产 → 执行出库 → 责任人确认 → 责任人直属 7 级及以上领导审批 → ES 出库管理员确认 → 正式出库 → 台账 / 库存 / 事务更新 → 采购接收来源则通知采购专员

机房资产手工领用：

创建草稿 → 选择同一审批链机房资产 → 执行出库 → 责任人直属 7 级及以上领导审批 → 正式出库 → 台账 / 库存 / 事务更新 → 采购接收来源则通知采购专员

员工资产申领：

员工资产申领流程 → 员工确认 → 上游执行出库 → 自动生成已完成领用出库单 → 核心出库查询 / 查看 / 打印 → 采购接收来源则通知采购专员

资产借用：

员工资产借用流程 → 审批及员工确认 → 上游执行借用出库 → 自动生成已完成借用出库单 → 资产状态=在用-借用中 → 核心出库查询 / 查看 / 打印 → 后续借用归还入库

耗材领用：

耗材申请 / 配给 → 员工确认 → 正式出库 → 耗材库存及台账更新 → 自动生成已完成领用出库单 → 采购接收来源则通知采购专员
