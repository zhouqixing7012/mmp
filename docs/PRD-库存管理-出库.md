# 库存管理 - 出库 PRD

## 1. 背景

出库用于承接资产、低值耐用品、普通耗材从仓库正式发出的库存处理。

出库单既可能由用户在「库存管理 → 出库」中手工创建，也可能由员工资产申领、资产借用、耗材领用等上游业务执行出库后自动生成。

本需求需明确：

- 出库单来源及不同来源处理方式；
- 手工领用出库的审批流程；
- 普通资产与机房资产不同的审批节点；
- 领用出库、借用出库的页面字段及交互；
- 草稿、审批中、已完成状态及状态流转；
- 待出库资产选择及仓库限制；
- 执行出库后的库存、资产台账、耗材台账及事务变化；
- 采购接收来源物资出库完成后的采购专员服务号通知；
- 出库打印、领用打印及 Excel 能力。

## 2. 出库类型及来源

当前出库类型固定为：

| 出库类型 | 说明 |
|---|---|
| 领用出库 | 资产或耗材由仓库正式发放给使用人 |
| 借用出库 | 资产临时借给员工使用，后续通过借用归还入库闭环 |

### 2.1 来源矩阵

| 来源 | 出库类型 | 生成方式 | 初始状态 | 是否在核心出库页再次审批 |
|---|---|---|---|---|
| 出库模块手工创建普通资产 | 领用出库 | 手工创建 | 草稿 | Y |
| 出库模块手工创建机房资产 | 领用出库 | 手工创建 | 草稿 | Y |
| 员工资产申领 | 领用出库 | 上游执行出库后自动生成 | 已完成 | N |
| 员工资产借用 | 借用出库 | 上游执行出库后自动生成 | 已完成 | N |
| 员工低值耐用品领用 | 领用出库 | 上游执行出库后自动生成 | 已完成 | N |
| 员工普通耗材领用 | 领用出库 | 上游执行出库后自动生成 | 已完成 | N |

上游业务自动生成的已完成出库单进入出库列表后，仅用于查询、查看、出库打印、领用打印和业务追溯，不得再次编辑或重复执行出库。

核心出库页点击【创建】时，出库类型固定为“领用出库”，不允许手工创建借用出库。借用出库由资产借用流程完成审批及员工确认后自动生成。

## 3. 出库单状态

出库单状态固定为：

| 状态 | 说明 |
|---|---|
| 草稿 | 尚未发起正式出库，可编辑 |
| 审批中 | 手工领用出库已发起审批，等待当前审批节点处理 |
| 已完成 | 已完成正式出库，只读 |

普通上游自动出库直接形成已完成单据。

手工领用出库状态流转：

`草稿 → 审批中 → 已完成`

审批驳回：

`审批中 → 草稿`

审批驳回后：

- 保留原出库单及已维护物资；
- 保留本次及历史审批记录；
- 不产生正式库存、资产台账或耗材台账变化；
- 制单人修改后可重新点击【执行出库】发起新一轮审批。

已完成单据不得恢复草稿。

## 4. 手工领用出库审批

仅在核心「库存管理 → 出库」手工创建的领用出库需要走本章节审批。员工资产申领、资产借用、耗材领用等上游流程已完成各自审批或确认，自动生成出库单后不重复审批。

### 4.1 普通资产审批路线

普通资产手工领用流程：

`创建草稿 → 执行出库 → 责任人确认 → 责任人直属7级及以上领导审批 → ES出库管理员确认 → 正式完成出库`

| 节点 | 处理人 | 可执行操作 | 结果 |
|---|---|---|---|
| 草稿 | 制单人 | 保存草稿 / 执行出库 | 执行出库校验通过后进入责任人确认 |
| 责任人确认 | 当前出库物资责任人 | 同意 / 驳回 | 同意进入领导审批；驳回回草稿 |
| 直属领导审批 | 责任人直属7级及以上领导 | 同意 / 驳回 | 同意进入 ES 出库管理员确认；驳回回草稿 |
| ES出库管理员确认 | 当前仓库 ES 出库管理员 | 同意 / 驳回 | 同意后正式出库；驳回回草稿 |

### 4.2 机房资产审批路线

机房资产包括：服务器、服务器备件、网络设备、网络设备备件。

机房资产手工领用流程：

`创建草稿 → 执行出库 → 责任人直属7级及以上领导审批 → 正式完成出库`

机房资产不经过独立“责任人确认”节点，也不经过“ES出库管理员确认”节点；直属7级及以上领导审批通过即正式完成出库。

| 节点 | 处理人 | 可执行操作 | 结果 |
|---|---|---|---|
| 草稿 | 制单人 | 保存草稿 / 执行出库 | 校验通过后进入领导审批 |
| 直属领导审批 | 责任人直属7级及以上领导 | 同意 / 驳回 | 同意后正式出库；驳回回草稿 |

### 4.3 单据拆分规则

一张手工领用出库单中的资产必须属于同一审批路线。

以下情况禁止混合在同一张手工出库单：

1. 普通资产与机房资产混单；
2. 普通资产对应的责任人、直属7级及以上领导或 ES 出库管理员不同；
3. 机房资产对应的直属7级及以上领导不同。

用户选择与当前出库单审批路线不一致的资产时阻断，提示：

`所选资产与当前出库单审批路线不一致，请拆分出库单处理。`

整单提交前再次校验审批链，若发现不同审批链提示：

`所选资产对应的责任审批链不一致，请拆分出库单后重新提交。`

### 5.3 列表操作

列表提供【创建】【删除】【出库打印】【领用打印】【导出】。

复选框允许选择不同状态的单据，具体业务限制由按钮动作统一校验。

#### 删除

- 至少选择1张出库单；
- 所选单据必须全部为草稿；
- 包含审批中或已完成时提示 `仅草稿出库单允许删除`；
- 删除前二次确认；
- 删除草稿不产生任何正式库存或台账变化。

#### 出库打印

- 至少选择1张；
- 所选单据必须全部为已完成；
- 草稿、审批中禁止正式出库打印。

#### 领用打印

- 至少选择1张；
- 所选单据必须全部为已完成；
- 已完成领用出库、已完成借用出库均允许领用打印。

#### 导出

导出当前查询结果，不受当前复选框选择影响。导出字段至少覆盖列表展示字段及业务追溯所需的来源单号、标签号等字段。

### 6.1 修改当前仓库

草稿无物资时可直接修改当前仓库。草稿已有物资时修改仓库，弹出二次确认：

`切换仓库后当前已添加物资将被清空，是否继续？`

确认后切换仓库并清空当前出库物资；取消则保留原仓库和已有物资。审批中、已完成仓库只读。

## 7. 手工出库物资选择

手工领用出库仅允许选择当前仓库内的资产类物资。低值耐用品和普通耗材不得通过核心出库页手工添加。

### 7.1 固定可选范围

资产必须同时满足：

1. 当前仓库与出库单当前仓库一致；
2. 资产状态属于在库-待处理 / 在库-新增 / 在库-再利用；
3. 未被其他有效领用、借用、移库等业务锁定；
4. 当前操作人具备对应仓库和资产范围的出库权限；
5. 与当前出库单已有资产属于同一审批路线及责任审批链。

### 7.2 资产选择弹窗查询条件

点击添加物资弹窗中的【资产标签号】或【SN号】打开资产选择弹窗。

| 字段 | 组件 | 查询规则 |
|---|---|---|
| 资产标签号 | 输入框 | 模糊查询 |
| SN号 | 输入框 | 模糊查询 |
| 资产说明 | 输入框 | 模糊查询 |
| 资产大类 | 输入框 / 下拉 | 查询资产大类 |
| 资产小类 | 输入框 / 下拉 | 查询资产小类 |
| 责任人 | 输入框 | 模糊查询 |

### 7.3 资产选择弹窗结果字段

结果字段：资产标签号、SN号、资产说明、公司、板块、资产大类、资产小类、当前状态、当前仓库、当前责任人。

一次选择1件实际资产。选择资产后返回添加物资页面，并整体带出当前资产基础信息。

### 9.3 借用正式出库结果

- 资产状态更新为在用-借用中；
- 保存借用人；
- 保存借用开始日期和预计归还日期；
- 从当前仓库可用库存中移出；
- 生成资产借用出库事务；
- 后续通过借用归还入库完成闭环。

## 10. 普通耗材 / 低值耐用品出库

普通耗材、低值耐用品不允许在核心出库页手工添加，均由耗材领用流程执行出库后自动生成已完成领用出库单。

### 10.1 普通耗材出库物资列表

| 字段 | 规则 |
|---|---|
| 行号 | 当前序号 |
| 标签号 | 无标签时显示“-” |
| 物资总类 | 耗材类型 |
| 耗材大类 | 来源耗材主数据 |
| 耗材说明 | 来源耗材主数据 |
| 数量 | 本次出库数量 |
| 领用人 | 来源耗材领用流程 |
| 领用日期 | 实际出库日期 |
| 耗材状态 | 已领用等正式结果 |

### 10.2 低值耐用品出库物资列表

| 字段 | 规则 |
|---|---|
| 行号 | 当前序号 |
| 耗材标签号 | 蓝色详情入口 |
| SN序列号 | 逐件 SN |
| 物资总类 | 低值耐用品 |
| 耗材大类 | 来源耗材主数据 |
| 耗材说明 | 来源耗材主数据 |
| 数量 | 单件通常为1 |
| 领用人 | 来源耗材领用流程 |
| 领用日期 | 实际出库日期 |
| 耗材状态 | 已领用等正式结果 |

低值耐用品及普通耗材详情统一使用耗材业务命名，不使用资产大类、资产说明、资产标记等资产专属字段。

### 10.3 正式出库结果

普通耗材正式出库后扣减目标耗材仓库存数量、更新耗材库存台账、生成耗材出库事务并自动生成已完成领用出库单。

低值耐用品正式出库后扣减耗材仓库存、更新低值耐用品耗材台账、保存耗材标签号/SN/领用人等结果、生成耗材出库事务并自动生成已完成领用出库单。

## 11. 审批中页面

手工领用出库进入审批中后，单据头、当前仓库、物资数据均只读，不允许添加、删除、编辑或 Excel 导入。

### 11.1 当前审批信息

| 字段 | 规则 |
|---|---|
| 审批路线 | 普通资产手工领用 / 机房资产手工领用 |
| 当前节点 | 当前等待处理的审批节点 |
| 当前处理人 | 工号-姓名 |
| 发起人 | 本轮审批发起人 |
| 发起时间 | 本轮审批发起时间 |
| 审批状态 | 审批中 |
| 审批意见 | 当前审批人填写；驳回必填，同意选填 |

当前审批人展示【同意】【驳回】；非当前审批人只读查看，不显示审批动作。

### 11.2 审批记录

审批记录字段：序号、节点、处理人、操作、操作时间、审批意见。

同意后进入下一节点；最后一个审批节点同意后正式完成出库。

驳回后记录驳回节点、处理人、时间、意见，单据恢复草稿，历史审批记录继续展示，不产生正式出库业务结果。

## 12. 页面操作

### 12.1 草稿

页面底部固定为【保存草稿】【执行出库】【返回】。

【执行出库】实际含义为“校验并发起出库审批”，不是立即修改库存。校验成功后提示当前审批节点。

### 12.2 审批中

当前审批人展示【同意】【驳回】【返回】；普通查看人员仅展示【返回】。

### 12.3 已完成

页面底部展示【打印】【返回】。如果采购专员通知状态为失败，额外显示【重新发送采购通知】。

重发通知不得重复执行出库、重复扣库存或重复生成事务。

## 13. 草稿物资删除

草稿状态允许勾选物资后点击【删除物资】，删除前二次确认。

删除仅影响当前草稿：不修改资产台账、不产生库存事务，对应资产恢复为可被其他业务选择。审批中、已完成禁止删除物资。

## 14. Excel

手工领用出库草稿的出库物资区域提供【模板下载】【Excel导入】。

### 14.1 模板下载

下载手工领用出库标准模板。

### 14.2 Excel导入

导入后先校验，不直接执行出库。至少校验：当前仓库、资产标签号是否存在、资产是否属于当前仓库、资产状态是否允许出库、是否已被其他业务锁定、是否与当前单据审批路线一致、必填领用字段、同单资产责任审批链是否一致。

校验通过的数据加入当前草稿。失败时反馈 Excel行号、字段、错误原因。

列表页【导出】负责查询结果导出，不在单据详情重复提供出库物资导出。

## 15. 执行出库校验

### 15.1 通用校验

| 校验项 | 规则 |
|---|---|
| 出库物资 | 至少存在1条 |
| 当前仓库 | 必填 |
| 出库数量 | 必须大于0 |
| 资产仓库 | 必须与当前仓库一致 |
| 资产状态 | 必须属于允许出库状态 |
| 业务锁定 | 不允许选择已被其他业务锁定资产 |
| 领用必填字段 | 全部维护完整 |
| 审批路线 | 单据内全部资产审批路线一致 |
| 审批责任链 | 单据内全部资产责任审批链一致 |

资产不属于当前仓库时提示 `资产不在当前库，请先执行移库操作！`。

必填信息不完整时提示 `请检查所有必填项及内容格式`。

### 15.2 审批人校验

普通资产必须确定责任人、责任人直属7级及以上领导、ES出库管理员；机房资产必须确定责任人及责任人直属7级及以上领导。无法确定审批链时不允许发起审批。

## 16. 正式完成出库的数据变化

只有最终审批通过或上游业务正式执行出库后，才产生正式数据变化。

### 16.1 普通资产领用

- 出库单更新为已完成并记录正式出库时间；
- 资产从当前仓库可用库存中移出；
- 资产责任人更新为领用人；
- 更新部门、公司、成本中心、业务线；
- 更新 City、Building、Floor、Room；
- 更新用途、使用说明；
- 资产状态更新为在用-使用中；
- 生成资产出库事务及相关报表数据。

### 16.2 机房资产领用

除正式出库通用结果外，保留 NO位置、服务等机房资产属性，更新实际责任人、使用位置及在用状态，并生成机房资产出库事务及相关报表。

### 16.3 借用出库

出库单已完成；资产状态更新为在用-借用中；保存借用人、借用日期、预计归还日期；从当前仓库可用库存中移出；生成资产借用事务；后续由借用归还入库闭环。

### 16.4 耗材及低值耐用品

按第10章正式扣减库存并更新耗材台账及事务。

### 16.5 事务原子性

正式出库业务结果作为一个完整事务处理。任一步骤失败时不得只完成部分库存扣减，不得产生半完成资产/耗材台账，不得将出库单提前标记为已完成；用户修正异常后重新执行对应正式处理。

## 17. 采购接收来源通知

凡正式出库物资来源属于采购接收链路，出库成功后均向对应采购专员发送服务号通知。

适用物资包括但不限于普通资产、服务器、服务器备件、网络设备、网络设备备件、低值耐用品、普通耗材。

判断依据为物资自身的采购、PO、采购接收关联关系，不根据物资类别简单判断。

### 17.1 通知与出库事务关系

1. 先完成正式出库及库存/台账/事务写入；
2. 再发送采购专员服务号通知；
3. 通知失败不回滚已完成出库。

### 17.2 通知状态及重试

存在采购接收来源时，已完成出库单展示【采购专员通知状态】，枚举为成功 / 失败。

通知失败时页面底部展示【重新发送采购通知】。

重试仅重新发送通知，不得重复执行出库、重复扣减库存、重复生成资产或耗材事务，也不得修改原出库时间。重试成功后通知状态更新为“成功”。

## 18. 打印

### 18.1 通用规则

- 正式出库单和领用/借用凭证仅允许对“已完成”出库单打印；草稿、审批中均不得打印正式凭证。
- 打印、预览、重打只读取当前已保存的出库单及明细，不改变库存、台账、审批状态、出库时间，也不重复生成出库事务。
- 列表批量【出库打印】、【领用打印】与单据详情打印使用同一字段口径。
- 空值打印为空白；金额保留两位小数；数量为整数时不展示无意义小数。
- 明细为空时不生成正式打印单；打印失败允许重试。

### 18.2 物资出库单

适用于所有已完成领用出库、借用出库。

打印标题固定为 **物资出库单**，版式和联次保持现有模板。

表头字段：

| 字段 | 规则 |
|---|---|
| 出库单号 | 当前出库单号 |
| 出库时间 | 正式出库时间，按现有日期格式展示 |
| 仓库名称 | 当前出库仓库名称 |
| PR单号 | 当前业务关联 PR 单号 |
| PO单号 | 当前业务关联 PO 单号；无值留空 |
| 地点位置 | 按现有位置口径展示 |
| 资产大类 | 当前出库物资大类名称 |
| 使用人 | 当前领用人/借用人 |
| 使用部门 | 当前使用部门名称 |

明细字段保持现状：

| 列 | 规则 |
|---|---|
| 序号 | 明细顺序，从1开始 |
| 品名（物资说明） | 按现有口径展示物资说明及物资类别子目录、品牌、规格型号等组合描述 |
| 资产标签号 | 资产/低值耐用品展示标签；无标签物资为空 |
| SN号 | 有SN时展示，无值留空 |
| 数量 | 本次出库数量 |
| 价值-单价 | 当前单价，保留两位小数 |
| 价值-原值 | 当前明细原值，保留两位小数 |
| 备注 | 保持现状口径，用于展示业务线、新资产地点或启用日期等当前查询返回的说明值；本次不改为资产卡片“使用说明” |

底部汇总数量和原值合计。

页脚保留：使用人（签字）/时间、部门经理（签字）/时间、库管员（签字）/时间。

### 18.3 员工领用单

已完成领用出库允许打印领用凭证。

一般领用标题为 **员工领用单**；新员工领用、借用业务按现有业务类型使用对应标题，不将所有场景统一成同一标题。

表头保持现有字段：领用单号、领用时间、仓库名称、使用部门、使用人。

明细保持现有列：

| 列 | 规则 |
|---|---|
| 序号 | 明细顺序 |
| 资产大类 | 当前资产大类名称 |
| 品名（物资说明） | 按现有组合口径展示 |
| 资产标签号 | 当前资产标签号 |
| SN号 | 当前SN |
| 数量 | 领用数量 |
| 领用类型 | 一般领用 / 新员工领用等实际类型 |
| 用途 | 来源领用业务用途 |
| 领用说明 | 保持现有口径，展示业务线或新资产地点等领用说明；与“用途”“使用说明”均为不同字段 |

打印固定展示现有保管职责声明，并保留使用人、部门经理、库管员的签字/时间区域。

### 18.4 员工借用单

已完成借用出库允许通过【领用打印】打印借用凭证。

标题按现有口径展示 **员工借用单**。

除领用单公共字段外，借用单展示借用类型以及预计借用/归还相关日期；字段取值沿用资产借用流程已经保存的结果，不在打印时重新计算。

保管职责和签字区域与现有借用打印模板保持一致。

## 19. 权限

至少区分：出库列表查看、手工创建、草稿编辑、草稿删除、草稿物资添加/删除、执行出库/发起审批、责任人确认、责任人直属7级及以上领导审批、ES出库管理员确认、出库打印、领用打印、Excel模板下载、Excel导入、列表导出、采购专员通知重试、可操作仓库范围。

## 20. 关键流程汇总

### 20.1 普通资产手工领用

`创建草稿 → 选择同一审批链普通资产 → 执行出库 → 责任人确认 → 责任人直属7级及以上领导审批 → ES出库管理员确认 → 正式出库 → 资产台账/库存/事务更新 → 采购接收来源则通知采购专员`

### 20.2 机房资产手工领用

`创建草稿 → 选择同一审批链机房资产 → 执行出库 → 责任人直属7级及以上领导审批 → 正式出库 → 资产台账/库存/事务更新 → 采购接收来源则通知采购专员`

### 20.3 员工资产申领

`员工资产申领流程 → 员工确认 → 上游执行出库 → 自动生成已完成领用出库单 → 核心出库页查询/查看/打印 → 采购接收来源则通知采购专员`

### 20.4 资产借用

`员工资产借用流程 → 审批及员工确认 → 上游执行借用出库 → 自动生成已完成借用出库单 → 资产状态=在用-借用中 → 核心出库页查询/查看/出库打印/领用打印 → 后续借用归还入库`

### 20.5 耗材领用

`耗材申请/配给 → 员工确认 → 执行出库 → 耗材库存及台账更新 → 自动生成已完成领用出库单 → 采购接收来源则通知采购专员`
