# 库存管理 - 出库

## 页面范围

本页面位于「库存管理 → 出库」。历史系统截图只作为字段与业务分支来源，页面结构和视觉继续遵循当前资产系统 UI 规范。

## 出库类型

- 领用出库
- 借用出库

两种类型共用出库单头；物资列表和添加物资后的业务维护字段按出库类型区分。

## 出库单列表

查询条件：出库单号、出库类型、单据状态、PO单号、申请单号、资产标签号、制单人、制单日期、资产责任人。

“制单日期”使用一个日期范围控件，不拆成“制单日期从 / 制单日期至”两个查询项。

列表不设置“操作”列。出库单号作为单据入口：草稿进入可编辑页，已完成进入只读详情页。

列表继续支持创建、删除、出库打印、领用打印。

## 出库单头

- 出库单号：保存后自动生成
- 单据类型：出库工单
- 单据状态
- 出库类型
- 制单人
- 制单时间
- 是否刷卡领用
- 当前仓库
- 备注：多行文本，独占完整一行

草稿态字段可按当前页面规则维护；已完成状态按只读详情展示。

## 页面操作

### 草稿态出库单

页面底部固定为：

- 保存草稿
- 执行出库
- 返回

执行出库后单据状态进入“已完成”。草稿态的物资区域可继续添加、删除、导入和编辑物资行。

### 已完成出库单

页面底部固定为：

- 打印
- 返回

已完成单据按只读详情展示，不再提供添加、删除、导入或物资行编辑入口。

页面级操作放页面底部居中；物资区域的添加、删除、导入只在草稿态显示。
