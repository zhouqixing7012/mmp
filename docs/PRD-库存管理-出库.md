# 库存管理 - 出库 PRD

## 1. 背景

出库用于承接资产、低值耐用品、普通耗材从仓库正式发出的库存处理。

出库单有两类来源：

1. **库存管理手工创建**：用于资产类领用出库，包括普通资产和机房资产。
2. **上游业务自动生成**：员工资产申领、员工资产借用、低值耐用品领用、普通耗材领用完成正式出库后，自动生成已完成出库单。

普通耗材按数量管理，通过耗材领用流程完成出库；低值耐用品通过低值耐用品领用流程完成出库。

出库类型固定为：

| 出库类型 | 业务含义 |
|---|---|
| 领用出库 | 资产、低值耐用品或普通耗材正式发放给使用人 |
| 借用出库 | 资产临时借给员工使用，后续通过借用归还入库闭环 |

库存管理手工创建的出库单固定为“领用出库”。

## 2. 权限

### 2.1 数据权限

出库数据按“公司 + 板块”控制查询范围，并叠加仓库操作权限。

用户可查看的数据包括：

- 出库单；
- 手工出库候选资产；
- 出库物资详情；
- 审批记录。

### 2.2 操作权限

仓库操作权限控制以下操作：

- 创建资产领用出库单；
- 编辑、删除草稿；
- 添加、编辑、删除出库资产；
- 选择当前仓库；
- 下载模板；
- Excel 导入资产；
- 执行出库；
- 出库打印；
- 领用打印。

审批处理权限按当前审批节点和处理人控制。

普通资产审批节点包括：

- 责任人确认；
- 责任人直属 7 级及以上领导审批；
- ES 出库管理员确认。

机房资产审批节点包括：

- 责任人直属 7 级及以上领导审批。

打开草稿、选择资产、执行出库、审批处理和正式完成出库时均重新校验当前权限。

## 3. 通用规则

### 3.1 出库来源与状态

| 来源 | 出库类型 | 生成方式 | 初始状态 |
|---|---|---|---|
| 库存管理手工创建普通资产 | 领用出库 | 手工创建 | 草稿 |
| 库存管理手工创建机房资产 | 领用出库 | 手工创建 | 草稿 |
| 员工资产申领 | 领用出库 | 上游正式执行后自动生成 | 已完成 |
| 员工资产借用 | 借用出库 | 上游正式执行后自动生成 | 已完成 |
| 低值耐用品领用 | 领用出库 | 上游正式执行后自动生成 | 已完成 |
| 普通耗材领用 | 领用出库 | 上游正式执行后自动生成 | 已完成 |

手工资产领用出库按“是否自购出库”流转：

- 是否自购出库 = 是：草稿 → 审批中 → 已完成；
- 是否自购出库 = 否：草稿 → 已完成。

审批驳回后，单据恢复草稿，保留出库资产和审批记录，制单人修改后可再次执行出库。

上游业务自动生成的出库单直接进入已完成状态，用于查询、查看和打印。

### 3.2 当前仓库

手工创建资产领用出库草稿时必须选择当前仓库。

当前仓库候选范围为当前用户有操作权限的资产仓。

规则：

- 【添加物资】从当前仓库查询合法候选资产；
- Excel 导入只处理当前仓库资产；
- 草稿为空时可直接修改当前仓库；
- 草稿已有资产时，修改仓库前二次确认；
- 确认修改后清空当前出库资产并释放对应资产锁定；
- 审批中、已完成单据的当前仓库只读。

同一张手工出库单中的全部资产属于同一当前仓库。

切换确认文案：

> 切换仓库后当前已添加物资将被清空，是否继续？

### 3.3 手工出库候选资产

手工出库仅选择资产类物资。

候选资产同时满足：

1. 当前仓库与出库单当前仓库一致；
2. 资产状态属于“在库-待处理”“在库-新增”“在库-再利用”；
3. 当前资产处于可出库状态；
4. 当前用户具备对应仓库及资产数据权限；
5. 与当前出库单已有资产属于同一审批路线和责任审批链。

普通资产和机房资产分别按本 PRD 审批路线执行。

### 3.4 手工领用审批路线

仅“是否自购出库 = 是”的手工资产领用出库进入审批。

#### 3.4.1 普通资产

流程：

创建草稿 → 执行出库 → 责任人确认 → 责任人直属 7 级及以上领导审批 → ES 出库管理员确认 → 正式完成出库

| 节点 | 处理人 | 操作 | 结果 |
|---|---|---|---|
| 草稿 | 制单人 | 保存草稿 / 执行出库 | 校验通过后进入责任人确认 |
| 责任人确认 | 当前出库资产责任人 | 同意 / 驳回 | 同意进入领导审批；驳回回草稿 |
| 直属领导审批 | 责任人直属 7 级及以上领导 | 同意 / 驳回 | 同意进入 ES 确认；驳回回草稿 |
| ES 出库管理员确认 | 当前仓库 ES 出库管理员 | 同意 / 驳回 | 同意正式出库；驳回回草稿 |

#### 3.4.2 机房资产

机房资产包括：

- 服务器；
- 服务器备件；
- 网络设备；
- 网络设备备件。

流程：

创建草稿 → 执行出库 → 责任人直属 7 级及以上领导审批 → 正式完成出库

### 3.5 审批链一致性

“是否自购出库 = 是”时，一张手工出库单中的资产使用同一审批路线和责任审批链。

普通资产与机房资产分别建单。

普通资产按责任人、直属 7 级及以上领导、ES 出库管理员拆分审批链；机房资产按直属 7 级及以上领导拆分审批链。

选择资产和执行出库时均校验审批链一致性。

提示文案：

> 所选资产与当前出库单审批路线不一致，请拆分出库单处理。

### 3.6 手工创建默认值

点击【创建】后：

| 字段 | 默认规则 |
|---|---|
| 出库类型 | 领用出库，只读 |
| 是否刷卡领用 | 否，只读 |
| 是否自购出库 | 否，可在草稿中选择是 / 否 |
| 当前仓库 | 用户选择有操作权限的资产仓 |

【添加物资】和 Excel 导入均用于添加当前仓库资产。

### 3.7 草稿资产编辑

草稿出库资产列表支持：

- 编辑；
- 复选删除；
- 添加物资；
- Excel 导入。

点击【编辑】复用“添加领用物资”弹窗并回显当前资产已保存的领用信息。

审批中、已完成单据按只读方式查看资产明细。

### 3.8 Excel 导入

手工资产领用出库草稿提供【模板下载】【Excel 导入】。

模板文件名：

> 出库单数据导入模板.xlsx

模板用于批量导入资产。字段包括：

| 字段 | 规则 |
|---|---|
| 错误提示 | 系统回写当前行错误 |
| 资产标签号 | 与 SN 至少填写一个 |
| SN号 | 与资产标签号至少填写一个 |
| 领用人（员工编号） | 必填 |
| 成本中心（编码） | 选填；填写时校验有效性 |
| 业务线 | 选填 |
| City | 选填；填写时校验有效性 |
| Building | 必填 |
| Floor | 必填 |
| 资产状态 | 必填 |
| 领用时间 | 必填，格式 YYYY-MM-DD |
| 用途 | 必填 |
| 项目 | 选填 |
| 领用说明 | 选填 |

资产状态枚举：

- 再利用-使用中；
- 在用-使用中。

用途枚举：

- 员工用机；
- 部门公用；
- 专业用途；
- 其他用途。

导入流程：

创建草稿 → 选择当前仓库 → 下载并填写模板 → 上传 Excel → 逐行校验 → 全部通过后确认导入 → 保存草稿资产 → 建立资产锁定

资产行规则：

1. 资产标签号和 SN 至少填写一个；同时填写时按资产标签号定位资产。
2. 资产必须属于当前仓库。
3. 来源资产状态为“在库-待处理”或“在库-新增”。
4. 资产按当前卡片数量整项出库。
5. 领用人、成本中心、业务线、地点、目标资产状态、领用时间、用途、项目按对应基础资料规则校验。
6. 导入后的资产继续满足当前出库单审批路线和责任审批链一致性。

Excel 导入采用整批校验。存在错误时，在【错误提示】中返回行级错误；全部通过后才能确认导入。

导入成功后锁定对应资产。删除导入明细或删除整张草稿时释放资产锁定。

### 3.9 正式出库

正式出库作为完整业务事务处理。

以下场景触发正式出库：

- “是否自购出库 = 否”的手工资产领用点击【执行出库】并校验通过；
- “是否自购出库 = 是”的手工资产领用最后审批节点同意；
- 上游资产申领、资产借用、低值耐用品领用、普通耗材领用正式执行。

正式出库完成后统一写入出库单、库存 / 台账变化和出库事务。

### 3.10 采购接收来源通知

正式出库物资属于采购接收来源时，完成出库后向对应采购专员发送服务号通知。

适用范围包括：

- 普通资产；
- 服务器；
- 服务器备件；
- 网络设备；
- 网络设备备件；
- 低值耐用品；
- 普通耗材。

采购专员根据物资本身的采购、PO 和采购接收关联关系确定。

系统保存通知结果，通知结果与正式出库结果分别记录。

## 5. 校验

### 5.1 草稿

| 校验项 | 规则 |
|---|---|
| 出库资产 | 至少 1 条 |
| 当前仓库 | 必填 |
| 出库数量 | 大于 0 |
| 资产仓库 | 与当前仓库一致 |
| 资产状态 | 属于允许出库状态 |
| 业务占用 | 当前资产处于可出库状态 |
| 领用字段 | 必填项完整 |
| 审批路线 | 单据内全部资产一致 |
| 审批责任链 | 单据内全部资产一致 |

资产仓库不一致提示：

> 资产不在当前库，请先执行移库操作！

必填信息不完整提示：

> 请检查所有必填项及内容格式

### 5.2 候选资产

选择资产和执行出库时均按 3.3 重新校验候选条件。

### 5.3 审批人

普通资产需要确定：

- 责任人；
- 责任人直属 7 级及以上领导；
- ES 出库管理员。

机房资产需要确定：

- 责任人；
- 责任人直属 7 级及以上领导。

审批链完整后才能发起审批。

### 5.4 审批操作

- 当前用户与当前审批节点处理人一致；
- 驳回时审批意见必填；
- 已完成节点保持只读；
- 最后节点同意前再次校验资产、仓库和业务状态。

### 5.5 Excel 导入

- 当前仓库已选择；
- 模板表头与正式出库模板一致；
- 每行资产标签号和 SN 至少填写一个；
- 同一文件中的资产唯一；
- 当前草稿中的资产唯一；
- 资产属于当前仓库；
- 来源资产状态为“在库-待处理”或“在库-新增”；
- 领用人、Building、Floor、目标资产状态、领用时间、用途按规则填写；
- 成本中心、业务线、项目填写时使用有效基础资料；
- 导入结果满足当前出库单审批路线和责任审批链一致性；
- 任一行校验失败时整批保持待确认状态，修正后重新上传。

### 5.6 删除

删除出库单时：

- 至少勾选 1 张单据；
- 所选单据全部为草稿。

删除草稿资产时：

- 当前单据为草稿；
- 删除前二次确认。

### 5.7 打印

正式出库打印和领用打印适用于已完成出库单。

打印内容来自已保存的出库单和出库明细。

## 6. 后续操作 / 业务结果 / 补充说明

### 6.1 草稿删除结果

删除草稿出库单后：

- 释放整张草稿的资产锁定；
- 资产重新进入合法业务候选范围；
- 正式资产台账、库存和事务记录保持原值。

删除草稿资产后：

- 从当前草稿移除对应明细；
- 释放对应资产锁定。

### 6.2 普通资产领用结果

正式出库完成后：

- 出库单状态更新为已完成；
- 记录正式出库时间；
- 资产从当前仓库可用库存中移出；
- 资产责任人更新为领用人；
- 更新部门、公司、成本中心、业务线；
- 更新 City、Building、Floor；
- 更新用途、使用说明；
- 资产状态更新为“在用-使用中”；
- 生成资产出库事务及相关报表数据。

### 6.3 机房资产领用结果

正式出库完成后：

- 出库单状态更新为已完成；
- 记录正式出库时间；
- 资产从当前仓库可用库存中移出；
- 更新实际责任人；
- 更新实际使用位置；
- 更新在用状态；
- 保留 NO 位置及服务等机房资产属性；
- 生成机房资产出库事务及相关报表数据。

### 6.4 借用出库结果

员工资产借用正式执行后：

- 自动生成已完成借用出库单；
- 资产状态更新为“在用-借用中”；
- 保存借用人、借用开始日期和预计归还日期；
- 资产从当前仓库可用库存中移出；
- 生成资产借用出库事务；
- 后续通过借用归还入库闭环。

### 6.5 普通耗材 / 低值耐用品出库结果

普通耗材领用流程正式执行后：

- 按领用数量扣减目标耗材仓库存；
- 更新耗材库存台账；
- 生成耗材出库事务；
- 自动生成已完成领用出库单。

低值耐用品领用流程正式执行后：

- 扣减耗材仓库存；
- 更新低值耐用品耗材台账；
- 保存耗材标签号、SN、领用人等结果；
- 生成耗材出库事务；
- 自动生成已完成领用出库单。

### 6.6 审批驳回结果

审批驳回后：

- 单据恢复草稿；
- 已维护出库资产继续保留；
- 本轮审批记录继续保留；
- 资产锁定继续关联当前草稿；
- 制单人修改后可再次执行出库。

### 6.7 采购接收来源通知

正式出库完成且物资属于采购接收来源时：

- 向对应采购专员发送服务号通知；
- 系统保存通知结果；
- 正式出库结果按已完成状态保留。

### 6.11 打印通用规则

- 单条打印和批量打印使用同一字段口径；
- 打印、预览、重打读取已保存数据；
- 空值按空白展示；
- 金额保留两位小数；
- 整数数量按整数展示；
- 明细跨页时重复表头并显示页码；
- 打印失败后可重新打印同一业务单。

### 6.12 关键流程

普通资产手工领用：

> 创建草稿 → 选择同一审批链普通资产 → 执行出库 → 责任人确认 → 责任人直属 7 级及以上领导审批 → ES 出库管理员确认 → 正式出库 → 台账 / 库存 / 事务更新 → 采购接收来源通知采购专员

机房资产手工领用：

> 创建草稿 → 选择同一审批链机房资产 → 执行出库 → 责任人直属 7 级及以上领导审批 → 正式出库 → 台账 / 库存 / 事务更新 → 采购接收来源通知采购专员

员工资产申领：

> 员工资产申领流程 → 员工确认 → 正式出库 → 自动生成已完成领用出库单 → 库存管理查询 / 查看 / 打印

资产借用：

> 员工资产借用流程 → 审批及员工确认 → 正式借用出库 → 自动生成已完成借用出库单 → 资产状态更新为“在用-借用中” → 后续借用归还入库

普通耗材领用：

> 耗材申请 / 配给 → 员工确认 → 正式出库 → 扣减耗材库存并更新台账 → 自动生成已完成领用出库单

低值耐用品领用：

> 低值耐用品申请 / 配给 → 员工确认 → 正式出库 → 更新低值耐用品耗材台账 → 自动生成已完成领用出库单
