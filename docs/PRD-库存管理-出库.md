# 库存管理 - 出库

## 页面范围

本页面位于「库存管理 → 出库」。本轮根据历史系统截图补齐创建出库单后的编辑页和添加物资弹窗。历史截图只作为字段与业务分支来源，页面结构和视觉继续遵循当前资产系统 UI 规范。

## 出库类型

- 领用出库
- 借用出库

两种类型共用出库单头；物资列表和添加物资后的业务维护字段按出库类型区分。

## 出库单头

- 出库单号：保存后自动生成
- 单据类型：出库工单
- 单据状态
- 出库类型
- 制单人
- 制单时间
- 是否刷卡领用
- 当前仓库
- 备注：多行文本，独占完整一行

## 页面操作

- 创建：进入出库单编辑页
- 添加物资：按当前出库类型打开对应添加物资弹窗
- 删除物资：删除勾选物资行
- Excel导入：保留出库物资导入入口
- 保存草稿：保存当前单据
- 出库单打印：保留打印入口
- 返回：返回出库列表

页面级操作放页面底部居中；物资区域的添加、删除、导入操作保留在「出库物资」Card 内。
