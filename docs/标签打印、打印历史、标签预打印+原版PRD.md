# 标签打印、打印历史、标签预打印 PRD

**标签打印**：打印已经存在的资产标签。**标签预打印**：在资产实际形成前，按标签编码规则提前批量生成标签号并打印。**打印历史**：查询预打印批次以及标签实际打印记录。

## 标签打印、打印历史、标签预打印 PRD

## 一、标签打印

## 功能说明

“标签打印”用于从当前系统已有的资产标签打印数据中查询资产，并通过本地标签打印机打印资产标签。

整体流程：

**进入资产标签打印**

→ 查询需要打印的资产

→ 勾选指定资产 / 打印当前查询范围全部资产

→ 设置打印份数

→ 调用本地 Brother b-PAC 打印组件

→ 按现有标签模板执行打印

→ 更新标签打印次数

## 页面查询条件

当前资产标签打印页面提供：

| **查询项** | **交互** | **当前规则** |
| --- | --- | --- |
| 公司中文名称 | 文本输入 | 按现有查询框架过滤 |
| 公司英文名称 | 文本输入 | 按现有查询框架过滤 |
| 部门 | 部门选择 | 支持选择部门范围 |
| 板块中文名称 | 文本输入 | 按现有字段查询 |
| 资产状态 | 下拉 | 使用 `ASSET_STATUS` |
| 资产标签号 | 文本输入 | 按标签号查询 |
| 序列号 | 文本输入 | 按 SN 查询 |
| 使用人 | 弹窗选择 | 按责任人员工编号查询 |
| 城市 | 下拉/选择 | 来源现有 City 数据 |

## 默认排序

**默认按照City → 使用人编号升序 → 资产标签号升序**

## 打印所选

用户勾选一条或多条资产，点击：

> **打印所选**

未选择资产：

> 请选择要打印的资产标签！

系统逐条校验。

### 公司英文名

公司英文名称为空：

> 资产标签号为“XXX”项没有公司英文名！

### 公司中文名

优先取：

> 板块中文名称

为空时回退：

> 公司中文名称

仍为空：

> 资产标签号为“XXX”项没有公司中文名！

## 打印份数

开始打印前，系统打开：

> **打印几份**

弹窗。

用户设置本次打印份数后，将数量传递给本地打印组件。

## 本地打印环境

当前资产标签打印不是由服务器生成 PDF，而是直接调用用户电脑上的打印组件。

运行依赖：

### 浏览器

当前主要要求：

> **Google Chrome**

### 浏览器插件

需要安装：

> **Brother b-PAC 浏览器打印组件**

未安装插件时：

Chrome：

> 请安装插件

其他浏览器：

> 请使用谷歌浏览器且安装插件

## 打印次数

“打印所选”完成后，针对本次选中的资产，将：

> **累计打印次数 += 本次打印份数**

因此打印次数统计的是标签被要求打印的累计份数。

## 打印全部

点击：**打印全部**含义不是打印当前分页，而是：**打印当前查询条件范围内全部标签数据。页面同样打开打印次数弹窗**

## 二、标签预打印

## 功能说明

“标签预打印”用于在资产实际接收或正式建卡前，根据现有资产标签编码规则：

1. 选择标签编码规则；

1. 预先生成一批资产标签号；

1. 形成标签批次；

1. 查看批次内标签；

1. 批量打印标签。

其核心对象不是正式资产，而是：

> **标签批次 + 标签明细**

## 标签预打印整体流程

**进入标签打印历史/批次列表**

→ 点击“预打印”

→ 进入“标签打印-预打印”

→ 选择账套

→ 选择标签编码规则

→ 输入生成标签数量

→ 设置标签大小、部件数量

→ 点击“生成标签”

→ 系统生成标签批次

→ 按序号规则生成标签明细

→ 展示批次号

→ 点击“打印标签”

→ 打开本批次标签清单

→ 打印所选 / 打印全部

→ 更新批次、标签打印状态

→ 写入打印日志

## 预打印页面

页面标题：

> **标签打印-预打印**

页面操作：

| **操作** | **当前规则** |
| --- | --- |
| 返回 | 返回上一页 |
| 生成标签 | 根据当前标签设置生成标签 |
| 打印标签 | 标签生成成功前隐藏，成功后展示 |

## 选择账套

“选择账套”为必填。

候选数据来源：

> `MMP_ASSETS_TAG_ACCOUNT`

展示：

> 账套编码 - 账套名称

标签的编码规则和最终打印中英文名称均可能与所选账套相关。

未选择账套时，不允许正常生成标签。

## 标签编码规则

当前支持 5 类标签规则。

| **规则** | **需要设置的信息** |
| --- | --- |
| 常规标签规则 | 资产类型 + 年份 |
| 高耗标签规则 | 高耗大类 + 高耗小类 + 年份 |
| 特殊规则-家具 | 家具类型 |
| 特殊规则-手机 | 固定使用手机标签规则 |
| 特殊规则-备件 | 备件类型 |

系统匹配现有标签流水号规则，再确定当前最大流水号及下一标签编号。

## 常规标签规则

选择：

> **常规标签规则**

需要维护：

- 资产类型；

- 年份。

资产类型来源：

> `ASSETS_TYPE`

页面展示：

> 当前最大序号

生成时根据：

> 账套 + 资产类型 + 年份

找到对应流水号配置。

## 高耗标签规则

选择：

> **高耗标签规则**

需要：

- 高耗大类；

- 高耗小类；

- 年份。

普通高耗标签使用当前：

> `QT-` 类规则

部分特定高耗类别按照小类使用不同标签前缀。

## 特殊规则—家具

家具标签使用：

> `RULE_SPECIAL_FURNITURE`

对应规则。

需要选择家具类型。

该规则下“当前最大序号”在当前页面存在人工调整入口。

如果人工输入的流水号小于系统已有最大流水号，后台会检查该范围是否已经被使用。

如果将产生流水号重叠：

> 当前输入的流水号，存在已经被使用的情况！

不允许生成。

## 特殊规则—手机

手机特殊标签：

> 固定前缀 `NE`

页面展示当前最大流水号。

生成时继续按照现有手机标签流水规则递增。

## 特殊规则—备件

需要选择：

> 备件类型

使用当前：

> `RULE_SPECIAL_SPARE_PARTS`

对应的标签序号规则生成。

## 标签生成设置

| **字段** | **当前规则** |
| --- | --- |
| 打印标签数量 | 默认 1，必须为正整数 |
| 部件数量 | 默认 1，允许 1～99 |
| 标签批次 | 生成前显示“生成标签后自动生成” |
| 操作员 | 当前登录用户 |
| 当前日期 | 当前系统日期 |
| 备注说明 | 用户填写 |
